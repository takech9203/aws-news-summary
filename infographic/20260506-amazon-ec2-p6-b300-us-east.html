📋 概要

Amazon EC2 P6-B300 インスタンスが US East (N. Virginia) リージョンで利用可能になりました。8 基の NVIDIA Blackwell Ultra GPU を搭載し、数兆パラメータ規模の基盤モデルや大規模言語モデルのトレーニング・デプロイに最適化された最上位 GPU インスタンスです。

8 基 NVIDIA Blackwell Ultra GPU
2.1 TB 高帯域幅 GPU メモリ
6.4 Tbps EFA ネットワーキング
4 TB システムメモリ

❌ BEFORE

  • P6-B300 は US West (Oregon) と GovCloud (US-East) の 2 リージョンのみ

  • US East (N. Virginia) で最高性能 GPU リソースに地理的制約

✅ AFTER

  • US East (N. Virginia) で P6-B300 が利用可能に
  • 東海岸から低レイテンシーで最高性能 GPU にアクセス
  • 3 リージョンでのワークロード分散・災害復旧が可能

⚡ 主要機能

🎮 NVIDIA Blackwell Ultra GPU
8 基搭載。FP4 (スパーシティなし) で P6-B200 比 1.5 倍の GPU TFLOPS。数兆パラメータ規模のモデルのトレーニングとデプロイに最適化。
🧠 大容量 GPU メモリ
2.1 TB の高帯域幅 GPU メモリ (HBM)。P6-B200 比 1.5 倍。大規模モデルのメモリ内保持が可能で、モデル並列化の必要性を低減。
🌐 高速ネットワーキング
6.4 Tbps の EFA + 300 Gbps の専用 ENA スループット。P6-B200 比 2 倍のネットワーク帯域幅で分散トレーニングを加速。
💾 大容量システムメモリ
4 TB のシステムメモリ。データの前処理、モデルのロード、大規模データセットのバッファリングに十分な容量。

🔧 設定方法

前提条件

1. US East (N. Virginia) リージョンへのアクセス権限を持つ AWS アカウント
2. P6-B300 インスタンスのサービスクォータが承認済みであること
3. EFA 対応の AMI とセキュリティグループの設定
4. 適切な VPC とサブネットの構成

ステップ 1: サービスクォータの確認

Bash クォータ確認 
aws service-quotas get-service-quota \
  --service-code ec2 \
  --quota-code L-417A185B \
  --region us-east-1

ステップ 2: EFA 対応セキュリティグループの作成

Bash セキュリティグループ作成 
aws ec2 create-security-group \
  --group-name p6-b300-efa-sg \
  --description "Security group for P6-B300 with EFA" \
  --vpc-id vpc-xxxxxxxx \
  --region us-east-1

aws ec2 authorize-security-group-ingress \
  --group-id sg-xxxxxxxx \
  --protocol -1 \
  --source-group sg-xxxxxxxx \
  --region us-east-1

ステップ 3: インスタンスの起動

Bash P6-B300 インスタンス起動 
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-xxxxxxxx \
  --key-name my-key-pair \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxxxxxxx,Groups=sg-xxxxxxxx,InterfaceType=efa" \
  --region us-east-1

AMI は NVIDIA ドライバーと EFA ドライバーがプリインストールされた Deep Learning AMI の使用を推奨します。

🎯 ユースケース

🚀 大規模基盤モデルの分散トレーニング
AI スタートアップが数兆パラメータ規模の基盤モデルを US East (N. Virginia) で分散トレーニング。既存のデータパイプラインや S3 バケットが同リージョンにあるため、データ転送コストを最小化。8 ノード x 8 GPU = 64 GPU で 16.8 TB の合計 GPU メモリを活用し、高いスケーリング効率を実現。
Bash 分散トレーニングクラスター起動 
# プレースメントグループの作成
aws ec2 create-placement-group \
  --group-name p6-b300-training-cluster \
  --strategy cluster \
  --region us-east-1

# P6-B300 クラスターでの分散トレーニング起動
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --count 8 \
  --image-id ami-deep-learning-base \
  --placement "GroupName=p6-b300-training-cluster" \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=sg-xxx,InterfaceType=efa" \
  --region us-east-1
💬 大規模 LLM の推論サービング
トリリオンパラメータ規模の LLM を本番環境でデプロイし、リアルタイムの推論サービスを提供。2.1 TB の GPU メモリにより超大規模モデルを単一インスタンスにロードでき、300 Gbps の ENA スループットで大量リクエストを高スループット処理。US East (N. Virginia) のエンドユーザーに低レイテンシーで応答を返す。
🌍 マルチリージョンでの AI ワークロード分散
グローバル企業が US West (Oregon) と US East (N. Virginia) の両リージョンで P6-B300 を使用し、地理的な冗長性を持つ AI プラットフォームを構築。リージョン障害時のフェイルオーバーやピーク時の負荷分散、エンドユーザーの地理的位置に基づいたルーティングにより全体的なレイテンシーを最適化。

💰 料金情報

P6-B300 インスタンスはオンデマンド、Reserved Instances、Savings Plans の各購入オプションで利用可能です。

購入オプション 特徴

最上位 GPU インスタンスのため、コスト最適化には Reserved Instances や Savings Plans の活用を推奨します。
