📌 概要

Amazon EC2 C7i インスタンスが、欧州 (ミラノ) およびカナダ西部 (カルガリー) リージョンで利用可能になりました。 AWS 専用のカスタム第 4 世代 Intel Xeon Scalable プロセッサ (Sapphire Rapids) を搭載したコンピューティング最適化インスタンスで、 バッチ処理、分散分析、広告配信、動画エンコーディングなどのコンピューティング集約型ワークロードに最適です。

😣 Before - アップデート前の課題
  • C7i がミラノ・カルガリーリージョンで利用できなかった
  • 第 4 世代 Intel Xeon Scalable プロセッサの性能を活用できなかった
  • データレジデンシー要件を満たしながら最新のコンピューティング最適化インスタンスを利用することが困難だった
😊 After - アップデート後の改善
  • 両リージョンで C7i インスタンスを直接起動可能に
  • C6i からの移行で最大 15% の価格パフォーマンス改善を実現
  • 最大 48xlarge と 2 つのベアメタルサイズで大規模ワークロードを両リージョンで実行可能に

⚡ 主要機能

🚀 C7i インスタンス
  • C6i と比較して最大 15% 優れた価格パフォーマンス
  • 最大 48xlarge までのサイズと metal-24xl / metal-48xl の 2 つのベアメタルサイズ
  • 継続的な高 CPU 使用率が必要なワークロードに最適
  • バッチ処理、分散分析、広告配信、動画エンコーディングに適している
🧠 カスタム第 4 世代 Intel Xeon Scalable プロセッサ
  • コードネーム Sapphire Rapids
  • AWS 専用のカスタムプロセッサ
  • 他のクラウドプロバイダーが使用する同等の x86 ベース Intel プロセッサと比較して最大 15% 優れたパフォーマンス
🔧 内蔵 Intel アクセラレータ (ベアメタルサイズのみ)
  • DSA (Data Streaming Accelerator): データストリーミング操作を効率化
  • IAA (In-Memory Analytics Accelerator): インメモリ分析を高速化
  • QAT (QuickAssist Technology): 暗号化と圧縮処理を高速化
  • データ操作の効率的なオフロードと高速化により、ワークロードのパフォーマンスを向上

ステップ 1: C7i インスタンスの起動

Bash ミラノリージョン eu-south-1 で起動 
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c7i.4xlarge \
  --region eu-south-1 \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --security-group-ids sg-xxxxxxxxxxxxxxxxx \
  --key-name my-key-pair

カナダ西部 (カルガリー) の場合は --region ca-west-1 を指定します。

ステップ 2: 利用可能なインスタンスタイプの確認

Bash カルガリーリージョンの C7i タイプ一覧を表示 
aws ec2 describe-instance-types \
  --filters "Name=instance-type,Values=c7i.*" \
  --region ca-west-1 \
  --query "InstanceTypes[].{Type:InstanceType,vCPU:VCpuInfo.DefaultVCpus,Memory:MemoryInfo.SizeInMiB}" \
  --output table

⚖️ メリットと制約事項

👍 メリット

✓コスト効率の向上: C6i 比で最大 15% 優れた価格パフォーマンスによりコンピューティングコストを削減
✓リージョン拡大: データレジデンシー要件を満たしながら最新インスタンスを利用可能
✓柔軟なサイジング: 最大 48xlarge と 2 つのベアメタルサイズから選択可能
✓高性能プロセッサ: AWS 専用カスタム第 4 世代 Intel Xeon Scalable プロセッサ
✓内蔵アクセラレータ: ベアメタルサイズで DSA / IAA / QAT を利用可能

⚠️ 制約・考慮点

✗DSA / IAA / QAT はベアメタルサイズ (metal-24xl / metal-48xl) でのみ利用可能
✗新規リージョンでは初期のサービスクォータが制限される場合がある
⚠コンピューティングリソースを完全に活用しないワークロードには C7i-flex の利用を検討
⚠既存の C6i インスタンスからの移行は新規起動で行う必要がある

💡 ユースケース

📦 大規模バッチ処理と分散分析

シナリオ: カナダ西部のデータレジデンシー要件を満たしながら、大規模なバッチ処理や分散分析をカルガリーリージョンで実行したい。

Bash 実装例 
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c7i.48xlarge \
  --region ca-west-1 \
  --iam-instance-profile Name=Batch-Processing-Role

効果: 最大 192 vCPU / 384 GiB メモリにより大規模なバッチ処理を高速に実行。データレジデンシー要件を満たしながら、C6i 比で最大 15% 優れた価格パフォーマンスを実現。

📝 まとめ

Amazon EC2 C7i インスタンスが欧州 (ミラノ) およびカナダ西部 (カルガリー) リージョンで利用可能になりました。 カスタム第 4 世代 Intel Xeon Scalable プロセッサ (Sapphire Rapids) を搭載し、C6i と比較して最大 15% 優れた価格パフォーマンスを提供します。 最大 48xlarge と 2 つのベアメタルサイズにより、大規模なコンピューティング集約型ワークロードにも対応します。 両リージョンでコンピューティング集約型ワークロードを実行しているお客様は、C7i への移行を検討し、パフォーマンスとコスト効率の向上を実現してください。
