🧠 Claude Sonnet 5 が AWS で利用可能に

Amazon Bedrock Claude Platform on AWS
2026-06-30
リリース日

📌 概要

AWS は Anthropic Claude Sonnet 5 の提供を開始しました。Sonnet ファミリーで最も高性能なモデルであり、Anthropic 最新世代における初の Sonnet モデルです。Sonnet の価格帯を維持しながら、コーディング、エージェント、日常的な専門業務において最上位レベルの知能を大規模に提供します。

能力・コスト・速度のバランスを保ちながら、大規模なコードベースの把握、複数ファイルにまたがる変更、ツールの正確な呼び出しと状態保持、非構造化データの構造化分析への変換まで幅広く対応します。お客様は Amazon Bedrock と Claude Platform on AWS という 2 つの経路でアクセスできます。

❌ アップデート前の課題

  • 最新世代の Sonnet モデルを AWS 上で利用できなかった
  • Sonnet の価格帯で最上位レベルの知能を大規模に活用しにくかった
  • 複数ファイルにまたがるコード変更やエージェントタスクで修正の往復が多かった

✅ アップデート後の改善

  • Anthropic 最新世代の Sonnet モデルを AWS 上で利用可能に
  • Sonnet の価格帯で最上位レベルの知能をコーディング・エージェント・専門業務に活用可能に
  • 用途に応じて 2 つのアクセス方法を選択可能に

ユーザーやアプリケーションは Amazon Bedrock または Claude Platform on AWS のいずれかの経路で Claude Sonnet 5 にアクセスします。Amazon Bedrock 経由では Guardrails、Knowledge Bases、データレジデンシーなどの AWS マネージド機能を併用できます。

⚡ 主要機能

💻 コーディング能力

  • 大規模なコードベースを把握して操作する
  • 複数ファイルにまたがる変更を実装する
  • デバッグやリファクタリングを、修正の往復を減らしながら完遂する

🤖 エージェント能力

  • ツールを正確に呼び出す
  • 多数のステップにわたって状態を保持する
  • エラーから回復する

📊 ナレッジワーク能力

  • スプレッドシートを作成する
  • ドキュメントを起草する
  • 非構造化データを構造化された分析に変換する

🔧 技術仕様 — アクセス経路の比較

🛡️ Amazon Bedrock

データを AWS インフラストラクチャ内に保持。Guardrails、Knowledge Bases、リージョン別データレジデンシーなどの AWS マネージド機能を統合サービスとして提供。

クライアント: AnthropicBedrockMantle

モデル ID: anthropic. プレフィックス付き

🎛️ Claude Platform on AWS

AWS マネジメントコンソールから Anthropic ネイティブのプラットフォーム体験に直接アクセス。AWS による統合された請求と認証を利用。

クライアント: AnthropicAWS

モデル ID: プレフィックスなしのファーストパーティ文字列

🛠️ 設定方法

前提条件

✓AWS アカウントと、Amazon Bedrock または Claude Platform on AWS へのアクセス権限
✓利用するリージョンでの Claude Sonnet 5 へのモデルアクセスの有効化
✓適切な IAM 権限と AWS 認証情報の設定

ステップ 1: モデルアクセスの確認

Amazon Bedrock マネジメントコンソールのモデルアクセス画面で、Claude Sonnet 5 へのアクセスを有効化します。利用可能なリージョンは Bedrock のモデルリージョン対応ドキュメントで確認してください。

ステップ 2: Amazon Bedrock 経由での呼び出し

Mantle クライアントを使用し、anthropic. プレフィックス付きのモデル ID を指定します。aws_region の指定は必須です。

PythonAmazon Bedrock (Mantle クライアント)
from anthropic import AnthropicBedrockMantle

client = AnthropicBedrockMantle(aws_region="us-east-1")

response = client.messages.create(
    model="anthropic.claude-sonnet-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "リファクタリング対象のコードを分析してください"}],
)

ステップ 3: Claude Platform on AWS 経由での呼び出し

AWS 向けクライアントを使用し、プレフィックスなしのモデル ID を指定します。認証は AWS の SigV4 と IAM に基づきます。

PythonClaude Platform on AWS
from anthropic import AnthropicAWS

# AWS_REGION と ANTHROPIC_AWS_WORKSPACE_ID は環境変数から取得
client = AnthropicAWS()

response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=16000,
    messages=[{"role": "user", "content": "リファクタリング対象のコードを分析してください"}],
)

🎯 メリット

💼 ビジネス面

✓コスト効率: Sonnet の価格帯で最上位レベルの知能を利用でき、大規模展開に適する
✓柔軟なアクセス: どちらの経路を選んでも AWS の請求・認証と統合
✓幅広い適用範囲: コーディング・エージェント・専門業務を 1 つのモデルでカバー

⚙️ 技術面

✓マルチファイル変更: 大規模コードベースの変更を往復を減らして完遂
✓エージェントの信頼性: 正確なツール呼び出し、状態保持、エラー回復
✓マネージド機能統合: Bedrock 経由で Guardrails や Knowledge Bases と組み合わせ可能

⚠️ デメリット・制約事項

制限事項

▲利用可能なリージョンは限定されており、Bedrock のモデルリージョン対応ドキュメントで確認が必要
▲料金の具体的な数値は本発表では明示されておらず、別途料金ページの確認が必要
▲Fast Mode や Message Batches などの一部機能は、アクセス経路によって対応状況が異なる場合がある

考慮すべき点

▲データレジデンシーやデータ保持の要件に応じて、どちらの経路が適しているかを評価する必要がある
▲既存アプリの移行時は、経路に応じてクライアントクラスとモデル ID のプレフィックスを正しく使い分ける必要がある

💡 ユースケース

1. 大規模コードベースのリファクタリング

シナリオ: 複数ファイルにまたがる変更が必要なレガシーアプリのリファクタリングを開発チームが効率化したい。

実装例: Amazon Bedrock 経由で Claude Sonnet 5 を呼び出し、コードベースの構造を把握させたうえで、複数ファイルにまたがる変更案を生成しデバッグまで完遂させる。

✅ 効果: 修正の往復が減り、リファクタリングやデバッグの所要時間を短縮できる。

2. ツールを活用するエージェントの構築

シナリオ: 社内システムと連携し、多数のステップを自律的に実行するエージェントを構築したい。

実装例: ツール定義を渡し、ツールの呼び出しと結果処理を多数のステップにわたって実行させ、途中でエラーが発生しても回復しながらタスクを完了させる。

✅ 効果: 状態保持とエラー回復により、長い手順のエージェントワークフローを安定して実行できる。

3. 非構造化データの構造化分析

シナリオ: 散在する非構造化のドキュメントやメモから、意思決定に使える構造化データを作成したい。

実装例: 非構造化の素材を Claude Sonnet 5 に入力し、スプレッドシートやレポートとして整理された分析結果を生成させる。

✅ 効果: 手作業による整理の負担を減らし、専門業務の生産性を高められる。

💰 料金・利用可能リージョン

料金: Claude Sonnet 5 は Sonnet の価格帯で提供されます。本発表では具体的な料金は示されていないため、最新情報は Amazon Bedrock の料金ページおよび Claude Platform on AWS の料金情報で確認してください。Amazon Bedrock では入力トークンと出力トークンに基づく従量課金が適用されます。
利用可能リージョン: 本発表では具体的なリージョンの一覧は示されていません。利用可能なリージョンは Amazon Bedrock のモデルリージョン対応ドキュメント (Anthropic モデルのセクション) で確認してください。

🔗 関連サービス・機能

🚧 Amazon Bedrock Guardrails

📚 Amazon Bedrock Knowledge Bases

🎛️ Claude Platform on AWS

Anthropic ネイティブのプラットフォーム体験に AWS の請求・認証で直接アクセスできる。

📝 まとめ

Claude Sonnet 5 が Amazon Bedrock と Claude Platform on AWS の両方で利用可能になり、Anthropic 最新世代の Sonnet モデルを AWS 上で活用できるようになりました。コーディング、エージェント、ナレッジワークを Sonnet の価格帯で大規模に実行したいお客様にとって有力な選択肢です。まずは利用リージョンでモデルアクセスを有効化し、データレジデンシーや認証の要件に応じて、どちらの経路が適しているかを評価することを推奨します。
