📣 Amazon Quick が AWS Quick に名称変更

リリース日: 2026 年 11 月 9 日
AWS Quick AWS Quick Sight リブランディング 機能・料金への影響なし

📝 概要

仕事専用に構築された AI ワークスペースである Amazon Quick が AWS Quick に名称変更されました。 新名称は、Quick が AWS サービスとして当初から備えているエンタープライズレベルのセキュリティとガバナンスを反映したものです。 あわせて、ビジネスインテリジェンス機能の Amazon Quick Sight も AWS Quick Sight に名称変更されました。

今回のアップデートは名称変更のみであり、機能、API、料金体系への影響はありません。既存のお客様に必要な対応はなく、Quick はこれまでと同じように動作します。

旧名称 🏷️ Amazon Quick
→
新名称 ✨ AWS Quick
旧名称 (BI 機能) 🏷️ Amazon Quick Sight
→
新名称 (BI 機能) ✨ AWS Quick Sight

❌ アップデート前

  • サービス名は「Amazon Quick」、BI 機能は「Amazon Quick Sight」ブランドで提供
  • 名称からは、AWS サービスとして組み込まれているエンタープライズセキュリティとガバナンスが伝わりにくかった

✅ アップデート後

  • サービス名が「AWS Quick」、BI 機能が「AWS Quick Sight」に変更
  • 新名称がウェブサイト、Web / デスクトップ / モバイルアプリ、AWS ドキュメントに反映
  • データ、設定、料金、利用方法には一切変更なし

🔧 サービスアップデートの詳細

1️⃣ Amazon Quick から AWS Quick への名称変更

  • AI ワークスペース本体の名称が AWS Quick に変更
  • AWS サービスとして最初から組み込まれているエンタープライズセキュリティとガバナンスを反映する命名
  • 新名称は Quick ウェブサイト、Web / デスクトップ / モバイルアプリ、AWS ドキュメントに反映

2️⃣ Amazon Quick Sight から AWS Quick Sight への名称変更

  • Quick のビジネスインテリジェンス機能も同様に名称変更
  • ダッシュボード、データセット、分析は従来どおり利用可能
  • データ、設定、料金に変更なし

3️⃣ 既存ユーザーへの影響なし

  • 既存のお客様に必要な対応はない
  • Quick の動作はこれまでと同じ

💡 AWS Quick とは

AWS Quick は、チームが AI エージェントを使って、ベンダーを問わず既存のデータやアプリケーション全体で リサーチ、分析、実行を行える AI ワークスペースです。 ユーザーの役割、チーム、業務のつながりを理解し、誰でも自然言語でエージェント、アプリ、自動化を構築して、チーム全体の共有資産にできます。

🎯 考慮すべき点

→ 社内ドキュメント、アーキテクチャ資料、調達関連資料などで「Amazon Quick」「Amazon Quick Sight」と記載している場合は、新名称「AWS Quick」「AWS Quick Sight」への表記更新を検討する
→ AWS ドキュメントやウェブサイト上の表記は新名称に切り替わるため、検索や参照の際は新名称を使用する
→ 機能や API に変更はないため、技術的な移行作業は発生しない

💰 料金と利用可能リージョン

💵 料金

今回の名称変更に伴う料金の変更はありません。Quick Sight を含む Quick の各機能は、従来と同じ料金体系で利用できます。詳細は AWS Quick のページを参照してください。

🌏 利用可能リージョン

AWS Quick は多数の AWS リージョンで利用可能です。最新のリージョン対応状況は AWS リージョン別サービス一覧を参照してください。
