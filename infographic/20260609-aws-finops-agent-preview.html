💰 AWS FinOps Agent

AWS FinOps Agent プレビュー
📅 リリース日: 2026 年 6 月 9 日

📌 概要

AWS は、FinOps 担当者やエンジニアリングチーム向けのフロンティアエージェントである AWS FinOps Agent のプレビュー提供を発表しました。コストに関する質問への回答、最適化機会の提示、コスト異常の自動調査、定期的な FinOps ワークフローの実行を担います。

自然言語で AWS コストについて質問でき、Cost Optimization Hub と Compute Optimizer からライトサイジング、アイドルリソース、Savings Plans の推奨を抽出して Jira チケットを作成できます。コスト異常が検出されると根本原因を自動調査し、結果を Slack に投稿します。対象は FinOps プラクティショナー、財務チーム、コストに責任を持つエンジニアリングチームです。

😓 アップデート前の課題
  • コスト異常時に Cost Explorer や CloudTrail を手作業で確認し、原因や責任者を特定する必要があった
  • 推奨事項の確認に Cost Optimization Hub や Compute Optimizer を個別に参照する必要があった
  • 定期的なコストレポートの作成・共有を手動で実施し、運用負荷が高かった
  • コストに関する質問への回答に、専門知識を持つ担当者の対応が必要だった
🎉 アップデート後の改善
  • CloudTrail との相関分析で、根本原因と責任者の候補を含むレポートを自動生成
  • 自然言語で質問し、実データに基づいた回答を取得できる
  • 日次・週次・月次のスケジュールでワークフローを自動実行
  • 調査結果や推奨を Jira / Slack へ自動連携し、手動トリアージが不要に

AWS FinOps Agent は、スケジュール実行・コスト異常検出・エンジニアからの質問の 3 つのトリガーで起動し、各種コスト管理サービスからデータを取得して Jira や Slack に結果を連携します。

⚡ 主要機能

🗣️ 自然言語によるコスト照会
  • 自然言語で AWS コストについて質問できる
  • 実際のコスト・使用量データに基づく回答
  • クラウドコストレポートを生成できる
🔍 コスト異常の自動調査
  • Cost Anomaly Detection のイベントで起動
  • CloudTrail イベントと相関分析
  • 根本原因の候補と責任者を含むサマリーを生成
  • ドル単位のしきい値などでフィルタ可能
💡 最適化機会の提示
  • Cost Optimization Hub と Compute Optimizer から推奨を抽出
  • ライトサイジング・アイドルリソース・Savings Plans
  • 推奨をまとめて Jira チケットを作成
🔄 定期的なワークフロー実行
  • 日次・週次・月次など任意のスケジュールで実行
  • HTML・PDF・PPT 形式でレポートを生成
🧠 コンテキストファイルとメモリ
  • アカウントと所有者のマッピングなど組織固有ファイルをアップロード
  • セッションをまたいで設定や好みを記憶

🛠️ 設定方法

前提条件

  • AWS Management Console へのサインインができること
  • US East (N. Virginia) us-east-1 リージョンを利用すること
  • クロスアカウント / クロスリージョンの場合は管理アカウントでセットアップ
  • IAM ロールのプロビジョニングが可能であること

導入ステップ

エージェントの作成
us-east-1 に切り替え、AWS FinOps Agent のページからエージェントを作成します。
IAM ロールのセットアップ
ワンクリックの IAM ロールセットアップで、各サービスへのアクセスに必要なカスタマー管理ロールを作成します。
外部ツールの連携 (任意)
Jira のスペースキーや Slack チャンネルを接続し、結果を連携できるようにします。
コンテキストのアップロードと利用開始
Web アプリを開き、初期コンテキストをアップロードして最初の自然言語クエリと自動化を設定します。

✅ メリット

💼 ビジネス面

  • 運用負荷の削減: 異常調査やレポート作成の手作業を自動化
  • コスト最適化の促進: 推奨を自動提示し最適化機会を見逃しにくく
  • 意思決定の迅速化: コストの質問にすぐ回答し判断を加速

🔧 技術面

  • 既存ツールとの統合: Jira や Slack に結果を連携
  • 根本原因の自動特定: CloudTrail 相関で要因や責任者を特定
  • 柔軟なスケジューリング: 日次・週次・月次でワークフローを定義

🚧 デメリット・制約事項

制限事項

  • プレビュー版であり、利用には月間の使用量上限が設定されている
  • US East (N. Virginia) us-east-1 リージョンでのみエージェントを利用できる
  • コスト・使用量データのカバー範囲は GovCloud (US) と中国 (北京・寧夏) を除く全リージョン
  • クロスアカウント / クロスリージョン管理には管理アカウントでのセットアップが必要

考慮すべき点

  • プレビュー中はエージェント自体は追加料金なしだが、関連サービスには標準料金が適用
  • IAM ロールのプロビジョニングが必要なため、適切な権限管理を検討
  • プレビュー版のため、本番利用は機能や制約を十分に評価したうえで判断する

🎯 ユースケース

1. コスト異常の自動調査と通知
シナリオ: 予期しないコスト増加が発生した際に、原因特定と関係者への通知を迅速に行いたい。
FLOW実装例
1. Cost Anomaly Detection で異常を検出
2. AWS FinOps Agent がイベントを受信して起動
3. CloudTrail イベントと相関分析し、根本原因と責任者を特定
4. 調査結果のサマリーを Slack チャンネルに自動投稿
💡 効果: 手動トリアージが不要になり、コスト異常への対応を迅速化できます。
2. 定期的なコストレポートの自動配信
シナリオ: 経営層やプロジェクトチームへ毎月のコストレポートを定期的に共有したい。
FLOW実装例
1. AWS FinOps Agent で月次スケジュールのワークフローを定義
2. 指定した日時にコストレポートを HTML、PDF、PPT 形式で生成
3. 必要に応じて関係者へ共有
💡 効果: レポート作成の手作業がなくなり、定期的なコスト可視化を継続できます。
3. 最適化推奨事項のチケット化
シナリオ: コスト最適化の推奨事項をエンジニアリングチームのタスクとして管理したい。
FLOW実装例
1. Cost Optimization Hub と Compute Optimizer から推奨事項を抽出
2. ライトサイジング、アイドルリソース、Savings Plans の推奨をまとめる
3. 推奨事項を Jira チケットとして自動作成
💡 効果: 最適化施策を既存の課題管理ワークフローに組み込み、対応漏れを防止できます。

💵 料金

AWS FinOps Agent は、プレビュー期間中は追加料金なしで利用できます。ただし月間の使用量上限が設定されています。関連して使用する他の AWS サービスには標準料金が適用されます。

🌍 利用可能リージョン

AWS FinOps Agent (プレビュー) は次のリージョンで利用できます。

US East (N. Virginia) us-east-1

コスト・使用量データは、AWS GovCloud (US) と AWS 中国 (北京・寧夏) を除くすべての AWS リージョンをカバーします。管理アカウントでセットアップすると、複数のリージョンおよびアカウントにまたがるコストを管理できます。

🔗 関連サービス・機能

  • AWS Cost Explorer: コスト・使用量データの分析基盤として回答の根拠となる
  • AWS Cost Anomaly Detection: コスト異常を検出し、自動調査のトリガーとなる
  • AWS Cost Optimization Hub: ライトサイジングや Savings Plans などの推奨の提供元
  • AWS Compute Optimizer: コンピューティングリソースの最適化推奨の提供元
  • AWS CloudTrail: コスト変動の根本原因と責任者を特定する相関分析に利用

📝 まとめ

AWS FinOps Agent (プレビュー) は、コスト異常の調査、最適化機会の提示、定期的なレポート作成といった FinOps 業務を自動化するエージェントです。Jira や Slack との連携により、エンジニアが普段利用するツールの中でコスト管理を進められる点が大きな価値です。プレビュー期間中は追加料金なしで利用できるため、US East (N. Virginia) リージョンでエージェントを作成し、コスト管理ワークフローの自動化を検証することをお勧めします。
