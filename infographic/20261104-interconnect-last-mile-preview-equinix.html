🔗 Equinix をパートナーとしたプレビューを開始

📅 リリース日: 2026 年 11 月 4 日 | フルマネージドなラストマイル接続

📝 概要

AWS は、支社、データセンター、リモート拠点を AWS へ簡単に接続できるフルマネージドな接続サービス AWS Interconnect - last mile について、 Equinix をパートナーとしたプレビュー提供を発表しました。 Equinix は世界 282 のデータセンターからなるグローバルネットワークを持つデータセンター事業者であり、 数クリックで自社インフラストラクチャから AWS へのプライベート接続を確立できます。

BGP ピアリング、VLAN 設定、ASN 割り当てといった複雑なネットワーク構成は自動化され、 Lumen (GA)、AT&T (ゲート付きプレビュー)、Megaport (プレビュー) に続くパートナー追加により、 ラストマイル接続の選択肢がさらに拡大しました。

❌ アップデート前の課題

  • クロスコネクトの発注やルーターの設置・設定を個別に行う必要があった
  • BGP ピアリング、VLAN 設定、ASN 割り当てを手動で構成する必要があり、専門知識と時間を要した
  • ラストマイルパートナーが Lumen、AT&T、Megaport に限られ、Equinix 利用のお客様は個別に接続を構成する必要があった

✅ アップデート後の改善

  • 世界 282 のデータセンターからなる Equinix のグローバルネットワークを利用した接続を選択可能に
  • 2 ロケーション・4 独立リンクの 4 重冗長容量により、高い耐障害性を持つ接続を数クリックで確立
  • 99.99% の SLA とデフォルトの MACsec 暗号化を提供。プレビュー中は 1 Gbps を無料で評価可能

お客様拠点から Equinix のラストマイル回線を経由し、AWS Interconnect と Direct Connect Gateway を通じて Amazon VPC へプライベート接続する流れです。AWS が生成するアクティベーションキーを Equinix Fabric One ポータルに入力することでプロビジョニングが完了し、BGP、VLAN、ASN の構成は自動的に処理されます。

ステップ 1: Interconnect の作成

AWS Management Console、CLI、API のいずれかで、希望する AWS リージョン、帯域速度、Direct Connect Gateway、Equinix Fabric One プロジェクト ID を選択して Interconnect を作成します。Equinix 側から接続を開始することも可能です。

ステップ 2: アクティベーションキーによるプロビジョニング完了

接続を開始すると AWS がアクティベーションキーを生成します。このキーを Equinix Fabric One ポータルに入力すると、Equinix 側のプロビジョニングが完了し、拠点から AWS への接続が確立されます。

ステップ 3: 接続の確認

BGP ピアリング、VLAN 設定、ASN 割り当ては自動的に構成されるため、プロビジョニング完了後に Direct Connect Gateway を介した VPC への疎通を確認します。

💡 メリットと制約事項

👍 メリット

  • 接続構築の迅速化: 数クリックで接続を開始でき、クロスコネクト発注やルーター設置が不要
  • 広範なカバレッジ: 世界 282 データセンターの Equinix グローバルネットワークを活用
  • 無料での評価: プレビュー期間中は 1 Gbps を無料で利用可能
  • 高い耐障害性: 4 重冗長容量と 99.99% SLA でミッションクリティカルにも対応
  • デフォルトの暗号化: MACsec により追加設定なしで通信を保護
  • 構成の自動化: BGP / VLAN / ASN の自動構成で設定ミスを低減

⚠️ 制約・考慮点

  • プレビューのため、利用可能メトロは San Jose (us-west-1) と Northern Virginia (us-east-1) に限定
  • プレビューの帯域は 1 Gbps のみ。1 Gbps〜100 Gbps の帯域変更は GA 時に提供予定
  • Equinix Fabric One のプロジェクト ID が必要で、Equinix との契約が前提
  • 本番環境への適用は提供状況や SLA を十分に確認したうえで判断が必要
  • 接続元拠点が Equinix のデータセンターフットプリントでカバーされるか事前確認が必要
  • GA 後の料金はメトロと最も遠い AWS リージョンとの距離ティアで決まるため、事前見積もりが必要

🎯 ユースケース

1️⃣ Equinix コロケーション利用企業のハイブリッド接続

シナリオ: Equinix のデータセンターにサーバーを設置している企業が、AWS とのハイブリッド構成で業務システムを稼働させたい。

効果: 既存の Equinix Fabric One プロジェクトを利用して数クリックで AWS へのプライベート接続を確立でき、クロスコネクトの発注やルーター設定の作業を削減できます。

2️⃣ 高い耐障害性が求められるミッションクリティカル接続

シナリオ: 金融系システムなど、回線障害時にも業務を継続できる高可用性のクラウド接続が必要。

効果: 2 ロケーション・4 リンクにまたがる 4 重冗長の容量と 99.99% の SLA により、単一リンク障害やロケーション障害に耐える接続を追加の設計作業なしで利用できます。

3️⃣ 暗号化要件のあるプライベート接続

シナリオ: コンプライアンス要件により、オンプレミスと AWS 間の通信経路での暗号化が求められている。

効果: AWS と Equinix のエッジデバイス間のトラフィックがデフォルトで MACsec により暗号化されるため、追加の暗号化設定なしでセキュリティ要件を満たしやすくなります。

💰 料金

プレビュー期間中は、San Jose メトロ経由の US West (N. California) と Northern Virginia メトロ経由の US East (N. Virginia) で、1 Gbps の接続を無料で利用できます。

GA 後は、Interconnect ごとに選択した帯域幅と自動割り当てされる料金ティアに基づく時間課金制で、 GB あたりのデータ転送料金は発生しません。 料金ティアは、Interconnect メトロと最も遠い AWS リージョンとの地理的距離に基づいて決定されます。

🚀 まとめ

AWS Interconnect - last mile の Equinix プレビューにより、世界 282 のデータセンターからなる Equinix のグローバルネットワークを利用して、数クリックで拠点から AWS への プライベート接続を確立できるようになりました。 4 重冗長の事前プロビジョニング容量、デフォルトの MACsec 暗号化、99.99% の SLA に加え、 プレビュー期間中は 1 Gbps の接続を無料で利用できる点が特徴です。

Equinix のデータセンターを利用中または検討中のお客様は、既存の Direct Connect Gateway と組み合わせて San Jose または Northern Virginia メトロでの評価を進めることを推奨します。
