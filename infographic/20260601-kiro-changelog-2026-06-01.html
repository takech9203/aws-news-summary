📝 概要

Kiro CLI 2.5.0 (パッチ 2.5.1) は、エージェントの動作をより透明かつ自律的にするリリース。

💭Thinking Display: モデルの推論プロセスをリアルタイム可視化
🔄Subagent Review Loops: サブエージェントが自らの出力をレビュー・修正
🎛️Display Controls: 出力レンダリングの表示設定カスタマイズ
⚡レンダリング高速化: ストリーミング中の表示速度が顕著に向上

✨ 主要機能

💭 Thinking Display

モデルの推論プロセスをリアルタイムでストリーミング表示。エージェントが問題に取り組む際の思考過程を可視化し、ロジックの流れを追跡して誤った方向に進んでいる場合に早期に介入可能。デフォルトで有効。

🔄 Subagent Review Loops

サブエージェントパイプラインに自己レビュー・修正機能を追加。レビュアーステージが実装者の成果物を評価し、品質基準を満たさない場合は修正指示とともに差し戻し。基準を満たすまで繰り返す。

🎛️ Display Controls

出力レンダリングに関する設定をカスタマイズ可能。ストリーミングアニメーション、装飾的 ASCII アート、アイコンとテキストのみの表示切り替えに対応。アクセシビリティ要件にも柔軟に対応。

⚙️ 設定方法

前提条件: Kiro CLI 2.5.0 以上、有効な Kiro アカウント (Free/Pro/Pro+/Power)

💭 Thinking Display の設定

  1. Kiro CLI でチャットセッションを開始
  2. /settings コマンドを実行
  3. Display セクションから Show thinking を選択
  4. 有効/無効を切り替え
  5. 次回セッションから反映

🎛️ Display Controls の設定

  1. /settings display コマンドを実行
  2. アニメーション/ASCII アート/アイコン表示を設定
  3. 即座に反映 (再起動不要)

🔄 Subagent Review Loops

特別な設定不要。マルチエージェントパイプラインで自動的に動作し、サブエージェントを使用するタスクにレビューループが自動適用される。

💡 ユースケース

1. コードレビューの自動化

サブエージェントにコードを生成させ、レビューサブエージェントがベストプラクティスに基づいて修正を要求。品質基準を満たすまで自動イテレーション。

2. リファクタリング

既存コードのリファクタリングを委任し、レビューループで設計原則への準拠を確認してから適用。

3. 推論のデバッグ

Thinking Display を活用し、エージェントが誤った前提に基づいて推論している場合に早期に中断・修正。

4. アクセシビリティ対応

スクリーンリーダー使用時にテキストのみ表示に切り替え、アニメーションや装飾を無効化。
