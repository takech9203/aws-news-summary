Amazon RDS for Oracle

🗄️ Oracle Management Agent 24.1.0.0.v1 サポート

OEM Cloud Control 24aiR1 による RDS for Oracle データベースの監視・管理が可能に
📅 2026 年 4 月 6 日

📋 概要

Amazon RDS for Oracle が Oracle Management Agent (OMA) バージョン 24.1.0.0.v1 をサポートしました。Oracle Enterprise Manager (OEM) Cloud Control 24ai Release 1 を使用して、RDS for Oracle データベースを監視・管理できます。

OEM 24ai は Oracle データベースの監視と管理を行う Web ベースツールです。RDS for Oracle に OMA をインストールし、Oracle Management Service (OMS) と通信してモニタリング情報を提供します。

❌ Before
  • OEM 24ai R1 対応の OMA が RDS for Oracle で利用不可
  • OMS 24.1 R1 使用時に最新 OMA で監視できなかった
  • OEM の最新機能を RDS 環境で活用する手段が不足
✅ After
  • OMA 24.1.0.0.v1 を RDS for Oracle にインストール可能
  • OEM Cloud Control 24aiR1 の最新機能でデータベースを監視・管理
  • オプショングループ設定で簡単に OMA を有効化

⚡ 主要機能

🔌 OMA バージョン 24.1.0.0.v1 のサポート

OEM Cloud Control 24ai Release 1 に対応する最新エージェント。OMS 24.1 R1 以降との互換性を保証し、Web ベースのモニタリングツールを通じた Oracle データベースの包括的な管理が可能。

⚙️ オプショングループによる簡単な設定

AWS Management Console の「Option Groups」から設定可能。新規または既存のオプショングループに「OEM_AGENT」オプションを追加し、AGENT_VERSION パラメータを「24.1.0.0.v1」に設定するだけ。

🔒 セキュアな通信

最小 TLS バージョンとして TLSv1.2 を設定。OMS ホスト名またはIP アドレスとポートを指定し、エージェント登録パスワードによる認証を実施。

Bash Step 1: オプショングループの確認 
aws rds describe-option-groups \
  --engine-name oracle-ee \
  --query "OptionGroupsList[*].{Name:OptionGroupName,Engine:EngineName,Version:MajorEngineVersion}"
Bash Step 2: OEM_AGENT オプションの追加 
aws rds add-option-to-option-group \
  --option-group-name my-oracle-option-group \
  --options "OptionName=OEM_AGENT,OptionSettings=[{Name=AGENT_VERSION,Value=24.1.0.0.v1},{Name=OMS_HOST,Value=oms.example.com},{Name=OMS_PORT,Value=4903},{Name=AGENT_REGISTRATION_PASSWORD,Value=your-registration-password},{Name=MINIMUM_TLS_VERSION,Value=TLSv1.2}]"
Bash Step 3: オプショングループを RDS インスタンスに適用 
aws rds modify-db-instance \
  --db-instance-identifier my-oracle-instance \
  --option-group-name my-oracle-option-group \
  --apply-immediately
💡 --apply-immediately を指定すると即座に適用されます。メンテナンスウィンドウでの適用も選択可能です。

💎 メリット・デメリット

✅ ビジネス面のメリット

  • → OEM 24ai の最新機能でデータベースのパフォーマンスや健全性を詳細に把握
  • → オンプレミスと RDS for Oracle を同一 OEM コンソールで一元管理
  • → TLSv1.2 以上の暗号化通信でコンプライアンス要件に対応

✅ 技術面のメリット

  • → オプショングループ設定のみで OMA を有効化、手動インストール不要
  • → OMS 24.1 R1 以降との互換性保証
  • → TLSv1.2 以上による暗号化通信でセキュアな監視データ転送

⚠️ 制限事項・考慮点

  • ! OMS 24.1 R1 以降が必要 (古い OMS バージョンでは利用不可)
  • ! OMS と RDS インスタンス間のネットワーク接続 (VPN, Direct Connect 等) が必要
  • ! OEM ライセンスは Oracle から別途取得が必要
  • ! オプショングループ変更時にインスタンス再起動が発生する場合あり
  • ! セキュリティグループで OMS への通信ポートの許可設定が必要

🎯 ユースケース

🏢 ハイブリッド Oracle 環境の統合監視

オンプレミスと AWS の両方で Oracle データベースを運用し、OEM Cloud Control で統一的に監視・管理するケース。単一の OEM コンソールから全データベースを監視でき、運用効率が向上します。

⬆️ OEM 24ai へのアップグレード対応

既存の OEM 環境を 24ai Release 1 にアップグレードし、RDS for Oracle の OMA も最新バージョンに更新するケース。AI を活用した分析など OEM 24ai の最新機能を RDS for Oracle の監視に適用できます。

📦 マルチ RDS インスタンスの一括監視設定

複数の RDS for Oracle インスタンスを運用しており、共通のオプショングループを使用して全インスタンスに OMA を一括設定するケース。効率的に OMA 設定を管理できます。

💰 料金情報

🌍 利用可能リージョン

Amazon RDS for Oracle が利用可能なすべてのリージョンで OMA 24.1.0.0.v1 を使用できます。ほとんどの AWS 商用リージョンおよび AWS GovCloud (US) リージョンで利用可能です。

📎 最新のリージョン対応状況は AWS リージョン別サービス一覧 で確認できます。

Amazon RDS for Oracle が OMA バージョン 24.1.0.0.v1 をサポートしたことで、OEM Cloud Control 24ai Release 1 を使用した RDS for Oracle データベースの監視・管理が可能になりました。OMS 24.1 R1 以降を運用している場合は、オプショングループに OEM_AGENT オプションを追加するだけで簡単に設定できます。
