Amazon Corretto 2026 年 7 月 四半期アップデート

OpenJDK の四半期セキュリティおよびクリティカルアップデートを公開。Docker ベース OS 変更と Corretto 8 の JavaFX 除外を含む
リリース日
2026-07-22

📋 概要

2026 年 7 月 22 日、Amazon は Amazon Corretto の OpenJDK に対する四半期セキュリティおよびクリティカルアップデートを発表しました。今回は LTS に加えて Feature Release バージョンも対象となり、26.0.2 / 25.0.4 / 21.0.12 / 17.0.20 / 11.0.32 / 8u502 がダウンロード可能になりました。

Amazon Corretto は、無料で、マルチプラットフォームに対応した、本番環境対応の OpenJDK ディストリビューションです。今回のリリースには通常のセキュリティ修正に加えて 2 つの重要な変更が含まれます。1 つ目はデフォルトの Corretto Docker イメージのベース OS が Amazon Linux 2023 に変更された点、2 つ目は Corretto 8 から JavaFX バイナリが同梱されなくなった点です。

🔄 アップデート前後の比較

😰 Before（課題）

  • 以前のバージョンにはセキュリティ脆弱性が存在していた可能性がある
  • デフォルトの Corretto Docker イメージが旧世代の Amazon Linux ベースであった
  • Corretto 8 に JavaFX が同梱され、イメージサイズや依存関係の管理に影響していた

😊 After（改善）

  • セキュリティおよびクリティカルな問題を修正し、より安全で安定した Java 実行環境を提供
  • デフォルト Docker イメージが Amazon Linux 2023 ベースとなり、より新しいベース OS を利用可能
  • Corretto 8 の JavaFX バイナリが分離され、必要な場合のみ個別に管理できる

⭐ 主要機能

🔒 セキュリティおよびクリティカルアップデート

  • 既知のセキュリティ脆弱性を修正
  • クリティカルなバグ修正を含み、安定性を向上
  • 本番環境での安全かつ信頼性の高い使用をサポート

🔢 LTS および Feature Release の両方をサポート

  • Corretto 26.0.2 (Feature Release)、25.0.4 (最新 LTS)
  • Corretto 21.0.12 / 17.0.20 / 11.0.32 (LTS)
  • Corretto 8u502 (LTS)

🐳 デフォルト Docker イメージの Amazon Linux 2023 への変更

  • デフォルトの Corretto Docker イメージが Amazon Linux 2023 ベースに変更
  • Amazon Linux 2 ベースのイメージは、非デフォルトオプションとして引き続き提供
  • より新しいベース OS により、パッケージやセキュリティ更新の面で改善

🚫 Corretto 8 からの JavaFX バイナリ除外

  • 本リリースから、Corretto 8 に JavaFX バイナリが同梱されなくなった
  • JavaFX を使用する場合の移行ガイダンスは Corretto 8 の GitHub ページで提供
  • 依存関係の明確化とディストリビューションの軽量化に寄与

⚙️ 設定方法

前提条件: Java アプリケーションまたは開発環境、適切なプラットフォーム (Linux / Windows / macOS)、インストール用の管理者権限。

ステップ 1-2: Linux での apt リポジトリ設定とインストール

Bash apt の例 (Debian / Ubuntu) 
wget -O- https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/corretto-keyring.gpg] https://apt.corretto.aws stable main" | sudo tee /etc/apt/sources.list.d/corretto.list
sudo apt-get update
sudo apt-get install -y java-21-amazon-corretto-jdk

署名キーを登録し、apt リポジトリを追加したうえで、Corretto 21 の JDK をインストールします。

ステップ 3: Docker イメージの利用 (コンテナ環境の場合)

Dockerfile デフォルトは Amazon Linux 2023 ベース 
FROM amazoncorretto:21
COPY target/myapp.jar /app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]

Amazon Linux 2 ベースのイメージが必要な場合は、非デフォルトのタグを指定します。ベース OS 変更による影響がないか、事前に検証してください。

ステップ 4: バージョンの確認

Bash 
java -version

🎯 ユースケース

1. 本番環境での Java アプリケーション運用

シナリオ: EC2 インスタンスで LTS バージョンの Java アプリケーションを運用。Corretto 21 をインストールし、四半期アップデート (例: 21.0.12) を定期的に適用する。
効果: 無料で本番環境対応の Java ランタイムを使用し、セキュリティアップデートを継続的に受け取る

2. コンテナ化された Java アプリケーション

シナリオ: Amazon ECS / EKS 上で Java マイクロサービスを Docker コンテナとして実行。amazoncorretto:21 イメージを利用する。
効果: Amazon Linux 2023 ベースのモダンな Corretto イメージでセキュリティと保守性を向上。移行できない場合は Amazon Linux 2 ベースも選択可能

3. Corretto 8 レガシーアプリケーションの継続運用

シナリオ: Corretto 8 で稼働する既存アプリを継続運用しつつ、8u502 へアップデートし、JavaFX 除外に対応する。
効果: レガシー環境でも最新のセキュリティ修正を適用しつつ、GitHub の移行ガイダンスに従い JavaFX の分離へ安全に対応できる

📌 まとめ

Amazon Corretto の 2026 年 7 月四半期アップデートにより、LTS および Feature Release の複数バージョンでセキュリティおよびクリティカルな問題が修正されました。加えて、デフォルト Docker イメージの Amazon Linux 2023 への変更と、Corretto 8 からの JavaFX バイナリ除外という重要な変更が含まれます。コンテナ環境や Corretto 8 で JavaFX を利用しているユーザーは、これらの変更の影響を検証したうえで、無料のアップデートを適用してセキュリティと安定性を向上させてください。
