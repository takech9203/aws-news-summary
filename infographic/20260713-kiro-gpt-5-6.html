🤖 Kiro に OpenAI GPT-5.6
Sol / Terra / Luna が登場

IDE・CLI・Web の全プラットフォームで OpenAI モデルを初提供
リリース日
2026-07-14

📌 概要

Kiro で OpenAI のモデルが初めて利用可能になりました。GPT-5.6 の 3 バリエーション Sol / Terra / Luna が Kiro IDE・CLI・Web の全プラットフォームで提供開始。これは Kiro がパブリックプレビューを開始してからちょうど 1 年の節目にあたります。

GPT-5.6 は「必要以上のコストをかけずに、より高い知能を提供する」という考え方で設計。3 段階のモデルにより、性能とコストのトレードオフを用途に応じて直接コントロールできます。3 モデルすべてが 272K のコンテキストウィンドウを備え、Kiro Pro / Pro+ / Pro Max / Power の各プラン向けに実験的サポートとして段階的にロールアウトされます。

😓 アップデート前の課題
  • 利用モデルは Anthropic 系が中心で、OpenAI モデルを選択できなかった
  • 性能とコストのバランスをタスク難易度に応じて細かく調整する手段が限られていた
  • 長時間のエージェント型タスクを、少ない監督で完了させることが難しかった
➡️
🎉 アップデート後の改善
  • 全プラットフォームで OpenAI GPT-5.6 (Sol / Terra / Luna) が利用可能に
  • 最大能力の Sol から最大効率の Luna まで、コストと性能を直接選択
  • 自律的なツール利用が向上し、複雑なマルチステップタスクを少ない監督で完遂

開発者は Kiro IDE・CLI・Web のモデルセレクターから GPT-5.6 の 3 モデルを選択し、us-east-1 または eu-central-1 のリージョンでクロスリージョン推論を通じて推論を実行します。

🧠 GPT-5.6 の 3 つのモデル

🔴 Sol

フラッグシップ (最大能力)
  • Coding Agent Index 80、Terminal-Bench 2.1 88.8%
  • 両ベンチマークで Claude Fable 5 を上回る
  • 出力トークン・所要時間ともに半分未満で達成
  • 難易度の高いスペック駆動実装、長期リファクタリングに最適
2.4x クレジット乗数

🟠 Terra

バランス型
  • Coding Agent Index 77.4
  • Claude Fable 5 (77.2) をわずかに上回る
  • フラッグシップの価格を払わずに高性能
  • 日常的なエージェント型作業に最適
1.2x クレジット乗数

🟢 Luna

効率重視 (最大効率)
  • Coding Agent Index 74.6
  • Claude Opus 4.8 (72.5) を上回る
  • Sol の約 1/4 のコストで動作
  • 大量の実行・高スループットを実現
0.6x クレジット乗数
⚙️ 長時間のエージェント型作業向けの設計
  • IDE・CLI・Web のいずれでも、監督なしでより長時間動作し自律的なツール利用を効率管理
  • ツールを連携させ中間結果を処理する軽量なプログラムを自ら記述・実行し、往復回数と不要なトークンを削減
  • IDE のスペック駆動ワークフローでは、ドリフトの少ない高精度な実装を実現
  • CLI・Web では、ブラウジング・ターミナル利用・複数ファイルのリファクタリングを行き詰まりを減らして完遂

🚀 設定方法

✅ 前提条件
  • Kiro Pro / Pro+ / Pro Max / Power のいずれかのプランを利用していること
  • Kiro IDE / CLI / Web のいずれかを利用できる環境であること
  • 実験的サポートとして段階的にロールアウトされるため、環境によってはまだ表示されない場合がある
1
IDE または CLI を再起動
Kiro IDE または CLI を再起動し最新の利用可能モデルを確認。Web の場合はブラウザを更新すると、モデルセレクターに GPT-5.6 が表示されます。
2
モデルセレクターから GPT-5.6 を選択
モデルセレクターを開き、Sol / Terra / Luna のいずれかを選択。タスクの難易度とコスト要件に応じて使い分けます。
3
タスクに応じたモデルの使い分け
最も難しいマルチステップ作業には Sol、日常的な作業には Terra、大量実行・高スループットには Luna を選択します。

⚖️ メリットと制約事項

👍 メリット
✓モデル選択肢の拡大: Anthropic 系に加えて OpenAI GPT-5.6 を選択可能
✓コスト最適化: 0.6 倍の Luna から 2.4 倍の Sol まで、コストを直接コントロール
✓開発生産性の向上: 複雑なタスクを少ない監督で完遂、介入回数を削減
✓高いベンチマーク性能: Sol は出力トークン・所要時間が半分未満で高性能
✓大規模コンテキスト対応: 全モデル 272K で大規模コードベースを扱える
⚠️ 制約・考慮点
!実験的サポートとして段階的ロールアウト、環境により未提供の場合あり
!対象プランは Kiro Pro / Pro+ / Pro Max / Power に限定
!利用可能リージョンは us-east-1 と eu-central-1 に限定
!Sol は 2.4 倍の乗数のため、利用量に応じてクレジット消費が増大
!モデル内部の思考プロセスは非表示、最終出力のみ確認可能
!新モデル表示には IDE / CLI 再起動、Web はブラウザ更新が必要

💡 ユースケース

1. 難易度の高いスペック駆動実装
シナリオ: 複雑な業務ロジックを含む機能を、スペック駆動開発で最後まで実装したい。
効果: GPT-5.6 Sol の 272K コンテキストと高いマルチステップ処理能力で、ドリフトの少ない高精度な実装を少ない監督で完遂。
2. 日常的なエージェント型作業のコスト最適化
シナリオ: 日々発生する中規模のコーディングタスクを、フラッグシップの価格を払わずに効率的に処理したい。
効果: Terra により、Claude Fable 5 を上回る Coding Agent Index の性能を低コストで得られる。
3. 大量タスクの高スループット処理
シナリオ: 反復的なリファクタリングやテスト生成タスクを、コストを抑えて大量に実行したい。
効果: 0.6 倍の Luna により、Sol の約 1/4 のコストでより多くの実行と高スループットを実現。

  • Kiro スペック駆動開発: GPT-5.6 の高精度な実装能力が活きる Kiro の中核ワークフロー

📝 まとめ

このアップデートにより、Kiro で初めて OpenAI GPT-5.6 (Sol / Terra / Luna) が利用可能になり、IDE・CLI・Web のすべてで性能とコストのトレードオフを直接選択できるようになりました。パブリックプレビュー開始から 1 年の節目となる今回のリリースは、Anthropic 系モデルに加えて選択肢を大きく広げるものです。Kiro Pro 以上のプランを利用している場合は、IDE / CLI を再起動、あるいは Web でブラウザを更新し、タスクの難易度に応じて 3 つのモデルを試すことを推奨します。
