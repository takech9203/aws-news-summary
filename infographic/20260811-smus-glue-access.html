AWS Glue Amazon SageMaker Unified Studio

🧩 AWS Glue コンソールから SageMaker Unified Studio へワンクリックアクセス

📅 リリース日: 2026 年 8 月 11 日 | 機能: コンソール間シームレス連携 + インライン権限パネル

📌 概要

AWS Glue コンソールから Amazon SageMaker Unified Studio へワンクリックで直接アクセスできるようになった。カタログ参照や ETL ジョブ構築の作業から、そのまま Unified Studio に移動してデータクエリ、データ品質チェック、パイプライン構築を即座に開始できる。

今回のリリースにより、S3 Tables、Athena、EMR、Redshift、AWS Glue の各コンソールから Unified Studio をワンクリックで開けるようになった。Glue コンソールと同じ IAM ロールを使用して作業を継続できる。さらに、未セットアップのユーザー向けにインライン権限パネルが提供され、IAM コンソールへの切り替えなしで IAM ポリシーの作成・設定が完結する。

❌ Before (アップデート前)
✗Glue 作業中に Unified Studio を使うには、別途 URL やコンソールを探して移動する必要があった
✗初期セットアップ時に IAM ポリシー作成のため IAM コンソールへ切り替えが必要だった
✗複数のブラウザタブを行き来する煩雑なセットアップ手順
✅ After (アップデート後)
✓Glue コンソールからワンクリックで Unified Studio を開き、クエリや品質チェックを即座に開始
✓Glue コンソールと同じ IAM ロールでカタログ操作やノートブッククエリを実行
✓インライン権限パネルでセットアップワークフロー内に権限設定が完結

AWS Glue コンソール (および S3 Tables、Athena、EMR、Redshift の各コンソール) からワンクリックで SageMaker Unified Studio に移動できる。未セットアップの場合はインライン権限パネルで IAM ポリシーの作成・設定をその場で完結できる。

⚡ 主要機能

1️⃣ Glue コンソールからのワンクリックアクセス
  • AWS Glue コンソールから SageMaker Unified Studio をワンクリックで起動できる
  • カタログテーブルの参照中や ETL ジョブの構築中に、シームレスに Unified Studio へ移動できる
  • 移動後は、データのクエリ実行、データ品質チェック、データパイプラインの構築を即座に開始できる
2️⃣ 同一 IAM ロールでの継続作業
  • Glue コンソールで使用しているものと同じ IAM ロールを使用して Unified Studio で作業できる
  • カタログデータの操作や、SageMaker ノートブックを使用したクエリの実行が可能
  • ロールの切り替えや再認証の手間なく、一貫したアクセス権限で作業を継続できる
3️⃣ インライン権限パネルによるセットアップ簡素化
  • 未セットアップのユーザー向けに、セットアップワークフロー内で必要な IAM ポリシーを作成・設定できるパネルを提供
  • IAM コンソールへの切り替えや複数ブラウザタブの往復が不要
  • 既存の IAM ロールの再利用や、コンテキスト内での権限カスタマイズに対応し、セットアップ手順を削減
4️⃣ 主要分析系コンソールからの統一的なアクセス
  • S3 Tables、Athena、EMR、Redshift、Glue の各コンソールから Unified Studio をワンクリックで開ける
  • 既存のコンソールユーザーが、より広範なデータ・AI 機能へシームレスにアクセスできる

🛠️ 設定方法

📋 前提条件

  • AWS Glue コンソールへのアクセス権限を持つ IAM ロールまたはユーザー
  • SageMaker Unified Studio がサポートされているリージョンでの利用
  • 初回利用時は、インライン権限パネルでの IAM ポリシー設定 (または既存ロールの再利用)

🚀 手順

1
AWS Glue コンソールを開く
AWS マネジメントコンソールから AWS Glue コンソールにアクセスし、カタログテーブルの参照や ETL ジョブの構築など通常の作業を行う。
2
SageMaker Unified Studio をワンクリックで起動
Glue コンソール内に表示される SageMaker Unified Studio へのリンクをクリックする。Glue コンソールと同じ IAM ロールで Unified Studio が開き、カタログデータの操作や SageMaker ノートブックでのクエリを開始できる。
3
初回セットアップ (未セットアップの場合のみ)
初めて利用する場合、インライン権限パネルが表示される。パネル内で必要な IAM ポリシーを作成・設定するか、既存の IAM ロールを再利用する。IAM コンソールへの切り替えは不要で、権限のカスタマイズもその場で行える。

⚠️ デメリット・制約事項

🚧 制限事項

✗SageMaker Unified Studio がサポートされているリージョンでのみ利用可能
✗ワンクリックアクセスは Glue、S3 Tables、Athena、EMR、Redshift の各コンソールからの遷移に限られる

🤔 考慮すべき点

同じ IAM ロールを使用するため、Unified Studio で必要な操作に応じたポリシーが該当ロールに付与されているか確認が必要
組織で IAM ポリシーの作成を制限している場合、インライン権限パネルでのポリシー作成に管理者の関与が必要になる可能性がある
チームで Unified Studio を本格利用する場合は、ドメインやプロジェクトの設計を事前に検討することが望ましい

💰 料金 / 🌏 利用可能リージョン

💰 料金

このワンクリックアクセス機能自体に追加料金は発生しない。Unified Studio で実行するクエリ、ノートブック、データ品質チェック、パイプラインなどの利用には、それぞれの基盤サービスの料金が適用される。詳細は各サービスの料金ページを参照。

🌏 利用可能リージョン

Amazon SageMaker Unified Studio がサポートされているすべての AWS リージョンで利用可能。
