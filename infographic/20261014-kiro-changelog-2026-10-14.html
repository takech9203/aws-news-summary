Kiro Changelog

🧠 Claude Sonnet 4 の提供終了と CLI 2.31.1

チャット内 Mermaid 図レンダリングほか | リリース日: 2026 年 10 月 14 日

📋 概要

2026 年 10 月 14 日、Kiro (kiro.dev) の Changelog に 2 件のアップデートが公開されました。Claude Sonnet 4 が同日をもって Kiro での提供を終了 (end of life) し、依存するワークフローは他の利用可能なモデル (最新の Sonnet 系は Claude Sonnet 5.5) への移行が必要です。あわせて Kiro CLI 2.31.1 がリリースされ、エージェント応答内の Mermaid 図をターミナルアートとしてチャット内に直接描画できるようになったほか、ヘッドレス V3 実行での保存済み設定の適用、モデルフォールバック、Windows サンドボックスなど多数の修正が含まれています。

Claude Sonnet 4 の利用者は Claude Sonnet 5.5 などへの移行が必要になり、CLI 2.31.1 ではエージェント応答内の Mermaid 図が対応構文であればターミナルアートとして描画され、未対応の場合はソース表示にフォールバックします。

⚡ 主要機能

🔚 1. Claude Sonnet 4 の提供終了 (Models)
  • Claude Sonnet 4 は 2026 年 10 月 14 日をもって提供終了 (end of life)
  • 依存する作業がある場合は、継続前に他の利用可能なモデルを選択する必要あり
  • Sonnet 系の最新モデルは Claude Sonnet 5.5
  • 各モデルのライフサイクルステージと提供終了日は公式ドキュメントの Model lifecycle セクションで確認可能
🖼️ 2. チャット内 Mermaid 図レンダリング (CLI 2.31.1)
  • フローチャート、シーケンス図、状態遷移図、ER 図を ターミナルアートとしてレンダリング
  • 未対応構文、サイズ超過、ASCII アート無効時は Mermaid ソースを表示
  • CLI のターミナル UI ドキュメントに詳細を記載
⚙️ 3. ヘッドレス V3 実行での保存済み設定の適用 (CLI 2.31.1)
  • V3 の非対話実行で、保存済みのコンパクション設定と Tool Search 設定が適用され、対話セッションと挙動が一致
🔁 4. モデルフォールバックとコンパクションの修正 (CLI 2.31.1)
  • モデルが応答テキストなしで拒否した場合にもモデルフォールバックが動作
  • コンパクションがモデルの拒否を会話サマリーとして保存しないよう修正
🔧 5. その他の修正 (CLI 2.31.1)
  • chat.disableWrap セッションおよび Lite ペインからコピーしたプロンプトの先頭に余分なスペース 2 つが付かないよう修正
  • ターミナルペインマネージャーの Herdr が、許可や回答待ちの V3 セッションをブロック状態として表示
  • Windows の /sandbox setup が一時フォルダの外で実行され、ポリシー制限環境での失敗を回避
  • /changelog がリリースノートの各エントリを 1 行ずつ表示
  • 分離された AWS パーティションで IAM Identity Center サインインが動作
  • V3 の /workflow で、ワークフローレシピのテキストがターミナルエスケープシーケンスを出力できないよう修正

CLI 2.31.1 の主な変更点

分類内容

Mermaid 図レンダリングの挙動

ASCII アートが無効📄 Mermaid ソースを表示

🛠️ 設定方法

前提条件

  • Claude Sonnet 4 を利用していた場合: 利用可能な代替モデル (Claude Sonnet 5.5 など) の選定
  • CLI の新機能を利用する場合: Kiro CLI をバージョン 2.31.1 以降へ更新
  • Mermaid 図のレンダリングを利用する場合: ASCII アート表示が有効であること

ステップ 1: 利用中のモデルを確認し移行する

Kiro CLI または IDE のモデルセレクターで現在使用しているモデルを確認します。Claude Sonnet 4 を使用していた場合は、Claude Sonnet 5.5 などの利用可能なモデルを選択します。エージェント設定やワークフローでモデルを明示的に指定している場合は、その指定も更新します。

ステップ 2: Kiro CLI を更新する
Bash バージョン確認 
# 現在のバージョンを確認
kiro --version

バージョンが 2.31.1 より古い場合は最新バージョンへ更新します。更新後にチャットでエージェントが Mermaid 図を含む応答を返すと、ターミナルアートとして描画されます。

ステップ 3: ヘッドレス V3 実行の挙動を確認する

非対話モードで V3 を実行しているスクリプトや CI ジョブがある場合、保存済みのコンパクション設定と Tool Search 設定が適用されるようになった点を確認します。これまで挙動差を前提にしていた場合は見直しが必要です。

ビジネス面

✓レビュー効率の向上: アーキテクチャ図やシーケンス図をチャット内でそのまま確認でき、設計レビューの往復が減る
✓自動化の信頼性向上: ヘッドレス実行が対話セッションと同じ設定で動作し、CI/CD パイプラインの挙動が予測しやすい

技術面

✓ターミナル内での図の可視化: Mermaid ソースを別ツールに貼り付けることなく CLI 上で図を確認できる
✓フォールバックの堅牢性向上: 応答テキストなしの拒否でもモデルフォールバックが動作し、セッションが継続しやすい
✓会話品質の保護: コンパクションが拒否をサマリーとして保存せず、以降の会話コンテキストの劣化を防げる

⚠️ デメリット・制約事項

制限事項

✗Claude Sonnet 4 は利用できなくなったため、同モデルを前提とした設定やワークフローは修正が必須
✗Mermaid 図のターミナルレンダリングは、未対応の構文やサイズの大きすぎる図ではソース表示にフォールバック
✗ASCII アート表示が無効の場合、Mermaid 図はレンダリングされずソースが表示される

考慮すべき点

→モデル移行時は、プロンプトやエージェント設定の挙動がモデルによって変わる可能性があるため、主要ワークフローでの動作確認を推奨
→ヘッドレス V3 実行で保存済み設定が適用されるため、デフォルト挙動を前提にしていた自動化ジョブは設定内容を確認
→今後のモデル提供終了に備え、Model lifecycle ページを定期的に確認する運用を推奨

🎯 ユースケース

📅 ユースケース 1: Claude Sonnet 4 からの計画的な移行

シナリオ: チームの標準モデルとして Claude Sonnet 4 を指定しており、提供終了に伴い移行が必要になった。

  1. エージェント設定やワークフローでのモデル指定箇所を洗い出す
  2. Claude Sonnet 5.5 など代替モデルへ指定を変更
  3. 主要なワークフローで出力品質と挙動を確認
  4. Model lifecycle ページで他モデルの提供終了日も確認し、次回に備える
✅ 効果: 突然の動作停止を回避し、計画的かつ安全にモデルを移行できる
🖥️ ユースケース 2: ターミナル内での設計レビュー

シナリオ: CLI でエージェントにアーキテクチャの説明を依頼し、図を交えてその場でレビューしたい。

  1. Kiro CLI 2.31.1 以降でチャットを開始
  2. 「このシステムの構成を Mermaid のフローチャートで説明して」と依頼
  3. 応答内の図がターミナルアートとして描画され、その場で構成を確認
✅ 効果: 別ツールへの貼り付けやブラウザでのプレビューが不要になり、設計の確認サイクルが短縮される
🔄 ユースケース 3: CI での V3 ヘッドレス実行の設定統一

シナリオ: CI パイプラインで V3 の非対話実行を使っており、対話セッションと同じコンパクション設定と Tool Search 設定で動作させたい。

  1. 対話セッションで利用しているコンパクション設定と Tool Search 設定を保存
  2. CLI 2.31.1 以降で CI の非対話実行を実行
  3. 保存済み設定が自動的に適用されることを確認
✅ 効果: ローカルの対話セッションと CI の挙動が一致し、デバッグや品質管理が容易になる

💰 料金・提供範囲

💳 料金

Kiro の各プラン (Free、Pro、Pro+、Pro Max、Power) のクレジットに基づく従量制です。CLI 2.31.1 の新機能自体に追加料金はありません。モデル移行に際しては、移行先モデルのクレジット倍率を確認してください。詳細は Kiro の料金ページ を参照してください。

📝 まとめ

Claude Sonnet 4 の提供終了により、同モデルを利用していたユーザーは Claude Sonnet 5.5 などへの移行が必須となります。モデル指定を含む設定やワークフローを早急に確認し、Model lifecycle ページを定期的にチェックする運用を整えることを推奨します。あわせて CLI 2.31.1 では、チャット内での Mermaid 図レンダリングによりターミナルだけで設計の確認が完結しやすくなり、ヘッドレス V3 実行の設定適用やモデルフォールバックの修正により自動化パイプラインの信頼性も向上しています。
