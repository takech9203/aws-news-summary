📌 概要

AWS Transform は、レガシーワークロードのモダナイゼーションを支援するエージェント型 AI サービスです。 今回のアップデートにより、生成 AI ワークロードを評価し、サードパーティのモデルプロバイダーから Amazon Bedrock へ移行するための計画を作成するカスタムトランスフォーメーションが提供されます。

この AI エージェントは移行アセスメントを自動化します。コードベースをスキャンして使用中のすべての AI SDK とモデルを特定し、 対話形式の質問で移行要件を収集。各モデルを Amazon Bedrock の同等モデルにマッピングし、 コスト比較と本番環境にそのまま適用できるコード変更を提示します。

❌ アップデート前の課題
  • 使用中の AI SDK やモデルを手作業で洗い出す必要があった
  • 移行先 Bedrock モデルやコスト影響を個別に調査する必要があった
  • アーキテクチャを維持してモデル層だけを置き換えるコード変更を手作業で設計
➜
✅ アップデート後の改善
  • スキャンから移行計画作成まで 1 つの自動化プロセスに
  • モデルマッピングとコスト比較が自動で得られる
  • アーキテクチャを保持し、モデル層のみを置き換える本番向けコードを生成

🎯 主要機能

🔍 コードベースの自動スキャンとモデル特定
  • コードベースをスキャンし、使用中のすべての AI SDK とモデルを特定
  • 対話形式の質問を通じて移行要件を収集
  • 特定したモデルを Amazon Bedrock の同等モデルにマッピング
🧩 幅広い移行元と統合パターンへの対応
  • 移行元: OpenAI、Google Gemini、Anthropic SDK の直接利用、LiteLLM / Ollama 経由の OSS モデル
  • 直接 SDK 統合、フレームワークラップ (LangChain、LlamaIndex)、エージェント型 (CrewAI、LangGraph)、マルチプロバイダールーティング層に対応
  • アプリケーションのアーキテクチャを維持し、モデル層のみを置き換え
💰 コスト最適化とライフサイクル考慮
  • 階層型モデルルーティングの推奨や、プロンプトキャッシュの分析を提供
  • 提供終了 (end-of-life) まで 90 日以内のモデルを推奨対象から除外
  • 一部のワークロードには OpenAI 互換エンドポイントをコード変更なしの移行パスとして提案

📋 技術仕様 - 対応する移行元と統合パターン

移行元モデルプロバイダーOpenAI、Google Gemini、Anthropic SDK の直接利用、LiteLLM / Ollama 経由のオープンソースモデル
統合パターン直接的な SDK 統合、フレームワークラップ (LangChain、LlamaIndex)、エージェント型アーキテクチャ (CrewAI、LangGraph)、マルチプロバイダールーティング層
移行先Amazon Bedrock の同等モデル、または OpenAI 互換エンドポイント
コスト最適化階層型モデルルーティング推奨、プロンプトキャッシュ分析、モデルライフサイクル考慮
提供形態ATX CLI から実行するカスタムトランスフォーメーション

API 変更履歴: 今回のアップデートに直接関連する AWS API の変更は awsapichanges.com では確認されませんでした。本機能は ATX CLI のカスタムトランスフォーメーションとして提供されます。

💡 ユースケース

1. OpenAI から Amazon Bedrock への移行

シナリオ: OpenAI の API を直接利用するアプリを、セキュリティとガバナンス強化のため Bedrock へ移行したい。

効果: 使用中モデルを自動特定し、Bedrock の同等モデルへのマッピングとコスト比較を取得。一部は OpenAI 互換エンドポイントでコード変更なしの移行パスを提示。

2. マルチプロバイダー構成の統合

シナリオ: LangChain や LiteLLM で複数のモデルプロバイダーを使い分けるアプリを Bedrock に統合したい。

効果: フレームワークラップやマルチプロバイダールーティング層を解析し、アーキテクチャを維持したままモデル層を Bedrock に置き換えるコードを生成。

3. コスト最適化を伴う移行

シナリオ: 生成 AI ワークロードのコストを抑えつつ Bedrock へ移行したい。

効果: 階層型モデルルーティング推奨やプロンプトキャッシュ分析を提供し、コスト効率の高い構成での移行を検討可能。提供終了が近いモデルは推奨から除外。

📝 まとめ

このアップデートにより、サードパーティの生成 AI モデルから Amazon Bedrock への移行アセスメントが、 コードスキャンからコスト比較、本番向けコード変更の生成まで自動化されます。 AI ワークロードを AWS 上に統合し、セキュリティ・ガバナンス・運用を一元化したい組織は、 標準の AWS Transform 料金の範囲内で本機能を試すことを検討するとよいでしょう。
