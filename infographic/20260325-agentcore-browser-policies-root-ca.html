📝 Overview

Amazon Bedrock AgentCore が、Chrome Enterprise Policy とCustom Root CA Certificate をサポート。エンタープライズ環境でブラウザ動作を細かく制御し、内部 CA 署名の SSL 証明書による安全な接続を実現。

Before
  • Enterprise Policy でブラウザ動作を一元管理する手段なし
  • 内部 CA 署名の SSL 証明書を使う社内サービスに接続不可
  • URL フィルタリング/コンテンツ制御をブラウザレベルで適用不可
→
After
  • S3 経由で 100 以上の Chrome Policy 項目を設定可能に
  • Secrets Manager のカスタム Root CA で社内 SSL 接続が可能に
  • MANAGED / RECOMMENDED の 2 種類で柔軟にポリシー適用

Chrome Enterprise Policy は S3 から、Custom Root CA 証明書は Secrets Manager から AgentCore Browser / Code Interpreter に適用されます。

⭐ Key Features

1 Chrome Enterprise Policy
  • 100 以上の Chrome Policy 項目を JSON 形式で設定可能
  • S3 にアップロード、ブラウザ作成時/セッション開始時に適用
  • セキュリティ、URL フィルタリング、DL 制御をカバー
MANAGED
強制適用
ユーザー変更不可
RECOMMENDED
推奨設定
柔軟に適用
2 Custom Root CA Certificate
  • 内部 CA 署名の SSL 証明書を信頼ルートとして追加
  • Secrets Manager に CA 証明書を安全に保存
  • Browser / Code Interpreter の両方で利用可能
  • VPC 内の社内サービスへの SSL/TLS 接続を実現
3 Browser Profile API 改善

ListBrowserProfiles API に名前ベースのフィルタリングオプションを追加。プロファイル管理効率が向上。

        'type': 'MANAGED'

        }

🎯 Use Cases

🏦 UC1: 金融機関のセキュアなブラウザ自動化

AI エージェントに社内金融データポータルを操作させつつ、外部サイトへのアクセスを厳密に制限。URLBlocklist で全サイトをブロックし、AllowList で社内サイトのみ許可。

効果: 機密データ漏洩リスクを最小化しながら業務自動化を実現

🔌 UC2: 社内マイクロサービスとの連携

VPC 内で社内 CA 署名 SSL で保護されたマイクロサービス群に、Code Interpreter から接続してデータ分析。

効果: 手動データエクスポート作業を排除し、分析を自動化

🏢 UC3: 部門別ブラウザポリシーの適用

営業部門 = CRM サイトアクセス許可、開発部門 = 技術ドキュメントアクセス許可など、部門ごとに最適化されたポリシーを適用。

効果: セキュリティを維持しつつ部門別に業務効率を最大化

✅ Benefits

💼 ビジネス面
  • Enterprise セキュリティ基準への準拠
  • 社内システムとの統合拡大
  • ガバナンスの強化 - コンプライアンス要件対応
🔧 技術面
  • MANAGED / RECOMMENDED で柔軟なポリシー管理
  • Secrets Manager で統一的な証明書管理
  • VPC 内プライベートサービスアクセス

⚠️ Limitations

  • Chrome Policy は AgentCore Browser のみ対応 - Code Interpreter は非対応
  • Policy は S3 経由のみ - 直接 API パラメータ指定不可
  • CA 証明書は Secrets Manager 経由のみ
  • 不適切なポリシーで AI エージェントの Web 操作がブロックされる可能性
  • CA 証明書の有効期限管理はユーザー責任
  • VPC モードでは適切な SG / Subnet 設定が必要
