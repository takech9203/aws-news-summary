💻 デスクトップアプリで組織の既存サインイン方式を利用可能に

📅 リリース日: 2026 年 11 月 2 日 | 機能: デスクトップアプリケーションでの組織既存サインイン方式の利用

📝 概要

Amazon Quick のデスクトップアプリケーションが、組織が Web 版の Amazon Quick で既に使用している サインイン方式をそのまま利用できるようになりました。 Web 版の Quick にサインインできるユーザーであれば、追加の設定なしでデスクトップアプリケーションにもサインインできます。

管理者は Amazon Quick コンソールでデスクトップコネクタを 1 回追加するだけで、 アカウント内の全ユーザーのデスクトップアクセスを有効化できます。 IAM Identity Center、IAM フェデレーション、Quick ネイティブユーザーのいずれのアカウントタイプでも動作します。

❌ アップデート前の課題

デスクトップ用に Web 版とは別の構成作業が必要

  • ID プロバイダーに OIDC アプリケーションを登録し、クライアント ID を作成する必要があった
  • デスクトップ拡張機能によるアクセス設定を別途追加する必要があった
  • Web 版とデスクトップ版で認証設定を二重管理する運用負荷があった

✅ アップデート後の改善

デスクトップのサインインが Web 版の既存認証構成に統合

  • コンソールでデスクトップコネクタを 1 回追加するだけで有効化
  • OIDC アプリケーション登録やクライアント ID の作成が不要に
  • ユーザーはアカウント名を入力し、ブラウザで認証を完了するだけ
  • 個別管理したい場合は専用 ID プロバイダー構成 (Entra ID、Google Workspace、Okta、Ping Identity) も選択可能

⚡ 主要機能

🔑 Web 版サインイン方式の自動利用

  • Web 版の Quick にサインインできるユーザーは、そのままデスクトップアプリにもサインイン可能
  • デフォルトでは OIDC アプリケーション登録、クライアント ID 作成、拡張機能アクセスの追加が不要
  • IAM Identity Center、IAM フェデレーション、Quick マネージドユーザー (ネイティブユーザー) のすべてのアカウントタイプで動作

🔌 デスクトップコネクタによる一括有効化

  • Quick コンソールの [Inbound connectors] からコネクタを 1 回追加するだけで有効化
  • コネクタを追加すると、アカウント内の全ユーザーのデスクトップアクセスが即座に有効に
  • 段階展開する場合は、カスタム権限プロファイルで Quick desktop 機能を制限してからコネクタを追加

👤 シンプルなユーザーサインインフロー

  • アカウント名を入力し、サインインを選択し、ブラウザで認証を完了するだけで利用可能
  • ブラウザでのアクティブな Quick Web セッションが必要で、ない場合は Web 版へのサインインを促す
  • サインインはアクティビティに関係なく最大 30 日間持続し、アクセスは 1 時間ごとにバックグラウンドで自動更新

🛡️ 専用 ID プロバイダー構成の継続提供

  • デスクトップのサインインを個別管理したい組織向けに、専用 ID プロバイダー構成 (高度な設定) も引き続き利用可能
  • Microsoft Entra ID、Google Workspace、Okta、Ping Identity をサポート
  • 専用構成を使用する場合は ID プロバイダー側のセッション制限も適用

  1. ステップ 1: デスクトップコネクタの追加 管理者として Quick コンソールにサインインし、[Manage account] → [Inbound connectors] → [Quick Desktop] タブから [Add desktop connector] を選択。ID 設定で [Use Quick's existing configured sign-in method] を選択して [Confirm]。 コネクタカードにステータス [Enabled] が表示されることを確認します。 追加により全ユーザーのアクセスが即座に有効になるため、段階展開する場合は先にカスタム権限プロファイルで対象外ユーザーを制限します。
  2. ステップ 2: ユーザーのサインイン デスクトップアプリで Quick のアカウント名を入力し、[Sign In] を選択してブラウザで認証を完了します。 アクティブな Quick Web セッションがない場合は、先に Web 版へのサインインが求められます。
  3. ステップ 3: デスクトップ拡張機能からの移行 (既存設定がある場合) 全デバイスでアプリをバージョン 1.1.4053 以降に更新し、デスクトップコネクタを追加。 全ユーザーの移行完了後に [Extensions] ページでデスクトップ拡張機能を削除します。 既存の拡張機能設定は引き続き動作し、廃止予定日は設定されていないため任意のタイミングで移行できます。 ただし、全ユーザーの移行前に拡張機能を削除すると未移行ユーザーがアクセスを失う点に注意が必要です。

⚠️ デメリット・制約事項

制限事項

✗Enterprise Edition のみが対象で、Free / Plus アカウントには適用されない
✗デスクトップアプリケーションのバージョン 1.1.4053 以降が必要
✗Amazon Quick のフル機能セット (エージェント機能) をサポートするリージョンでのみ利用可能
✗サインインにはブラウザでのアクティブな Quick Web セッションが必要

考慮すべき点

⚠コネクタ追加で全ユーザーのアクセスが即座に有効になるため、段階展開する場合は事前にカスタム権限プロファイルで制限する
⚠拡張機能からの移行時は、全ユーザーがバージョン 1.1.4053 以降へ更新するまで既存の拡張機能を削除しない
⚠DisableAutoUpdates ポリシー使用時は自動更新が行われないため、コネクタ追加前に全デバイスへ新バージョンを配布する
⚠サインインは最大 30 日間持続するため、組織のセッションポリシーとの整合性を確認する

Text実装例

2. デスクトップコネクタを追加
3. 全ユーザーの移行確認後、Extensions ページで
   デスクトップ拡張機能を削除

💡 効果: OIDC アプリケーションやクライアント ID の管理が不要になり、認証構成の保守負荷を削減できる。

💰 料金・利用可能リージョン

💵 料金

このアップデート自体に追加料金はありません。 Amazon Quick on desktop を含むプランと料金の詳細は Amazon Quick の料金ページ を参照してください。デスクトップのエンタープライズサインインは Enterprise Edition が対象です。

🌏 利用可能リージョン

Amazon Quick のフル機能セットをサポートするすべての AWS リージョンで利用できます。 Amazon Quick on desktop はエージェント機能をサポートするリージョンでのみ利用可能なため、 Supported AWS Regions for Amazon Quick の Agentic Features 列で対象リージョンを確認してください。
