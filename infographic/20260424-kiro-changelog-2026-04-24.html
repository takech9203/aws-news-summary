📋 概要

Kiro CLI 2.1 がリリースされ、開発者のフローを維持することに重点を置いた複数の重要な機能が追加されました。シェルコマンドの出力がリアルタイムで行ごとにストリーミングされるようになり、Tool Search により MCP ツールがオンデマンドで読み込まれてコンテキストウィンドウを節約し、スキルがスラッシュコマンドとして直接呼び出せるようになりました。

さらに、リモート環境向けのデバイスフロー認証、Red Hat Enterprise Linux サポート、エンタープライズ管理者向けのモデル別メッセージカウント機能が追加されました。パッチ v2.1.1 もあわせてリリースされ、レンダリングと安定性に関する修正が含まれています。

🔄 Before / After

❌ Before
  • シェル出力はプロセス完了までバッファリング。長時間コマンドの進捗確認不可
  • 全 MCP ツール定義が毎回送信され、コンテキストウィンドウを圧迫
  • スキル利用にはエージェント切替やプロンプトへの手動コピーが必要
  • リモート環境認証にポートフォワーディングが必要
  • RHEL でターミナル UI が未サポート
  • モデル別使用状況の把握手段なし
✅ After
  • 行ごとにリアルタイムストリーミング。進捗を即座に確認可能
  • Tool Search で MCP ツールをオンデマンド読み込み。コンテキスト効率化
  • /skill-name スラッシュコマンドで直接呼び出し可能
  • デバイスフロー認証でポートフォワーディング不要
  • RHEL で完全なターミナル UI 体験を提供
  • 日次レポートでモデル別メッセージカウントを確認可能

🚀 主要機能

📡 リアルタイムシェル出力ストリーミング

シェルコマンドの出力がプロセス完了を待たずに、行ごとにリアルタイムでターミナルにストリーミングされるように改善されました。

  • ビルド、テストスイート、デプロイメントなどの長時間実行コマンドの進捗を即座に確認可能
  • 問題の早期検出が可能になり、完了まで待つ必要がなくなった
  • 従来のバッファリング方式から大幅に開発体験が向上
🔎 Tool Search -- MCP ツールのオンデマンド読み込み

MCP ツールをリクエストごとに全定義を送信する代わりに、オンデマンドで読み込む仕組みです。

  • 多数の MCP サーバーを設定している場合でもコンテキストウィンドウを圧迫しない
  • kiro-cli settings toolSearch.enabled true で有効化
  • AI モデルが必要なツールを必要な時にだけ検索・利用し、トークン効率が大幅に向上
⚡ スキルスラッシュコマンド

.kiro/skills/ ディレクトリに定義されたスキルが /skill-name スラッシュコマンドとして利用可能になりました。

  • / と入力してスキル名を指定するだけで直接呼び出し可能
  • エージェントの切り替えやプロンプトへの手動コピーが不要に
  • 再利用可能なエージェント指示への素早いアクセスを実現
🔐 デバイスフロー認証

SSH セッション、コンテナ、クラウドワークスペースからポートフォワーディングなしで認証可能になりました。

  • CLI が URL とワンタイムコードを表示し、任意のブラウザで入力するフロー
  • Google および GitHub アカウントでのサインインに対応
  • Builder ID および IAM Identity Center と同じ認証フローを採用
🐧 Red Hat Enterprise Linux サポート

Kiro CLI のターミナル UI が RHEL 上で完全に動作するようになりました。

  • 他の Linux ディストリビューション、macOS、Windows と同等のフル機能ターミナル UI を提供
  • 企業環境での Kiro CLI 導入の障壁を低減
📊 モデル別メッセージカウント

日次ユーザーアクティビティレポートで AI モデル別のメッセージ数の内訳を表示するエンタープライズ機能です。

  • レポート期間中に使用された各モデルに独自のカラムが追加
  • 例: Auto_messages、Claude_Opus_4.6_messages
  • 管理者がモデルの採用状況を追跡し、使用量がどのモデルに対応しているかを把握可能
🩹 パッチ v2.1.1

リリースと同日にパッチ v2.1.1 が適用されました。レンダリングおよび安定性に関する修正が含まれています。

⚙️ 設定方法

前提条件: Kiro CLI v2.0 以上がインストール済み / macOS、Linux、Windows 11 環境 / エンタープライズ機能は Enterprise プランが必要

ステップ 1: Kiro CLI のアップデート

Bash 最新バージョンへのアップデート 
kiro-cli update

Kiro CLI を最新バージョン v2.1.1 にアップデートします。自動アップデートが有効な場合はバックグラウンドで自動的に更新されます。

ステップ 2: Tool Search の有効化

Bash Tool Search を有効にする

MCP ツールのオンデマンド読み込みを設定します。多数の MCP サーバーを利用している場合に特に効果的です。

⚖️ メリット / 制約事項

✅ ビジネス面のメリット

  • 開発フローの中断を最小化し、ビルドやテストの進捗を待つ間も作業継続可能
  • モデル別メッセージカウントで AI モデルの採用状況とコストを正確に把握
  • デバイスフロー認証でリモート開発環境からの安全なアクセスが容易に

✅ 技術面のメリット

  • Tool Search でトークン使用量を削減し、AI モデルとのやり取りの品質を向上
  • スキルスラッシュコマンドで再利用可能な指示を素早く呼び出し可能
  • RHEL サポートでエンタープライズ Linux 環境での導入が可能に

⚠️ 制限事項

  • Tool Search はオプトイン機能。デフォルトでは無効で手動有効化が必要
  • スキルスラッシュコマンドは .kiro/skills/ にスキルが事前定義されている必要あり
  • モデル別メッセージカウントはエンタープライズプランのみ

⚠️ 考慮すべき点

  • Tool Search 有効時、MCP ツールの初回呼び出しでオンデマンド読み込み遅延の可能性
  • リアルタイムストリーミングで出力量増加。低帯域リモート接続では注意
  • RHEL サポート対象バージョンの詳細は公式ドキュメント参照

💡 ユースケース

🏗️ ユースケース 1: 長時間ビルドのリアルタイム監視

大規模プロジェクトのビルドやテストスイートの実行に数分から数十分かかる場合、進捗をリアルタイムで確認しながら問題を早期に検出したいシナリオ。

Bash ビルド出力のリアルタイムストリーミング 
# Kiro CLI 2.1 ではビルド出力がリアルタイムでストリーミング
kiro-cli
> このプロジェクトをビルドして、テストを実行してください

# 出力が行ごとにリアルタイム表示
# [1/10] Compiling module-a...
# [2/10] Compiling module-b...
# ERROR: module-c に型エラーが検出されました
# → 問題を即座に確認し、ビルド完了を待たずに修正を開始可能
✅ プロセス完了を待たずに問題箇所を即座に特定でき、デバッグのターンアラウンドタイムを短縮
🔌 ユースケース 2: 多数の MCP サーバーを利用するプロジェクト

データベース、API テスト、ドキュメント検索、コード分析など複数の MCP サーバーを設定しているプロジェクトで、コンテキストウィンドウの効率を改善したいシナリオ。

# コンテキストウィンドウに余裕が生まれ、レスポンス品質が向上
✅ コンテキストウィンドウの使用量を大幅に削減し、AI モデルのレスポンス品質と精度を向上
🌐 ユースケース 3: リモートコンテナ環境での開発

クラウドワークスペースや SSH セッション経由でコンテナ内の開発環境にアクセスし、ポートフォワーディングなしで Kiro CLI を認証して利用したいシナリオ。

Bash デバイスフロー認証の利用 
# SSH 経由でリモート環境に接続
ssh developer@remote-workspace

# Kiro CLI を起動 (デバイスフロー認証が自動的に開始)
kiro-cli

# 表示された URL をローカルブラウザで開き、ワンタイムコードを入力
# → Please visit https://kiro.dev/auth/device
# → Enter code: ABCD-EFGH
# Google または GitHub アカウントで認証完了

# スキルをスラッシュコマンドで呼び出し
> /deploy-staging
✅ ポートフォワーディングの設定が不要になり、リモート環境でもシームレスに全機能を利用可能

📝 まとめ

Kiro CLI 2.1 は、開発者のフローを維持するための 3 つの主要機能 (リアルタイムシェルストリーミング、Tool Search、スキルスラッシュコマンド) を中心に、リモート環境対応の強化とエンタープライズ管理機能の拡充を実現したリリースです。
