Kiro - AWS が提供する AI 搭載 IDE IDE 1.0.309

🤖 ネストされた AGENTS.md サポートと長時間セッションの効率化

📅 リリース日: 2026 年 8 月 13 日 | 🌍 グローバル提供 (リージョン制約なし)

📋 概要

Kiro IDE 1.0.309 の目玉機能はネストされた AGENTS.md サポートです。ワークスペース内のサブディレクトリに AGENTS.md を配置すると、そのディレクトリツリーにスコープされた指示を Kiro に与えられます。検出は Git と Kiro の ignore ルールに従うため、無視対象ディレクトリのファイルが誤って読み込まれることはありません。

さらに、長時間セッションの効率化にも重点を置き、アイドル時の CPU 使用量の削減と未変更ファイルの重複追加の解消により、長いセッションでもより多くのコンテキストを本来の作業に使えるようになりました。Cloud Sessions への設定同期の信頼性向上や、チャット、フック、MCP 接続に関する多数の修正も含まれています。

😓 アップデート前の課題

  • IDE では AGENTS.md によるディレクトリ単位のスコープ指定ができず、モジュール固有の指示をコードの近くで管理しづらい
  • セッション履歴が増えるにつれてアイドル時の CPU 使用量が増加
  • 未変更ファイルが会話に繰り返し追加され、長時間セッションでコンテキストを圧迫
  • 依存関係ディレクトリを持つスキルが過剰なリソースを消費し、Git、リンター、エディタ拡張機能を妨害
  • Cloud Sessions への設定同期が一時的な失敗から回復できず不整合が発生
  • User-Agent ヘッダー必須の CDN やファイアウォール配下のエンタープライズ MCP レジストリが HTTP 403 で接続失敗

😀 アップデート後の改善

  • サブディレクトリの AGENTS.md がディレクトリツリーにスコープされた指示として読み込まれる (Git / Kiro の ignore ルールに準拠)
  • セッション履歴が増えてもアイドル時の CPU 使用量が低く保たれる
  • 未変更ファイルの重複追加がなくなり、利用可能なコンテキストが増加
  • スキル監視が改善され、Git、リンター、エディタ拡張機能への影響が解消
  • Cloud 設定同期が一時的な失敗から自動回復し一貫性を維持
  • MCP 接続、フック、チャットに関する多数の不具合を修正

⚡ 主要機能 (Improvements)

📄 1. ネストされた AGENTS.md サポート

サブディレクトリに AGENTS.md を配置すると、ワークスペースのその部分にスコープされたガイダンスを Kiro に与えられます。検出は Git と Kiro の ignore ルールに従うため node_modules などは読み込まれません。モノレポや大規模リポジトリで、モジュール固有の規約やドメイン知識をコードのすぐ隣で管理できます。

🔋 2. アイドルリソース使用量の削減

セッション履歴が増えても、アイドル時の CPU 使用量が低く保たれるようになりました。

🧠 3. コンテキスト使用の効率化

変更されていないファイルが会話に繰り返し追加されなくなり、長時間のセッションでも、より多くのコンテキストを本来の作業に利用できます。

🛠️ 4. スキル監視の信頼性向上

依存関係ディレクトリを持つスキルが過剰なシステムリソースを消費しなくなり、Git、リンター、エディタ拡張機能の動作を妨げる問題が解消されました。

☁️ 5. Cloud 設定同期の信頼性向上

Cloud Sessions に同期されるステアリング、カスタムエージェント、スキル、Powers、フックが、一時的な失敗から回復して一貫性を保つようになりました。

💬 6. チャットタブタイトルのホバー表示

省略表示されたチャットタブのタイトルにホバーすると、フルネームを確認できるようになりました。

🔧 修正 (Fixes)

  • ✔特定の Go コードブロックを含むチャットがフリーズしたり、再度開けなくなる問題を修正
  • ✔マルチルートワークスペースや file:// URI で、ワークスペースファイルリンクが誤った場所を開く問題を修正 (Agent Focus Mode を含む)
  • ✔~/.kiro/hooks/ のグローバルフックが Agent Hooks エディタで空のフィールドとして開かれる問題を修正 (既存フックの上書きリスクも解消)
  • ✔macOS で新規作成された設定ディレクトリが検出されず、ステアリング、カスタムエージェント、Powers、MCP 設定の更新が遅延する問題を修正
  • ✔入力エリアのサイズ変更時に、最新メッセージへの自動スクロールが停止する問題を修正
  • ✔User-Agent ヘッダー必須の CDN やファイアウォール配下のエンタープライズ MCP レジストリが HTTP 403 を返す問題を修正
  • ✔MCP の再試行がサーバーステータスの更新や、接続失敗後のクリーンアップに失敗する問題を修正
  • ✔ファイルマッチ型ステアリングファイルへの同一サイズの編集が、同じセッション中に検出されない問題を修正
  • ✔有効な旧形式の .kiro.hook ファイルが無効と表示される問題を修正し、自動トリガーフックの有効/無効切り替えコントロールを復元
  • ✔エージェントがファイル検索でサポート外の正規表現構文を使用し、結果が返らない問題を修正

Bash モジュールごとの AGENTS.md 配置例 
# 例: モジュールごとに AGENTS.md を配置
my-repo/
├── AGENTS.md              # ワークスペース全体の指示
└── services/
    ├── auth/
    │   ├── AGENTS.md      # 認証モジュール固有の指示
    │   └── src/
    └── billing/
        ├── AGENTS.md      # 課金モジュール固有の指示
        └── src/

各ファイルは配置したディレクトリツリーにスコープされた指示として Kiro に読み込まれます。.gitignore や Kiro の ignore ルールで無視されているディレクトリ内のファイルは検出されません。

2スコープされた指示を記述する
Markdown services/auth/AGENTS.md の例 
# services/auth/AGENTS.md の例

## 認証モジュールの規約
- トークン検証には共通ライブラリ auth-core を使用する
- 秘密情報は環境変数から取得し、ハードコードしない
- 新しいエンドポイントには必ずレート制限を設定する

ワークスペースルートの AGENTS.md には共通ルールを、サブディレクトリにはモジュール固有のルールを配置する構成が有効です。

✓長時間セッションの品質維持: 未変更ファイルの重複追加がなくなり、コンテキストウィンドウを実際の作業に有効活用できる
✓ignore ルールとの統合: ビルド成果物や依存関係ディレクトリ内のファイルが誤って読み込まれる心配がない

⚠️ デメリット・制約事項

🚧 制限事項

✗本アップデートは Kiro IDE (1.0.309) が対象。Kiro CLI では 2.18.0 で同様のネストされた AGENTS.md サポートが先行導入されている
✗AGENTS.md の検出は Git と Kiro の ignore ルールに従うため、ignore 対象ディレクトリに配置したファイルは読み込まれない

🤔 考慮すべき点

⚠ルートとサブディレクトリの AGENTS.md で指示が重複・矛盾しないよう、共通ルールはルートに、モジュール固有ルールはサブディレクトリに、と役割を分けて整理することを推奨
⚠多数の AGENTS.md を配置する場合は、各ファイルを簡潔に保ち、エージェントに読み込まれるコンテキスト量を意識する
