AWS Partner Central

TCV によるディールサイジング機能

Total Contract Value を使用した MRR 自動算出

2026-05-28

📋 概要

AWS Partner Central のオポチュニティ管理におけるディールサイジング機能が強化され、Total Contract Value (TCV、契約総額) を使用した見積もりが可能になった。パートナーは顧客との契約総額を入力するだけで、システムが自動的に月次経常収益 (MRR) を算出する。

本機能は AWS Partner Central のコンソールおよび AWS Partner Central API for Selling の両方で利用可能であり、CRM システムとの統合にも対応している。

❌ Before

  • パートナーが MRR を手動で計算する必要があり、計算ミスが発生
  • 契約総額から月次収益への変換に時間がかかり提出が遅延
  • パイプライン予測精度にばらつきがあり収益予測の信頼性が低い

✅ After

  • TCV と契約期間の入力だけで MRR が自動算出
  • 手動計算不要でオポチュニティ提出速度が大幅向上
  • 統一された計算ロジックでパイプライン全体の予測精度が改善

⚡ 主要機能

🧮
TCV からの MRR 自動算出
契約総額 (TCV) を USD または EUR で入力し、契約期間を月数で指定するだけでシステムが自動的に予測 MRR を計算。提出前にレビューも可能。
📋
複数の MRR 見積もり方法
Forecast MRR from TCV (新機能)、Forecast MRR、AWS Pricing Calculator、Manual entry の 4 種類から選択可能。
🔌
API 対応
AWS Partner Central API for Selling を通じて CRM システムとの自動連携が可能。プログラマティックなオポチュニティ管理をサポート。
🌐
マルチ通貨対応
USD と EUR の両方をサポートし、グローバルな案件管理に対応。通貨変換の手間なく契約を登録できる。

⚙️ 設定方法

前提条件

✓AWS Partner Central アカウントを保有していること
✓オポチュニティの作成・更新権限があること
✓API 利用時は AWS Partner Central API for Selling へのアクセス権限があること

手順

1
オポチュニティの作成または編集
AWS Partner Central コンソールにログインし、新規オポチュニティを作成するか、既存のオポチュニティを編集する。
2
MRR 見積もり方法の選択
ディールサイジングセクションで「Forecast MRR from TCV」を選択する。
3
TCV と契約期間の入力
契約総額 (TCV) を USD または EUR で入力し、契約期間を月数で指定する。
4
予測 MRR の確認と提出
システムが自動算出した予測 MRR を確認し、問題がなければオポチュニティを提出する。

💡 ユースケース

🏢 大型エンタープライズ契約の登録
パートナーが 3 年間で $1,200,000 のエンタープライズ契約を獲得したケース。
TCV: $1,200,000 USD
契約期間: 36 ヶ月
予測 MRR: 自動算出 (約 $33,333/月)
→ 複雑な長期契約でも即座に MRR が算出され、パイプラインに正確に反映される。
🔄 CRM 連携による大量案件の自動登録
パートナーの CRM システムに蓄積された複数の案件を API 経由で一括登録するケース。
AWS Partner Central API for Selling を使用し、
各案件の TCV と契約期間をプログラマティックに送信。
MRR は自動算出されるため、個別計算が不要。
→ 数十件の案件を手動計算なしで迅速にパイプラインに反映できる。
🌍 マルチリージョン案件の通貨対応
欧州の顧客との契約を EUR で管理したいケース。
TCV: EUR 500,000
契約期間: 24 ヶ月
予測 MRR: 自動算出 (約 EUR 20,833/月)
→ 通貨変換の手間なく、EUR ベースの契約をそのまま登録できる。

考慮点
