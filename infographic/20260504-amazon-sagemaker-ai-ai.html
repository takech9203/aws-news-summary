📋 概要

Amazon SageMaker AI に、モデルカスタマイズのためのエージェント体験 (Agentic Experience) が追加された。従来数か月を要していたモデルカスタマイズのワークフローを、数日または数時間で完了できるようになる。開発者は自然言語でコーディングエージェントと対話しながら、ユースケースの定義から本番環境へのデプロイまでの全プロセスを効率化できる。

数か月 → 数時間 カスタマイズ期間の短縮
9 スキル エージェントスキル数
4 モデルファミリー 対応モデル数

🔄 Before / After

❌ Before (従来)

  • ワークフロー全体を手動管理、数か月を要する
  • インフラ構築が差別化されない重労働
  • 各ステップで高い専門知識が必要
  • 複数モデル・手法の比較が複雑

✅ After (新機能)

  • 自然言語で指示するだけでエンドツーエンド実行
  • AWS ベストプラクティスを自動適用
  • 再利用可能な Jupyter Notebook を生成
  • 好みの IDE にスキルをインストール可能

⚡ 主要機能

📋 エージェントスキルによる段階的ガイダンス
Planning スキルが開発者の意図を理解し、ステップバイステップのカスタマイズ計画を生成。Use Case Specification スキルがゴール・制約・成功基準を構造化されたドキュメントとして整理。各ステージで実行可能な Jupyter Notebook を生成し、セルごとにレビュー・編集・実行が可能。
🔧 包括的なデータ準備とファインチューニング
Dataset Evaluation スキルがデータ品質のバリデーション・フォーマット検出・要件分析を実施。Dataset Transformation スキルが SageMaker 互換のトレーニングフォーマットへ自動変換。最適な手法 (SFT、DPO、RLVR) とベースモデルを自動選択し、ハイパーパラメータ設定とトレーニングジョブの実行を自動化。
📈 LLM-as-a-Judge による品質評価
Model Evaluation スキルが評価設計、ベンチマーク選択、LLM-as-a-Judge メトリクスによるモデル比較を実施。Amazon Bedrock Evaluations を活用した包括的な品質評価と、成功基準に対するモデル候補の自動判定。
🚀 柔軟なデプロイオプション
Amazon Bedrock へのモデルインポートとデプロイ、SageMaker AI エンドポイントへのデプロイの両方に対応。コスト効率の高いデプロイ構成を自動推奨。
🖥️ マルチエージェント・マルチ IDE 対応
Kiro、Claude Code、CoPilot と連携可能。Visual Studio Code、Cursor、SageMaker Studio Notebooks に対応。SageMaker Studio Notebooks には Kiro エージェントとスキルがプリインストール済み。

⚠️ デメリット・制約事項

制限事項

⚠️ Amazon Nova モデルはカスタマイズが us-east-1 のみに限定、LLM-as-a-Judge 評価にも非対応
⚠️ SageMaker デフォルト実行ポリシーでは "sagemaker" を含む S3 バケットのみアクセス可能
⚠️ RLVR では Lambda 関数名に "sagemaker" を含む必要あり
⚠️ Kiro IDE のチャットでは "vibe" モードでのみスキルが正しくトリガーされる

考慮すべき点

💡 生成される Notebook は実行前にレビューが必要 (Human-in-the-Loop アプローチ)
💡 Bedrock デプロイではリージョン推論ポリシーの設定が追加で必要
💡 LLM-as-a-Judge 機能は Amazon Bedrock Evaluations の料金が別途発生
💡 スキルは OSS だが、組織固有の要件に合わせたカスタマイズが推奨

💡 ユースケース

🏷️ UC1: カスタマーサポート分類モデルの構築
EC サイトのカスタマーサポートチームが、問い合わせを自動分類するカスタムモデルを構築。既存の問い合わせデータはあるが、ML チームのリソースが限られている。
→ ML エンジニアなしでも 1-2 日でカスタム分類モデルを構築・デプロイ可能。SFT を使用。
📝 UC2: 社内文書要約モデルのトーン調整
コンサルティング企業が、社内レポートを経営層向けに要約するモデルを構築。文体やフォーマットを自社のスタイルガイドに合わせる必要がある。
→ DPO で組織固有のスタイルに調整。LLM-as-a-Judge で品質を定量評価し反復的に改善。
💻 UC3: コード生成モデルの正確性向上
SaaS 企業が、自社の API に特化したコード生成モデルを構築。生成されるコードの正確性を検証可能な方法で保証する必要がある。
→ RLVR でテストスイートを報酬関数として活用。Lambda 関数による報酬計算でスケーラブルなトレーニングパイプラインを実現。

💰 料金

SageMaker AI モデルカスタマイズスキル自体の利用は無料 (OSS プラグイン)。以下の AWS リソース使用に応じた料金が発生。

⚡ SageMaker Training トレーニングインスタンスの使用時間に応じた従量課金
🌐 SageMaker Endpoints エンドポイントインスタンスの稼働時間に応じた従量課金
🧠 Amazon Bedrock モデルインポートとリクエスト数に応じた従量課金
📈 Bedrock Evaluations 評価実行ごとの課金
🪣 Amazon S3 データ・モデルアーティファクトのストレージ料金
⚙️ AWS Lambda RLVR 使用時の報酬関数の実行回数・時間に応じた課金

🌍 利用可能リージョン

SageMaker AI モデルカスタマイズスキルは、Amazon SageMaker AI が利用可能なすべてのリージョンで使用可能。ただし以下の制約あり。

📍 Amazon Nova モデルのカスタマイズ: us-east-1 のみ
📍 Bedrock デプロイ: Bedrock が利用可能なリージョン
📍 SageMaker Studio Notebooks (プリインストール環境): SageMaker Studio が利用可能なリージョン
