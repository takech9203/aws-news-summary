📱 AWS Builder Center
iOS / Android モバイルアプリ提供開始

AWS Builder Center モバイルアプリ 📅 リリース日: 2026 年 9 月 17 日

📌 概要

AWS Builder Center が iOS および Android のモバイルアプリとして利用可能になりました。記事、ワークショップ、サンドボックス環境、イベント、学習リソースを一箇所に集めたグローバルビルダーコミュニティ向けプラットフォームに、いつでもどこでもアクセスできます。

AWS Builder ID でサインインするとセッションをまたいでサインイン状態が維持され、トレンド記事の閲覧、600 以上の AWS Skill Builder コース、無料サンドボックス環境を使ったハンズオンワークショップの管理、プッシュ通知、Wishlist によるフィードバック提出まで、モバイルから直接行えます。アプリは Apple App Store と Google Play Store を通じて全世界で提供されています。

❌ アップデート前の課題

✗デスクトップと Web ブラウザからのみアクセス可能だった
✗移動中や外出先で記事やイベント情報を手軽に確認する手段が限られていた
✗購読トピックやコミュニティの更新をリアルタイムに受け取る仕組みがなかった

✅ アップデート後の改善

✓iOS / Android ネイティブアプリからいつでもコンテンツにアクセス可能
✓プッシュ通知で購読トピック・コミュニティの更新をリアルタイム受信
✓AWS Builder ID のサインイン状態が維持され、毎回のログイン操作が不要
✓移動中でも Builder Loft イベント確認やワークショップ管理が可能

ビルダーがモバイルアプリから AWS Builder ID でサインインし、記事、学習コース、ワークショップ、コミュニティ、イベント、Wishlist の各機能にアクセスできる構成です。購読中のトピックやコミュニティの更新はプッシュ通知でアプリに届きます。

⚡ 主要機能

📚 コンテンツと学習リソースへのモバイルアクセス

  • コミュニティのトレンド記事をモバイルから閲覧可能
  • 600 以上の AWS Skill Builder コースにアクセス可能
  • 無料サンドボックス環境を使ったハンズオンワークショップをアプリから管理可能

🤝 コミュニティとイベント機能

  • AWS Heroes、Community Builders、User Group Leaders をフォロー可能
  • Builder Loft イベントカレンダーを外出先から確認可能
  • 購読しているトピックやコミュニティの更新をプッシュ通知で受信可能

💡 Wishlist による製品フィードバック

  • AWS チームへの製品フィードバックをアプリから直接提出可能
  • 提出済みフィードバックの管理にも対応

🔐 AWS Builder ID によるシームレスなサインイン

  • セッションをまたいでサインイン状態を維持
  • AWS アカウント (クレジットカード登録) は不要で、無料の AWS Builder ID のみで利用可能

ステップ 1: アプリのインストール

Apple App Store (iOS) または Google Play Store (Android) で「AWS Builder Center」を検索してインストール。詳細は builder.aws.com/mobile を参照。

ステップ 2: AWS Builder ID でサインイン

AWS Builder ID を持っていない場合は、メールアドレスのみで無料で作成できます。一度サインインすると、セッションをまたいでサインイン状態が維持されます。

ステップ 3: トピックとコミュニティの購読

興味のあるトピックやコミュニティを購読し、プッシュ通知を有効化。フォローしている AWS Heroes や Community Builders の投稿、コミュニティの更新をリアルタイムに受け取れます。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓学習機会の拡大: 通勤・移動中のスキマ時間で 600 以上のコースや記事で学習を継続
✓コミュニティエンゲージメント向上: プッシュ通知で最新情報やイベントを見逃さず、参加機会を最大化
✓フィードバックループ強化: 現場で気づいた要望を Wishlist でその場で AWS チームに届けられる

🛠️ 技術面のメリット

✓マルチデバイス対応: デスクトップ、Web、モバイルから利用シーンに応じて選択可能
✓シームレスな認証: サインイン状態の維持により毎回の認証操作が不要
✓ワークショップ管理のモバイル化: 無料サンドボックス環境のワークショップをモバイルから管理

⚠️ 制限事項

✗サンドボックスでの実際のハンズオン作業 (コンソール操作やコーディング) は、画面サイズの観点からデスクトップの方が適する場合がある
✗利用には AWS Builder ID が必要 (IAM ユーザーや AWS アカウントの認証情報では利用しない)

🤔 考慮すべき点

⚠多数のトピック・コミュニティで通知を有効化すると通知が増えるため、購読対象の整理が必要
⚠組織の MDM ポリシーによっては、アプリのインストールに制限がある場合がある

💰 料金と利用可能リージョン

💰 料金

モバイルアプリは無料で利用可能。AWS Builder ID の作成も無料で、AWS アカウントやクレジットカードの登録は不要です。

🌍 利用可能リージョン

Apple App Store および Google Play Store を通じて全世界で利用可能です。

🔗 関連サービス・機能

→AWS Builder ID: AWS アカウントとは独立した個人向けの無料 ID。Builder Center へのサインインに使用
→AWS Skill Builder: AWS の公式学習プラットフォーム。モバイルアプリから 600 以上のコースにアクセス可能
→AWS Builder Center 無料サンドボックス環境: 対象ワークショップで利用できる時間制限付きの無料 AWS 環境。モバイルアプリからワークショップを管理可能
→AWS Heroes / Community Builders / User Group Leaders: AWS コミュニティプログラム。モバイルアプリからフォローして最新情報を取得可能

📝 まとめ

AWS Builder Center のモバイルアプリ提供により、記事、学習コース、ワークショップ、コミュニティ、イベントといったビルダー向けリソースに、いつでもどこからでもアクセスできるようになりました。プッシュ通知と Wishlist 機能により、コミュニティとのつながりと AWS へのフィードバックがより手軽になります。

🚀 推奨アクション

まずは App Store または Google Play Store からアプリをインストールし、AWS Builder ID でサインインして、関心のあるトピックの購読から始めることを推奨します。
