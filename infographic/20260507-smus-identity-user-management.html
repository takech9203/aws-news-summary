Amazon SageMaker Unified Studio

🔐 ID とユーザー管理機能の追加

IAM ドメインと Identity Center ドメインの両方で柔軟な認証とアクセス管理を実現
2026-05-07

📋 概要

Amazon SageMaker Unified Studio に、ID 構成とユーザー管理に関する新しい管理機能が追加された。IAM ドメインでは AWS IAM Identity Center を設定して SSO によるユーザーオンボーディングが可能になり、Identity Center ドメインではフェデレーテッド IAM ロールを通じたポータルアクセスがサポートされた。

これにより、認証方法に関係なくチームメンバーがプロジェクトデータとリソースで共同作業できるようになる。

Before

  • IAM ドメインで SSO オンボーディング不可
  • ユーザー管理が分散、一元ビューなし
  • Identity Center でフェデレーテッドアクセス不可
  • 同一 IAM ロール共有時のセッション分離不可
  • ドメインタイプ間のコラボレーション困難

After

  • IAM ドメインで SSO オンボーディング可能
  • 新しいユーザー管理ページで一元管理
  • Identity Center でフェデレーテッドアクセス対応
  • ユーザーごとに一意のセッション作成
  • 認証方法を問わず共同作業が可能

🚀 主要機能

🌐
IAM ドメインでの SSO オンボーディング
AWS IAM Identity Center を設定し、IAM ドメインでも SSO 経由のユーザーオンボーディングが可能に。IAM ロール、IAM ユーザー、Identity Center ユーザー/グループをプロジェクトメンバーとして追加可能。
📊
ドメインユーザー管理ページ
IAM ドメイン向けの新しい一元管理画面。ドメイン内の全アクティブユーザーを統合ビューで表示し、アクセス管理と権限更新を単一画面から実行可能。
🔗
フェデレーテッド IAM ロールアクセス
Identity Center ドメインで IAM ロールを通じたフェデレーテッドアクセスをサポート。フェデレーテッドユーザーごとに一意のセッションを自動作成し、作業の上書きを防止。
🤝
クロスドメインタイプの ID サポート
IAM アイデンティティと IAM Identity Center 企業 ID の両方を、両ドメインタイプで使用可能。認証方法に関係なくチームメンバーが共同作業可能。

💡 ユースケース

🧪 マルチチームでの ML プロジェクト共同作業
シナリオ: データサイエンスチーム (Identity Center 管理) とインフラチーム (IAM ロール管理) が同一の ML プロジェクトで共同作業する必要がある。

実装: IAM ドメインで Identity Center を構成し、データサイエンスチームを Identity Center グループとして、インフラチームを IAM ロールとして追加。両チームが同一プロジェクトのデータとリソースにアクセス可能に。

効果: 認証基盤の違いを意識することなく、チーム横断でのコラボレーションが実現。
🔑 外部コンサルタントの一時的なアクセス付与
シナリオ: 外部コンサルタントに IAM ロール経由のフェデレーテッドアクセスを付与し、Identity Center ドメインのプロジェクトに参加させる。

実装: Identity Center ドメインでフェデレーテッド IAM ロールアクセスを有効化。コンサルタント用の IAM ロールを作成し、フェデレーションを通じてポータルにアクセス。一意のセッションにより個別の作業履歴が保持される。

効果: Identity Center にユーザーを追加することなく、既存の IAM ロールベースのアクセス管理で外部ユーザーのオンボーディングが可能。
🏢 大規模組織でのユーザー管理の効率化
シナリオ: 数百人規模のデータサイエンティストが所属する組織で、IAM ドメインのユーザー管理を効率化したい。

実装: 新しいドメインユーザー管理ページで全アクティブユーザーの一覧を確認し、不要なアクセス権限を特定して削除。グループ単位での権限更新を実行。

効果: 管理者の運用負荷を軽減し、アクセス権限の棚卸しを効率的に実施可能。

⚖️ メリット・制約事項

メリット

  • チームコラボレーションの向上
  • SSO 統合でオンボーディング工数削減
  • フェデレーテッドユーザーの個別アクション追跡
  • IAM と Identity Center の ID を単一プラットフォームで管理
  • 同一 IAM ロール共有時のセッション分離
  • 追加料金なし

制約事項・注意点

  • IAM Identity Center が同一リージョンで有効化されている必要あり
  • SSO 構成は管理者ポータルからの手動設定が必要
  • 15 リージョンのみで利用可能
  • 既存ドメインへの統合時は既存ユーザーへの影響を事前確認
  • セッション有効期限やタイムアウトの適切な設定が必要
  • 組織のセキュリティポリシーとの整合性確認が必要

💰 料金

SageMaker Unified Studio の ID 管理およびユーザー管理機能自体に追加料金は発生しない。SageMaker Unified Studio の標準料金が適用される。AWS IAM Identity Center の使用料金も無料。
