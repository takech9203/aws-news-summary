📋 概要

AWS Management Console および AWS Console Mobile App で提供されてきた Amazon Q Developer が、AWS assistant という新しい名称に変更されました。AWS は名称変更の理由として、「製品が何をするものかが即座に伝わる名前にするため」と説明しています。

AWS assistant は、アカウント情報を踏まえたパーソナライズされたガイダンスとアクションを提供し、AWS 上での構築、運用、最適化を簡素化します。名称は変わりますが、機能自体は従来と同じものが提供されます。既存の Amazon Q Developer Pro サブスクライバーは、AWS assistant においても Pro ティアの機能を自動的に維持できます。

⚙️ 主要機能

機能自体は従来の Amazon Q Developer in console と同じです。

🔍 リソースの理解と管理
スクリプトを書いたり複数のコンソールページを行き来したりせずに、AWS インフラの構成や関係性を自然言語で確認できます。
💬 例: 「このバケットのアラームを表示して」「米国東部 (オハイオ) で実行中の EC2 インスタンスを表示して」
💰 コスト分析
AWS Cost Explorer のコストデータを分析し、主要なコスト要因や月次の支出推移などを質問できます。
💬 例: 「先月の請求額は?」
🛠️ トラブルシューティング
コンソールの [Diagnose with AWS assistant] ボタンで、権限エラー、設定ミス、サービス制限超過などの一般的なエラーを診断します。
💬 例: 「Lambda 関数の何が問題?」「API Gateway でエラーが出るのはなぜ?」
🚨 運用インシデントの調査
調査のためのインサイトやランブック提案を提供し、メトリクスの精査や問題リソースの手動特定の手間を削減します。
🔒 ネットワークセキュリティ構成の分析 (プレビュー)
不足または誤設定されたネットワークセキュリティサービスを特定し、修復手順を推奨します。
🏗️ 構築支援
サーバーレス API 構築のためのサービス提案、CLI コマンドの案内、DynamoDB と RDS の使い分けなどの質問に対応します。

🚀 利用方法

前提条件

✓AWS アカウントを保有していること
✓AWS Management Console または Console Mobile App にアクセスできること

手順

1
コンソールで AWS assistant を開く
AWS Management Console にサインインし、画面上のアシスタントアイコンから AWS assistant を開きます。従来 Amazon Q Developer を利用していた場所と同じ導線で、名称のみが AWS assistant に変わります。
2
自然言語で質問する
リソースの状態確認、コスト分析、エラーのトラブルシューティングなどを自然言語で質問します。アカウント情報を踏まえたパーソナライズされた回答とアクションが提供されます。
3
既存の Pro サブスクリプションの確認 (該当する場合)
既存の Amazon Q Developer Pro サブスクライバーは、特別な移行作業なしに AWS assistant でも Pro ティアの機能を自動的に利用できます。
