AWS Partner Central

📋 概要

AWS Partner Central agents は Amazon Bedrock AgentCore 上に構築された AI 搭載の新機能。パートナーの営業チームと連携して販売サイクルの短縮とファンディングアクセスの簡素化を実現する。コンソールからの直接利用のほか、Model Context Protocol (MCP) を通じて CRM システムからプログラマティックにアクセスできる。

Before / After

❌ Before
  • 手動でのデータ入力や案件情報の更新に多くの時間を消費
  • ファンディングの適格性確認や申請書作成を手作業で実施
  • パイプラインの分析やセールス戦略の立案を個別に実行
✅ After
  • トランスクリプトやメモの共有だけでフィールドを自動入力
  • 案件レベルでファンディングを推奨、事前入力済み申請書を自動作成
  • MCP 経由で CRM から直接 AI 機能を活用

⚡ 主要機能

📈
パイプラインインサイトと次のステップ推奨
パイプラインの状況を可視化し、カスタマイズされたセールスプレイと次のステップの推奨をオンデマンドで取得。どの案件に注力すべきか AI が分析して提示する。
✍️
営業データの自動入力と案件進行
会議のトランスクリプト、メモ、メールを共有するだけでフィールドを自動入力し案件を進行。データ入力ではなく販売活動に集中できる。
💰
ファンディング推奨と申請支援
案件レベルでファンディングを推奨し、適格性のギャップを特定。事前入力済みのファンド申請書を自動作成して迅速な資金獲得を支援。
🔌
MCP によるプログラマティックアクセス
Model Context Protocol を通じたプログラマティックアクセスを提供。既存の CRM システムからエージェント機能に直接アクセスし、営業ワークフローを中断しない。

🚀 設定方法

前提条件

✓ AWS パートナーとして登録済みであること
✓ AWS Partner Central へのアクセス権限があること
✓ CRM 連携の場合は MCP サーバーガイドを参照済みであること

手順

1
エージェントガイドの確認
AWS Partner Central agents の利用を開始する前に、エージェントガイドを確認し、機能と利用方法を把握する。
2
コンソールからのエージェント利用
AWS コンソールで Partner Central にアクセスし、Opportunities セクションからエージェント機能を利用開始。パイプラインインサイトの確認やセールスプレイの取得が可能。
3
CRM システムとの MCP 連携
CRM からエージェントにアクセスする場合は、Partner Central agents MCP サーバーガイドに従い MCP 連携を設定。営業チームが CRM から直接エージェント機能を利用可能に。

⚠️ 制約事項・考慮点

制限事項

⚠️AWS パートナーとして登録済みのユーザーのみが利用可能
⚠️AI による分析結果であり、最終的な営業判断は人間が行う必要がある
⚠️CRM 連携には MCP サーバーの設定が必要で、初期導入に技術的作業が発生

考慮すべき点

💡トランスクリプトやメールなど機密性の高いデータ共有時のデータガバナンスポリシー確認が必要
💡推奨精度は入力データの質と量に依存するため、継続的なデータ入力が重要
