AWS Marketplace

💰 プロフェッショナルサービスの
出品手数料を 0.5% に引き下げ

📅 リリース日
2026年6月16日

📌 概要

AWS Marketplace は、プロフェッショナルサービスの出品手数料 (リスティング手数料) を従来の 2.5% から 0.5% へ引き下げました。 コンサルティングパートナー、システムインテグレーター、マネージドサービスプロバイダー、独立系ソフトウェアベンダー (ISV) は、 サービス販売のコストを大幅に削減できます。

従来の手数料
2.5%
→
新しい手数料
0.5%

手数料を 5 分の 1 に圧縮。新規プライベートオファーに適用

プロフェッショナルサービスは AWS Marketplace で成長を続けるカテゴリーであり、数百のパートナーがアクティブに取引しています。 今回の引き下げは新規に作成されるプライベートオファーに適用され、利用可能なすべての AWS リージョン、すべての価格モデル、すべての通貨が対象です。 既存の出品を持つパートナーは、特別な操作なしで自動的に恩恵を受けられます。

⚠️ アップデート前の課題

  • 2.5% の出品手数料が発生し、パートナーの取り分が圧迫されていた
  • 手数料負担が大きく、Marketplace 経由取引のインセンティブが限定的だった
  • ソフトウェア製品と比べてサービス販売のコスト効率が課題だった

✅ アップデート後の改善

  • 出品手数料が 0.5% に引き下げられ、パートナーの取り分が増加
  • 既存出品を持つパートナーは追加操作なしで自動適用
  • すべてのリージョン・価格モデル・通貨で一律に適用

🔧 主要機能

① 出品手数料の引き下げ

  • プロフェッショナルサービスの出品手数料を 2.5% から 0.5% へ引き下げ
  • 新規に作成されるすべてのプライベートオファーに適用
  • 既存のオファーやサブスクリプションは元の契約条件を維持

② 自動適用

  • 既存の出品を持つパートナーは追加操作不要で自動適用
  • パートナー側での設定変更や再申請は不要

③ 幅広い適用範囲

  • AWS Marketplace が利用可能なすべての AWS リージョンで適用
  • すべての価格モデルと通貨に対応
  • 従量課金やタイムアンドマテリアルなどの可変課金モデルにも対応

🛠️ 設定方法

前提条件

✓AWS Partner Network (APN) のメンバーであること
✓AWS Marketplace の販売者 (Seller) として登録済みであること
✓プロフェッショナルサービスの出品要件を満たしていること

ステップ1: AWS Partner Central での出品

コンサルティング、移行支援、マネージドサービスなどのサービス内容を製品として登録します。

ステップ2: プライベートオファーの作成

価格、課金モデル (定額、従量課金、タイムアンドマテリアルなど)、契約期間を設定します。新規オファーには自動的に 0.5% の出品手数料が適用されます。

ステップ3: お客様への提供と成約

お客様は AWS Marketplace 上で内容を確認しサブスクリプションを購入。成約時に引き下げ後の出品手数料が適用されます。

💵 料金例

出品手数料はパートナーがプライベートオファーを通じて成約した取引額に対して課されます。下記は概算であり、実際の金額は取引条件によって異なります。

🎯 メリット

ビジネス面

  • コスト削減: 手数料引き下げでパートナーの取り分が増加
  • 追加操作不要: 既存出品は自動的に恩恵を受けられる
  • 取引促進: Marketplace 経由の取引を選択しやすくなる

技術面

  • 既存ワークフロー維持: 出品・請求の変更なしで適用
  • 幅広い課金モデル対応: 従量課金やタイムアンドマテリアルに対応
  • 統合された取引: ソフトウェアとサービスを 1 つの取引に組み合わせるマルチプロダクトソリューションにも対応

⚠️ デメリット・制約事項

制限事項

→引き下げ後の手数料は新規に作成されるプライベートオファーにのみ適用
→既存のオファーやサブスクリプションは元の契約条件のまま、引き下げは適用されない
→プロフェッショナルサービスのカテゴリーが対象。ソフトウェア製品の手数料体系には影響しない

考慮すべき点

💡既存の長期契約を持つパートナーは、新規オファーへの切り替えによる影響を確認する必要がある
💡メリットを最大化するため、新規取引でのプライベートオファー活用を検討する

🚀 ユースケース

1. システムインテグレーターによる移行支援サービス

シナリオ: エンタープライズのお客様にクラウド移行支援サービスを提供し、Marketplace のプライベートオファーで移行プロジェクトの契約を締結する。

効果: 手数料 0.5% への引き下げで、大規模な移行プロジェクトでもコスト効率よくサービスを提供できる。

2. マネージドサービスプロバイダーの継続的運用支援

シナリオ: お客様のワークロードを継続的に運用・監視するマネージドサービスを月額課金で提供する。

効果: 継続的な課金モデルでも低い手数料が適用され、長期契約での収益性が向上する。

3. ISV によるソフトウェアと導入支援のセット提供

シナリオ: 独立系ソフトウェアベンダーが、自社ソフトウェア製品と導入支援サービスを 1 つの取引にまとめて提供する。

効果: マルチプロダクトソリューションとして組み合わせ、サービス部分には引き下げ後の手数料が適用される。

🔗 関連サービス・利用可能リージョン

  • AWS Partner Central: パートナーがプロフェッショナルサービスを出品・管理するためのポータル
  • AWS Marketplace プライベートオファー: 特定のお客様向けにカスタマイズした条件でサービスを提供する仕組み
  • AWS Professional Services: AWS 第一者のプロフェッショナルサービスも AWS Marketplace で提供されている
🌍利用可能リージョン: AWS Marketplace が利用可能なすべての AWS リージョン。すべての価格モデルおよび通貨が対象。

📝 まとめ

出品手数料が 2.5% → 0.5% へ大幅に引き下げられ、パートナーは AWS Marketplace を通じたサービス販売のコスト効率を大きく改善できます。 既存の出品は追加操作なしで自動適用されるため、新規のプライベートオファー作成時にこの引き下げを活用することを推奨します。 プロフェッショナルサービスの提供を検討しているパートナーは、AWS Partner Central での出品を進めるとよいでしょう。
