📋 概要

NVIDIA の Nemotron 3.5 Super VL が Amazon SageMaker JumpStart で利用可能になりました。Nemotron 3.5 ファミリーのビジョン言語モデル (VLM) であり、画像、動画、テキストを入力として受け取り、テキストを生成します。ドキュメントインテリジェンス、GUI 理解、動画質問応答、マルチモーダルエージェントアプリケーション向けに設計されており、AWS インフラストラクチャ上でマルチモーダル AI ソリューションをデプロイできます。

❌ アップデート前の課題

  • SageMaker JumpStart の Nemotron 3.5 ファミリーはテキスト中心で、画像や動画を扱うには別のモデルや仕組みが必要だった
  • ドキュメント、チャート、GUI、動画といった視覚情報とテキストを組み合わせたエージェントワークフローを単一のオープンモデルで構築することが難しかった
  • 長大なドキュメントや動画の処理では、コンテキスト長の制約が課題となるケースがあった

✅ アップデート後の改善

  • 画像、動画、テキストを入力できる VLM を SageMaker JumpStart から数クリックでデプロイ可能に
  • 最大 100 万トークンのコンテキスト長により、大規模なドキュメントや長時間の動画を含むユースケースに対応
  • NVFP4 版による最適化された推論と、BF16 版によるファインチューニングなどのカスタマイズを用途に応じて選択可能に

Nemotron 3.5 Super VL は、ビジョンエンコーダーで画像や動画を処理し、ハイブリッド MoE 言語バックボーンと MTP ヘッドによる投機的デコードでテキストを生成します。推論最適化向けの NVFP4 版とカスタマイズ向けの BF16 版の 2 つのバリアントから選択できます。

⭐ 主要機能

🖼️ 1. マルチモーダル入力対応
  • 画像、動画、テキストを入力として受け取り、テキストを生成
  • ドキュメントインテリジェンス、GUI 理解、動画質問応答、マルチモーダルエージェントアプリケーション向けに設計
  • 画像、動画、ドキュメント、チャート、GUI データによるマルチモーダル SFT と GRPO 強化学習によるポストトレーニングを実施
🧠 2. 大規模かつ効率的なモデルアーキテクチャ
  • 120B パラメータのハイブリッド Mixture-of-Experts (MoE) 言語バックボーン + ビジョンエンコーダー
  • アクティブパラメータは 12B で、パラメータ規模に対して効率的な推論を実現
  • 最大 100 万トークンのコンテキスト長をサポート
⚡ 3. 高速なテキスト生成と設定可能な推論
  • 投機的デコード用の Multi-Token Prediction (MTP) ヘッドを内蔵し、テキスト生成を高速化
  • リクエストごとに推論 (reasoning) の有効 / 無効を設定可能
  • 構造化 JSON 出力とツール呼び出しに対応し、エンタープライズエージェントワークフローに適合
🌏 4. 多言語サポート
🇺🇸 英語 🇫🇷 フランス語 🇪🇸 スペイン語 🇩🇪 ドイツ語 🇯🇵 日本語 🇮🇳 ヒンディー語 🇰🇷 韓国語 🇨🇳 中国語 +2 言語
  • 日本語を含む 10 言語をサポートし、グローバルおよび国内ユースケースに適用可能
📦 5. 用途に応じた 2 つのバリアント
  • NVFP4 版: NVIDIA RTX PRO 4500 Blackwell Server Edition GPU を搭載した G7 インスタンスでの最適化された推論向け
  • BF16 リファレンスウェイト版: ml.p5en.48xlarge での SFT、強化学習、蒸留、ドメイン適応などのカスタマイズ向け

🪜 デプロイ手順

1
SageMaker JumpStart モデルカタログでモデルを検索

SageMaker コンソールからモデルカタログを開き、「Nemotron 3.5 Super VL」を検索。モデルカードから詳細情報とデプロイオプションを確認できます。

2
モデルをデプロイ

コンソールから数クリックでデプロイするか、SageMaker Python SDK を使用してデプロイします。

Python SageMaker Python SDK によるデプロイ 
from sagemaker.jumpstart.model import JumpStartModel

# JumpStart モデル ID を指定してモデルを作成
# (実際のモデル ID は SageMaker JumpStart のモデルカタログで確認してください)
model = JumpStartModel(model_id="<nemotron-3-5-super-vl-model-id>")

# エンドポイントにデプロイ
predictor = model.deploy()
3
推論リクエストの送信

デプロイしたエンドポイントに画像、動画、テキストを含むマルチモーダルな入力を送信し、テキスト出力を取得。リクエストごとに推論 (reasoning) の有効 / 無効を設定できます。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓マルチモーダル AI の迅速な導入: 数クリックでデプロイでき、ドキュメント処理や動画解析を短期間で立ち上げ可能
✓エージェントワークフローへの適合: 構造化 JSON 出力とツール呼び出しに対応
✓多言語対応: 日本語を含む 10 言語でグローバル / 国内ユースケースに適用可能

🔬 技術面のメリット

✓効率的な推論: MoE 構成 (120B / アクティブ 12B) と MTP ヘッドによる投機的デコードで高速なテキスト生成
✓長大なコンテキスト: 最大 100 万トークンで大量のドキュメントや長い動画を処理
✓カスタマイズの柔軟性: BF16 版で SFT、強化学習、蒸留、ドメイン適応が可能

⚠️ 制限事項

✗出力はテキストのみで、画像や動画の生成には非対応
✗NVFP4 版には G7 インスタンス、BF16 版には ml.p5en.48xlarge が推奨されており、クォータ確保が必要
✗利用可能リージョンが公式発表で明示されておらず、利用予定リージョンでの提供状況確認が必要

💡 考慮すべき点

⚠推論エンドポイントは稼働時間に応じて課金されるため、スケーリングや停止などのエンドポイント管理が必要
⚠大規模なコンテキスト利用時は、レイテンシーとコストへの影響を事前に検証することが望ましい
⚠カスタマイズ (SFT、RL、蒸留など) には学習データの準備と評価プロセスの設計が必要

📝 まとめ

NVIDIA Nemotron 3.5 Super VL の SageMaker JumpStart 提供により、画像、動画、テキストを扱うマルチモーダル AI ソリューションを AWS 上で容易にデプロイできるようになりました。最大 100 万トークンのコンテキスト長、構造化 JSON 出力、ツール呼び出し、日本語を含む 10 言語対応など、エンタープライズエージェントワークフローに適した特徴を備えています。
