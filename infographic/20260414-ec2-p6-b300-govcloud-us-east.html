📋 概要

Amazon EC2 P6-B300 インスタンスが AWS GovCloud (US-East) リージョンで利用可能になりました。8 基の NVIDIA Blackwell Ultra GPU を搭載し、数兆パラメータ規模の基盤モデル (FM) や大規模言語モデル (LLM) のトレーニングとデプロイに最適化されています。

GovCloud リージョンでの提供開始により、米国政府機関や規制対象のワークロードを扱う組織が、最新世代の GPU コンピューティングリソースを活用して AI/ML ワークロードを実行できるようになります。

P6-B300 インスタンスのアーキテクチャ構成。8 基の NVIDIA Blackwell Ultra GPU、2.1 TB の GPU メモリ、6.4 Tbps の EFA、300 Gbps の ENA、4 TB のシステムメモリを搭載し、2 リージョンで利用可能です。

⚡ 主要機能

🎮 NVIDIA Blackwell Ultra GPU
  • 8 基の NVIDIA Blackwell Ultra GPU を搭載
  • FP4 (スパーシティなし) で P6-B200 比 1.5 倍の GPU TFLOPS を提供
  • 数兆パラメータ規模のモデルのトレーニングとデプロイに最適化
🧠 大容量 GPU メモリ
  • 2.1 TB の高帯域幅 GPU メモリ (HBM)
  • P6-B200 と比較して 1.5 倍の GPU メモリサイズ
  • 大規模モデルのメモリ内保持が可能
🌐 高速ネットワーキング
  • 6.4 Tbps の Elastic Fabric Adapter (EFA) ネットワーキング
  • 300 Gbps の専用 Elastic Network Adapter (ENA) スループット
  • P6-B200 と比較して 2 倍のネットワーク帯域幅
💾 大容量システムメモリ
  • 4 TB のシステムメモリ
  • データの前処理やモデルのロードに十分な容量

🔧 設定方法

前提条件

✓ AWS GovCloud (US-East) リージョンへのアクセス権限
✓ P6-B300 インスタンスのサービスクォータが承認済み
✓ EFA 対応の AMI とセキュリティグループの設定
✓ 適切な VPC とサブネットの構成

ステップ 1: サービスクォータの確認

Bash クォータ確認 
aws service-quotas get-service-quota \
  --service-code ec2 \
  --quota-code L-417A185B \
  --region us-gov-east-1

ステップ 2: EFA 対応セキュリティグループの作成

Bash セキュリティグループ作成 
# セキュリティグループの作成
aws ec2 create-security-group \
  --group-name p6-b300-efa-sg \
  --description "Security group for P6-B300 with EFA" \
  --vpc-id vpc-xxxxxxxx \
  --region us-gov-east-1

# 同一 SG 内の全トラフィックを許可
aws ec2 authorize-security-group-ingress \
  --group-id sg-xxxxxxxx \
  --protocol -1 \
  --source-group sg-xxxxxxxx \
  --region us-gov-east-1

ステップ 3: インスタンスの起動

Bash EFA 付きインスタンス起動 
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-xxxxxxxx \
  --key-name my-key-pair \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxxxxxxx,Groups=sg-xxxxxxxx,InterfaceType=efa" \
  --region us-gov-east-1

AMI は NVIDIA ドライバーと EFA ドライバーがプリインストールされた Deep Learning AMI の使用を推奨します。

⚠️ 制限事項

インスタンスサイズは p6-b300.48xlarge のみ。小さなサイズは未提供
利用可能リージョンは US West (Oregon) と GovCloud (US-East) の 2 リージョンに限定
GPU インスタンスのサービスクォータ引き上げが必要な場合あり

⚠️ 考慮すべき点

最大級のインスタンスタイプのため、コストが高額になる可能性
NVIDIA Blackwell Ultra GPU のドライバー/ソフトウェアスタックの互換性を事前確認
EFA の最大活用には適切なネットワーク構成と SG 設定が不可欠
