Amazon SageMaker AI

NVIDIA Nemotron モデルの
サーバーレスファインチューニング対応

SFT (教師ありファインチューニング) と RFT (強化ファインチューニング) でモデルをカスタマイズ
リリース日
2026.06.12

📌 概要

Amazon SageMaker AI が NVIDIA Nemotron 3 Nano モデルのサーバーレスモデルカスタマイズに対応しました。 合計 30B パラメータの人気オープンウェイトモデルを、独自のドメインやワークフローに合わせて適応できます。 インフラのプロビジョニングとトレーニングのオーケストレーションは SageMaker AI が処理するため、 利用者はクラスター管理ではなくデータと評価に集中でき、利用した分だけの従量課金となります。

❌ アップデート前の課題
  • Nemotron 3 Nano はデプロイ可能だが、独自データによるカスタマイズには非対応
  • 大規模モデルのファインチューニングにはクラスターのプロビジョニング・管理が必要で運用負荷が高い
  • インフラ管理に手間がかかり、データ準備やモデル評価に注力しにくい
➜
✅ アップデート後の改善
  • SFT および RFT で独自データにカスタマイズ可能に
  • サーバーレス方式で、プロビジョニングとオーケストレーションが不要
  • 利用した分だけの従量課金で、クラスター管理コストを意識せずに済む

SageMaker Studio または Python SDK からカスタマイズジョブを起動すると、SageMaker AI がインフラのプロビジョニングとトレーニングを自動で行い、独自データで適応させたモデルを生成します。

⚙️ 主要機能

🧩 NVIDIA Nemotron 3 Nano のサーバーレスカスタマイズ
  • 合計 30B パラメータを持つ NVIDIA のオープンウェイトモデルをカスタマイズ対象に
  • デプロイだけでなく、独自のドメインやワークフローへの適応が可能
  • インフラ管理を SageMaker AI に任せ、データと評価に集中できる
🎓 教師ありファインチューニング SFT
  • ラベル付きデータを用いて、ドメイン固有タスクの精度を向上
  • 組織のトーンやスタイルに合わせた出力の調整に活用
🏆 強化ファインチューニング RFT
  • 報酬に基づく学習により、新しいタスクへの性能を強化
  • SFT と組み合わせることで、より高度なモデル適応が可能

🔧 技術仕様: モデルとカスタマイズ手法

項目詳細
対象モデルNVIDIA Nemotron 3 Nano (オープンウェイト)
パラメータ数合計 30B
カスタマイズ手法教師ありファインチューニング (SFT)、強化ファインチューニング (RFT)
インフラ管理サーバーレス (プロビジョニング・オーケストレーションは SageMaker AI が実施)
課金方式従量課金 (利用した分のみ)
起動方法SageMaker Studio の Models ページ、または SageMaker Python SDK

🚀 設定方法

前提条件

✓Amazon SageMaker AI を利用可能な AWS アカウント
✓カスタマイズに使用するラベル付きの独自データ (SFT / RFT 向け)
✓対応リージョンでの SageMaker Studio または Python SDK の利用環境

手順

1
SageMaker Studio からカスタマイズジョブを起動
Models ページで NVIDIA Nemotron 3 Nano を選択し、データセットとカスタマイズ手法 (SFT / RFT) を指定すると、SageMaker AI が自動でトレーニングを実行します。
2
SageMaker Python SDK でプログラムから実行
SDK を使うことで、ノートブックやスクリプトからプログラム的にカスタマイズジョブを定義・起動できます。
Bash SageMaker Python SDK のインストール 
# SageMaker Python SDK のインストール
pip install --upgrade sagemaker
3
カスタマイズ済みモデルの評価とデプロイ
トレーニング完了後、カスタマイズ済みモデルを評価し、SageMaker AI 上にデプロイして推論エンドポイントとして利用します。

⚖️ メリットと制約事項

👍 メリット

✓運用負荷の軽減: クラスター管理が不要、データ準備・評価に集中
✓コスト最適化: 従量課金でアイドルインフラコストを抑制
✓市場投入の迅速化: ドメイン特化モデルを素早く構築・展開
✓柔軟なカスタマイズ: SFT と RFT の 2 手法に対応
✓スケーラビリティ: 規模に応じたリソースを自動確保

⚠️ 制約・考慮点

!対応モデルは現時点で NVIDIA Nemotron 3 Nano に限定
!利用可能リージョンは 4 リージョンに限定
!高品質なカスタマイズには適切に準備されたラベル付きデータが必要
!SFT と RFT でデータ形式や評価方法が異なり、目的に応じた手法選択が重要
!従量課金のため、データ量やジョブ回数に応じたコスト見積もりが必要

💡 ユースケース

🏥 1. ドメイン固有の精度向上
シナリオ: 医療や金融など専門用語が多い分野で、業界固有のラベル付きデータで SFT を実施
→ 効果: ドメイン固有タスクの回答精度が向上し、専門領域での実用性が高まる
💬 2. 組織のトーンへの出力調整
シナリオ: カスタマーサポートのチャットボットで、自社ブランドガイドラインに沿った応答トーンを実現するため過去の対応データで SFT
→ 効果: ブランドに一貫した応答が可能になり、顧客体験の質が向上
🎯 3. 新しいタスクへの性能強化
シナリオ: 既存モデルが対応していない独自タスクに対し、RFT で報酬ベースの学習を実施
→ 効果: 新規タスクでのモデル性能が強化され、業務固有の要件に対応

💰 料金

サーバーレスモデルカスタマイズは従量課金制で、利用したリソース分のみが課金されます。 クラスターのプロビジョニングや管理に伴う固定コストは発生しません。 具体的な料金は使用量やリージョンによって異なるため、最新の料金は Amazon SageMaker AI の料金ページを参照してください。

📝 まとめ

今回のアップデートにより、NVIDIA Nemotron 3 Nano をサーバーレスで SFT / RFT カスタマイズできるようになり、 インフラ管理の負担なくドメイン特化モデルを構築できます。東京リージョンでも利用可能なため、 独自データを活用した生成 AI の精度向上を検討している場合は、SageMaker Studio の Models ページまたは Python SDK からカスタマイズジョブを試してみることをお勧めします。
