Amazon EC2

🎮 EC2 G7 インスタンス
US East (バージニア北部) で利用可能に

📅 リリース日 2026 年 7 月 10 日 GPU インスタンス / リージョン拡大

📌 概要

AWS は、NVIDIA RTX PRO 4500 Blackwell Server Edition GPU を搭載した Amazon EC2 G7 インスタンスが、US East (バージニア北部) リージョンで 利用可能になったことを発表しました。これにより、G7 インスタンスは バージニア北部・オハイオ・オレゴンの 3 リージョンで利用できるようになりました。

G7 は前世代 G6 と比較して最大 4.6 倍の AI 推論パフォーマンスと 最大 2.1 倍のグラフィックスパフォーマンスを提供します。AI モデルのデプロイ、 映像品質グラフィックスレンダリング、ゲームストリーミング、動画トランスコーディング、空間コンピューティング、 GPU アクセラレーションによるデータ分析など幅広いワークロードに適しています。

❌ アップデート前の課題
  • バージニア北部で G7 を利用できず、他リージョンへの展開を検討する必要があった
  • 前世代 G6 では大規模化する AI 推論やグラフィックスワークロードで性能が不足するケースがあった
  • レイテンシやデータ所在地の要件から、バージニア北部での GPU リソース確保が求められていた
✅ アップデート後の改善
  • バージニア北部で G7 を起動でき、対応リージョンが 3 つに拡大
  • G6 比 最大 4.6 倍の AI 推論・最大 2.1 倍のグラフィックス性能をバージニア北部でも利用可能
  • リージョンをまたぐ構成変更なしに最新世代 GPU を活用可能に

G7 インスタンスの主要コンポーネントと、今回追加された US East (バージニア北部) を含む利用可能リージョン、サポートされるワークロードを示す構成図。

⚙️ 主要機能

🎮 NVIDIA RTX PRO 4500 Blackwell Server Edition GPU
  • 最新の NVIDIA Blackwell アーキテクチャを採用
  • GPU あたり 32 GB のメモリを搭載、最大 8 基まで搭載可能
  • G6 比で最大 4.6 倍の AI 推論・最大 2.1 倍のグラフィックス性能
🖥️ カスタム Intel Xeon 6 プロセッサ
  • 最大 192 個の仮想 CPU (vCPU) をサポート
  • 最大 768 GiB のシステムメモリ
  • 高性能な CPU と GPU の組み合わせで複雑なワークロードに対応
⚡ 高速ネットワークとストレージ
  • Elastic Fabric Adapter (EFA) で最大 700 Gbps のネットワーク帯域幅
  • 最大 7.6 TB のローカル NVMe SSD ストレージ
📍 US East (バージニア北部) での提供
  • バージニア北部・オハイオ・オレゴンの 3 リージョンで利用可能
  • オンデマンド、スポット、Savings Plans の購入オプションに対応

🚀 設定方法

前提条件

✓AWS アカウントが作成されている
✓適切な IAM 権限 (EC2 インスタンスの起動権限) が付与されている
✓G7 が利用可能なリージョン (バージニア北部・オハイオ・オレゴン) のいずれかを使用

AWS CLI からインスタンスを起動

Bash us-east-1 で G7 インスタンスを起動 
aws ec2 run-instances \
  --region us-east-1 \
  --image-id ami-xxxxxxxxx \
  --instance-type g7.xlarge \
  --key-name your-key-pair \
  --security-group-ids sg-xxxxxxxxx \
  --subnet-id subnet-xxxxxxxxx

GPU の確認

Bash nvidia-smi で GPU 認識を確認 
# インスタンスにログイン後、GPU の状態を確認
nvidia-smi

コンソールからは、リージョンをバージニア北部に設定し、インスタンスタイプで「G7」を選択して起動します (AMI は Deep Learning AMI 推奨)。

💡 メリット

ビジネス面

✓バージニア北部での可用性向上: 最大規模リージョンでリージョン移行なしにワークロードを最適化
✓高速な AI 推論: G6 比 最大 4.6 倍でレスポンス時間を短縮、顧客体験が向上
✓コスト効率: 高速処理により同じワークロードをより少ないインスタンスで処理

技術面

✓多様なワークロード対応: AI 推論からレンダリング、ストリーミング、データ分析まで幅広く対応
✓豊富なローカルストレージ: 最大 7.6 TB の NVMe SSD で大容量データへ高速アクセス
✓高スループットネットワーク: 最大 700 Gbps の EFA で分散ワークロードを高速化

⚠️ デメリット・制約事項

制限事項

!現在、バージニア北部・オハイオ・オレゴンの 3 リージョンでのみ利用可能
!GPU メモリは 32 GB/GPU に固定され、増減できない
!より大きな GPU メモリ (96 GB/GPU) が必要な場合は G7e を検討

考慮すべき点

!高性能な分コストも相応に高い (オンデマンド料金が高額)
!スポットインスタンスは中断のリスクがある
!Savings Plans はコスト削減できるが長期コミットメントが必要
!マルチ GPU を活用するにはアプリ側のコード最適化が必要

processor = AutoProcessor.from_pretrained(model_id)

Amazon EC2 G7 インスタンスが US East (バージニア北部) リージョンで利用可能になり、 対応リージョンが 3 つに拡大しました。NVIDIA RTX PRO 4500 Blackwell GPU を搭載し、 G6 比 最大 4.6 倍の AI 推論・最大 2.1 倍のグラフィックス性能を提供します。

AI 推論、グラフィックスレンダリング、ゲームストリーミング、データ分析など幅広いワークロードに適しており、 バージニア北部を中心に運用するお客様は、オンデマンド・スポット・Savings Plans の各購入オプションから選択して活用を検討することをお勧めします。
