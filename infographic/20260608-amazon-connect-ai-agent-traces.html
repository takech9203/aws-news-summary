Amazon Connect

AI エージェントトレース詳細

セルフサービス音声対話における AI エージェントの推論・行動・応答を完全可視化

2026/06/08

📋 概要

Amazon Connect Customer に、セルフサービス音声対話における AI エージェントのトレース詳細機能が追加された。AI エージェントが顧客との会話中にどのように推論し、行動し、応答したかをステップバイステップで可視化できるようになる。

❌ Before
  • AI エージェントの内部推論プロセスを確認する手段がなかった
  • 推論エラー/ツール呼び出しエラー/タイムアウトの切り分けが困難
  • 動作検証の仕組みがなく、本番デプロイに不安が伴っていた
✅ After
  • Connect Web UI からステップバイステップのトレースを直接確認可能
  • 推論・ツール呼び出し・応答生成の各段階を個別に検証可能
  • エージェンティックな体験を自信を持ってデプロイ可能に

🏗️ アーキテクチャ図

AI エージェントが顧客と音声で対話する際の処理フローと、管理者が Connect Web UI でトレース詳細を確認する流れ。

sequenceDiagram
    participant C as 顧客

    C->>V: 音声問い合わせ

    T-->>AI: ツール応答

    UI->>UI: トランスクリプト表示

SearchContacts API の変更内容

SearchContacts API に AiAgents 検索条件が追加され、AI エージェントが処理したコンタクトをフィルタリングできるようになった。

JSON SearchCriteria リクエスト例 
{
  "SearchCriteria": {
    "AiAgents": {
      "Criteria": [
        {
          "Id": "string",
          "VersionNumber": 123,
          "AiAgentEscalated": true,
          "AiUseCase": "AgentAssistance | SelfService"
        }
      ]
    }
  }
}
JSON AiAgentInfo レスポンス例 
{
  "Contacts": [
    {
      "AiAgentInfo": [
        {
          "AiAgentVersionId": "string",
          "AiAgentEscalated": true,
          "AiUseCase": "AgentAssistance | SelfService"
        }
      ]
    }
  ]
}

Step 1: AI エージェントトレースへのアクセス

Connect Web UI にログインし、コンタクト検索機能から対象の音声対話を検索。AiAgents フィルタで AI エージェント処理コンタクトを絞り込み。

Step 2: トレース詳細の確認

対象コンタクトを選択すると、トランスクリプトと並んで AI エージェントのトレース詳細が表示。各ステップの推論内容、ツール呼び出し、応答生成の過程を確認。

Step 3: 問題の診断

トレース内で問題が発生したステップを特定し、推論の正確性、ツール呼び出しパラメータの適切性、タイムアウトの有無を確認。

🎯 ユースケース

🔎 ユースケース 1: AI エージェントの障害分析
顧客が注文状況を確認しようとしたが、AI エージェントが正しく応答できずにエスカレーションが発生した。
1. Connect Web UI でエスカレーションされたコンタクトを検索
2. AiAgentEscalated: true でフィルタリング
3. トレース詳細で推論ステップを確認
4. ツール呼び出しパラメータのエラーを特定
5. AI エージェントのプロンプトまたはツール設定を修正
→ 問題の根本原因を数分で特定し、再発防止策を迅速に実施できる
🧪 ユースケース 2: AI エージェントの品質保証
新しい AI エージェントを本番環境にデプロイする前に、テスト対話のトレースを確認して動作を検証する。
1. テスト環境で様々なシナリオの音声対話を実施
2. 各対話のトレースを確認し、期待通りの推論が行われているか検証
3. エッジケースでの動作を確認
4. 問題なければ本番環境にデプロイ
→ デプロイ前の品質保証プロセスが確立され、本番環境での障害リスクを低減
📈 ユースケース 3: AI エージェントの継続的改善
セルフサービスの解決率が低下傾向にあるため、AI エージェントの改善ポイントを特定したい。
1. SearchContacts API で AiUseCase: SelfService のコンタクトを抽出
2. エスカレーション率が高いパターンを特定
3. 該当するトレースを分析し、共通の失敗パターンを発見
4. プロンプト調整やツール設定の最適化を実施
→ データドリブンで AI エージェントの改善サイクルを回すことが可能に

📝 まとめ

Amazon Connect Customer に AI エージェントトレース詳細機能が追加され、セルフサービス音声対話における AI エージェントの推論・行動・応答プロセスの完全な可視化が実現した。

コンタクトセンターの運用チームは、AI エージェントの問題を迅速に診断し、動作を検証したうえで本番デプロイできるようになる。AI エージェントを活用したセルフサービスの品質向上と運用効率化に直接貢献するアップデートであり、Amazon Connect で AI エージェントを運用中または導入検討中の組織は、早期にこの機能を活用した運用フローの整備を推奨する。
