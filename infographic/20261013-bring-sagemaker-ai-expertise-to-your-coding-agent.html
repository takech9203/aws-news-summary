Amazon SageMaker AI Agent Toolkit for AWS 📅 2026 年 10 月 13 日

🧠 AWS AI/ML スキルで SageMaker AI の専門知識をコーディングエージェントへ

Agent Toolkit for AWS の aws-ai-ml スキルにより、Kiro や Claude Code などのエージェントが自然言語ワークフローで ML のモデル選択・トレーニング・最適化・デプロイを実行

📋 概要

Agent Toolkit for AWS の AWS AI/ML スキル (aws-ai-ml) により、Kiro や Claude Code などのコーディングエージェントに Amazon SageMaker AI の深い専門知識を付与できるようになりました。開発者は 自然言語の単一ワークフローで、SageMaker AI 上でのモデルの選択・トレーニング・最適化・デプロイを、他の AWS 環境との連携も含めて実行できます。

本スキルは Agent Toolkit for AWS のコアスキルとして提供され、EC2 や Bedrock など他の AWS スキルと組み合わせて利用可能です。今回の発表により、Agent Toolkit for AWS が唯一のサポート対象の統合ポイントとなり、従来の AWS Labs のスキル / プラグインを置き換えます。また、SageMaker Studio の JupyterLab にプリインストールされており、Studio 内のターミナルからすぐに利用を開始できます。

対象ユーザー: コーディングエージェントを活用して ML ワークロードを構築する ML エンジニア、データサイエンティスト、アプリケーション開発者

❌ アップデート前の課題

  • エージェントが推論最適化やファインチューニングなどの専門ワークフローを理解しておらず、開発者が API 仕様やベストプラクティスを自分で調査してコードを書く必要があった
  • AWS Labs のスキル / プラグインが複数の場所に分散し、統合ポイントが一本化されていなかった
  • SageMaker Studio の JupyterLab でエージェントに SageMaker AI の知識を使わせるには、個別のセットアップが必要だった

✅ アップデート後の改善

  • 自然言語の指示だけで、モデルの選択・トレーニング・最適化・デプロイまでの一連のワークフローをエージェントに実行させることが可能に
  • Agent Toolkit for AWS が唯一のサポート対象の統合ポイントとなり、EC2 や Bedrock など他の AWS スキルと組み合わせた一貫したエージェント体験を実現
  • SageMaker Studio の JupyterLab にプリインストールされ、追加セットアップなしで利用開始が可能に

⚙️ 主要機能

⚡ 推論最適化 (Inference optimization)

レイテンシ、スループット、コストの観点から推論構成を最適化。既存エンドポイントのベンチマークを実行し、スループット (req/s、トークン/s)、レイテンシ (p50、p99、TTFT、トークン間レイテンシ) をレポート。S3 上のカスタムモデル、JumpStart 基盤モデル、Hugging Face Hub のモデルに対してランク付けされたインスタンスタイプ推奨を提供し、2 つのベンチマーク結果の差分比較も可能。

🎯 モデルカスタマイズ (Model customization)

ユースケースの定義からトレーニング、評価、デプロイまでをガイド付きで支援するファインチューニングワークフロー。AI 主導のワークフローにより、複雑な設定を簡素化。

🏋️ サーバーフルトレーニング (Serverful training)

従来型 ML と生成 AI の両方のトレーニングジョブに対応。SageMaker AI のマネージドインフラストラクチャ上でのトレーニング実行を支援。

📊 MLflow による実験管理

実験追跡とモデルライフサイクル管理をエージェント経由で操作。SageMaker AI のマネージド MLflow と連携。

🚀 JumpStart モデルのデプロイと推奨

事前構築済みモデルのデプロイと、ユースケースに応じたモデル推奨を提供。

🔄 Processing jobs によるデータ準備

マネージドコンピュート上でのデータ準備と ETL 処理を支援。

🔧 技術仕様

📦 スキルの提供形態

項目詳細
スキル名aws-ai-ml
提供元Agent Toolkit for AWS (GitHub: aws/agent-toolkit-for-aws)
対応エージェントKiro、Claude Code、Codex、Cursor、fx など MCP 対応エージェント全般
プリインストール環境SageMaker Studio JupyterLab
生成コードSageMaker Python SDK v3 (検査・修正・実行が可能)
位置づけ従来の AWS Labs スキル / プラグインを置き換える唯一のサポート対象統合ポイント

🛡️ エージェントの動作原則

✓エンドポイント名や S3 URI などの不足情報は推測せず、開発者に質問する
✓実トラフィックを伴う操作 (ベンチマークなど) の前に明示的な確認を求める
✓生成されるコードはすべて検査・修正可能な SageMaker Python SDK v3 のコードで、不透明な UI の裏で処理が実行されることはない

🚀 設定方法

📌 前提条件

1.AWS CLI 2.35 以降と uv がインストールされていること (ローカル利用の場合)
2.AWS 認証情報に SageMaker AI の API (エンドポイント作成、ベンチマーク / 推奨ジョブ実行など) を呼び出す IAM 権限があること
3.SageMaker Studio で利用する場合は、JupyterLab スペースの共有設定が Private であること (スキル同期の条件)

ステップ 1: Agent Toolkit for AWS のインストール (ローカル利用の場合)

BashAWS CLI 組み込みコマンド
aws configure agent-toolkit

Claude Code の場合は、公式マーケットプレイス経由のプラグインインストール (/plugin install aws-core@claude-plugins-official など) も利用できます。

ステップ 2: AWS AI/ML スキルの追加

BashGitHub リポジトリからスキルを追加
npx skills add aws/agent-toolkit-for-aws/skills/aws-ai-ml

Kiro の場合は、.kiro/settings/mcp.json に AWS MCP Server の設定を追加したうえでスキルをインストールします。

ステップ 3: 自然言語での利用

Textエージェントへの指示例
Benchmark my Llama endpoint on SageMaker AI.
Find the best instance for model huggingface-reasoning-qwen3-8b on SageMaker AI.

エージェントのチャットで「What skills are available?」とスキルの認識を確認したあと、自然言語で意図を伝えます。エージェントがスキルの知識に基づいて SageMaker Python SDK v3 のコードを生成し、確認を経て実行します。

📓 SageMaker Studio の場合: スキルがプリ構成されたイメージで JupyterLab スペースを作成し、ターミナルからエージェントにログイン (例: kiro-cli login) するだけで利用を開始できます。

💡 メリット

💼 ビジネス面

✓ML ワークフローの開発速度向上: API 仕様やベストプラクティスの調査が不要になり、自然言語の指示だけで推論最適化やファインチューニングを進められる
✓コスト最適化の促進: モデルごとに最適なインスタンスタイプの推奨とベンチマーク比較が容易になり、推論コストの削減判断をデータに基づいて行える
✓追加コストなし: スキル自体は無料で、エージェントが使用する AWS リソースの料金のみが発生する

🔬 技術面

✓透明性の高いコード生成: 出力はすべて検査・修正・実行可能な SageMaker Python SDK v3 のコードであり、ブラックボックス化を回避できる
✓他の AWS スキルとの統合: EC2 や Bedrock などのスキルと組み合わせて、ML ワークロードと周辺の AWS 環境を単一のエージェントワークフローで扱える
✓安全な実行制御: 実トラフィックを伴う操作の前に明示的な確認を求めるなど、エージェントの動作原則が組み込まれている

⚠️ デメリット・制約事項

🚧 制限事項

✗従来の AWS Labs のスキル / プラグインは置き換えられるため、既存利用者は Agent Toolkit for AWS への移行が必要
✗SageMaker Studio でスキルを同期するには、JupyterLab スペースの共有設定を Private にする必要がある
✗モデルデプロイの実行など、スキルのスコープ外の操作についてはエージェントが代替案を提示するにとどまる場合がある

🤔 考慮すべき点

⚠️ベンチマークは既存エンドポイントに実トラフィックを送信するため、本番エンドポイントへの実行は影響を考慮して判断する必要がある
⚠️エージェントが生成・実行するコードは SageMaker AI の API を呼び出すため、IAM 権限の適切なスコープ設定が重要
⚠️ベンチマークで作成したエンドポイントや JupyterLab スペース、S3 上のジョブ成果物は、課金回避のため利用後に削除することが推奨される
⚠️Hugging Face Hub のゲート付きモデル (Llama 系など) を利用する場合は、ライセンス確認と Hugging Face トークンが必要

💰 料金

AWS AI/ML スキル自体に追加料金はありません。エージェントが使用する AWS リソース (SageMaker AI のエンドポイント、トレーニングジョブ、ベンチマークジョブなど) に対してのみ料金が発生します。

🔗 関連サービス・機能

🧪 Amazon SageMaker AI

スキルが操作する対象のマネージド ML サービス。推論、トレーニング、JumpStart、MLflow、Processing jobs などの機能をエージェント経由で利用する。

🧰 Agent Toolkit for AWS

AWS 公式のスキル、MCP サーバー、プラグインのコレクション。aws-core、aws-agents、aws-data-analytics などのプラグインと組み合わせて利用できる。

Agent Toolkit for AWS の他のスキルがカバーする生成 AI サービス。AWS AI/ML スキルと組み合わせて、Bedrock と SageMaker AI をまたぐワークフローを構築できる。
