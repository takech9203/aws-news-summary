🧪 ノートブックインスタンスで
G6e インスタンスをサポート

リリース日
2026-06-23

📌 概要

Amazon SageMaker は、ノートブックインスタンスで Amazon EC2 G6e インスタンスの一般提供 (GA) を開始しました。最大 8 基の NVIDIA L40s Tensor Core GPU (各 48 GB メモリ) と第 3 世代 AMD EPYC プロセッサを搭載します。

G5 インスタンス比で最大 2.5 倍のパフォーマンスを提供し、最大 13B パラメータの LLM や、画像・動画・音声を生成する拡散モデルのインタラクティブなデプロイ・ファインチューニングを単一のノートブック環境で完結できます。

❌ アップデート前の課題

  • 大規模 LLM・拡散モデルのテストに十分な GPU メモリを確保しにくい
  • G5 世代では高負荷な生成 AI ファインチューニングで性能不足
  • 高性能 GPU 検証にノートブック以外の環境が別途必要

✅ アップデート後の改善

  • 48 GB の NVIDIA L40s GPU をノートブック上で直接利用可能
  • 最大 2.5 倍の性能でファインチューニング・検証を高速化
  • 最大 13B パラメータの LLM・拡散モデルをインタラクティブに検証

SageMaker ノートブックインスタンス上で G6e を選択し、NVIDIA L40s GPU で生成 AI のファインチューニングやモデルデプロイのインタラクティブなテストを行う構成。

  • 大規模モデルや高解像度の拡散モデルワークロードに対応
🖥️ 第 3 世代 AMD EPYC プロセッサ
  • GPU と組み合わせて高いスループットを実現
  • データ前処理や推論パイプラインの CPU 処理にも対応

  • EC2 G5 インスタンスと比較して最大 2.5 倍のパフォーマンス
  • 生成 AI のファインチューニングや拡散モデルの実行を高速化
🤖 生成 AI ワークロードへの最適化
  • 最大 13B パラメータの LLM のデプロイに対応
  • 画像・動画・音声を生成する拡散モデルの実行に対応
  • インタラクティブなモデルトレーニング・デプロイテストに利用可能

🛠️ 設定方法

前提条件

✓SageMaker を利用可能な AWS アカウントと適切な IAM 権限
✓G6e インスタンスがサポートされているリージョンの利用
✓必要に応じた GPU インスタンスのサービスクォータの引き上げ申請

ステップ 1: ノートブックインスタンスの作成

インスタンスタイプとして G6e (例: ml.g6e.xlarge) を選択して作成します。

Bashcreate-notebook-instance
aws sagemaker create-notebook-instance \
  --notebook-instance-name my-g6e-notebook \
  --instance-type ml.g6e.xlarge \
  --role-arn arn:aws:iam::123456789012:role/SageMakerExecutionRole

ステップ 2: 起動と接続

ステータスが InService になったら、JupyterLab または Code Editor を開いて作業を開始できます。

Bashdescribe-notebook-instance
aws sagemaker describe-notebook-instance \
  --notebook-instance-name my-g6e-notebook

ステップ 3: 生成 AI ワークロードの実行

JupyterLab 上で LLM のファインチューニングや拡散モデルの推論を実行。48 GB / GPU のメモリを活用し、最大 13B パラメータのモデルをインタラクティブにテストできます。

💡 メリット

💼 ビジネス面
  • 開発の高速化: 最大 2.5 倍の性能で検証サイクルを短縮
  • 環境の統合: ノートブックで高性能 GPU を直接利用、別環境の手間とコストを削減
  • 生成 AI 対応: LLM・拡散モデルのプロトタイピングを単一環境で完結
⚙️ 技術面
  • 大容量 GPU メモリ: 各 48 GB で大規模・高解像度ワークロードに対応
  • 柔軟なスケーリング: xlarge から 48xlarge まで選択可能
  • 最新 GPU の活用: L40s でトレーニングと推論の両方を効率化

⚠️ デメリット・制約事項

制限事項

▸利用可能なリージョンが限定されています
▸GPU インスタンスはサービスクォータの引き上げ申請が必要になる場合があります
▸最大 13B パラメータの LLM が推奨対象であり、より大規模なモデルには別構成が必要な場合があります

考慮すべき点

▸GPU インスタンスは高コストになりやすいため、不要時はノートブックインスタンスの停止を推奨
▸大規模な本番トレーニング・推論には、SageMaker トレーニングジョブや推論エンドポイントの検討を推奨

🎯 ユースケース

1. 生成 AI モデルのファインチューニング

シナリオ: 自社データで LLM をファインチューニングし、ドメイン固有タスクに対応させたい。

ml.g6e.12xlarge で 13B パラメータ規模の LLM を読み込み、PEFT / LoRA などでインタラクティブに検証。

効果: 高性能 GPU でパラメータ調整を短いサイクルで反復できます。

2. 拡散モデルによるコンテンツ生成の検証

シナリオ: 画像や動画を生成する拡散モデルの出力品質を対話的に調整したい。

ml.g6e.xlarge で拡散モデルをロードし、プロンプトやパラメータを変えながら生成結果を即座に確認。

効果: 48 GB の GPU メモリで高解像度生成を行い、検証作業を効率化できます。

3. モデルデプロイのインタラクティブなテスト

シナリオ: 本番デプロイ前に推論挙動とレイテンシーを確認したい。

ノートブック上でモデルをロードし、サンプル入力に対する推論結果とパフォーマンスを確認。

効果: 本番デプロイ前に動作を検証し、想定外の問題を早期発見できます。

💰 料金

G6e インスタンスの利用には SageMaker ノートブックインスタンスの料金が適用されます。料金はインスタンスサイズ (ml.g6e.xlarge から ml.g6e.48xlarge) およびリージョンによって異なります。最新かつ正確な料金は公式の Amazon SageMaker 料金ページを参照してください。

📝 まとめ

SageMaker ノートブックインスタンスでの G6e サポートにより、データサイエンティストは NVIDIA L40s GPU を活用して、生成 AI のファインチューニングや LLM・拡散モデルのインタラクティブなテストを高速に実行できるようになりました。生成 AI のプロトタイピングを進めるチームは、対応リージョンでインスタンスサイズとサービスクォータを確認し、既存のノートブックワークフローへの導入を検討することが推奨されます。
