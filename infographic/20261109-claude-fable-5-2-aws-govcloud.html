🧠 Claude Fable 5.2 が AWS GovCloud (US) で利用可能に

Anthropic 最高性能の一般提供モデルを、政府機関・規制業界のコンプライアンス境界内で

📋 概要

Anthropic の最も高性能な一般提供モデル Claude Fable 5.2 が、AWS GovCloud (US) リージョンの Amazon Bedrock で利用可能になりました。米国政府機関や規制要件の厳しい業界のお客様が、コーディング、数学、科学分野で新しい水準を達成したフロンティアモデルを FedRAMP High や ITAR 対応環境で利用できます。

Claude Fable 5.2 は数時間から数日に及ぶ無人での自律稼働が可能で、複数リポジトリやモノレポにまたがる大規模で曖昧なエンジニアリング課題に取り組み、自己テストと「引き継いだ結論を疑う姿勢」により従来モデルが見逃していた根本原因を発見します。リードエージェントとして数百のサブエージェントを調整する能力も確認されています。

同一基盤モデルでサイバーセキュリティ・バイオ研究向け能力を完全に保持した Claude Mythos 5.2 も、Anthropic の検証プログラムを通じて利用できます。両モデルは「covered models」に指定されており、安全性モニタリングのためのデータ保持が必要です (対象のお客様はゼロデータ保持で利用可能)。

⚡ 主要機能

🏛️ 1. AWS GovCloud (US) での Claude Fable 5.2 提供
  • us-gov-east-1 と us-gov-west-1 の両リージョンで利用可能
  • Geo クロスリージョン推論プロファイル経由で提供 (In-Region 推論と Global 推論は非対応)
  • 商用リージョンと同じフロンティアモデルをコンプライアンス境界内で利用可能
🤖 2. 長時間の自律的な技術作業
  • 数時間から数日に及ぶ無人稼働で、より大きく困難なプロジェクトに対応
  • 複数リポジトリやモノレポにまたがる、大規模で定義の曖昧な課題に対応
  • 自己テストと「引き継いだ結論を疑う姿勢」で従来モデルが見逃した根本原因を発見
  • リードエージェントとして数百のサブエージェントを調整し、再現しない結果にフラグを立てる能力を確認済み
🔬 3. コーディングを超えた適用領域
  • 科学研究向けの新しい分析手法の開発
  • 定量的ファイナンス分野へのフロンティア推論の適用
  • 判断力、反復、正確性が重要な分野 (ソフトウェアエンジニアリング、科学研究、金融) を推奨用途に
🔐 4. Claude Mythos 5.2 の提供 (検証プログラム限定)
  • Claude Fable 5.2 と同一の基盤モデルで、サイバーセキュリティ・バイオ研究向けの能力を完全に保持
  • Anthropic の検証プログラム (Cyber Verification Program など) を通じた許可リスト制で提供
🛡️ 5. 安全性分類器とデータ保持要件
  • 高リスクなサイバーセキュリティ活動・研究バイオロジータスクをブロックする安全性分類器を搭載 (ブロック時は stop_reason: "refusal" と stop_details を返却)
  • covered model のため、Data Retention API でデータ保持モードを aws_review に設定するオプトインが必要
  • Enterprise Frontier Safeguards の提供開始まで、対象のお客様はゼロデータ保持で利用可能

📡 API 変更履歴

既存の Amazon Bedrock Runtime API (Converse、InvokeModel、Messages) に新しいモデルを追加するもので、新規 API の追加はありません。既存アプリケーションはモデル ID の変更のみで移行可能です。

🗄️ データ保持設定

利用には Data Retention API でデータ保持モードを aws_review に設定するオプトインが必要です。ゼロデータ保持の対象可否は AWS に確認してください。

🚀 設定方法

✅ 前提条件

✓AWS GovCloud (US) アカウントを保有していること
✓Amazon Bedrock コンソールで Claude Fable 5.2 へのモデルアクセスを有効化していること
✓Data Retention API でデータ保持モードを設定していること (ゼロデータ保持の対象可否は AWS に確認)
1
推論プロファイルの確認

GovCloud で利用可能な Geo クロスリージョン推論プロファイル ID を確認します。GovCloud では In-Region 推論ではなく推論プロファイル経由でモデルを呼び出します。

Bash推論プロファイルの一覧取得
aws bedrock list-inference-profiles \
  --region us-gov-west-1 \
  --query "inferenceProfileSummaries[?contains(inferenceProfileId, 'claude-fable-5-2')]"
2
Converse API でモデルを呼び出す

確認した推論プロファイル ID を指定して Converse API を呼び出します。既存の Converse / InvokeModel ベースのアプリケーションは、モデル ID の変更のみで移行できます。

BashConverse API の呼び出し
aws bedrock-runtime converse \
  --region us-gov-west-1 \
  --model-id "<ステップ 1 で確認した推論プロファイル ID>" \
  --messages '[{"role": "user", "content": [{"text": "Amazon Bedrock の特徴を説明してください"}]}]'
3
refusal 応答のハンドリングを実装する

安全性分類器によるブロック時は HTTP 200 で stop_reason: "refusal" と制限カテゴリを含む stop_details が返却されます。アプリケーション側で stop_reason を確認する処理を実装してください。サイバーセキュリティやバイオ研究の正当な用途では、Anthropic の検証プログラムを通じて制限の緩いアクセスを申請できます。

✓自律エージェントによる生産性向上: 数時間から数日の無人稼働で大規模プロジェクトを推進

🔧 技術面のメリット

✓1M トークンコンテキスト: モノレポ全体の大規模なコード理解・修正が可能
✓適応的思考と effort 制御: 5 段階の effort レベルで推論の深さとコストを調整
✓プロンプトキャッシュ対応: 繰り返し利用するコンテキストのコストとレイテンシを削減
✓既存 API との互換性: 移行はモデル ID の変更のみ

⚠️ 制限事項

✗GovCloud では Geo クロスリージョン推論のみ (In-Region / Global 推論は非対応)
✗サービスティアは Standard のみ (Priority / Flex / Reserved は非対応)
✗Count tokens API、Intelligent prompt routing、暗黙的プロンプトキャッシュは非対応
✗temperature は 1.0 または未指定、top_k は非対応
✗適応的思考は常時有効で無効化できない

🤔 考慮すべき点

⚠covered model のため aws_review モードへのオプトインが必要。ZDR が必要な場合は対象顧客向け措置の適用可否を確認
⚠stop_reason: "refusal" のハンドリング実装が必要
⚠Claude Mythos 5.2 の利用は Anthropic の検証プログラムへの申請が必要
⚠難しいタスクでは 1 リクエストが長時間になり得るため、タイムアウト設計とストリーミングの利用を検討

🏛️ 1. 政府機関の大規模レガシーシステムのモダナイゼーション

シナリオ: 連邦政府機関が、複数リポジトリにまたがる大規模なレガシーコードベースのモダナイゼーションを、GovCloud のコンプライアンス境界内で実施。

  • GovCloud 上の開発環境から Bedrock の Claude Fable 5.2 を呼び出すエージェントを構築
  • モノレポ全体を 1M トークンのコンテキストで解析し、依存関係と修正方針を特定
  • エージェントが修正、テスト、検証を自律的に反復し、人間はレビューに集中
✨ 効果: 機密性の高いコードを商用環境に出すことなく、フロンティアモデルによる長時間の自律的なエンジニアリング作業を実現。
🔬 2. 規制業界における科学研究・定量分析

シナリオ: 政府系研究機関や金融規制対象の組織が、科学研究の分析手法開発や定量的ファイナンスの高度な推論に Claude Fable 5.2 を活用。

  • 研究データや市場データを GovCloud 内の S3 と Bedrock Knowledge Base に配置
  • 分析手法の設計と検証を依頼し、再現しない結果のフラグ付けを活用
  • effort レベルを high / xhigh に設定し、正確性が重要な分析の品質を確保

  • Cyber Verification Program に申請し、許可リストへの登録を受ける
  • GovCloud 上の Bedrock から Claude Mythos 5.2 を呼び出し、大規模コードベースの脆弱性を調査
  • 悪用可能性の実証を含む具体的な調査結果をもとに、脅威が顕在化する前に修正
✨ 効果: 完全なサイバー能力を保持したモデルにより、防御的セキュリティ業務を加速。
