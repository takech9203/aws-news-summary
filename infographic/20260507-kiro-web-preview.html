📋 概要

Kiro Web (Preview) が app.kiro.dev で利用可能になった。Kiro Pro、Pro+、Power プランのユーザーが対象で、ブラウザベースの AI エージェントと対話しながらコード変更を進め、最終的にプルリクエストとして成果物を出力できる。

複数リポジトリにまたがる変更を単一セッションで調整できる点が大きな特徴。IDE (デスクトップ) と CLI に加え、Web インターフェースが追加されたことで、環境構築なしにブラウザからすぐにエージェントを利用可能に。

❌ Before

  • デスクトップ IDE のインストールまたは CLI セットアップが必要
  • 複数リポジトリの変更は個別に作業
  • PR まで自動化する手段がない
  • 規約の引き継ぎが限定的

✅ After

  • ブラウザからすぐにエージェント利用可能
  • 単一セッションで複数リポジトリを横断変更
  • Autonomous モードで計画から PR まで自動実行
  • Steering ファイルが IDE/CLI/Web で統一動作

⚡ 主要機能

🔀 Collaborative モードと Autonomous モード

  • Collaborative モード (デフォルト): ユーザーがエージェントと対話しながらアプローチを議論し、コードを共同作成。準備ができたら PR の作成を指示
  • Autonomous モード: エージェントがタスク全体を所有。質問で要件を明確化し、計画を立て、専門サブエージェントに委任し、自動的に PR を作成
  • モードはセッション中にトグルで切り替え可能

🐙 GitHub ネイティブワークフロー

  • セッション開始時に作業対象のリポジトリを選択
  • 隔離サンドボックスにクローンし、複数リポジトリの編集と PR を単一セッションで調整
  • GitHub Issues に kiro ラベルまたは /kiro コメントで作業を割り当て
  • フィーチャーブランチの作成、コミット、詳細な説明付き PR を自動生成
  • PR レビューコメントに /kiro all で一括対応、/kiro fix で個別対応

📐 Steering の持続

  • .kiro/steering/ ディレクトリの Steering ファイルがセッション開始時にロード
  • Kiro IDE、CLI と同じフォーマットで動作
  • PR コメントを通じてエージェントに教えた内容が将来のセッションに引き継ぎ
  • チーム全体のリポジトリで一貫した規約を適用可能

🔒 隔離サンドボックス

  • 各タスクは専用の隔離サンドボックスで実行
  • リポジトリのクローン、環境設定の検出・構成、完了後のクリーンアップを自動実行
  • ネットワークアクセス、環境変数、シークレット、MCP サーバーをエージェント設定ページから制御

🔧 GitHub 連携コマンド

kiro ラベル Issue にラベルを付与してエージェントに作業を割り当て
/kiro Issue または PR にコメントでエージェントを呼び出し
/kiro all PR の全レビューフィードバックに一括対応
/kiro fix PR の個別スレッドに対応

💡 ユースケース

🔄 マイクロサービスの横断的リファクタリング

共通ライブラリの API を変更し、依存する複数のマイクロサービスを同時に更新する必要がある場合。

  1. app.kiro.dev でセッション開始
  2. 共通ライブラリ + 3 つのサービスリポジトリを選択
  3. Autonomous モードに切り替え
  4. 「共通ライブラリの認証モジュールを OAuth 2.1 に更新し、依存サービスを追従させてください」と指示
  5. エージェントが 4 つのリポジトリに整合性のある PR を作成

効果: 従来は数時間～数日かかっていた横断的変更を単一セッションで完了

🐛 GitHub Issue からのバグ修正自動化

バグレポートが Issue として報告され、原因調査から修正、テスト追加、PR 作成までを自動化。

  1. GitHub Issue に "kiro" ラベルを付与
  2. エージェントが Issue を認識し、タスクを自動開始
  3. コードベースを分析し、バグの原因を特定
  4. 修正コードとテストケースを生成
  5. フィーチャーブランチで PR を作成し、Issue を参照

効果: 定型的なバグ修正を自動化し、Issue から PR までのリードタイムを大幅に短縮

👁️ PR レビューフィードバックへの一括対応

PR に複数のレビュアーから指摘があり、それぞれのフィードバックに対応する必要がある場合。

  1. レビュアーが PR にコメントを追加
  2. PR に "/kiro all" とコメント
  3. エージェントが全レビューコメントを分析
  4. 各指摘に対する修正を実施し、コミットをプッシュ
  5. レビュアーに対応完了を通知

効果: レビュー対応時間を短縮し、PR マージまでのサイクルを高速化
