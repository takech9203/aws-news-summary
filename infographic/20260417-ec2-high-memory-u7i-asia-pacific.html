概要

Amazon EC2 High Memory U7i インスタンスが、AWS アジアパシフィック (シンガポール) リージョン (ap-southeast-1) で利用可能になりました。U7i-8TB と U7i-12TB の 2 つのインスタンスタイプが提供され、SAP HANA、Oracle、SQL Server などの大規模なインメモリデータベースワークロードに対応します。

U7i インスタンスは AWS 第 7 世代のインスタンスファミリーに属し、カスタム第 4 世代 Intel Xeon Scalable Processors (Sapphire Rapids) を搭載しています。シンガポールリージョンは ASEAN 地域のハブとして、東南アジア全域のお客様にとって重要な拠点です。

アジアパシフィック (シンガポール) リージョンで利用可能になった U7i High Memory インスタンスの構成を示しています。2 つのインスタンスタイプが 100 Gbps のネットワークおよび EBS 帯域幅を備え、SAP HANA、Oracle、SQL Server などのインメモリデータベースワークロードに対応します。

主要機能

U7i-8TB インスタンス
  • 8 TiB の DDR5 メモリを搭載
  • 448 vCPU を提供
  • 最大 100 Gbps の Amazon EBS 帯域幅をサポート
  • 最大 100 Gbps のネットワーク帯域幅をサポート
U7i-12TB インスタンス
  • 12 TiB の DDR5 メモリを搭載
  • 896 vCPU を提供
  • 最大 100 Gbps の Amazon EBS 帯域幅をサポート
  • 最大 100 Gbps のネットワーク帯域幅をサポート
プロセッサとメモリ
  • カスタム第 4 世代 Intel Xeon Scalable Processors (Sapphire Rapids) を搭載
  • DDR5 メモリにより、DDR4 と比較して高いメモリ帯域幅を実現
  • AWS 第 7 世代インスタンスファミリーに属する
ネットワーク機能
  • 100 Gbps の EBS 帯域幅と 100 Gbps のネットワーク帯域幅を同時にサポート
  • ENA Express をサポートし、低レイテンシの通信が可能
  • 高速なデータローディングとバックアップに対応

設定方法

前提条件

AWS アカウントでアジアパシフィック (シンガポール) リージョンが利用可能であること
U7i インスタンスタイプに対応するサービスクォータが確保されていること
適切な AMI (SAP HANA、Oracle、SQL Server 用) が利用可能であること

ステップ 1: サービスクォータの確認

Bash vCPU クォータの確認 
# vCPU クォータの確認
aws service-quotas get-service-quota \
  --region ap-southeast-1 \
  --service-code ec2 \
  --quota-code L-43DA4232

U7i インスタンスは大量の vCPU を使用するため、Running On-Demand High Memory instances のクォータが十分であることを確認します。

ステップ 2: インスタンスの起動

Bash U7i-12TB インスタンスをシンガポールリージョンで起動 
# U7i-12TB インスタンスをシンガポールリージョンで起動
aws ec2 run-instances \
  --region ap-southeast-1 \
  --instance-type u7i-12tb.224xlarge \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --key-name my-key-pair \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --block-device-mappings '[{"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":500,"VolumeType":"gp3"}}]'

ステップ 3: インスタンスの確認

Bash 起動したインスタンスの状態を確認 
# 起動したインスタンスの状態を確認
aws ec2 describe-instances \

  --query 'Reservations[].Instances[].[InstanceId,InstanceType,State.Name]' \
  --output table

ユースケース

ASEAN 地域の SAP HANA インメモリデータベース
シンガポールを拠点とする製造業企業が、東南アジア地域のデータレジデンシー要件を満たしながら SAP HANA を最大 12 TiB のメモリで運用したい。
Bash SAP HANA 認定 AMI で U7i-12TB を起動 
# SAP HANA 認定の AMI で U7i-12TB インスタンスを起動
aws ec2 run-instances \
  --region ap-southeast-1 \
  --instance-type u7i-12tb.224xlarge \
  --image-id ami-sap-hana-certified \
  --placement '{"Tenancy":"dedicated"}' \
  --block-device-mappings '[
    {"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":500,"VolumeType":"gp3"}},
    {"DeviceName":"/dev/sdb","Ebs":{"VolumeSize":2000,"VolumeType":"io2","Iops":64000}}
  ]'
12 TiB のメモリにより大規模な SAP HANA データベースをシンガポールリージョンで運用でき、ASEAN 地域のデータ規制を遵守しながら低レイテンシのアクセスを実現
Oracle Database のインメモリ処理
東南アジアの金融機関が Oracle Database をインメモリオプション付きで運用し、リアルタイムの取引分析を高速に処理したい。
Bash Oracle Database 用 U7i-8TB を起動 
# Oracle Database 用の U7i-8TB インスタンスを起動
aws ec2 run-instances \
  --region ap-southeast-1 \
  --instance-type u7i-8tb.112xlarge \
  --image-id ami-oracle-linux \
  --block-device-mappings '[
    {"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":200,"VolumeType":"gp3"}},
    {"DeviceName":"/dev/sdb","Ebs":{"VolumeSize":5000,"VolumeType":"io2","Iops":64000}}
  ]'
8 TiB のメモリで Oracle Database In-Memory オプションを最大限活用し、大規模なデータセットのリアルタイムクエリを高速に処理
SQL Server ビジネスインテリジェンス
ASEAN 地域の小売企業が SQL Server のインメモリ OLTP とカラムストアインデックスを活用して、大規模なビジネスインテリジェンス分析を実行したい。
Bash SQL Server 用 U7i-8TB を起動 
# SQL Server 用の U7i-8TB インスタンスを起動
aws ec2 run-instances \
  --region ap-southeast-1 \
  --instance-type u7i-8tb.112xlarge \
  --image-id ami-windows-sql-enterprise \
  --block-device-mappings '[
    {"DeviceName":"/dev/sda1","Ebs":{"VolumeSize":200,"VolumeType":"gp3"}},
    {"DeviceName":"xvdf","Ebs":{"VolumeSize":3000,"VolumeType":"io2","Iops":64000}}
  ]'
8 TiB のメモリにより SQL Server のインメモリ OLTP とカラムストアインデックスを大規模なデータセットに適用でき、BI クエリの応答時間が大幅に短縮

メリット・デメリット

ビジネス面のメリット

ASEAN 各国のデータレジデンシー要件を満たしながら大規模インメモリ DB を運用可能
東南アジア全域のエンドユーザーに近い場所でワークロードを実行し、応答性が向上
アジアパシフィック地域内の複数リージョンにまたがるディザスタリカバリ戦略を構築可能

技術面のメリット

DDR5 メモリにより大規模インメモリ DB の読み書き性能が向上
100 Gbps の EBS / ネットワーク帯域幅でストレージとネットワークのボトルネックを解消
ENA Express サポートにより DB クラスタ間のレプリケーション性能が向上

制限事項

シンガポールリージョンのみの追加。他のアジアパシフィックリージョンは別途アナウンス
ベアメタルに近い大規模インスタンスであり、小規模ワークロードにはコスト効率が低い
Dedicated Hosts またはオンデマンドとしての利用が必要。スポットインスタンスは利用不可の可能性

考慮すべき点

大量の vCPU を使用するため、事前にサービスクォータの引き上げリクエストが必要になる場合あり
インスタンスの起動に時間がかかる場合があり、Capacity Reservations の利用を検討
SAP HANA 等の認定ワークロードでは AWS 認定の AMI と OS の組み合わせが必要

料金

U7i インスタンスの料金は、インスタンスタイプ、リージョン、および利用形態によって異なります。High Memory インスタンスは大規模なリソースを提供するため、料金も相応に高額です。

オンデマンド 使用した分だけ支払い。初期費用やコミットメント不要
リザーブドインスタンス 1 年または 3 年のコミットメントで大幅な割引が適用
Savings Plans コンピューティング使用量に対する柔軟なコミットメントベースの割引

詳細については Amazon EC2 料金ページ を参照してください。
