提供リージョン拡大 🌏

ネットワーク最適化
第 6 世代インスタンス

📌 概要

ネットワーク最適化された第 6 世代インスタンス Amazon EC2 M6in / M6idn が、 新たに アジアパシフィック (ハイデラバード) と 南米 (サンパウロ) の 2 リージョンで提供開始されました。

M6in / M6idn は、第 3 世代 Intel Xeon Scalable プロセッサと AWS Nitro System 上に構築され、 最大 200Gbps のネットワーク帯域幅 (同等の第 5 世代の 2 倍) を提供します。 高性能ファイルシステム、分散インメモリキャッシュ、リアルタイムビッグデータ分析、5G UPF などの通信事業者向けアプリケーションといった、 ネットワーク負荷の高いワークロードが対象です。M6idn はさらに最大 7.6 TB の低レイテンシーなローカル NVMe SSD を備えます。

❌ アップデート前の課題
  • ハイデラバード / サンパウロで M6in / M6idn を直接利用できなかった
  • 他のインスタンスファミリーで代替、または他リージョンへのデプロイが必要だった
  • データレジデンシーやレイテンシー要件のあるワークロードで選択肢が限られていた
➡
✅ アップデート後の改善
  • 両リージョンで M6in / M6idn を直接利用可能に
  • 最大 200Gbps の帯域幅を対象リージョン内で低レイテンシーに活用
  • データレジデンシー要件を満たしつつネットワーク最適化性能を活用可能

ネットワーク最適化された M6in / M6idn が新規 2 リージョンで利用可能となり、ネットワーク負荷の高いワークロードを対象リージョン内で実行できることを示しています。

⚡ 主要機能

1提供リージョンの拡大
  • アジアパシフィック (ハイデラバード) で新たに利用可能
  • 南米 (サンパウロ) で新たに利用可能
  • 対象ワークロードをより多くのリージョンでネイティブに実行可能に
2高いネットワーク性能
  • 最大 200Gbps のネットワーク帯域幅を提供
  • 同等の第 5 世代インスタンス比で 2 倍の帯域幅
  • 32xlarge および metal サイズで Elastic Fabric Adapter (EFA) をサポート
3M6idn の高速ローカルストレージ
  • 最大 7.6 TB の高速・低レイテンシーなローカル NVMe SSD を搭載
  • 一時データ、キャッシュ、スクラッチ領域を必要とするワークロードに最適

💡 メリット

📈 ビジネス面

  • データレジデンシー対応: リージョン内でワークロードを実行でき、データ所在地要件を満たしやすい
  • 柔軟なコスト最適化: Savings Plans / オンデマンド / スポットの各購入オプションを利用可能
  • 地域ユーザーへの近接: エンドユーザーに近いリージョンでレイテンシー低減とUX向上

⚙️ 技術面

  • 高いネットワークスループット: 最大 200Gbps でネットワーク負荷の高いワークロードの性能が向上
  • 高速ストレージ (M6idn): 最大 7.6 TB のローカル NVMe SSD で低レイテンシーアクセス
  • HPC 向けネットワーキング: 32xlarge / metal の EFA サポートで密結合 HPC にも対応

⚠️ デメリット・制約事項

制限事項

▲今回の提供対象はハイデラバードとサンパウロの 2 リージョン。その他は全リージョン一覧の確認が必要
▲M6idn のローカル NVMe SSD は一時ストレージ。インスタンスの停止・終了時にデータが失われる
▲EFA のサポートは 32xlarge および metal サイズに限定される

考慮すべき点

✓永続化が必要なデータは Amazon EBS や Amazon S3 など別途の永続ストレージに保存
✓ワークロードのネットワーク・ストレージ要件を評価し、M6in と M6idn のいずれが適切か検討
✓リージョンごとに料金やサイズの可用性が異なる場合があるため、料金ページで最新情報を確認

🎯 ユースケース

1. 高性能ファイルシステム 📁

シナリオ: 大量の並列 I/O が発生する高性能ファイルシステム (Lustre など) を、南米ユーザーに近いサンパウロで運用したい。

効果: 最大 200Gbps の帯域幅でノード間の高速データ転送を実現し、ファイルシステム全体のスループットを向上。

2. 分散インメモリキャッシュ ⚡

シナリオ: ハイデラバードで、低レイテンシーが求められる分散インメモリキャッシュ (Redis / Memcached クラスターなど) を構築したい。

効果: 高い帯域幅と M6idn の高速ローカルストレージで、キャッシュノード間の通信とデータアクセスを高速化。

3. 通信事業者向けアプリケーション 📡

シナリオ: 5G User Plane Function (UPF) など、パケット処理性能とスループットが重要な Telco ワークロードを実行したい。

効果: 最大 200Gbps の帯域幅と EFA サポートにより、高いパケット処理性能を必要とするワークロードを効率的に実行。

💰 料金

M6in / M6idn は Savings Plans、オンデマンド、スポットインスタンス の各購入オプションで利用できます。 料金はインスタンスサイズおよびリージョンによって異なります。最新かつ正確な料金は Amazon EC2 の料金ページで確認してください。

📝 まとめ

今回のアップデートにより、ネットワーク最適化された Amazon EC2 M6in / M6idn が アジアパシフィック (ハイデラバード) と 南米 (サンパウロ) で利用可能になりました。 これらのリージョンでネットワーク負荷の高いワークロードを運用するユーザーは、 データレジデンシー要件を満たしつつ最大 200Gbps のネットワーク性能を活用できます。 対象リージョンでのワークロードについて、M6in / M6idn インスタンスへの移行や新規デプロイを検討することをおすすめします。
