Amazon MWAA

Apache Airflow 2.11.2 サポート開始

📅 リリース: 2026 年 7 月 24 日

📌 概要

Amazon Managed Workflows for Apache Airflow (MWAA) が、 Apache Airflow バージョン 2.11.2 のサポートを開始しました。 今回はセキュリティ改善、バグ修正、依存関係アップグレードを含むメンテナンスリリースです。

Web サーバーとタスク実行レイヤーの安定性向上、キュー登録タスクのライフサイクル管理の修正、 ログ内のシークレットマスキング強化、Task Instances 一覧ビューの UI 修正、 S3 / CloudWatch へのログ配信を担うプロバイダーパッケージの更新が含まれます。 新規環境の作成も既存環境のアップグレードも、AWS マネジメントコンソールから数クリックで実行できます。

😟 アップデート前の課題

  • 既知のバグやセキュリティ上の懸念が残存
  • キュー登録タスクのライフサイクル管理に不具合
  • ログ内のシークレットマスキングが一部不十分

😊 アップデート後の改善

  • コア依存関係にセキュリティパッチ適用、安定性向上
  • タスクのライフサイクル管理の不具合を修正
  • シークレットマスキング強化で露出リスク低減
  • S3 / CloudWatch 向けプロバイダーパッケージ更新

🚀 設定方法

前提条件

  • Amazon MWAA を利用可能な AWS アカウントを保有
  • DAG や依存関係を保存する Amazon S3 バケットを準備
  • 既存環境の場合、DAG・プラグイン・requirements の 2.11.2 互換性を事前確認
1

新規環境の作成

コンソールで新規環境を作成する際、Airflow バージョンとして 2.11.2 を選択。指定しない場合は最新のサポートバージョンで作成されます。

2

既存環境のアップグレード

既存環境を編集し Airflow バージョンを 2.11.2 に変更。マイナーバージョンアップグレードをサポートしており数クリックで実行できます。事前に検証環境で互換性を確認することを推奨します。

3

動作確認

DAG の正常ロード、タスクの期待どおりの実行、CloudWatch / S3 へのログ配信が正常に行われることを確認します。

💡 2.7.2 以降のバージョンでは、requirements ファイルに --constraint 文が必須です。

✅ メリット

💼 ビジネス面

  • セキュリティリスク低減: パッチ + マスキング強化で機密情報の露出リスクを低減
  • 運用の安定性向上: Web / タスク実行レイヤーの改善でワークフローの信頼性向上
  • サポート期間の確保: 最新パッチでより長いサポート期間を確保

🛠️ 技術面

  • タスク管理の信頼性向上: 状態遷移がより確実に
  • ログ配信の改善: S3 / CloudWatch 向けパッケージ更新
  • UI の改善: Task Instances 一覧ビューの可視性向上

⚠️ デメリット・制約事項

制限事項

  • メジャーバージョンをまたぐアップグレード (例: 2.y.z → 3.y.z) はサポート対象外
  • ダウングレードはダウングレード時点でサポートされているバージョンに限られる
  • 2.7.2 以降では requirements ファイルに --constraint 文が必須

考慮すべき点

  • 本番適用前に検証環境で DAG やプラグインの互換性を確認することが望ましい
  • メンテナンスリリースであり、新機能追加ではなく安定性・セキュリティ改善が中心
  • サポート終了が近い場合は Health Dashboard の通知を確認し早期アップグレードを検討

🎯 ユースケース

1. セキュリティ要件が厳しい環境でのログ管理

シナリオ金融機関などで、DAG のログに接続情報などの機密情報が含まれる可能性がある環境を運用。

効果強化されたシークレットマスキングで機密情報の意図しない露出リスクを低減し、コンプライアンス対応が容易に。

2. 大量のタスクを処理するデータパイプライン

シナリオ多数のタスクを並列実行する ETL パイプラインで、キュー登録タスクの状態管理に課題。

効果ライフサイクル管理の修正で状態遷移がより確実になり、パイプラインの信頼性が向上。

3. S3 および CloudWatch を活用したログ集約

シナリオDAG の実行ログを S3 と CloudWatch Logs に配信して一元管理。

効果更新されたプロバイダーパッケージでログ配信が改善され、可観測性が向上。

💰 料金・利用可能リージョン

💵 料金

今回のアップデート自体による追加料金は発生しません。 MWAA の料金は、環境クラス (mw1.small / medium / large など)、 追加ワーカー・スケジューラーのインスタンス時間、 メタデータベースのストレージ使用量に基づきます。

🌐 利用可能リージョン

現在 Amazon MWAA が利用可能なすべてのリージョンで、 Apache Airflow 2.11.2 を利用できます。

📝 まとめ

Apache Airflow 2.11.2 のサポート開始は、セキュリティ・安定性・ログ管理の改善を中心としたメンテナンスリリースです。 既存環境のお客様は検証環境で互換性を確認したうえで早期のアップグレードを検討することを推奨します。 新規環境では最新パッチである 2.11.2 を選択することで、より長いサポート期間とセキュリティ上の利点を得られます。
