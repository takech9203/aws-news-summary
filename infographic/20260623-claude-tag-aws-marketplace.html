🤖 Claude Tag

Anthropic Claude Enterprise — チームのチャネルに Claude を直接組み込む新機能
リリース日
2026.06.23

📌 概要

Anthropic は、チームが普段利用しているコミュニケーションチャネルに Claude を直接組み込む新機能 「Claude Tag」をベータ版として発表しました。第一弾として Slack に対応しており、AWS Marketplace を通じて Claude Enterprise を 利用している AWS のお客様は、本日からベータ版を利用できます。

選択したチャネルへのアクセスを Claude に付与し、任意のツール・データ・コードベースに接続できます。 マルチプレイヤー対応のため、チャネル内の誰もが @Claude をタグ付けしてタスクを委任でき、その間ユーザーは別の作業に集中できます。 Claude はチャネルから関連情報を記憶してコンテキストを構築し、将来実行するタスクを計画することも可能です。

セキュリティとガバナンスの観点では、Claude Tag は独自のアイデンティティで動作し、チャネルごとにスコープが設定されます。 支出管理機能を備え、アンビエントモードはデフォルトでオフです。AWS Marketplace 経由のお客様の体験は ファーストパーティの Claude Enterprise と完全に同一です。

😣 アップデート前の課題
  • 専用インターフェースに移動が必要で、作業チャネルから離れる必要があった
  • タスク委任時にチャネルのコンテキストや過去のやり取りを引き継ぎにくかった
  • AI エージェントの権限範囲や支出をチャネル単位で細かく制御する仕組みが不足していた
🎉 アップデート後の改善
  • Slack 上で @Claude をタグ付けするだけでワークフロー内から直接タスクを委任できる
  • チャネルから関連情報を記憶してコンテキストを構築し、将来のタスクを計画できる
  • チャネル別スコープの独自アイデンティティ・支出管理・組織全体の予算可視化が可能に

⚙️ 設定方法

前提条件

  • AWS Marketplace を通じた Claude Enterprise の利用権を保有していること
  • Claude 管理コンソールへの管理者アクセス権を持っていること
  • 統合対象となる Slack ワークスペースおよびチャネルが存在すること

手順

既存の利用権の確認

AWS Marketplace で取得済みの Claude Enterprise on AWS の利用権を使用します。Claude Tag のための新たな購入は不要です。利用体験はファーストパーティと同一です。

エージェントアイデンティティのプロビジョニング

管理者が Claude 管理コンソールでエージェントアイデンティティをプロビジョニングします。この作業には約 1 時間を要します。

チャネルごとのスコープ設定

チャネル単位で権限と支出を制御します。アンビエントモードはデフォルトでオフのため、必要に応じて有効化します。設定後、メンバーは @Claude をタグ付けしてタスクを委任できます。

✅ メリット

💼 ビジネス面

  • 既存の作業環境での利用: 普段の Slack 内で完結し、ツール切り替えによる生産性低下を抑制
  • ヘッドカウントに依存しない料金: 消費ベースで実際の使用量に基づき課金
  • 予算の可視化と統制: 組織全体の予算可視化とチャネル別上限でコストを統制

🛠️ 技術面

  • 完全な機能パリティ: ファーストパーティと同一のセットアップ・機能・コントロール
  • コンテキストの自動構築: チャネルの関連情報を記憶しタスク計画に活用
  • きめ細かいガバナンス: 独自アイデンティティとチャネル別スコープで権限範囲を制御

⚠️ デメリット・制約事項

🚧 制限事項

  • 現時点ではベータ版での提供
  • 対応チャネルは Slack のみ (第一弾)
  • AWS Marketplace 経由の既存 Claude Enterprise 利用権が必要

🧐 考慮すべき点

  • エージェントアイデンティティのプロビジョニングに約 1 時間を要する
  • アンビエントモードはデフォルトオフのため利用シーンに応じた設定検討が必要
  • 消費ベース料金のため上限設定・予算可視化を活用した使用量管理が望ましい

🎯 ユースケース

1. 開発チームのタスク委任

シナリオ: 開発チームの Slack チャネルで、コードレビューや調査タスクを Claude に委任したい。

Slack#dev-team チャネル
@Claude このプルリクエストの変更点をレビューして、
潜在的な問題点をまとめてください

効果: 誰もが Claude にタスクを委任でき、メンバーは他の作業に集中しながら結果を受け取れる。

2. 部門横断のナレッジ共有

シナリオ: サポートチームのチャネルで、過去のやり取りを踏まえた問い合わせ対応の下書きを作成したい。

Slack#support チャネル
@Claude このお客様の過去のやり取りを踏まえて、
返信の下書きを作成してください

効果: Claude がチャネルから関連情報を記憶してコンテキストを構築し、文脈に沿った対応が可能になる。

3. ガバナンスを重視した AI 導入

シナリオ: セキュリティチームが、チャネルごとに権限と支出を厳格に制御しながら AI エージェントを導入したい。

ConsoleClaude 管理コンソール
- エージェントアイデンティティをプロビジョニング
- チャネルごとにスコープを設定
- チャネル別の支出上限を設定し、アンビエントモードはオフのまま運用

効果: 独自アイデンティティとチャネル別スコープにより、組織全体の予算を可視化しつつ統制された形で AI を展開できる。

💰 料金と提供範囲

消費ベース人数ではなく使用量で課金

組織全体予算の可視化が可能

💰 料金

Claude Tag は消費ベースの料金体系を採用しており、ヘッドカウント (人数) ではなく 実際の使用量に基づいて課金されます。組織全体の予算可視化とチャネル別の上限設定が可能です。お客様は既存の Claude Enterprise on AWS の利用権を使用します。具体的な料金は、AWS Marketplace の Claude Enterprise 出品ページおよび Anthropic の公式情報を確認してください。

🌍 利用可能リージョン

AWS Marketplace を通じて Claude Enterprise を利用している AWS のお客様が対象です。詳細な提供範囲については、 AWS Marketplace の出品ページを確認してください。

🔗 関連サービス・機能

  • AWS Marketplace: Claude Enterprise の利用権を取得・管理する基盤。Claude Tag は既存の利用権を使用する
  • Claude Enterprise: Claude Tag の基盤となるエンタープライズ向け製品。AWS Marketplace 経由でもファーストパーティと同一の機能を提供する
  • Slack: Claude Tag が第一弾として統合するコミュニケーションチャネル

📝 まとめ

Claude Tag は、チームが普段利用している Slack 内に Claude を直接組み込み、マルチプレイヤーでのタスク委任と コンテキスト構築を可能にする新機能です。AWS Marketplace 経由のお客様は、既存の利用権を使って ファーストパーティと同一の体験を得られます。独自アイデンティティ、 チャネル別スコープ、消費ベースの料金により、 ガバナンスとコスト統制を両立できる点が大きな価値です。まずはベータ版を対象チャネルで試し、 エージェントアイデンティティのプロビジョニングと支出管理の設定を検討することをお勧めします。
