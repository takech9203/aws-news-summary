Amazon Quick

👥 マルチアカウントサインイン

同一ブラウザで最大 5 アカウントに同時アクセス -- 環境切り替えの手間を解消
2026 年 4 月 16 日

📋 概要

Amazon Quick にマルチセッションサポートが追加され、同一ブラウザ内で最大 5 つの Amazon Quick アカウントに同時にサインインできるようになった。開発、テスト、本番などの異なる環境用に複数のアカウントを使用しているユーザーが、ブラウザを切り替えることなく効率的にリソースを管理できる。

すべての URL に Amazon Quick アカウント名が含まれるようになり、エージェント、スペース、フロー、リサーチレポート、ダッシュボードなどのアセットを開く際に、正しいアカウントへ容易にアクセスできる。グローバル URL にアクセスした場合は、ログイン済みアカウントが事前入力されたアカウント選択ページが表示される。

この機能は、Amazon Quick がサポートされているすべてのリージョンで利用可能。複数アカウントを日常的に運用する組織にとって、業務効率を大幅に向上させるアップデートとなる。

  • ✖ URL からアクセス先アカウントの判別が困難
  • ✖ 環境比較に複数ブラウザウィンドウの並行操作が必要

⭐ 主要機能

🔑 マルチセッションサポート
  • → 同一ブラウザ内で最大 5 つのアカウントに同時サインイン
  • → 各アカウントのセッションは独立して管理
  • → ブラウザのタブごとに異なるアカウントのリソースにアクセス可能
🔗 URL ベースのアカウント識別
  • → すべての URL にアカウント名が含まれる
  • → エージェント、スペース、フロー、レポート、ダッシュボードが対象
  • → URL 共有時にアカウントを明確に識別可能
📋 アカウント選択ページ
  • → グローバル URL アクセス時に表示
  • → ログイン済みアカウントが事前入力
  • → ワンクリックで目的のアカウントを選択
⚙️ 柔軟なセッション管理
  • → 右上メニューから追加サインインが可能
  • → 特定タブのセッションのみログアウト可能
  • → 全セッション一括ログアウトにも対応

🛠️ 設定方法

前提条件

  • ✔️ Amazon Quick アカウントが複数作成済みであること
  • ✔️ 各アカウントへのサインイン認証情報を保持していること
  • ✔️ サポートされている Web ブラウザを使用していること

手順

1

最初のアカウントにサインイン

Amazon Quick のサインインページにアクセスし、最初のアカウントの認証情報を使用してサインインする。

2

追加アカウントにサインイン

右上メニューをクリックし、「別のアカウントにサインイン」を選択。追加アカウントの認証情報を入力してサインインする。新しいブラウザタブが開き、追加アカウントのセッションが確立される。

3

アカウント間の切り替え

URL にアカウント名が含まれるため、ブラウザのタブを切り替えるだけで異なるアカウントのリソースにアクセス可能。グローバル URL を使用する場合は、アカウント選択ページから選択する。

4

セッションのログアウト

個別ログアウトは特定のタブで右上メニューから「このセッションをログアウト」を選択。一括ログアウトは「すべてのセッションをログアウト」を選択する。

📈 メリット

💼 業務効率の向上

ブラウザやウィンドウの切り替えが不要になり、複数環境間のリソース確認・比較作業の時間を大幅に削減。

🛡️ 運用ミスの低減

URL にアカウント名が含まれることで、誤ったアカウントでの操作リスクが軽減。

⚡ トラブルシューティングの迅速化

開発、テスト、本番環境のリソース構成やインサイトを同一ブラウザ内で並行比較可能。

🔒 セッション分離

各アカウントのセッションが独立して管理され、セキュリティを維持。個別・一括のログアウトを使い分け可能。

⚠️ 制限事項・注意点

🚫 制限事項

  • • 同時サインインは最大 5 アカウントまで
  • • ブラウザのセッションストレージ / クッキーに依存
  • • シークレットモードでの挙動は通常と異なる可能性あり

📝 考慮すべき点

  • • 多数のタブを開いた場合のメモリ使用量に注意
  • • セキュリティポリシーにより同一端末での複数アクセスが制限される場合あり
  • • 共有端末使用時は全セッションのログアウトを忘れないよう注意

💰 料金

🎉 追加料金なし

マルチアカウントサインイン機能自体に追加料金は発生しない。各アカウントの利用料金は、既存の Amazon Quick の料金体系に基づいて個別に課金される。
