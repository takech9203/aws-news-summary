🚀 Claude Haiku 5.5 が AWS GovCloud (US) の Kiro で利用可能に

📅 リリース日: 2026 年 11 月 2 日 ｜ サービス: Kiro ｜ 機能: Claude Haiku 5.5 のモデル追加

📝 概要

AWS が提供する AI 搭載 IDE である Kiro において、AWS GovCloud (US) リージョンで Anthropic の Claude Haiku 5.5 が利用可能になりました。 これにより Claude 5.5 ファミリーの 3 モデル (Opus 5.5、Sonnet 5.5、Haiku 5.5) がすべて出揃い、 政府機関や規制の厳しい業界のユーザーが、コンプライアンス要件を満たした環境でタスクに応じたモデルの使い分けを実現できます。

❌ アップデート前の課題

✗GovCloud の Kiro では Opus 5.5 と Sonnet 5.5 のみ利用可能で、軽量・高速な Haiku 5.5 を選択できなかった
✗要約・分類・一括処理などの単純で大量のタスクにも、倍率の高い上位モデル (Sonnet 5.5 は 1.3 倍、Opus 5.5 は 2.0 倍) を使う必要があった
✗上位モデルと並行して動く低コストなレビュー用サブエージェント構成を Claude 5.5 ファミリーで組めなかった

✅ アップデート後の改善

✓GovCloud の Kiro IDE と CLI で Claude 5.5 ファミリーの 3 モデルすべてを選択可能に
✓大量処理タスクを 0.06 倍という低いクレジット倍率で高速に実行可能に
✓Opus 5.5 / Sonnet 5.5 が計画・コーディング、Haiku 5.5 が並列レビューを担う役割分担が可能に
✓5 段階のアダプティブシンキングでタスクに応じた思考量の調整が可能に
