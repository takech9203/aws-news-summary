📋 概要

Amazon EC2 G6 インスタンスが SageMaker ノートブックインスタンスにおいて、Asia Pacific (Tokyo, Mumbai, Sydney) および Europe (London, Paris, Frankfurt, Stockholm, Zurich) の 8 リージョンで一般利用可能 (GA) になりました。

G6 インスタンスは最大 8 基の NVIDIA L4 Tensor Core GPU (各 GPU あたり 24 GB メモリ) と第 3 世代 AMD EPYC プロセッサを搭載し、EC2 G4dn インスタンスと比較して深層学習推論で 2 倍のパフォーマンスを提供します。

東京リージョン対応: ap-northeast-1 での利用が可能になり、日本のデータレジデンシー要件を満たしながら高性能な GPU アクセラレーテッドコンピューティングを活用できるようになりました。

  • 第 4 世代 Tensor Core によるディープラーニング推論の高速化
  • 第 3 世代 RT Core によるグラフィックスワークロードのサポート

⚡ G4dn 比 2 倍の推論パフォーマンス

  • TensorRT, CUDA, cuDNN などの NVIDIA ライブラリとの互換性
  • FP8, INT8, FP16, FP32, TF32 など多様な精度をサポート

前提条件

  • 対象リージョンで有効な AWS アカウント

aws service-quotas get-service-quota \
  --service-code sagemaker \
  --quota-code L-B87F5E30 \
  --region ap-northeast-1

ステップ 2: ノートブックインスタンスの作成

Bash G6 インスタンスでノートブック作成 
# G6 インスタンスを使用してノートブックインスタンスを作成
aws sagemaker create-notebook-instance \
  --notebook-instance-name "my-g6-notebook" \
  --instance-type ml.g6.xlarge \
  --role-arn arn:aws:iam::<account-id>:role/SageMakerExecutionRole \
  --volume-size-in-gb 50 \
  --region ap-northeast-1

Ada Lovelace アーキテクチャの第 4 世代 Tensor Core による FP8 推論サポート。AWS Nitro System による GPU パススルーモードでベアメタルに近いパフォーマンスを実現

⚠️ 制約事項・注意点

制限事項:
  • SageMaker ノートブックインスタンス (クラシック) での対応であり、SageMaker Studio ノートブックとは別サービス
  • リージョンによって利用可能な G6 インスタンスサイズが異なる可能性あり
  • 新規対応リージョンではデフォルトのサービスクォータが低く設定されている場合あり
考慮すべき点:
  • GPU インスタンスは CPU インスタンスと比較してコストが高いため、不要時は必ず停止
  • 単一インスタンスで動作するため、分散学習には SageMaker Training Job を検討
  • ライフサイクル設定スクリプトで自動停止を設定し、コスト超過を防止
  • 大規模モデルを扱う場合は EBS ボリュームサイズを十分に確保

💡 ユースケース

🗼 東京リージョンでの LLM 推論テスト

シナリオ: 日本の企業がオンプレミスのデータを活用して LLM の推論パフォーマンスを評価。データを海外リージョンに転送することはセキュリティポリシー上許可されていない。

効果: 東京リージョン内でデータを保持したまま、NVIDIA L4 GPU の高い推論性能を活用して日本語 LLM のパフォーマンス評価が可能。G4dn 比 2 倍の推論速度により、評価の反復サイクルを短縮。

Python ml.g6.2xlarge - LLM 推論テスト例 
# SageMaker ノートブックインスタンス (ml.g6.2xlarge) 上で実行
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# NVIDIA L4 GPU を活用した推論
model_name = "rinna/japanese-gpt-neox-3.6b"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(
    model_name,
    torch_dtype=torch.float16,
    device_map="auto"
)

# 推論実行
inputs = tokenizer("日本の機械学習の未来は", return_tensors="pt").to("cuda")
with torch.no_grad():
    outputs = model.generate(**inputs, max_new_tokens=100)
    print(tokenizer.decode(outputs[0]))

🤖 生成 AI モデルのプロトタイピング

シナリオ: インドのスタートアップが多言語対応のテキスト生成モデルをプロトタイピング。Mumbai リージョンで低レイテンシーの開発環境が必要。

効果: 4 基の NVIDIA L4 GPU (合計 96 GB GPU メモリ) を活用し、大規模モデルの量子化ロードと LoRA ファインチューニングを Mumbai リージョン内で実行可能。

Python ml.g6.12xlarge - 生成 AI プロトタイピング例 
# SageMaker ノートブックインスタンス (ml.g6.12xlarge) 上で実行
from transformers import AutoModelForCausalLM, AutoTokenizer, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model
import torch

# 4bit 量子化で大規模モデルをロード
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16
)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3-8B",
    quantization_config=bnb_config,
    device_map="auto"  # 4 GPU に自動分散
)

# LoRA によるパラメータ効率的ファインチューニング
lora_config = LoraConfig(
    r=16, lora_alpha=32,
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj"],
    lora_dropout=0.05
)
model = get_peft_model(model, lora_config)
