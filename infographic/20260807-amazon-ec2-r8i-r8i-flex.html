📌 概要

AWS 専用にカスタマイズされた Intel Xeon 6 プロセッサを搭載したメモリ最適化インスタンス R8i / R8i-flex が、新たに欧州 (ミラノ) リージョンで利用可能になりました。 同等の Intel ベースクラウドプロセッサの中で最高クラスのパフォーマンスとメモリ帯域幅を提供します。 R8i-flex は AWS 初のメモリ最適化 Flex インスタンスで、リソースを常時フル活用しないワークロードにコスト効率の高い選択肢を提供します。 イタリアおよび周辺地域でデータレジデンシー要件を持つお客様も、最新世代インスタンスを利用できるようになりました。

新規対応した欧州 (ミラノ) リージョンで、R8i / R8i-flex インスタンスがカスタム Intel Xeon 6 プロセッサと第 6 世代 Nitro Card を基盤として利用できることを示しています。

🚀 主要機能

🧠 カスタム Intel Xeon 6 プロセッサ

  • AWS 専用にカスタマイズされた Intel Xeon 6 プロセッサを搭載
  • 全コアターボ周波数は最大 3.9 GHz (前世代の 3.2 GHz から向上)
  • L3 キャッシュは前世代比で 4.6 倍に拡大
  • Intel AMX の FP16 データ型をサポートし、AI/ML ワークロードに対応

💪 R8i インスタンス

  • large から 96xlarge まで、ベアメタル 2 サイズを含む 13 サイズを提供
  • 新しい 96xlarge サイズは 384 vCPU、3,072 GiB メモリを提供
  • SAP 認定済みで、142,100 aSAPS はオンプレミスおよびクラウドの同等マシンの中で最高値
  • 大規模なサイズや継続的な高 CPU 使用率を必要とするワークロードに最適

💡 R8i-flex インスタンス

  • AWS 初のメモリ最適化 Flex インスタンス
  • large から 16xlarge までのサイズを提供
  • CPU パフォーマンスを 95% の時間で最大限まで引き出せる
  • すべてのコンピューティングリソースを常時フル活用しないワークロードに最適

🔧 第 6 世代 AWS Nitro Card

  • 前世代比で最大 2 倍のネットワークおよび EBS 帯域幅を提供
  • ネットワークと Amazon EBS 帯域幅の間で 25% 単位の割り当て調整が可能

💼 ビジネス面

✓コスト最適化: 前世代比で最大 15% 優れた価格性能比により、同一ワークロードの実行コストを削減
✓Flex によるコスト効率: R8i-flex は、リソースをフル活用しないワークロードにコスト効率の高い選択肢を提供
✓イタリアでのデータレジデンシー対応: 欧州 (ミラノ) リージョンで要件を満たしつつ最新世代インスタンスを利用可能

🔬 技術面

✓メモリ帯域幅の向上: 2.5 倍のメモリ帯域幅により、メモリ集約型ワークロードのパフォーマンスが向上
✓大規模スケール対応: 96xlarge (384 vCPU、3,072 GiB) により、大規模ワークロードを単一インスタンスで実行可能
✓SAP ワークロード対応: SAP 認定済み (142,100 aSAPS) で、ミッションクリティカルな SAP HANA などの運用に最適

⚠️ デメリット・制約事項

🚫 制限事項

✗R8i-flex はベアメタルサイズを提供していない
✗R8i-flex は 16xlarge が最大サイズであり、それ以上の規模には R8i が必要
✗継続的に高い CPU 使用率が求められるワークロードには R8i-flex は不向き

🤔 考慮すべき点

⚠ワークロードのリソース使用パターンに応じて、R8i と R8i-flex を適切に選択する必要がある
⚠リージョンによって提供されるインスタンスサイズが異なる場合があるため、利用前に確認が必要

🎯 ユースケース

1️⃣ 大規模インメモリデータベース

📖 シナリオ: SAP HANA や Redis などのインメモリデータベースを欧州 (ミラノ) リージョンで運用する場合

💡 効果: 2.5 倍のメモリ帯域幅と最大 3,072 GiB のメモリにより、大規模なインメモリデータセットを高速に処理できます

2️⃣ コスト効率重視のウェブスケールキャッシュ

📖 シナリオ: 常時フルにリソースを使わない分散キャッシュや中規模のインメモリ分析ワークロード

💡 効果: R8i-flex を使用することで、コスト効率を高めつつ、必要時には CPU パフォーマンスを最大限に引き出せます

3️⃣ ミッションクリティカルな SAP ワークロード

📖 シナリオ: SAP 認定インスタンスが必要な基幹業務システムをイタリア国内でホスティングする場合

💡 効果: 142,100 aSAPS の SAP 認定パフォーマンスと最大 96xlarge のサイズにより、大規模な SAP 環境を安定して運用できます
