📌 概要

Amazon MSK は、AI コーディングアシスタントに対して MSK 運用の専門的かつ最新のガイダンスを提供する AI Agent Skills を提供開始しました。トラブルシューティング、サイジング、構成、モニタリング、外部 Apache Kafka クラスターからの移行といった一般的な運用タスクの専門知識を、AI コーディングエージェントに付与します。

普段利用しているコーディングエージェントに「自分の MSK クラスターにはどのブローカータイプとサイズを使うべきか」「自分の Kafka クラスターは MSK Express と互換性があるか」と直接尋ねるだけで、段階的なガイドを得られます。追加料金なしで利用できます。

⚡ Kiro 🟣 Claude Code 🔷 Cursor

  • 基盤モデルの学習データは数か月〜数年前のもので、新機能の正確なガイダンスを得にくい
  • 外部 Kafka から MSK への移行は互換性確認や手順検討に手間がかかる
🎉 アップデート後の改善
  • 普段のコーディングエージェントに質問するだけで専門的かつ最新のガイダンスを取得
  • 一般的な運用タスクを段階的なガイドに従って進められる
  • 外部 Kafka の MSK Express 移行を互換性チェック込みでエージェント支援

  • クラスターを健全で高パフォーマンスな状態に保つ支援を対話形式で受けられる
  • 「どのブローカータイプとサイズを使うべきか」といった質問に応答

🔀 外部 Kafka クラスターからの移行支援

🧰 技術仕様: Agent Toolkit for AWS の構成要素

AI Agent Skills は、AI コーディングエージェントが AWS 上でアプリケーションを構築・デプロイ・管理するためのツール、知識、ガードレールを提供する Agent Toolkit for AWS の一部として提供されます。

構成要素詳細
AWS MCP ServerModel Context Protocol (MCP) を通じてエージェントに AWS へのアクセスを提供するマネージドサーバー。単一エンドポイントで CloudWatch メトリクスと IAM ベースのアクセス制御を提供
Agent skills特定の AWS タスク完了のための手順、コードスクリプト、参照資料をまとめたキュレーション済みパッケージ。オンデマンドで読み込まれる
PluginsClaude Code および Codex 向けの単一インストールパッケージ。AWS MCP Server 構成とスキルセットをバンドル
Rules filesプロジェクトレベルの設定ファイル。エージェントの動作に関するガードレールや設定を定義

🔐 認証とアクセス制御

AWS MCP Server は全リクエストに 2 つのグローバル条件コンテキストキー (aws:ViaAWSMCPService と aws:CalledViaAWSMCP) を自動付与します。これにより IAM ポリシーで MCP 経由のアクションと直接の API 呼び出しを区別できます。認証・認可には既存の AWS IAM ロールとポリシーが使用されます。

※ 今回のアップデートは Agent Toolkit for AWS を通じた AI Agent Skills の追加であり、Amazon MSK の API 自体への変更は伴いません。

✅ メリット

💼 ビジネス面

  • 専門知識への依存の低減: 運用・移行作業を開発者自身がエージェント支援で進められる
  • 追加料金なし: 操作する AWS リソースの標準料金のみ発生
  • 移行の促進: MSK Express 移行を後押しし高パフォーマンスとコスト効率を実現

🛠️ 技術面

  • 最新かつ正確なガイダンス: 学習データが古くても最新の MSK 情報に基づくガイダンス
  • 既存ワークフロー維持: ツール切り替え不要でそのまま利用
  • セキュリティと可視性: 既存 IAM で制御、CloudTrail で API 呼び出しを監査

⚠️ デメリット・制約事項

制限事項

  • MCP に対応した AI コーディングエージェント (Kiro、Claude Code、Cursor など) の利用が前提
  • 提供されるのはガイダンスであり、実際の運用判断や操作は利用者の責任

考慮すべき点

  • エージェントが AWS リソースを操作する場合は最小権限の原則で IAM ロールを必要最小限に絞る
  • 移行や構成変更を実行する前にエージェントの提案内容を検証する

💡 ユースケース

1. MSK クラスターのサイジング

シナリオ: 新規に MSK クラスターを構築するチームが、ワークロードに適したブローカータイプとサイズを判断できずにいる。

PROMPT
What broker type and size should I use for my MSK cluster?

効果: 適切なブローカータイプとサイズの選定を支援し、過剰プロビジョニングや性能不足を回避。

2. 外部 Kafka から MSK Express への移行

シナリオ: 自己管理の Apache Kafka クラスターを運用するチームが、MSK Express への移行を検討している。

PROMPT
Is my Kafka cluster compatible with MSK Express?

効果: 互換性チェックと移行手順のガイダンスにより、最大 3 倍のスループット、最大 20 倍高速なスケーリング、90% 短縮されたリカバリ時間を活用した移行を実現。

3. 運用中クラスターのトラブルシューティング

シナリオ: 本番運用中の MSK クラスターでパフォーマンス低下や異常が発生し、原因を切り分けたい。

PROMPT
Why is my MSK cluster experiencing high consumer lag?

効果: トラブルシューティングとモニタリングのスキルに基づき、原因の切り分けと対処をガイドし、クラスターを健全な状態に保つ。

💰 料金・利用可能リージョン

💰 料金

AI Agent Skills を含む Agent Toolkit for AWS は追加料金なしで利用できます。エージェントがプロビジョニング/操作する AWS リソースに対して標準の AWS 料金のみが発生します。

🌍 利用可能リージョン

AI Agent Skills は Agent Toolkit for AWS を通じて提供されます。Amazon MSK および MSK Express の利用可能リージョンは AWS 公式リージョン表を参照してください。

🔗 関連サービス・機能

  • Amazon MSK Express: 外部 Kafka 移行先のブローカータイプ。Standard と比較して高スループット・高速スケーリング・短いリカバリ時間
  • Agent Toolkit for AWS: AI Agent Skills の基盤。AWS MCP Server、スキル、プラグイン、ルールファイルで構成
  • Kiro / Claude Code / Cursor: MSK Agent Skills を利用できる AI コーディングエージェント

🎯 まとめ

今回のアップデートにより、MSK の運用や外部 Kafka からの移行といった専門知識を要する作業を、Kiro、Claude Code、Cursor の既存 AI コーディングエージェントを通じて段階的に進められるようになりました。追加料金なしで利用できるため、まずは Agent Toolkit for AWS を AWS CLI で構成し、MSK のサイジングや MSK Express への移行可否についてエージェントに質問してみることが推奨されます。
