📱 Kiro for Android の提供開始

リリース日: 2026 年 11 月 12 日 | Kiro for Android (Kiro Mobile)

📋 概要

Kiro for Android が Google Play で利用可能になりました。Android スマートフォンから Kiro の クラウドセッションにアクセスし、新しい作業の開始、進行中の作業の確認とステア (方向付け)、 変更内容のレビューまでを行えます。ラップトップの前に戻らなくても、移動中や外出先からエンジニアリング作業を前進させられることが最大の価値です。

クラウドセッションにより、同じ作業が Kiro CLI、Web、IDE、Android の間で共有されます。セッションはサーフェスを切り替えたり スマートフォンを置いたりしてもクラウドサンドボックス内で実行され続け、Android 上では 「実行中」「完了」「要対応」のセッションを一覧で確認できます。

クラウドセッションはクラウド上のサンドボックスで実行され続け、Android を含むすべての Kiro サーフェスから同じセッションにアクセスできます。 セッションはリポジトリのコードを操作し、最終的に PR を作成します。

⚡ 主要機能

🔄 1. サーフェスをまたぐ作業の継続 (クラウドセッション連携)
  • Kiro CLI、Web、IDE、Android の間で同じ作業 (会話履歴・セッション履歴) を共有
  • Android でクラウドセッションを開くと会話とセッション履歴がそのまま引き継がれる
  • Android で開始した作業を後から別のサーフェスで再開可能
  • 同期済みの Kiro 設定 (モデル設定など) はクラウドセッションでも利用される
  • サーフェス切り替えやスマートフォンを置いた後もクラウドサンドボックスで実行を継続
  • 「実行中」「完了」「要対応」のセッション状態を Android 上で一覧確認
🚀 2. スマートフォンからの新規セッション開始
  • Android から新しいセッションを開始し、リポジトリを接続して構築・修正・調査を指示
  • スクリーンショットを添付して意図を伝えることが可能
  • Kiro はコードの調査、ツールの使用、変更の実施、テストの実行をクラウド上で継続
🧭 3. 作業のブロック解除 (ステア)
  • ブランチ選択、実装詳細の確認、方針転換などの判断が必要になると通知
  • Android からセッションを開き、質問への回答やコンテキストの追加で作業を継続させられる
🔍 4. スマートフォンからのレビューと出荷
  • 変更が完成したら diff をスマートフォン上で直接確認
  • ファイル編集はモバイルフレンドリーなカードとして表示され、ファイル単位でレビュー可能
  • 修正が必要な場合は Kiro に差し戻して再作業を指示
  • 問題がなければ Kiro が PR を作成し、PR ステータスをセッションと合わせて表示

🛠️ 設定方法

前提条件

✓有料の Kiro プラン (Pro、Pro+、Pro Max、Power など) を契約していること
✓Kiro CLI、Web、IDE で使用しているサインイン用アイデンティティを保有していること
✓IAM Identity Center 利用のエンタープライズ組織では、管理者によってクラウドセッションが有効化されていること

手順

1
アプリのインストール
Google Play から「Kiro」アプリ (dev.kiro.mobile) をダウンロードしてインストールします。
https://play.google.com/store/apps/details?id=dev.kiro.mobile
2
サインイン
Kiro CLI、Web、IDE と同じアイデンティティでサインインします。クラウドセッション、接続済みリポジトリ、モデル設定、同期済み設定が自動的に引き継がれます。
3
セッションの開始または再開
新規セッションではリポジトリを接続し、構築・修正・調査したい内容をプロンプトで指示します。必要に応じてスクリーンショットを添付できます。既存のクラウドセッションは一覧から開いて会話を継続します。

💡 メリット

📈 ビジネス面

✓リードタイムの短縮: アイデアの発生から作業開始までの時間を短縮し、デスクに戻る前に調査や修正を進められる
✓作業のブロック解消: セッションが判断待ちで停止する時間を最小化し、エンジニアリング作業全体のスループットを向上できる
✓場所にとらわれない開発体制: 通勤中や外出先でもレビューと PR 作成まで完結でき、チームの対応速度が向上する

⚙️ 技術面

✓マルチサーフェス対応: CLI、Web、IDE、Android で同一のクラウドセッションと設定を共有し、一貫した作業体験を実現
✓クラウドサンドボックスでの継続実行: スマートフォンを閉じてもセッションは実行を継続し、テスト実行まで自動で進行
✓モバイル最適化されたレビュー体験: diff がカードとして表示され、小さな画面でもファイル単位のレビューが可能

⚠️ デメリット・制約事項

制限事項

✗有料プランが必要であり、無料プランでは Kiro for Android を利用できない
✗クラウドセッションは現時点で us-east-1 (バージニア北部) でのみ提供される
✗IAM Identity Center 利用組織では、管理者がクラウドセッションを有効化するまでアクセスできない
✗iOS 版はプレビュー段階であり、一般提供はされていない

考慮すべき点

💭 クラウドセッションはクラウド上のサンドボックスでコードを扱うため、組織のセキュリティポリシーやデータ所在地の要件を事前に確認する必要があります。
💭 スマートフォンでのレビューは手軽である一方、大規模な変更の精査にはデスクトップ環境との併用が現実的です。

💡 ユースケース 1: 外出先でのアイデアの即時着手

シナリオ: 移動中に新機能のアイデアを思いついた開発者が、デスクに戻る前に実装を開始したい。

Text実装例
1. Android の Kiro アプリで新規セッションを開始
2. 対象リポジトリを接続
3. 「リクエスト ID の検証・生成ロジックを /myapp/common に移動し、
   ゲートウェイを共有実装に更新して」と指示
4. Kiro がクラウド上でコード調査、変更、テスト実行を継続
✅ 効果: デスクに戻った時点で変更とテストが完了しており、レビューから着手できる。
🔓 ユースケース 2: 判断待ちセッションのブロック解除

シナリオ: クラウドセッションが実装方針の確認を必要として停止しているが、担当者は外出中である。

Text実装例
1. Android アプリで「要対応」状態のセッションを確認
2. セッションを開き、Kiro からの質問 (ブランチ選択や実装詳細) に回答
3. 必要に応じて追加のコンテキストを提供
4. Kiro が回答を受けて作業を再開
✅ 効果: ラップトップに戻るまで作業が停止することがなくなり、セッションの待ち時間を最小化できる。
🔀 ユースケース 3: スマートフォンからのレビューと PR 作成

シナリオ: 通勤中に、完了したセッションの変更内容をレビューして PR を作成したい。

Text実装例
1. Android アプリで完了済みセッションを開く
2. モバイルフレンドリーなカード表示でファイルごとの diff をレビュー
3. 修正が必要なら Kiro に差し戻して再作業を指示
4. 問題なければ Kiro に PR の作成を指示し、PR ステータスをセッション上で確認
✅ 効果: レビューから PR 作成までをスマートフォンで完結でき、変更の出荷サイクルが加速する。

📝 まとめ

Kiro for Android の提供開始により、クラウドセッションを使ったエンジニアリング作業を Android スマートフォンから 開始・ステア・レビューできるようになり、デスクを離れている時間が作業のブロック要因ではなくなりました。 有料プランを利用中のユーザーは Google Play からアプリをインストールし、既存のアイデンティティでサインインするだけで利用を開始できます。 IAM Identity Center を利用する組織では、管理者によるクラウドセッションの有効化を事前に確認することを推奨します。
