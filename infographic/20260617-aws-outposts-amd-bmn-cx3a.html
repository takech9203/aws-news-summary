AWS Outposts

⚙️ bmn-cx3a インスタンス対応

アクセラレーテッドネットワーキング対応の AMD ベースインスタンス
📅 2026 年 6 月 17 日

📌 概要

AWS は、第 2 世代 AWS Outposts ラックにおける bmn-cx3a インスタンスの提供を発表しました。bmn-cx3a は、Outposts 上で初めてアクセラレーテッドネットワーキングに対応した AMD ベースのインスタンスです。第 5 世代 AMD EPYC プロセッサ (最大 4.1 GHz) と NVIDIA ConnectX-7 (CX7) NIC を搭載し、ほぼラインレートで動作する最大 800 Gbps のベアメタルアクセラレーテッドネットワーク帯域幅を提供します。

ネイティブのレイヤー 2 (L2) マルチキャストとハードウェア Precision Time Protocol (PTP) をサポートし、リアルタイム市場データの取り込み・配信、市場/リスク分析、通信業界の 5G コアネットワーク、メディア配信といった高スループットワークロード向けに設計されています。金融サービス、通信、メディア業界のお客様が、低レイテンシかつ高帯域なベアメタル性能をデータの所在地で実現できます。

🔄 Before / After

❌ アップデート前の課題
  • Outposts ラックでアクセラレーテッドネットワーキング対応の AMD ベースインスタンスを利用できなかった
  • Outposts 上で 800 Gbps クラスのベアメタル帯域を要する高スループットワークロードの実行が難しかった
  • ネイティブ L2 マルチキャストやハードウェア PTP を要するワークロードの選択肢が限られていた
✅ アップデート後の改善
  • 第 2 世代 Outposts ラックで AMD EPYC ベースのベアメタルインスタンスを利用可能に
  • Outposts 上で最大 800 Gbps のアクセラレーテッドネットワークを要するワークロードを実行可能に
  • L2 マルチキャストとハードウェア PTP を要する金融・通信・メディア系ワークロードをオンプレミスで実行しやすく

bmn-cx3a インスタンスはオンプレミスの第 2 世代 Outposts ラック上で動作し、CX7 NIC による高帯域ネットワークでデータ所在地に近い場所で高スループットワークロードを処理します。

🚀 主要機能

🔧 AMD EPYC ベースのベアメタルインスタンス

  • 第 5 世代 AMD EPYC プロセッサを搭載し、最大 4.1 GHz で動作
  • Outposts 上で初めての AMD ベースかつアクセラレーテッドネットワーキング対応インスタンス
  • 最大 256 コア、1.5 TB のメモリを提供

⚡ アクセラレーテッドネットワーキング

  • NVIDIA ConnectX-7 (CX7) ネットワークインターフェイスカードを搭載
  • ほぼラインレートで動作する最大 800 Gbps のベアメタルネットワーク帯域幅
  • ネイティブ L2 マルチキャストとハードウェア PTP をサポート

📐 2 つのインスタンスサイズ

  • bmn-cx3a.metal-32xl と bmn-cx3a.metal-64xl の 2 サイズを提供
  • いずれも 2 基の 8 TB NVMe SSD ストレージを備える

🛠️ 設定方法

前提条件

✓第 2 世代 AWS Outposts ラックが利用可能なリージョン・国/地域であること
✓第 2 世代 Outposts ラックの注文と設置が完了していること
✓該当する Outposts に bmn-cx3a 用のキャパシティが割り当てられていること

1Outposts のキャパシティ構成を確認する

Bash利用可能なインスタンスタイプ確認
aws outposts get-outpost-instance-types --outpost-id op-xxxxxxxxxxxxxxxxx

指定した Outpost で利用可能なインスタンスタイプを確認し、bmn-cx3a が含まれているかを確認します。

2bmn-cx3a インスタンスを起動する

Bashインスタンス起動
aws ec2 run-instances \
  --instance-type bmn-cx3a.metal-32xl \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --placement "AvailabilityZone=ap-northeast-1a"

Outposts に紐づくサブネット上で bmn-cx3a を起動します。ワークロードに応じて metal-32xl または metal-64xl を指定します。

3高スループットワークロードの構成

L2 マルチキャストやハードウェア PTP を利用する場合は、各ワークロード (市場データ配信、5G コア、メディア配信など) の要件に合わせてネットワークと時刻同期を構成します。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓データ所在地要件への対応: オンプレミスでデータを保持しつつ高性能ベアメタル処理を実現
✓対象業界の拡大: 金融・通信・メディアの低レイテンシ/高帯域ワークロードを Outposts で実行
✓運用の一貫性: クラウドと同じ AWS 運用モデルでオンプレミスを管理

🔧 技術面のメリット

✓高帯域ネットワーク: 最大 800 Gbps のアクセラレーテッドネットワーク
✓大規模コンピュート: 最大 256 コア、1.5 TB メモリのベアメタル性能
✓特殊ネットワーク機能: L2 マルチキャストとハードウェア PTP に対応

⚠️ 制限事項・考慮点

!第 2 世代 Outposts ラックがサポートされる国/地域でのみ利用可能
!提供サイズは metal-32xl と metal-64xl の 2 種類に限られる
!ベアメタルインスタンスのため、利用にはキャパシティの事前確保が前提
!800 Gbps を活かすにはオンプレミス側のネットワーク設計も合わせて検討が必要
!PTP や L2 マルチキャストを利用する場合は、対応するアプリケーション側の設定が必要

🎯 ユースケース

1. リアルタイム市場データの取り込みと配信

シナリオ: 金融機関が取引所に近いデータセンターで、低レイテンシかつ高帯域な市場データの取り込み・配信を行いたい
bmn-cx3a.metal-64xl + L2 マルチキャスト + ハードウェア PTP
効果: ほぼラインレートの 800 Gbps と正確な時刻同期により、リアルタイム性の高い市場データ処理を実現

2. 通信業界の 5G コアネットワーク

シナリオ: 通信事業者が 5G コアネットワークアプリケーションをオンプレミスで運用しつつ、AWS の運用モデルを利用したい
bmn-cx3a.metal-32xl + CX7 NIC によるアクセラレーテッドネットワーキング
効果: 高スループットなパケット処理をベアメタル性能で実行し、データ所在地要件を満たしながら 5G を運用

3. メディア配信

シナリオ: メディア企業が大容量コンテンツの配信処理を低レイテンシで行いたい
bmn-cx3a.metal-64xl + 2x 8 TB NVMe SSD
効果: 大容量メモリと高速ローカルストレージ、高帯域ネットワークで高スループットなメディア配信を実現

✨ まとめ

bmn-cx3a は、Outposts 上で初めてアクセラレーテッドネットワーキングに対応した AMD ベースのベアメタルインスタンスであり、最大 800 Gbps のネットワーク、256 コア、1.5 TB メモリ、L2 マルチキャストとハードウェア PTP をオンプレミスで提供します。

金融、通信、メディア業界で低レイテンシ・高帯域を要するワークロードを運用しているお客様は、第 2 世代 Outposts ラックでの本インスタンス活用を検討することをおすすめします。まずは対象リージョンと必要なキャパシティを確認し、要件に合わせたサイズを選定してください。
