Amazon WorkSpaces

🖥️ 新しい Windows クライアントエクスペリエンスWorkSpaces Advisor プレビュー

📅 リリース日: 2026 年 11 月 17 日 | 対象: Amazon WorkSpaces Personal (DCV ベース)

📝 概要

Amazon WorkSpaces Personal 向けに、刷新された Windows クライアントエクスペリエンスが提供開始されました。Windows クライアントバージョン 5.37 以降では、モダンな UI、簡素化された接続フロー、見つけやすい設定画面を備えた新エクスペリエンスがデフォルトになります。クラシックエクスペリエンスとの切り替えも可能で、選択は次回起動時にも記憶されます。

目玉は新機能 WorkSpaces Advisor (パブリックプレビュー) によるプロアクティブトラブルシューティング。デバイス・ネットワーク・WorkSpace の主要メトリクスを監視し、問題検知時にユーザー自身で実行できる対処方法を提案します。管理者やサポートに問い合わせる前に、一般的な問題を自己解決できるようになります。

😣 アップデート前の課題

  • 接続・サインイン問題の原因 (デバイス / ネットワーク / WorkSpace) の切り分けが難しく、管理者やサポートへの問い合わせが必要
  • 設定項目やセッション中のツールが分散していて見つけにくい
  • エラーメッセージの情報が限られ、対処方法がわかりにくい
  • ネストされた仮想化の有効化には管理者側の操作が必要

😊 アップデート後の改善

  • WorkSpaces Advisor (プレビュー) が接続前・接続中・切断後を監視し、問題検知時にアラート表示と推奨アクションを提示
  • 統合ツールバーから設定・セッションツール・デバイス管理・ファイル転送にアクセス可能
  • 接続エラーと切断イベントに事象の説明と解決手順を表示
  • 管理者が許可した WorkSpace でネストされた仮想化をセルフサービスで有効化
  • 初回起動時のウェルカムツアー (ヘルプメニューから再生可能)

WorkSpaces Advisor (プレビュー) は、ローカルデバイス・ネットワーク・WorkSpace の 3 つの観点でメトリクスを監視し、登録・サインイン・接続に問題が発生した際にユーザーへ推奨アクションを提示します。管理者はセルフサービス権限で Advisor とネストされた仮想化の有効 / 無効を制御できます。

⚡ 主要機能

🩺 1. WorkSpaces Advisor プロアクティブトラブルシューティング (パブリックプレビュー)

接続前・接続中・切断後を通して、デバイス・ネットワーク・WorkSpaces サービスの主要メトリクスを監視。登録、サインイン、接続全般、セッション切断時に問題が検知されると、アイコンの色が変化しアラートを表示。パネルを開くと問題の詳細と実行可能な推奨アクションを確認できます。ネットワークチェックには設定画面で構成したプロキシを使用。デフォルトで有効 (管理者は無効化可能)。

🎨 2. 刷新されたインターフェイスと簡素化された接続フロー

クリーンなレイアウトとモダンなデザインで設定とツールを見つけやすく再設計。WorkSpace の登録・接続フローを簡素化し、頻繁にアクセスする WorkSpaces の管理オプションを追加。ライト / ダーク / システム追従のカラーテーマをサポートし、接続エラーと切断イベントには事象の説明と解決手順を表示します。

🧰 3. 新しい統合ツールバーとフルスクリーン体験の改善

セッション中にキーボードショートカット、デバイス制御 (カメラ、マイク、オーディオ、USB)、ファイル転送、WorkSpaces Advisor へアクセスできる統合ツールバー。ウィンドウモードではタイトルバーに統合、フルスクリーンモードでは画面上部にフローティング表示後に自動的に隠れます (ピン留めで常時表示も可能)。前回使用したディスプレイでの起動、ウィンドウ状態・サイズ・位置の復元に対応。

🚀 4. ウェルカムツアーとセルフサービス機能

初回起動時と初回セッションでウェルカムツアーを表示 (ヘルプメニューからいつでも再生可能)。管理者が許可した WorkSpace ではネストされた仮想化をセルフサービスで有効化できます。マイクとスピーカーの選択、相対マウスモード (CAD やゲームなどのグラフィックスアプリケーション向け)、mailto / ftp リンクのローカルデバイスへのリダイレクトなども追加。

API 変更履歴

日付サービス変更内容
2026/11/17 workspaces 2 updated api methods - ModifySelfservicePermissions に NestedVirtualization と EnableEndUserAdvisor のセルフサービス権限を追加。ディレクトリ単位でネストされた仮想化と End User Advisor の有効 / 無効を切り替え、DescribeWorkspaceDirectories で設定を確認可能。End User Advisor はデフォルトで有効

セルフサービス権限の設定例

Bash AWS CLI - セルフサービス権限の変更 
# ディレクトリのセルフサービス権限を変更
# WorkSpaces Advisor とネストされた仮想化の有効 / 無効を制御
aws workspaces modify-selfservice-permissions \
  --resource-id d-xxxxxxxxxx \
  --selfservice-permissions \
    "EnableEndUserAdvisor=ENABLED,NestedVirtualization=ENABLED"

🛠️ 設定方法

前提条件

✓DCV ベースの Amazon WorkSpaces Personal を利用していること
✓Windows 11 を実行するローカルデバイスであること
✓Amazon WorkSpaces Windows クライアント バージョン 5.37 以降をインストールしていること

手順

1

最新クライアントのインストール

https://clients.amazonworkspaces.com/ から最新の Windows クライアントをダウンロードしてインストール。「自分のみ」と「デバイスの全ユーザー」の 2 つのオプションがあり、USB リダイレクトドライバーを使用する場合は全ユーザー向けインストールが必要です。

2

新エクスペリエンスでの接続

バージョン 5.37 以降では、起動時に新エクスペリエンスがデフォルトで開きます。初回起動時にはウェルカムツアーを表示。クラシックに戻す場合は画面右上の [Return to classic] を選択します。

3

WorkSpaces Advisor の利用

接続前・接続中・切断後に問題が検知されると、ツールバーの Advisor (プレビュー) アイコンの色が変わりアラートを表示。アイコンを選択してパネルを開き、問題の詳細と推奨される対処方法を確認して実行します。

4

管理者によるセルフサービス権限の制御 (オプション)

管理者は ModifySelfservicePermissions API または WorkSpaces コンソールから、ディレクトリ単位で End User Advisor とネストされた仮想化のセルフサービス権限を制御できます。End User Advisor はデフォルトで有効です。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓サポートコストの削減: ユーザー自身による問題解決でヘルプデスクへの問い合わせ件数と解決時間を削減
✓生産性向上: 簡素化された接続フローとわかりやすいエラーメッセージで業務中断時間を短縮
✓追加コストなし: 新クライアントエクスペリエンスは追加料金なしで利用可能

🔬 技術面のメリット

✓プロアクティブな問題検知: デバイス・ネットワーク・WorkSpace の 3 層で監視し、切り分けを自動化
✓段階的な移行: 新旧エクスペリエンスを切り替え可能。Client Experience Policy で制御可能
✓セルフサービスの拡充: ネストされた仮想化の有効化や診断ログのオンデマンド送信 (AWS Support 向け参照コード付き)

🚧 制限事項

✗新エクスペリエンスは DCV ベースのみ対応。PCoIP と WorkSpaces Pools はクラシックで自動的に開く
✗WorkSpaces Advisor はパブリックプレビューで、仕様変更の可能性あり
✗Microsoft がサポートする Windows 11 が必要
✗USB リダイレクトドライバーは全ユーザー向けインストール時のみ導入可能

⚠️ 考慮すべき点

⚠Client Experience Policy でエクスペリエンス固定時、ユーザーは切り替え不可
⚠ネストされた仮想化は管理者が許可した WorkSpace でのみ利用可能
⚠セッション切断後に短い満足度調査が表示されることがある
⚠エクスペリエンスの切り替えには数秒程度かかる場合がある

💰 料金と利用可能リージョン

💵 料金

新しいクライアントエクスペリエンス (WorkSpaces Advisor パブリックプレビューを含む) は追加料金なしで利用できます。Amazon WorkSpaces Personal 自体の料金は、従来どおりバンドルと課金モード (月額または時間単位) に応じて発生します。

🌏 利用可能リージョン

Amazon WorkSpaces Personal が利用可能なすべての AWS リージョンで利用できます (東京、大阪リージョンを含む)。

🛟 AWS Support: 新しい診断ログのオンデマンド送信機能で発行される参照コードを使用した問い合わせが可能

✅ まとめ

Amazon WorkSpaces Personal の Windows クライアントが刷新され、WorkSpaces Advisor (パブリックプレビュー) によるプロアクティブなトラブルシューティングが利用可能になりました。接続問題の自己解決を支援することでヘルプデスクの負荷軽減が期待できます。

✓WorkSpaces を運用する組織は、クライアントのバージョン 5.37 以降への更新と新エクスペリエンスのユーザー展開を検討することを推奨
⚠PCoIP ベースの WorkSpaces を利用中の場合は、クラシックエクスペリエンスが引き続き使用される点に留意
