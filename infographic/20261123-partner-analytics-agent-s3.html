AWS Partner Central

🤝 Partner Central Agents と Data Subscriptions による分析データアクセスの拡張

📅 リリース日: 2026 年 11 月 23 日 | 🧩 機能: 自然言語による分析と S3 へのデータセット毎日配信

📝 概要

AWS Partner Central に、分析データへアクセスする 2 つの新しい方法が追加されました。

🤖 1. Partner Central Agents

リード、マーケティングキャンペーン、商談 (Opportunity) とパイプライン、ファンディングに関する質問を自然言語で行い、ダッシュボード操作やスプレッドシートへのエクスポートなしに回答を取得。AWS Marketplace 出品者は利用状況、契約、更新、請求、回収、支払いも質問可能。同じ機能は Partner Central MCP サーバー経由でパートナー自身の AI アシスタントからも利用できます。

📦 2. Data Subscriptions

すぐに利用可能なデータセットをパートナー所有の Amazon S3 バケットに毎日配信。リード、マーケティングキャンペーン、パートナーアカウント関係、商談とパイプライン、Marketplace の利用状況・契約・更新が対象。BI ツール、Salesforce や HubSpot などの CRM、生成 AI アシスタントと連携したカスタムレポーティングに活用できます。

いずれも既存の IAM ポリシーに基づいて動作するため、閲覧が許可されているデータのみにアクセスでき、エクスポートされたデータは自身の AWS アカウント内に保持されます。

❌ Before: アップデート前の課題
  • 分析データの確認にはダッシュボード操作か、スプレッドシートへの手動エクスポートが必要
  • BI ツールや CRM への取り込みには独自のエクスポートパイプラインの構築・維持が必要
  • Marketplace の利用状況や請求などの横断的な照会には複数の画面やレポートの確認が必要
✅ After: アップデート後の改善
  • 自然言語の質問だけで、リード、キャンペーン、パイプライン、ファンディングなどの分析情報を即座に取得
  • Data Subscriptions により、データセットが毎日自動で自社の S3 バケットへ配信
  • Partner Central MCP サーバーを通じて、自社の AI アシスタントやツールから同じ分析機能を利用可能

Partner Central Agents は自然言語の質問に直接回答し、Data Subscriptions はデータセットをパートナー所有の S3 バケットに毎日配信して BI ツール、CRM、生成 AI アシスタントとの連携を可能にします。

⚙️ 主要機能

💬 Partner Central Agents による自然言語での分析
✓リード、マーケティングキャンペーン、商談とパイプライン、ファンディングに関する質問に自然言語で回答
✓AWS Marketplace 出品者は、利用状況、契約、更新、請求、回収、支払いについても質問可能
✓ダッシュボードの操作やスプレッドシートへのエクスポートが不要
✓例: 「今四半期の上位の商談は何か?」といった質問を Partner Central にサインインして実行
🔌 Partner Central MCP サーバー経由のアクセス
✓Partner Central Agents と同じ分析機能を、パートナー自身の AI アシスタントから利用可能
✓Model Context Protocol (MCP) に対応したツールと連携し、既存のワークフローに組み込める
📦 Data Subscriptions による S3 へのデータセット配信
✓すぐに利用可能なデータセットを、パートナー所有の Amazon S3 バケットへ毎日配信
✓対象: リード、マーケティングキャンペーン、パートナーアカウント関係、商談とパイプライン、Marketplace の利用状況・契約・更新
✓1 つのサブスクリプションが 1 つのデータセットを 1 つのバケットに配信。複数のサブスクリプションで同じバケットを共有可能
✓配信ファイルはパートナーが指定するカスタマーマネージド AWS KMS キーで暗号化
🔐 既存の IAM ポリシーに基づくアクセス制御
✓両機能とも既存の IAM ポリシーを利用し、閲覧が許可されているデータのみにアクセス可能
✓エクスポートされたデータはパートナー自身の AWS アカウント内に保持される
✓AWS Partner Central はバケットへの書き込みのみを行い、オブジェクトの読み取り、一覧表示、削除は行わない

📜 バケットポリシーの例

AWS Partner Central がパートナーのアカウントに代わってファイルを書き込めるようにするには、以下のステートメントをバケットポリシーに追加します。

JSON S3 バケットポリシー 
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "AllowAWSDataSubscriptionsPutObject",
            "Effect": "Allow",
            "Principal": {
                "Service": "datasubscriptions.partnercentral.amazonaws.com"
            },
            "Action": "s3:PutObject",
            "Resource": "arn:aws:s3:::amzn-s3-demo-bucket/*",
            "Condition": {
                "StringEquals": {
                    "aws:SourceAccount": "111122223333"
                }
            }
        }
    ]
}

あわせて、KMS キーポリシーには kms:GenerateDataKey を許可するステートメント (kms:ViaService 条件で S3 経由に限定) を追加します。Partner Central にデータの復号権限を付与する必要はありません。

🚀 設定方法

✅ 前提条件

✓AWS Partner Central アカウントにリンクされた AWS アカウントを保有していること
✓AWS KMS キーと同一リージョンに Amazon S3 バケットを作成済みであること (オプトインリージョンは非対応)
✓同一アカウント内にカスタマーマネージド AWS KMS キーを作成済みであること
✓バケットポリシーと KMS キーポリシーを編集できる権限、および Data Subscriptions 操作に必要な IAM 権限があること
1
Partner Central Agents に質問する

AWS Partner Central にサインインし、エージェントに自然言語で質問する (例: 「What are my top opportunities this quarter?」)。サインインするだけで利用でき、既存の IAM ポリシーで許可された範囲のデータに基づいて回答が返されます。

2
S3 バケットと KMS キーを準備する
Bash S3 バケットと KMS キーの作成 
# S3 バケットを作成 (KMS キーと同一リージョン)
aws s3api create-bucket --bucket amzn-s3-demo-bucket --region us-east-1

# カスタマーマネージド KMS キーを作成
aws kms create-key --description "Partner Central Data Subscriptions"

配信先となる S3 バケットと、配信ファイルの暗号化に使用するカスタマーマネージド KMS キーを作成します。その後、前述のバケットポリシーとキーポリシーを適用します。

3
Data Subscriptions を作成する

AWS Partner Central にサインインし、[Settings] から [Data Subscriptions] に移動。配信するデータセット、配信先バケット、KMS キーの ARN を指定してサブスクリプションを作成します。作成後、指定したデータセットが毎日 S3 バケットの対応するフォルダに配信されます。サブスクリプションは作成後に変更できないため、設定を変更する場合はキャンセルして再作成します。

💡 メリット

📈 ビジネス面
✓意思決定の迅速化: ダッシュボード操作やエクスポート作業なしに、自然言語の質問でパイプラインやリードの状況を即座に把握
✓運用負荷の削減: 独自のエクスポートパイプラインの構築・保守が不要になり、アライアンスチームや分析チームの工数を削減
✓既存ツールの活用: データが自社の S3 バケットに配信されるため、既存の BI ツールや CRM (Salesforce、HubSpot など) をそのまま活用可能
🛠️ 技術面
✓MCP 対応による拡張性: Partner Central MCP サーバー経由で、自社の AI アシスタントやエージェントワークフローに分析機能を組み込める
✓セキュアなデータ配信: カスタマーマネージド KMS キーによる暗号化と最小権限のバケットポリシー (s3:PutObject のみ) により、データの管理権をパートナー側が保持
✓一貫したアクセス制御: 既存の IAM ポリシーに基づいて動作するため、新たな権限モデルの設計が不要

⚠️ デメリット・制約事項

🚧 制限事項

✗Data Subscriptions は作成後に変更できず、データセット・バケット・キーを変更するにはキャンセルして再作成する必要がある
✗S3 バケットは KMS キーと同一リージョンに配置する必要があり、オプトインリージョンはサポートされない
✗暗号化にはカスタマーマネージド KMS キーが必須で、AWS 所有キーや他アカウントのキー、エイリアス ARN は使用できない

🤔 考慮すべき点

⚠️配信データへのアクセス権はバケットポリシー、IAM ポリシー、KMS キーポリシーで決まるため、サブスクリプション作成前および運用中も継続的なアクセス権のレビューが必要
⚠️バケットポリシーの Resource にプレフィックスのみを指定すると配信がブロックされる可能性があるため、ドキュメントどおり /* を指定する必要がある
⚠️KMS キーの利用に伴う AWS KMS の料金や、S3 のストレージ料金が自社アカウント側に発生する

💰 料金

公式発表に料金に関する記載はありません。なお、Data Subscriptions の利用では、配信先の S3 バケットのストレージ料金やカスタマーマネージド KMS キーに関する AWS KMS の料金が、パートナー自身の AWS アカウントに発生する点に留意してください。

🌍 利用可能リージョン

AWS Partner Central が利用可能なすべての AWS リージョンで利用できます。ただし、Data Subscriptions の配信先 S3 バケットと KMS キーは同一リージョンに配置する必要があり、オプトインリージョンはサポートされません。

📝 まとめ

AWS Partner Central の Partner Central Agents と Data Subscriptions により、パートナーは自然言語での即時の分析と、自社 S3 バケットへの毎日のデータセット配信という 2 つの方法で分析データを活用できるようになりました。ダッシュボード操作や独自パイプラインの構築が不要になるため、AWS パートナーや Marketplace 出品者は、まず Partner Central Agents で質問を試し、継続的なデータ活用が必要な場合は Data Subscriptions のセットアップ (S3 バケット、KMS キー、ポリシー設定) を進めることを推奨します。
