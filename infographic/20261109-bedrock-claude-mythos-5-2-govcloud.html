🧠 Claude Mythos 5.2 が AWS GovCloud (US) の対象顧客向けに提供開始

📅 リリース日: 2026 年 11 月 9 日 | 🔐 許可リスト制 (Cyber Verification Program)

📌 概要

Amazon Bedrock が Claude Mythos 5.2 を AWS GovCloud (US) の対象顧客向けに提供開始しました。 サイバーセキュリティ、ソフトウェアコーディング、複雑な推論タスクにおける Anthropic の最も先進的な AI モデルです。 強力なサイバーセキュリティ能力を持つ Anthropic のモデルとして AWS GovCloud (US) で利用可能になった最初のモデルであり、 同日発表の Claude Fable 5.2 と同一の基盤モデルで、サイバーおよびバイオ研究向けの能力を完全に保持したバージョンです。

アクセスは許可リストに登録された組織に限定され、利用には Anthropic の Cyber Verification Program への申請が必要です。

❌ Before: アップデート前の課題
  • GovCloud では強力なサイバーセキュリティ能力を持つ Anthropic モデルが利用できなかった
  • 一般提供モデルでは安全性分類器が高リスクなサイバー関連リクエストをブロックし、正当な防御的業務に制約があった
  • 大規模コードベースの脆弱性調査に多くの手動ガイダンスと人的リソースが必要だった
✅ After: アップデート後の改善
  • GovCloud リージョンの Bedrock 経由で Claude Mythos 5.2 を利用可能に
  • 脆弱性の特定と悪用可能性の実証を、コンプライアンス要件を満たした環境内で実行可能に
  • より少ない手動ガイダンスで実用的な調査結果を取得し、防御的セキュリティ業務を加速

⚡ 主要機能

🏛️ 1. AWS GovCloud (US) での Claude Mythos 5.2 提供
  • 強力なサイバーセキュリティ能力を持つ Anthropic モデルとして GovCloud 初
  • 政府機関や規制業界が、コンプライアンス境界内で高度なセキュリティ業務に AI を活用可能
  • アクセスは許可リストに登録された組織に限定
🔍 2. 高度なセキュリティ脆弱性の特定と実証
  • ソフトウェアの高度な脆弱性を特定し、悪用可能性を実証可能
  • 大規模コードベースを理解し、従来モデルより少ない手動ガイダンスで実用的な調査結果を提供
  • 脅威が顕在化する前に脆弱性を発見・修正する防御的業務を加速
🧬 3. Claude Fable 5.2 と同一の基盤モデル
  • 同日に GovCloud で提供開始された Claude Fable 5.2 と同じ基盤モデル
  • 一般提供版では安全性分類器で制限されるサイバー・バイオ研究向け能力を完全に保持
  • コーディング、数学、科学分野のフロンティア性能をそのまま利用可能
🛡️ 4. Cyber Verification Program によるアクセス管理
  • 検証ポータルで組織単位の申請、本人確認・事業者確認を経て許可リストに登録
  • 3 つのアクセスティア (Defense / Red Team / Specialized) を提供
  • MFA や短期 API キーなどのセキュリティ統制が必要で、ティアが上がるほど要件が厳格化

🎚️ 3 つのアクセスティア

🛡️ Defense Access
  • 防御業務向け
  • 審査期間の目安: 約 2 日
  • 2026 年 12 月 15 日以降は静的 API キー廃止 → 短期クレデンシャルへ移行
🔴 Red Team Access
  • 許可されたペネトレーションテスト向け
  • 最大 75 ユーザー
  • ISO 27001 / SOC 2、OSCP、CVE クレジットなどの証跡が必要。審査は約 2 週間
⚙️ Specialized Access
  • 重要インフラの高リスクテスト向け
  • 最大 25 ユーザー
  • 米国政府との連携のもとで詳細審査

💡 API 変更: 既存の Amazon Bedrock Runtime API (Converse、InvokeModel、Messages) に新しいモデルの提供範囲を追加するもので、新規 API の追加はありません。

✓Anthropic の有料プランまたは API 利用契約があること (Cyber Verification Program の申請要件)
✓MFA や短期 API キーなど、申請ティアに応じたセキュリティ統制を実装していること

ステップ 1: Anthropic の検証ポータルから組織の Owner または Admin が申請。業務内容に応じてティアを選択し、本人確認と事業者確認を実施。
ステップ 2: 検証完了後、GovCloud アカウントを連携し、Bedrock コンソールでモデルアクセスを有効化。管理者がワークスペースまたはカスタムロールへアクセスを割り当て。
ステップ 3: 推論プロファイルを確認し、既存の Converse / InvokeModel API からモデルを呼び出し。

aws bedrock list-inference-profiles \
  --region us-gov-west-1 \
  --query "inferenceProfileSummaries[?contains(inferenceProfileId, 'mythos')]"

💼 ビジネス面

✓規制環境での防御的セキュリティの加速: コンプライアンス境界内で最先端のサイバーセキュリティ AI を利用可能
✓脅威の先回り対応: 脅威が顕在化する前に脆弱性を発見・修正し、インシデント対応コストを削減
✓セキュリティ人材の生産性向上: 限られた専門人材をより高度な判断業務に集中可能

⚙️ 技術面

✓悪用可能性の実証まで対応: 指摘にとどまらず実証まで AI が支援し、修正の優先順位付けを高精度化
✓大規模コードベースの理解: 複雑で大規模なコードベース全体を対象とした脆弱性調査が可能
✓既存 API との互換性: 既存の Converse / InvokeModel API をそのまま利用可能

⚠️ デメリット・制約事項

🚧 制限事項

✗許可リスト制で、Cyber Verification Program での検証が必須
✗Red Team / Specialized は組織のみ申請可能で、ユーザー数に上限 (最大 75 / 25 ユーザー)
✗covered model のためデータ保持が必須 (ゼロデータ保持は既存の免除がある場合のみ)
✗CVP はサイバー領域のみ調整。バイオなど他領域の制限は維持

🔍 考慮すべき点

⚠顧客向けサービスとして外部提供する場合は別の承認が必要 (未承認の顧客向け利用は除外事由)
⚠DoS 攻撃や物理的損害を伴う行為などは全ティア禁止。Anthropic はいつでもアクセスを見直し・取り消し可能
⚠2026 年 12 月 15 日以降、Defense Access では静的 API キーが廃止 → 短期クレデンシャルへ移行が必要
⚠ティアに応じてフィッシング耐性 MFA、管理対象デバイス、バックグラウンドチェックなどの統制強化が必要

🎯 ユースケース

🏛️ ユースケース 1: 政府機関の重要システムの脆弱性調査

シナリオ: 政府機関のセキュリティチームが Defense Access を取得し、重要システムの大規模コードベースの脆弱性調査を実施。

流れ: CVP に Defense Access を申請 → GovCloud 上の Bedrock から Mythos 5.2 でコードベース全体を解析 → 悪用可能性の実証を含む調査結果をもとに修正の優先順位を決定。

✅ 効果: 機密性の高いコードをコンプライアンス境界の外に出すことなく、脅威が顕在化する前に脆弱性を修正。
🔴 ユースケース 2: 許可されたレッドチーム演習の高度化

シナリオ: 規制業界の組織が Red Team Access を取得し、許可されたペネトレーションテストと敵対者エミュレーションに活用。

流れ: ISO 27001 / SOC 2 認証や OSCP などの証跡を添えて申請 → 承認後に演習チームのワークスペースへアクセスを割り当て → GovCloud 内で攻撃シナリオの検証と防御策の評価を実施。

✅ 効果: 安全性分類器による中断を減らしながら、現実的な攻撃シナリオに基づく防御力評価を実現。
⚡ ユースケース 3: 重要インフラの高リスクテスト

シナリオ: 電力網や金融決済基盤などの重要インフラ事業者が、Specialized Access を通じて許可された高リスクテストを実施。

流れ: Specialized Access を申請 (米国政府との連携のもとで詳細審査) → 管理対象デバイスやネットワーク統制など厳格な要件を整備 → GovCloud 内で重要インフラ固有の脅威シナリオを検証。

✅ 効果: 最も深刻な攻撃手法に対する耐性を、統制された環境で事前に検証。

💰 料金・利用可能リージョン

Amazon Bedrock の従量課金モデルに基づき、入出力トークン数に応じて課金されます。 Cyber Verification Program の申請には、Anthropic の有料プランまたは API 利用契約が前提となります。

🌎 利用可能リージョン

us-gov-east-1 us-gov-west-1

商用リージョンを含むその他の提供状況は、Anthropic の検証プログラムを通じた許可リスト制で管理されます。

📝 まとめ

Claude Mythos 5.2 の AWS GovCloud (US) 提供により、政府機関や重要インフラ事業者などの対象顧客が、 強力なサイバーセキュリティ能力を持つ Anthropic の最先端モデルをコンプライアンス境界内で利用できるようになりました。 脆弱性の特定から悪用可能性の実証までを AI が支援することで、防御的セキュリティ業務の大幅な加速が期待できます。

利用を検討する組織は、まず Anthropic の Cyber Verification Program で自組織に適したアクセスティアを確認し、 必要なセキュリティ統制を整備した上で申請することを推奨します。
