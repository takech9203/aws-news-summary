AWS Interconnect - last mile プレビュー

🔗 AWS Interconnect - last mile
Megaport をパートナーとしたプレビューを開始

📅 リリース日: 2026 年 10 月 22 日 | フルマネージドなラストマイル接続

📌 概要

支社、データセンター、リモート拠点を AWS へ簡単に接続できるフルマネージド接続サービス 「AWS Interconnect - last mile」が、Megaport をパートナーとしたプレビューを開始しました。 ネットワークセットアップの手間と複雑さを排除し、数クリックでプライベートかつ高速な接続を確立できます。

Megaport は SDN (Software Defined Network) プロバイダーであり、広範なデータセンターフットプリントを持ちます。 BGP ピアリング、VLAN 設定、ASN 割り当てといった複雑なネットワーク構成は自動化されます。

⚖️ Before / After

❌ アップデート前の課題
  • ラストマイル回線の手配とネットワーク機器の設定を個別に行う必要があった
  • BGP ピアリング、VLAN 設定、ASN 割り当てを手動で構成する必要があり、専門知識と時間を要した
  • パートナーが Lumen (GA) と AT&T (ゲート付きプレビュー) に限られ、米国のお客様が中心だった
✅ アップデート後の改善
  • 31 か国 1,200 以上のデータセンターをカバーする Megaport のフットプリントを利用した接続が選択可能に
  • コンソール、CLI、API のいずれからでもプレビューの Interconnect を作成可能に
  • BGP、VLAN、ASN が自動構成され、99.99% の SLA とダウンタイムなしのメンテナンスを提供

お客様拠点から Megaport のラストマイル回線を経由し、AWS Interconnect と Direct Connect Gateway を通じて Amazon VPC へプライベート接続する流れを示しています。BGP、VLAN、ASN の構成は AWS Interconnect が自動的に処理します。

⚡ 主要機能

🌏 1. Megaport をパートナーとしたプレビュー提供

→ SDN プロバイダーである Megaport のネットワークを利用して、拠点から AWS へのプライベート接続を確立

→ Megaport は 31 か国にわたる 1,200 以上のデータセンターをカバー

→ プレビューでは San Jose (us-west-1) メトロと N. Virginia (us-east-1) メトロで利用可能

🖱️ 2. 数クリックでのラストマイル接続の確立

→ コンソールから AWS リージョン、帯域速度、Direct Connect Gateway ID、パートナーサブスクライバー ID を選択するだけで接続を開始

→ 接続開始後、AWS がアクティベーションキーを生成し、Megaport 側でのプロビジョニングを完了

→ コンソールに加え、CLI および API からも Interconnect を作成可能

🤖 3. 複雑なネットワーク構成の自動化

→ BGP ピアリング、VLAN 設定、ASN 割り当てを自動的に構成

→ 容量の事前プロビジョニングにより、接続確立を迅速化

📈 4. 高可用性と帯域の動的スケーリング

→ ダウンタイムなしのメンテナンス設計で、99.99% の SLA を提供

→ GA 時には、コンソールから 1 Gbps〜100 Gbps の帯域変更が可能になる予定

🔧 技術仕様

📝 接続に必要なパラメータ

項目詳細
AWS リージョン接続先となる希望の AWS リージョン
帯域速度 (bandwidth)確立する接続の帯域幅。GA 時には 1 Gbps〜100 Gbps の動的変更に対応予定
Direct Connect Gateway ID接続先の Direct Connect Gateway の ID
パートナーサブスクライバー IDパートナー (Megaport) 側のサブスクライバー識別子
アクティベーションキー接続開始時に AWS が生成し、Megaport 側のプロビジョニングに使用

⚙️ 自動構成される項目

項目詳細
BGP ピアリング経路交換のためのピアリング設定を自動化
VLAN 設定仮想 LAN の構成を自動化
ASN 割り当て自律システム番号の割り当てを自動化
容量事前プロビジョニングにより迅速な接続確立を実現

🛠️ 設定方法

✅ 前提条件

✓Direct Connect Gateway が作成済みであること
✓Megaport のサブスクライバー ID を保有していること
✓プレビュー対象メトロ (San Jose または N. Virginia) で利用可能であること

🪜 手順

STEP 1 📋 Interconnect の作成
リージョン、帯域速度、DXGW ID、サブスクライバー ID を選択
→
STEP 2 🔑 プロビジョニング完了
AWS 生成のアクティベーションキーで Megaport 側を完了
→
STEP 3 ✅ 接続の確認
BGP/VLAN/ASN は自動構成、VPC への疎通を確認

Interconnect の作成はコンソール、CLI、API のいずれでも可能です。 BGP ピアリング、VLAN 設定、ASN 割り当ては自動的に構成されるため、プロビジョニング完了後に Direct Connect Gateway を介した VPC への疎通を確認するだけで利用を開始できます。

💡 メリットと考慮事項

📊 ビジネス面のメリット

✓接続構築の迅速化: 数クリックで接続を開始でき、接続確立にかかる時間を短縮
✓広範なカバレッジ: 31 か国 1,200 以上のデータセンターをカバーする Megaport のフットプリントを活用
✓信頼性の担保: 99.99% の SLA に裏付けられた高可用性設計で、ミッションクリティカルなワークロードにも適用しやすい

🔬 技術面のメリット

✓構成の自動化: BGP、VLAN、ASN の設定が自動化され、手動設定に伴う設定ミスのリスクを低減
✓ダウンタイムなしのメンテナンス: 運用中の接続に影響を与えずにメンテナンスを実施
✓柔軟な帯域変更: GA 時には 1 Gbps〜100 Gbps の帯域を動的に変更可能になる予定

🚧 制限事項

✗プレビューであり、利用可能なメトロは San Jose (us-west-1) と N. Virginia (us-east-1) に限定
✗Megaport のサブスクライバー ID が必要で、Megaport との契約が前提
✗帯域の動的スケーリング (1 Gbps〜100 Gbps) は GA 時に提供予定

⚠️ 考慮すべき点

⚠プレビュー段階のため、本番適用は提供状況や SLA を十分に確認したうえで判断
⚠接続元の拠点が Megaport のフットプリントでカバーされているかを事前に確認
⚠料金はメトロと最も遠い AWS リージョンとの距離に基づくティアで決まるため、構成による料金差を事前に見積もる

🎯 ユースケース

🏢 ユースケース 1: 支社から AWS へのプライベート接続

シナリオ: 複数の拠点を持つ企業が、各拠点から AWS 上の業務システムへ低レイテンシかつセキュアに接続したい。

効果: 各拠点から Megaport のラストマイル回線経由で AWS へ数クリックで接続でき、拠点ごとの複雑なネットワーク設定作業を削減できます。

🗄️ ユースケース 2: コロケーションデータセンターとのハイブリッド接続

シナリオ: Megaport がカバーするコロケーションデータセンターを利用する企業が、AWS とのハイブリッド構成でミッションクリティカルなワークロードを稼働させたい。

効果: Direct Connect Gateway を介したプライベート接続を 99.99% の SLA 付きで確立でき、高可用性を求められるハイブリッド環境の信頼性を高められます。

📈 ユースケース 3: 帯域需要が変動するワークロードへの対応

シナリオ: データ移行や定期的なバックアップなど、時期によって必要な帯域が大きく変動するワークロードを運用している。

効果: GA 時に提供予定の動的スケーリングにより、コンソールから 1 Gbps〜100 Gbps の範囲で帯域を変更でき、需要に応じた柔軟な回線運用が可能になります。

💰 料金

Interconnect ごとに選択した帯域幅と自動割り当てされる料金ティアに基づく時間課金制です。 GB あたりのデータ転送料金は発生しません。課金は Interconnect の作成時に開始され、削除時に停止します (1 時間単位、端数は切り上げ)。

料金ティアは Tier 1 (最安) から Tier 5 (最高額) の 5 段階で、Interconnect メトロと、 単一の Direct Connect Gateway に接続された最も遠い AWS リージョンとの地理的距離に基づいて自動決定されます。 AWS Cloud WAN を利用する場合は、トポロジー内で最も高いティアの Core Network Edge によってティアが決まる点に注意が必要です。

🧮 料金例

🔗 関連サービス・機能

🔌 AWS Direct Connect

専用のネットワーク接続を提供するサービス。AWS Interconnect - last mile は Direct Connect Gateway と連携してプライベート接続を確立します。

🌉 AWS Direct Connect Gateway

複数の VPC やリージョンへの接続を集約するゲートウェイ。接続作成時に ID を指定します。

🌐 AWS Cloud WAN

グローバルネットワークを構築・管理するサービス。利用時は Core Network Edge の構成が料金ティアに影響します。

☁️ AWS Interconnect - multicloud

他クラウドプロバイダーとのプライベート接続を提供する姉妹機能。Google Cloud、OCI、Microsoft Azure との接続に対応しています。

📝 まとめ

AWS Interconnect - last mile の Megaport プレビューにより、31 か国 1,200 以上のデータセンターをカバーする Megaport のフットプリントを利用して、数クリックで拠点から AWS へのプライベート接続を確立できるようになりました。 Lumen、AT&T に続くパートナーの追加であり、ラストマイル接続の選択肢が着実に拡大しています。

San Jose または N. Virginia メトロ周辺に拠点を持ち、Megaport を利用中または検討中のお客様は、 既存の Direct Connect Gateway と組み合わせてプレビューでの評価を進めることを推奨します。
