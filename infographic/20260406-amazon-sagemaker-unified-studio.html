Amazon SageMaker Unified Studio
ノートブックインポート/エクスポート & 開発者アクセラレーション

JupyterLab からのシームレスな移行と、より快適なノートブック開発体験を実現

2026/04/06

Amazon SageMaker

📝 概要

SageMaker Unified Studio のノートブックにインポート/エクスポート機能が追加されました。JupyterLab やその他のプラットフォームからの移行が可能になり、.ipynb / .json / .py 形式をサポートします。

さらに開発者アクセラレーション機能として、セルの並び替え、キーボードショートカット、セルリネーム、マルチライン SQL サポートが追加されました。

🔄 Before / After

Before
❌他プラットフォームからの直接取り込み手段がなく手動移行が必要
❌標準的なエクスポート手段が限定的
❌セル操作やショートカットが不足し効率的開発が困難
➡
After
✅3 形式のファイルを直接インポート、メタデータも保持
✅4 形式のエクスポートでチーム間共有がスムーズ
✅セル並び替え、ショートカット、SQL サポートで効率向上

3 つのインポート形式と 4 つのエクスポート形式をサポートするワークフロー

⭐ 主要機能

Import ノートブックインポート
  • 📥JupyterLab やその他プラットフォームからの移行をサポート
  • 📄.ipynb / .json / .py 形式に対応
  • 💾セルタイプ、メタデータ、出力を保持してインポート
  • ✅既存のノートブック資産をそのまま活用可能
Export ノートブックエクスポート
  • 📦Jupyter + requirements (.zip): 依存関係を含む完全パッケージ
  • 📓標準 .ipynb: 他の Jupyter 互換環境に最適
  • 🐍Python スクリプト (.py): コード再利用やバージョン管理に便利
  • 📄ネイティブ形式 (.json): Studio 間での共有に使用
Accel 開発者アクセラレーション
  • 🔄セルの並び替え: ドラッグ&ドロップでセルを自由に移動
  • ⌨キーボードショートカット: 一般的な操作を素早く実行
  • 📝セルのリネーム: 分かりやすい名前で管理性を向上
  • 🗃マルチライン SQL: 複数行の複雑な SQL クエリの記述が可能

🛠 設定方法

前提条件: SageMaker Unified Studio ドメイン設定済み / プロジェクト作成済み / 適切な IAM ロール設定済み

メニューから用途に応じた 4 形式のいずれかを選んでエクスポート

🌟 メリット

💼 ビジネス面
  • マイグレーションコスト削減: 既存ノートブック資産をそのまま移行、手動書き換え不要
  • チームコラボレーション向上: 複数エクスポート形式で異なるツール間の共有が容易
  • 開発者生産性向上: ショートカットやセル操作で日常の開発効率が向上
🔧 技術面
  • 相互運用性: 標準ファイル形式のサポートで JupyterLab とのシームレスな移行が可能
  • メタデータ保持: セルタイプ、メタデータ、出力が維持されノートブックの再現性を確保
  • マルチライン SQL: 複雑な分析クエリの記述が容易に

⚠ デメリット / 制約事項

プラットフォーム固有の拡張機能やウィジェットは完全に再現されない場合がある
.zip 形式の requirements は他の環境でそのまま使用できるとは限らない
カスタムカーネルやプラグインに依存するノートブックは追加設定が必要になる可能性がある
大量ノートブックの一括インポート時はバッチ処理の可用性を確認する必要がある

💡 ユースケース

📜 JupyterLab からの移行
ローカル JupyterLab で開発していたノートブックを SageMaker Unified Studio に移行
→ .ipynb をそのままインポート、出力やメタデータが保持され手動修正が最小限に
👥 マルチプラットフォーム共有
SageMaker / JupyterLab / VS Code など異なるツールを使うチーム間でノートブック共有
→ .ipynb や .py でエクスポートし各ツールで継続作業が可能
📊 SQL 分析効率化
ノートブック内で複雑な SQL クエリを使用したデータ分析を実施
→ マルチライン SQL + ショートカット + セル並び替えで分析ワークフローを大幅効率化

💰 料金 & リージョン

SageMaker Unified Studio 利用料金に含まれます。コンピューティングリソースは通常の SageMaker 料金体系が適用。

🌎 SageMaker Unified Studio が利用可能なすべての AWS リージョンで使用可能

📝 まとめ

Amazon SageMaker Unified Studio のノートブックインポート/エクスポート機能により、JupyterLab などからの移行が大幅に簡素化されました。開発者アクセラレーション機能と合わせて、データサイエンティストやアナリストの日常的な開発体験が向上しています。既存のノートブック資産を活用しつつ SageMaker Unified Studio への移行を検討している組織は、この機能を活用して移行コストの削減を推奨します。
