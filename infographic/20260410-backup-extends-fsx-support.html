📋 概要

AWS Backup が Amazon FSx for Windows File Server、Amazon FSx for OpenZFS、Amazon FSx for Lustre に対するサポートを 2 つの側面で拡張しました。5 つの追加リージョンでバックアップ・リストアが利用可能になり、14 リージョンでクロスリージョンおよびクロスアカウントコピーが新たにサポートされました。

オプトインリージョンでも FSx バックアップを 論理的エアギャップボールト に保存できるようになり、ランサムウェアイベントからの復旧に役立つ追加の防御層を提供します。

❌ Before
  • マレーシア、台北、タイ、カルガリー、メキシコの 5 リージョンで FSx バックアップ・リストアが利用不可
  • 14 リージョンで FSx のクロスリージョン・クロスアカウントコピーが利用不可
  • オプトインリージョンでの FSx バックアップに対するエアギャップボールトの利用が制限
✅ After
  • 5 つの追加リージョンで FSx バックアップ・リストアが利用可能に
  • 14 リージョンでクロスリージョン・クロスアカウントコピーが利用可能に
  • オプトインリージョンでもエアギャップボールトに FSx バックアップを保存でき、ランサムウェア対策が強化

🔧 主要機能

🌏 5 リージョンでの FSx バックアップ・リストアサポート追加
アジアパシフィック (マレーシア、台北、タイ)、カナダ西部 (カルガリー)、メキシコ (中部) で FSx for Windows File Server、FSx for OpenZFS、FSx for Lustre のバックアップ作成およびリストアを完全サポート。
🌍 14 リージョンでのクロスリージョン・クロスアカウントコピー
アフリカ、アジアパシフィック、カナダ西部、ヨーロッパ、イスラエル、メキシコの 14 リージョンで、オンデマンドコピーとスケジュールされたバックアッププランの両方に対応。
  • オンデマンドコピーとコピールール付きバックアッププランの両方をサポート
  • クロスリージョンおよびクロスアカウントの両方のコピーに対応
🔒 エアギャップボールトのサポート拡張
オプトインリージョンでも FSx バックアップをエアギャップボールトに保存可能。論理的エアギャップにより、意図しない削除や悪意のある削除から保護し、ランサムウェアイベントからの復旧を支援する追加の防御層を提供。

🛠️ 設定方法

前提条件: AWS Backup が利用可能なリージョンでアカウントが有効化済み / オプトインリージョンが有効化済み / FSx ファイルシステムが作成済み / AWS CLI v2 がインストール済み

ステップ 1: バックアッププランの作成

Bash 日次バックアップ + クロスリージョンコピー 
# FSx ファイルシステムのバックアッププランを作成
aws backup create-backup-plan \
  --backup-plan '{
    "BackupPlanName": "fsx-cross-region-plan",
    "Rules": [
      {
        "RuleName": "daily-backup-with-copy",
        "TargetBackupVaultName": "Default",
        "ScheduleExpression": "cron(0 5 ? * * *)",
        "StartWindowMinutes": 60,
        "CompletionWindowMinutes": 180,
        "Lifecycle": {
          "DeleteAfterDays": 35
        },
        "CopyActions": [
          {
            "DestinationBackupVaultArn": "arn:aws:backup:ap-southeast-5:123456789012:backup-vault:Default",
            "Lifecycle": {
              "DeleteAfterDays": 35
            }
          }
        ]
      }
    ]
  }'

ステップ 2: FSx リソースの割り当て

Bash バックアッププランへの FSx 割り当て 
# バックアッププランに FSx ファイルシステムを割り当て
aws backup create-backup-selection \
  --backup-plan-id "your-backup-plan-id" \
  --backup-selection '{
    "SelectionName": "fsx-resources",
    "IamRoleArn": "arn:aws:iam::123456789012:role/AWSBackupDefaultServiceRole",
    "Resources": [
      "arn:aws:fsx:ap-northeast-1:123456789012:file-system/fs-0123456789abcdef0"
    ]
  }'

ステップ 3: エアギャップボールトの作成

Bash ランサムウェア対策用エアギャップボールト 
# 論理的エアギャップボールトを作成
aws backup create-logically-air-gapped-backup-vault \
  --backup-vault-name "fsx-airgapped-vault" \
  --min-retention-days 7 \
  --max-retention-days 365 \
  --backup-vault-tags Purpose=RansomwareProtection

ステップ 4: オンデマンドのクロスアカウントコピー

Bash 別アカウントへのオンデマンドコピー 
# 別アカウントへのオンデマンドコピー
aws backup start-copy-job \
  --source-backup-vault-name "Default" \
  --destination-backup-vault-arn "arn:aws:backup:ap-southeast-5:987654321098:backup-vault:Default" \
  --recovery-point-arn "arn:aws:backup:ap-northeast-1:123456789012:recovery-point:xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx" \
  --iam-role-arn "arn:aws:iam::123456789012:role/AWSBackupDefaultServiceRole"

⚠️ デメリット・制約事項

⚠️ 制限事項
  • 対象は FSx for Windows File Server、FSx for OpenZFS、FSx for Lustre の 3 種類。FSx for NetApp ONTAP は対象に含まれていない場合あり (公式ドキュメントでの確認を推奨)
  • クロスリージョンコピーにはデータ転送料金が発生
  • オプトインリージョンの利用には事前にリージョンの有効化が必要
💡 考慮すべき点
  • クロスリージョンコピー先での暗号化キー管理 (KMS キー) の設計が必要
  • クロスアカウントコピーには送信元・送信先の両方で適切な AWS Backup 組織ポリシーの設定が必要
  • エアギャップボールトの最低保持期間設定において、ストレージコストとセキュリティ要件のバランスを考慮

🎯 ユースケース

🌏 ユースケース 1: アジアパシフィック地域のディザスタリカバリ
タイのリージョンで稼働する FSx for Windows File Server のバックアップを、マレーシアリージョンにクロスリージョンコピーして DR 体制を構築。
✅ タイリージョンで障害が発生した場合でも、マレーシアリージョンのバックアップから FSx ファイルシステムをリストアして業務を継続可能
🔒 ユースケース 2: ランサムウェア対策のためのエアギャップボールト活用
重要な業務データを保持する FSx for OpenZFS のバックアップをエアギャップボールトに保存し、ランサムウェア攻撃によるバックアップデータの改ざんや削除を防止。最低保持期間 30 日を設定。
✅ エアギャップボールト内のバックアップは最低保持期間内に削除不可。ランサムウェア攻撃を受けても確実にクリーンなバックアップからリストアが可能
👥 ユースケース 3: マルチアカウント環境でのバックアップ集約
AWS Organizations を使用したマルチアカウント環境で、各アカウントの FSx for Lustre バックアップをセキュリティアカウントに集約し、一元的にバックアップデータを保護。
✅ 個別アカウントが侵害された場合でも、セキュリティアカウントのバックアップボールトから FSx ファイルシステムをリストアでき、データ損失リスクを最小化

📝 まとめ

AWS Backup の Amazon FSx サポートが 5 つの追加リージョン でのバックアップ・リストアと 14 リージョン でのクロスリージョン・クロスアカウントコピーに拡張されたことにより、グローバルに展開する FSx ワークロードのデータ保護戦略がより柔軟に構築できるようになりました。

特に エアギャップボールト のオプトインリージョンでのサポートは、ランサムウェア対策として重要な防御層を提供します。新リージョンで FSx ファイルシステムを運用しているユーザーは、バックアッププランにクロスリージョンコピールールを追加し、エアギャップボールトの導入を検討することを推奨します。
