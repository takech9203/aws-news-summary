📌 概要

Amazon Bedrock で提供されている OpenAI の最上位モデル GPT-5.6 Sol の API 価格が引き下げられました。入力は 100 万トークンあたり $4 (20% 引き下げ)、出力は 100 万トークンあたり $20 (33.3% 引き下げ) となり、プロモーション価格は少なくとも 2026 年 11 月 21 日まで有効です。

GPT-5.6 Sol は、コーディング、サイバーセキュリティ、科学研究の分野で最先端のエージェンティック性能を発揮するモデルで、エージェンティックコーディングベンチマークで最先端の結果を達成しています。今回の値下げは、先行して実施された GPT-5.6 Terra / Luna の値下げに続くもので、OpenAI モデルファミリー全体の価格が引き下げられました。

自律型コーディングエージェント、マルチステップの分析、リサーチワークフローなど、大量のトークンを消費する高ボリュームワークロードをより手頃なコストで運用でき、フロンティアモデルを活用したエージェント構築のハードルが下がります。

❌ Before: アップデート前の課題

  • 値下げ前は入力 $5 / 出力 $30 (100 万トークンあたり、引き下げ率からの換算値) で、大量トークン消費ワークロードのコストが高額になりやすかった
  • 自律型コーディングエージェントのような長時間・多ターンのワークロードでは、出力トークン課金がコストの大きな割合を占めていた
  • コスト面の理由から、最上位モデルの利用を一部のワークロードに限定せざるを得ないケースがあった

✅ After: アップデート後の改善

  • 入力価格が 100 万トークンあたり $4 に引き下げられた (20% 引き下げ)
  • 出力価格が 100 万トークンあたり $20 に引き下げられた (33.3% 引き下げ)
  • 出力トークンを大量に生成するエージェンティックワークロードほど恩恵が大きく、最上位モデルをより広範なワークロードへ適用しやすくなった

⚡ 主要機能

📥 1. 入力トークン価格の引き下げ
  • 入力価格が 100 万トークンあたり $4 に引き下げ (引き下げ率 20%)
  • プロンプトキャッシュ (キャッシュ読み取りは 100 万トークンあたり $0.40) と組み合わせることで、繰り返しの多いワークロードのコストをさらに削減可能
📤 2. 出力トークン価格の引き下げ
  • 出力価格が 100 万トークンあたり $20 に引き下げ (引き下げ率 33.3%)
  • 入力よりも引き下げ率が大きく、出力トークンを大量に生成するエージェンティックワークロードで特に効果が大きい
📆 3. プロモーション期間
  • 引き下げ後の価格は少なくとも 2026 年 11 月 21 日まで有効
  • GPT-5.6 Terra および Luna の値下げに続く措置で、OpenAI モデルファミリー全体が値下げの対象に

🛠️ 設定方法

📋 前提条件

✓AWS アカウントを保有していること
✓Amazon Bedrock コンソールで API キー (長期キー) を作成済みであること
✓IAM アイデンティティに、推論プロファイルに加えてアカウントのデフォルトプロジェクト (arn:aws:bedrock:{region}:{account-id}:project/default) に対する bedrock:InvokeModel 権限が付与されていること
1
SDK のインストール

Amazon Bedrock は OpenAI 互換エンドポイントを提供しているため、OpenAI Python SDK をそのまま利用できます。

BashOpenAI SDK のインストール
pip install openai
2
環境変数の設定

Bedrock の API キーと bedrock-runtime エンドポイントのベース URL を設定し、OpenAI SDK からの呼び出しを Amazon Bedrock にルーティングします。

Bash認証と接続の設定
export OPENAI_API_KEY="<Bedrock API キー>"
export OPENAI_BASE_URL="https://bedrock-runtime.us-east-1.amazonaws.com/openai/v1"
3
推論リクエストの実行

bedrock-runtime エンドポイントではリージョン内推論は利用できないため、モデル名にはクロスリージョン推論プロファイル (us.openai.gpt-5.6-sol または global.openai.gpt-5.6-sol) を指定します。

PythonResponses API での呼び出し
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="global.openai.gpt-5.6-sol",
    input="Can you explain the features of Amazon Bedrock?"
)
print(response)

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓コスト削減: 入力 20%、出力 33.3% の値下げにより、既存ワークロードのコストを変更なしで削減
✓最上位モデルの適用範囲拡大: コスト面で見送っていたワークロードにもフロンティアモデルを適用しやすい
✓予見性のあるプロモーション期間: 2026 年 11 月 21 日までの価格が明示され、コスト計画を立てやすい

🔬 技術面のメリット

✓エージェンティックワークロードとの親和性: 出力の値下げ幅が大きく、長い推論・生成を繰り返す自律型エージェントのコスト効率が特に向上
✓プロンプトキャッシュとの併用: キャッシュ読み取り $0.40 / 100 万トークンで、システムプロンプトやツール定義の再利用コストを大幅削減
✓OpenAI SDK 互換: Responses API / Chat Completions API をそのまま利用でき、移行コストが小さい

⚠️ 制限事項

✗プロモーション価格の保証期間は 2026 年 11 月 21 日まで。それ以降の価格は明示されていない
✗サービスティアは Standard のみ (Priority、Flex、Reserved は利用不可)
✗bedrock-runtime エンドポイントはリージョン内推論に非対応。クロスリージョン推論プロファイルの利用が必要
✗構造化出力、Count tokens、Intelligent prompt routing などの一部 Bedrock 機能には非対応

💡 考慮すべき点

→$4 / $20 は Global CRIS のショートコンテキスト (272K) 価格。In-Region / Geo CRIS では $4.40 / $22.00 とやや高い
→272K 超のロングコンテキスト (1M) 利用時は別価格 (Global CRIS で入力 $8、出力 $30)。コスト試算に注意
→2026 年 11 月 21 日以降の価格改定に備え、コスト前提を定期的に見直すことを推奨

🎯 ユースケース

💻 1. 自律型コーディングエージェント

シナリオ: リポジトリ全体を対象にコード生成、テスト、修正を繰り返す自律型コーディングエージェントを運用。1 タスクあたり大量の出力トークンを生成する。

Python実装例
from openai import OpenAI

client = OpenAI()

response = client.responses.create(
    model="global.openai.gpt-5.6-sol",
    input="リポジトリのテスト失敗を解析し、修正パッチを生成してください。",
)
✅ 効果: 出力価格が 33.3% 引き下げられたため、出力トークン中心のコーディングエージェントの運用コストを大幅に削減できる。
📊 2. マルチステップのデータ分析パイプライン

シナリオ: 大量のドキュメントやログを段階的に解析し、要約・分類・レポート生成を行うマルチステップ分析を日次バッチで実行する。

Python実装例
for document in documents:
    response = client.responses.create(
        model="us.openai.gpt-5.6-sol",
        input=f"次のドキュメントを解析し、重要な指標を抽出してください。\n{document}",
    )
✅ 効果: 入力 20% の値下げにより、大量ドキュメントを投入する高ボリュームワークロードの月次コストを圧縮できる。
🔍 3. リサーチワークフロー

シナリオ: 科学研究やセキュリティ調査において、長い推論チェーンを伴う調査タスクを GPT-5.6 Sol に実行させる。共通のシステムプロンプトと参照資料を繰り返し利用する。

Python実装例
# プロンプトキャッシュを活用して共通コンテキストの再利用コストを削減
response = client.responses.create(
    model="global.openai.gpt-5.6-sol",
    input=research_prompt_with_shared_context,
)
✅ 効果: 値下げ後の価格とプロンプトキャッシュ (キャッシュ読み取り $0.40 / 100 万トークン) の併用により、繰り返しの多いリサーチワークフローのコスト効率が大きく向上する。

📝 まとめ

Amazon Bedrock 上の OpenAI GPT-5.6 Sol が入力 20%、出力 33.3% 値下げされ、エージェンティックコーディングをはじめとする高ボリュームワークロードでフロンティアモデルを活用するコストが大きく下がりました。プロモーション価格は少なくとも 2026 年 11 月 21 日まで有効です。
