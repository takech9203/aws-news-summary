📋 概要

Amazon Quick が、Visier のピープルアナリティクスプラットフォームの AI アシスタント「Vee」と Model Context Protocol (MCP) を通じて統合されました。HR ビジネスパートナー、財務マネージャー、オペレーションリーダーが、ツールを切り替えることなく Amazon Quick ワークスペース内から直接、Visier のガバナンス付きワークフォースインテリジェンスにアクセスできます。

自然言語で人員数、離職率、勤続年数、オープンポジションなどに関する質問を行い、Visier のガバナンス付きワークフォースデータモデルに基づく回答を受け取ることができます。さらに Quick Flows からの自動化、Quick Research による深層分析にも対応し、Quick Spaces の企業ナレッジと組み合わせたコンテキスト化された回答を提供します。

✗リーダーシップ会議の準備で、スプレッドシート照合やダッシュボード切り替えに数時間を消費
✗ワークフォースレビューの実施に手動での反復作業が必要

✅ アップデート後の改善
✓Quick ワークスペース内から Visier のライブデータに自然言語でアクセス可能
✓Quick Flows による定期ワークフォースレビューの自動化で手動作業が不要
✓ライブデータと企業ナレッジを統合した回答を単一インターフェースで取得

ビジネスユーザーが Amazon Quick に自然言語で質問すると、Quick Agent がインテントを解析し、MCP を通じて Visier の Vee エージェントにルーティング。ライブデータと企業ナレッジを統合した回答を返します。

🚀 主要機能

🔌 MCP を通じた Visier Vee 統合
  • Visier がホストするリモート MCP サーバーを通じて Amazon Quick と Visier のピープルアナリティクス機能を接続
  • Amazon Quick の組み込み MCP クライアントが Visier の MCP サーバーのツールを自動検出
  • カスタム統合を構築することなく、標準化されたプロトコルで安全にデータ連携
💬 自然言語によるワークフォースデータアクセス
  • Quick Agent を通じて会話形式で質問し、即座の回答を取得
  • 人員数、離職率、勤続年数、オープンポジションなどの指標に対応
  • 各回答にデータソースの帰属情報が付与され、Visier データか社内ドキュメントかを明確に識別
⚡ Quick Flows によるワークフロー自動化
  • 定期的なワークフォースレビュー、しきい値アラート、会議前ブリーフィングを自動化
  • スケジュール実行により、毎週月曜日の朝に自動でレポートを生成・配信
  • ライブデータ取得から複合スコア算出、ブリーフィング作成までを一連のフローで実行
🔍 Quick Research による深層分析
  • 自然言語で成果を記述すると、Quick Research が自律的に複数ソースを横断してクエリを実行
  • ライブワークフォースデータ、社内ポリシー、外部ベンチマークを統合した構造化レポートを生成
  • エグゼクティブサマリー、ベンチマーク比較、ギャップ分析などの形式で出力
🔒 ガバナンスとセキュリティ
  • Visier 側のデータガバナンスポリシーにより、認可されたワークフォースデータのみ公開
  • Quick Spaces のエンタープライズナレッジは既存のアクセス制御を維持
  • CloudWatch メトリクス/ログ、CloudTrail による完全な可観測性と監査証跡

人員管理総人員数、地域別分布、人員目標との差異

勤続年数平均勤続年数、役職別勤続年数、勤続マイルストーン
採用オープンポジション数、充足率
パフォーマンスハイパフォーマー比率、パフォーマンストレンド

モニタリングと監査

メトリクスAmazon CloudWatch で MCP アクションコネクタの呼び出し回数やエラー率を監視
ログCloudWatch Logs でチャット、コネクタ呼び出し、引用リソースを記録。S3 や Data Firehose へ配信可能

🛠 設定方法

前提条件

1. Amazon Quick へのアクセス権限を持つ AWS アカウント
2. アクティブなサブスクリプションを持つ Visier 環境
3. API アクセスと MCP サーバーが有効化された Visier アカウント

セットアップ手順

1
Visier の MCP サーバーを設定
Visier 管理コンソールで API & Integrations セクションに移動し、MCP サーバーを有効化。エンドポイント URL と認証情報を記録。
2
Amazon Quick で MCP 統合を追加
インテグレーション設定から認証タイプを選択し、認証情報を入力。Quick が Visier の MCP サーバーのツールを自動検出。他のユーザーと共有して設定完了。
3
Quick Spaces に企業ドキュメントをアップロード
ワークフォースプランニングドキュメントやポリシードキュメントをアップロードし、Visier のライブデータと組み合わせた回答の精度を向上。
4
Quick Flows で自動化を設定 (オプション)
定期的なワークフォースレビューが必要な場合、Quick Flows でスケジュール実行のフローを作成。
🔄 Quick Flows 自動化の例 (毎週月曜 8:00 AM)
1
Visier MCP サーバーから指標を取得 (総人員数、平均勤続年数、ハイパフォーマー数)
2
Quick Spaces から目標値・しきい値を取得 (人員目標、分布目標、比率目標)
3
ワークフォースヘルススコアを算出 (各指標を目標と比較し 100 点満点でスコアリング)
4
フォーマット済みブリーフィングを生成・マネージャーに配信

💡 ユースケース

👤 HR ビジネスパートナーによるワークフォースヘルスブリーフィング
HR ビジネスパートナーがリーダーシップ会議に向けてブリーフィングを準備。人員数、勤続年数、ハイパフォーマー比率などの指標を社内ポリシーのしきい値と照合する必要がある場面で、Quick Agent に自然言語で質問。
Quick Agent 質問例 
Q: 「当社のワークフォース全体の平均勤続年数と、
    最も勤続年数が長い役職は何ですか?」
→ Visier からライブデータを取得し、Quick Spaces の
   リテンションポリシーのしきい値と照合して回答

Q: 「リーダーシップブリーフィング用にワークフォースヘルスリスクを
    要約してください」
→ すべてのワークフォースデータをポリシーしきい値と照合し、
   リスク項目と推奨アクションを含むブリーフィングを生成
✅ 複数システムを横断した手動データ収集・分析作業が不要になり、数時間かかっていたブリーフィング準備を短時間で完了
💰 財務マネージャーによる人員予算管理
財務マネージャーが人員予算に対する実績を追跡。ライブの人員数データを承認済みの予算目標と比較し、差異を把握する必要がある場面。
Quick Agent 質問例 
Q: 「現在の従業員数と、そのうち米国拠点の人員数は?」
→ Visier MCP 経由でライブの人員データを取得

Q: 「米国の人員数は分布目標と比較してどうですか?」
→ Visier のライブ人員数と Quick Spaces の
   FY26 ワークフォースヘルス目標ドキュメントを照合
✅ リアルタイムの人員データと予算目標を単一の会話内で比較でき、予算逸脱の早期検知と対応が可能
🔄 定期ワークフォースレビューの自動化
組織全体のワークフォースヘルススコアを毎週自動算出し、マネージャーに配信。手動での反復作業を完全に排除するシナリオ。
Quick Flows 自動化フロー 
trigger: 毎週月曜日 8:00 AM
steps:
  - Visier からライブワークフォース指標を取得
  - Quick Spaces から目標値・しきい値を取得
  - 各指標をスコアリング (On Track / Needs Attention / Below Target)
  - 複合ワークフォースヘルススコアを算出 (100 点満点)
  - 注意が必要な指標のポリシー推奨アクションを取得
  - フォーマット済みブリーフィングを生成し配信
✅ 毎週の手動レビュー作業が完全に自動化され、一貫した基準でのモニタリングとタイムリーなアラートが実現

✅ メリット

✓統合ワークフォースインテリジェンス: ライブ人材データと社内の予算・ポリシー・計画を単一インターフェースで統合
✓インサイトまでの時間短縮: スプレッドシート照合やダッシュボード切り替えの時間を削減
✓部門横断的な意思決定支援: HR、財務、オペレーション全てで活用可能
✓標準化された MCP 接続: カスタム統合不要で安全なデータ連携
✓包括的な監視・監査機能: CloudWatch + CloudTrail による完全な可観測性

⚠️ 制約事項・考慮点

!Visier のアクティブなサブスクリプションと API アクセスが別途必要 (追加コスト発生)
!データ範囲は Visier に統合されたデータソース (HRIS、給与、採用追跡) に依存
!MCP 接続セットアップに Visier 管理コンソールでの管理者権限が必要
!Visier のデータガバナンスポリシー設定が不適切な場合、意図しないデータアクセスの可能性
!Quick Flows の自動化設計にはワークフォース指標・目標値の事前定義が必要

💲 料金とリージョン

💲 料金情報

  • Amazon Quick: Amazon Quick の料金体系に基づく
  • Visier: プラットフォームのサブスクリプション料金が別途必要
  • MCP 接続: 統合自体に追加料金なし (API コール量やデータ転送量に応じた料金が適用される場合あり)
