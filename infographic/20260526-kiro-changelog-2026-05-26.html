🏥 Kiro - HIPAA 対象サービスに追加

Kiro HIPAA Eligible
2026-05-26

📋 概要

Kiro が AWS HIPAA Eligible Services Reference に追加されました。医療機関や医療関連企業が HIPAA コンプライアンス要件の下で保護対象医療情報 (PHI) を取り扱う環境において、Kiro を使用したソフトウェア開発が可能になります。

Kiro は AWS が提供するエージェント型 AI 搭載 IDE であり、スペック駆動開発によりプロトタイプから本番環境への移行を支援します。

⚠️
重要: Kiro Web は HIPAA 対象から除外されています。デスクトップ版 Kiro IDE および Kiro CLI のみが対象です。

❌ Before

  • HIPAA 準拠環境で AI 支援開発ツール Kiro を使用できなかった
  • ePHI を処理する開発環境では Kiro の利用が制限されていた
  • 医療系ソフトウェア開発でエージェント型 AI IDE を活用不可

✅ After

  • AWS BAA 締結により Kiro を HIPAA 準拠環境で利用可能
  • ePHI を取り扱う開発ワークフローでエージェント型 AI 開発が可能
  • コンプライアンスを維持しながら医療系開発の効率化を実現

AWS BAA の締結を前提に、Kiro IDE/CLI からの開発作業が他の HIPAA 対象 AWS サービスと連携し、セキュリティ制御の下で ePHI を安全に取り扱う構成です。

🏅 HIPAA Eligible Service としての認定
  • Kiro が AWS HIPAA Eligible Services Reference に正式に追加
  • 電子保護対象医療情報 (ePHI) の作成、受信、処理、保持、送信に利用可能
  • AWS が HIPAA 要件への準拠を実証済み

  • AWS 側: Kiro サービスの HIPAA 要件への準拠を保証
  • 顧客側: HIPAA 要件に合致するようサービスを設定する責任

⚠️ デメリット・制約事項

制限事項

✗Kiro Web は HIPAA 対象外。ePHI を取り扱う開発にはデスクトップ版 IDE または CLI を使用する必要がある
✗AWS BAA の事前締結が必須。BAA なしでの ePHI 利用は HIPAA 違反となる
✗顧客側で HIPAA 要件に合致するサービス設定を行う責任がある
✗HIPAA 対象サービスリストに含まれない AWS サービスでは ePHI を処理・保存できない

考慮すべき点

→HIPAA 準拠環境の構築と維持には追加のセキュリティ設定と運用管理が必要
→開発チーム全員に HIPAA セキュリティ意識向上トレーニングの実施が推奨
→Kiro で生成されたコードが ePHI を取り扱う場合、そのコードの HIPAA 準拠性も確認が必要
→ePHI を含まない開発作業は、従来どおり Kiro Web を含むすべての機能を利用可能
