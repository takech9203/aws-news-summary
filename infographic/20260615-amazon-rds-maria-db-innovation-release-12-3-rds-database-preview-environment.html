Amazon RDS for MariaDB

🐬 MariaDB 12.3 をプレビュー環境で
GA 前に評価可能に

2026-06-15
リリース日

📌 概要

Amazon RDS for MariaDB が Amazon RDS Database Preview Environment において MariaDB 12.3 をサポートしました。最新の長期サポート (LTS) リリースを、 一般提供 (GA) 開始前にマネージドなサンドボックスで評価できます。

本番環境に影響を与えることなく、新機能の検証や既存アプリケーションとの互換性確認が可能です。 対象はデータベース管理者、アプリケーション開発者、移行を計画しているお客様です。

⛔ アップデート前の課題
  • GA 前に新メジャーバージョンを RDS 上で評価する手段がなかった
  • 検証には GA を待つか自己管理環境の構築が必要
  • 本番リリース直前に短期間で互換性確認するリスク
➡️
✅ アップデート後の改善
  • MariaDB 12.3 を GA 前にプレビュー環境で評価可能
  • マネージドなサンドボックスで自己構築が不要
  • 本番と隔離した環境で検証を前倒しで実施

米国東部 (オハイオ) リージョンで MariaDB 12.3 インスタンスを起動し、テスト用アプリケーションから接続して検証。 インスタンスは最大 60 日間保持され、保持期間後に自動削除されます。

⚡ MariaDB 12.3 の主要機能

🔄 Oracle TO_DATE() 互換

Oracle の TO_DATE() と互換性のある関数を追加。Oracle 併用環境での日付文字列変換が容易に。

📋 SQL 標準 IS JSON 述語

ネイティブな JSON 検証をサポート。カラムや式が有効な JSON か標準構文で検証可能。

🗂️ 基本的な XML データ型

基本的な XML データ型を追加。XML データの格納と取り扱いをサポート。

📍 プリペアドステートメントのカーソル

プリペアドステートメント上でカーソルを利用できるように。

✂️ CTE 読み取りを伴う UPDATE/DELETE

共通テーブル式 (CTE) からの読み取りが可能に。複雑な更新・削除ロジックを簡潔に記述。

🚀 クエリオプティマイザの改善

並べ替え可能な LEFT JOIN の処理効率化、RANGE パーティションの順序付きスキャン効率向上。

🛠️ 設定方法

前提条件

✓AWS アカウントを保有していること
✓RDS Database Preview Environment へのアクセス権を持つ IAM 権限
✓米国東部 (オハイオ) リージョンを利用できること

ステップ 1: プレビュー環境のコンソールにアクセス

RDS Database Preview Environment 専用のコンソール URL からアクセス。通常の RDS コンソールとは別エンドポイントです。

ステップ 2: MariaDB 12.3 インスタンスの作成

Bash AWS CLI でプレビューインスタンスを作成 
aws rds create-db-instance \
    --db-instance-identifier mariadb-12-3-preview \
    --db-instance-class db.r6g.large \
    --engine mariadb \
    --engine-version 12.3 \
    --allocated-storage 20 \
    --master-username admin \
    --master-user-password <password> \
    --region us-east-2

ステップ 3: アプリケーションの検証

作成したインスタンスにテスト用アプリケーションから接続し、新機能や既存機能の互換性を検証。検証完了後はスナップショットで結果を保全できますが、プレビュー環境内でのみ利用可能な点に注意してください。

🎯 ユースケース

1. Oracle からの移行検証

シナリオ: Oracle から MariaDB への移行を計画する企業が、TO_DATE() など Oracle 互換関数の挙動を事前確認したい。
SQL
SELECT TO_DATE('2026-06-15', 'YYYY-MM-DD');
✅ 効果: 互換関数が期待どおり動作することを GA 前に確認し、移行作業の手戻りを削減。

2. JSON データの検証強化

シナリオ: JSON データを扱うアプリで、格納値が有効な JSON であることを SQL 標準構文で検証したい。
SQL
SELECT * FROM orders WHERE payload IS JSON;
✅ 効果: ネイティブな JSON 検証を標準述語で記述でき、アプリ側の検証ロジックを簡素化。

3. クエリ性能改善の評価

シナリオ: LEFT JOIN を多用する分析クエリや RANGE パーティションテーブルで、12.3 のオプティマイザ改善による性能向上を測定したい。
SQL
SELECT a.id, b.value
FROM orders a
LEFT JOIN order_items b ON a.id = b.order_id
ORDER BY a.created_at;
✅ 効果: 代表的なクエリで性能を比較検証し、バージョンアップ効果を定量的に把握。

📝 まとめ

Amazon RDS for MariaDB が MariaDB 12.3 をプレビュー環境でサポートしたことで、最新の長期サポートリリースを GA 前にマネージドなサンドボックスで評価できるようになりました。 Oracle 互換関数、IS JSON 述語、XML データ型、CTE を伴う更新・削除、オプティマイザ改善など多くの新機能が含まれます。 移行を検討中のお客様は、米国東部 (オハイオ) のプレビュー環境でアプリケーション互換性と性能を早期に検証することを推奨します。
