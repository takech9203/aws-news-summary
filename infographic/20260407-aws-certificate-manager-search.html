AWS Certificate Manager

🔐 ネイティブ証明書検索機能

SearchCertificates API + コンソール検索バーで証明書管理を効率化
📅 2026-04-07

📋 概要

AWS Certificate Manager (ACM) にネイティブの証明書検索機能が追加されました。コンソールの新しい検索バーと新規 SearchCertificates API により、ドメイン名、証明書 ARN、有効期限などの複数パラメータを使用して証明書を効率的に検索できます。

大規模環境では数百から数千の証明書管理が必要であり、目的の証明書を迅速に特定することが運用上の重要課題でした。今回のアップデートにより、コンソールと API の両方から柔軟な検索条件で証明書を検索でき、管理効率が大幅に向上します。

全リージョン パブリック / China / GovCloud
18+ ソート基準
And / Or / Not 論理演算子サポート
追加料金なし ACM 標準機能として提供

🔄 Before / After

❌ Before
  • コンソールは一覧表示のみ、条件指定の検索不可
  • 大量の証明書を手動スクロールで確認が必要
  • API は ListCertificates の基本フィルタのみ
  • 複数属性を組み合わせた検索に非対応
✅ After
  • コンソール検索バーでドメイン名 / ARN / 有効期限等で即座に検索
  • SearchCertificates API で And/Or/Not の複合条件構築が可能
  • X.509 属性、ACM メタデータ、キーアルゴリズム等の多様なフィルタ
  • 作成日、有効期限、ステータスなど多数の基準でソート可能

⚡ 主要機能

🖥️ コンソール検索バー
  • ACM コンソールに統合された検索バーで直感的に証明書を検索可能
  • ドメイン名、証明書 ARN、証明書の有効期限などのパラメータに対応
  • 複数のパラメータを組み合わせた検索が可能
🔌 SearchCertificates API
  • プログラマティックな証明書検索を実現する新規 API
  • And、Or、Not の論理演算子をサポートし、再帰的に複合条件を構築可能
  • ページネーション対応 (MaxResults + NextToken)
  • 多様なソート基準とソート順序の指定が可能
🔍 豊富なフィルタ条件
  • X.509 属性: CommonName、DNS 名、KeyAlgorithm、KeyUsage、ExtendedKeyUsage、SerialNumber、NotAfter、NotBefore
  • ACM メタデータ: Status、RenewalStatus、Type、InUse、Exported、ExportOption、ManagedBy、ValidationMethod
  • CertificateArn による直接指定
  • 文字列フィルタで CONTAINS / EQUALS の比較演算子を使用可能

🛠️ 設定方法・コードサンプル

ステップ 1: コンソールでの検索

ACM コンソールにアクセスし、画面上部の検索バーにドメイン名や証明書 ARN を入力して検索を実行します。

ステップ 2: AWS CLI での検索

Bash ドメイン名による検索 - 有効期限の昇順 
aws acm search-certificates \
  --filter-statement '{
    "Filter": {
      "X509AttributeFilter": {
        "Subject": {
          "CommonName": {
            "Value": "example.com",
            "ComparisonOperator": "CONTAINS"
          }
        }
      }
    }
  }' \
  --sort-by NOT_AFTER \
  --sort-order ASCENDING

ステップ 3: 複合条件での検索

Bash And 演算子による複合条件 
aws acm search-certificates \
  --filter-statement '{
    "And": [
      {
        "Filter": {
          "AcmCertificateMetadataFilter": {
            "Status": "ISSUED",
            "Type": "AMAZON_ISSUED"
          }
        }
      },
      {
        "Filter": {
          "X509AttributeFilter": {
            "KeyAlgorithm": "RSA_2048"
          }
        }
      }
    ]
  }' \
  --sort-by CREATED_AT \
  --sort-order DESCENDING

ステップ 4: Python SDK での検索

Python 有効期限が迫る使用中の証明書を検索 
import boto3
from datetime import datetime

client = boto3.client('acm')

response = client.search_certificates(
    FilterStatement={
        'And': [
            {
                'Filter': {
                    'AcmCertificateMetadataFilter': {
                        'Status': 'ISSUED',
                        'InUse': True
                    }
                }
            },
            {
                'Filter': {
                    'X509AttributeFilter': {
                        'NotAfter': {
                            'Start': datetime(2026, 4, 1),
                            'End': datetime(2026, 6, 30)
                        }
                    }
                }
            }
        ]
    },
    SortBy='NOT_AFTER',
    SortOrder='ASCENDING',
    MaxResults=50
)

for cert in response['Results']:
    arn = cert['CertificateArn']
    common_name = cert['X509Attributes']['Subject']['CommonName']
    not_after = cert['X509Attributes']['NotAfter']
    print(f"{common_name} - {arn} - Expires: {not_after}")

✅ メリット

💼 ビジネス面

  • 大量の証明書から目的の証明書を迅速に特定でき、管理時間を大幅に削減
  • 有効期限が迫る証明書や特定キーアルゴリズムの証明書を即座にリストアップし、監査対応を効率化
  • 問題発生時に関連する証明書を即座に特定でき、障害対応時間を短縮

🔧 技術面

  • And/Or/Not の論理演算子による複合条件の構築で高度な検索ニーズに対応
  • SearchCertificates API で証明書の棚卸しや期限管理の自動化ワークフローを構築可能
  • 18 種類のソート基準により必要な観点で結果を整理して確認可能

⚠️ デメリット・制約事項

制限事項

  • SearchCertificates API のスロットリング制限が適用される可能性がある
  • 大量の結果取得にはページネーションによる複数回の API 呼び出しが必要
  • FilterStatement の再帰的な構造には深さの制限がある可能性がある

考慮すべき点

  • 既存の ListCertificates API との使い分けを検討する必要がある
  • IAM ポリシーで acm:SearchCertificates アクションの権限を適切に設定する必要がある
  • 複雑なクエリのテストと検証が推奨される

🎯 ユースケース

📅 有効期限が迫る証明書の一括確認
セキュリティチームが 90 日以内に期限切れとなる証明書を定期的に確認し、更新漏れを防止する。NotAfter フィルタとステータスフィルタの And 条件を使用して、有効期限順にリストアップ。
✅ 更新が必要な証明書を有効期限順にリストアップし、計画的な証明書更新を実現
🌐 特定ドメインの証明書管理
複数のサブドメインを持つ大規模 Web アプリケーションで、特定のドメインに関連する証明書をすべて把握する。DnsName フィルタの CONTAINS 演算子で部分一致検索。
✅ ワイルドカード証明書やサブドメイン証明書を含むすべての関連証明書を網羅的に把握
🛡️ セキュリティ監査のための証明書棚卸し
セキュリティ監査に備え、インポートされた証明書のうち現在使用中でないものを特定してクリーンアップする。Type=IMPORTED かつ InUse=False の条件で検索。
✅ 未使用のインポート証明書を特定し、セキュリティポスチャの改善とコスト最適化を実現
