AWS Site-to-Site VPN

🔒 既存 VPN 接続のトンネル帯域幅変更

接続を再作成せずに帯域幅を standard / large 間で柔軟にスケール

📅 2026-05-06

📋 概要

AWS Site-to-Site VPN で、既存の VPN 接続のトンネル帯域幅を standard (最大 1.25 Gbps) と large (最大 5 Gbps) の間で変更できるようになりました。接続を削除・再作成することなく、帯域幅を柔軟にスケールできます。

🔄 Before / After 比較

❌ Before

  • 帯域幅変更には VPN 接続を削除して再作成が必要
  • 新しいトンネル IP が生成され、オンプレミス VPN デバイスの再設定が必要
  • ファイアウォールルール変更とセキュリティチーム調整が発生
  • ダウンタイムとオペレーションの複雑さで迅速なスケーリングが困難

✅ After

  • modify-vpn-connection-options コマンドで帯域幅を直接変更
  • トンネル IP、CIDR、事前共有鍵、全設定が保持される
  • オンプレミス VPN デバイスやファイアウォール変更が不要
  • ビジネス要件に応じた迅速な帯域幅スケーリングが可能

⚡ 主要機能

🔧 インプレース帯域幅変更

既存の VPN 接続を削除せずに帯域幅を standard から large、または large から standard に変更可能。両方のトンネルが同じ帯域幅設定でなければならず、Transit Gateway または Cloud WAN にアタッチされた VPN 接続でのみ利用可能。

🔐 設定の完全保持

トンネル IP アドレス、CIDR ブロック、事前共有鍵 (Pre-Shared Key)、ルーティング設定、IKE/IPsec パラメータなど全ての設定が変更なしで継続。

📊 帯域幅オプション

standard: トンネルあたり最大 1.25 Gbps (デフォルト)、large: トンネルあたり最大 5 Gbps。2 本のトンネルで合計最大 10 Gbps の帯域幅を実現。

📐 技術仕様

帯域幅オプション比較

項目 standard large
トンネルあたり最大帯域幅 1.25 Gbps 5 Gbps
接続あたり最大帯域幅 2.5 Gbps 10 Gbps
対応アタッチメント Transit Gateway / Cloud WAN / Virtual Private Gateway Transit Gateway / Cloud WAN のみ
Accelerated VPN サポート 非サポート
MTU 1,500 bytes 1,500 bytes
接続料金 標準料金 $0.60/hr

制約事項

  • Transit Gateway または Cloud WAN へのアタッチメントが必須
  • 両トンネルとも同一帯域幅設定が必要
  • カスタマーゲートウェイは固定 IP アドレスのみ (IP なし CGW は非対応)
  • Accelerated VPN は Large Bandwidth Tunnel では非対応
  • NAT-T ポートはトンネル確立中の変更に非対応
  • 断片化が必要なパケットはパフォーマンス低下の可能性あり

🛠️ 設定方法

前提条件

  • 既存の Site-to-Site VPN 接続が Transit Gateway または Cloud WAN にアタッチされていること
  • カスタマーゲートウェイに固定 IP アドレスが設定されていること
  • IAM に ec2:ModifyVpnConnectionOptions 権限があること

💡 メリット

📈 ビジネス面

  • 運用コスト削減: メンテナンスウィンドウやチーム間調整が不要
  • ダウンタイム最小化: 接続再作成不要でサービス中断リスク低減
  • 俊敏なスケーリング: ビジネスイベントや季節変動に迅速対応

🔧 技術面

  • 設定の一貫性: IP アドレスや暗号化パラメータが保持
  • ECMP 代替: 複雑な ECMP 設定なしで高帯域幅を実現
  • オペレーション簡素化: 単一 API コールで完了

⚠️ デメリット・考慮事項

  • Virtual Private Gateway にアタッチされた VPN 接続では利用不可 (Transit Gateway / Cloud WAN 必須)
  • 両トンネルが同一帯域幅必要。片方だけのアップグレードは不可
  • IP アドレスなしのカスタマーゲートウェイでは Large Bandwidth Tunnel 使用不可
  • Accelerated VPN との併用は不可
  • Large Bandwidth Tunnel は接続料金が高い ($0.60/hr vs 標準料金)
  • 帯域幅変更中にトンネルの短時間中断の可能性あり (冗長構成を推奨)
  • MTU は 1,500 bytes。フラグメンテーションが必要なパケットではパフォーマンス低下の可能性

🎯 ユースケース

🛒 季節変動への対応

EC サイトのブラックフライデーやセール期間中に、オンプレミスのデータセンターと AWS 間のデータ転送量が大幅に増加するケース。セール開始前に帯域幅を拡大し、終了後に縮小してコスト最適化。

Bash セール期間の帯域幅制御 
# セール開始前に帯域幅を拡大
aws ec2 modify-vpn-connection-options \
    --vpn-connection-id vpn-1234567890abcdef0 \
    --tunnel-bandwidth large

# セール終了後に帯域幅を縮小してコスト最適化
aws ec2 modify-vpn-connection-options \
    --vpn-connection-id vpn-1234567890abcdef0 \
    --tunnel-bandwidth standard
✅ オンプレミス側の設定変更なしで、ピーク時に最大 10 Gbps の帯域幅を確保し、通常時はコストを抑制

🔗 Direct Connect バックアップの強化

10 Gbps の Direct Connect をプライマリとし、Site-to-Site VPN をバックアップとして構成。フェイルオーバー時に帯域幅を動的に確保。

Bash Direct Connect 障害時の帯域幅制御 
# Direct Connect 障害検知時に VPN 帯域幅をアップグレード
aws ec2 modify-vpn-connection-options \
    --vpn-connection-id vpn-backup-connection \
    --tunnel-bandwidth large

# Direct Connect 復旧後にコスト最適化
aws ec2 modify-vpn-connection-options \
    --vpn-connection-id vpn-backup-connection \
    --tunnel-bandwidth standard
✅ Direct Connect 障害時にも高帯域幅バックアップを動的に確保し、ビジネス継続性を維持

🚀 段階的なクラウド移行

大規模データ移行プロジェクトで、移行フェーズに応じてオンプレミスから AWS への転送帯域幅を段階的に増加。移行期間中のみ高帯域幅を確保し、完了後は standard に戻してコスト最適化。

✅ コストを最適化しながら移行スケジュールを短縮

🔗 関連サービス

🔀 AWS Transit Gateway

Large Bandwidth Tunnel を利用するために必要なルーティングハブ。複数 VPC と VPN 接続を集約管理。

🌐 AWS Cloud WAN

グローバルネットワーク構築・管理サービス。Large Bandwidth Tunnel の接続先として利用可能。

🔌 AWS Direct Connect

専用線接続サービス。Site-to-Site VPN と組み合わせて冗長性を確保するアーキテクチャで使用。

📊 VPN CloudWatch メトリクス

トンネルの帯域幅使用率を監視し、スケーリング判断に活用。
