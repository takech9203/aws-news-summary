Amazon Connect (Customer)

🖍️ エージェント画面録画向け
ルールベースの墨消し

2026-06-30
リリース日

📌 概要

Amazon Connect Customer が、エージェント画面録画に映り込んだ機密情報をルールに基づいて自動的に墨消し (レダクション) できる機能をサポートしました。

管理者は特定のアプリケーションウィンドウや URL を対象とするルールを定義し、録画に映り込んだ該当コンテンツを自動でマスクできます。墨消しは録画のアセンブル時 (コンタクト終了後) に適用され、マスクされた墨消し版とオリジナル版の両方が Amazon S3 に別々のプレフィックスで保存されます。セキュリティプロファイルの権限でアクセス範囲を個別に制御できます。

😟 アップデート前の課題

  • クレジットカード入力画面や機密アプリが映り込んでも、自動でマスクする手段がなかった
  • 記録が禁止されたページがある場合、録画機能そのものの利用を制限せざるを得なかった
  • 通話音声は Contact Lens で墨消しできたが、画面録画の映像は対象外だった

😊 アップデート後の改善

  • URL / ウィンドウタイトルルールで該当ページやウィンドウを自動マスク
  • 墨消し版とオリジナル版を別保存し、権限をセキュリティプロファイルで個別制御
  • コンタクトフロー内で設定し、キューや属性に応じて異なるルールを適用可能

エージェントの画面がクライアントアプリで録画され、フローで定義したルールに基づきコンタクト終了後にマスク処理され、オリジナル版と墨消し版が S3 に別々に保存される。

✨ 主要機能

🎯 1. ルールベースの自動墨消し
  • エージェントが閲覧した各ブラウザページ・アプリウィンドウを設定ルールと照合
  • 一致したウィンドウは最終録画でマスクされ、それ以外はそのまま残る
  • リアルタイムではなく、コンタクト終了後の録画アセンブル時に適用

🔀 2. 2 つの墨消しモード

Denylist — 拒否リスト
ルールに一致したコンテンツのみをマスクし、他はすべて表示。幅広いアプリを扱い、特定の機密ページのみ隠したい場合に使用。
Allowlist — 許可リスト
ルールに一致したコンテンツのみを表示し、他はすべてマスク。承認された少数のアプリのみで作業する場合に使用。
📋 3. 2 種類のルール
  • URL ルール: ブラウザのアドレスバーの URL と照合。ブラウザ拡張機能が必要で Chrome / Edge / Firefox でサポート
  • ウィンドウタイトルルール: デスクトップアプリや対象外ブラウザなど、ネイティブアプリのウィンドウタイトルと照合
🗂️ 4. 墨消し版とオリジナル版の分離保存
  • 墨消し版はオリジナルと同じ S3 バケット内の別プレフィックスに保存
  • 2 つの新しいセキュリティプロファイル権限で、閲覧・ダウンロードを個別制御

🔐 新しいセキュリティプロファイル権限

セキュリティプロファイルの Recordings and Transcripts カテゴリに 2 つの権限が追加されました。

権限付与される操作
Screen recording (redacted) - Accessコンタクト詳細ページのメディアプレーヤーを開き、墨消し版の画面録画を閲覧する
Screen recording (redacted) - Enable download button墨消し版の画面録画をダウンロードする (Access 権限が前提)

ユーザーが墨消し版とオリジナル版の両方のアクセス権を持ち、そのコンタクトで墨消しが有効化されていた場合、詳細ページには墨消し版が表示されます。

⚙️ 設定方法

✅ 前提条件

  • Connect Customer インスタンスでエージェント画面録画を有効化
  • ワークステーションがルールベース墨消しの要件 (Windows) を満たすことを確認
  • クライアントアプリを v3.0.2 以降に更新
  • 録画対象コンタクトで使用する全ブラウザに Connect Customer ブラウザ拡張機能をデプロイ

📝 手順

1
フローブロックの追加

対象コンタクトフローに Set recording, analytics, and processing behavior ブロックを追加。[Config] タブで [Select action] に Set recording and analytics behavior、[Select channel] に Screen recording を選択。

2
墨消しの有効化とモード選択

[Enable screen recording] を選択後、[Redaction configuration] を展開し [Enable redaction] を選択。[Mode] で Allowlist または Denylist を選択して動作方針を決定。

3
ルールの定義とフローの公開

[URL rules] と [Window title rules] にルールを追加し、各ルールで比較タイプとパターンを設定。両タイプを同一ブロックに混在可能。保存・公開後、新規コンタクトから適用され、進行中コンタクトには影響しない。

💡 メリット

💼 ビジネス面

  • コンプライアンス強化: 記録禁止のページやアプリを自動マスクし露出リスクを低減
  • 録画活用範囲の拡大: 映り込みを理由に躊躇していた録画をより広範に活用
  • アクセス権の分離: 墨消し版は広範に公開、オリジナルは限定担当者のみ

🛠️ 技術面

  • 柔軟な制御: フロー内設定でキューや属性ごとに異なるルールセットを適用
  • 設定の再利用: フローモジュールに配置し複数フロー間で共有・一元管理
  • 既存フローへの影響なし: 終了後に適用されるためリアルタイム処理に影響しない

⚠️ デメリット・制約事項

🚫 制限事項

  • Windows のみが対象 OS。他の OS はサポートされない
  • URL ルールは Chrome / Edge / Firefox でのみ一致。他ブラウザはウィンドウタイトルルールで対応
  • フィールド単位の墨消し不可。一致したウィンドウ全体がマスクされる
  • 音声・チャットは対象外。通話録音の墨消しは Contact Lens を別途使用
  • ルール数は最大 100 件、各パターンは 1 から 128 文字

🤔 考慮すべき点

  • 墨消し版はオリジナルに加えて生成されるためストレージ使用量が増加。S3 ライフサイクルポリシーの設定を検討
  • ルール一致には全対象ブラウザに拡張機能のデプロイが必要
  • 事後適用のため、進行中コンタクトへの設定変更は反映されない

🎬 ユースケース

1. 決済ページとレガシー業務アプリの墨消し
シナリオ: 社内 CRM の決済入力ページと、レガシー請求アプリのウィンドウを録画から隠したい。
ConfigDenylist モード
モード: Denylist - hide matching content
URL ルール:
  - Begins with : https://crm.example.com/contacts/
  - Contains    : /payment
ウィンドウタイトルルール:
  - Contains    : Legacy Billing App
効果: 機密性の高い決済画面と特定アプリのみが自動マスクされ、他はコーチング用にそのまま確認できる。
2. 承認済みアプリのみを表示
シナリオ: 少数の承認済みアプリのみで作業する環境で、それ以外の画面をすべて隠したい。
ConfigAllowlist モード
モード: Allowlist - show matching content
URL ルール:
  - Begins with : https://connect.example.com/
  - Begins with : https://crm.example.com/
  - Begins with : https://knowledge.example.com/
ウィンドウタイトルルール:
  - Contains    : Amazon Connect Client
  - Contains    : Company CRM
効果: 承認済みのアプリとサイトのみが録画に残り、想定外・私的なウィンドウは自動マスクされる。
3. キューごとに異なる墨消しを適用
シナリオ: 金融部門のキューと一般問い合わせのキューで、異なる墨消しルールを適用したい。
Configフロー分岐
フローを各キューへのルーティング前に分岐させ、
分岐ごとに Set recording, analytics, and processing behavior ブロックを配置。
各ブロックで異なるモードとルールセットを設定する。
共通ルールはフローモジュールに配置して複数フローで再利用する。
効果: 業務内容に応じた粒度の異なる墨消しポリシーを、単一の Connect インスタンス内で運用できる。

💰 料金・利用可能リージョン

💵 料金

ルールベース墨消しの追加料金は Amazon Connect の料金ページを参照。画面録画は Contact Lens の機能として提供され、利用料金が発生します。

🌎 リージョン

Connect Customer のエージェント画面録画をサポートするすべての AWS リージョンで利用可能。対象ワークステーションの OS は Windows のみ。

🔗 関連サービス・機能

  • Amazon Connect Contact Lens: 画面録画機能の基盤。通話音声の墨消しは Contact Lens 側で設定
  • Amazon S3: オリジナル版と墨消し版を保存。ライフサイクルポリシーで保持期間を制御
  • Connect Customer ブラウザ拡張機能: URL ルールを機能させるため各ブラウザへのデプロイが必要
  • セキュリティプロファイル: 墨消し版・オリジナル版の閲覧とダウンロード権限を制御

🎯 まとめ

エージェント画面録画向けルールベースの墨消しは、URL やウィンドウタイトルのルールで機密コンテンツを自動マスクし、コンプライアンスを維持しながら録画の活用範囲を広げる機能です。墨消し版とオリジナル版の分離保存とセキュリティプロファイル権限により、アクセス制御も柔軟に行えます。

画面録画を利用・検討中の組織は、クライアントアプリの v3.0.2 以降への更新とブラウザ拡張機能のデプロイを準備し、コンタクトフローで墨消しルールの設定を検討することを推奨します。
