📋 概要

AWS Transform のエージェント機能が、Kiro、Claude、Cursor、Codex といった主要な AI 開発環境から直接利用可能になりました。

AWS Transform は数十年にわたる AWS のマイグレーション / モダナイゼーション経験に基づいて構築されたエージェント AI サービスで、Windows、VMware、メインフレームなどのレガシーシステムのモダナイゼーションを支援します。

開発者は Kiro Power、エージェントプラグイン、AWS Transform MCP サーバー の 3 つのインターフェースを通じて、好みの開発環境から AWS Transform の全機能にアクセスできるようになりました。

❌ Before

  • 操作は Web コンソールに限定
  • IDE 作業中にコンテキストの切り替えが必要
  • プログラマティックなアクセス手段がなく CI/CD 統合が困難
  • 認証方式が限定的

✅ After

  • Kiro, Claude, Cursor, Codex から直接利用可能
  • MCP サーバーで自動化ワークフロー連携
  • IAM ロール認証で既存クレデンシャルを活用
  • IDE と Web コンソールのシームレス連携

💡 ユースケース

🖥️ IDE 内でのレガシー .NET アプリケーションモダナイゼーション

.NET Framework アプリケーションを .NET 8 にアップグレード。Kiro を使用して日常の開発作業の中でモダナイゼーションを実行。

Bash Kiro Power でプロジェクト変換 
# Kiro Power を使用してプロジェクトの変換を開始
@transform upgrade --source ./legacy-app --target dotnet8

✅ 効果: IDE から離れずに変換の開始・監視・結果適用を完結。モダナイゼーション期間を短縮。

🔄 CI/CD パイプラインからの MCP 統合

大規模なマイクロサービス群のフレームワークバージョンを一括で更新するため、MCP サーバーを CI/CD パイプラインに組み込む。

JSON MCP サーバー設定 
{
  "mcpServers": {
    "aws-transform": {
      "command": "aws-transform-mcp-server",
      "args": ["--region", "us-east-1"],
      "env": {
        "AWS_ROLE_ARN": "arn:aws:iam::123456789012:role/TransformCIRole"
      }
    }
  }
}

✅ 効果: 数百のリポジトリに対する一括変換を自動化し、手動作業を大幅に削減。
