Kiro and Cursor IDEs as Remote IDEs
2026/03/26 AWS What's New

📋 Overview

Amazon SageMaker Studio が、Kiro および Cursor IDE からのリモート接続をサポートしました。データサイエンティスト、ML エンジニア、開発者は、Kiro のスペック駆動開発や自動機能生成、Cursor の会話型コーディングや AI コード補完といった各 IDE 固有の機能をそのまま活用しながら、SageMaker Studio のスケーラブルなコンピューティングリソースにアクセスできるようになります。

❌ Before

  • Kiro / Cursor の AI 支援機能とクラウドリソースの間でコンテキストスイッチが必要
  • リモート IDE サポートは VS Code に限定
  • Kiro のスペック駆動開発ワークフローをクラウド環境で活用する手段がなかった

✅ After

  • AWS Toolkit 拡張機能で SageMaker Studio に直接リモート接続が可能
  • 各 IDE 固有のエージェンティック開発ワークフローをクラウド上で活用可能
  • 単一環境で AWS の分析サービスや AI/ML サービスを利用可能

ローカルの Kiro / Cursor IDE から AWS Toolkit 拡張機能を介して SageMaker Studio にリモート接続し、クラウド上の開発環境や AI/ML サービスにアクセスする全体構成

🔑 Key Features

🤖 Kiro IDE からのリモート接続

  • スペック駆動開発ワークフローをクラウド環境で活用可能
  • ステアリングファイルやフックなどの Kiro 固有のカスタマイズをそのまま利用
  • 自動機能生成機能によるクラウド上での効率的な開発

🖥️ Cursor IDE からのリモート接続

  • AI パワードのコード補完機能をクラウドリソース上で利用可能
  • 会話型コーディングによる直感的な開発体験
  • マルチファイル編集機能による大規模プロジェクトの効率的な管理

🔐 AWS Toolkit 拡張機能による統合認証

  • Kiro / Cursor 内の AWS Toolkit 拡張機能を通じた IAM ベースの認証
  • SageMaker Studio の Web インターフェースからの認証にも対応
  • Web ベースの環境と同じセキュリティ境界を維持

⚙️ Setup

前提条件: Kiro / Cursor IDE がローカル環境にインストール済み、AWS アカウントと SageMaker Studio へのアクセス権限、AWS Toolkit 拡張機能がインストール済み

1

AWS Toolkit 拡張機能のインストール

Kiro / Cursor IDE の拡張機能マーケットプレイスから AWS Toolkit をインストール。両 IDE とも Code-OSS 互換のため、VS Code 互換の拡張機能が利用可能です。

2

AWS 認証情報の設定

AWS Toolkit 拡張機能を使用して認証情報を設定。IAM ユーザーまたは IAM Identity Center の認証情報でサインイン。SageMaker Studio の Web UI からの認証も可能です。

3

SageMaker Studio 開発環境への接続

認証完了後、AWS Toolkit から開発環境一覧を確認し、接続先を選択。数クリックで接続が完了し、ローカル IDE の全機能をクラウドリソース上で利用開始できます。

💡 Benefits / Limitations

📈 Business

✅
開発生産性の向上: コンテキストスイッチ不要で集中力と生産性が向上
✅
ツール選択の柔軟性: Kiro、Cursor、VS Code など最適な IDE を自由に選択可能
✅
導入コストの低減: 既存の IDE ライセンスと AWS 環境をそのまま活用

🔧 Technical

✅
エージェンティック開発のスケール: AI 機能とクラウドリソースの組み合わせ
✅
シームレスなワークフロー: プロトタイピングからクラウドスケール処理まで同一 IDE 内で完結
✅
セキュアな接続: Web ベースと同じセキュリティ境界、IAM 認証

⚠️ Limitations

⚠️ Kiro / Cursor は有償ソフトウェアのため、ライセンスコストが追加で発生
⚠️ リモート接続の安定性はネットワーク環境に依存
⚠️ 一部のローカル拡張機能がリモート環境では正常に動作しない場合がある
⚠️ IDE バージョンアップに伴い AWS Toolkit との互換性を定期的に確認する必要がある
⚠️ チーム内で複数 IDE 使用時は標準化と IDE 固有設定のバランス検討が必要

🎯 Use Cases

🤖 UC1: Kiro を活用したスペック駆動 ML 開発

ML エンジニアが Kiro のスペック駆動開発機能を活用し、ML パイプラインの仕様を定義。自動機能生成で実装を効率化しつつ、SageMaker Studio のスケーラブルなコンピューティングリソース上でトレーニングジョブを実行します。

効果: スペック駆動開発による設計から実装までの一貫したワークフローと、クラウドリソースによる大規模トレーニングの実行を両立

🖥️ UC2: Cursor を活用した AI 支援データ分析

データサイエンティストが Cursor の会話型コーディング機能を使用し、自然言語でデータ分析コードを記述。SageMaker Studio 上のリソースで大規模データセットの処理を実行します。

効果: AI 支援によるコーディング速度の向上と、クラウドリソースによる大規模データ処理の効率化

👥 UC3: マルチ IDE チームでの共同開発

チーム内で Kiro、Cursor、VS Code を使用する開発者が混在する環境で、全員が同じ SageMaker Studio の開発環境にアクセスし、統一されたインフラストラクチャ上で共同開発を行います。

効果: IDE の選択自由度を維持しながら、統一されたクラウドインフラストラクチャによるチーム開発の効率化
