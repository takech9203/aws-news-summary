Kiro CLI セッションから会話をエクスポートする流れと、モデル/エフォート設定が自動的に永続化される仕組み

📋 概要

Kiro CLI v2.6.0 がリリースされ、会話のポータビリティと作業復帰の効率化に焦点を当てた複数の新機能が追加された。

日々の開発ワークフローにおける「セッション管理の煩雑さ」を解消することを目的としている。

🔄 Before / After

Before

  • 会話の共有手段がコピペのみ
  • 複数ウィンドウの識別が困難
  • 設定変更を毎回手動で保存
  • 起動時にリーズニングレベル指定不可

After

  • /transcript save で 3 形式エクスポート
  • /title でウィンドウにラベル設定
  • 設定がセッション間で自動永続化
  • --effort フラグで起動時指定可能

✨ 主要機能

📤 トランスクリプトエクスポート

/transcript save で会話全体をファイルにエクスポート。Markdown、プレーンテキスト、JSON に対応。チーム共有やチケット添付に活用可能。

🏷️ ターミナルウィンドウタイトル

/title コマンドでウィンドウタイトルを設定/解除。複数セッション並行時のセッション識別に有効。

⚡ 起動時エフォート指定

kiro-cli chat --effort <level> でセッション開始時のリーズニングレベルを設定。low / medium / high / xhigh / max から選択。

💾 モデルとエフォートの永続化

/model と /effort の選択が自動的に次回セッション以降に引き継がれる。手動での set-current-as-default が不要に。

📖 コマンドリファレンス

コマンド 説明
/transcript save 会話をファイルにエクスポート
/transcript save --plain プレーンテキスト形式
/transcript save --json JSON 形式
/title <name> ターミナルタイトル設定
/title タイトルをクリア
kiro-cli chat --effort <level> エフォートレベル指定で開始

📊 エフォートレベル

レベル 用途
low 簡単な質問、クイックルックアップ
medium 一般的なコーディングタスク
high 複雑な実装、設計判断
xhigh 高度な分析、アーキテクチャ設計
max 最大限の推論が必要な複雑な問題

💻 設定方法

前提条件: Kiro CLI v2.6.0 以降 + 有効なアカウント

Bash トランスクリプトエクスポート 
# Markdown 形式で保存
/transcript save

# プレーンテキスト形式で保存
/transcript save --plain

# JSON 形式で保存
/transcript save --json
Bash ターミナルタイトル 
# タイトルを設定
/title backend-refactoring

# タイトルをクリア
/title
Bash エフォートレベル指定起動 
# 高い推論レベルで起動
kiro-cli chat --effort high

# 低い推論レベルで高速応答
kiro-cli chat --effort low

🎯 ユースケース

1. コードレビューの共有

Kiro とのリファクタリング議論後、/transcript save --plain でエクスポートし、PR の説明として活用。設計判断の根拠をチームに共有。

2. 複数プロジェクトの並行開発

/title frontend-react と /title backend-api でターミナルを識別。コンテキストスイッチのオーバーヘッドを削減。

3. タスクに応じたリーズニング使い分け

朝のスタンドアップ準備は --effort low で高速に。午後のアーキテクチャ設計は --effort max で深い分析。クレジット消費を最適化。

✅ メリット

  • + チームコラボレーション向上: AI との議論をチケットやドキュメントに添付し知識共有
  • + 作業コンテキストの保存: エクスポートした会話を参照資料として活用
  • + オンボーディング効率化: 過去の AI 会話で設計判断を伝達
  • + ワークフロー効率化: 設定の自動永続化で手動操作不要
  • + マルチセッション管理: タイトルで並行セッションを容易に管理
  • + 適応的リーズニング: コスト効率と応答品質のバランスを最適化

⚠️ 制約事項・注意点

  • エクスポート形式は 3 種類 (Markdown, Text, JSON) に限定
  • ターミナルタイトルはエミュレータのタイトル表示対応に依存
  • 高エフォートレベルはクレジット消費量が増加。プラン上限を考慮
  • エクスポートした会話にはコードやプロジェクト情報が含まれる可能性あり。共有先に注意
  • 永続化された設定は明示的に変更するまで維持。プロジェクト切替時はレベル見直し推奨
