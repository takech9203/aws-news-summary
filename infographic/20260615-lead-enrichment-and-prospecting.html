📅 リリース日: 2026 年 6 月 15 日

📌 概要

AWS パートナーが、AWS 提供または自社獲得のリードに対して AWS が生成する AI インサイトと適格性レコメンデーションを付加できる機能が登場しました。

各リードについて 購買傾向 (propensity-to-buy) シグナル、ソリューションカテゴリ整合性、3 つのプログラムへのアカウント適格性チェックを受け取り、データに基づいた見込み顧客の優先順位付けと精度の高い営業判断が可能になります。リードの提出はコンソールと API の両方に対応します。

⚖️ アップデート前後の変化

❌ Before（課題）
✗購買傾向や AWS Marketplace 経由での購入可能性を AWS シグナルとして取得できなかった
✗対象顧客のプログラム/資金提供の適格性をリード単位で自動確認できなかった
✗カテゴリ整合性を評価できず、優先順位付けが経験と手作業に依存していた
✅ After（改善）
✓リードごとに購買傾向シグナル（Marketplace 経由の購入可能性を含む）を取得
✓PGP・Pioneer Credits・Partner-Led Sales Motion の適格性を確認
✓コンソールと API の両方から提出し、データドリブンに優先順位付け

コンソールまたは API を通じて提出したリードが、エンリッチメント処理を経て購買傾向シグナル・カテゴリ整合性・プログラム適格性という AI 生成インサイトとして返される流れを示します。

⚙️ 主要機能

📈 購買傾向シグナル (Propensity-to-buy)

  • 各リードについて、顧客が購入に至る可能性を示すシグナルを提供
  • AWS Marketplace 経由で購入する可能性を含む
  • データに基づいて見込み顧客の確度を評価できる

🗂️ ソリューションカテゴリ整合性

  • リードがどのソリューションカテゴリに整合するかのインサイトを提供
  • 提供ソリューションと見込み顧客ニーズの適合度を把握できる

✅ アカウント適格性チェック

以下の 3 つのプログラムに対する対象アカウントの適格性を確認します。

🌱 Partner Greenfield Program (PGP) 💳 Pioneer Credits 🤝 Partner-Led Sales Motion

🖥️ コンソールと API による提出

  • AWS Partner Central コンソールからの手動提出に対応
  • Partner Central API でプログラムから提出し、既存営業ワークフローへ統合可能

  • AWS Partner Central へのアクセス権を持つこと
  • API 利用時は Partner Central Selling API への適切な IAM 権限を構成していること

💡 メリット

ビジネス面

  • ✓営業の優先順位付けの高度化: 購買傾向シグナルで成約確度の高い見込み顧客にリソースを集中
  • ✓資金プログラム活用の最大化: PGP・Pioneer Credits・Partner-Led Sales Motion の適格性を事前に把握し、活用機会を逃さない
  • ✓AWS Marketplace 経由の販売促進: Marketplace 経由の購入可能性を把握し取引を後押し

技術面

  • ✓API による自動化: リード提出とインサイト取得を自動化し、既存 CRM や営業ツールへ統合
  • ✓データドリブンな評価: 経験や手作業ではなく AWS が生成するデータでリードを評価
  • ✓コンソールと API の選択肢: 規模や用途に応じて使い分け可能

🎯 ユースケース

1. 見込み顧客の優先順位付け

シナリオ多数のリードを抱えるパートナーが、限られた営業リソースをどの顧客に充てるべきか判断したい。

効果購買傾向シグナルを参照し、成約確度の高いリードを優先的にフォローして営業効率を高められる。

2. 資金プログラムの適格性確認

シナリオ対象顧客にどの AWS パートナープログラムや資金提供を活用できるか把握したい。

効果PGP・Pioneer Credits・Partner-Led Sales Motion の適格性結果をもとに、活用可能なプログラムを早期に特定し提案に組み込める。

3. 営業ワークフローへの統合

シナリオ自社の CRM や営業システムとリード管理を連携させ、リード評価を自動化したい。

効果Partner Central API でリード提出とインサイト取得を自動化し、既存システムにデータドリブンな評価を組み込める。

⚠️ 制限事項・考慮点

制限事項

  • ▲API は現時点で米国東部 (バージニア北部) リージョンでのみ提供
  • ▲利用できるのは APN Customer Engagements (ACE) 対象 AWS パートナーに限られる
  • ▲適格性チェックの対象は PGP・Pioneer Credits・Partner-Led Sales Motion の 3 プログラム

考慮すべき点

  • ▲提供インサイトはあくまで判断を支援するシグナルであり、最終的な営業判断はパートナー側で行う必要がある
  • ▲API 活用時は適切な IAM 権限の設計とワークフローへの統合が必要

📝 まとめ

このアップデートにより、AWS パートナーはリードの質と成約可能性を データに基づいて評価し、営業判断を高度化できます。

購買傾向シグナルとプログラム適格性チェックを活用すれば、見込み顧客の優先順位付けと資金プログラムの活用を最適化できます。ACE 対象パートナーは、コンソールまたは API を通じてリードを提出し、AI 生成インサイトを営業プロセスに組み込むことを検討してください。
