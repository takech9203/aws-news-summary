クレジットメモの自動適用設定

💳 未払い請求書へのクレジットメモ充当方法を、コンソールから柔軟にコントロール
リリース日 2026.07.23 全商用リージョン対応

📌 概要

AWS は、電子資金振替 (EFT) で支払うお客様向けに、クレジットメモ (credit memo) を未払いの請求書へ自動適用する方法を設定できる機能を追加しました。コンソールの [Payment preferences] ページから、自社の支払いプロセスに合わせて適用方法を選択できます。

クレジットメモとは、過払いや調整によって生じた金額をお客様の未払い請求書に充当するために AWS が発行する貸方伝票です。今回のアップデートにより、元の請求書・将来の請求書・最も古い未払い請求書への適用を組み合わせて指定できるようになりました。デフォルトでは、まず元の請求書に適用され、その後は将来の請求書に適用されます。

❌ アップデート前の課題
  • クレジットメモは元の請求書のみに適用するデフォルト動作だった
  • 元の請求書がクローズ済みだと未適用のまま残り、他の請求書へ充当されなかった
  • 自社の会計処理や消込プロセスに合わせて適用方法を選ぶ手段がなかった
→
✅ アップデート後の改善
  • コンソール上で 5 種類の適用方法から選択可能に
  • 元の請求書・将来の請求書・最古の未払い請求書への適用を組み合わせ可能
  • 設定は保存後すぐに反映され、柔軟な運用が可能に

🔧 主要機能

1️⃣ 5 種類のクレジットメモ適用方法

  • 元の請求書に優先適用し、残額を将来の請求書へ (推奨・現行デフォルト)
  • 元の請求書に優先適用し、残額を最も古い未払い請求書へ
  • 元の請求書のみに適用 (旧デフォルト)
  • 将来の請求書に適用
  • 最も古い未払い請求書に適用

2️⃣ コンソールからのセルフサービス設定

  • [Payment preferences] > [Balance application preferences] タブから設定
  • [Credit memo application strategy] で方法を選び [Save preferences] で保存
  • 変更はすぐに反映され、以降すべてのクレジットメモ適用に適用

3️⃣ 適用時の通知と履歴確認

  • 適用時に請求先連絡先 (ルート/代替/追加) へメール通知が送信
  • 通知にはクレジットメモ番号、適用合計額、適用先請求書、残額を記載
  • 未適用分は [Payments] > [Unapplied funds] タブで確認可能

📋 適用方法の一覧

🧾 元の請求書優先 → 将来推奨/現行デフォルト
対象請求書がオープンならそこに適用し、残額は次の対象となる将来の請求書へ順次適用。
🧾 元の請求書優先 → 最古
対象請求書に適用し、残額は最も古い未払い請求書へ適用。
🧾 元の請求書のみ旧デフォルト
対象請求書がオープンな場合のみ適用。クローズ済みなら未適用のまま残る。
🗓️ 将来の請求書
クレジットメモを保留し、次の対象となる将来の請求書へ適用。
🗓️ 最古の請求書
最も古い未払い請求書へ適用。

⚙️ 適用ロジック

項目詳細
全額適用クレジットメモの金額が対象請求書の残高以下の場合、全額が適用される
一部適用金額が単一請求書の残高を超える場合、まずその請求書に適用し、残額は設定に応じて追加の請求書へ
複数請求書への適用最古の請求書を対象とする設定では、古い請求書から順に消費されるまで適用

🛠️ 設定方法

前提条件：EFT で支払う AWS アカウントであること (クレジットカード等では [Balance application preferences] タブが非表示)。コンソールへのアクセス権限が必要。

1

Payment preferences ページを開く

AWS Billing and Cost Management コンソールを開き、ナビゲーションペインで [Payment preferences] を選択。

2

Balance application preferences タブを選択

[Balance application preferences] タブを開き、[Credit memo application strategy] セクションで現在の適用方法を確認。

3

適用方法を選択して保存

希望する適用方法を選び [Save preferences] を選択。変更はただちに反映され、以降のすべての適用に適用される (適用済み分は影響を受けない)。

⚖️ メリットと制約事項

👍 メリット

✓社内プロセスとの整合：消込作業や会計ルールに合わせて適用先を制御
✓未適用残高の削減：クローズ済みでも将来/最古の請求書へ自動充当
✓透明性の向上：適用のたびにメール通知で適用先・残額を把握
✓即時反映・追加コストなし：コンソールから無料で即設定変更

⚠️ 制約・考慮点

✗EFT 支払いアカウントのみ対象 (クレジットカード等は不可)
✗クレジットメモのみ対象。プロモーションクレジットには影響しない
✗AWS Marketplace 発行分は元の請求書にのみ適用
!同じ販売者・同じ通貨の請求書にのみ適用可能
!設定変更は将来の適用のみに影響 (適用済みは変更されない)

💡 ユースケース

ユースケース 1: 未払い残高の早期解消

シナリオ: 複数の未払い請求書を抱える企業が、最も古い請求書から充当して延滞を早期に解消したい。
Strategy
Credit memo application strategy: 最古の請求書に適用
効果: 最も古い未払い請求書から順に適用され、延滞リスクの高い残高を優先的に削減。

ユースケース 2: 元の請求書との対応関係を維持

シナリオ: 会計上、クレジットメモを対象の元の請求書に紐付けて処理する必要がある企業。
Strategy
Credit memo application strategy: 元の請求書のみに適用
効果: 必ず元の請求書に対応付けられ消込追跡が容易。ただしクローズ済みの場合は未適用として残る点に留意。

ユースケース 3: 将来の支払い負担の平準化

シナリオ: キャッシュフロー管理のため、クレジットメモを将来の請求書に充当して今後の支払い額を抑えたい企業。
Strategy
Credit memo application strategy: 将来の請求書に適用
効果: クレジットメモが保留され、次の対象請求書へ順次適用されるため将来の支払い額が軽減。

💰 料金・利用可能リージョン・関連サービス

本機能は AWS Billing and Cost Management の一部として 追加費用なしで利用可能。適用設定を変更しても追加料金は発生しません。すべての商用 AWS リージョンで利用できます。

AWS Billing and Cost Management — 本機能を提供、[Payment preferences] で設定
AWS プロモーションクレジット — 本設定の影響を受けない
AWS Marketplace — 発行分は元の請求書にのみ適用

🎯 まとめ

このアップデートは、EFT で支払う AWS ユーザーがクレジットメモの適用方法を自社の会計プロセスに合わせて柔軟に制御できるようにするものです。追加費用なしでコンソールから即座に設定でき、未適用残高の削減や消込作業の効率化につながります。経理部門の方は、[Payment preferences] ページで自社に最適な適用方法を確認・設定することをおすすめします。
