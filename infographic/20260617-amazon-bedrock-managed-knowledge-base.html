Managed Knowledge Base

Amazon Bedrock GA 一般提供
📅 リリース日: 2026 年 6 月 17 日

📌 概要

エンタープライズデータに根拠付けされた本番環境レベルの AI エージェントを構築できる、 フルマネージドの検索拡張生成 (RAG) サービスが一般提供を開始しました。

ベクトルデータベース、データパイプライン、検索インフラを自前で運用することなく、 データの取り込み、ストレージ最適化、高度な検索を Amazon Bedrock に任せられます。 6 つのネイティブコネクタによる自動データ同期と、 価格性能比に最適化されたマネージドベクトルストレージを備え、 プロトタイプから本番環境への移行を高速化します。

⏪ アップデート前の課題

  • ベクトルデータベースの選定・プロビジョニング・運用を自身で実施する必要があった
  • 取り込み・埋め込み生成・同期処理のパイプラインを個別に実装する必要があった
  • マルチホップクエリのクエリプランニングや再ランキングを自前で組み込む必要があった

⏩ アップデート後の改善

  • ベクトルストレージとデータパイプラインをマネージドサービスとして利用 (インフラ運用不要)
  • 6 つのネイティブコネクタで主要エンタープライズデータソースを自動同期
  • ハイブリッド検索・ランキング・エージェント型検索が標準で利用可能

データソースから取り込まれたデータがマネージドベクトルストレージに格納され、AI エージェントからの問い合わせに対して高度な検索を通じて根拠付けされた回答を返します。

⚙️ 主要機能

🔍 1. 高度な検索 (Advanced Retrieval)

  • ハイブリッド検索: セマンティック検索とキーワード検索を組み合わせて関連性を向上
  • ドキュメントランキング: 取得結果の精度を向上
  • エージェント型検索 (Agentic Retrieval): クエリプランニング・中間応答の評価・再ランキングを自律的に行い、複雑なマルチホップクエリに対応

🔌 2. 6 つのネイティブデータコネクタ

🪣 Amazon S3
📁 SharePoint
📘 Confluence
📗 Google Drive
📙 OneDrive
🌐 Web Crawler
  • 自動データ同期によりデータソースの更新をナレッジベースに反映
  • 価格性能比に最適化されたマネージドベクトルストレージを利用

🎨 3. マルチモーダルナレッジベース

  • テキスト、動画、音声、画像を横断するナレッジベースを構築
  • 従業員アシスタント、カスタマーサポート自動化などに活用

🤖 4. Amazon Bedrock AgentCore とのネイティブ統合

  • 権限の自動生成 (auto-generated permissions) で設定の手間を軽減
  • ビルトインの可観測性 (observability) でエージェントの動作を把握

ステップ 1: ナレッジベースの作成

Bashcreate-knowledge-base
aws bedrock-agent create-knowledge-base \
  --name "enterprise-kb" \
  --role-arn "arn:aws:iam::111122223333:role/BedrockKBRole" \
  --region us-east-1

ベクトルストレージはマネージド提供のため、ベクトルデータベースの個別構成は不要です。

ステップ 2: データソースの追加

Bashcreate-data-source
aws bedrock-agent create-data-source \
  --knowledge-base-id "KB_ID" \
  --name "s3-source" \
  --data-source-configuration '{"type":"S3","s3Configuration":{"bucketArn":"arn:aws:s3:::my-docs"}}' \
  --region us-east-1

S3、SharePoint、Confluence、Google Drive、OneDrive、Web Crawler の各コネクタを指定できます。

ステップ 3: データの取り込みと検索

Bashstart-ingestion-job
aws bedrock-agent start-ingestion-job \
  --knowledge-base-id "KB_ID" \
  --data-source-id "DS_ID" \
  --region us-east-1

取り込み完了後、Retrieve や AgenticRetrieveStream などのデータプレーン API でナレッジベースを検索できます。

💡 ユースケース

1. 社内従業員アシスタント

シナリオ: SharePoint や Confluence に分散した社内ドキュメントを横断検索し、従業員の質問に回答。

データソース: SharePoint + Confluence ／ 検索方式: ハイブリッド検索 + エージェント型検索 ／ 統合: AgentCore

効果: 社内情報の検索時間を短縮し、従業員の生産性を向上

2. カスタマーサポート自動化

シナリオ: 製品マニュアルや FAQ を Amazon S3 に格納し、顧客の問い合わせに自動回答。

データソース: Amazon S3 + Web Crawler ／ 検索方式: ドキュメントランキング ／ API: RetrieveAndGenerate

効果: 対応の自動化でサポートコストを削減し応答時間を短縮

3. マルチモーダルナレッジベース

シナリオ: 操作動画、画像付きマニュアル、音声記録を含むナレッジベースで複数モダリティ横断検索を実現。

データソース: Amazon S3 (テキスト / 動画 / 音声 / 画像) ／ 検索方式: マルチモーダル検索 + エージェント型検索

効果: テキスト以外の情報も活用し、より豊かなコンテキストに基づく回答を提供

ベクトルデータベースや検索インフラの運用なしに、本番環境レベルの RAG アプリケーションを構築できるようになりました。
