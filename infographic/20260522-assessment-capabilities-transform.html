アセスメント機能

📅 2026-05-22

📋 概要

AWS Transform に新しいエージェント型マイグレーションアセスメント機能が追加された。オンプレミス環境のワークロードを自動的に検出・分析し、AWS への移行計画を作成できる。AI エージェントが TCO の算出、What-if シナリオの比較、最適な AWS サービスの推奨を自動で行い、手動作業を大幅に削減する。

AWS Transform は 1 年前にローンチされたエンタープライズ IT 変革のためのワークベンチであり、数十の専門 AI エージェントがアセスメント、コード分析、リファクタリング、依存関係マッピング、変革計画を自動化する。

Before / After

❌ Before

  • 手動でのインフラデータ収集・分析に数週間~数か月
  • TCO 分析に複数のスプレッドシートやツールを使い分け
  • What-if シナリオの手動比較が困難

✅ After

  • RVTools、CMDB など既存データをそのまま取り込み可能
  • AI エージェントが複数の What-if シナリオを自動生成・比較
  • 包括的な TCO 分析が数分で完了

⚡ 主要機能

🔀 What-if シナリオ分析

カスタマイズした前提条件で複数のマイグレーションシナリオを作成可能。リージョン、リソース使用率、サービスマッピングなどのパラメータを調整し、シナリオ間の比較を自動化して最適な移行パスを提示する。

📂 柔軟なデータ入力

RVTools エクスポート、CMDB データ、AWS Transform Discovery Tool のエクスポートに対応。サードパーティの Discovery ツールからのデータも受け入れ可能で、「手持ちのデータで即座に開始」できる設計。

💰 包括的な TCO コストモデリング

EC2、FSx、S3、SQL Server on EC2、仮想デスクトップのコストモデリングをサポート。Cloud Value Framework の柱による拡張分析が可能。

🤖 エージェント型自動化

専門 AI エージェントがディスカバリ、分析、プランニングを自動実行。MCP 対応により IDE やオーケストレーターからの呼び出しが可能。Human-in-the-loop 設計で人間がレビュー・修正可能。

📝 設定方法

1

ワークスペースの作成

AWS Transform コンソールにアクセスし、ワークスペースを作成する。ワークスペースはコネクタやジョブのパーミッション境界として機能する。

2

インフラデータの取り込み

既存のインフラデータ (RVTools エクスポート、CMDB データ、サードパーティ Discovery ツールのエクスポート) をアップロード。手持ちのデータでそのまま開始できる。

3

What-if シナリオの作成

カスタマイズ可能な前提条件 (リージョン、リソース使用率、サービスマッピング) を設定し、複数のマイグレーションシナリオを作成する。

4

シナリオ比較とレポート生成

AI エージェントが各シナリオを分析し、TCO 比較レポートと最適な移行計画を自動生成。Cloud Value Framework の柱を追加して包括的なビジネスケースを構築できる。

⚠️ 制限事項・考慮点

! コストモデリング対象は EC2、FSx、S3、SQL Server on EC2、仮想デスクトップに限定
! 利用可能リージョンが 8 リージョンに限定
! エージェントの推奨結果は前提条件に依存 - 入力データの品質が重要
! 複雑なレガシーアプリの依存関係は自動検出だけでは完全に把握できない場合あり
! Human-in-the-loop レビューによる検証を推奨

💡 ユースケース

🏢 大規模 VMware 環境の移行計画

数百台の VM を持つオンプレミス VMware 環境を AWS へ移行する際に、最適なアプローチと TCO を評価。

1. RVTools で VMware 環境のインベントリをエクスポート
2. AWS Transform にデータをアップロード
3. EC2 移行シナリオと Amazon EVS 移行シナリオを作成・比較
4. TCO レポートから最適な移行パスを選択

→ 手動分析に比べ数週間の工数削減。複数シナリオの定量比較により、ステークホルダーへの説明が容易に。

🗄️ マルチワークロードの統合アセスメント

コンピュート、ストレージ、データベースが混在するオンプレミス環境の包括的な移行アセスメントを実施。

1. CMDB からサーバー、ストレージ、データベースのデータをエクスポート
2. AWS Transform に全ワークロードデータを取り込み
3. EC2 + FSx + S3 + SQL Server on EC2 のコストモデリングを実行
4. Cloud Value Framework の全柱を含むビジネスケースを生成

→ 環境全体を統合的に評価でき、移行の全体像とビジネスインパクトを把握可能。

📈 経営層向け移行ビジネスケースの作成

クラウド移行プロジェクトの承認を得るために、経営層向けの定量的なビジネスケースを迅速に作成。

1. 既存の Discovery データを AWS Transform に取り込み
2. 保守的シナリオと楽観的シナリオの 2 パターンを作成
3. コスト削減 + スタッフ生産性 + 運用レジリエンスの観点で比較
4. 経営層向けサマリーレポートを出力

→ 数日以内に経営層が意思決定可能な定量データを含むビジネスケースを作成可能。

💲 料金情報

追加料金なし

AWS Transform の利用に追加料金は発生しない。移行後に使用する AWS サービス (EC2、S3 など) の標準料金のみが発生。
