⚖️ Amazon MSK Express ブローカー
Intelligent Rebalancing 既存クラスター対応

Amazon MSK
📅 2026 年 6 月 18 日

📌 概要

Amazon MSK の Express ブローカーを使用する MSK Provisioned クラスターで、 Intelligent Rebalancing がすべての既存クラスターで利用可能になりました。

これまでこの機能は 2025 年 11 月の初回リリース以降に新規作成されたクラスターのみが対象でした。今回のアップデートで、 それ以前に作成された既存の Express クラスターでも有効化できるようになり、追加料金なしで自動リバランシングの恩恵を受けられます。

Intelligent Rebalancing は Kafka リソースを最適に再配置することでキャパシティ使用率を最大化し、 サードパーティーツールや手動操作によるパーティション管理を不要にします。

❌ アップデート前の課題
  • 2025/11/20 より前に作成した Express クラスターでは利用不可
  • パーティション再配置を手動または Cruise Control などで管理
  • スケール時の再配置を自前で計画・実行する運用負荷
→
✅ アップデート後の改善
  • 既存の Express クラスターでも有効化が可能に
  • Rebalancing Status を Active にするだけで有効
  • 手動 / サードパーティーツール管理が不要になり運用負荷を軽減

Intelligent Rebalancing は Express ベースのクラスターを継続的に監視し、リソースの偏りや過負荷を検知すると、 クラスターの可用性を維持したままパーティションを自動的に再配置します。

⚙️ 主要機能

1️⃣ 既存クラスターでの有効化
  • Express ブローカーを使うすべての MSK Provisioned クラスターで利用可能
  • 2025/11/20 より前に作成したクラスターは初期状態が Paused
  • コンソール / AWS CLI / SDK から Rebalancing Status を Active にして有効化
2️⃣ スケールアップ / スケールダウン時の自動リバランシング
  • ブローカーの追加・削除をシングルクリックで実行
  • AWS の内部ベストプラクティスに基づきパーティションを自動再配置
  • スケール操作はクラスターの可用性に影響を与えずに完了
3️⃣ 定常状態でのリバランシング (Steady state rebalancing)
  • ブローカー間でリソース使用率に偏りが生じた場合
  • ブローカーが過剰プロビジョニング / 低使用率になった場合
  • ブローカーが追加・削除された場合

⚠️ デメリット・制約事項

制限事項

✗自動再配置はブローカーあたり最大 20,000 パーティションまで
✗有効化中はパーティション再配置 API やサードパーティーツール (Cruise Control 等) を使用できない
✗これらの API / ツール利用には、まず Intelligent Rebalancing の一時停止が必要

考慮すべき点

●2025/11/20 より前のクラスターは初期 Paused のため、有効化に明示的な操作が必要
●サードパーティーツールから移行する場合は運用フローの見直しが必要

🎯 ユースケース

1. 既存 Express クラスターの運用負荷削減
シナリオ2025 年初頭から運用する Express クラスターで、パーティションリバランシングを手動管理しており運用負荷が高い。
効果Rebalancing Status を Active にするだけで手動管理が不要になり、偏りや過負荷を自動解消。
2. スケーリング時のパーティション再配置自動化
シナリオトラフィック増減に応じてブローカー数を調整するが、再配置計画に時間がかかっている。
効果シングルクリックで追加・削除でき、ベストプラクティスに基づき自動再配置。30 分以内に完了し可用性にも影響なし。
3. サードパーティーツールからの移行
シナリオCruise Control でリバランシングしているが、運用とメンテナンスの負荷を削減したい。
効果有効化することでツール依存をなくし、MSK のマネージド機能でリバランシングを完結。

💰 料金・リージョン・関連サービス

💴 料金: Intelligent Rebalancing は追加料金なし。MSK Provisioned クラスターおよび Express ブローカーの通常料金が適用されます。
🌍 利用可能リージョン: Amazon MSK Express ブローカーがサポートされるすべての AWS リージョンで利用可能。

🔗 関連サービス・機能

→Amazon MSK Express ブローカー: 本機能の対象。Standard 比で最大 180 倍高速な運用操作
→Amazon CloudWatch: RebalanceInProgress / UnderProvisioned でリバランシング状況を監視
→AWS CloudFormation: Intelligent Rebalancing の設定をテンプレートで管理可能

🏁 まとめ

今回のアップデートにより、Intelligent Rebalancing が新規クラスターだけでなく 既存のすべての Express クラスターで利用可能になりました。 手動やサードパーティーツールでパーティション管理を行っていた運用者は、追加料金なしで自動リバランシングの恩恵を受けられます。 2025 年 11 月 20 日より前に作成したクラスターを利用している場合は、 Rebalancing Status を Active に設定して有効化することを推奨します。
