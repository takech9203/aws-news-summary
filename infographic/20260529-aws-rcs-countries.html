🌍 概要

AWS End User Messaging の RCS for Business が新たに 20 か国で利用可能に。対応国数が合計 22 か国に拡大し、ヨーロッパ、南米、中米、アジアの主要市場をカバー。

RCS は SMS の次世代規格であり、認証済みブランドアイデンティティからのメッセージ配信、リッチコンテンツ対応、自動 SMS フォールバックにより、確実で信頼性の高いメッセージングを実現する。

Before / After

❌ Before

  • 米国とカナダの 2 か国のみ
  • 国ごとに別のプロバイダーが必要
  • 海外顧客へのブランド認証メッセージ不可

✅ After

  • 22 か国で統一 API から送信可能
  • コード変更不要で即座に展開
  • 認証済みブランドメッセージでエンゲージメント向上

⚡ 主要機能

🌐 20 か国追加対応

ヨーロッパ 13 か国、南米 3 か国、中米・カリブ 3 か国、アジア 1 か国が新規追加。既存の米国・カナダと合わせて合計 22 か国で RCS メッセージングが利用可能に。

🔌 既存 API での即座の利用

SendTextMessage API をそのまま使用可能。アプリケーションの変更不要で、AWS RCS Agent ARN を origination identity として指定するだけで RCS 配信が開始される。

🔄 自動 SMS フォールバック

Phone Pool を使用した場合、RCS 非対応デバイスには自動的に SMS で配信。25 秒の RCS 配信タイムアウト後に SMS フォールバックが発動し、配信率 100% を目指す。

🏢 ブランド認証済みメッセージ

企業のロゴ、ブランドカラー、表示名が受信者に表示される。フィッシングメッセージとの区別が容易で、顧客の信頼性とエンゲージメント向上に貢献。

ステップ 4: RCS メッセージの送信

Python SendTextMessage API 呼び出し 
import boto3

client = boto3.client('pinpoint-sms-voice-v2')

response = client.send_text_message(
    DestinationPhoneNumber='+442071234567',
    OriginationIdentity='arn:aws:sms-voice:us-east-1:123456789012:rcs-agent/rcs-a1b2c3d4',
    MessageBody='Your order has been shipped. Track it here: https://example.com/track',
    MessageType='TRANSACTIONAL'
)

print(f"Message ID: {response['MessageId']}")

ステップ 5: SMS フォールバック付き Pool の設定

Bash Phone Pool 作成と SMS 番号追加 
# Pool を作成
aws pinpoint-sms-voice-v2 create-pool \

    --message-type TRANSACTIONAL

# SMS 番号を Pool に追加
aws pinpoint-sms-voice-v2 associate-origination-identity \
    --pool-id pool-a1b2c3d4e5f6g7h8i \
    --origination-identity phone-number-id

⚖️ メリット・デメリット

✅ メリット

  • グローバルリーチ: 22 か国に統一 API で配信
  • コード変更不要: 既存実装をそのまま活用
  • ブランド信頼性: 認証済みメッセージで開封率向上
  • 自動フォールバック: RCS 非対応時に SMS へ透過的に切替
  • 配信ステータス追跡: EventBridge/CloudWatch で可視化

⚠️ 制約・注意点

  • 全デバイスが RCS 対応ではない
  • 国ごとのキャリア承認に時間がかかる場合あり
  • 日本はまだ未対応
  • 料金は送信先の国により大きく異なる
  • Agent メンテナンス費用: 月額 $200
  • 一部国で高額な初期費用が発生

💡 ユースケース

🛒 グローバル EC のトランザクション通知

国際的な EC サイトが、注文確認・配送通知・配達完了メッセージを世界各国の顧客に送信。ブランド認証済みメッセージにより顧客が安心して配送情報を確認でき、フィッシングメッセージとの混同を防止。

🔐 多国籍企業の OTP 認証

SaaS プロバイダーがヨーロッパと南米の顧客に二要素認証コードを送信。ブランド認証により正規の認証コードであることが一目で分かり、SMS スプーフィング攻撃からの保護を強化。

📢 マーケティングキャンペーンの国際展開

小売チェーンがヨーロッパ複数国の顧客にセール情報やプロモーションメッセージを配信。単一の API と Pool 設定で複数国へ配信を実現し、開封率と CTR の向上が期待できる。

Python マルチ国配信の実装例 
import boto3

client = boto3.client('pinpoint-sms-voice-v2')

# 各国の顧客に同一 API でプロモーション配信
countries_numbers = [
    ('+33612345678', 'FR'),   # フランス
    ('+34612345678', 'ES'),   # スペイン
    ('+39312345678', 'IT'),   # イタリア
]

for number, country in countries_numbers:
    response = client.send_text_message(
        DestinationPhoneNumber=number,
        OriginationIdentity='pool-marketing',
        MessageBody='Summer Sale! 30% off all items this weekend.',
        MessageType='PROMOTIONAL'
    )

💰 料金情報

RCS メッセージングの料金は送信先の国によって異なる。課金は配信成功時のみ発生し、未配信メッセージには課金されない。

📝 まとめ

AWS End User Messaging の RCS for Business が 22 か国に拡大したことで、企業はグローバルなリッチメッセージング戦略を単一の AWS API で実現できるようになった。既存の SendTextMessage API がそのまま利用可能で移行コストがゼロであるため、現在 SMS を使用している企業は Phone Pool の設定を追加するだけで RCS の恩恵を受けられる。

日本はまだ対応国に含まれていないが、シンガポールが対応したことでアジア展開の足がかりとなるため、グローバルメッセージング基盤の検討を開始することを推奨する。
