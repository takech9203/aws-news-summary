Amazon Bedrock AgentCore

⌨️ AgentCore CLI バージョン 1.0 の一般提供開始

📅 リリース日: 2026 年 10 月 28 日 | 🏷️ 機能: Amazon Bedrock AgentCore CLI v1.0

📝 概要

AgentCore CLI バージョン 1.0 が一般提供開始されました。ターミナルから AI エージェントと関連リソースの作成、開発、デプロイ、運用を一貫して行えるコマンドラインツールです。npm パッケージ @aws/agentcore 1.0.0 として公開されています。

v1.0 再構築で起動高速化と一貫したコマンド体系
2 モード スクリプタブル CLI + インタラクティブ TUI
6 リソース ハーネス / ランタイム / メモリ / アイデンティティ / ゲートウェイ / ペイメントを直接操作

❌ アップデート前の課題

✗複数 AWS サービスの API 呼び出し、実行ロール設定、ストリーミング処理を個別に行う必要があり導入障壁が高い
✗プロジェクトを作成しないと各リソースを操作できず、アドホックな操作が煩雑
✗コマンド体系や出力形式が不統一で、自動化やスクリプト化がしにくい

✅ アップデート後の改善

✓再構築により起動が高速化、コマンド構造の一貫性が向上
✓6 種のリソースをプロジェクトなしで直接操作、ID または ARN での呼び出しに対応
✓インタラクティブシェル、検索可能メニュー、リソースピッカー、ガイド付きワークフローを追加
✓リージョン選択、JSON 出力、デバッグをグローバルフラグとして統一
✓既存プロジェクトは agentcore migrate で移行可能

AgentCore CLI v1.0 は、スクリプトモードとインタラクティブ TUI の 2 つの利用形態を提供し、プロジェクトワークフローまたはリソースへの直接操作を通じて Amazon Bedrock AgentCore の各リソースを管理します。

⚡ 主要機能

🔄 1. バージョン 1.0 への再構築

  • 起動時間が短縮され、より高速に CLI を利用可能
  • コマンド構造の一貫性が向上し、学習コストと自動化コストを削減
  • 既存プロジェクトは agentcore migrate コマンドでバージョン 1 へ移行可能

🎯 2. 幅広いリソースの直接操作

  • ハーネス、ランタイム、メモリ、アイデンティティ、ゲートウェイ、ペイメントを、プロジェクトに追加することなく直接操作可能
  • ID または ARN を指定してリソースを呼び出し可能
  • プロジェクトワークフローと直接操作の両方をサポート

🖥️ 3. インタラクティブな操作体験

  • インタラクティブシェル、検索可能なメニュー、リソースピッカー、ガイド付きワークフローを提供
  • ハーネスのエクスポート機能に対応
  • フラグなしでコマンドを実行すると TUI モードが起動し、ガイド付きで操作可能

🚩 4. 一貫したグローバルフラグ

  • --region によるリージョン選択
  • --json による JSON 形式の出力 (CI パイプラインやコーディングエージェントとの連携に有用)
  • --debug によるデバッグ出力、バージョン情報の表示

ステップ 1: CLI のインストール

Bashnpm からグローバルインストール
npm install -g @aws/agentcore

インストール後は agentcore コマンドが利用可能になります。

ステップ 2: プロジェクトの作成とハーネスの追加

Bashプロジェクト作成とハーネス追加
agentcore create --name MyProject
cd MyProject
agentcore add harness --name MyAssistant

ハーネスはモデル、システムプロンプト、ツール、スキルを YAML で定義し、AgentCore 側で実行されるマネージドエージェントです。

ステップ 3: デプロイと呼び出し

BashAWS へのデプロイと動作確認
agentcore deploy
agentcore invoke --harness MyAssistant --prompt "Hey, what can you do for me?"

ステップ 4: 既存プロジェクトの移行

Bash旧バージョンのプロジェクトを v1 形式へ移行
agentcore migrate

💡 メリット

💼 ビジネス面

✓開発スピードの向上: プロジェクト作成からデプロイ、呼び出しまでを数コマンドで完結でき、市場投入までの時間を短縮
✓導入障壁の低減: ガイド付きワークフローと TUI により、AgentCore に不慣れな開発者でも迷わずエージェントを構築可能
✓運用の標準化: 一貫したコマンド体系とグローバルフラグにより、チーム内での運用手順を統一しやすい

⚙️ 技術面

✓自動化との親和性: --json フラグによる構造化出力で、CI/CD パイプラインやコーディングエージェントからの利用が容易
✓リソースへの直接アクセス: プロジェクトを経由せずに ID または ARN でリソースを操作でき、アドホックな運用作業が効率化
✓複雑さの抽象化: 複数の AWS サービスの呼び出し、実行ロールの設定、ストリーミングレスポンスの処理を CLI が肩代わり

⚠️ デメリット・制約事項

🚫 制限事項

•Node.js 20.12 以降が必要
•Python ベースの AgentCore Starter Toolkit と agentcore コマンド名が競合するため、併用する場合は事前にアンインストールが必要
•Python テンプレートの利用には uv のインストールが必要

🤔 考慮すべき点

•既存プロジェクトをバージョン 1 で利用するには agentcore migrate による移行作業が必要
•CLI 自体は無料だが、デプロイした AgentCore リソース (ランタイム、メモリ、ゲートウェイなど) には利用料金が発生

🎯 ユースケース

🧪 1. ターミナルからの迅速なエージェントプロトタイピング

シナリオ: 新しい AI エージェントのアイデアを検証するため、最小限の手順でエージェントを構築して動作確認を行いたい。

Bashプロトタイプの構築から検証まで
agentcore create --name PrototypeAgent
cd PrototypeAgent
agentcore add harness --name Assistant
agentcore deploy
agentcore invoke --harness Assistant --prompt "こんにちは"

✅ 効果: コンソール操作や複数サービスの個別設定を行うことなく、数分でエージェントのプロトタイプをデプロイして検証できる。

🔁 2. CI/CD パイプラインによるエージェントの自動デプロイ

シナリオ: エージェントのコードやハーネス定義を Git で管理し、変更をマージしたら自動でビルド・デプロイしたい。

BashCI パイプライン内で実行
agentcore build --json
agentcore deploy --json
agentcore status --json

✅ 効果: JSON 出力により結果をパイプラインでパースでき、エージェントのデプロイを完全に自動化できる。

🔍 3. デプロイ済みリソースの運用・トラブルシューティング

シナリオ: 本番環境で稼働中のエージェントの動作を確認し、問題発生時にログやトレースを調査したい。

BashARN を指定した直接操作
# ARN を指定してプロジェクト外からリソースを直接操作
agentcore invoke --harness <ハーネスの ARN> --prompt "テストメッセージ"
agentcore logs
agentcore traces

✅ 効果: プロジェクトディレクトリに依存せず、ID または ARN を指定してデプロイ済みリソースを直接操作・調査できる。

💰 料金・利用可能リージョン

💵 料金

AgentCore CLI 自体は無料のオープンソースツール (Apache-2.0 ライセンス) です。CLI からデプロイ・利用する Amazon Bedrock AgentCore の各リソース (ランタイム、メモリ、ゲートウェイ、アイデンティティなど) には、AgentCore の料金体系に基づく利用料金が発生します。詳細は AgentCore 料金ページ を参照してください。

🌍 利用可能リージョン

公式発表ではリージョンの明示的な記載はありません。CLI はグローバルフラグ --region で操作対象のリージョンを選択でき、Amazon Bedrock AgentCore が利用可能なリージョンで使用できます。

🔗 関連サービス・機能

→Amazon Bedrock AgentCore: 本 CLI の操作対象となる、本番環境向け AI エージェントの構築・運用プラットフォーム
→AWS CDK: CLI が生成するプロジェクトには CDK アプリが含まれ、カスタムリソースや IAM 権限、環境変数の追加など拡張が可能
→AgentCore Starter Toolkit: 従来の Python ベースのツールキット。本 CLI と agentcore コマンド名が競合するため併用時は注意が必要

AgentCore CLI バージョン 1.0 の一般提供により、ターミナルから AI エージェントの作成、デプロイ、運用までを一貫して行える環境が整いました。高速な起動、一貫したコマンド体系、リソースへの直接操作、JSON 出力による自動化対応など、開発から本番運用までをカバーする実用的なツールです。
