AWS Partner Central / AWS Marketplace

🤝 AWS Marketplace リスティングを
co-sell 機会に直接関連付け

既存リスティングを機会に紐付け、二重管理を解消
📅 リリース日
2026 年 7 月 1 日

📌 概要

AWS は、パートナーが AWS Marketplace カタログにある 1 つ以上の AWS Marketplace ソリューションおよび製品リスティングを、 AWS Partner Central の co-sell 機会 (opportunity) に直接関連付けられるようになったことを発表しました。 これにより、Marketplace で販売しているリスティングと共同販売用ソリューションを別々に管理する必要がなくなります。

この機能は AWS Console 上の AWS Partner Central で一般提供 (GA) されており、 同等の操作は AWS Partner Central Selling API を通じてプログラムからも利用できます。 対象は、AWS との共同販売を行うすべての AWS パートナー (ISV、コンサルティングパートナーなど) です。

❌ アップデート前の課題

  • 機会には co-sell 用に特別に作成したソリューションを紐付ける必要があった
  • Marketplace カタログ向けと co-sell 向けのソリューションを別々に管理する必要があった
  • 既存リスティングを機会に直接関連付けできず、フルフィルメント追跡が煩雑だった
➡️

✅ アップデート後の改善

  • 既存の Marketplace ソリューション・製品リスティングを機会に直接関連付け可能に
  • ソリューションの二重管理が不要になり運用負荷が軽減
  • 機会単位でフルフィルメントをより正確に追跡可能に
  • サブシディアリ (子会社) アカウント内のリスティングも関連付け可能に

⚙️ 主要機能

1. AWS Marketplace リスティングの機会への関連付け

  • Marketplace カタログのソリューションと製品を co-sell 機会に直接関連付け可能
  • 機会の作成時または編集時に、AWS Console の AWS Partner Central から操作
  • co-sell 専用ソリューションを別途作成する必要がなくなった

2. 4 つの関連付けオプション

機会作成・編集時に以下のいずれかを選択可能:

① ソリューション + 製品 ② ソリューションのみ ③ 製品のみ ④ その他 (Other)

3. 関連付け上限とサブシディアリアカウント対応

  • 1 機会に最大 10 個のソリューションと最大 10 個の製品を関連付け可能
  • サブシディアリアカウント接続が確立された AWS アカウント内のリスティングも、ARN を手動入力して関連付け可能

4. API によるプログラム操作

  • 同等の機能を AWS Partner Central Selling API 経由で利用可能
  • 既存の CI/CD やインテグレーションから機会への関連付けを自動化可能

🛠️ 設定方法

前提条件

✓AWS Partner Central のアカウントを保有し、Opportunity Management にアクセスできること
✓Marketplace カタログに "Limited" または "Public" ステータスのソリューションまたは製品リスティングが存在すること
✓サブシディアリアカウントのリスティングを関連付ける場合は、サブシディアリアカウント接続が確立されていること

手順

1

機会の作成または編集を開始する

AWS Partner Central にサインインし、[Sell] から [Opportunity Management] を選択。新規は [Create]、既存は該当機会を選択して [Project Details] を開く。

2

AWS Marketplace リスティングを関連付ける

[Project Details] の [AWS Marketplace Solutions and Products] セクションで関連付け。表示されるのは "Limited" / "Public" のリスティングのみ。11 個以上ある場合は ID または名前で検索可能。サブシディアリアカウント経由は [Enter ... ARNs manually] フィールドに ARN を入力。

3

保存して機会を進行させる

残りのフィールドを入力し、[Save and Submit] (新規) または [Save] (編集) を選択。Committed / Launched へ進めるには、ソリューション・製品・パートナーソリューションのいずれかの関連付けが必須。

💡 メリット

ビジネス面

✓運用負荷の軽減: 二重管理が不要になり、カタログ管理と共同販売管理を一元化
✓フルフィルメント追跡の向上: 実際の Marketplace リスティングを紐付け、受注から履行まで正確に追跡
✓共同販売の可視性向上: AWS セラーとのパイプライン共有で商談状況を明確に共有

技術面

✓API による自動化: Selling API でリスティング関連付けを自動化
✓サブシディアリアカウント対応: ARN 指定で複数アカウント構成でも柔軟に関連付け
✓柔軟な関連付けオプション: 4 つのオプションから選択可能

⚠️ デメリット・制約事項

制限事項

!1 機会に関連付けできるソリューションと製品はそれぞれ最大 10 個まで
!ドロップダウンに表示されるのは "Limited" または "Public" ステータスのソリューションのみ
!Committed / Launched へ進めるには、少なくとも 1 つのソリューション、製品、またはパートナーソリューションの関連付けが必須
📝 考慮すべき点: サブシディアリアカウントのリスティングを関連付けるには、事前に接続を確立しておく必要があります。またドキュメントによれば、機会には必ずソリューションの追加が必要で、ソリューション未作成の状態では [Other] オプションのみでの運用はできない点に留意してください。

🎯 ユースケース

ユースケース 1: カタログと co-sell の一元管理

シナリオ: 複数の SaaS 製品を Marketplace に出品している ISV が、co-sell 用ソリューションと Marketplace カタログを個別に管理していた。

効果: 既存リスティングを直接機会に関連付け、二重管理をなくし、営業チームが最新の製品情報で商談を進められる。

ユースケース 2: 商談ごとのフルフィルメント追跡

シナリオ: パートナーが 1 つの大型商談に複数の Marketplace 製品を含めて提案し、どの製品がどの機会に紐付くかを追跡したい。

効果: 1 機会に最大 10 ソリューション + 10 製品を関連付けられ、商談内容と実際のリスティングを対応付けてフルフィルメントを正確に管理できる。

ユースケース 3: API による機会管理の自動化

シナリオ: 独自の CRM やパイプライン管理システムを運用するパートナーが、機会作成時に自動で Marketplace リスティングを関連付けたい。

効果: Selling API を利用して関連付けをプログラムから実行し、既存の営業ワークフローに統合できる。

💰 料金・利用可能リージョン・関連サービス

料金

本アップデートは AWS Partner Central の機能であり、リスティングを co-sell 機会に関連付ける操作自体に追加料金は発生しません。AWS Partner Central および AWS Marketplace の通常の利用条件に従います。

利用可能リージョン

AWS Console 上の AWS Partner Central で一般提供。AWS Partner Central はグローバルに提供されるサービスです。

関連サービス・機能

→AWS Marketplace: 関連付けるソリューション・製品リスティングのカタログを提供
→Partner Central Selling API: 機会への関連付けをプログラムから実行
→サブシディアリアカウント接続: 別アカウント内のリスティングを ARN 指定で関連付け
→AWS Partner Customer Engagement (ACE): co-sell 機会を AWS セラーと共有する共同販売プログラム

🏁 まとめ

このアップデートにより、パートナーは既存の AWS Marketplace リスティングを co-sell 機会に直接関連付けられるようになり、 ソリューションの二重管理が解消されます。 共同販売のフルフィルメント追跡を効率化したいパートナーは、AWS Console または AWS Partner Central Selling API を利用して既存リスティングの関連付けを試すことを推奨します。
