🛠️ Kiro IDE 1.4.62 - Windows システムワイドインストーラー、Shift 不要のファイルドラッグ、枠付き Mermaid 図

📅 リリース日: 2026 年 10 月 28 日
Windows 向けシステムワイドインストーラー (x64 / ARM64)、Shift キー不要のチャットへのファイルドラッグ、ダークテーマでも見やすい枠付き Mermaid 図の描画

📝 概要

2026 年 10 月 28 日、Kiro IDE 1.4.62 がリリースされました。本リリースでは、Windows 向けのシステムワイドインストーラー (x64 / ARM64) が追加され、1 台のコンピューター上のすべてのユーザーが Kiro を利用できるインストール方式が選択可能になりました (インストールには管理者権限が必要)。また、チャットへのファイル添付が改善され、Shift キーを押さずにファイルをドラッグ & ドロップして添付できるようになったほか、ステータスバーのサンドボックス表示が Sandbox: Active / Sandbox: Off のような短いラベルに変更されました。

修正面では、チャット内の Mermaid 図がテーマに合わせた枠付きブロックで表示されるようになり、ダークテーマでも矢印が見やすくなりました。このほか、スラッシュコマンド直後の入力、フック切り替え失敗時のエラー表示、同名メモリの取り扱い、MCP パネルの表示などが修正されています。

❌ Before: アップデート前の課題
  • Windows 向けインストーラーはユーザー単位のみで、共有端末や管理された環境で全ユーザー向けに展開する手段がなかった
  • チャットへのファイルのドラッグ & ドロップ添付には Shift キーの長押しが必要だった
  • ダークテーマでは Mermaid 図の矢印などが背景に溶け込み、視認しづらい場合があった
  • スラッシュコマンド直後に入力・貼り付け・音声入力すると、テキストがコマンド名と結合して実行されなかった
  • フックの切り替えに失敗しても (読み取り専用・削除済みなど) エラーが表示されず原因が分からなかった
  • 別リポジトリに同名のメモリがあると、Memory created 行から目的のメモリを開けなかった

  • x64 / ARM64 向けシステムワイドインストーラーで、コンピューター上のすべてのユーザーが Kiro を利用可能に
  • Shift キーを押さずにファイルをドラッグ & ドロップしてチャットに添付できるように
  • Mermaid 図がテーマに合わせた枠付きブロックで描画され、ダークテーマでも矢印が見やすく

  • フックの切り替えに失敗した場合にエラーが表示され、原因を把握できるように
  • 同名のメモリが個別の行として表示され、正しいメモリを開けるように

⚡ 主要機能

🪟 1. Windows システムワイドインストーラー
x64 または ARM64 向けのインストーラーをダウンロードし、コンピューター上のすべてのユーザーが Kiro を利用できる形でインストール可能。インストールには管理者権限が必要で、共有端末や IT 部門が管理する環境への展開に適した方式です。
📎 2. Shift キー不要のファイルドラッグ添付
デスクトップやファイルマネージャーからファイルを Kiro のチャットにドラッグするだけで添付できます。従来必要だった Shift キーの長押しが不要になりました。サポートされていないファイル形式の場合、チャットにファイル名付きのエラーが表示されます (複数の非対応ファイルの場合は件数を表示)。
🏷️ 3. ステータスバーのサンドボックス表示の簡潔化
ステータスバーのサンドボックス項目が Command sandbox ではなく Sandbox で始まる表記に変更されました (例: Sandbox: Active、Sandbox: Off)。項目を選択するとサンドボックス設定を開けます。
📊 4. 枠付き Mermaid 図の描画 (Fix)
チャット内の Mermaid 図が、テーマに合わせた枠付きブロック内に表示され、ダークテーマでも矢印が見やすくなりました。図の上でスクロールするとチャットがスクロールし、ズームは Ctrl + スクロールまたはトラックパッドのピンチ操作で実行します。
⌨️ 5. スラッシュコマンドとチャット UI の修正 (Fix)
スラッシュコマンドの直後に入力・貼り付け・音声入力したテキストがコマンド名と結合しなくなり、コマンドが確実に実行されます。失敗が繰り返された後に Kiro が表示する質問は、チャット履歴に未回答カードとして残らず、チャット入力欄の上にのみ表示されます。また、Select model や Select agent などのツールチップが、Kiro ウィンドウに戻った際に勝手に開かなくなりました。
🪝 6. フック・メモリ・MCP パネルの修正 (Fix)
Hooks ビューでフックを切り替えた際、フックファイルを変更できない場合 (読み取り専用・削除済みなど) にエラーが表示されるようになりました。チャットの Memory created 行からは、同名メモリが複数ある場合でも正しいメモリが開きます。Powers 由来の MCP サーバー名が power- で始まる場合に、MCP パネルで power-power- と二重のプレフィックスが表示される問題も修正されました。

🚀 設定方法

前提条件

✓Kiro IDE を利用していること
✓システムワイドインストーラーを利用する場合は Windows (x64 または ARM64) と管理者権限
✓各修正を利用するには Kiro IDE 1.4.62 以降へのアップデート

手順

1
Kiro IDE を 1.4.62 に更新する
Kiro IDE は自動アップデートに対応しています。手動で確認する場合は、IDE のアップデート確認メニューから最新バージョンを適用します。新規に Windows へ全ユーザー向けインストールを行う場合は、ダウンロードページから x64 または ARM64 のシステムワイドインストーラーを取得し、管理者権限で実行します。
2
ファイルをチャットにドラッグ & ドロップする
デスクトップまたはファイルマネージャーからファイルを Kiro のチャットにドラッグします。Shift キーを押す必要はありません。非対応のファイル形式の場合は、ファイル名または件数付きのエラーがチャットに表示されます。
3
サンドボックス設定と Mermaid 図の表示を確認する
ステータスバーの Sandbox: Active / Sandbox: Off 表示を選択すると、サンドボックス設定を開けます。詳細はサンドボックスドキュメントを参照してください。チャットで Mermaid 図を生成すると、テーマに合わせた枠付きブロックで表示されます。ズームは Ctrl + スクロールまたはピンチ操作で行います。

⚠️ 制約事項・考慮点

✗システムワイドインストーラーは Windows (x64 / ARM64) 向けであり、インストールには管理者権限が必要
✗本リリースは Kiro IDE のアップデートであり、CLI / Web / Crew は対象外
✗非対応のファイル形式はドラッグ & ドロップしてもチャットに添付できない (エラーが表示される)
⚠既存のユーザー単位インストールから全ユーザー向けインストールへ切り替える場合は、組織のソフトウェア配布ポリシーに沿った展開計画が必要
⚠Mermaid 図の上でのスクロール操作はチャットのスクロールに割り当てられたため、図のズームには Ctrl + スクロールまたはピンチ操作を使用する点に注意

🎯 ユースケース

🏢 ユースケース 1: 共有端末・管理環境への Kiro 一括展開

シナリオ: IT 部門が、複数の開発者が共用する Windows 端末や管理されたデバイスに Kiro を展開したい。

  1. ダウンロードページから x64 または ARM64 のシステムワイドインストーラーを取得
  2. 管理者権限でインストーラーを実行し、全ユーザー向けにインストール
  3. 各ユーザーが自分のアカウントでサインインして利用開始

効果: ユーザーごとの個別インストールが不要になり、管理された Windows 環境への展開と運用が容易になる。

📄 ユースケース 2: 設計資料やログファイルを使ったチャット駆動開発

シナリオ: 開発者が、エラーログや仕様書などのファイルを Kiro チャットに添付しながら調査・実装を進めたい。

  1. ファイルマネージャーから対象ファイルをチャットへそのままドラッグ (Shift 不要)
  2. 非対応形式の場合はエラー表示を確認し、対応形式に変換して再添付
  3. 添付ファイルを参照しながらエージェントに調査・修正を依頼

効果: ファイル添付の操作が簡単になり、資料を参照したチャット駆動の開発がスムーズになる。

🌙 ユースケース 3: ダークテーマでのアーキテクチャ図レビュー

シナリオ: ダークテーマを利用する開発者が、エージェントが生成した Mermaid のアーキテクチャ図をチャット上でレビューしたい。

  1. チャットでエージェントにアーキテクチャ図の生成を依頼
  2. テーマに合わせた枠付きブロックで描画された図を確認
  3. 細部は Ctrl + スクロールまたはピンチ操作でズームして確認

効果: ダークテーマでも矢印やラベルが見やすく、チャット内で図のレビューが完結する。
