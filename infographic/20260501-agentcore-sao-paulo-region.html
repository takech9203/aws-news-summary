📋 概要

Amazon Bedrock AgentCore が AWS 南米 sa-east-1 リージョンで利用可能になりました。AgentCore は AI エージェントの構築、接続、最適化を行うためのプラットフォームであり、任意のフレームワークとモデルを使用してエージェントを迅速に開発できます。インフラストラクチャレイヤーでセキュリティが強制されるため、エージェントがセキュリティ制御をバイパスすることはできません。

7 全コンポーネント利用可能
7 対応リージョン数
LGPD ブラジルデータ保護法準拠

❌ Before

  • 南米から他リージョンへアクセスが必要でレイテンシーが高い
  • LGPD のデータレジデンシー要件を満たすことが困難
  • リージョン間通信によるエージェント応答の遅延

✅ After

  • 南米リージョンでローカルデプロイ、レイテンシー大幅削減
  • データがサンパウロ内に保持され法規制準拠が容易に
  • 全 7 機能が制限なく利用可能

⚙️ 主要機能

サンパウロリージョンでローンチ時点から全 7 コンポーネントが利用可能です。

⚡ Agent Runtime

任意のフレームワークとモデルでエージェントを実行するマネージドランタイム。コンテナベースデプロイ、セッション管理、VPC ネットワーク構成をサポート。

🔑 Identity

OAuth 2.0、API キー、IAM ベースの認証をサポート。OBO トークン交換により、ユーザーに代わったセキュアなリソースアクセスが可能。

🔌 Gateway

MCP サーバー、OpenAPI、Lambda、API Gateway など多様なターゲットタイプをサポート。VPC 内のプライベートエンドポイント接続が可能。

📋 Policy

インフラストラクチャレイヤーでセキュリティを強制するポリシーエンジン。エージェントがバイパスできないガードレールを適用。

📊 Observability

エージェントの動作監視、パフォーマンスメトリクス収集、継続的最適化のためのインサイト提供。

💻 Code Interpreter

サンドボックス環境でコードを安全に実行。データ分析、計算、ファイル処理などのタスクをサポート。

🌐 Browser Tools

エージェントが Web ブラウザを操作する機能。カスタム Chrome 拡張機能、セキュアなブラウザセッション管理。

🔒 データレジデンシー

  • LGPD: ブラジルの一般データ保護法。個人データのブラジル国内での処理・保存を推奨
  • データローカリティ: エージェントの処理データがサンパウロリージョン内に保持される
  • 規制コンプライアンス: 金融、ヘルスケアなどの規制業界向けにデータ主権要件を充足

🔧 設定方法

前提条件

  • AWS アカウントが sa-east-1 リージョンで有効であること
  • AgentCore を使用するための適切な IAM 権限が設定されていること
  • 使用するモデルがサンパウロリージョンで利用可能であること

ステップ 1: リージョンの選択

Bash リージョン設定 
# AWS CLI でサンパウロリージョンを指定
export AWS_DEFAULT_REGION=sa-east-1

ステップ 2: AgentCore Runtime の作成

Bash Agent Runtime 作成 
# AgentCore Agent Runtime を作成
aws bedrock-agentcore-control create-harness \
  --harness-name "my-agent-saopaulo" \
  --execution-role-arn "arn:aws:iam::123456789012:role/AgentCoreRole" \
  --region sa-east-1

ステップ 3: Gateway の設定

Bash Gateway 作成 
# Gateway を作成してツールを接続
aws bedrock-agentcore-control create-gateway \
  --gateway-name "my-gateway-saopaulo" \
  --region sa-east-1

💡 ユースケース

🏦 ブラジル金融機関向けカスタマーサポートエージェント

顧客データを国内に保持しながら AI エージェントによるカスタマーサポートを提供。VPC 内のセキュアな環境でエージェントが動作。

Bash 金融向けエージェント作成例 
aws bedrock-agentcore-control create-harness \
  --harness-name "finance-support-agent" \
  --execution-role-arn "arn:aws:iam::123456789012:role/FinanceAgentRole" \
  --environment '{"agentCoreRuntimeEnvironment": {"networkConfiguration": {"networkMode": "VPC"}}}' \
  --region sa-east-1
✅ 顧客データが LGPD に準拠してブラジル国内で処理され、セキュアな環境でエージェントが動作

🛒 南米 EC サイトの注文管理エージェント

注文追跡やカスタマーサービスを AI エージェントで自動化し、低レイテンシーで応答。

Bash 注文管理 Gateway 設定例 
aws bedrock-agentcore-control create-gateway-target \
  --gateway-identifier "gw-12345" \
  --name "order-management-api" \
  --target-configuration '{"mcp": {"apiGateway": {"restApiId": "abc123", "stage": "prod"}}}' \
  --region sa-east-1
✅ リクエストがサンパウロ内で完結し、注文情報取得から応答までのレイテンシーが数百ミリ秒削減

🏥 ヘルスケアデータ分析エージェント

患者データを国外に転送せずに AI エージェントによるデータ分析を実施。

Bash ヘルスケア分析エージェント作成例 
aws bedrock-agentcore-control create-harness \
  --harness-name "healthcare-analysis-agent" \
  --execution-role-arn "arn:aws:iam::123456789012:role/HealthcareAgentRole" \
  --tools '[{"type": "agentcore_code_interpreter", "name": "data-analyzer", "config": {"agentCoreCodeInterpreter": {"codeInterpreterArn": "arn:aws:bedrock:sa-east-1:123456789012:code-interpreter/ci-12345"}}}]' \
  --region sa-east-1
✅ 患者データがブラジル国内に留まり、LGPD およびヘルスケア規制に準拠しながら高度なデータ分析が可能

💰 料金情報

AgentCore の料金は使用するコンポーネントと使用量に応じて課金されます。サンパウロリージョンの料金は他リージョンと異なる場合があります。

Gateway リクエスト数、データ転送量
Code Interpreter 実行時間
Browser Tools セッション時間
