📄 Amazon Textract Core
AI エージェント向けスキルの提供開始

🗓️ リリース日: 2026 年 11 月 20 日 | 機能: Amazon Textract Core 向け AI エージェントスキル

📌 概要

AI エージェントが Amazon Textract Core を使用してドキュメントからデータを抽出するための新しいスキルが登場。サーバーやインフラのデプロイ一切不要で、テキスト、表、フォーム、領収書、請求書、本人確認書類などからデータを抽出できます。

スキルは AWS Agent Toolkit で公開され、Kiro、Claude Code、Cursor などのエージェントから利用可能。AWS MCP サーバーと aws-core プラグインを使用している場合、エージェントがスキルを自動的に読み込みます。ユーザーは自然言語で指示するだけで、エージェントがドキュメント処理を実行し回答を直接返します。

❌ アップデート前の課題
✗エージェントと Textract を接続するカスタムインテグレーションを独自に構築・保守
✗ドキュメントタイプごとの Textract API 選択ロジックを自前で実装
✗API 出力 JSON を読み取り順テキストや構造化フィールドに変換するパーサーを自作
✅ アップデート後の改善
✓インフラのデプロイなしでエージェントがドキュメントからデータを抽出
✓スキルがドキュメントタイプに応じて適切な API へ誘導、選択ロジック実装が不要
✓テスト済みパーサー同梱で、読み取り順テキストや構造化フィールドへ変換
✓信頼度スコアで自動受け入れと人によるレビューを振り分けるワークフローを構築可能

AI エージェントが AWS Agent Toolkit のスキルを通じて Amazon Textract Core API を呼び出し、抽出結果を構造化データとしてユーザーに返す流れ。信頼度スコアに基づいて自動受け入れと人によるレビューを振り分けられます。

⚡ 主要機能

🧭 1. ドキュメントタイプに応じた API ルーティング

一般文書、フォーム、領収書、請求書、本人確認書類などのタイプに基づき、スキルが適切な Textract Core API へエージェントを誘導。開発者による API 選択ロジックの実装が不要。複数ページの PDF にも対応し、全ページを読み取り順で返却。

🧩 2. テスト済みパーサーの同梱

Textract API の出力を読み取り順のテキストと構造化フィールド (フォームの質問への回答、請求書・領収書の明細、本人確認書類のフィールドなど) に変換。自前でのパーサー実装・保守が不要。

🎯 3. 信頼度スコアによるレビューワークフロー

高信頼度の結果は自動受け入れ、低信頼度の結果はフラグを立てて人によるレビューへ振り分け。例: 患者の問診票を構造化データに変換し、不明瞭なフィールドにスタッフレビュー用のフラグを付与。

🤝 4. 主要なエージェントとの統合

AWS MCP サーバーと aws-core プラグインを使用すると、エージェントがスキルを自動的に読み込み。AWS Agent Toolkit で公開され、Kiro、Claude Code、Cursor などから利用可能。

🚀 手順

1
AWS MCP サーバーと aws-core プラグインの設定
エージェントの MCP 設定に AWS MCP サーバーを追加し、aws-core プラグインを有効化。エージェントが Textract Core スキルを自動的に読み込みます。
2
スキルの確認
AWS Agent Toolkit のリポジトリでスキルの内容と利用方法を確認。スキルには API の選択ガイドとパーサーが含まれています。
3
自然言語でドキュメント処理を指示
エージェントに指示するだけで、スキルが適切な Textract Core API を呼び出し、構造化データを返します。

🚧 制限事項

⚠Amazon Textract が利用可能な商用リージョンでのみ使用可能
⚠スキルの利用には MCP 対応のエージェント環境が必要
⚠抽出精度は Amazon Textract Core API の性能に依存

🤔 考慮すべき点

⚠スキル自体は無料だが、Textract API には標準料金が発生。処理量に応じたコスト見積もりが必要
⚠低信頼度の結果を扱う人によるレビュープロセスは別途設計が必要
⚠機密性の高いドキュメントを扱う場合は、IAM 権限やデータ取り扱いポリシーの整備が必要

🎬 ユースケース

🏥 ユースケース 1: 医療機関の問診票のデジタル化

シナリオ: 紙の問診票をスキャンし、電子カルテシステムに取り込むためのデータ化を行う。

Textエージェントへの指示
「この患者の問診票を構造化データに変換し、
不明瞭なフィールドにはスタッフレビュー用のフラグを付けてください」
✅ 効果: 高信頼度のフィールドは自動取り込み、不明瞭な項目のみスタッフが確認。入力作業を大幅に削減しながらデータ品質を維持。
🧾 ユースケース 2: 経理部門の請求書処理の自動化

シナリオ: 取引先から受領した請求書 PDF から、請求金額、支払期日、明細を抽出して会計システムに連携する。

Textエージェントへの指示
「受領した請求書 PDF から請求元、請求金額、支払期日、明細行を
抽出して JSON で出力してください」
✅ 効果: スキルが請求書向け Textract API を自動選択し構造化された明細データを返すため、手入力によるミスと工数を削減。
🪪 ユースケース 3: 本人確認書類を使ったオンボーディングの効率化

シナリオ: 金融サービスの口座開設フローで、本人確認書類から氏名、住所、生年月日などを抽出して申込情報と照合する。

Textエージェントへの指示
「アップロードされた本人確認書類からフィールドを抽出し、
申込フォームの入力内容と一致するか確認してください」
✅ 効果: 抽出とフィールド構造化はスキル側で行われるため、照合ロジックの開発に集中でき、オンボーディング所要時間を短縮。

💰 料金

スキル自体の利用に追加料金はかかりません。スキルが呼び出す Amazon Textract API の使用に対して、標準の Amazon Textract 料金が適用されます。

詳細は Amazon Textract 料金ページ を参照してください。

🔗 関連サービス・機能

📄 Amazon Textract

ドキュメントからテキスト、表、フォームデータを抽出するマネージド OCR サービス。本スキルの基盤となる API を提供。

🧰 AWS Agent Toolkit

AI エージェント向けのスキルやツールを集約した AWS 公式ツールキット。本スキルの配布元。

🔌 AWS MCP サーバー

Model Context Protocol を通じて AI エージェントに AWS の機能を提供するサーバー。aws-core プラグインと組み合わせてスキルを自動読み込み。

💻 Kiro

AWS が提供する AI 搭載 IDE。本スキルを利用できるエージェントの 1 つ。
