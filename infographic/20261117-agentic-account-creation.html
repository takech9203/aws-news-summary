アカウント作成機能

📅 リリース日: 2026 年 11 月 17 日 | 機能: Agentic account creation for agentic coding harnesses

📋 概要

Claude Code、Codex、Cursor などのコーディングエージェントから直接 AWS サインアップを開始できる新機能。 エージェントがブラウザを自動的に開き、サインアップ完了後に短期認証情報がハーネスへ自動返却されるため、 アイデアからデプロイまでコーディング環境を離れずに完結します。

作成される環境は新しい AWS 体験「Sign up for AWS (new)」に基づき、最初のプロジェクトには ホームリージョン、IAM ロールマネージャー、自動更新される短期認証情報が事前セットアップ済み。 サインアップ直後からデプロイを開始できます。

⚙️ 主要機能

1️⃣ コーディングエージェントからのサインアップ開始
  • AWS アカウントを持たない開発者に対し、AI コーディングツールが AWS CLI から「Sign up for AWS (new)」を開始
  • ブラウザが自動的に開き、サインアップと新しいプロジェクトの選択をブラウザ上で完了
  • 完了後、AWS CLI が認証情報を受け取り、AI コーディングツールがその認証情報を利用可能
2️⃣ 事前構成されたプロジェクト環境
  • 連絡先情報に基づき、コンテンツ保存先となるホームリージョンを自動設定
  • IAM ロールマネージャー、AWS Organizations、IAM Identity Center へ自動オプトイン
  • 同一プロジェクト内の全 AWS リソースにアクセスできるマネージドなセキュリティ実装を適用、追加のアクセス設定は不要
3️⃣ 自動更新される短期認証情報
  • AWS CLI、AWS Tools for PowerShell、AWS SDK で利用可能
  • リソースへのアクセスは 12 時間有効、aws login --profile {プロファイル名} で更新
  • AWS は 90 日間認証情報を更新可能、90 日経過後はブラウザでの再認可が必要
4️⃣ AWS Agent Toolkit
  • AWS MCP サーバー設定と厳選されたエージェントスキルのセットをバンドル
  • 新しい AWS 体験向けに調整されたガイダンスを含むルールファイルを提供
  • 支援レベルを Low (セキュリティリスクの指摘のみ)、Medium (潜在的な問題の確認)、High (アーキテクチャ改善の提案) から選択可能

🛠️ 設定方法

✅ 前提条件

✓エージェンティックコーディングハーネス (Claude Code、Codex、Cursor など) がインストール済み
✓AWS CLI が利用可能
✓サインアップを完了するためのブラウザ環境がある
1
AWS Agent Toolkit のセットアップ
Bashセットアップ手順の取得
curl -fsSL https://github.com/aws/agent-toolkit-for-aws/blob/main/setup-instructions/setup.md

AWS アカウントを持っていない場合、このセットアップ手順がサインアップを自動的に開始します。コンソール利用の場合は AWS Settings (settings.aws.com) の [Copy agent prompt] からエージェント用プロンプトを取得する方法も利用できます。

2
ブラウザでサインアップを完了

ブラウザが自動的に開き、新しい AWS サインアップ体験が表示されます。サインアップを完了してプロジェクトを選択すると、AWS CLI が短期認証情報を受け取り、コーディングエージェントがデプロイを開始できます。セットアップ時にはプロジェクトにアクセスするためのプロファイル名を入力します。

3
認証情報の更新
Bash有効期限 12 時間が切れた場合に実行
aws login --profile MyFirstProjectProfile

デフォルトブラウザが自動的に開き、プロジェクト名を選択するとログインが完了します。複数プロジェクトを利用する場合は、プロジェクトごとに異なるプロファイル名を使い分けます。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓オンボーディング時間の短縮: アカウント作成から初回デプロイまでの手順が自動化
✓開発体験の向上: アイデアからデプロイまでコーディング環境内で完結
✓コスト管理: プロジェクトごとの支出上限で AI エージェントによる予期しないコスト増加を抑制

🔧 技術面のメリット

✓セキュアな認証情報管理: 12 時間で失効する短期認証情報により漏えいリスクを低減
✓事前構成されたガードレール: AWS が SCP、RCP を管理し、プロジェクト間はデフォルトで分離
✓MCP サーバーとエージェントスキルの統合: AWS Agent Toolkit によりベストプラクティスを自動導入

🚫 制限事項

✗利用できる AWS サービスが限定 (フルセットが必要なら advanced を使用)
✗リージョンを自分で選択不可 (オプトインリージョンへのアクセスも不可)
✗HIPAA や FedRAMP などの規制ワークロードは非対応
✗AWS Marketplace、Savings Plans、AWS Partner Network への参加は利用不可
✗作成した IAM ロール / ユーザーはプログラムアクセス専用 (コンソールアクセス不可)

⚠️ 考慮すべき点

⚠AI が作成したリソースの責任 (セキュリティ・課金) は責任共有モデルに基づき利用者にある
⚠認証情報は AWS CLI / PowerShell / SDK 向け。外部ツールは非サポートの場合あり
⚠90 日経過後は再認可が必要なため、長期運用の自動化パイプラインには別の認証方式を検討
⚠細かい粒度の権限管理やロールベースの権限制御が必要な場合は不向き

💰 料金と利用可能リージョン

💵 料金

この機能自体に追加料金はありません。サインアップ後に作成した AWS リソースに対して、選択したプラン (Free Plan または Paid Plan) に基づく通常の料金が発生します。

Paid Plan ではプロジェクトごとに月額の支出上限 (スペンドリミット) を設定できます。AI コーディングツールが作成したリソースの課金は利用者の責任となる点に注意してください。

🌍 利用可能リージョン

新しい AWS サインアップ体験は、選択された一部の AWS リージョンで利用できます。

コンテンツの保存先となるホームリージョンは連絡先情報に基づいて自動的に設定され、利用者が変更することはできません。オプトインリージョンへのアクセスはサポートされていません。
