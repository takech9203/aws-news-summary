ネットワーク最適化 / EBS 最適化の 2 つのバリアントで、最大 43% のパフォーマンス向上を実現

2026 年 4 月 16 日

概要

AWS は Amazon EC2 C8in および C8ib インスタンスの一般提供開始 (GA) を発表しました。AWS 専用のカスタム第 6 世代 Intel Xeon Scalable プロセッサーと第 6 世代 AWS Nitro カードを搭載し、前世代の C6in インスタンスと比較して最大 43% のパフォーマンス向上を実現します。

C8in はネットワーク帯域幅に、C8ib は EBS 帯域幅にそれぞれ最適化された 2 つのバリアントです。両インスタンスとも最大 384 vCPU、768 GiB メモリまでスケールアップが可能です。

C8in と C8ib は同じプロセッサー基盤を共有しながら、それぞれネットワーク帯域幅と EBS 帯域幅に最適化されており、異なるワークロードに対応します。

主要機能

C8in - ネットワーク最適化
  • 最大 600 Gbps のネットワーク帯域幅 - 拡張ネットワーキング対応 EC2 インスタンスの中で最高
  • EBS 帯域幅は最大 120 Gbps
  • 分散コンピューティング、大規模データ分析、S3 やデータレイクからのデータ取り込みに最適
  • 大量のノード間通信を伴う HPC やクラスター型ワークロードに最適
C8ib - EBS 最適化
  • 最大 300 Gbps の EBS 帯域幅 - 非アクセラレーテッドコンピューティングインスタンスの中で最高
  • 最大 1,440K IOPS をサポート
  • インスタンスあたり最大 128 EBS ボリュームをサポート
  • 高パフォーマンスな商用 DB、ファイルシステム、NoSQL データベースに最適
共通の性能向上
  • カスタム第 6 世代 Intel Xeon Scalable プロセッサー (AWS 専用)
  • 第 6 世代 AWS Nitro カードによるセキュリティとパフォーマンスの最適化
  • C6in と比較して最大 43% のパフォーマンス向上
  • 最大 384 vCPU、768 GiB メモリまでスケールアップ可能

ステップ 1: C8in インスタンスを起動

Bash C8in インスタンス起動 - 東京リージョン 
# AWS CLI を使用して C8in インスタンスを起動
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c8in.24xlarge \
  --region ap-northeast-1 \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --security-group-ids sg-xxxxxxxxxxxxxxxxx \
  --key-name my-key-pair

東京リージョンで c8in.24xlarge を起動。150 Gbps のネットワーク帯域幅を備え、ネットワーク集約的なワークロードに適しています。

ユースケース

大規模分散データ分析
データレイクから大量のデータを取り込み、複数ノードで分散処理を行う大規模データ分析基盤
Bash C8in.48xlarge で分散分析ノードを起動 
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c8in.48xlarge \
  --count 10 \
  --region ap-northeast-1 \
  --placement "GroupName=analytics-cluster" \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=[sg-xxx]"
300 Gbps のネットワーク帯域幅により、ノード間のデータシャッフルと S3 からのデータ取り込みが高速化され、バッチ分析の処理時間を大幅に短縮
高パフォーマンス商用データベース
Oracle Database や SQL Server など、高い IOPS と EBS スループットを要求する商用データベースの運用
Bash C8ib.96xlarge で高パフォーマンス DB サーバーを起動 
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c8ib.96xlarge \
  --region us-east-1 \
  --block-device-mappings '[
    {"DeviceName":"/dev/sdf","Ebs":{"VolumeSize":1000,"VolumeType":"io2","Iops":64000}},
    {"DeviceName":"/dev/sdg","Ebs":{"VolumeSize":2000,"VolumeType":"io2","Iops":64000}}
  ]'
300 Gbps の EBS 帯域幅と 1,440K IOPS により、データベースのクエリ応答時間とバッチ処理スループットが大幅に改善
高パフォーマンスファイルシステム
Amazon FSx for Lustre や Amazon FSx for NetApp ONTAP を使用した高パフォーマンスファイルシステムのバックエンド
Bash C8ib.48xlarge でファイルシステムクライアントを起動 
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type c8ib.48xlarge \
  --region us-east-1 \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --security-group-ids sg-xxxxxxxxxxxxxxxxx
150 Gbps の EBS 帯域幅により、ファイルシステムへの読み書きスループットが向上し、メディア処理や科学計算ワークロードのパフォーマンスが改善

メリット・デメリット

ビジネス面のメリット

C8in の 600 Gbps により少ないインスタンス数で大規模データ転送を処理でき、インフラコストを削減
C8ib の 300 Gbps EBS と 1,440K IOPS で商用 DB の応答時間を短縮し、SLA 達成が容易に
C8in が東京リージョンで利用可能。日本国内のワークロードを低レイテンシーで実行可能

技術面のメリット

C8in の 600 Gbps は拡張ネットワーキング対応 EC2 インスタンスの中で最高のネットワーク帯域幅
C8ib の 300 Gbps EBS / 1,440K IOPS は非アクセラレーテッドインスタンスの中で最高
C6in 比最大 43% のパフォーマンス向上で同じワークロードをより少ないリソースで処理可能
第 6 世代 Nitro カードによるハードウェアレベルのセキュリティとパフォーマンス最適化

制限事項

C8ib は米国東部と米国西部の 2 リージョンのみ。東京リージョンでは未提供
C8in は 4 リージョンのみの提供。一部のリージョンでは利用不可
新しいインスタンスタイプのため、すべての AMI やソフトウェアが最適化されていない場合がある

考慮すべき点

ワークロードの I/O パターンに応じて C8in / C8ib の適切なバリアントを選択する必要がある
ネットワークと EBS の両方で高い性能が必要な場合、アーキテクチャの分離を検討
C6in / C6id からの移行時にはアプリケーション互換性テストとベンチマークを実施すること

料金

C8in および C8ib インスタンスの料金は、選択したインスタンスタイプ、リージョン、購入オプションによって異なります。

オンデマンド 使用した分だけ支払い。初期費用やコミットメント不要
Savings Plans 1 年または 3 年のコミットメントで大幅な割引
スポットインスタンス 未使用の EC2 容量を大幅な割引で利用。中断耐性のあるワークロード向け

詳細な料金については Amazon EC2 料金ページ を参照してください。

関連サービス・機能

Amazon EC2 C8i / C8i-flex
同じ第 6 世代 Intel Xeon プロセッサー搭載の汎用コンピューティング最適化インスタンス。ネットワークや EBS の特別な最適化が不要な場合に適している
Amazon EBS
C8ib と組み合わせて最大 300 Gbps の EBS 帯域幅と 1,440K IOPS を活用した高パフォーマンスストレージを実現
Elastic Fabric Adapter
C8in の高帯域幅ネットワークと組み合わせ、HPC や ML の分散ワークロードでの低レイテンシー通信を実現
AWS Nitro System
第 6 世代 Nitro カードにより、ハードウェアレベルのセキュリティ分離とパフォーマンス最適化を提供
