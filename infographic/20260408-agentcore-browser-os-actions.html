OS Level Interaction

Amazon Bedrock AgentCore
2026-04-08

📋 Overview

Amazon Bedrock AgentCore Browser に OS レベルのインタラクション機能が追加されました。 Chrome DevTools Protocol (CDP) だけでは対応できなかったブラウザワークフローの自動化が可能になります。 マウス操作、キーボード操作、デスクトップ全体のスクリーンショット取得など、OS レベルの座標系を活用した操作を 新しい InvokeBrowser API 経由で実行できます。

❌ Before

  • CDP のみでは印刷ダイアログ、ネイティブシステムアラート、ファイル選択ダイアログなど OS レベルの UI 要素を操作できなかった
  • ブラウザビューポート外の要素に対するインタラクションが制限されていた
  • 右クリックメニューやキーボードショートカットを含む複雑な UI 操作の自動化が困難だった

✅ After

  • OS レベルの座標系でマウス操作 (クリック、移動、ドラッグ、スクロール) が可能に
  • キーボード操作 (テキスト入力、キー押下、ショートカット) を API 経由で実行可能に
  • デスクトップ全体のスクリーンショットを取得でき、ビジョンベース AI エージェントがブラウザ環境全体を視覚的に把握可能に

⚡ Key Features

🖱️

Mouse Operations

  • Left / Right / Middle button click
  • Click count specification (double-click etc.)
  • Mouse move to coordinates
  • Drag from start to end coordinates
  • Horizontal / Vertical scroll (deltaX / deltaY)
⌨️

Keyboard Operations

  • keyType: Direct text input
  • keyPress: Key press with count
  • keyShortcut: Ctrl+A, Ctrl+P etc.
📸

Screenshot Capture

  • Full desktop PNG screenshot
  • OS-level coordinate capture beyond viewport
  • Vision-based AI agent screen recognition

🔧 Technical Specifications

Item Details
API Name InvokeBrowser
Required Parameters browserIdentifier, sessionId, action
Mouse Button Types LEFT, RIGHT, MIDDLE
Screenshot Format PNG
Response status (SUCCESS / FAILED) + error info

💻 Code Examples

Python Mouse Click 
import boto3

client = boto3.client('bedrock-agentcore')

# Mouse click operation
response = client.invoke_browser(
    browserIdentifier='my-browser',
    sessionId='session-123',
    action={
        'mouseClick': {
            'x': 500,
            'y': 300,
            'button': 'LEFT',
            'clickCount': 1
        }
    }
)
Python Keyboard Shortcut 
# Keyboard shortcut operation
response = client.invoke_browser(
    browserIdentifier='my-browser',
    sessionId='session-123',
    action={
        'keyShortcut': {
            'keys': ['ctrl', 'p']
        }
    }
)
Python Screenshot Capture 
# Screenshot capture
response = client.invoke_browser(
    browserIdentifier='my-browser',
    sessionId='session-123',
    action={
        'screenshot': {
            'format': 'PNG'
        }
    }
)
screenshot_data = response['result']['screenshot']['data']

⚙️ Setup

Prerequisites

  • Amazon Bedrock AgentCore enabled in AWS account
  • AgentCore Browser session created
  • IAM policy allowing bedrock-agentcore:InvokeBrowser action

IAM Policy

JSON IAM Policy for InvokeBrowser 
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": [
                "bedrock-agentcore:InvokeBrowser",
                "bedrock-agentcore:CreateSession",
                "bedrock-agentcore:ListSessions"
            ],
            "Resource": "*"
        }
    ]
}

⚠️ Production environments should restrict Resource to specific browser ARNs.

✅ Benefits

💼 Business

  • Expanded browser automation scope: Native dialogs and system alerts can now be automated, improving E2E test coverage
  • Document management efficiency: Workflows including print dialogs and file upload/download can be fully automated
  • Improved AI agent practicality: Vision-based AI agents can understand and operate the full browser environment

🔧 Technical

  • CDP constraints resolved: Operations beyond browser viewport and native UI elements now possible
  • Unified API design: Mouse/keyboard/screenshot all unified in single InvokeBrowser API
  • Error handling: Individual success/failure status with error info per operation

⚠️ Limitations & Considerations

  • 🔸 Screenshot format is currently PNG only
  • 🔸 OS-level operations require coordinate specification, potentially affected by screen resolution and layout changes
  • 🔸 Empty sessions are automatically deleted after 1 day
  • 🔸 OS-level coordinate system depends on browser zoom level and DPI settings - coordinate consistency across environments requires attention
  • 🔸 Screen state may change between screenshot capture and action execution when used with vision-based AI agents
  • 🔸 Proper design to distinguish between CDP-based and OS-level operations is important
