🚀 C9g / C9gd インスタンス
AWS Graviton5 搭載で一般提供開始

2026-06-30
Compute Optimized ファミリー

📌 概要

AWS は第 5 世代のカスタム設計 CPU AWS Graviton5 を搭載した Amazon EC2 C9g / C9gd インスタンスの一般提供 (GA) を開始しました。 コンピューティング最適化ファミリーとして、Amazon EC2 上で最高のコストパフォーマンスを提供します。

C9g は HPC 、バッチ処理、ゲーミング、動画エンコーディング、科学技術モデリング、CPU ベースの ML 推論、 リアルタイム分析などに最適です。C9gd はこれに加え、スクラッチ領域や一時ファイル向けの 高速・低レイテンシーなローカル NVMe SSD ストレージを備えます。

Graviton5 搭載の C9g / C9gd は第 6 世代 Nitro System 上に構築され、Nitro Isolation Engine が形式的検証によって ワークロード間の分離を保証します。C9g は Amazon EBS を、C9gd はローカル NVMe SSD を利用できます。

✨ 主要機能

🧠 AWS Graviton5 プロセッサ

  • AWS がカスタム設計した第 5 世代 CPU
  • コンピューティング負荷の高いワークロードで EC2 上最高のコストパフォーマンス
  • 常時オンのメモリ暗号化、vCPU ごとの専用キャッシュ、ポインタ認証をサポート

⚡ C8g / C8gd 比での性能向上

  • コンピューティング性能が最大 25% 向上
  • DB +30% 、Web アプリ +35% 、機械学習 +35% の高速化
  • 5 倍のキャッシュとクラウド最速クラスのメモリを搭載

🔒 Nitro Isolation Engine

  • 第 6 世代 AWS Nitro System 上に構築された初のインスタンス
  • 形式的検証で、ワークロード間・AWS オペレーターからの分離を数学的に保証
  • 数学的に証明されたクラウドセキュリティの新たな標準を切り拓く

💽 C9gd のローカル NVMe ストレージ

  • スクラッチ領域、一時ファイル、キャッシュ向けの高速・低レイテンシーな NVMe SSD ブロックストレージを提供

⚠️ デメリット・制約事項

制限事項

!提供リージョンが米国東部 (バージニア北部、オハイオ)、米国西部 (オレゴン)、欧州 (フランクフルト) に限定。東京リージョンなどでは未提供
!Arm アーキテクチャ (AWS Graviton) ベースのため、x86 依存のバイナリは Arm 向けのビルド・検証が必要

考慮すべき点

!C9gd のローカル NVMe はインスタンス停止・終了でデータが失われる。永続化には EBS や S3 を併用
!x86 ベースからの移行時は、性能・互換性の検証を事前に実施することを推奨

🎯 ユースケース

1. HPC / 科学技術モデリング

大規模な数値シミュレーションや科学技術計算をコスト効率よく実行したい研究機関・エンジニアリング部門。
高いコンピューティング性能と大容量キャッシュで、演算集約型ジョブのスループットを向上しつつコストを抑制。

2. CPU ベースの ML 推論

低コストで大量の推論リクエストをさばく必要がある機械学習アプリケーション。
機械学習で最大 35% の高速化により、より少ないインスタンス数で処理でき推論コストを削減。

3. 動画エンコーディング / バッチ処理

一時ファイルや中間データを多用する動画トランスコードや大規模バッチ処理パイプライン。
C9gd のローカル NVMe SSD でスクラッチ領域への高速 I/O が可能となり、処理時間を短縮。

💰 料金 & 🌍 利用可能リージョン

C9g / C9gd は Savings Plans 、オンデマンド、スポット、Dedicated Instances 、Dedicated Hosts で購入できます。 料金はリージョンおよびインスタンスサイズにより異なるため、最新の価格は Amazon EC2 の料金ページを参照してください。

📝 まとめ

Amazon EC2 C9g / C9gd は、AWS Graviton5 と第 6 世代 Nitro System により、 コンピューティング負荷の高いワークロード向けに最大 25% の性能向上と 数学的に保証された分離を提供します。

C8g / C8gd を利用中のお客様は、対象リージョンで C9g / C9gd を起動し、 既存ワークロードとの互換性と性能を評価しながら、コストパフォーマンス改善を検証することを推奨します。
