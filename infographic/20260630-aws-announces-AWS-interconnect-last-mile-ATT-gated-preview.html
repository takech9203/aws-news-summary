AWS Interconnect - last mile 🔒 ゲート付きプレビュー 📅 2026 年 6 月 30 日

数クリックで拠点を AWS へプライベート接続
AT&T パートナーのフルマネージド ラストマイル接続

支社・データセンター・リモート拠点から AWS への専用線接続を、BGP・VLAN・ASN の複雑な構成なしで確立できるフルマネージドサービス。AWS のクラウドイノベーションと AT&T の広範なネットワークフットプリントを組み合わせ、企業のクラウド接続方法を刷新します。

📌 概要 : 何が変わったのか

利用者は希望する AWS リージョン、帯域速度、Direct Connect Gateway ID、パートナーサブスクライバー ID を選択するだけで、AWS へのプライベートかつ高速な接続を即座に確立できます。従来は専門知識が必要だった複雑なネットワーク構成が自動化されます。

⚠️ アップデート前の課題
  • ラストマイル回線の手配とネットワーク機器の設定を個別に実施する必要があった
  • BGP ピアリング・VLAN 設定・ASN 割り当てを手動構成 — 専門知識と時間を要した
  • キャリアと AWS 側のプロビジョニングを別々に調整 — 接続確立まで時間がかかった
➡
✨ アップデート後の改善
  • リージョン・帯域・DX Gateway ID・サブスクライバー ID の指定だけで数クリックで開始
  • BGP・VLAN・ASN の複雑な構成が自動化され、手動設定が不要に
  • 容量の事前プロビジョニング + ゼロダウンタイムメンテナンス + SLA による高可用性

🚀 主要機能

1. 数クリックでのラストマイル接続の確立

  • リージョン・帯域速度・DX Gateway ID・サブスクライバー ID を選ぶだけでプライベート高速接続を開始
  • 接続開始後、AWS がアクティベーションキーを生成し、AT&T でのプロビジョニングを完了
  • 拠点から AWS までの最終区間 (ラストマイル) を複雑なセットアップなしに実現

2. 複雑なネットワーク構成の自動化

  • BGP ピアリング・VLAN 設定・ASN 割り当てを自動的に構成
  • 容量の事前プロビジョニングにより接続確立を迅速化
  • ネットワークの専門知識がなくても接続を構築可能

3. 高可用性とゼロダウンタイムメンテナンス

  • 高可用性を考慮した設計で、SLA によるサポートを提供
  • ゼロダウンタイムメンテナンスにより、運用中の接続への影響を抑制

4. パートナー向けオープン API パッケージ

  • GitHub 公開のオープン API パッケージ (OpenAPI 3.0 仕様) を通じて容易にサービスへ参画
  • マネージドな L3 (レイヤー 3) 接続を調整するための対称型 API を定義

💡 メリット

📈 ビジネス面

  • 接続構築の迅速化 : 数クリックで接続を開始でき、接続確立時間を短縮
  • 運用負荷の軽減 : 複雑な構成が自動化され、専門人材への依存を低減
  • 信頼性の担保 : SLA に裏付けられた高可用性でミッションクリティカルにも適用可能

⚙️ 技術面

  • 構成の自動化 : BGP・VLAN・ASN の設定が自動化され設定ミスのリスクを低減
  • ゼロダウンタイム : 運用中の接続に影響を与えずメンテナンス実施
  • 標準化された連携 : オープン API によりパートナー連携が標準化

⚠️ デメリット・制約事項

制限事項

•現時点ではゲート付きプレビュー — 利用にはアクセスリクエストと承認が必要
•提供対象は米国のお客様に限定
•現時点でのパートナーは AT&T のみ

考慮すべき点

•AT&T のネットワークフットプリントが利用可能なエリアか事前確認が必要
•料金体系はプレビュー段階では公開情報が限られ、AWS アカウントチームへの確認を推奨

🎯 ユースケース

ユースケース 1 : 支社から AWS へのプライベート接続

シナリオ : 米国内に複数の支社を持つ企業が、各拠点から AWS 上の業務システムへ低レイテンシかつセキュアに接続したい。

効果 : 各支社から AT&T のラストマイル回線経由で AWS へ数クリックで接続でき、拠点ごとの複雑なネットワーク設定作業を削減。

ユースケース 2 : オンプレミスデータセンターとのハイブリッド接続

シナリオ : オンプレミス DC を運用する企業が、AWS とのハイブリッド構成でミッションクリティカルなワークロードを稼働させたい。

効果 : Direct Connect Gateway 経由のプライベート接続を SLA 付きで確立でき、高可用性が求められるハイブリッド環境の信頼性を向上。

ユースケース 3 : パートナーによる接続サービスの提供

シナリオ : ネットワークサービスプロバイダーが、自社顧客に対して AWS への接続サービスを標準化された形で提供したい。

効果 : GitHub 公開のオープン API パッケージ (OpenAPI 3.0) を活用し、マネージドな L3 接続を調整する標準化されたインテグレーションを構築。

🔗 関連サービス・機能

  • AWS Direct Connect : 専用のネットワーク接続を提供。AWS Interconnect - last mile は DX Gateway と連携してプライベート接続を確立
  • AWS Direct Connect Gateway : 複数の VPC やリージョンへの接続を集約するゲートウェイ。接続作成時に ID を指定
  • Amazon VPC : 接続先となる仮想プライベートクラウド。ラストマイル接続を通じてプライベートにアクセス

📝 まとめ

AWS Interconnect - last mile は、BGP・VLAN・ASN といった複雑なネットワーク構成を自動化し、数クリックで拠点から AWS へのプライベート接続を確立できるフルマネージドサービスです。現時点では AT&T をパートナーとした米国向けのゲート付きプレビューですが、ラストマイル接続の構築を大幅に簡素化する点で注目に値します。対象となるお客様は、プレビューアクセスをリクエストし、既存の Direct Connect Gateway と組み合わせて評価を進めることを推奨します。
