📞 Amazon Connect Customer
コンタクトレコードへの関連ケース表示

📅 リリース日: 2026 年 11 月 4 日 | 対象: Amazon Connect Customer / Connect Customer Cases

📝 概要

Amazon Connect Customer が、コンタクトレコードにケース ID と参照番号を表示する機能を発表。 スーパーバイザーや分析担当者は、どの顧客課題 (ケース) がコンタクトボリュームを生み出しているかを把握できるようになります。

ケースは、請求に関する問い合わせや返金リクエストなど、複数のやり取り・複数のチームにまたがる顧客課題を追跡する機能です。コンタクト詳細ページでの直接確認に加え、DescribeContact API やコンタクトイベントストリームからも同じデータを取得できます。

😓 Before: アップデート前の課題
  • コンタクト詳細ページから関連ケースを直接確認できなかった
  • スーパーバイザーはケースを 1 件ずつ検索する必要があった
  • 「どのケースがどれだけのコンタクトを生んでいるか」の定量把握が困難だった
😊 After: アップデート後の改善
  • コンタクト詳細ページでケースの ID と参照番号を直接確認できる
  • 個別検索が不要になり、スーパーバイザーの調査作業が効率化
  • DescribeContact API・イベントストリーム経由でケースごとのコンタクト件数を分析できる

コンタクトに関連付けられたケースの ID と参照番号がコンタクトレコードに記録され、コンタクト詳細ページ、DescribeContact API、コンタクトイベントストリームの 3 つの経路から参照できる構成です。

⚙️ 主要機能

🖥️ 1. コンタクト詳細ページでの関連ケース表示
  • コンタクト詳細ページ上に、そのやり取りに紐づくケースが表示される
  • スーパーバイザーがケースを 1 件ずつ検索する必要がなくなる
  • 顧客対応の全体像をコンタクト単位で素早く把握できる
🔌 2. DescribeContact API による関連ケース情報の取得
  • コンタクトレコードに含まれるケース ID と参照番号を API 経由で取得
  • 外部の分析基盤やレポーティングツールとの連携が可能
  • ケースごとに何件のやり取りが発生したかを定量的に測定できる
⚡ 3. コンタクトイベントストリームへの反映
  • コンタクトイベントストリームからも関連ケース情報を取得できる
  • ニアリアルタイムでのモニタリングや自動処理への活用が可能

🛠️ 設定方法

✅ 前提条件

✓Amazon Connect インスタンスで Connect Customer Cases (ケース機能) が有効化されていること
✓エージェントまたはフローにより、コンタクトとケースの関連付けが行われていること
✓コンタクト詳細の閲覧や DescribeContact API 呼び出しに必要な権限が付与されていること

📝 手順

1
コンタクト詳細ページで関連ケースを確認する

Amazon Connect の管理 Web サイトでコンタクト検索からコンタクト詳細ページを開くと、関連付けられたケースの情報を確認できます。追加の設定作業は不要です。

2
DescribeContact API で関連ケース情報を取得する
Bash DescribeContact API の呼び出し 
aws connect describe-contact \
  --instance-id <インスタンス ID> \
  --contact-id <コンタクト ID>

レスポンスに、関連付けられたケースのケース ID と参照番号が含まれます。

3
コンタクトイベントストリームで関連ケース情報を活用する

コンタクトイベントストリーム (Amazon EventBridge 経由) を設定している場合、イベントデータから関連ケース情報を取得し、分析基盤への取り込みや自動処理に活用できます。

⚠DescribeContact API やイベントストリームを利用した分析基盤の構築には別途実装が必要となる
