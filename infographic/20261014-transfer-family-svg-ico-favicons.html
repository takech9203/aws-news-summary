AWS Transfer Family

🎨 Web アプリの SVG ロゴ・ICO ファビコン対応

コンソールでのブランディングアセットのアップロードが大幅に改善 | リリース日: 2026 年 10 月 14 日

📋 概要

AWS Transfer Family コンソールが、Web アプリのブランディングカスタマイズにおいて、ロゴ用の SVG ファイルとファビコン用の ICO ファイルのアップロードに対応しました。あわせて、アップロードサイズの上限が 2 MB に引き上げられています。

Transfer Family Web アプリは、ブラウザ経由で Amazon S3 とデータを転送できるシンプルなインターフェイスを提供する機能です。コンソールはアップロードされた画像を自動的にリサイズし、JPG または PNG に変換してから保存します。なお、API 経由でのアップロード制限とフォーマット要件は変更されていません。

❌ アップデート前の課題
✗コンソールは JPG と PNG のみ受け付け、SVG や ICO は事前の変換が必要だった
✗ロゴ上限 50 KB、ファビコン上限 20 KB と小さく、縮小・圧縮の手間が発生していた
✗画像の変換・圧縮作業のために別途ツールが必要だった
✅ アップデート後の改善
✓ロゴに SVG、ファビコンに ICO を直接アップロード可能に
✓アップロード上限が 2 MB に引き上げられ、事前のサイズ調整が不要に
✓コンソールが自動的にリサイズして JPG / PNG に変換するため、手動加工が不要に

⚡ 主要機能

🖼️ SVG ロゴのサポート
  • →Web アプリのロゴとして SVG ファイルを直接アップロード可能
  • →ベクター形式の企業ロゴをそのまま利用でき、事前のラスタライズ変換が不要
  • →従来の JPG / PNG 形式も引き続き利用可能
🔖 ICO ファビコンのサポート
  • →Web アプリのファビコンとして ICO ファイルを直接アップロード可能
  • →既存の Web サイトで使用しているファビコンをそのまま流用できる
  • →従来の JPG / PNG 形式も引き続き利用可能
📈 アップロード上限の引き上げと自動変換
  • →ロゴ・ファビコンともにアップロード上限が 2 MB に拡大
  • →コンソールが画像を自動的にリサイズし、JPG または PNG に変換して保存
  • →手動での画像圧縮・リサイズ作業が不要に

📌 注意事項
自動変換はコンソールからのアップロードに適用されます。API 経由でブランディングアセットを設定する場合、既存のアップロード制限とフォーマット要件が引き続き適用されます。

🛠️ 設定方法

✅ 前提条件

✓AWS IAM Identity Center のインスタンス (アカウントインスタンスまたは組織インスタンス) が設定済みであること
✓Web アプリで使用する Amazon S3 バケットが用意されていること
✓Transfer Family Web アプリを作成する権限を持つこと

📝 手順

  1. Web アプリの作成またはデザイン設定を開く
    Transfer Family コンソールで [Web apps] を選択し、新規作成時は [Create web app]、既存の Web アプリの場合は対象を選択して編集画面に進みます。
  2. ロゴとファビコンをアップロード
    [Design web app] ページで、ページタイトル (未入力の場合は「Transfer Web App」)、ロゴ (SVG / JPG / PNG、最大 2 MB)、ファビコン (ICO / JPG / PNG、最大 2 MB) を設定します。コンソールが自動的にリサイズし、JPG または PNG に変換して保存します。
  3. 変更の確認
    Web アプリのアクセスエンドポイントにブラウザでアクセスし、ロゴとファビコンが正しく表示されることを確認します。

💡 メリット

💼 ビジネス面
  • ✓ブランド体験の向上: 既存アセットをそのまま使用でき、一貫性のあるブランド体験を提供
  • ✓作業時間の短縮: 画像の変換・圧縮作業が不要になり、セットアップが迅速化
  • ✓デザイン部門との連携簡素化: 受領した SVG ロゴや ICO ファビコンを加工せずに利用可能
⚙️ 技術面
  • ✓自動変換による簡素化: 画像処理の知識やツールが不要
  • ✓上限緩和による柔軟性: 2 MB までの高解像度アセットで品質劣化を回避
  • ✓後方互換性: 従来の JPG / PNG もサポートされ、既存ワークフローへの影響なし

⚠️ デメリット・制約事項

制限事項
  • ✗画像は最終的に JPG / PNG に変換されるため、SVG のベクター特性 (拡大縮小時の品質維持) は保存後には引き継がれない
  • ✗API 経由のアップロードには従来の制限とフォーマット要件が引き続き適用される
  • ✗アップロード上限は 2 MB で、それを超えるファイルは事前に圧縮が必要
🤔 考慮すべき点
  • →自動リサイズ・変換後の見た目が意図通りか、実際の Web アプリ画面で確認することを推奨
  • →IaC (API / CloudFormation など) でブランディングを管理している場合は、コンソールとは異なる制限が適用される点に注意

🎯 ユースケース

1. 取引先向けファイル転送ポータルのブランディング

シナリオ: 製造業の企業が、取引先とのファイル授受に Web アプリを利用。コーポレートアイデンティティ部門からは SVG 形式のロゴのみが提供されている。

実装: 対象の Web アプリを選択 → デザイン設定で SVG ロゴ (最大 2 MB) をアップロード → アクセスエンドポイントで表示を確認

✅ 効果: SVG から PNG への手動変換作業が不要になり、ブランドガイドラインに準拠したポータルを短時間で構築できる。
2. 既存 Web サイトのファビコンの流用

シナリオ: 既存のコーポレートサイトで使用している ICO 形式のファビコンを Web アプリにも適用し、一貫したユーザー体験を提供したい。

実装: 既存サイトの favicon.ico を取得 → コンソールのデザイン設定でファビコンとしてアップロード → ブラウザのタブ表示を確認

✅ 効果: 既存アセットの再利用により、ブラウザタブ上でも自社サービスとして認識されやすくなる。
3. 高解像度ロゴによる品質改善

シナリオ: 従来は 50 KB の制限により低解像度に圧縮したロゴを使用しており、表示品質に課題があった。

実装: 高解像度のロゴ画像 (2 MB 以内) を用意 → コンソールから再アップロード → 自動リサイズ後の表示品質を確認

✅ 効果: 事前圧縮による画質劣化を回避し、より鮮明なロゴ表示を実現できる。

💰 料金・利用可能リージョン

💵 料金

今回のアップデート自体に追加料金はありません。Transfer Family Web アプリの料金は、プロビジョニングした Web アプリユニット数に基づく従量課金です。

🌍 利用可能リージョン

Transfer Family Web アプリが提供されているすべての AWS リージョンで利用可能です。

🔗 関連サービス・機能

🪣 Amazon S3

Web アプリ経由でファイルを転送する対象のストレージ。S3 Access Grants によるアクセス制御と連携。

🔐 AWS IAM Identity Center

Web アプリのユーザー認証基盤。外部 IdP (Okta など) との連携も可能。

🌐 Amazon CloudFront

カスタム URL を使用した Web アプリのブランド化で利用されるケースがある。

📝 まとめ

AWS Transfer Family コンソールが SVG ロゴと ICO ファビコンに対応し、アップロード上限も 2 MB に拡大されたことで、既存のブランディングアセットをそのまま活用した Web アプリのカスタマイズが容易になりました。

Transfer Family Web アプリを運用中で、低解像度ロゴや形式変換の手間に課題を感じていた場合は、コンソールからアセットの再アップロードを検討することを推奨します。
