ユーザーが自然言語でプロンプトを入力し、データセットを選択すると、AI エンジンがプロンプトを解析して分析プランを生成。レビュー後にダッシュボードが自動生成され、既存のワークフローに統合可能。

📝 概要

自然言語のプロンプトからダッシュボードを自動生成する新機能。最大 3 つのデータセットを選択し、編集可能なプランをレビューした上でダッシュボードを生成できる。

Before
  • 手動で数時間の設定作業
  • DAX 計算式の知識が必要
  • BI チームへの依頼が必須
→
After
  • 数分でダッシュボード完成
  • 計算フィールド自動生成
  • セルフサービスで作成可能

✨ 主要機能

💬
自然言語によるダッシュボード定義
目標を自然言語で記述するだけで AI が解析。専門的な BI スキル不要
📊
データセット選択と分析プラン
最大 3 つのデータセットを選択。生成前に編集可能なプランをレビュー
🎨
インテリジェントなビジュアル生成
データ特性に基づく最適なビジュアルタイプ自動選択、フィルターコントロール自動配置
🧮
計算フィールドの自動生成
YoY (前年比成長率)、MoM (前月比比較) などの分析指標を自動生成
🔌
既存ワークフローとの互換性
パブリッシュ、埋め込み、CI/CD、ポイントアンドクリック編集に対応

⚙️ 設定方法

前提条件: Enterprise サブスクリプション + Author Pro ユーザー + 登録済みデータセット

1
Generate Analysis の開始

コンソールから新しい Analysis 作成 → Generate Analysis を選択

2
自然言語プロンプトの入力

ビジネスゴール、含めたい指標、比較の軸を明確に記述

3
データセットの選択

最大 3 つ選択。スキーマ情報が AI エンジンに渡される

4
分析プランのレビューと編集

シート構成、ビジュアル種類、計算フィールド、フィルター配置を確認

5
ダッシュボードの生成と調整

自動生成後、ポイントアンドクリック編集で詳細調整→パブリッシュ

🎯 メリット

ビジネス面

  • 🚀 Time to Insight の大幅短縮 - 数時間 → 数分に短縮
  • 👥 BI 専門リソースの最適化 - バックログ削減
  • 🌐 セルフサービス分析の民主化 - 専門知識不要

技術面

  • 🔗 既存 CI/CD パイプラインと完全互換
  • 🧮 YoY/MoM 計算式の自動生成でエラーリスク低減
  • 👁️ 編集可能な中間プランで品質を制御可能

⚠️ デメリット・制約事項

  • Enterprise + Author Pro のみ利用可能 (Standard / 通常 Author は不可)
  • データセットは最大 3 つまで
  • 業界固有の複雑な指標は手動追加が必要な場合あり
  • プロンプトの記述精度がダッシュボード品質に直結
  • Author Pro ライセンスコスト: $40/月 + インフラ費用 $250/月
