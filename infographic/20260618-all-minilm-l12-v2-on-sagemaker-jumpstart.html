Amazon SageMaker JumpStart

📦 all-MiniLM-L12-v2 の提供開始

セマンティック検索・文章類似度向け軽量テキスト埋め込みモデル

🗓️ 2026年6月18日

📝 概要

AWS は、Sentence Transformers が開発したテキスト埋め込みモデル all-MiniLM-L12-v2 を Amazon SageMaker JumpStart で利用可能にしました。文や段落を 384 次元の密ベクトルにマッピングし、セマンティック検索・テキストクラスタリング・文章類似度などのユースケースをサポートします。

33.4M パラメータという小さなフットプリントで高速な推論を実現しながら、本番スケールに耐える高い埋め込み品質を維持。SageMaker Studio または Python SDK から数クリックでデプロイでき、RAG パイプラインやベクトル検索基盤の構築を素早く開始できます。

  • JumpStart から数クリックでデプロイ可能に
  • 12 層アーキテクチャで L6 系より高品質、かつ軽量・高速推論を維持
  • 最小限の設定で埋め込み基盤を本番運用へ展開できる

アプリケーションはテキストを SageMaker 推論エンドポイントに送信し、384 次元の埋め込みベクトルを取得します。取得したベクトルは OpenSearch や pgvector などのベクトルストアに登録・検索され、セマンティック検索や RAG を実現します。

⚡ 主要機能

🎯 384 次元の密ベクトル生成

  • 文や段落を 384 次元の密ベクトル空間にマッピング
  • 意味的な情報を捉え、表層的な単語一致を超えた類似度比較が可能
  • 情報検索・セマンティック検索・クラスタリング・重複検出・言い換え識別に利用

🧠 12 層アーキテクチャで高品質と高速推論を両立

  • microsoft/MiniLM-L12-H384-uncased をベースとした 12 層 BERT 系トランスフォーマー (33.4M パラメータ)
  • 小さなフットプリントで高速推論を実現しつつ、本番スケールでも高い品質を維持
  • 軽量な L6 系モデルより深い層構造で高品質な埋め込みが期待できる

🚀 SageMaker JumpStart からの簡単なデプロイ

  • SageMaker Studio の Models 画面から数クリックでデプロイ可能
  • SageMaker Python SDK によるコードベースのデプロイにも対応
  • デプロイ後は推論エンドポイント経由で埋め込み生成を呼び出せる

ステップ 2: モデルをデプロイ

PythonJumpStartModel でデプロイ
from sagemaker.jumpstart.model import JumpStartModel

# JumpStart モデル ID を指定してモデルを初期化
model = JumpStartModel(model_id="huggingface-sentencesimilarity-all-minilm-l12-v2")

# 推論エンドポイントへデプロイ
predictor = model.deploy()
📌 実際のモデル ID やインスタンスタイプは SageMaker JumpStart のモデルカードおよびドキュメントで確認してください。

ステップ 3: 埋め込みを生成

Pythonテキストから 384 次元ベクトルを取得

⚠️ デメリット・制約事項

制限事項

!最大シーケンス長は 256 word pieces。超過する長文は切り捨てられる (長文はチャンク分割が必要)
!学習データの大半が英語コーパス。多言語・日本語特有のタスクでは品質を事前検証する必要がある
!384 次元は効率に優れる一方、最大精度を求めるタスクでは高次元モデルに劣る場合がある

🎯 ユースケース

1. 社内ドキュメント検索 (RAG)

社内ナレッジベースを対象に、自然言語の質問から関連ドキュメントを検索する RAG パイプラインを構築。

Flow
ドキュメント → all-MiniLM-L12-v2 で埋め込み生成 → ベクトルストアに登録
質問 → 埋め込み生成 → ベクトル類似度検索 → 関連文書を LLM へ渡して回答生成

✅ 効果: キーワード一致では拾えない意味的に関連する文書を検索でき、回答精度が向上

2. 重複・類似コンテンツの検出

大量のテキストデータ (問い合わせ、レビュー、記事) から重複や言い換えを検出。

Flow
各テキストを埋め込みベクトル化 → ベクトル間のコサイン類似度を計算
→ 閾値を超えるペアを重複・類似候補として抽出

✅ 効果: 表現が異なる重複コンテンツを高精度に検出し、データ品質向上や名寄せを自動化

3. テキストクラスタリングによる分類

ラベルのない大量のテキストを意味的に近いグループへ自動分類。

Flow
テキスト群を埋め込みベクトル化 → k-means などのクラスタリングを適用
→ 意味的に近いトピックごとにグループ化

✅ 効果: 教師データなしでトピックの傾向を把握でき、問い合わせ分類やコンテンツ整理を効率化

💰 料金・利用可能リージョン

料金: モデル自体は Apache 2.0 ライセンスの OSS であり、ソフトウェア利用料は発生しません。課金は、デプロイした SageMaker 推論エンドポイントで使用するインスタンスの稼働時間に対して発生します (インスタンスタイプ・リージョンで変動)。

利用可能リージョン: What's New 発表時点では明示されていません。最新の対応リージョンおよびインスタンスタイプは、SageMaker JumpStart のモデルカードおよび公式ドキュメントで確認してください。
