📌 概要

AWS は、Anthropic の Claude Fable 5 が一般提供 (GA) になったことを発表しました。初めて一般提供される Mythos クラスのモデルであり、より広範な利用を安全にするための強力なセーフガード (安全分類器) を備えた状態で、Mythos レベルの能力をすべてのお客様に提供します。

テストされたほぼすべてのベンチマークで 最高水準 (state-of-the-art) を達成。複雑なナレッジワークやコーディングタスクを、人間の介入なしで長時間にわたって自律実行できるよう設計され、金融・法務・マーケティング・営業・データ・エンジニアリングといった専門業務向けに構築されています。

なお、安全分類器を含まない同一モデルの Claude Mythos 5 は、現在 Claude Mythos Preview のアクセス権を持つ少数のお客様に限定提供されています。

⏪ アップデート前の課題

  • Mythos レベルの最先端能力が一般向けに提供されていなかった
  • 長時間の自律タスクを安全に本番実行できるモデルの選択肢が限定的
  • 専門業務特化の最高水準モデルを AWS ガバナンスと組み合わせる手段が限定的
➡

⏩ アップデート後の改善

  • 強力なセーフガード付き Mythos クラスを全顧客が GA で利用可能
  • 人間の介入なしで長時間自律実行する最高水準モデルを本番活用
  • Bedrock 経由でデータを AWS 内に保持し Guardrails / KB と統合

Claude Fable 5 へは、AWS マネージド機能を備えた Amazon Bedrock 経由、または Anthropic 運用の Claude Platform on AWS 経由の 2 通りでアクセスできます。

⭐ 主要機能

🚀

初の一般提供 Mythos クラスモデル

  • Mythos レベルの能力を全顧客が GA で利用可能
  • 広範な利用を安全にする強力なセーフガード (安全分類器) を内蔵
  • 分類器なしの Claude Mythos 5 は Preview 限定提供
📊

最高水準のベンチマーク性能

  • テスト済みのほぼ全ベンチマークで state-of-the-art を達成
  • 自律ナレッジワークとコーディングで段階的な進化
  • 本番 AI アプリを構築する開発者・企業が対象
⏱️

長時間の自律実行

  • 複雑なタスクを人間の介入なしで長時間実行
  • 金融・法務・マーケティング・営業・データ・エンジニアリング向けに構築
🔌

2 つのアクセス方法

  • Amazon Bedrock: AWS 内にデータ保持 + Guardrails / KB / データレジデンシー
  • Claude Platform on AWS: Anthropic ネイティブ体験 + 統合 AWS 請求・認証

🔀 2 つのアクセス方法の比較

🛡️ Amazon Bedrock

  • AWS が運用する統合サービス
  • データを AWS インフラ内に保持
  • Guardrails / ナレッジベース / リージョナルデータレジデンシー
  • モデル ID にプレフィックス付与

⚡ Claude Platform on AWS

  • Anthropic が運用
  • Anthropic ネイティブの Claude プラットフォーム体験に直接アクセス
  • 統合された AWS の請求と認証を利用
  • Managed Agents / サーバーサイドツールはこちらで利用

📋 利用上の注意点 (API)

  • アダプティブ思考のみをサポート。thinking: {type: "enabled", budget_tokens: N} は 400 エラー
  • サンプリングパラメータ (temperature / top_p / top_k) は利用不可。指定すると 400 エラー
  • 明示的な thinking: {type: "disabled"} は 400 エラー。無効化する場合は thinking パラメータ自体を省略
  • アシスタントターンのプレフィルは 400 エラー。出力形式の制御は構造化出力 output_config.format を使用
  • 思考ブロックのテキストはデフォルトで省略。表示する場合は thinking: {type: "adaptive", display: "summarized"}

💻 API 呼び出し例 (Python)

Python Claude Platform on AWS / 第一者 API 
import anthropic

# Amazon Bedrock 経由の場合は AnthropicBedrock クライアントを使用
client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-fable-5",
    max_tokens=64000,
    thinking={"type": "adaptive"},
    output_config={"effort": "high"},
    messages=[{"role": "user", "content": "長時間の自律タスクを実行してください"}],
)

アダプティブ思考を有効化し、effort で思考の深さを制御しています。

✅ メリット

💼 ビジネス面

  • 最先端の能力を全顧客へ: 限定されていた Mythos レベルの能力を GA で広く活用
  • 専門業務への適用: 金融・法務・マーケ・営業・データ・エンジニアリングの高付加価値業務へ
  • 柔軟な調達: Bedrock の統合請求、または Platform の統合 AWS 請求・認証から選択

🛠️ 技術面

  • 長時間の自律実行: 介入なしで長時間処理、エージェント型ワークロードを効率化
  • 安全性の組み込み: 広範な利用を安全にする強力なセーフガードを内蔵
  • AWS ガバナンス統合: Bedrock 経由でデータを AWS 内に保持し Guardrails / KB / レジデンシーと併用

⚠️ デメリット・制約事項

制限事項

  • Claude Mythos 5 (分類器なし同一モデル) は Preview 限定で GA ではない
  • 利用可能リージョンは限定される場合あり。最新は Bedrock のドキュメントで要確認
  • Bedrock では Managed Agents や Anthropic のサーバーサイドツールは非対応 (利用時は Platform を選択)

考慮すべき点

  • 最上位ティアのためコストがモデル選択の判断材料になる
  • 大きな出力 (高い max_tokens) を扱う場合はストリーミングが必要
  • API 仕様が Opus 系と一部異なり、既存コード移行時に確認が必要

🎯 ユースケース

UC 1

自律的なコーディングエージェント

大規模コードベースのリファクタリングや複数ファイルにまたがる機能実装を、人間が逐一指示せず自律的に進行。タスク仕様を最初の 1 ターンで明確に提示し、effort を high / xhigh に設定して長時間の自律実行を行わせます。

💡 効果: 複雑なコーディングタスクを介入なしで長時間実行でき、開発者の負荷を軽減。

UC 2

専門業務のナレッジワーク自動化

金融や法務などの専門業務で、文書分析やレポート作成を高精度で自動化。Bedrock のナレッジベースと組み合わせ、社内文書を参照しながらナレッジワークを実行します。

💡 効果: 専門業務特化の最高水準モデルにより、高品質な成果物を効率的に生成。

UC 3

ガバナンスを重視した本番 AI アプリケーション

データを AWS インフラ内に保持し、ガードレールを適用したうえで本番環境へ AI 機能を組み込み。Bedrock 経由 + Guardrails で入出力のポリシー制御を行いながら統合します。

💡 効果: データレジデンシーやガードレールと組み合わせ、ガバナンス要件を満たしつつ最先端モデルを活用。

🌐 利用可能リージョン・関連サービス

利用可能リージョン

利用可能なリージョンは、Amazon Bedrock のモデルカードおよびリージョン提供状況のドキュメントを確認してください。提供状況は順次拡大される場合があります。

関連サービス・機能

  • Amazon Bedrock: データを AWS 内に保持し、Guardrails / KB / データレジデンシーとともに Claude Fable 5 を利用できる統合サービス
  • Claude Platform on AWS: Anthropic 運用。統合 AWS 請求・認証で Anthropic ネイティブ体験を提供
  • Amazon Bedrock Guardrails: 入出力のポリシー制御により安全性・コンプライアンス要件を満たす機能

📝 まとめ

Claude Fable 5 の一般提供は、Mythos クラスの最先端能力を強力なセーフガードとともにすべてのお客様へ届ける重要なマイルストーンです。長時間の自律的なナレッジワークとコーディングを実現し、Amazon Bedrock のガバナンス機能、または Claude Platform on AWS のネイティブ体験という 2 つのアクセス方法から組織の要件に合わせて選択できます。本番 AI アプリケーションを検討している場合は、利用可能リージョンと料金を確認のうえ、まずは小規模な検証から導入を進めることを推奨します。
