CLI 3.3.0 / CloudTrail 監査ログ対応

リリース日: 2026 年 11 月 12 日
Kiro CLI 3.3.0 /copy コマンド拡張 コンパクション設定 AWS CloudTrail MCP ツール監査

📝 概要

2026 年 11 月 12 日付の Kiro Changelog では 2 つの主要なアップデートが発表されました。 1 つ目は Kiro CLI 3.3.0 のリリースで、過去の応答をコピーする /copy N および /copy last N コマンドの追加と、 自動コンパクション (会話履歴の要約) を開始するコンテキスト使用率をユーザー自身が選択できる機能が含まれます。

2 つ目は「Audit Kiro Tool Calls with AWS CloudTrail」で、Kiro サービス MCP ツールの呼び出しが AWS CloudTrail に記録されるようになりました。対象は us-east-1 および eu-central-1 の Kiro プロファイルです。 誰が・いつ・どのツールを呼び出し、完了したかどうかを CloudTrail 上で確認できます。

※ 同日発表の「Kiro Mobile for Android」は別レポートでカバーしているため、本インフォグラフィックでは割愛します。

😣 アップデート前の課題

  • /copy は最新の応答しかコピーできず、過去の応答は手動での選択・コピーが必要
  • 自動コンパクション開始のコンテキスト使用率は固定で、ユーザーが調整できなかった
  • Kiro サービスツールの呼び出し履歴を組織として一元的に監査する手段がなく、セキュリティ・コンプライアンス対応が難しかった

😊 アップデート後の改善

  • /copy N で N 番目に新しい応答を、/copy last N で直近 N 件のメッセージをまとめてコピー可能に
  • /settings の Compaction 画面からしきい値をグローバルデフォルトとして設定でき、オン / オフも切り替え可能に
  • Kiro サービス MCP ツールの呼び出しが CloudTrail に記録され、既存の AWS 監査基盤 (CloudTrail Lake、Athena、SIEM 連携) で分析可能に

Kiro クライアントから Kiro サービス MCP ツールへの呼び出しが AWS CloudTrail に記録される流れです。 特権ツール呼び出しは管理イベントとしてデフォルトで記録され、ツール一覧や読み取り専用呼び出しはデータイベントの有効化により記録できます。

⚡ 主要機能

📋 1. 過去の応答のコピー (/copy N / /copy last N)

  • /copy は従来どおり最新の応答をコピー
  • /copy N は N 番目に新しい応答をコピー (例: /copy 2 は最新の 1 つ前の応答)
  • /copy last N は直近 N 件のメッセージを古い順にまとめてコピー。プロンプトには **You:**、返答には **Kiro:** のラベル付き
  • ツール呼び出しをまたいで分割された返答は 1 件のメッセージとして数える
  • 会話全体が必要な場合は /transcript を使用

⚙️ 2. 自動コンパクション開始タイミングの選択

  • V3 セッションで /settings → Compaction 画面から、現在のしきい値確認とグローバルデフォルト設定が可能
  • しきい値は Kiro が古い履歴を要約し始めるコンテキスト使用率 (%) を意味する
  • エディタに許容範囲とデフォルト値が表示され、設定は次に開始または読み込むセッションから適用
  • 同じ画面で自動コンパクションのオン / オフも切り替え可能
  • 設定値は compaction.autoCompactionThreshold として保存され、ワークスペースの cli.json で上書き可能

🔧 3. CLI 3.3.0 のその他の改善・修正

  • エージェントモニターに各サブエージェントのタスクを表示
  • /model の検索・ソート・編集操作を Up キーに移動
  • V2 エージェントを V3 にアップグレードした際に allow ルールが広がらないよう修正
  • エージェント再起動後に停止したワークフローセッションを再読み込み
  • ヘッドレス実行、resume、/memories、/goal、音声、クリップボード、セッション、検索表示に関する問題を修正

🔒 4. Kiro ツール呼び出しの AWS CloudTrail 監査 (General)

  • Kiro サービス MCP ツールへの呼び出しを AWS CloudTrail に記録
  • 対象は米国東部 (バージニア北部) us-east-1 および欧州 (フランクフルト) eu-central-1 の Kiro プロファイル
  • 誰がリクエストしたか、どのツールが呼び出されたか、いつ実行されたか、完了したかどうかを確認可能
  • 特権ツール呼び出しは管理イベントとしてデフォルトで記録
  • ツール一覧の取得や読み取り専用ツール呼び出しは、データイベントの有効化で記録可能
  • イベントではツールの引数は編集 (redact) され、結果は含まれない
  • 対象は Kiro サービスツールのみで、ユーザーが Kiro に追加した MCP サーバーは対象外

🛠️ 設定方法

✅ 前提条件

✓Kiro CLI 3.3.0 以降 (コピー・コンパクション機能)
✓us-east-1 または eu-central-1 に作成された Kiro プロファイル (CloudTrail 監査)
✓CloudTrail のイベントを参照できる IAM 権限 (監査チーム向け)
1

Kiro CLI を最新版に更新

Bashバージョン確認
kiro --version

現在の CLI バージョンを確認します。3.3.0 未満の場合は、Kiro の更新手順に従って最新版に更新します。

2

過去の応答をコピー

Bashチャット内で実行
# チャット内で実行
/copy 2        # 最新の 1 つ前の応答をコピー
/copy last 4   # 直近 4 件のメッセージを古い順にコピー

/copy 2 は最新の 1 つ前の応答をクリップボードにコピーします。/copy last 4 は直近 4 件のメッセージ (プロンプトと返答の両方) を You / Kiro のラベル付きでコピーします。

3

コンパクションしきい値を設定

BashV3 セッション内で実行
# V3 セッション内で実行
/settings
# Compaction 画面を開き、しきい値 (コンテキスト使用率 %) を設定

設定値は compaction.autoCompactionThreshold として保存され、次のセッションから適用されます。チーム共通の値を使いたい場合は、ワークスペースの cli.json で上書きします。

4

CloudTrail で Kiro ツール呼び出しを確認 (監査チーム)

対象リージョンの CloudTrail コンソールでイベント履歴を確認します。特権ツール呼び出しは管理イベントとしてデフォルトで記録されています。ツール一覧や読み取り専用ツール呼び出しも記録したい場合は、証跡 (Trail) のデータイベントを有効化します。

💡 メリット

💼 ビジネス面

✓監査・コンプライアンス対応: Kiro の利用状況が CloudTrail に記録され、組織のセキュリティポリシーや監査要件に沿った AI コーディングツールの運用が可能に
✓既存監査基盤の活用: AWS 標準の仕組みのため、既存の SIEM 連携やログ分析パイプラインをそのまま活用できる
✓開発者の生産性向上: 過去の応答の再利用が容易になり、長時間セッションでの作業効率が向上

⚙️ 技術面

✓柔軟なコンテキスト管理: しきい値調整により、履歴保持とコンテキスト節約のバランスをプロジェクト特性に合わせて最適化
✓設定の階層化: グローバルデフォルトとワークスペース cli.json による上書きで、個人設定とチーム設定を両立
✓プライバシーに配慮したログ: ツール引数は編集され結果も含まれないため、機密情報の漏えいリスクを抑えつつ監査証跡を確保

⚠️ デメリット・制約事項

🚧 制限事項

⚠CloudTrail 監査の対象は us-east-1 および eu-central-1 の Kiro プロファイルに限られる
⚠ログの対象は Kiro サービスツールのみで、ユーザーが追加した MCP サーバーの呼び出しは記録されない
⚠イベントにはツール引数の詳細や実行結果は含まれないため、操作内容の完全な再現はできない
⚠コンパクションしきい値の設定は V3 セッションが対象で、適用は次のセッションから

🤔 考慮すべき点

⚠読み取り専用ツール呼び出しまで記録する場合はデータイベントの有効化が必要で、CloudTrail のデータイベント料金が発生する可能性がある
⚠ワークスペースの cli.json がしきい値を上書きするため、個人設定が反映されない場合は cli.json の内容を確認する

🇺🇸 米国東部 (バージニア北部) us-east-1 🇩🇪 欧州 (フランクフルト) eu-central-1

🔗 関連サービス・機能

  • AWS CloudTrail: Kiro サービスツール呼び出しの記録先。管理イベント・データイベントの仕組みをそのまま利用できる
  • Kiro CLI: 本アップデートの /copy 拡張とコンパクション設定は CLI 3.3.0 で提供
  • Kiro Mobile for Android: 同日発表のモバイルアプリ。詳細は別レポートを参照
  • MCP (Model Context Protocol): Kiro サービスツールは MCP ツールとして提供される。ユーザー追加の MCP サーバーは今回の監査対象外

📌 まとめ

Kiro CLI 3.3.0 では /copy N / /copy last N による過去応答の柔軟なコピーと、 自動コンパクション開始しきい値のユーザー設定が可能になり、長時間セッションでの使い勝手が大きく向上しました。

あわせて、Kiro サービス MCP ツールの呼び出しが AWS CloudTrail に記録されるようになり、 エンタープライズでのガバナンス要件に対応しやすくなっています。 us-east-1 または eu-central-1 に Kiro プロファイルを持つ組織は、CloudTrail での監査体制の整備を検討することを推奨します。
