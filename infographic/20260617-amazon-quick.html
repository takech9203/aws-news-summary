📅 2026 年 6 月 17 日
リリース

📌 概要

Amazon Quick は、Slack、Microsoft Teams、Outlook、CRM、データベース、ドキュメントなど多様なアプリやデータソースを 1 つのワークスペースに統合する AI アシスタントです。ユーザーのワークフローを学習し、実データに基づいて回答するだけでなく、ダッシュボード作成や調査、各種業務の代行まで実行できます。

今回のアップデートでは、3 つの主要機能が発表されました。中心となる「自律エージェント」は、自然言語でタスクを指示でき、ステップごとの承認からゴールベースの広範な自動実行まで自律性を設定可能。継続的に稼働し、反復業務を自動化することで、手作業の繰り返しと通知過多 (notification overload) の負担を軽減します。

Before / After 比較

⛔ アップデート前の課題
  • 停滞商談のフォロー、規制情報の要約、PO 処理を毎回手作業で実行
  • 複数データソース横断の分析に、技術的なデータ準備や事前結合が必要
  • 返信や承認のために複数アプリを切り替える必要があった
✅ アップデート後の改善
  • 自然言語で指示するだけで、自律エージェントが反復業務を継続自動実行
  • 事前結合や技術準備なしで、複数データソース横断の自然言語クエリが可能
  • アクティビティフィードから優先順位付け・返信・承認をアプリ切替なしで実行

💡 ユーザーは自然言語で Amazon Quick に指示し、3 つの主要機能がデータソースやアプリと連携して業務を自動化・分析します。マルチデータセット分析では、既存の権限を尊重する ID 伝播 (identity propagation) によりセキュリティを確保します。

⚡ 主要機能

🤖 自律エージェント (Autonomous Agents)
  • 自然言語でタスクを記述し、自律性のレベルを設定できる
  • ステップごとの承認から、ゴールベースの広範な自動実行まで調整可能
  • 継続稼働し、停滞商談のフォロー・規制アップデート要約・PO 処理などの反復業務を自動化
  • 手作業の繰り返しと通知過多の削減を目的とする
📊 マルチデータセット分析 (Multi-Dataset Analytics)
  • Snowflake やリレーショナルデータベースを含む複数ソースを自然言語で横断クエリ
  • 技術的なデータ準備やデータセットの事前結合が不要
  • AWS Glue、Databricks Unity Catalog、Collibra からセマンティックな知識を継承
  • 既存の権限を尊重する ID 伝播でセキュリティを確保
📰 刷新されたアクティビティフィード (Redesigned Activity Feed)
  • パーソナライズされた会話型インターフェース
  • サムズアップ・サムズダウンのフィードバックでアップデートの優先順位を付与
  • メールや Slack への返信、リクエスト承認をアプリ切替なしで直接実行
  • Quick アプリを公開ウェブサイトとして共有し、組織を越えたコラボが可能

API 変更履歴

基盤となる Amazon QuickSight において、ナレッジベース関連の API が追加されています。Amazon Quick が業務データに基づき回答を生成する仕組みと関連性が高い変更です。

日付サービス変更内容
2026/06/05 Amazon QuickSight 8 new api methods - ナレッジベース API とインデックス容量 API のサポートを追加

追加された主な API メソッド。

  • ナレッジベース管理: DescribeKnowledgeBase、SearchKnowledgeBases、ListKnowledgeBases、DeleteKnowledgeBase、BatchDeleteKnowledgeBase
  • 権限管理: UpdateKnowledgeBasePermissions、DescribeKnowledgeBasePermissions
  • インデックス容量: ListUsersIndexCapacity (ユーザーごとのインデックス容量消費量を取得)

分析の利用

aws.com/quick からアカウントを作成し、業務アプリを接続します。自然言語でタスクを記述してエージェントの自律性を設定し、接続済みデータソースに対して横断的な自然言語クエリを実行できます (データの事前結合は不要)。

🎯 ユースケース

1. 営業商談の自動フォローアップ

シナリオ: 営業チームが多数の商談を抱え、停滞案件のフォローが後回しになっている。

エージェント指示例
「2 週間以上更新のない商談を検出し、担当者にフォローアップを
促すサマリーを毎朝作成する」というタスクを自律エージェントに設定。

効果: 停滞商談の見落としを防ぎ、手動の進捗確認の手間を削減。

2. 複数データソース横断の分析

シナリオ: 売上データが Snowflake、顧客マスターが RDB に分散し、横断分析にデータ準備の工数がかかる。

自然言語クエリ例
「直近四半期の売上上位顧客と、そのリスクスコアを一覧で表示して」
と自然言語でクエリを実行する (事前のデータ結合は不要)。

効果: 事前準備を待たず、ビジネスユーザー自身がデータドリブンな分析を実行。

3. アクティビティフィードからの一元対応

シナリオ: メール・Slack・承認リクエストが複数アプリに分散し、アプリ切替が負担。

操作例
アクティビティフィード上で、メールや Slack メッセージへ直接返信し、
承認リクエストをその場で承認する。

効果: アプリ間の切替を削減し、日々の対応業務を 1 つのインターフェースに集約。

料金: 無料でアカウントを作成して利用を開始できます。Amazon Quick Suite として Free / Plus / Pro / Enterprise のプランが提供されています。各プランの具体的な金額は公式の料金ページを参照してください。

利用可能リージョン: 公式発表時点では、具体的な情報は明示されていません。最新の対応状況は公式ページで確認してください。

関連サービス・機能

🚀 まとめ

今回のアップデートは、AI アシスタントを「質問に答える」段階から「業務を自律的に実行する」段階へと進化させる重要な発表です。自律エージェント、マルチデータセット分析、刷新されたアクティビティフィードにより、反復業務の自動化とデータ活用の民主化が大きく前進します。

日々の定型業務に時間を奪われているチームは、まず無料アカウントで自律エージェントとデータソース連携を試し、自社ワークフローへの適用効果を評価することを推奨します。
