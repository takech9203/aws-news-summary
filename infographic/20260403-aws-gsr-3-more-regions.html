📋 概要

AWS Glue Schema Registry が、アジアパシフィック (ジャカルタ)、ヨーロッパ (スペイン)、ヨーロッパ (チューリッヒ) の 3 つの新リージョンで利用可能になりました。Schema Registry は AWS Glue のサーバーレスかつ無料の機能であり、Apache Avro、JSON、Protobuf スキーマ形式を使用してストリーミングデータの進化を検証・制御できます。

データストリーミングシステムにおけるデカップルされたアプリケーション間のデータフォーマットと構造を管理するための一元化されたリポジトリとして機能し、データ検証ロジックやチーム間の調整を排除してストリーミングデータの品質を向上させます。

❌ Before
-ジャカルタ、スペイン、チューリッヒで Schema Registry が利用不可
-他リージョンの利用が必要でレイテンシーが課題
-データレジデンシー要件への対応が困難
✅ After
+3 つの新リージョンでローカルに利用可能
+ローカルリージョンでレイテンシーが改善
+EU / 東南アジアのデータ主権規制に対応

🔧 主要機能

📋 スキーマの一元管理

Apache Avro、JSON、Protobuf スキーマ形式をサポート。デカップルされたプロデューサーとコンシューマー間のデータ互換性を保証し、スキーマのバージョニングと進化ルールの管理が可能です。

✅ ストリーミングデータの品質管理

データ検証ロジックをアプリケーションコードから分離し、スキーマ互換性チェックによるデータ品質の自動検証を実現。下流アプリケーションの障害を未然に防止します。

🔗 幅広いサービス連携

  • → Apache Kafka / Amazon MSK
  • → Amazon Kinesis Data Streams
  • → Kinesis Data Analytics for Apache Flink
  • → AWS Lambda
  • → C# / Java アプリケーション

📐 サポートされるスキーマ形式

スキーマ形式 説明
Apache Avro バイナリシリアライゼーション形式。コンパクトで高速なデータ交換に最適
JSON Schema JSON ドキュメントの構造を定義。REST API やイベント駆動型アーキテクチャで広く使用
Protocol Buffers Google 開発のバイナリ形式。高効率なシリアライゼーションと言語間互換性を提供

⚙️ 設定方法

前提条件

1. AWS アカウントが新リージョンで有効化されていること
2. AWS Glue へのアクセス権限を持つ IAM ロール/ユーザーが設定済みであること
3. ストリーミングデータのプロデューサーまたはコンシューマーアプリケーションが存在すること

ステップ 1: Schema Registry の作成

Bash Schema Registry の作成 
aws glue create-registry \
  --registry-name my-schema-registry \
  --region ap-southeast-3

ステップ 2: スキーマの登録

Bash Avro スキーマの登録 
aws glue create-schema \
  --registry-id RegistryName=my-schema-registry \
  --schema-name my-avro-schema \
  --data-format AVRO \
  --compatibility BACKWARD \
  --schema-definition '{"type":"record","name":"User","fields":[{"name":"name","type":"string"},{"name":"age","type":"int"}]}' \
  --region ap-southeast-3

ステップ 3: アプリケーションからの利用

Java Schema Registry 統合例 
// Java アプリケーションでの Schema Registry 統合例
GlueSchemaRegistryKafkaSerializer serializer =
    new GlueSchemaRegistryKafkaSerializer();

Properties props = new Properties();
props.put("region", "ap-southeast-3");
props.put("schemaAutoRegistrationEnabled", "true");
props.put("dataFormat", "AVRO");

💡 メリット

💼 ビジネス面

✓ データレジデンシー要件への対応: EU および東南アジアのデータ主権規制に対応可能
✓ コスト削減: リージョン間データ転送が不要になり、ネットワークコストを削減
✓ グローバル展開の加速: 既存のストリーミングワークロードに Schema Registry をローカルに追加可能

🔬 技術面

✓ 低レイテンシー: ローカルリージョンでのスキーマ検証によりストリーミング処理が高速化
✓ 無料機能: AWS Glue の無料機能であり追加コストなし
✓ サーバーレス: インフラ管理不要でスキーマ管理に集中可能

⚠️ 制約事項・注意点

! Schema Registry のスキーマ数やバージョン数にはサービスクォータの上限がある
! C# および Java 以外の言語向けのネイティブシリアライザー/デシリアライザーは提供されていない
! リージョン間でのスキーマの自動レプリケーション機能は提供されていない
! 既存リージョンから新リージョンへのスキーマ移行は手動で行う必要がある
! 複数リージョンにまたがる場合、各 Schema Registry でスキーマの一貫性を維持する運用が必要

💰 料金

無料
AWS Glue Schema Registry は AWS Glue の無料機能です。
Schema Registry 自体の使用に追加料金はかかりません。
ただし、関連する AWS サービス (Amazon MSK、Kinesis Data Streams など) の利用料金は別途発生します。
