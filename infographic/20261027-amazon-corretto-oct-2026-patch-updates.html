📝 概要

Amazon は、無料でマルチプラットフォーム対応の本番環境対応 OpenJDK ディストリビューションである Amazon Corretto の Long-Term Supported (LTS) バージョンおよび Feature Release (FR) バージョンに対するパッチアップデートを発表しました。Corretto 27.0.1.0.11、25.0.5.0.10、21.0.13.0.11、17.0.21.0.11、11.0.33.0.10、8u512 がダウンロード可能です。

今回のアップデートはセキュリティ修正を含むパッチリリースであり、CVSS スコア 9.1 の脆弱性 CVE-2026-114820 への対処が含まれています。本番環境で Java アプリケーションを実行しているすべてのユーザーに適用が推奨されます。

ステップ 1: Corretto のダウンロード

Corretto ホームページから適切なバージョン (27、25、21、17、11、8) をダウンロードします。

ステップ 2: Linux リポジトリ経由でのアップデート (推奨)

BashApt の例 (Debian/Ubuntu)
wget -O - https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/corretto-keyring.gpg] https://apt.corretto.aws stable main" | sudo tee /etc/apt/sources.list.d/corretto.list
sudo apt-get update
sudo apt-get install -y java-21-amazon-corretto-jdk

Corretto の GPG 署名キーを登録し、Apt リポジトリを追加した上で、Corretto 21 の JDK をインストールします。既にリポジトリ設定済みの場合は sudo apt-get update && sudo apt-get upgrade のみでパッチが適用されます。

ステップ 3: バージョンの確認

Bashバージョン確認
java -version

Corretto 21 の場合、出力に 21.0.13 が含まれていればパッチ適用済みです。

ステップ 4: コンテナイメージの更新 (コンテナ利用時)

Bash公式コンテナイメージの更新
docker pull amazoncorretto:21

公式の Corretto コンテナイメージを最新に更新します。ベースイメージを更新した上でアプリケーションイメージを再ビルドしてください。
