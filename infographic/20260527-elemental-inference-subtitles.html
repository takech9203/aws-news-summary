AWS Elemental Inference

📋 概要

AWS Elemental Inference に Smart Subtitles 機能が追加。AI を活用した音声認識技術により、ライブビデオストリームからリアルタイムで字幕を自動生成する。TTML 形式で低レイテンシーの字幕を配信し、手動キャプショニングやサードパーティサービスの利用が不要になる。

6 対応言語
4 利用可能リージョン
6 新規 API メソッド

  • 専門オペレーターやカスタムパイプラインが必要
  • 専門用語のキャリブレーションが困難

✅ After

  • AI ベースの音声認識でリアルタイム自動字幕生成
  • カスタム辞書で専門用語の認識精度向上
  • MediaLive との統合で既存ワークフローに容易に追加

ライブビデオストリームが AWS Elemental Inference の音声認識エンジンに入力され、カスタム辞書を参照しながら TTML 形式の字幕がリアルタイム生成される。生成された字幕は AWS Elemental MediaLive のエンコードストリームと統合され、CDN 経由で視聴者に配信される。

⚡ 主要機能

🎤 リアルタイム音声認識と字幕生成

ライブビデオストリームの音声をリアルタイムで文字起こしし、TTML 形式で低レイテンシー字幕を出力

📖 カスタム辞書

専門用語、固有名詞、アスリート名などを登録。API またはコンソールから作成・更新・削除・エクスポートが可能

🚫 不適切表現フィルタ

3 段階のフィルタリングオプションで不適切な表現を制御可能

📡 MediaLive ネイティブ統合

既存のスマートクロッピングやクリップ生成機能と併用可能。複数機能で非線形料金体系が適用

🚫 不適切表現フィルタオプション

DISABLED フィルタなし
CENSOR 不適切表現を伏せ字に
DROP 不適切表現を含む字幕を非表示

AWS CLI での設定手順

Bash Step 1: カスタム辞書の作成 
aws elemental-inference create-dictionary \
    --name "sports-dictionary" \
    --language eng \
    --entries "athlete-names.txt"
Bash Step 2: Feed に字幕出力を設定 
aws elemental-inference create-feed \
    --name "live-stream-with-subtitles" \
    --outputs '[{
        "name": "subtitle-output",
        "outputConfig": {
            "subtitling": {
                "language": "eng-us",
                "aspectRatio": {"width": 1920, "height": 1080},
                "dictionary": "dictionary-id",
                "profanityFilter": "CENSOR"
            }
        },
        "status": "ENABLED",
        "description": "English subtitles for live stream"
    }]'
Bash Step 3: MediaLive チャンネルとの統合 
aws elemental-inference associate-feed \
    --id "feed-id" \
    --associated-resource-name \
      "arn:aws:medialive:us-east-1:123456789012:channel/channel-id" \
    --outputs '[{
        "name": "subtitle-output",
        "outputConfig": {
            "subtitling": {
                "language": "eng-us",
                "dictionary": "dictionary-id",
                "profanityFilter": "CENSOR"
            }
        },
        "status": "ENABLED"
    }]'

⚠️ 制約事項・注意点

⚠️ 制限事項
  • 対応言語は 6 言語に限定 (日本語、中国語、韓国語などアジア言語は未対応)
  • 利用可能リージョンが 4 リージョンに限定
  • カスタム辞書の言語コードは汎用コードのみ (地域バリアント非対応)
⚠ 音声品質が低い場合や背景ノイズが大きい場合、字幕精度が低下する可能性
⚠ 専門的なコンテンツではカスタム辞書の初期設定に時間がかかる場合がある
⚠ 複数言語の字幕を同時生成する場合は、言語ごとに Feed 出力を設定する必要がある

🎯 ユースケース

🏟️ スポーツのライブ中継

大規模スポーツイベントのライブ中継において、選手名やチーム名をカスタム辞書に登録し、リアルタイムで高精度な字幕を複数言語で配信。視聴者にとって分かりやすい字幕が自動生成される。

📺 ニュースのライブ配信

24 時間ニュースチャンネルのライブ配信において、コスト効率よくリアルタイム字幕を提供。従来の手動キャプショニングと比較して大幅なコスト削減を実現しつつ、規制要件に準拠した字幕配信が可能。

🌐 企業イベントの多言語配信

グローバル企業の全社ミーティングやプロダクト発表会を複数言語で同時配信。単一サービスで複数言語の字幕を同時生成し、グローバルな視聴者にリアルタイムでアクセシブルなコンテンツを提供。

💰 料金

Smart Subtitles は使用時間に基づく従量課金制。複数の Elemental Inference 機能 (スマートクロッピング、クリップ生成、Smart Subtitles) を同一コンテンツに同時適用する場合は、非線形の料金体系により機能あたりのコストが低減される。

※ 具体的な料金は AWS Elemental Inference 料金ページ を参照
