🤝 AWS Partner Central
Account Mapping and Planning

AWS Partner Central 📅 リリース日: 2026 年 11 月 20 日

📋 概要

AWS Partner Central で Account Mapping and Planning が利用可能になりました。パートナーは自社のターゲットアカウントリストを AWS のレコードと照合し、ACE オポチュニティが存在する前の段階で AWS との共同 Go-to-Market の協業機会を特定できます。

アカウントリストは CSV アップロード、API、CRM 連携のいずれかで登録でき、マッチングは自動実行されます。マッチしたアカウントには AWS Marketplace の購入傾向インサイト、ソリューションレベルの購入可能性、Partner Greenfield Program や Partner-Led Sales Motion などのプログラム適格性シグナルが付与されます。さらに Qualified アカウントについては、AWS セールスチームとの共同アカウントプランニングをリクエストできます。

❌ Before: アップデート前の課題
  • アカウントマッピングはスプレッドシートベースの手作業で、時間と工数がかかっていた
  • ACE オポチュニティが存在しないアカウントの協業機会を体系的に特定する手段がなかった
  • Marketplace 購入可能性やプログラム適格性などの AWS 側シグナルを参照できず、優先順位付けが困難だった
✅ After: アップデート後の改善
  • CSV、API、CRM 連携でアップロードするだけで AWS レコードとの照合が自動実行される
  • ACE オポチュニティのないアカウントやあらゆる国のアカウントも照合でき、早期の協業機会発見が可能に
  • Marketplace 購入傾向やプログラム適格性に基づき、高成果が見込めるアカウントを優先できる
  • Qualified アカウントに AWS セールスとの共同アカウントプランニングをリクエスト可能に

パートナーが CSV、API、CRM 連携のいずれかでターゲットアカウントリストをアップロードすると、AWS レコードとの照合とインサイト付与が自動実行され、Qualified アカウントに対して AWS セールスとの共同アカウントプランニングをリクエストできる流れを示しています。

⚙️ 主要機能

🔍 1. 自動アカウントマッチング
  • CSV アップロード、API、CRM 連携で登録すると AWS レコードとの照合が自動実行
  • ACE オポチュニティが存在しないアカウントも照合対象で、協業の初期段階から利用可能
  • あらゆる国のアカウントが対象で、グローバルな Go-to-Market 計画に活用できる
✨ 2. インサイトによるアカウントエンリッチメント
  • AWS Marketplace の購入傾向インサイトとソリューションレベルの購入可能性を付与
  • Partner Greenfield Program や Partner-Led Sales Motion などのプログラム適格性シグナルを確認可能
  • 購入可能性が高くプログラム適格性のあるアカウントに Go-to-Market 活動を集中できる
👥 3. AWS セールスとの共同アカウントプランニング
  • Qualified とマークされたアカウントについて共同アカウントプランニングをリクエスト可能
  • コンサルティングパートナーは ACE 適格、Premier ティア、PDM 担当付きが条件
  • ISV は ACE 適格、SaaS Co-sell Benefit プログラム登録、PDM 担当付きが条件
🔌 4. 複数のアクセス方法
  • Partner Central コンソールの Sell タブに加え、API / SDK からプログラム操作が可能
  • Partner Central MCP サーバー経由で AI エージェントからも利用できる
  • インテグレーションパートナーを通じてマッチング結果を CRM に連携できる
🖥️ コンソール Sell タブ 🔌 API / SDK 🤖 MCP サーバー 🗂️ CRM 連携

🛠️ 設定方法

📌 前提条件

✓AWS Partner Network (APN) に登録済みで、AWS Partner Central へのアクセス権があること
✓ACE 適格パートナーであること (アカウントマッチング・エンリッチメントの利用条件)
✓共同アカウントプランニングを利用する場合は、パートナー種別ごとの条件を満たすこと

Partner Central にサインインし、Sell タブ配下の Account Mapping ページからアカウントリストを登録します。登録後は照合が自動実行されるため、付与されたインサイトを確認して優先アカウントを特定し、Qualified アカウントに対して共同アカウントプランニングをリクエストします。

💡 メリット

💼 ビジネス面
  • 協業機会の早期発見: ACE オポチュニティ登録前の段階で共同 Go-to-Market の機会を特定し、営業パイプラインを早期構築
  • データドリブンな優先順位付け: 購入傾向や適格性シグナルに基づき、成約可能性の高いアカウントにリソースを集中
  • AWS セールスとの連携強化: 共同アカウントプランニングで協業体制を体系的に構築
🔧 技術面
  • 手作業の排除: スプレッドシートベースの手動マッピングが不要になり、照合作業を自動化
  • 柔軟な連携手段: CSV、API / SDK、MCP サーバー、CRM 連携など既存ワークフローに合わせて利用可能
  • CRM との統合: マッチング結果を CRM に取り込み、既存の営業管理プロセスに組み込める

⚠️ デメリット・制約事項

🚧 制限事項

✗アカウントマッチングとエンリッチメントの利用には ACE 適格パートナーであることが必要
✗共同アカウントプランニングのリクエストは Qualified とマークされたアカウントに限定
✗共同プランニングには、コンサルティングパートナーは Premier ティアかつ PDM 担当付き、ISV は SaaS Co-sell Benefit プログラム登録かつ PDM 担当付きという条件がある

🤔 考慮すべき点

⚡マッチング精度はアップロードするアカウントデータの品質に依存するため、企業名やドメインなどの情報整備が望ましい
⚡CRM 連携を利用する場合は、対応するインテグレーションパートナーのソリューションの確認が必要

🎯 ユースケース

📦 ユースケース 1: ISV による新規ターゲット市場の開拓

シナリオ: SaaS を提供する ISV が、新しい業種向けのターゲットアカウントリストを作成し、AWS との共同営業の可能性を評価したい。

実装例
1. ターゲットアカウントリストを CSV で Account Mapping ページにアップロード
2. 自動マッチング結果から、Marketplace 購入傾向の高いアカウントを抽出
3. SaaS Co-sell Benefit プログラムの条件を満たしたうえで、
   Qualified アカウントに対して共同アカウントプランニングをリクエスト

✅ 効果: ACE オポチュニティ登録前の早期段階で有望アカウントを特定し、AWS セールスと連携した営業活動を開始できる。

🌱 ユースケース 2: コンサルティングパートナーによる Greenfield アカウントの優先攻略

シナリオ: Premier ティアのコンサルティングパートナーが、AWS 利用がまだ少ない Greenfield アカウントを優先的に開拓したい。

実装例
1. 自社 CRM のターゲットアカウントを CRM 連携で Account Mapping に登録
2. Partner Greenfield Program の適格性シグナルが付与されたアカウントを抽出
3. PDM と連携し、該当アカウントの共同アカウントプランニングを実施

✅ 効果: プログラム適格性シグナルに基づいて Greenfield アカウントを特定し、AWS のプログラム支援を活用した効率的な開拓が可能になる。

🤖 ユースケース 3: API / MCP サーバーによる営業ワークフローの自動化

シナリオ: パートナーの営業オペレーションチームが、アカウントマッピングの結果を定期的に取得し、自社の営業ダッシュボードに反映したい。

実装例
1. Partner Central Selling API を使用してアカウントリストをバルク登録
2. マッチング結果とインサイトを API で定期取得し、BI ツールに連携
3. Partner Central MCP サーバー経由で AI エージェントから
   アカウント情報を照会し、営業活動の提案に活用

✅ 効果: 手作業を介さずにマッチング結果を営業ワークフローへ継続的に反映でき、データの鮮度と営業効率が向上する。

💰 料金・利用可能リージョン

💵 料金

What's New では本機能に関する追加料金の記載はありません。AWS Partner Central の利用には AWS Partner Network への登録が必要です。アカウントマッチングとエンリッチメントはすべての ACE 適格パートナーが利用できます。

🌍 利用可能リージョン

AWS Partner Central はグローバルに提供されるパートナー向けポータルであり、アカウントマッチングはあらゆる国のアカウントを対象として利用できます。

🔗 関連サービス・機能

🤝ACE (APN Customer Engagements): AWS とパートナーがオポチュニティを共有する共同営業の仕組み。Account Mapping は ACE オポチュニティ登録前の段階を補完する
🛒AWS Marketplace: マッチしたアカウントに付与される購入傾向インサイトの基盤。Marketplace 経由の販売戦略の立案に活用できる
🔌Partner Central Selling API: アカウントの登録・照会やアカウントプランニング招待をプログラムから操作できる API
🤖Partner Central MCP サーバー: AI エージェントから Partner Central の機能にアクセスするためのインターフェース

📝 まとめ

Account Mapping and Planning により、AWS パートナーはスプレッドシートによる手動のアカウントマッピングから脱却し、ACE オポチュニティ登録前の早期段階で AWS との協業機会をデータに基づいて特定できるようになりました。ACE 適格パートナーは、まず Sell タブの Account Mapping ページからターゲットアカウントリストをアップロードし、インサイトを活用した優先順位付けと共同アカウントプランニングの活用を検討することを推奨します。
