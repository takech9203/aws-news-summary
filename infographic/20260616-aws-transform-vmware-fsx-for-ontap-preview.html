AWS Transform パブリックプレビュー

🚀 Amazon FSx for NetApp ONTAP への
ブロックストレージ移行サポート

オンプレミス / クラウドの任意のソースから FSx for ONTAP へ直接移行
📅 2026年6月16日

📌 概要

AWS は AWS Transform で Amazon FSx for NetApp ONTAP (FSx for ONTAP) へのブロックストレージ移行をサポートする新機能をパブリックプレビューとして発表しました。これまでサポートしていた Amazon EBS への移行を拡張するものです。

AWS Transform for migrations は、ワークロードの検出・計画・移行を自動化するエージェント型 AI サービスです。今回のアップデートで、接続されたブロックストレージを FSx for ONTAP へも移行できるようになりました。FSx for ONTAP は NetApp の ONTAP ファイルシステム上に構築されたフルマネージド共有ストレージのため、データの管理方法を変更せずに移行でき、NetApp、Dell、Pure Storage、VMware などの環境に対応します。

⛔ Before（課題）
  • リホスト時の移行先は Amazon EBS に限定
  • 共有ストレージのデータ管理方法を維持したまま移行することが困難
  • 中間ストレージや別の移行ツールが必要で、追加コストとリスクが発生
➡️
✅ After（改善）
  • ブロックストレージを FSx for ONTAP へ直接移行
  • コンピューティング・ネットワークと同一の移行ウェーブで複製
  • 中間ツールが不要になり、追加コストとリスクを削減

AWS Transform が同一の移行ウェーブ内でコンピューティングを Amazon EC2 へ移行すると同時に、接続されたブロックストレージを FSx for ONTAP ボリュームへ複製する流れを示しています。

⚙️ 主要機能

🗄️ FSx for ONTAP への直接移行

  • 接続されたブロックストレージデータを FSx for ONTAP ボリュームへ直接複製
  • 従来の Amazon EBS に加えて、新たな移行先として FSx for ONTAP を選択可能
  • NetApp の ONTAP ファイルシステム上のフルマネージド共有ストレージへ移行するため、データの管理方法を変更不要

🔌 任意のソースベンダーからの移行

  • NetApp、Dell、Pure Storage、VMware などの環境からの移行に対応
  • VMware 環境のブロックストレージや NFS データストアを扱える
  • オンプレミスまたはクラウドの任意のソースを移行元として利用可能

🌊 移行ウェーブへの統合

  • コンピューティングとネットワークと同一の移行ウェーブでストレージ移行を実行
  • 中間ストレージプラットフォームや別個の移行ツールが不要
  • 追加コストとリスクを削減しながら移行を完了

🛠️ 設定方法

前提条件: ① AWS Transform for migrations を利用できる AWS アカウント ② 移行元環境 (VMware、NetApp など) へのネットワーク接続 ③ 移行先 FSx for ONTAP ファイルシステムを利用するためのネットワーク構成
STEP 1 🔍 検出と評価 サーバー仕様・ストレージ構成・依存関係を AI が収集分析
→
STEP 2 📋 ウェーブ計画 移行先に FSx for ONTAP を選択し同一ウェーブに構成
→
STEP 3 🚀 移行の実行 EC2 移行と同時にストレージを FSx for ONTAP へ複製

🎯 ユースケース

1️⃣ VMware 環境からの大規模移行

シナリオNetApp ストレージを利用する VMware 環境をデータセンターから AWS へ移行したいが、ストレージのデータ管理方法を維持したい。
効果VMware ワークロードを EC2 へリホストすると同時に、ブロックストレージを FSx for ONTAP へ複製。ONTAP ベースの管理方法を維持したまま移行を完了できる。

2️⃣ 中間ツールを排除した移行の効率化

シナリオ従来はストレージ移行のために中間ストレージや専用ツールを用意しており、コストと運用負荷が高かった。
効果移行ウェーブにストレージ移行を統合し、中間ツールを排除。コストとリスクを削減しながら移行できる。

3️⃣ 共有ストレージワークロードのモダナイゼーション

シナリオ複数のサーバーから共有される NFS データストアを含む環境を AWS へ移行し、マネージドサービスで運用したい。
効果VMware 環境の NFS データストアやブロックストレージを FSx for ONTAP へ移行し、フルマネージド共有ストレージとして運用負荷を軽減できる。

📝 まとめ

このアップデートにより、AWS Transform はブロックストレージの移行先として Amazon FSx for NetApp ONTAP をサポートし、NetApp や VMware などの環境からデータ管理方法を維持したまま移行できるようになりました。中間ツールを排除して移行ウェーブに統合できるため、コストとリスクの削減が期待できます。

パブリックプレビューであるため、本番移行を計画する際はまず検証環境で対応データ種別やリージョンの提供状況を確認することを推奨します。
