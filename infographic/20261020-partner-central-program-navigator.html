🏢 AWS Partner Central

Program Navigator / Case Study Generator / 効率化された Specialization レビュー

📅 リリース日: 2026 年 10 月 20 日 | 対象: すべての AWS パートナー | 提供場所: Partner Central「Go to Market」セクション

📌 概要

AWS Partner Central に、AWS Specialization プログラムへの申請を一元管理できる新機能 Program Navigator、AI を活用してケーススタディを作成できる Case Study Generator、および 効率化された Specialization レビュープロセスが追加されました。すべての AWS パートナーが、左ナビゲーションの「Go to Market」セクションから利用できます。

GTM (市場開拓) 目的のケーススタディは軽量なポリシー検証のみで AWS ドメインに直接公開できるようになり、詳細な Specialization レベルのレビューは Program Navigator の申請に関連するケーススタディのみに適用されます。

❌ アップデート前の課題
✗Specialization の要件・特典の確認や申請の提出・追跡を一元的に行う仕組みがなく、申請プロセスの見通しが立てにくかった
✗ケーススタディをゼロから手作業で作成する必要があり、既存の成功事例や商談情報を活用した効率的な作成手段がなかった
✗GTM 目的のケーススタディでも詳細なレビューが必要で、公開までに時間がかかっていた
✅ アップデート後の改善
✓Program Navigator で Specialization の閲覧、要件・特典の確認、ガイド付きワークフローでの申請提出・追跡が一元的に可能に
✓Case Study Generator で AI アシスタンス、既存事例 URL のインポート、商談からの自動入力の 3 つの方法で効率的に作成可能に
✓GTM 目的のケーススタディは軽量なポリシー検証のみで AWS ドメインに直接公開でき、リードタイムが短縮
✓Program Navigator 経由の申請はレビュー時間が短縮され、要件レベルの詳細なフィードバックを取得可能に

Program Navigator による Specialization 申請フローと、Case Study Generator による 3 つのケーススタディ作成方法、および目的に応じて分岐するレビュープロセスの全体像

⚙️ 主要機能

🧭 1. Program Navigator
  • AWS Specialization プログラムへの申請を一元管理する新機能
  • Specialization の指定 (Designation) を閲覧し、各プログラムの要件と特典を確認可能
  • ガイド付きのステップバイステップワークフローで申請を提出し、進捗を追跡可能
  • Program Navigator 経由の申請ではレビュー時間が短縮され、要件レベルの詳細なフィードバックを提供
✍️ 2. Case Study Generator

ケーススタディ作成のための新しいエクスペリエンス。以下の 3 つの開始方法を提供。

🤖
AI アシスタンス
AI の支援を受けながら直接作成
🔗
URL インポート
既存の顧客成功事例 URL から取り込み
💼
商談から自動入力
商談 (オポチュニティ) のデータを活用
⚡ 3. 効率化されたレビュープロセス
  • GTM 目的のケーススタディは、軽量なポリシー検証のみの簡素化されたレビューを経て、Specialization レビューなしで AWS ドメインに直接公開可能
  • 詳細な Specialization レベルのレビューは、Program Navigator の申請に関連するケーススタディのみに適用
  • Specialization 以外のプログラム申請は従来の方法で継続

🔧 設定方法

前提条件

  • ✓ AWS Partner Network (APN) に登録済みであること
  • ✓ AWS Partner Central のアカウントを保有していること
  • ✓ Partner Central で適切なユーザーロールが割り当てられていること

手順

1
AWS Partner Central にサインイン
AWS Partner Central (https://console.aws.amazon.com/partnercentral/home) にサインインします。
2
Program Navigator にアクセス
左ナビゲーションの「Go to Market」セクションから「Program Navigator」を選択。Specialization の一覧から対象プログラムを選び、要件と特典を確認した上で、ガイド付きワークフローに沿って申請を提出します。
3
Case Study Generator でケーススタディを作成
「Go to Market」セクションから「Case Studies」を選択。AI アシスタンスによる直接作成、既存の顧客成功事例 URL からのインポート、商談からの自動入力のいずれかの方法で作成し、レビューに提出します。

💡 メリット

📈 ビジネス面

✓申請プロセスの可視化: 要件と特典を事前に確認でき、進捗も追跡できるため、プログラム取得の計画が立てやすい
✓市場投入までの時間短縮: GTM 目的のケーススタディは軽量なレビューで直接公開でき、マーケティングを迅速に展開できる
✓コンテンツ作成コストの削減: AI アシスタンスや商談からの自動入力により、作成工数を削減できる

🛠️ 技術面

✓ガイド付きワークフロー: ステップバイステップの申請フローにより、申請内容の不備や手戻りを削減
✓既存データの再利用: 既存の成功事例 URL や Partner Central 上の商談データを活用して生成可能
✓詳細なフィードバック: 要件レベルの詳細なフィードバックが得られ、改善ポイントを特定しやすい

⚠️ デメリット・制約事項

制限事項

⚠️詳細な Specialization レベルのレビューは、Program Navigator の申請に関連するケーススタディにのみ適用される
⚠️Specialization 以外のプログラム申請は従来の方法のままで、今回の効率化の対象外
⚠️本機能の利用には AWS Partner Central へのアクセス権が必要

考慮すべき点

💭GTM 目的で公開したケーススタディを Specialization 申請に使用する場合は、別途 Specialization レベルのレビューが必要
💭AI アシスタンスで生成したケーススタディは、公開前に内容の正確性を自社で確認することが望ましい

🎯 ユースケース

📝 ユースケース 1: Specialization 取得計画の策定と申請

シナリオ: コンサルティングパートナーが新たに AWS Specialization の取得を目指しており、要件の把握から申請までを効率的に進めたい。

1. Partner Central の「Go to Market」から Program Navigator を開く 2. 取得候補の Specialization の要件と特典を比較検討する 3. ガイド付きワークフローに沿って必要情報を入力し申請を提出する 4. Program Navigator 上で申請ステータスとフィードバックを追跡する
✅ 効果: 要件の見落としを防ぎ、レビュー時間の短縮と要件レベルのフィードバックにより、Specialization 取得までの期間を短縮できる。
🚀 ユースケース 2: 商談データからのケーススタディ迅速公開

シナリオ: パートナーが成約済みの商談をもとに、マーケティング用のケーススタディを早期に公開したい。

1. Case Study Generator で「商談からの自動入力」を選択する 2. 対象の商談を選び、AI アシスタンスで内容を補完・編集する 3. GTM 目的として提出し、軽量なポリシー検証を受ける 4. 検証完了後、AWS ドメイン上に公開する
✅ 効果: Specialization レビューを待たずにケーススタディを公開でき、営業・マーケティング活動に迅速に活用できる。
♻️ ユースケース 3: 既存の成功事例の再活用

シナリオ: 自社サイトに掲載済みの顧客成功事例を、AWS ドメイン上のケーススタディとしても展開したい。

1. Case Study Generator で「既存の顧客成功事例 URL からのインポート」を選択する 2. 自社サイトの事例ページ URL を指定して内容を取り込む 3. 取り込んだ内容を編集し、ポリシー検証に提出する
✅ 効果: 既存コンテンツを再利用することで、新規作成の工数をかけずに AWS ドメイン上での露出を増やせる。

AWS Partner Central の Program Navigator と Case Study Generator により、Specialization 申請の一元管理と AI を活用したケーススタディ作成が可能になり、GTM 目的のケーススタディは軽量なレビューのみで迅速に公開できるようになりました。

AWS パートナー企業は、Partner Central の「Go to Market」セクションから新機能を確認し、Specialization 取得計画やケーススタディ公開のワークフローへの組み込みを検討することを推奨します。
