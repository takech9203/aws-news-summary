📝 Overview

Amazon SageMaker AI のサーバーレスモデルカスタマイズおよび強化学習ファインチューニングが、新たに 12 のオープンウェイトモデルに対応。1.5B から 120B パラメータまで幅広いサイズをカバーし、SFT、DPO、RFT の各手法がインフラ管理不要の従量課金制で利用可能に。

Before
  • サーバーレス対応オープンウェイトモデルの選択肢が限定的
  • RLVR / RLAIF にはクラスタセットアップや分散トレーニングの専門知識が必要
  • DeepSeek-R1 系や Qwen3 系をサーバーレスでカスタマイズする手段なし
→
After
  • 1.5B - 120B の 12 モデルがサーバーレス対応、最適なサイズを選択可能
  • SFT / DPO / RLVR / RLAIF がインフラ管理不要で利用可能
  • 従量課金制で使用した分だけの支払い

1 モデル選択

SageMaker AI コンソールのモデルカスタマイズから、12 の対応モデルの中からユースケースに適したモデルを選択

2 ファインチューニング手法の選択
  • SFT: 一般タスクへのモデル適応
  • DPO: 人間の選好に合わせる
  • RLVR: コード / 数学など検証可能タスク
  • RLAIF: AI フィードバックによる品質制御
3 データ準備とジョブ実行

選択した手法に応じたフォーマットでデータを準備し S3 にアップロード。ハイパーパラメータ設定後、サーバーレスでジョブを実行。クラスタセットアップ不要。

🎯 Use Cases

💻 UC1: ドメイン固有のコード生成精度向上

社内フレームワーク / カスタム API 向けコード生成タスクに RLVR を適用。DeepSeek-R1-Distill-Llama-70B + コード実行結果ベースの報酬シグナルで精度向上。

効果: 開発者の手動修正コストを削減

💬 UC2: カスタマーサポート応答品質の最適化

チャットボットの応答品質と安全性を RLAIF で自社品質基準に最適化。Qwen3 14B + 正確性 / 丁寧さ / ブランドガイドライン準拠の AI フィードバック。

効果: 一貫した応答品質で顧客満足度向上

⚡ UC3: 軽量モデルの低コストカスタマイズ

エッジデバイスや低レイテンシ環境向けに、Qwen3 1.7B / DS-R1-Qwen-1.5B を SFT で特定タスクに最適化。

効果: 低コスト / 低レイテンシで特化モデルを取得

✅ Benefits

💼 ビジネス面
  • 従量課金制でインフラ固定費不要のコスト効率
  • インフラ管理不要で迅速なファインチューニング開始
  • 1.5B - 120B の幅広いモデルからコスト / 性能最適選択
🔧 技術面
  • RLVR / RLAIF で複雑な推論タスクへの対応
  • 分散トレーニング / クラスタ管理の専門知識不要
  • DeepSeek-R1 / Qwen3 など最新モデルに即座にアクセス

⚠️ Limitations

  • 利用可能リージョンが 4 リージョンに限定
  • サーバーレス環境のため実行環境のきめ細かな制御に制限あり
  • 対応は発表時点の 12 モデルのみ
  • FT 手法ごとにデータ形式 / 量が異なるため事前のデータ戦略が重要
  • 大規模モデルは高コストの可能性 - まず小規模で実験を推奨
