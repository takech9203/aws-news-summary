🚀 Amazon EC2 P6-B300 インスタンスが
Asia Pacific (Hyderabad) と South America (Sao Paulo) で利用可能に

Amazon EC2 📅 リリース日: 2026 年 8 月 28 日 🌏 ap-south-2 (Hyderabad) 🌎 sa-east-1 (Sao Paulo)

📝 概要

Amazon EC2 P6-B300 インスタンスが Asia Pacific (Hyderabad) および South America (Sao Paulo) リージョンで利用可能になりました。P6-B300 は 8 基の NVIDIA Blackwell Ultra GPU を搭載し、2.1 TB の高帯域幅 GPU メモリ、6.4 Tbps の EFA ネットワーキング、300 Gbps の専用 ENA スループット、4 TB のシステムメモリを提供する最上位クラスの GPU インスタンスです。

前世代の P6-B200 と比較して 2 倍のネットワーク帯域幅、1.5 倍の GPU メモリサイズ、1.5 倍の GPU TFLOPS (FP4、スパーシティなし) を実現。今回の拡大でインドと南米では初の提供リージョンとなり、両地域の組織がデータを国内 / 域内に保持したまま、数兆パラメータ規模の基盤モデル (FM) や大規模言語モデル (LLM) のトレーニングとデプロイが可能になります。

❌ アップデート前の課題
  • P6-B300 は米国 3 リージョンと Asia Pacific (Seoul) の計 4 リージョンのみで提供され、インドや南米では利用できなかった
  • インドや南米の組織が利用するには、米国や韓国リージョンへのデータ転送や高いネットワークレイテンシーを許容する必要があった
  • データレジデンシー要件により国内でのデータ処理が求められるインドやブラジルの組織は、最新世代の Blackwell Ultra GPU を活用できなかった
✅ アップデート後の改善
  • Asia Pacific (Hyderabad) で P6-B300 が利用可能になり、インド国内で数兆パラメータ規模の基盤モデルのトレーニングとデプロイが可能に
  • South America (Sao Paulo) で P6-B300 が利用可能になり、南米地域で初めて最新の Blackwell Ultra GPU にアクセス可能に
  • 計 6 リージョン体制となり、グローバルでのワークロード分散配置、データレジデンシー対応、災害復旧の選択肢が拡大

⚡ 主要機能

🧠 NVIDIA Blackwell Ultra GPU
  • 8 基の NVIDIA Blackwell Ultra GPU を搭載
  • FP4 (スパーシティなし) で P6-B200 比 1.5 倍の GPU TFLOPS を提供
  • 数兆パラメータ規模のモデルのトレーニングとデプロイに最適化
💾 大容量 GPU メモリ
  • 2.1 TB の高帯域幅 GPU メモリ (HBM)
  • P6-B200 と比較して 1.5 倍の GPU メモリサイズ
  • 大規模モデルのメモリ内保持が可能で、モデル並列化の必要性を低減
🔗 高速ネットワーキング
  • 6.4 Tbps の Elastic Fabric Adapter (EFA) ネットワーキング
  • 300 Gbps の専用 Elastic Network Adapter (ENA) スループット
  • P6-B200 と比較して 2 倍のネットワーク帯域幅で分散トレーニングを加速
🌏 インドおよび南米地域初の提供リージョン
  • Asia Pacific (Hyderabad) はインドで初めて P6-B300 が提供されるリージョン
  • South America (Sao Paulo) は南米で初めて P6-B300 が提供されるリージョン
  • データレジデンシー要件への対応と低レイテンシーアクセスを両立

🛠️ 設定方法

✅ 前提条件

  • Asia Pacific (Hyderabad) または South America (Sao Paulo) リージョンへのアクセス権限を持つ AWS アカウント (Hyderabad はオプトインリージョンのため、事前の有効化が必要)
  • P6-B300 インスタンスのサービスクォータが承認済みであること
  • EFA を使用する場合は、EFA 対応の AMI とセキュリティグループの設定が必要
  • 適切な VPC とサブネットの構成
1
オプトインリージョンの有効化 (Hyderabad の場合)
Bash ap-south-2 リージョンの有効化 
aws account enable-region --region-name ap-south-2

Asia Pacific (Hyderabad) はオプトインリージョンのため、アカウントでリージョンを有効化します。有効化には数分かかる場合があります。

2
サービスクォータの確認と申請
Bash P6 系インスタンスのクォータ確認 
aws service-quotas list-service-quotas \
  --service-code ec2 \
  --region ap-south-2 \
  --query "Quotas[?contains(QuotaName, 'P6')]"

対象リージョンにおける P6 系インスタンスの vCPU クォータを確認します。不足している場合は、Service Quotas コンソールまたは CLI からクォータの引き上げをリクエストしてください。Sao Paulo の場合は --region sa-east-1 を指定します。

3
EFA 対応セキュリティグループの作成とインスタンスの起動
Bash セキュリティグループ作成と P6-B300 起動 
aws ec2 create-security-group \
  --group-name p6-b300-efa-sg \
  --description "Security group for P6-B300 with EFA" \
  --vpc-id vpc-xxxxxxxx \
  --region ap-south-2

aws ec2 authorize-security-group-ingress \
  --group-id sg-xxxxxxxx \
  --protocol -1 \
  --source-group sg-xxxxxxxx \
  --region ap-south-2

aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-xxxxxxxx \
  --key-name my-key-pair \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxxxxxxx,Groups=sg-xxxxxxxx,InterfaceType=efa" \
  --region ap-south-2

EFA を使用するためのセキュリティグループを作成し、同じセキュリティグループ内のインスタンス間での全トラフィックを許可した上で、EFA ネットワークインターフェースを指定してインスタンスを起動します。AMI は NVIDIA ドライバーと EFA ドライバーがプリインストールされた Deep Learning AMI の使用を推奨します。

💡 メリットと制約事項

👍 ビジネス面のメリット

✓インド / 南米地域からの低レイテンシーアクセス: 現地リージョンでの提供により、低レイテンシーで最高性能の GPU コンピューティングにアクセス可能
✓データレジデンシー要件への対応: インドやブラジルの国内にデータを保持したまま最新の Blackwell Ultra GPU で AI ワークロードを実行可能
✓リージョン選択の柔軟性: 6 リージョンで利用可能となり、コスト、レイテンシー、コンプライアンス要件に応じた最適なリージョン選択が可能

⚙️ 技術面のメリット

✓大規模モデル対応: 2.1 TB の GPU メモリにより、数兆パラメータ規模のモデルをメモリ内に保持してトレーニングおよび推論が可能
✓高速分散トレーニング: 6.4 Tbps の EFA ネットワーキングにより、マルチノードトレーニングのノード間通信ボトルネックを解消
✓高スループット推論: 300 Gbps の専用 ENA スループットにより、大量の推論リクエストを高スループットで処理可能

⚠️ 制限事項

⚠インスタンスサイズは p6-b300.48xlarge のみで、より小さなサイズは提供されていない
⚠アジア太平洋地域では Hyderabad と Seoul のみの提供であり、東京リージョンなど他のアジアリージョンでは未提供
⚠GPU インスタンスのサービスクォータの引き上げが必要になる場合があり、承認まで時間がかかる可能性がある

🤔 考慮すべき点

⚠最上位クラスのインスタンスタイプであるため利用コストが高額。長期利用の場合は購入オプションの検討が必要
⚠Asia Pacific (Hyderabad) はオプトインリージョンのため、利用前にアカウントでのリージョン有効化が必要
⚠NVIDIA Blackwell Ultra GPU のドライバーとソフトウェアスタック (CUDA、cuDNN、NCCL) の互換性を事前に確認する必要がある
⚠EFA を最大限に活用するには、クラスタープレースメントグループの設定や適切なネットワーク構成が不可欠

🎯 ユースケース

🇮🇳 ユースケース 1: インド国内での大規模基盤モデルのトレーニング

シナリオ: インドの AI 企業が、ヒンディー語をはじめとするインド諸言語に特化した数兆パラメータ規模の基盤モデルを国内リージョンでトレーニング。学習データを国外に転送せず、データレジデンシー要件を満たす。

Bash クラスタープレースメントグループでの分散トレーニング 
# クラスタープレースメントグループの作成
aws ec2 create-placement-group \
  --group-name p6-b300-training-cluster \
  --strategy cluster \
  --region ap-south-2

# P6-B300 クラスターでの分散トレーニング起動
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --count 8 \
  --image-id ami-deep-learning-base \
  --placement "GroupName=p6-b300-training-cluster" \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=sg-xxx,InterfaceType=efa" \
  --region ap-south-2

効果: 8 ノード x 8 GPU = 64 GPU で合計 16.8 TB の GPU メモリを活用し、数兆パラメータ規模のモデルを効率的にトレーニング可能。EFA 6.4 Tbps のノード間通信により高いスケーリング効率を実現しつつ、データをインド国内に保持できる。

🇧🇷 ユースケース 2: 南米地域向け LLM 推論サービング

シナリオ: 企業が大規模 LLM を本番環境にデプロイし、ブラジルおよび南米地域のエンドユーザーにリアルタイムの推論サービスを低レイテンシーで提供。

Bash Sao Paulo リージョンでの推論インスタンス起動 
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-deep-learning-inference \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=sg-xxx,InterfaceType=efa" \
  --region sa-east-1 \
  --tag-specifications "ResourceType=instance,Tags=[{Key=Purpose,Value=LLM-Inference}]"

効果: 2.1 TB の GPU メモリにより超大規模モデルを単一インスタンスにロードして推論を実行でき、300 Gbps の ENA スループットにより大量のリクエストを高スループットで処理可能。米国リージョンからの提供と比較して南米のエンドユーザーへの応答レイテンシーを大幅に削減できる。

🌐 ユースケース 3: グローバル 6 リージョンにまたがる AI プラットフォーム

シナリオ: グローバル企業が米国、韓国、インド、ブラジルの各リージョンで P6-B300 インスタンスを使用し、地理的な冗長性を持つ AI プラットフォームを構築。

効果: 北米、アジア、南米の複数リージョンにわたるワークロード分散により、リージョン障害時のフェイルオーバーやピーク時の負荷分散が可能になる。エンドユーザーの地理的位置に基づいたルーティングにより、グローバル全体でのレイテンシーを最適化できる。

💰 料金

P6-B300 インスタンスの料金は、リージョンおよび購入オプションによって異なります。P6-B300 は最上位クラスの GPU インスタンスであるため、コスト最適化のために以下の購入オプションを検討することを推奨します。

購入オプション特徴
オンデマンド初期費用なし、時間課金、短期ワークロードに適合
Savings Plans1 年または 3 年のコミットメントによる割引

具体的な料金については、Amazon EC2 料金ページ を参照してください。

📌 まとめ

Amazon EC2 P6-B300 インスタンスが Asia Pacific (Hyderabad) と South America (Sao Paulo) リージョンで利用可能になり、インドと南米で初めて提供されるリージョンとなりました。8 基の NVIDIA Blackwell Ultra GPU、2.1 TB の GPU メモリ、6.4 Tbps の EFA ネットワーキングを搭載した P6-B300 は、数兆パラメータ規模の基盤モデルのトレーニングやデプロイに最適です。インドやブラジルの国内でのデータ処理が求められる組織や、両地域のエンドユーザーに低レイテンシーで AI サービスを提供したい組織は、新リージョンでの P6-B300 利用を検討することを推奨します。
