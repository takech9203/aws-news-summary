📋 概要

AWS は Amazon SageMaker JumpStart において、Qwen3 シリーズの音声モデル 3 種の提供を開始した。テキスト音声変換 (TTS) と 音声認識 (ASR) の両方向で、多言語対応の高品質な音声 AI アプリケーションを AWS インフラストラクチャ上で構築できるようになった。

3 追加モデル数
52 ASR 対応言語数
3 秒 ボイスクローニング入力

❌ Before

  • 音声関連の基盤モデルの選択肢が限定的
  • 多言語 TTS モデルのデプロイに大きな工数
  • 音声カスタマイズに専門的な ML エンジニアリングが必要

✅ After

  • 3 つの Qwen3 音声モデルを数クリックでデプロイ
  • 10 言語対応 TTS + 52 言語対応 ASR をマネージド環境で利用
  • 指示ベースの音声スタイル制御や 3 秒ボイスクローニングが容易に

3 つのモデルはそれぞれ異なる音声処理タスクに特化しており、SageMaker JumpStart を通じて統一的にデプロイ・管理できる。

⚡ 主要機能

🎭 Qwen3-TTS-12Hz-1.7B-CustomVoice

カスタマイズ可能な多言語 TTS

  • 10 言語に対応した多言語テキスト音声変換
  • 指示ベース (instruction-driven) で音質、感情、韻律を制御可能
  • リアルタイムインタラクティブ音声アプリケーションに最適
  • カスタマー向けバーチャルアシスタントやコンテンツ制作ワークフローに対応

🎵 Qwen3-TTS-12Hz-1.7B-Base

高速ボイスクローニング TTS

  • 3 秒間の音声入力からの高速ボイスクローニング
  • 多言語テキスト音声変換の柔軟な基盤モデル
  • ドメイン固有の音声合成のファインチューニングに対応
  • カスタム音声アプリケーション構築の基盤として利用可能

📝 Qwen3-ASR-1.7B

高精度自動音声認識

  • 52 言語・方言に対応した自動音声認識
  • 複雑な音響環境でも高精度を実現
  • ストリーミングとオフラインの両モードに対応
  • 文字起こし、多言語カスタマーサポート、リアルタイム字幕に対応

🚀 設定方法・デプロイ

前提条件

✓AWS アカウントと SageMaker へのアクセス権限
✓SageMaker Studio ドメインのセットアップ済み環境
✓モデルデプロイ用のインスタンスクォータの確保 (GPU インスタンス推奨)

方法 1: SageMaker Studio コンソール

SageMaker Studio の Models セクションからモデルを検索し、数クリックでデプロイする。

方法 2: SageMaker Python SDK

Python CustomVoice TTS モデルのデプロイ 
from sagemaker.jumpstart.model import JumpStartModel

# CustomVoice TTS モデルのデプロイ
model = JumpStartModel(model_id="qwen3-tts-12hz-1-7b-customvoice")
predictor = model.deploy()

# 推論の実行
response = predictor.predict({
    "text": "Hello, this is a test of text-to-speech.",
    "language": "en"
})
Python ASR モデルのデプロイ 
from sagemaker.jumpstart.model import JumpStartModel

# ASR モデルのデプロイ例
model = JumpStartModel(model_id="qwen3-asr-1-7b")
predictor = model.deploy(
    instance_type="ml.g5.xlarge",
    initial_instance_count=1
)

推論の実行

Python TTS / ASR 推論例 
# TTS の例: テキストを音声に変換
tts_response = predictor.predict({
    "text": "本日はご来場いただき、ありがとうございます。",
    "language": "ja",
    "voice_style": "professional"
})

# ASR の例: 音声をテキストに変換
import base64
with open("audio.wav", "rb") as f:
    audio_data = base64.b64encode(f.read()).decode()

asr_response = predictor.predict({
    "audio": audio_data,
    "language": "ja"
})

🎯 ユースケース

🌍 多言語カスタマーサポート

グローバル展開する EC サイトが、多言語対応の音声チャットボットを構築。CustomVoice モデルで自然な応答音声を生成し、10 言語に対応した顧客満足度の向上とサポートコストの削減を両立。

Python 実装例 
response = tts_predictor.predict({
    "text": "Thank you for your inquiry. Your order will arrive tomorrow.",
    "language": "en",
    "voice_style": "friendly, professional"
})

🎬 コンテンツ制作の自動化

メディア企業が、記事コンテンツをポッドキャストや音声ニュースとして配信。Base モデルの 3 秒ボイスクローニングでブランド固有のナレーション音声を生成し、大量コンテンツを効率的に音声化。

Python 実装例 
clone_response = tts_predictor.predict({
    "text": article_text,
    "reference_audio": narrator_3sec_sample,
    "language": "ja"
})

💬 リアルタイム会議文字起こし

リモートワーク環境で、多言語チームのオンライン会議をリアルタイムに文字起こし・翻訳。52 言語対応のストリーミング音声認識でコミュニケーション障壁を低減し、議事録の自動生成を実現。

Python 実装例 
asr_response = asr_predictor.predict({
    "audio": streaming_audio_chunk,
    "language": "auto",
    "mode": "streaming"
})
