Amazon EC2 3rd Gen Intel Xeon 追加リージョン

Amazon EC2 R6in / R6idn
Europe (Paris) と Canada (Central) で提供開始

2026 年 7 月 21 日

概要

Amazon EC2 R6in および R6idn インスタンスが、新たに Europe (Paris) および Canada (Central) リージョンで利用可能になりました。R6in / R6idn は、第 3 世代 Intel Xeon Scalable プロセッサ (Ice Lake) と AWS Nitro System を基盤とする、ネットワーク最適化されたメモリ最適化インスタンスです。

最大 200 Gbps のネットワーク帯域幅と、第 5 世代インスタンス比で最大 2 倍のパケット処理性能を提供します。メモリ集約型の SQL / NoSQL データベース、インメモリキャッシュ、SAP HANA などのインメモリデータベース、大規模データ分析といったネットワーク集約型ワークロードに適しています。

今回のリージョン拡大により、パリおよびカナダ (中部) のユーザーは、データレジデンシー要件やレイテンシー要件を満たしながら、高いネットワーク性能を必要とするワークロードを構築できるようになります。

Before - アップデート前の課題
  • Europe (Paris) や Canada (Central) では R6in / R6idn を起動できなかった
  • 高ネットワーク性能のために他リージョンへのデプロイやレイテンシーの妥協が必要だった
  • フランスやカナダのデータレジデンシー要件下で最適なネットワーク最適化インスタンスを選びづらかった
After - アップデート後の改善
  • Europe (Paris) と Canada (Central) で R6in / R6idn を直接起動できる
  • 対象リージョン内で最大 200 Gbps のネットワーク帯域幅を活用できる
  • データレジデンシーとレイテンシーの両立が容易になった

主要機能

🌎
追加リージョンでの提供開始
Europe (Paris) と Canada (Central) で新たに利用可能に。既存の提供リージョンに加えての拡大です。
⚡
高いネットワーク性能
最大 200 Gbps のネットワーク帯域幅 (第 5 世代の 2 倍)。32xlarge および metal サイズで EFA をサポート。
💾
メモリとストレージ構成
最大 128 vCPU / 1024 GiB メモリ。EBS 帯域幅は最大 100 Gbps / 400K IOPS。R6idn は最大 7.6 TB のローカルストレージを搭載。

ユースケース

🗃️ ユースケース 1: メモリ集約型データベース
シナリオ: フランス国内でデータを保持する必要があるメモリ集約型の SQL / NoSQL データベースを運用したい
✔ Europe (Paris) で R6idn を利用し、高いネットワーク帯域幅と低レイテンシーローカルストレージを活用しつつデータレジデンシー要件を充足
⚡ ユースケース 2: インメモリキャッシュ / データベース
シナリオ: Memcached や Redis によるインメモリキャッシュ、SAP HANA などのインメモリデータベースを高スループットで運用したい
✔ 最大 1024 GiB のメモリと最大 200 Gbps の帯域幅で大規模インメモリワークロードを安定処理
📈 ユースケース 3: ビッグデータ分析
シナリオ: Canada (Central) で Apache Hadoop や Apache Spark を用いた大規模データ分析を実行したい
✔ ネットワーク最適化インスタンスによりノード間の大量データ転送を効率化し、分析ジョブの処理時間を短縮

メリット

💰 ビジネス面
  • データレジデンシーの充足: フランス・カナダ国内で処理を完結でき地域要件を満たしやすい
  • レイテンシー低減: 対象地域のユーザーに近いリージョンで高性能インスタンスを実行
  • 柔軟な購入オプション: Savings Plans、リザーブド、オンデマンド、スポットに対応
⚡ 技術面
  • 高スループット処理: 最大 200 Gbps の帯域幅でネットワーク集約型ワークロードを効率処理
  • HPC 対応: EFA サポートにより大規模並列処理や HPC ワークロードに対応
  • 高速ローカルストレージ: R6idn では低レイテンシーの NVMe SSD ストレージを活用

制約事項・考慮点

⚠ 制限事項
  • EFA のサポートは 32xlarge および metal サイズに限定される
  • ローカルインスタンスストレージは R6idn のみで提供される
  • ネットワーク最適化インスタンスのため、汎用用途では他のファミリーがコスト効率に優れる場合がある
ℹ 考慮すべき点
  • ワークロードのネットワーク要件を評価し、標準のメモリ最適化インスタンス (R6i など) との比較検討が必要
  • ローカルストレージ上のデータは停止・終了時に失われるため、永続化には EBS や S3 を利用
