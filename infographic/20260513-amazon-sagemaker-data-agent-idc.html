Amazon SageMaker Data Agent
IAM Identity Center 対応

自然言語でデータ分析を加速する AI アシスタントが SSO 環境でも利用可能に

2026/05/13

📋 概要

Amazon SageMaker Data Agent が、IAM Identity Center で構成された SageMaker Unified Studio ドメインで利用可能になった。Data Agent は AI を活用したアシスタント機能で、データアナリストやデータエンジニアが自然言語 (英語) で分析目的を記述するだけで、接続されたデータソースに最適化された Python / SQL コードを自動生成できる。

⚡ 主要機能

💬
自然言語によるコード生成

分析目的を平易な英語で記述するだけで Python / SQL コードを自動生成。データソースのスキーマを自動認識し、収益成長率計算、可視化、DataFrame 変換、クエリ最適化に対応。

🧠
会話コンテキストの維持

ノートブックセル間でコンテキストを保持。選択テーブルやクエリ履歴を記憶し、ステップバイステップの計画提案後にコードを生成。段階的な分析深掘りが可能。

🔧
Fix with AI

実行エラーを AI が分析し修正提案を自動生成。根本原因を特定して具体的な修正方法を提示。開発サイクルの短縮に貢献。

🔐
IAM Identity Center 統合

SSO 認証によるシームレスなアクセス。組織の ID 管理と統合された認証フロー。IAM 認証ドメインに加え Identity Center ドメインでも利用可能に。

🛠️ 設定方法

前提条件

✓IAM Identity Center が有効化された AWS 環境
✓SageMaker Unified Studio ドメインが IAM Identity Center で構成されていること
✓プロジェクト内でデータソースが接続されていること

手順

1
SageMaker Unified Studio プロジェクトにアクセス
コンソールにアクセスし、対象のプロジェクトを開く。IAM Identity Center を通じて SSO 認証が行われる。
2
Notebook または Query Editor を開く
プロジェクト内で Notebook 環境または Query Editor を起動する。
3
Data Agent パネルを選択
サイドバーまたはメニューから Data Agent パネルを選択して起動。分析目的を自然言語で入力し、生成されたコードを実行する。

🎯 ユースケース

📊 四半期売上分析レポートの自動生成
Redshift 上の売上データから四半期ごとの成長率を算出し可視化したい場合
Text Data Agent への入力例 
Calculate quarterly revenue growth rates from the sales table
for the past 2 years and generate a line chart visualization
✅ 複数テーブルの JOIN や集約関数の記述を自動化し、数分で分析コードと可視化を取得
🔧 データパイプラインのデバッグ
Athena クエリで型変換エラーが発生し、原因を特定できない場合

エラー発生時に "Fix with AI" ボタンをクリック → Data Agent がエラーメッセージを分析し、カラムのデータ型不一致を特定、修正済みクエリを提案。

✅ エラーの根本原因特定と修正に要する時間を大幅に短縮
🔗 クロスソースデータ統合分析
S3 上のログデータと Redshift 上の顧客データを組み合わせてユーザー行動分析を行いたい場合
Text Data Agent への入力例 
Join the user activity logs from S3 with the customer table
in Redshift to identify top 10 customers by engagement score
✅ 異なるデータソースを横断した分析コードを自動生成し、複雑なデータ統合作業を簡素化

⚠️ 制約事項・注意点

✗自然言語入力は現時点で英語のみ対応
✗IAM Identity Center で構成されたドメインが必要
✗AI 生成コードの正確性は保証されず、実行結果の検証が必要
!生成コードはデータソースの権限に依存
!機密データアクセスは既存の IAM ポリシーとデータガバナンスポリシーが適用
!大規模データセットのクエリ生成時はコスト最適化を意識

💰 料金

SageMaker Data Agent の料金は SageMaker Unified Studio の利用料金に含まれる。データソースへのクエリ実行に伴う料金 (Athena のスキャン量、Redshift のコンピュートノード、S3 のリクエスト費用など) は別途発生。
