📋 概要

Amazon Connect に AI エージェントのパフォーマンスを測定・改善するための 8 つの新しいメトリクスが追加された。ゴール成功率、忠実性スコア、ツール選択精度などを含むこれらのメトリクスにより、AI 駆動のカスタマーインタラクションの品質を可視化し、継続的に測定・改善できるようになる。
❌ アップデート前の課題
  • AI エージェントの解決率を定量的に測定する手段がなかった
  • ハルシネーションの有無を自動的に評価する仕組みがなかった
  • ツール選択の正確性を体系的にモニタリングすることが困難だった
  • 顧客フィードバックを AI パフォーマンス評価に組み込む方法がなかった
✅ アップデート後の改善
  • 8 つの専用メトリクスで多角的かつ定量的に評価可能に
  • 忠実性スコアによりハルシネーション検出・応答品質評価が自動化
  • ツール選択精度メトリクスで継続的モニタリングが可能に
  • ダッシュボード、API、データレイクの 3 経路で柔軟な分析を実現

🎯 8 つの新規メトリクス

品質メトリクス
🎯
ゴール成功率
Goal Success Rate
AI エージェントが顧客のリクエストを正常に解決した割合を測定。定義されたゴールに対する達成度をパーセンテージで表示し、AI エージェントの全体的な有効性を評価する最も重要な指標。
パーセンテージ (%)
📋
忠実性スコア
Faithfulness Score
AI エージェントの応答が提供されたコンテキストやナレッジベースにどの程度忠実であるかを評価。コンテキストに基づくハルシネーションの検出に活用し、応答の正確性と信頼性を定量的にスコアリング。
スコア (0-100)
ツールメトリクス
🔧
ツール選択精度
Tool Selection Accuracy
AI エージェントが顧客のリクエストに対して適切なツールを選択した割合を測定。利用可能なツール群から最適なツールが選ばれているかを評価し、ツール構成やプロンプト設計の改善に活用。
パーセンテージ (%)
📐
ツール利用精度
Tool Utilization Accuracy
選択されたツールが正しいパラメータで正確に実行されたかを評価。ツール呼び出しの成功率と正確性を測定し、ツールの実行品質の継続的な監視に利用。
パーセンテージ (%)
フィードバックメトリクス
👍
サムズアップ率
Thumbs Up Rate
顧客が AI エージェントの応答にサムズアップ評価を与えた割合。顧客満足度の直接的な指標として機能し、有効化されている場合に顧客フィードバックを自動収集。
パーセンテージ (%)
👎
サムズダウン率
Thumbs Down Rate
顧客が AI エージェントの応答にサムズダウン評価を与えた割合。改善が必要な領域を特定するための指標であり、否定的なフィードバックのパターン分析に活用。
パーセンテージ (%)
解決メトリクス
✅
解決率
Resolution Rate
AI エージェントが人間のエージェントへのエスカレーションなしに問い合わせを完了した割合。セルフサービスの有効性とコスト効率を評価し、自律的な問題解決能力の指標。
パーセンテージ (%)
🔄
エスカレーション率
Escalation Rate
AI エージェントから人間のエージェントへエスカレーションされたインタラクションの割合。処理できなかったケースのパターンを分析し、能力拡張や改善の優先順位付けに活用。
パーセンテージ (%)

📈 アクセス方法

📊
AI Agent Performance ダッシュボード
Amazon Connect コンソール内の専用ダッシュボードで全 8 メトリクスを可視化。リアルタイムおよび履歴データの表示、フィルタリングやドリルダウン機能で詳細分析が可能。
🔌
GetMetricDataV2 API
プログラムによるメトリクスデータの取得。カスタムダッシュボードやレポートの構築、既存の分析システムとの統合に最適。
🪣
ゼロ ETL データレイク
ETL パイプラインの構築不要でデータを直接クエリ可能。Amazon Athena や Amazon QuickSight との連携によるカスタム分析。

💻 コードサンプル

GetMetricDataV2 API によるメトリクス取得

Python メトリクスデータの取得 
import boto3

client = boto3.client('connect')

response = client.get_metric_data_v2(
    ResourceArn='arn:aws:connect:us-east-1:123456789012:instance/instance-id',
    StartTime='2026-04-24T00:00:00Z',
    EndTime='2026-04-24T23:59:59Z',
    Filters=[
        {
            'FilterKey': 'CHANNEL',
            'FilterValues': ['CHAT']
        }
    ],
    Metrics=[
        {'Name': 'AI_AGENT_GOAL_SUCCESS_RATE'},
        {'Name': 'AI_AGENT_FAITHFULNESS_SCORE'},
        {'Name': 'AI_AGENT_TOOL_SELECTION_ACCURACY'},
        {'Name': 'AI_AGENT_TOOL_UTILIZATION_ACCURACY'},
        {'Name': 'AI_AGENT_THUMBS_UP_RATE'},
        {'Name': 'AI_AGENT_THUMBS_DOWN_RATE'},
        {'Name': 'AI_AGENT_RESOLUTION_RATE'},
        {'Name': 'AI_AGENT_ESCALATION_RATE'}
    ]
)

for result in response['MetricResults']:
    for metric in result['Collections']:
        print(f"{metric['Metric']['Name']}: {metric['Value']}")

🔧 設定方法

前提条件

  • ☁️ Amazon Connect インスタンスが作成済みであること
  • 🤖 AI エージェント (Amazon Q in Connect) が有効化されていること
  • 🔐 GetMetricDataV2 API を使用する場合、適切な IAM 権限が付与されていること

手順

  1. AI Agent Performance ダッシュボードへのアクセス
    Amazon Connect コンソールにログインし、対象インスタンスを選択。左側ナビゲーションの「Analytics and optimization」から「AI Agent Performance」ダッシュボードにアクセス。
  2. メトリクスの確認と分析
    ダッシュボード上で 8 つのメトリクスを確認。期間フィルターで表示期間を調整し、特定の AI エージェントやチャネルでフィルタリングして詳細な分析を実施。
  3. 顧客フィードバックの有効化
    サムズアップ / サムズダウン評価を収集するには、AI エージェントのコンタクトフロー設定で顧客フィードバック機能を有効化する。
  4. API によるカスタムレポーティング
    GetMetricDataV2 API を使用してプログラムによるメトリクスデータの取得を行い、既存の分析ツールや BI ダッシュボードに統合。
  5. ゼロ ETL データレイクの活用
    Amazon Connect データレイクにメトリクスデータをエクスポートし、Amazon Athena で直接クエリを実行してカスタム分析を実施。

💡 ユースケース

🔄 AI エージェントの品質改善サイクル
コンタクトセンターの管理者が AI エージェントの応答品質を継続的に改善したい場合。週次でメトリクスを自動取得し、忠実性スコアが 80% を下回った場合にナレッジベースの更新を推奨するアラートを設定。
✔ メトリクスに基づく体系的な品質改善により、ゴール成功率を向上させ、顧客満足度の継続的な向上を実現
🔍 ハルシネーション検出と対策
金融サービス企業が AI エージェントの応答における不正確な情報提供を防止したい場合。忠実性スコアの監視アラームを CloudWatch で設定し、閾値を下回った際に SNS 通知を送信。
✔ リアルタイムの忠実性スコア監視により、ハルシネーションの発生を早期に検出し、コンプライアンスリスクを最小化
📊 カスタム分析ダッシュボードの構築
複数の Amazon Connect インスタンスを運用する大規模企業が、統合的な AI エージェントパフォーマンスレポートを構築したい場合。ゼロ ETL データレイクと Amazon Athena の組み合わせで SQL クエリを実行。
✔ ETL パイプラインの構築不要で複数インスタンスにまたがる統合分析を実現

Athena クエリ例

SQL ゼロ ETL データレイクを使用した集計 
SELECT
    date_trunc('day', interaction_timestamp) AS day,
    ai_agent_id,
    AVG(goal_success_rate) AS avg_goal_success,
    AVG(faithfulness_score) AS avg_faithfulness,
    AVG(tool_selection_accuracy) AS avg_tool_accuracy,
    SUM(CASE WHEN thumbs_up = true THEN 1 ELSE 0 END) * 100.0
        / COUNT(*) AS thumbs_up_pct
FROM connect_ai_agent_metrics
WHERE interaction_timestamp >= date_add('day', -30, current_date)
GROUP BY 1, 2
ORDER BY 1 DESC, avg_goal_success DESC;

⚖️ メリットとデメリット

✅ メリット

ビジネス面

  • 8 つのメトリクスで AI エージェントの品質を多角的に可視化し、改善アクションを特定
  • 忠実性スコアやフィードバックで顧客満足度への影響を早期発見・対処
  • 解決率とエスカレーション率の分析でコスト最適化を実現

技術面

  • 忠実性スコアによるハルシネーション自動検出
  • ダッシュボード、API、データレイクの 3 経路で柔軟にデータアクセス
  • メトリクスデータに基づく PDCA サイクルで体系的な改善が可能

⚠️ 制限事項・考慮点

  • Amazon Connect AI Agents がサポートされているリージョンでのみ利用可能
  • サムズアップ / サムズダウン評価はコンタクトフローで明示的に有効化が必要
  • 忠実性スコアはコンテキストベースのハルシネーション検出に特化しており、全種類の不正確な応答を検出するものではない
  • 顧客フィードバックは任意のため、サンプルバイアスが発生する可能性がある
  • メトリクスの解釈にはコンタクトセンターの運用コンテキストを考慮する必要がある
