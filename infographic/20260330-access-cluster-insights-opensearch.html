NEW Amazon OpenSearch Service

🔍 Cluster Insights
コンソール & EventBridge 対応

AWS マネジメントコンソールからの直接アクセス & イベント駆動型自動化
📅 2026 年 3 月 30 日
OpenSearch v2.17+

📝 概要

Amazon OpenSearch Service の Cluster Insights が、AWS マネジメントコンソールから直接アクセス可能に。さらに Amazon EventBridge へのイベント発行にも対応しました。

クラスターの運用ヘルスに関するキュレーションされたインサイトと、問題を予防するためのアクション可能な推奨事項を提供します。

追加コストなし OpenSearch 2.17+

🔄 Before / After

❌ Before
OpenSearch Dashboards UI でのみ確認
コンソールとの画面切り替えが必要
設定変更は別途 API/コンソールで実行
イベント駆動型ワークフロー構築不可
→

確認と設定変更を同一画面で実行

Dashboards UI でも引き続き利用可

AWS コンソールでの Cluster Insights

⚙️ 設定方法

前提条件

✅OpenSearch バージョン 2.17 以降
✅適切な IAM アクセス権限
✅EventBridge ルール作成権限
1 OpenSearch Service コンソールでドメインを選択し、Cluster Insights セクションを確認
2 推奨された設定変更を同一画面から実行

CLI でインサイト一覧取得

Bash list-insights 
aws opensearch list-insights \
  --entity Type=DomainName,Value=my-domain \
  --time-range From=$(date -d '7 days ago' +%s),To=$(date +%s) \
  --sort-order DESC \
  --max-results 10

EventBridge ルール設定

Bash EventBridge Rule 
aws events put-rule \
  --name "opensearch-cluster-insights" \
  --event-pattern '{
    "source": ["aws.es"],
    "detail-type": ["OpenSearch Service Cluster Insight"]
  }' \
  --state ENABLED
Bash EventBridge Target 
aws events put-targets \
  --rule "opensearch-cluster-insights" \
  --targets "Id"="sns-target","Arn"="arn:aws:sns:us-east-1:123456789012:opensearch-alerts"

⚠️ デメリット・制約

🔒OpenSearch 2.17 以降のみ対応。以前のバージョンはアップグレード必要
📊詳細メトリクス・Top-N 分析は引き続き Dashboards UI のみ
🔑EventBridge ルール設定には追加 IAM 権限が必要
📢大量インサイト時はフィルタリングでノイズ軽減が必要
🧪IsExperimental: true のインサイトは本番判断に慎重な評価が必要

💡 ユースケース

1. 統合コンソールでのクラスター運用管理

複数ドメインのヘルス状態を AWS コンソールで一元確認し、推奨事項に基づく設定変更を同一画面から実行

2. EventBridge による自動通知と対応

CRITICAL / HIGH 優先度のインサイトをフィルタリングし、オンコールチームへ即座に通知。Lambda で自動修復も実現

3. 定期的なヘルスレポート自動生成

API でインサイト情報を取得し、週次レポートの自動生成や社内ダッシュボード連携を実現
