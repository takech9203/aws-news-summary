AWS End User Messaging

📨 Notify によるエンドツーエンドのマネージド OTP 検証

📅 リリース日: 2026 年 10 月 16 日 | 機能: Notify のエンドツーエンドマネージドワンタイムパスコード OTP 検証

📝 概要

AWS End User Messaging の Notify 機能が、エンドツーエンドのマネージド OTP 検証をサポートしました。 電話番号のセットアップ、通信キャリアへの登録、メッセージ配信の管理を行うことなく、AWS 提供の電話番号とコード検証を含む 完全な OTP ソリューションを 5 分以内に構築できます。

Notify がコードの生成・配信・検証までを一貫して実行するため、自前のコード管理ロジックが不要になります。 配信チャネルにはテキスト (SMS)、音声に加えて、新たに WhatsApp が追加されました。

⚙️ 主要機能

🔐 1. マネージドコード生成・検証

endusermessaging 名前空間の SendNotifyCodeVerification と ValidateNotifyCodeVerification の 2 つの API 操作で検証フローが完結。 AWS End User Messaging がパスコードを生成して配信し、受信者が入力したコードを検証します。コードの保存や有効期限管理のロジックを自前で実装する必要がありません。

📋 2. Notify コード設定による一元的なポリシー管理

コードの種別、桁数、有効期間、受信者ごとの試行回数を一度定義すれば再利用可能。チャネルごとのテンプレートもあわせて設定でき、 設定後は送信 API の呼び出し 1 回で選択したチャネルにコードを配信できます。

💬 3. マルチチャネル配信 (WhatsApp 対応を追加)

テキスト (SMS)、音声に加えて、新たに WhatsApp でのコード配信をサポート。AWS 管理の送信元電話番号と事前承認済みテンプレートを使用するため、 電話番号のプロビジョニングやキャリア登録が不要です。

🛡️ 4. 組み込みの不正対策

すべての Notify 設定に、人為的に増幅されたトラフィック (AIT) をフィルタリングする不正対策が必須で含まれます。 即時利用可能な Basic ティアと、上限引き上げと対応国拡大が可能な Advanced ティアを提供します。

🚧 制限事項

✗テンプレートは AWS 管理の事前承認済みテンプレートから選択する方式であり、独自テンプレートの作成・変更はできない
✗Basic ティアは即時利用できるが上限が保守的に設定されており、上限引き上げと対応国の拡大には Advanced ティアへのアップグレード検証が必要
✗メッセージ送信前に、モバイルキャリアの前提条件 (利用規約、プライバシー、オプトイン) への対応が必要

🤔 考慮すべき点

⚠OTP 検証には成功した検証ごとの料金が通常のメッセージ送信料金に加算されるため、既存の自前実装と比較したコスト評価が必要
⚠既にコード生成・検証ロジックを自前で運用している場合は、マネージド方式への移行による挙動の違い (有効期間、試行回数の扱いなど) を確認する必要がある

🎯 ユースケース

🔑 ユースケース 1: サインアップ・ログイン時の本人確認

シナリオ: Web サービスやモバイルアプリの新規登録・ログイン時に、電話番号の所有確認を行いたい。

実装例: Notify コード設定で 6 桁・有効期間数分・試行回数制限を定義 → 登録フォーム送信時に SendNotifyCodeVerification で SMS にコードを送信 → ユーザーが入力したコードを ValidateNotifyCodeVerification で検証

効果: コード管理基盤を自前で構築することなく、短期間で本人確認フローをリリースできる。

💳 ユースケース 2: トランザクション認証

シナリオ: EC サイトや金融サービスで、高額決済や設定変更などの重要操作時に追加認証を行いたい。

実装例: 重要操作の実行前に SendNotifyCodeVerification を呼び出し → ユーザーの選択に応じて SMS、音声、WhatsApp のチャネルを指定 → 検証成功時のみトランザクションを続行

効果: AIT 保護が組み込まれたマネージド基盤により、不正トラフィックを抑えつつ重要操作のセキュリティを強化できる。

🔓 ユースケース 3: アカウント復旧

シナリオ: パスワードを忘れたユーザーのアカウント復旧時に、登録済み電話番号で本人確認を行いたい。

実装例: 復旧リクエスト受付時に SendNotifyCodeVerification でコードを送信 → SMS が届きにくい環境のユーザーには音声または WhatsApp を選択 → ValidateNotifyCodeVerification の検証成功後にパスワード再設定を許可

効果: 複数チャネルへの対応により、ユーザー環境を問わず確実な本人確認を実現できる。

💰 料金

Notify は従量課金制で、メッセージごとに Notify 利用料と各チャネルの標準メッセージ送信料金が課金されます。

項目 料金
Notify 利用料 (段階制) 1 メッセージあたり 0.045 USD から。月間 250,001 メッセージ超では 0.030 USD まで低減
OTP 検証 成功した検証 1 件あたり 0.045 USD (標準のメッセージ送信料金に加えて課金)
WhatsApp 配信 AWS 利用料 (送信 1 件あたり 0.005 USD など) に加えて、国とメッセージタイプにより異なる Meta の料金が発生
音声 分単位の課金。送信先の国・キャリアにより料金が異なる
