I8ge ストレージ最適化インスタンスが AWS GovCloud (US) で利用可能に

📅 2026 年 7 月 20 日

📌 概要

AWS は、Amazon EC2 I8ge インスタンスが AWS GovCloud (US-East)、AWS GovCloud (US-West) の各リージョンで利用可能になったことを発表しました。 I8ge は AWS Graviton4 プロセッサーを搭載したストレージ最適化インスタンスで、前世代の Graviton2 ベースのストレージ最適化インスタンスと比較して最大 60% 優れたコンピューティング性能を提供します。

今回の提供開始により、米国連邦政府機関やその関連組織など、規制要件の厳しいワークロードを AWS GovCloud (US) 上で運用するお客様も、最新世代のストレージ最適化インスタンスを活用できるようになりました。 I8ge は第 3 世代 AWS Nitro SSD によるローカル NVMe ストレージを使用し、1 インスタンスあたり最大 120TB のローカル NVMe ストレージ、最大 180 Gbps のネットワーク帯域幅を提供します。

⛔ Before：アップデート前の課題
  • GovCloud (US) では I8ge が利用できず、Graviton4 ベースのストレージ最適化インスタンスの性能を活用できなかった
  • 規制対象ワークロードでは前世代のインスタンスを利用せざるを得ず、コンピューティングおよびストレージ性能に制約があった
  • 大容量ローカル NVMe や高帯域ネットワークを必要とする GovCloud 上のワークロードで、最新世代の選択肢が限られていた
🎉 After：アップデート後の改善
  • GovCloud (US-East、US-West) の両リージョンで I8ge が利用可能になり、規制要件を満たしながら Graviton4 の高性能を活用できる
  • 第 3 世代 Nitro SSD により、1 インスタンスあたり最大 120TB のローカル NVMe ストレージを利用可能
  • 最大 180 Gbps のネットワーク帯域幅により、データ集約型ワークロードのスループットが向上
  • メタルサイズ 2 つを含む 11 種類のサイズから最適なサイズを選択可能

Bash ステップ 1: Arm 対応 AMI の検索 
# GovCloud US-West リージョンで Arm 対応の Amazon Linux 2023 AMI を検索
aws ec2 describe-images \
  --region us-gov-west-1 \
  --filters "Name=name,Values=al2023-ami-*-arm64*" \
            "Name=state,Values=available" \
  --owners amazon \
  --query "Images | sort_by(@, &CreationDate) | [-1].ImageId" \
  --output text
Bash ステップ 2: I8ge インスタンスの起動 
# I8ge インスタンスを GovCloud US-West リージョンで起動
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type i8ge.xlarge \
  --region us-gov-west-1 \
  --subnet-id subnet-xxxxxxxxxxxxxxxxx \
  --security-group-ids sg-xxxxxxxxxxxxxxxxx \
  --key-name my-key-pair
Bash ステップ 3: ローカル NVMe ストレージの確認とマウント 
# インスタンスに接続後、NVMe デバイスを確認
lsblk

# NVMe ストレージをフォーマットしてマウント
sudo mkfs -t xfs /dev/nvme1n1
sudo mkdir /data
sudo mount /dev/nvme1n1 /data
💡 ローカルストレージの注意点
I8ge のローカル NVMe ストレージは一時ストレージ (エフェメラルストレージ) です。インスタンスの停止や終了時にデータが失われるため、永続化が必要なデータは EBS や S3 にバックアップしてください。

✅ メリット

💼 ビジネス面

  • 規制対象ワークロードへの対応：GovCloud (US) 提供により、厳格なコンプライアンス要件を満たしながら最新インスタンスを利用可能
  • コスト効率の向上：より少ないインスタンスで処理でき、TB あたり性能向上でストレージコストを最適化
  • 大規模データワークロードの集約：最大 120TB のローカルストレージで少数インスタンスに集約可能

🔧 技術面

  • 大容量ローカルストレージ：第 3 世代 Nitro SSD により最大 120TB の NVMe を利用可能
  • 高帯域ネットワーク：最大 180 Gbps でデータ転送やレプリケーションが高速化
  • Graviton4 の性能：前世代比最大 60% の性能向上でデータ処理やクエリを高速化
  • 柔軟なサイズ選択：メタルを含む 11 種類から最適なサイズを選択

⚠️ デメリット・制約事項

制限事項

  • Arm (Graviton) アーキテクチャのため、x86 専用ソフトウェアやバイナリは動作しない (Arm 対応版が必要)
  • ローカル NVMe はエフェメラルであり、インスタンス停止・終了時にデータが失われる
  • 現時点では GovCloud (US-East、US-West) での提供であり、マルチリージョン構成では可用性の確認が必要

考慮すべき点

  • Im4gn からの移行時には Graviton4 互換性テストの実施を推奨
  • ローカル NVMe 容量はインスタンスサイズに依存するため、適切なサイズ選択が重要
  • データの永続化には EBS や S3 への定期的なバックアップ戦略が必要
  • Graviton2 から Graviton4 への移行ではベンチマークテストを推奨

🎯 ユースケース

1. 政府機関向け高性能リレーショナルデータベース
シナリオ：米国連邦政府機関が、大規模な行政データを管理するセルフマネージド PostgreSQL データベースを GovCloud (US) で運用したい。
実装：i8ge.4xlarge で PostgreSQL データベースサーバーを起動 (us-gov-west-1)。
効果：高性能なローカル NVMe により、トランザクション処理のレスポンスタイムが改善され、コンプライアンス要件を満たしながらピーク時のクエリ性能が向上。
2. 大規模データ分析基盤
シナリオ：規制対象の組織が、最大 120TB の大規模データセットに対する分散処理基盤を GovCloud 上に構築したい。
実装：データ分析ノード用に複数の i8ge.12xlarge をプレイスメントグループで起動 (us-gov-east-1)。
効果：最大 120TB のローカルストレージと最大 180 Gbps のネットワーク帯域により、大規模データセットの高速分散処理を実現。
3. 検索エンジン / 分散ファイルシステム
シナリオ：政府関連の組織が、数百万件のドキュメントに対するリアルタイム全文検索を提供するセルフマネージド OpenSearch クラスターを構築したい。
実装：OpenSearch データノード用に複数の i8ge.2xlarge を起動 (us-gov-west-1)。
効果：高ランダム I/O 性能により、インデックス検索の応答時間が改善され、検索結果返却が高速化。

🏛️ AWS GovCloud (US) について
AWS GovCloud (US) は、米国政府の規制要件やコンプライアンス要件に対応するために設計された分離されたリージョンです。今回の提供開始により、規制対象ワークロードでも最新のストレージ最適化インスタンスを活用できるようになりました。

🔗 関連サービス・機能

  • Amazon EBS：I8ge のローカル NVMe と組み合わせて、永続データ用に EBS ボリュームを使用
  • Amazon S3：ローカルストレージのデータバックアップ先として活用
  • Amazon EC2 Auto Scaling：ワークロードに応じた I8ge インスタンスの自動スケーリング
  • AWS Graviton：I8ge が搭載する Graviton4 プロセッサーのエコシステムと Arm 対応ソフトウェア
  • AWS Nitro System：I8ge の基盤となるセキュリティとパフォーマンスの最適化インフラストラクチャ

📝 まとめ

Amazon EC2 I8ge インスタンスが AWS GovCloud (US-East、US-West) リージョンで利用可能になったことにより、規制要件の厳しいワークロードを運用するお客様も、AWS Graviton4 プロセッサーと第 3 世代 Nitro SSD を活用した最新のストレージ最適化インスタンスを利用できるようになりました。 1 インスタンスあたり最大 120TB のローカル NVMe ストレージ、最大 180 Gbps のネットワーク帯域幅、前世代比最大 60% のコンピューティング性能向上を提供します。 GovCloud 上でリレーショナルデータベース、NoSQL データベース、検索エンジン、大規模データ分析など、ローカルストレージへの高ランダム I/O アクセスを必要とするワークロードを運用している場合は、I8ge への移行を検討し、パフォーマンスとコスト効率の向上を実現してください。
