🧠 Claude Opus 4.7 Adaptive Thinking

2026-05-07

📋 概要

Kiro IDE および CLI で Claude Opus 4.7 に Adaptive Thinking (適応型思考) 機能が追加された。タスクの複雑さに応じてモデルが使用する推論の深さを自動的に調整し、難しい問題にはより多くの時間をかけて思考し、単純な問題にはすばやく応答する。

Pro、Pro+、Power サブスクライバー、および IAM Identity Center ユーザーに提供される。最適なパフォーマンスには IDE v0.11.133 以降 および CLI v2.2.0 以降 が必要。

Before / After

❌ Before

  • 思考深度が固定で、単純/複雑タスクに同じリソースを消費
  • 単純なタスクで応答が不必要に遅い
  • 複雑なタスクで推論不足、品質低下
  • 手動でモード切替が必要、フロー中断

✅ After

  • 複雑さを自動判定し推論深度を動的調整
  • 単純タスクへの応答速度が向上
  • 複雑タスクには十分な推論が自動割当
  • 手動切替不要でシームレスな開発体験

⚡ 主要機能

🧠 Adaptive Thinking (適応型思考)

タスクの複雑さをリアルタイムで分析し、最適な推論深度を自動選択。単純なタスクには最小限の推論で高速応答、複雑なタスクにはより多くの推論ステップを費やして精度を向上。開発者による手動の思考モード設定が不要。

👥 Pro / Pro+ / Power サブスクライバーへの提供

Pro プラン以上のすべてのサブスクライバーが利用可能。IAM Identity Center ユーザーにも対応。既存の Opus 4.7 クレジット乗数 (2.2x) は維持。

🖥️ IDE および CLI の両方に対応

Kiro IDE v0.11.133 以降、Kiro CLI v2.2.0 以降で利用可能。最新バージョンへのアップデートにより最適なパフォーマンスを発揮。

タスク複雑度 推論深度 特徴

⚙️ 設定方法

前提条件

  • Pro、Pro+、または Power プランのサブスクリプションが有効であること
  • AWS IAM Identity Center でのログインが設定されていること
  • Kiro IDE v0.11.133 以降、または Kiro CLI v2.2.0 以降がインストールされていること

Step 1: Kiro のアップデート

Bash CLI アップデート

IDE の場合は、アプリを再起動することで最新バージョンが自動的に適用される。

Step 2: モデルの選択

Bash モデル設定 
# CLI の場合: Opus 4.7 を選択
kiro config set model opus-4.7

IDE の場合は、モデル選択メニューから Claude Opus 4.7 を選択する。Adaptive Thinking は Opus 4.7 選択時に自動的に有効化される。

Step 3: 動作確認

Bash バージョン確認 
# バージョン確認
kiro --version

バージョンが 2.2.0 以上であることを確認し、通常通りタスクを実行する。Adaptive Thinking は自動的に動作し、追加の設定は不要。

⚠️ デメリット・制約事項

制限事項

  • Pro プラン以上が必要であり、Free プランでは利用不可
  • IDE v0.11.133 以降、CLI v2.2.0 以降が必須であり、旧バージョンでは Adaptive Thinking が機能しない
  • Opus 4.7 のクレジット乗数は 2.2x であり、Sonnet モデルと比較してクレジット消費が多い

考慮すべき点

  • 推論深度の自動判定は、タスクの記述方法によって結果が変わる可能性がある
  • ユーザーが明示的に深い思考を強制する方法が限定的な場合がある
