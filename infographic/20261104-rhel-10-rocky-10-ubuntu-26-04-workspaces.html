Amazon WorkSpaces Personal

🖥️ RHEL 10 / Rocky Linux 10 / Ubuntu 26.04 LTS
バンドルの提供開始

📅 リリース日: 2026 年 11 月 4 日 | 最新エンタープライズ Linux デスクトップを WorkSpaces で

📋 概要

AWS は、Amazon WorkSpaces Personal 向けの新しい Linux バンドルとして、 Rocky Linux 10、Red Hat Enterprise Linux 10、 Ubuntu 26.04 LTS の 3 つを発表しました。 最新のエンタープライズ Linux OS 上で WorkSpaces を起動し、これらのリリースでのみ利用可能な新しいソフトウェアパッケージを使用できます。

新バンドルはモダンな Wayland ディスプレイ技術を搭載し、 各ディストリビューションによる強化されたセキュリティと、より長いサポートライフサイクルを提供します。 対象は、Linux ベースの仮想デスクトップを利用する開発者、エンジニアリングチーム、IT 管理者です。

❌ アップデート前の課題

  • Linux バンドルは Rocky Linux 8/9、RHEL 8/9、Ubuntu 22.04/24.04 LTS までで、最新メジャーバージョンを利用できなかった
  • 最新 OS リリースでのみ提供されるパッケージやデスクトップ機能を利用できなかった
  • 旧 OS のサポートライフサイクル終了が近づくにつれ、移行計画の制約が大きくなっていた

✅ アップデート後の改善

  • Rocky Linux 10、RHEL 10、Ubuntu 26.04 LTS のマネージドバンドルで最新 Linux デスクトップを起動可能
  • モダンな Wayland ディスプレイ技術で最新のデスクトップ機能を利用可能
  • 強化されたセキュリティと長期サポートライフサイクルの恩恵
  • 既存バンドルも継続利用可能で、自社のペースで段階的に移行できる

新しい 3 つの Linux バンドルが WorkSpaces Personal に追加され、既存バンドルと並行して提供されます。 新バンドルは Wayland ディスプレイ技術を搭載し、4 つのバンドルサイズから選択できます。

⚡ 主要機能

1️⃣ 最新エンタープライズ Linux OS のサポート

  • Rocky Linux 10、RHEL 10、Ubuntu 26.04 LTS のマネージドバンドルを新規提供
  • これらのリリースでのみ利用可能な新しいソフトウェアパッケージを使用可能
  • 強化されたセキュリティと長期サポートライフサイクルを享受

2️⃣ Wayland ディスプレイ技術の搭載

  • 新バンドルはモダンな Wayland ディスプレイ技術を搭載
  • 最新の Linux デスクトップ機能へのアクセスが可能

3️⃣ 既存環境への影響なしの段階的移行

  • Rocky Linux 8/9、RHEL 8/9、Ubuntu 22.04/24.04 LTS の既存バンドルは引き続き利用可能
  • 既存の WorkSpaces は変更なしでそのまま稼働を継続
  • アプリケーションとワークフローの準備が整い次第、ユーザーを新 OS へ移行できる

4️⃣ 複数のバンドルサイズ

  • Standard、Performance、Power、PowerPro の 4 サイズで提供
  • ワークロードの要件に応じてコンピューティングリソースを選択可能

ステップ 1: バンドルの確認

Bash AWS マネージドバンドルの一覧確認 
aws workspaces describe-workspace-bundles \
  --owner AMAZON \
  --query "Bundles[?contains(Name, 'Ubuntu') || contains(Name, 'Rocky') || contains(Name, 'Red Hat')].{Name:Name,BundleId:BundleId}"

AWS が提供するマネージドバンドルの一覧から、Rocky Linux 10、RHEL 10、Ubuntu 26.04 LTS のバンドル ID を確認します。

ステップ 2: 新しい WorkSpace の作成

Bash 新バンドルで WorkSpace を作成 
aws workspaces create-workspaces \
  --workspaces "DirectoryId=<ディレクトリID>,UserName=<ユーザー名>,BundleId=<バンドルID>"

確認したバンドル ID を指定して、新しい Linux WorkSpace を作成します。マネジメントコンソールからも、WorkSpace 作成時に新しい OS のマネージドバンドルを選択できます。

ステップ 3: 段階的な移行

既存の WorkSpaces は変更なしで稼働を継続するため、アプリケーションの動作確認が完了したユーザーから順次、新 OS バンドルの WorkSpace へ移行します。

💡 メリット

💼 ビジネス面

✓長期サポートライフサイクル: サポート期間を最大限活用でき、OS 移行の頻度と計画リスクを低減
✓自社ペースでの移行: 既存バンドルが継続提供されるため、業務影響を抑えて段階的に移行可能
✓コンプライアンス対応: 最新 OS のセキュリティ強化で、社内標準への準拠を維持しやすい

⚙️ 技術面

✓最新パッケージの利用: 新リリースでのみ提供されるパッケージやツールチェーンを活用
✓Wayland による最新デスクトップ体験: モダンなディスプレイ技術で最新機能を活用
✓運用の簡素化: マネージドバンドルのため OS イメージの独自メンテナンスが不要

⚠️ デメリット・制約事項

制限事項

⚠️対象は WorkSpaces Personal であり、新規作成する WorkSpace でバンドルを選択する方式
⚠️バンドルサイズは Standard、Performance、Power、PowerPro の 4 種類から選択

考慮すべき点

⚠️既存 WorkSpace の新 OS 切り替えには、アプリケーションとワークフローの互換性確認が必要
⚠️X11 前提のアプリケーションやツールは、Wayland への移行に伴い事前の動作検証が望ましい
⚠️RHEL バンドルはサブスクリプション体系の確認が必要なため、料金ページで最新の課金条件を確認

🎯 ユースケース

1. 開発者向け最新 Linux デスクトップの標準化

シナリオ: RHEL 8 ベースの WorkSpaces を利用している企業が、サポートライフサイクルの長い RHEL 10 へ計画的に移行したい。

Amazon WorkSpaces Personal で RHEL 10、Rocky Linux 10、Ubuntu 26.04 LTS の最新 Linux バンドルが利用可能になり、 Wayland ディスプレイ技術による最新のデスクトップ体験と長期サポートライフサイクルを享受できるようになりました。 既存の WorkSpaces は影響を受けないため、まずは検証用 WorkSpace を新バンドルで作成し、 アプリケーションの互換性を確認したうえで段階的な移行を計画することを推奨します。
