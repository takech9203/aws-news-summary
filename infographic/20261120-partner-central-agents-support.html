🤝 AWS Partner Central

🤖 Partner Central Agents による
サポートケースの作成・管理

📅 リリース日: 2026 年 11 月 20 日
Partner Central と AWS Marketplace のサポートを単一チャットで即時解決・ケース化

📋 概要

AWS Partner Central Agents が、AWS Partner Central と AWS Marketplace のサポートケースを 1 か所で作成・管理できるようになりました。エージェントは 24 時間 365 日稼働し、パートナーのアカウント情報と AWS が提供するパートナー固有の信頼できるナレッジを活用して、多くの問い合わせを即座に解決します。サポートエンジニアの対応が必要な場合は、エージェントが詳細を収集してケースを起票します。

本機能はコンソールに加えて MCP サーバー経由でも提供され、Kiro、AWS Quick、CRM システムなどの AI クライアントからも同じサポート体験を利用できます。

❌ Before: アップデート前の課題

  • Partner Central と Marketplace の問い合わせ窓口が分かれており、どこに問い合わせるべきかを探す必要があった
  • よくある質問でもケースを起票して回答を待つ必要があり、解決までに時間がかかっていた
  • カテゴリ選択や説明文の記述をすべて手動で行う必要があり、情報不足でサポートとのやり取りが往復しがちだった

✅ After: アップデート後の改善

  • Partner Central と Marketplace のケースを単一のチャット体験から作成・管理できる
  • エージェントが多くの問い合わせに即時回答し、ケース起票なしで解決できる
  • カテゴリ割り当てと説明文のドラフトを自動化し、パートナーは確認と送信だけで済む
  • 進捗確認・返信・ファイル添付まで同一チャットで完結し、記録は AWS Support Center に保存
  • MCP サーバー経由で Kiro、AWS Quick、CRM などの AI クライアントからも利用可能

パートナーはコンソールのチャットまたは MCP サーバー経由の AI クライアントから Partner Central Agents にアクセスし、多くの問い合わせは即時回答で解決、必要な場合のみサポートケースが作成されて AWS Support Center に記録されます。

⚡ 主要機能

1️⃣ 単一チャットでのサポートケース作成
  • Support ページで「Get support」を選択するか、チャットで課題を説明するだけで開始
  • エージェントが必要な詳細 (事象、発生時期、関連する商談・ファンド申請・リスティング・請求書の ID など) をヒアリング
  • 生成 AI がケースフォーム (件名、説明、カテゴリ、サブカテゴリ) をドラフトし、パートナーは確認・修正して送信するだけ
2️⃣ 即時回答による問い合わせの自己解決
  • アカウントの詳細と、Partner Central・Marketplace のガイドに基づく信頼できるナレッジを活用して回答
  • 多くの質問はサポートケースを起票せずにその場で解決
  • 24 時間 365 日利用可能
3️⃣ ケースのエンドツーエンド管理
  • 同一チャット内でやり取りの確認、進捗モニタリング、返信、ファイル添付が可能
  • ステータス確認や、やり取りの要約もチャットに依頼できる
  • 返信や解決などの書き込み操作は「Approve」を選択する人間による承認フローを経由
4️⃣ AWS Support Center への統合
  • 本リリースにより Partner Central と Marketplace のケースは AWS Support Center に移行
  • 完全な記録が保存され、「Active cases」「Resolved cases」タブでも追跡可能
  • やり取りは中国語、フランス語、ドイツ語、日本語、韓国語、ポルトガル語、スペイン語に翻訳可能
5️⃣ MCP サーバーによる AI クライアント連携
  • MCP サーバー経由で同じサポート体験を利用可能
  • Kiro、AWS Quick、Claude Code、Claude Desktop、CRM システムなどの MCP 互換クライアントに対応
  • 認証はブラウザベースの OAuth または SigV4 署名に対応。プロキシや IDE プラグインは不要

🔌 MCP サーバーの仕様

項目詳細
エンドポイントhttps://partnercentral-agents-mcp.us-east-1.api.aws/mcp
ホストリージョン米国東部 (バージニア北部) のみ。接続は任意の場所から可能

🔐 必要な IAM 権限 (Support ページ)

AWS マネージドポリシー (AWSMarketplaceSellerProductsReadOnly を除く) を使用している場合は、すでに必要な権限が含まれています。

JSON IAM ポリシー例 
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PartnerCentralAndMarketplaceSupportCases",
      "Effect": "Allow",
      "Action": [
        "support:SearchForCases",
        "support:DescribeCases",
        "support:DescribeCommunications",
        "support:CreateCase",
        "support:AddAttachmentsToSet",
        "support:AddCommunicationToCase",
        "support:ResolveCase"
      ],
      "Resource": "*"
    },
    {
      "Sid": "SupportCenterConsole",
      "Effect": "Allow",
      "Action": "support-console:*",
      "Resource": "*"
    },
    {
      "Sid": "PartnerCentralAccountCheck",
      "Effect": "Allow",
      "Action": "partnercentral:ListPartners",
      "Resource": "*",
      "Condition": {
        "StringEquals": {
          "partnercentral:Catalog": ["AWS", "Sandbox"]
        }
      }
    }
  ]
}
💡 AWS Marketplace セラーの場合は、partnercentral:ListPartners の代わりに aws-marketplace:ListEntities が必要です。アカウントがパートナーとセラーの両方である場合は両方を含めます。

🛠️ 設定方法

✅ 前提条件

✓AWS Partner Network (APN) に参加し、Partner Central のアカウントを保有していること (または AWS Marketplace セラーであること)
✓Partner Central のアカウントが AWS コンソールに移行済みで、AWS アカウントと連携していること
✓利用する IAM ロールに、サポートケースの作成・管理に必要な権限が付与されていること
✓MCP サーバーを利用する場合は、MCP 互換クライアント (Kiro、AWS Quick、Claude Code、Claude Desktop など) を用意していること

📋 手順

1
Support ページでサポートチャットを開始する

Partner Central コンソールの Support ページを開き、「Get support」を選択するか、提示された質問例を選択します。AWS assistant パネルにサポートチャットが開きます。

2
課題を説明して回答を確認する

チャットに質問や課題を入力すると、エージェントがアカウント情報とパートナー向けナレッジに基づいて即座に回答します。多くの質問はこの時点で解決します。チャットの会話は保存されないため、必要な情報は閉じる前にコピーしておきます。

3
必要に応じてサポートケースを作成する

回答で解決しない場合、エージェントが詳細 (事象、発生時期、関連 ID など) をヒアリングし、ケースフォームをドラフトします。内容を確認・修正し、必要に応じてファイルを添付して「Submit」を選択すると、ケースが「Active cases」タブと AWS Support Center に登録されます。

4
同一チャットでケースをフォローする

ケース ID を伝えるか、オープン中のケースの一覧表示を依頼することで、ステータス確認、やり取りの要約、フォローアップの送信、ケースの解決を依頼できます。返信や解決などの操作は「Approve」の選択で実行されます。

5
(オプション) MCP サーバー経由で AI クライアントから利用する

Kiro や AWS Quick などの AI クライアントから利用する場合は、MCP サーバーを登録します。以下は Claude Code CLI の例です。

Bash MCP サーバーの登録 (Claude Code CLI) 
claude mcp add partnercentral --transport http \
  https://partnercentral-agents-mcp.us-east-1.api.aws/mcp
💡 初回接続時にブラウザで AWS Sign-In による OAuth 認証を行います。CI/CD や自動化スクリプトなどブラウザを使えない環境では、SigV4 署名 (サービス名: partnercentral-agents-mcp、リージョン: us-east-1) で認証します。

💡 メリット

💼 ビジネス面

✓問い合わせ解決の高速化: 24 時間 365 日稼働のエージェントが多くの問い合わせを即時解決し、回答待ちによる業務停滞を削減
✓窓口の一本化: Partner Central と Marketplace のサポートが単一チャットに統合され、問い合わせ先を探す手間がなくなる
✓グローバルチームでの活用: ケースのやり取りを日本語を含む 7 言語に翻訳でき、分散チームでも対応しやすい

⚙️ 技術面

✓ケース品質の向上: 詳細を漏れなくヒアリングし、カテゴリ割り当てと説明文のドラフトを自動化。往復のやり取りを削減
✓AI クライアント統合: MCP サーバー経由で Kiro、AWS Quick、CRM などから利用でき、既存ワークフローに組み込める
✓記録の一元管理: 完全な記録が AWS Support Center に保存され、追跡・監査がしやすい

⚠️ デメリット・制約事項

🚧 制限事項

✗サポートチャットの会話自体は保存されないため、必要な情報はチャットを閉じる前にコピーしておく必要がある (ケースの記録は AWS Support Center に保存される)
✗チャットからのケース作成時の添付ファイルは最大 3 ファイルで、画像 3.75 MB・ドキュメント 4.5 MB のサイズ制限がある (AWS Support Center からの返信では最大 10 ファイル、各 150 MB)
✗MCP サーバーのホストは米国東部 (バージニア北部) のみ (接続は任意の場所から可能)
✗MCP サーバーの OAuth 認証には signin:AuthorizeOAuth2Access と signin:CreateOAuth2Token の IAM 権限が必要で、組織が制限している場合は SigV4 認証を使用する必要がある

🤔 考慮すべき点

⚠️ケースのやり取りはケースを閲覧できる全員に表示されるため、認証情報、クレジットカード番号、署名付き URL、個人を特定できる情報は記載しない
⚠️エージェントがドラフトしたケースフォームは送信前に必ず内容を確認し、カテゴリが予測されなかった場合は手動で選択する
⚠️ルートユーザー以外でサインインしている場合、ケース通知を受け取るには自分のメールアドレスを「Additional email contacts」に追加する
⚠️MCP サーバー利用時の書き込み操作は人間による承認 (human-in-the-loop) を前提とし、提案されたパラメータを確認してから承認する運用が推奨される

🗄️ AWS Support Center

本リリースにより Partner Central と Marketplace のケースの保存先となるサービス。やり取りの翻訳 (7 言語) や返信・解決の操作も可能。

サポートに加えて、商談管理、ファンディング、パートナーオンボーディングなどのエージェント体験を MCP 互換クライアントに提供するサーバー。

🛒 AWS Marketplace

セラー向けのサポートケース (Commercial Marketplace、European Sovereign Cloud Marketplace など) も本チャット体験の対象。
