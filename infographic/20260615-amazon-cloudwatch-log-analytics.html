💡 概要 — 3 つの機能が 1 画面に

Amazon CloudWatch が、ログ分析を 1 つのコンソールに統合する Log Analytics を発表しました。 ログのクエリと分析を行う Logs Insights、リアルタイムのログストリーミングを行う Live Tail、 上位コントリビューターを特定する Contributor Insights を 1 画面に集約します。

Log Analytics はデフォルトのエクスペリエンスとして提供され、異なるタブで複数のクエリを同時に実行できます。 すべての商用 AWS リージョンで利用でき、基盤となる各機能と同じ料金体系のため追加コストは発生しません。

❌ Before — 分断されたワークフロー
  • クエリ・リアルタイム監視・コントリビューター分析が別々の画面に分離
  • 目的ごとに画面を切り替える必要があった
  • 複数クエリの並行実行と比較が行いにくく、調査効率が低下
➡
✅ After — 統合コンソール
  • Logs Insights / Live Tail / Contributor Insights を 1 つのコンソールで利用
  • 異なるタブで複数のクエリを同時に実行可能
  • パターン分析・保存クエリ・ファセット・自然言語クエリ生成・可視化をそのまま継承

Log Analytics は CloudWatch Logs のロググループに対して、クエリ・リアルタイムストリーミング・コントリビューター分析の 3 つの機能を 1 つのコンソールから提供します。

🔧 主要機能

🖥️ 統合コンソールエクスペリエンス
  • Logs Insights / Live Tail / Contributor Insights を 1 画面に集約
  • デフォルトのエクスペリエンスとして提供
  • オプトアウトすると従来の各機能を Log Analytics と並べて利用可能
🗂️ マルチタブによる複数クエリ実行
  • 異なるタブで複数のクエリを同時に実行
  • 複数の調査を並行して進めて分析効率を向上
♻️ 既存 Logs Insights 機能の継承
  • パターン分析でログの傾向を把握
  • パラメータ付き保存クエリで再利用
  • ファセットによるインタラクティブ探索
  • 自然言語クエリ生成・可視化に対応
🔗 Live Tail / Contributor Insights 統合アクセス
  • Live Tail でログをリアルタイムストリーミング
  • Contributor Insights で上位コントリビューターを特定
  • いずれも Log Analytics 内から直接アクセス可能

📋 技術仕様 — 機能の構成要素

項目詳細
Logs Insightsログデータのクエリと分析。パターン、保存クエリ、ファセット、自然言語クエリ生成、可視化に対応
Live Tailログのリアルタイムストリーミング
Contributor Insights上位コントリビューターの特定
デフォルト設定Log Analytics がデフォルトエクスペリエンス。オプトアウト可能
料金基盤となる各機能と同じ料金体系 (追加料金なし)

⚙️ 設定方法 — 3 ステップ

1
Log Analytics を開く

CloudWatch コンソールを開き、ナビゲーションから Log Analytics を選択します。デフォルトのエクスペリエンスとして表示されます。

2
クエリを実行する

分析対象のロググループを選択しクエリを実行。異なるタブで複数クエリを同時実行でき、自然言語クエリ生成も利用できます。

3
Live Tail と Contributor Insights を利用する

同じ Log Analytics 内から Live Tail でリアルタイムストリーミング、Contributor Insights で上位コントリビューターを特定。従来画面を希望する場合はオプトアウトで並列利用も可能です。

前提条件: ログを送信中のロググループが存在すること / CloudWatch コンソールへの IAM 権限 / 各機能の利用権限を保有していること。

🎯 ユースケース

🚨 1. インシデント対応時の集約的なログ調査

シナリオ: 本番でエラー率が上昇した際、クエリ・リアルタイム監視・上位コントリビューター特定を同時に行いたい。

効果: 統合コンソールから 3 機能を切り替えずに利用でき、原因特定までの時間を短縮。

🗂️ 2. マルチタブによる並行調査

シナリオ: 複数サービスにまたがる問題を、サービスごとに異なるクエリで並行実行し比較したい。

効果: 異なるタブで複数クエリを同時実行し、横断的な分析を効率化。

💬 3. 自然言語クエリによるログ分析の民主化

シナリオ: クエリ構文に不慣れなメンバーがログから必要な情報を抽出したい。

効果: 自然言語クエリ生成で構文を意識せずクエリを作成でき、より多くのメンバーが分析に参加可能。

🔗 関連サービス・機能

  • Amazon CloudWatch Logs — Log Analytics が分析対象とするログを保管するサービス
  • CloudWatch Logs Insights — ログのクエリと分析を行う基盤機能。Log Analytics の中核を構成
  • CloudWatch Live Tail — ログのリアルタイムストリーミング機能。Log Analytics から直接利用可能
  • CloudWatch Contributor Insights — 上位コントリビューターを特定する機能。Log Analytics から直接利用可能

📝 まとめ

Amazon CloudWatch Log Analytics は、Logs Insights・Live Tail・Contributor Insights を 1 つの統合コンソールにまとめ、 ログ調査のワークフローを大幅に効率化するアップデートです。

追加料金なくすべての商用リージョンで利用できるため、まずは CloudWatch コンソールで Log Analytics を開き、 マルチタブでのクエリ実行や既存機能の継承による操作性の向上を確認することをおすすめします。
