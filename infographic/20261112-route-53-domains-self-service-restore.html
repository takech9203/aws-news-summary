Amazon Route 53 Domains

🌐 期限切れ・削除済みドメインのセルフサービス復元

📅 リリース日: 2026 年 11 月 12 日 ｜ 新機能: RestoreDomain API によるセルフサービス復元

📝 概要

Amazon Route 53 Domains が、期限切れまたは削除済みドメインのセルフサービス復元をサポートしました。 Route 53 コンソール、AWS CLI、AWS SDK から、お客様自身でドメインの復元を実行できます。

これまで、更新忘れ・支払い方法の有効期限切れ・誤削除などで失われたドメインの復元には AWS サポートへの問い合わせが必要でした。 今回のアップデートにより、新しく追加された RestoreDomain API を使用して、サポートを介さずに復元を完了できます。

復元プロセスは 4 ステップで完結。Route 53 が TLD レジストリと連携して登録を再有効化し、ドメインを AWS アカウントに戻します。

❌ アップデート前の課題
✗復元には AWS サポートへの問い合わせが必要で、時間がかかっていた
✗復元可能な期限が限られる中、サポートとのやり取りによる遅延が機会損失のリスクに
✗復元作業を自動化やスクリプトに組み込めなかった
✅ アップデート後の改善
✓コンソール・CLI・SDK からセルフサービスで復元可能に
✓RestoreDomain API により復元操作をプログラムから実行可能
✓復元コストを事前確認・同意した上でリクエストでき、意図しない課金を防止
✓復元できない場合はリクエストが失敗し、課金は発生しない

RestoreDomain API の呼び出し例 (Python SDK)

Python RestoreDomain API 呼び出し例 
response = client.restore_domain(
    DomainName='example.com',
    Consent={
        'MaxPrice': 123.0,
        'Currency': 'USD'
    }
)
# レスポンス
# {
#     'OperationId': 'string'
# }

Consent パラメータで同意する上限価格と通貨を指定します。レスポンスの OperationId を使用して、復元オペレーションの進捗を追跡できます。

🛠️ 設定方法

前提条件

  • 復元対象のドメインが登録されていた AWS アカウントを使用できること
  • 対象ドメインの TLD レジストリが復元をサポートしていること
  • TLD ごとに定められた復元可能期間内であること
1
TLD の復元サポート状況と復元可能期間を確認

Route 53 で登録できるドメイン のドキュメントで対象ドメインの TLD を検索し、「ドメインの更新と復元の期限」セクションの値を確認します。TLD によって復元の可否と復元可能期間が異なります。

2
復元料金を確認
Bash GetDomainPrices API で復元料金を確認 
aws route53domains get-domain-prices \
  --tld com \
  --region us-east-1

通常ドメインの復元料金は Route 53 のドメイン登録料金表の Restoration Price 列にも記載されています。プレミアムドメインは料金がドメイン名ごとに異なるため、コンソールでの検索または GetDomainPrices API での確認が必要です。

3
ドメインを復元
Bash RestoreDomain API で復元をリクエスト 
aws route53domains restore-domain \
  --domain-name example.com \
  --consent MaxPrice=123.0,Currency=USD \
  --region us-east-1

ドメインが登録されていた AWS アカウントから実行する必要があります。復元に成功すると、ドメインが Route 53 コンソールに再表示されます。

💡 メリット

💼 ビジネス面
✓ダウンタイムの最小化: サポートの問い合わせを待たずに即座に復元を開始でき、サービス停止やブランド毀損のリスクを低減
✓機会損失の防止: 迅速な対応により第三者にドメインを取得されるリスクを低減
✓コストの透明性: 復元コストを事前確認・同意した上でリクエストし、想定外の課金を回避
⚙️ 技術面
✓プログラマブルな復元: 運用スクリプトや自動化ワークフローに組み込み可能
✓オペレーション追跡: OperationId で復元オペレーションの状況を追跡
✓安全な失敗動作: 復元できない場合は課金なしで失敗するため、安心して試行できる

⚠️ デメリット・制約事項

制限事項

✗すべての TLD レジストリが復元をサポートしているわけではない
✗復元可能期間は TLD レジストリごとに異なり、期間を過ぎると復元できない
✗汎用 TLD (gTLD) で登録から 5 日以内に削除されたドメインには、標準の 30 日間の償還期間 (redemption period) が適用されず、誰でも即座に再登録できる
✗復元料金の支払いに AWS クレジットは使用できない

考慮すべき点

⚠復元は通常、ドメインの新規登録や更新よりも高額になる
⚠復元後の有効期限は以前と異なる場合があるため、復元後に有効期限の確認を推奨
⚠そもそもドメインを失わないよう、自動更新の有効化と支払い方法の有効期限管理が重要

🎯 ユースケース

1. 更新忘れによる期限切れドメインの復元

シナリオ: 支払い方法の有効期限切れにより自動更新が失敗し、ドメインが遅延更新期間を過ぎて期限切れになった。

Bash 料金確認と復元 
# 復元料金を確認
aws route53domains get-domain-prices --tld com --region us-east-1

# ドメインを復元
aws route53domains restore-domain \
  --domain-name example.com \
  --consent MaxPrice=123.0,Currency=USD \
  --region us-east-1

✅ 効果: サポートの問い合わせを待たずに復元を開始でき、サービスの停止時間を最小化できる。

2. 誤削除したドメインの即時復旧

シナリオ: 運用作業中に誤って本番利用中のドメインを削除してしまった。

Bash 復元とオペレーション状況の確認 
# ドメインを復元
aws route53domains restore-domain \
  --domain-name example.com \
  --consent MaxPrice=123.0,Currency=USD \
  --region us-east-1

# オペレーションの状況を確認
aws route53domains get-operation-detail \
  --operation-id <OperationId> \
  --region us-east-1

✅ 効果: 復元可能期間内であれば、第三者に取得される前に迅速にドメインを取り戻せる。

3. 復元手順の運用 Runbook への組み込み

シナリオ: 多数のドメインを管理する組織で、ドメイン喪失時の復旧手順を標準化したい。

Python boto3 による標準化された復旧手順 
import boto3

client = boto3.client('route53domains', region_name='us-east-1')

response = client.restore_domain(
    DomainName='example.com',
    Consent={
        'MaxPrice': 123.0,
        'Currency': 'USD'
    }
)
print(response['OperationId'])

✅ 効果: API ベースの標準化された復旧手順により、担当者によらず迅速かつ確実にドメインを復元できる。

💰 料金

ドメインの復元には復元料金が発生します。復元料金は、通常、ドメインの新規登録や更新よりも高額です。

  • 通常ドメインの復元料金は、Route 53 のドメイン登録料金表 の Restoration Price 列を参照
  • プレミアムドメインの復元料金はドメイン名ごとに異なるため、Route 53 コンソールでの検索または GetDomainPrices API で確認
  • 復元料金の支払いに AWS クレジットは使用できない
  • 復元に失敗した場合、課金は発生しない

🌍 利用可能リージョン

Amazon Route 53 Domains はグローバルサービスです。 API エンドポイントは米国東部 (バージニア北部) リージョン (us-east-1) で提供されます。

🔗 関連サービス・機能

🌐 Amazon Route 53 (DNS)

復元したドメインのホストゾーンで DNS レコードを管理。ドメイン期限切れ中に DNS 解決が停止していた場合、復元後の動作確認が必要。

🔍 GetDomainDetail API

復元成功後、ドメインの詳細 (有効期限など) を確認するために使用。

💲 GetDomainPrices API

TLD ごとの復元料金を事前に確認するために使用。

📊 GetOperationDetail API

RestoreDomain が返す OperationId を使用して復元オペレーションの進捗を追跡。

📌 まとめ

Amazon Route 53 Domains のセルフサービス復元により、更新忘れや誤削除で失われたドメインを、AWS サポートを介さず コンソール・CLI・SDK から迅速に取り戻せるようになりました。 復元可能期間は TLD ごとに限られるため、ドメイン喪失に気づいたら速やかに TLD の復元サポート状況を確認し、RestoreDomain API で復元を実行することを推奨します。 あわせて、自動更新の有効化と支払い方法の管理により、そもそもドメインを失わない運用を徹底することが重要です。
