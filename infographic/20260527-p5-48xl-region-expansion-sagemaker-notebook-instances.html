SageMaker Notebook Instances で NVIDIA H100 GPU を東京リージョンで利用可能に

📋 概要

Amazon SageMaker Notebook Instances において、P5.48xlarge インスタンスがアジアパシフィック (東京) リージョンで利用可能になった。NVIDIA H100 Tensor Core GPU を 8 基搭載した高性能インスタンスにより、大規模言語モデル (LLM) のトレーニングや生成 AI ワークロードを国内で実行できる。

❌ Before (アップデート前)

  • P5.48xlarge を SageMaker Notebook で利用できるリージョンが限定的
  • 東京リージョンのユーザーは他リージョンへのデータ転送が必要
  • データレジデンシー要件がある場合、高性能 GPU へのアクセスが制限

✅ After (アップデート後)

  • 東京リージョンで P5.48xlarge が直接利用可能に
  • データを国内に保持しながら H100 GPU でトレーニング可能
  • レイテンシー削減とデータ転送コストの排除

⚡ 主要機能

🎮 NVIDIA H100 Tensor Core GPU
8 基の H100 GPU を搭載し、合計 640 GB の HBM3 メモリを提供。GPU 間通信は NVSwitch により 900 GB/s の帯域幅を実現。FP8、FP16、BF16、TF32 などの混合精度演算をサポート。
🌐 高帯域ネットワーキング
3200 Gbps の Elastic Fabric Adapter (EFA) ネットワーク帯域幅。GPUDirect RDMA による GPU 間の低レイテンシー通信。EBS 帯域幅 80 Gbps による高速なデータ I/O。
💾 大容量ストレージ
8 x 3.84 TB NVMe SSD インスタンスストレージ (合計約 30.72 TB)。大規模データセットのローカルキャッシュに最適。EBS ボリュームとの組み合わせによる柔軟なストレージ構成。

🛠️ 設定方法

前提条件

✓ AWS アカウントに SageMaker へのアクセス権限があること
✓ 東京リージョン (ap-northeast-1) で P5 インスタンスのサービスクォータが確保されていること
✓ 適切な IAM ロールが設定されていること

ステップ 1: サービスクォータの確認

Bash クォータ確認コマンド 
aws service-quotas get-service-quota \
  --service-code sagemaker \
  --quota-code L-3F5B4A67 \
  --region ap-northeast-1

ml.p5.48xlarge のサービスクォータが 1 以上であることを確認。必要に応じてクォータ引き上げをリクエスト。

ステップ 2: Notebook Instance の作成

Bash Notebook Instance 作成 
aws sagemaker create-notebook-instance \
  --notebook-instance-name "p5-notebook" \
  --instance-type ml.p5.48xlarge \
  --role-arn arn:aws:iam::123456789012:role/SageMakerExecutionRole \
  --volume-size-in-gb 500 \
  --region ap-northeast-1

ステップ 3: Notebook Instance の起動

Bash 起動コマンド 
aws sagemaker start-notebook-instance \
  --notebook-instance-name "p5-notebook" \
  --region ap-northeast-1
