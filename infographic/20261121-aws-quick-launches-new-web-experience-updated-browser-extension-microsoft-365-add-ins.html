AWS Quick

🌐 AWS Quick - 新しい Web エクスペリエンスと
ブラウザ拡張機能・Microsoft 365 アドインの更新

📅 リリース日: 2026 年 11 月 21 日 | 🏷️ 新しい Web エクスペリエンス / ブラウザ拡張機能 / Microsoft 365 アドイン

📝 概要

AWS Quick が、デスクトップアプリの体験をブラウザに持ち込む 新しい Web エクスペリエンス を発表しました。Web アプリでは、デスクトップと同じエージェント、スキル、コネクターをそのまま作成・共有・利用できます。1 日の始まりには デイリーブリーフィング と優先度付きフィードが表示され、重要なメールやメッセージなど注意が必要な項目をすぐに把握できます。

会話、エージェント、ファイルは Web・デスクトップ・モバイル間で同期 され、Web から起動・スケジュールしたエージェントはブラウザを閉じた後もバックグラウンドで動作を続けます。結果や入力待ちは Mission Control で一元的に確認できます。あわせて、ブラウザ拡張機能と Word、Excel、PowerPoint、Outlook 向けの Microsoft 365 アドインも更新されました。

❌ アップデート前の課題

  • デスクトップアプリ相当のフル機能の Quick 体験をブラウザだけで利用する手段が限られていた
  • デバイスやサーフェスをまたいで作業を継続するには、会話やエージェントのコンテキストを引き継ぐ仕組みが必要だった
  • 複数のエージェントの実行状況や入力待ちの項目を、会話やエージェントごとに個別に確認する必要があった

✅ アップデート後の改善

  • ブラウザだけでデスクトップと同じエージェント、スキル、コネクターを作成・共有・利用可能に
  • デイリーブリーフィングと優先度付きフィードで、注意が必要な項目から 1 日を始められる
  • 会話、エージェント、ファイルが Web・デスクトップ・モバイル間で同期され、作業の継続が可能に
  • ブラウザを閉じてもエージェントが動作を続け、Mission Control で結果と入力待ちを一元確認
  • 更新された拡張機能とアドインで、普段使うツールの中で Quick の支援を受けられる

Web、デスクトップ、モバイル、拡張機能のすべてが同じ AWS Quick ランタイムに接続し、会話・エージェント・ファイルが同期される構成です。ブラウザを閉じてもバックグラウンドエージェントは動作を続け、結果や入力待ちは Mission Control から確認できます。

⚡ 主要機能

🌐 1. 新しい Web エクスペリエンス

  • デスクトップと同じエージェント、スキル、コネクターを Web 上で作成・共有・利用できる
  • 1 日の始まりにデイリーブリーフィングを表示し、優先度付きフィードで注意が必要な項目を提示
  • ダッシュボード、トピック、スペースはこれまでどおり動作

🔄 2. クロスデバイス同期

  • 会話、エージェント、ファイルが Web、デスクトップ、モバイルの間で同期される
  • あるサーフェスで始めたタスクを、別のサーフェスでそのまま続行できる
  • 拡張機能も同じ Quick ランタイムの一部として動作し、拡張機能で始めた作業を各サーフェスで継続できる

🤖 3. バックグラウンドエージェントと Mission Control

  • Web から起動・スケジュールしたエージェントは、ブラウザを閉じた後も実行を継続する
  • Mission Control で成果物の確認、実行中ランのライブ監視・一時停止・キャンセル、入力待ちへの承認・回答が可能
  • 失敗ラン数、実行中数、週間実行数、エージェント時間などの KPI とクリエイター分析も提供

🧭 4. 更新されたブラウザ拡張機能

  • Google Chrome、Mozilla Firefox、Microsoft Edge に対応。管理者セットアップなしで利用開始
  • Web ページの要約、複数ページを横断した質問、スペースの組織ナレッジ参照、ファイル分析に対応
  • Quick で設定済みのコネクターのアクションをブラウザから直接実行できる

📄 5. 更新された Microsoft 365 アドイン

  • Outlook: 未読メールの要約と優先度付け、自然言語での検索・整理、会議調整、返信ドラフト作成
  • Excel: ワークブック分析、データのインポートとクレンジング、テーブル・チャート生成、操作の自動化
  • Word: 書式付きドキュメント生成、文体と構成を維持した編集、変更履歴とコメントによるレッドライン
  • PowerPoint: プレゼン作成、自然言語によるスライド編集、構成変更やトランジション適用の効率化
  • いずれも管理者セットアップなしで開始可能 (Slack / Microsoft Teams 拡張機能は従来どおり管理者設定が必要)

🛠️ 設定方法

📋 前提条件

✓AWS Quick を利用できること (aws.com/quick でのサインアップ、または AWS Management Console からのプロビジョニング)
✓ブラウザ拡張機能を使う場合、Google Chrome、Mozilla Firefox、Microsoft Edge のいずれかを利用していること
✓Microsoft 365 アドインを使う場合、対象の Microsoft 365 アプリケーションを利用できること。Outlook アドインの一部機能には、管理者による Microsoft Graph API 権限の承認が必要

🚀 手順

1

Web アプリにサインインする

ブラウザで AWS Quick にサインインします。ホームにはデイリーブリーフィングと優先度付きフィードが表示され、注意が必要な項目から 1 日を始められます。デスクトップで作成済みのエージェント、スキル、コネクターはそのまま Web でも利用できます。

2

ブラウザ拡張機能をインストールする

Chromium 系ブラウザ (Microsoft Edge を含む) は Chrome Web Store、Mozilla Firefox は Firefox Add-ons ストアから「Amazon Quick」拡張機能をインストールし、サインインします。管理者によるセットアップは不要です。組織全体へは各ブラウザのエンタープライズポリシーで一括配布できます。

3

Microsoft 365 アドインを追加する

Word、Excel、PowerPoint、Outlook の各アプリ内のストアで「AWS Quick」を検索してアドインを追加します。Outlook アドインの一部機能 (受信トレイの優先度付け、カレンダー管理、メール整理など) には Microsoft Graph API 権限が必要なため、利用できない場合は管理者に承認状況を確認します。

4

バックグラウンドエージェントを活用する

Web からエージェントを起動またはスケジュールすると、ブラウザを閉じても実行が継続します。Mission Control を開くと、完了した作業の確認、実行中ランの監視、入力待ちへの回答をまとめて行えます。モバイルアプリと組み合わせれば、外出先からエージェントの質問に回答し、デスクトップで最終結果を確認できます。

💎 メリット

💼 ビジネス面

✓導入ハードルの低減: アプリのインストールなしにブラウザだけでフル機能を利用でき、組織全体への展開や試用が容易に
✓1 日の業務の起点: デイリーブリーフィングと優先度付きフィードで対応漏れを防ぎ、朝の状況把握を効率化
✓業務ツールへの組み込み: メール処理・資料作成・データ分析の中で AI 支援を受けられ、アプリ切り替えが不要に

⚙️ 技術面

✓サーフェス間のコンテキスト同期: 会話・エージェント・ファイルが同期され、作業の中断と再開がデバイスをまたいで可能
✓非同期実行モデル: エージェントがブラウザのセッションに依存せず実行を継続し、長時間タスクを安心して任せられる
✓運用の一元化: Mission Control の KPI とクリエイター分析で、実行状況と利用状況を一元管理
✓エンタープライズ配布: Chrome / Firefox / Edge の各エンタープライズポリシーで組織一括配布が可能

⚠️ デメリット・制約事項

🚧 制限事項

✗利用可能リージョンは米国東部 (バージニア北部)、米国西部 (オレゴン)、欧州 (フランクフルト、アイルランド、ロンドン)、アジアパシフィック (シドニー、東京) に限られる
✗ブラウザ拡張機能がコンテキストとして扱えるのは、Web ページとアップロードファイルの合計で最大 20 件
✗Outlook アドインの一部機能 (受信トレイ優先度付け、カレンダー管理、メール整理) には、管理者による Microsoft Graph API 権限の承認が必要
✗Slack / Microsoft Teams 拡張機能は、引き続き管理者による拡張機能アクセスの設定が必要

🤔 考慮すべき点

⚠会話と関連ファイルは非アクティブ状態が 30 日間続くと自動削除される (拡張機能の会話保持期間は組織のポリシーに従う)
⚠拡張機能やアドインの応答は各ユーザーの権限を反映するため、全受信者がアクセスできない情報が含まれる可能性があり、共有前の確認が必要
⚠拡張機能の利用中に Quick がリクエストを処理する時間は秒単位で計測され、エージェント時間 (agent hours) として課金対象にカウントされる
⚠Outlook アドインは生成 AI によりコードを生成・実行するため、応答と実行結果の確認が推奨される

💡 ユースケース

🌅 ユースケース 1: 朝のトリアージから 1 日を始める

シナリオ: 複数のプロジェクトを掛け持ちするマネージャーが、毎朝大量のメールとメッセージの中から優先対応すべき項目を素早く見極めたい。

  1. 朝、ブラウザで Quick Web アプリを開く
  2. デイリーブリーフィングと優先度付きフィードで、重要なメールとメッセージを確認する
  3. Outlook アドインで「未読メールを要約して、今日中に返信が必要なものをハイライトして」と依頼し、返信ドラフトを作成する

効果: 受信トレイを総当たりで確認する時間を削減し、優先度の高い対応から 1 日を始められる。

📱 ユースケース 2: デバイスをまたいだバックグラウンドエージェントの活用

シナリオ: 外出の多い営業担当者が、時間のかかる調査タスクをエージェントに任せ、移動中も進捗を確認したい。

  1. 朝、Web アプリで競合調査のエージェントをスケジュールして起動し、ブラウザを閉じて外出する
  2. 会議の合間に、モバイルアプリでエージェントからの確認事項に回答する
  3. 帰社後、デスクトップの Mission Control で完了した調査結果と成果物を確認し、チャットで追加の質問をする

効果: エージェントの実行がブラウザセッションに縛られず、人間の確認が必要なタイミングだけモバイルで対応することで、調査のリードタイムを短縮できる。

📄 ユースケース 3: ブラウザ拡張機能と Microsoft 365 アドインによる資料作成

シナリオ: 企画担当者が、Web 上の複数の記事と社内ナレッジをもとに提案資料を作成したい。

  1. ブラウザ拡張機能で参考記事のタブを + アイコンで会話スコープに追加し、要点を横断的に整理する
  2. スペースの社内ナレッジを参照しながら、論点の抜け漏れを確認する
  3. Word アドインで整理した要点から書式付きドキュメントを生成し、PowerPoint アドインで提案スライドに仕上げる

効果: ブラウザと Office アプリの間でコピー & ペーストを繰り返すことなく、情報収集から資料作成までを一貫した AI 支援のもとで完結できる。

🎯 まとめ

今回のアップデートにより、AWS Quick はデスクトップアプリと同等の体験をブラウザで提供し、Web・デスクトップ・モバイル・拡張機能のすべてで会話とエージェントが同期する 「どこでも同じ Quick」 を実現しました。ブラウザを閉じても動き続けるバックグラウンドエージェントと Mission Control の組み合わせは、AI エージェントを日常業務の非同期ワーカーとして使う働き方を後押しします。

まずは Web アプリのデイリーブリーフィングを試し、ブラウザ拡張機能と Microsoft 365 アドインを普段のメール処理や資料作成に組み込むことを推奨します。
