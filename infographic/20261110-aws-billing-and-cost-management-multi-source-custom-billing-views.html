AWS Billing and Cost Management

💰 マルチソース対応のカスタム請求ビュー

Billing Conductor の請求グループビューと Billing Transfer のビューをソースビューとして統合可能に
📅 リリース日: 2026 年 11 月 10 日

📝 概要

カスタム請求ビュー (Custom Billing View) のソースビューとして、AWS Billing Conductor の請求グループビューとAWS Billing Transfer のビューがサポートされました。複数の AWS マネージドビューを 1 つのカスタム請求ビューに統合し、フィルターを適用した上で Cost Explorer、AWS Budgets、Billing and Cost Management コンソールから利用できます。

作成したビューは AWS RAM を通じて組織内外のアカウント (財務チームや下流の再販事業者など) と共有できます。アクセス権限モデルは従来から変更されず、すでにアクセス権を持つマネージドビューのみをソースとして利用できます。

複数 → 1
複数のマネージドビューを 1 つの統合ビューに集約
追加料金なし
ビュー作成・統合・RAM 共有は無料
全商用リージョン
すべての AWS 商用リージョンで利用可能
❌ Before: アップデート前の課題
  • Billing Conductor / Billing Transfer のビューをカスタム請求ビューのソースとして直接指定できなかった
  • 請求グループ・請求転送関係ごとにビューが分かれ、顧客単位・グループ単位で個別に参照する必要があった
  • 転送コスト合計やエンドカスタマー向け請求額の全体像の把握には手動集計が必要だった
✅ After: アップデート後の改善
  • 請求グループビュー・請求転送ビュー・転送ショーバックビューをソースビューとして指定し、1 つのカスタム請求ビューに統合可能
  • 統合ビューにフィルターを適用し、Cost Explorer、AWS Budgets、Billing コンソールで分析可能
  • 転送コスト合計やエンドカスタマー向け請求総額を 1 つの統合ビューで確認可能

複数の AWS マネージドソースビューを 1 つのカスタム請求ビューに統合し、フィルター適用後に Cost Explorer や AWS Budgets で分析し、AWS RAM で組織内外に共有するフロー

⚙️ 主要機能

📦 請求グループビューのソースビュー対応
AWS Billing Conductor の各請求グループのコストを保持するビューをソースビューとして指定可能。ビジネスユニット単位のチャージバック・ショーバックに活用でき、複数の請求グループを 1 つのカスタムビューに集約してプロフォーマ請求全体を俯瞰できます。
📤 請求転送ビューと転送ショーバックビューのソースビュー対応
請求転送ビュー (エンドカスタマーごとに自アカウントへ転送されたコストを表示) と転送ショーバックビュー (各エンドカスタマーが参照するコストを表示) を集約し、転送コストの合計とエンドカスタマーが受け取る請求総額の両方を把握できます。
📊 統合ビューの分析と共有
統合したカスタム請求ビューにフィルターを適用して対象データのサブセットを定義可能。Cost Explorer、AWS Budgets、Billing and Cost Management コンソールで利用でき、AWS RAM を通じて組織内外のアカウントと共有できます。
🔒 変更されないアクセス権限モデル
マネージドビューをソースビューとして利用できるのは、すでにそのビューへのアクセス権を持つ場合のみ。既存の権限設定を変更することなく、新しい統合機能を利用できます。

🔧 技術仕様

📋 請求ビューの種類

ビュータイプ管理者共有可否説明
プライマリ請求ビューAWS共有不可 アカウントに関連するすべてのコスト管理データを含むデフォルトビュー
請求グループビューAWS共有不可 Billing Conductor の請求グループごとのコストを保持するビュー
請求転送ビューAWS共有不可 Billing Transfer の転送関係ごとのビュー。My view と Showback/chargeback view の 2 種類
カスタム請求ビューお客様組織内外と共有可能 複数のソースビューから派生し、フィルターを適用した統合ビュー

🗂️ カスタム請求ビューのソースビュー

ソースビュー用途
プライマリ請求ビュー組織の管理アカウントが持つ全コストデータの絞り込み
他のカスタム請求ビュー既存カスタムビューのさらなる派生・絞り込み
請求グループビュービジネスユニット単位のチャージバック・ショーバック
請求転送ビューエンドカスタマーごとの転送コストの集約
転送ショーバックビューエンドカスタマーが参照する請求額の集約

🛠️ 設定方法

✅ 前提条件

✓AWS Billing and Cost Management コンソールへのアクセス権限があること
✓ソースビューとして利用するマネージドビュー (請求グループビューまたは請求転送ビュー) へのアクセス権があること
✓請求グループビューの利用には AWS Billing Conductor の有効化、Billing Transfer のビューの利用には請求転送関係の設定が必要

📝 手順

  1. Billing Views ページへ移動 Billing and Cost Management コンソールのナビゲーションから [Billing Views] を選択。利用可能なマネージドビューとカスタムビューの一覧が表示されます。
  2. カスタム請求ビューの作成 ソースビューとして請求グループビュー、請求転送ビュー、転送ショーバックビューなどを選択。複数のソースビューを 1 つのビューに統合し、必要に応じてフィルターを適用してデータのサブセットを定義します。
  3. 共有と分析 作成したカスタム請求ビューを AWS RAM で組織内外のアカウントと共有。共有先のアカウントは Cost Explorer や AWS Budgets でコストデータを分析できます。

⚖️ メリットと制約事項

💼 ビジネス面のメリット

✓再販ビジネスの可視化: 顧客ごとに分散していた転送コストを 1 つのビューに集約し、収支を効率的に把握
✓チャージバック・ショーバックの効率化: ビジネスユニット横断のコスト配賦レポートを簡素化
✓手動集計の排除: ビューの個別参照と手動集計が不要に

🔧 技術面のメリット

✓既存ツールとの統合: Cost Explorer、AWS Budgets、Billing コンソールでそのまま利用可能
✓安全な共有: 管理アカウントへのアクセスを付与せず、必要なコストデータのみ提供
✓権限モデルの維持: 意図しないデータ公開のリスクがない

🚧 制限事項

✗ソースビューとして利用できるのは、アクセス権をすでに持つマネージドビューのみ
✗請求グループビューには Billing Conductor の有効化、請求転送ビューには Billing Transfer の転送関係の設定が前提
✗AWS マネージドビュー自体は他アカウントへ直接共有不可。共有にはカスタム請求ビューの作成が必要

⚠️ 考慮すべき点

⚠組織外へ共有する場合は、含まれるコストデータの範囲をフィルターで適切に制御する必要がある
⚠プロフォーマ料金と実際の請求額の違い (Billing Conductor のカスタム料金設定など) を理解した上でデータを解釈する必要がある

💡 ユースケース

1️⃣ AWS パートナーによる再販ビジネス全体の収支管理

シナリオ: Billing Transfer で顧客ごとの請求を受領している再販パートナー。顧客数の増加に伴い、顧客単位のビューを個別に確認する運用が負担に。

手順転送コストの統合管理
1. すべての請求転送ビューをソースビューとして選択
2. 1 つのカスタム請求ビューに統合
3. Cost Explorer で転送コスト合計の推移を分析
4. AWS Budgets で全体コストにしきい値アラートを設定

効果: 全顧客の転送コストを 1 つのビューで把握でき、収支管理とコスト超過の早期検知が効率化される。

2️⃣ エンドカスタマー向け請求総額のショーバック

シナリオ: 再販事業者が、各エンドカスタマーに提示している請求額の総額を把握し、転送コストとの差分 (マージン) を分析したい。

手順マージン分析
1. 転送ショーバックビューを統合したカスタムビューを作成
2. 請求転送ビューを統合したカスタムビューを別途作成
3. 2 つのビューを Cost Explorer で比較し、マージンを分析

効果: エンドカスタマーが参照する請求総額と実際の転送コストを比較でき、価格戦略の検討に活用できる。

3️⃣ ビジネスユニット横断のチャージバック

シナリオ: Billing Conductor でビジネスユニットごとに請求グループを運用している企業が、財務チームに全ビジネスユニットのプロフォーマコストを一元的に提供したい。

手順財務チームへの一元提供
1. すべての請求グループビューをソースビューとして選択
2. 統合カスタム請求ビューを作成
3. AWS RAM で財務チームのアカウントに共有
4. 財務チームは Cost Explorer で全ユニットのコストを分析

効果: 財務チームは管理アカウントへアクセスすることなく、全ビジネスユニットのチャージバックデータを一元的に参照できる。

💵 料金と利用可能リージョン

💰 料金
追加料金なしで利用可能。カスタム請求ビューの作成、マネージドビューのソースビューとしての利用、AWS RAM による共有に追加コストは発生しません。
🌍 利用可能リージョン
すべての AWS 商用リージョンで利用可能です。

🔗 関連サービス・機能

📦 AWS Billing Conductor
請求グループごとのプロフォーマ請求を構成するサービス。今回のアップデートで請求グループビューがソースビューとして利用可能に。
📤 AWS Billing Transfer
組織をまたいだ請求の転送を実現するサービス。請求転送ビューと転送ショーバックビューがソースビューとして利用可能に。
🤝 AWS Resource Access Manager (AWS RAM)
カスタム請求ビューを組織内外のアカウントと共有するために使用。
📈 AWS Cost Explorer / AWS Budgets
統合したカスタム請求ビューのコストデータを可視化・監視するツール。

🎯 まとめ

Billing Conductor の請求グループビューと Billing Transfer のビューをカスタム請求ビューのソースビューとして統合できるようになり、再販ビジネスやプロフォーマ請求を運用する組織のコスト集計が大幅に効率化されます。追加料金なしですべての商用リージョンで利用できるため、顧客ごと・グループごとのビューを個別に管理している場合は、Billing and Cost Management コンソールの Billing Views から統合ビューの作成を検討することを推奨します。
