📥 サブスクリプションデータの CSV ダウンロード

Kiro Console - Users & Groups ページに CSV エクスポート機能が追加
📅 2026 年 3 月 27 日
Download subscription data as CSV

📝 概要

Kiro Console の Users & Groups ページに、サブスクリプションデータを CSV ファイルとしてエクスポートする機能が追加されました。

管理者は Subscriptions テーブルの「Download CSV」ボタンをクリックするだけで、ユーザー情報を CSV 形式でダウンロードできます。

🔄 Before / After

❌ Before

  • 画面上でのみ確認可能
  • 外部ツールへのエクスポート手段なし
  • 手動でのデータ転記が必要
  • 大規模組織で管理が煩雑
→

✅ After

  • ワンクリックで CSV エクスポート
  • 構造化データを即座に取得
  • Excel / スプレッドシートで加工可能
  • 管理業務の効率向上

⚡ 主要機能

📥
CSV ダウンロードボタン
Users & Groups ページの Subscriptions テーブルに「Download CSV」ボタンが追加。ワンクリックでエクスポート可能。
📋
エクスポートデータフィールド
User Name Subscription Plan Status Type Activation Date

🔧 技術仕様

フィールド 説明
User Nameサブスクリプションに紐づくユーザーの名前
Subscription Plan利用しているプラン
Status現在のステータス
Typeサブスクリプションのタイプ
Activation Date有効化日

📌 設定方法

前提条件: Kiro Console への管理者権限アクセス / 組織にサブスクリプションが存在すること

1
Kiro Console にアクセス
ログインし、左側ナビゲーションから「Users & Groups」ページに移動
2
CSV ファイルのダウンロード
Subscriptions テーブルの「Download CSV」ボタンをクリック
3
データの活用
Excel、Google Sheets 等で開き、フィルタリング・ソート・ピボットテーブル等で分析

✅ メリット

ビジネス面

ライセンス管理の効率化

CSV で一括取得し、ライセンスの棚卸しやコスト分析を迅速に実施

レポート作成の簡素化

手動データ転記が不要。社内向けの利用状況レポートを効率的に作成

監査対応の改善

エクスポートデータを保存し、監査やコンプライアンス対応に活用

技術面

データの二次利用

CSV 形式で既存の分析ツールやスクリプトでの処理が容易

操作のシンプルさ

API 不要、ブラウザ上のボタン操作のみでデータ取得完了

⚠️ デメリット・制約事項

制限事項

エクスポートフィールドは 5 項目に限定。管理者権限が必要。

考慮すべき点

大規模組織では CSV ファイルサイズが大きくなる可能性。個人情報を含むため適切なアクセス管理と保管が必要。
