🔌 AWS SAM - WebSocket API サポート

AWS SAM API Gateway
2026-05-05

📋 概要

AWS SAM が Amazon API Gateway の WebSocket API をネイティブサポート。新しい AWS::Serverless::WebSocketApi リソースタイプにより、最小限の設定でリアルタイム通信アプリケーションを構築可能に。

チャット、ライブダッシュボード、AI/LLM ストリーミング、IoT など、リアルタイムアプリケーションに不可欠な WebSocket API を、SAM テンプレートの数行で定義できる。

Before / After

❌ Before

  • CloudFormation で全リソースを手動設定
  • IAM 権限の欠落によるデバッグが困難
  • ルート、インテグレーション、ステージを個別定義

✅ After

  • SAM テンプレートで簡潔に WebSocket API を定義
  • IAM ポリシー、リソース関係を自動生成
  • Globals で複数 API 間の共通設定を共有

⚡ 主要機能

🔌 AWS::Serverless::WebSocketApi リソースタイプ

$connect、$disconnect、$default ルートおよびカスタムルートを定義可能。Lambda 関数ハンドラーを指定するだけでインテグレーションと権限を自動設定。

🔐 認証・認可サポート

IAM 認証および Lambda オーソライザーをサポート。ルートごとに異なる認証方式を設定可能。

🎯 完全な機能パリティ

API Gateway WebSocket API の全機能をカバー。カスタムドメイン、RouteSettings、Models、StageVariables、Globals による共通設定の一元管理に対応。

🛡️ IAM 権限の自動生成

Lambda 関数に必要な IAM ポリシーが自動的に設定され、権限不足のエラーが解消される。

💻 設定例

YAML SAM テンプレート - WebSocket API 定義 
AWSTemplateFormatVersion: '2010-09-09'
Transform: AWS::Serverless-2016-10-31

Resources:
  MyWebSocketApi:
    Type: AWS::Serverless::WebSocketApi
    Properties:
      StageName: prod

  ConnectFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: connect.handler
      Runtime: nodejs20.x
      Events:
        ConnectRoute:
          Type: WebSocket
          Properties:
            ApiId: !Ref MyWebSocketApi
            Route: $connect

  DisconnectFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: disconnect.handler
      Runtime: nodejs20.x
      Events:
        DisconnectRoute:
          Type: WebSocket
          Properties:
            ApiId: !Ref MyWebSocketApi
            Route: $disconnect

  DefaultFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: default.handler
      Runtime: nodejs20.x
      Events:
        DefaultRoute:
          Type: WebSocket
          Properties:
            ApiId: !Ref MyWebSocketApi
            Route: $default

  SendMessageFunction:
    Type: AWS::Serverless::Function
    Properties:
      Handler: sendmessage.handler
      Runtime: nodejs20.x
      Events:
        SendMessageRoute:
          Type: WebSocket
          Properties:
            ApiId: !Ref MyWebSocketApi
            Route: sendmessage

🎯 ユースケース

💬 リアルタイムチャットアプリケーション

マルチユーザーのチャットアプリケーションで、接続管理とメッセージのブロードキャストを実現。DynamoDB で接続 ID を管理し、SAM が IAM 権限を自動設定。

🤖 AI/LLM ストリーミングレスポンス

生成 AI アプリケーションで、Amazon Bedrock などの LLM サービスからのストリーミングレスポンスを WebSocket 経由でクライアントにリアルタイム配信。

📡 IoT リアルタイムダッシュボード

IoT デバイスからのセンサーデータをリアルタイムでダッシュボードに表示。IoT ルールからのデータを Lambda 経由で WebSocket 接続中のクライアントにプッシュ配信。

ビジネス面

→ 開発速度の向上: WebSocket API 構築の設定量が大幅に削減
→ 運用コストの削減: 手動設定ミスの減少、デバッグ時間の短縮
→ 市場投入の加速: リアルタイム機能を素早くプロトタイプおよびリリース

技術面

→ 設定の簡素化: CloudFormation で数十行 → SAM テンプレートで数行に
→ IAM 権限の自動生成: 権限不足のエラーが解消
→ 一貫性のある構成管理: Globals で複数 API の共通設定を統一管理

⚠️ 制約事項・注意点

⚠ 接続タイムアウト最大 2 時間、ペイロードサイズ最大 128 KB (API Gateway の制約)
⚠ SAM テンプレートの Transform が AWS::Serverless-2016-10-31 である必要あり
⚠ 既存 CloudFormation 構築の WebSocket API から SAM への移行は手動作業が必要
⚠ 複雑なカスタム認証フローには Lambda オーソライザーの追加設定が必要

💰 料金情報

WebSocket API の料金は Amazon API Gateway の標準料金に基づく。SAM 自体の利用に追加料金は発生しない。

使用量月額料金 (概算、東京リージョン)
メッセージ 100 万件約 $1.20
接続時間 100 万分約 $0.29
データ転送 1 GB約 $0.114

🌍 利用可能リージョン

Amazon API Gateway WebSocket API が利用可能な全リージョンで使用可能。東京リージョン (ap-northeast-1) を含む主要リージョンで利用できる。
