🩺 Amazon Connect Health🧪 パブリックプレビュー

🧾 メディカルコーディング

臨床ドキュメントから請求コードセットを AI が自動生成 — エビデンスと信頼度スコア付きでレビューを支援
📅 リリース日: 2026 年 11 月 16 日

📌 概要

Amazon Connect Health は、患者エンゲージメントからポイントオブケアのワークフローまで医療チームと連携して動作する HIPAA 対応の AI サービスです。 新機能のメディカルコーディングは、既存の臨床ドキュメント (診療記録) を分析し、ICD-10-CM 診断コード、CPT 処置・サービスコード、E/M レベル、モディファイアを含む請求コードセットを自動生成します。

すべてのコードに診療記録内の根拠 (エビデンス) へのリンクと 0 から 1 の信頼度スコアが付与され、人間によるレビュー・承認を前提とした設計です。Amazon Connect Health SDK による EHR / 請求アプリケーションへの組み込みや、アンビエントドキュメンテーション機能との組み合わせが可能です。

🔄 Before / After

❌ アップデート前の課題
  • 診療ごとにコーダーが臨床ノートを読み、ICD-10-CM / CPT コードとモディファイアを手作業で割り当て
  • 外来・遠隔診療では、医学的意思決定 (MDM) から E/M レベルを判断する熟練した手作業が毎回発生
  • コーディングのバックログで請求提出が遅延し、コーディングエラーが支払い拒否・再作業・コンプライアンスリスクに直結
✅ アップデート後の改善
  • 診断コード、処置・サービスコード、モディファイア、E/M レベルを含む完全なコードセットを AI が自動生成
  • 各コードにエビデンスと 0 から 1 の信頼度スコアが付与され、コーダーはゼロから構築ではなくレビューに集中
  • 過去のコーディング済み診療データで組織固有のリファレンスセットを構築でき、修正のフィードバックで提案精度が継続向上

EHR や請求アプリケーションから臨床ドキュメントを送信すると、メディカルコーディングがエビデンスと信頼度スコア付きのコードセットを返し、コーダーのレビュー・修正結果が組織固有のリファレンスセットに反映されて精度が向上する流れを示しています。

⚡ 主要機能

1️⃣ 請求コードセットの自動生成
  • ICD-10-CM 診断コードを、ドキュメントが裏付ける最も具体的なレベルで生成
  • 処置・サービスに対する CPT コードを生成し、文書化された医学的意思決定 (MDM) から E/M レベルを導出
  • 報告方法に影響する状況がある場合は CPT モディファイアを付与
  • 各 CPT コードを医学的必要性を裏付ける ICD-10-CM コードにリンク (コードリンケージ)
2️⃣ エビデンスと信頼度スコアによるレビュー支援
  • すべての提案コードに、根拠となる診療記録内の該当箇所への参照 (エビデンス) を付与
  • 医学的必要性、診断と治療の整合性、コードの具体性を反映した 0 から 1 の信頼度スコアを付与
  • アプリケーション側で、信頼度に応じて診療ごとのレビュー深度を制御可能
3️⃣ 組織固有のカスタマイズ
  • プレビュー期間中、過去にコーディング済みの診療データを任意でアップロードし、組織に合わせたコーディングリファレンスセットを構築可能
  • コーダーによる修正がリファレンスセットにフィードバックされ、以降の提案精度が向上
  • ターゲットコードリストや過去のコーディングサンプルを用いたモデルの適応も可能
4️⃣ 柔軟な統合方式
  • Amazon Connect Health SDK により、既存の EHR や請求アプリケーションへ組み込み可能
  • アンビエントドキュメンテーション機能と組み合わせ、診療記録の生成からコーディングまでを一貫して実行可能
  • コンタクトセンターは不要で、ポイントオブケアエージェントとして単体で利用可能

コードセット対象出力内容

CPT処置・サービス (E/M 診療を含む)処置・サービスコード。MDM から導出された E/M レベルを含む
CPT モディファイアサービスの報告方法に影響する状況ドキュメントが必要とする場合のモディファイア
コードリンケージ医学的必要性各 CPT コードと、それを裏付ける ICD-10-CM コードのリンク
エビデンス監査可能性各コードを裏付けるノート内の該当箇所への参照
信頼度レビューの優先順位付け各コードに対する 0 から 1 のスコア

🔌 API (2 つの非同期 API)

API役割
StartMedicalCodingJob臨床ドキュメントを入力としてコーディングジョブを開始
GetMedicalCodingJobジョブのステータスと結果 (構造化された JSON 出力) を取得
💡 リクエストの encounterContext (診療の種類・設定) と patientContext (患者のステータス・属性) はオプションですが、適用されるコードに直接影響するため、最適な性能を得るには指定が重要です。

🛠️ 設定方法

✅ 前提条件

  • AWS アカウントと、米国東部 (バージニア北部) または米国西部 (オレゴン) リージョンへのアクセス
  • プレビューへのアクセス (AWS アカウントチームへの連絡が必要)
  • コーディング対象の臨床ドキュメント (テキスト) を送信できるアプリケーション環境
1
プレビューアクセスのリクエスト
AWS アカウントチームに連絡し、メディカルコーディングのプレビューアクセスをリクエストします。組織のターゲットコードリストや過去のコーディングサンプルを用いたモデル適応についても、アカウントチームと調整できます。
2
コーディングジョブの開始
StartMedicalCodingJob API で臨床テキストと、任意の encounterContext、patientContext を送信し、非同期のコーディングジョブを開始します。コンテキスト情報の提供でコード選択の精度が向上します。
Bash コーディングジョブ開始のイメージ 
# 臨床ドキュメントを入力としてコーディングジョブを開始するイメージ
# 実際のパラメータはユーザーガイドの Medical coding inputs を参照
aws connecthealth start-medical-coding-job \
  --region us-east-1 \
  --cli-input-json file://coding-job-input.json
3
結果の取得とレビューワークフローへの統合
GetMedicalCodingJob API でジョブの完了を確認し、構造化された JSON 形式のコードセット (コード、リンケージ、エビデンス、信頼度) を取得します。結果をコーダーのワークベンチや EHR のレビュー画面に表示し、承認・修正のワークフローに組み込みます。
Bash 結果取得のイメージ 
# ジョブのステータスと結果を取得するイメージ
aws connecthealth get-medical-coding-job \
  --region us-east-1 \
  --job-id <ジョブ ID>

👍 メリット

💼 ビジネス面

✓収益サイクルの加速: コーディングのバックログを削減し、請求提出までのリードタイムを短縮できる
✓支払い拒否・再作業の削減: 診断コードと処置コードがリンクされた請求可能な形で生成され、医学的必要性の裏付けを確認しやすくなるため、コーディングエラー起因の否認リスクを低減できる
✓コーダーの生産性向上: コードセットをゼロから構築する作業がエビデンス付き提案のレビュー作業に変わり、熟練コーダーがより複雑な症例に集中できる

⚙️ 技術面

✓監査可能性: すべてのコードにエビデンスと信頼度スコアが付与され、監査担当者やコーダーが検証に必要な情報を得られる
✓柔軟な統合: 構造化 JSON 出力により、ポイントオブケア、コーダーワークベンチ、自動化パイプラインのいずれにも組み込める。コンタクトセンターは不要
✓継続的な精度向上: コーダーの修正が組織固有のリファレンスセットにフィードバックされ、利用するほど提案精度が向上する

⚠️ デメリット・制約事項

🚫 制限事項

✗プレビュー段階の機能であり、仕様や提供状況は変更される可能性がある。プレビュー機能は本番環境での使用は推奨されない
✗利用可能リージョンは米国東部 (バージニア北部) と米国西部 (オレゴン) の 2 リージョンのみで、日本リージョンでは利用できない
✗外来診療のプロフェッショナルコーディングに最適化されており、入院施設コーディング (ICD-10-PCS や DRG 割り当て) はサポートされない
✗プライマリケアの外来・遠隔診療に最適化。その他の専門科のドキュメントも送信できるが、提案精度が低下する可能性があるため特に注意深いレビューが必要

🤔 考慮すべき点

⚠提案されたコードは、医療提供者またはコーダーによるレビューと承認を経てから請求に使用する運用設計が前提
⚠encounterContext と patientContext はオプションだが、コード選択の精度に直接影響するため、可能な限り提供することが推奨される
⚠米国の医療請求コード体系 (ICD-10-CM、CPT、E/M) を対象としており、日本の診療報酬制度には対応していない
⚠料金に関する情報は発表に含まれていないため、利用前に AWS アカウントチームへの確認が必要

📝 まとめ

Amazon Connect Health のメディカルコーディングは、米国医療機関の収益サイクルにおける最大のボトルネックの一つであるコーディング作業を、エビデンスと信頼度スコア付きの AI 提案によって支援するパブリックプレビュー機能です。人間によるレビュー・承認を前提とした設計で、監査可能性と精度の継続的改善を両立しています。米国市場向けのヘルスケアソリューションを扱う場合は、アンビエントドキュメンテーションとの組み合わせを含め、プレビューでの評価を検討する価値があります。
