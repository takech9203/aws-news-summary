Amazon RDS for PostgreSQL が Extended Support の新しいマイナーバージョンをリリース。PostgreSQL 11、12、13 の各バージョンに対して、既知のセキュリティ脆弱性とバグの修正が含まれている。Extended Support は、メジャーバージョンの標準サポート終了後に最大 3 年間の追加サポートを提供するプログラムである。

⚡ 主要機能

🔒 セキュリティ脆弱性の修正

PostgreSQL コミュニティで報告された既知のセキュリティ脆弱性に対するパッチを含む。重大度の高い CVE に対応し、以前のマイナーバージョンからのアップグレードが推奨される。

🔄 自動マイナーバージョンアップグレード

メンテナンスウィンドウ中に自動的に新バージョンへアップグレード。DB インスタンスの「Auto Minor Version Upgrade」設定を有効にすることで、手動介入なしでセキュリティパッチを適用。

🏢 AWS Organizations Upgrade Rollout Policy

組織全体で数千のデータベースインスタンスを段階的にアップグレード。開発環境を先行してアップグレードし、問題がないことを確認後に本番環境へ展開。マルチアカウント環境での運用を大幅に簡素化。

🔵🟢 Blue/Green デプロイメント

物理レプリケーションを使用した Blue/Green デプロイメントによりダウンタイムを最小化。Green 環境で新バージョンをテスト後、スイッチオーバーで本番切り替え。ロールバックも容易に実行可能。

🛠️ 設定方法

前提条件

✓Amazon RDS for PostgreSQL の DB インスタンスが PostgreSQL 11、12、または 13 で稼働していること
✓Extended Support が有効化されていること
✓適切な IAM 権限が設定されていること

Step 1: 自動マイナーバージョンアップグレードの有効化

Bash 自動アップグレード有効化 
aws rds modify-db-instance \
  --db-instance-identifier my-postgres-instance \
  --auto-minor-version-upgrade \
  --apply-immediately

Step 2: Blue/Green デプロイメントによるアップグレード

Bash Blue/Green デプロイメント作成とスイッチオーバー 
# Blue/Green デプロイメントの作成
aws rds create-blue-green-deployment \
  --blue-green-deployment-name my-pg-upgrade \
  --source arn:aws:rds:ap-northeast-1:123456789012:db:my-postgres-instance \
  --target-engine-version 13.23

# Green 環境でテスト後にスイッチオーバー
aws rds switchover-blue-green-deployment \
  --blue-green-deployment-identifier my-pg-upgrade

Step 3: 手動アップグレードの実行

Bash 即時アップグレード 
aws rds modify-db-instance \
  --db-instance-identifier my-postgres-instance \
  --engine-version 13.23 \
  --apply-immediately

⚠️ デメリット・制約事項

制限事項

✗Extended Support は追加料金が発生する (vCPU 時間単位の課金)
✗料金は年数が経過するにつれて増加 (年 1-2 と年 3 で料金が異なる)
✗最大 3 年間のみ。最終的にはメジャーバージョンアップグレードが必須

考慮すべき点

!セキュリティとバグ修正のみを提供し、新機能は含まれない
!PostgreSQL 11 は Extended Support 期間の終了が近づいているため、早期のメジャーバージョンアップグレードを強く推奨
!Blue/Green デプロイメントには一時的に 2 倍のリソースが必要 (コストへの影響を考慮)

🎯 ユースケース

1. 大規模エンタープライズ環境での段階的アップグレード

数百のアカウントに数千の PostgreSQL 13 インスタンスが稼働する環境で、Organizations Upgrade Rollout Policy を活用。開発環境で 1 週間検証後にステージング、その後本番環境へと段階的にアップグレードを展開し、問題発生時の影響範囲を限定。

2. ミッションクリティカルなデータベースのゼロダウンタイムアップグレード

24/365 で稼働するオンラインサービスの PostgreSQL 12 インスタンスに対し、Blue/Green デプロイメントの物理レプリケーションを使用。リアルタイム同期された Green 環境でテスト後、スイッチオーバー時のダウンタイムを数秒に抑制。

3. コンプライアンス要件を満たすための即時パッチ適用

セキュリティ監査で PostgreSQL の既知の脆弱性が指摘された場合、メンテナンスウィンドウを待たずに --apply-immediately オプションでセキュリティパッチを即時適用し、監査要件を迅速に充足。

💰 料金情報

Amazon RDS Extended Support は、標準の RDS インスタンス料金に加えて追加料金が発生する。vCPU あたりの時間単位で課金。

期間 料金水準
年 1-2 (標準サポート終了後 1-2 年目) 基本 Extended Support 料金
年 3 (標準サポート終了後 3 年目) 年 1-2 より高い料金
💡 ポイント: 具体的な料金はリージョン、PostgreSQL バージョン、標準サポート終了からの経過年数によって異なる。長期的なコスト削減のためには、メジャーバージョンアップグレードを計画的に実施することが推奨される。

🌍 利用可能リージョン

Amazon RDS for PostgreSQL Extended Support は、Amazon RDS for PostgreSQL が利用可能なすべての AWS リージョンで提供される。
