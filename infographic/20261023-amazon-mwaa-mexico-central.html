Amazon Managed Workflows for Apache Airflow (Amazon MWAA) — mx-central-1 での Provisioned 環境の提供開始

📝 概要

Amazon MWAA は Apache Airflow 向けのマネージドオーケストレーションサービスで、クラウド上でエンドツーエンドのデータパイプラインを大規模にセットアップ・実行する作業を簡素化します。

今回のアップデートにより、Mexico (Central) リージョン (mx-central-1) で Provisioned 環境が利用可能になりました。同リージョンでは MWAA Serverless がすでに提供されており、両方の利用形態を選択できるようになりました。環境は AWS マネジメントコンソール、AWS CLI、AWS SDK、AWS CloudFormation から作成できます。

❌ アップデート前の課題

✗Mexico (Central) リージョンでは Provisioned 環境を作成できず、利用形態は Serverless に限られていた
✗メキシコ国内にデータソースやエンドユーザーを持つ場合でも、Provisioned 環境は他リージョンで実行する必要があった
✗レイテンシやデータレジデンシーの面で制約があった

✅ アップデート後の改善

✓Mexico (Central) リージョンで Provisioned 環境の Apache Airflow ワークフローを実行可能に
✓データソースやエンドユーザーの近くで実行でき、レイテンシを低減
✓メキシコ国内のデータレジデンシー要件への対応に役立つ
✓同一リージョン内で Serverless と Provisioned を選択可能に

🔧 設定方法

前提条件

✓AWS アカウントと Mexico (Central) リージョン (mx-central-1) へのアクセス
✓DAG を配置する Amazon S3 バケットなど、MWAA 環境作成に必要なリソース

ステップ 1: 環境の作成

Bash AWS CLI で MWAA 環境を作成 
aws mwaa create-environment \
  --region mx-central-1 \
  --name my-mwaa-environment \
  --source-bucket-arn arn:aws:s3:::my-dag-bucket \
  --dag-s3-path dags \
  --execution-role-arn arn:aws:iam::123456789012:role/my-mwaa-role \
  --network-configuration SubnetIds=subnet-xxxx,subnet-yyyy,SecurityGroupIds=sg-zzzz

AWS CLI でリージョンに mx-central-1 を指定し、MWAA 環境を作成します。コンソール、SDK、CloudFormation からも同様に作成できます。
