Amazon Bedrock

Advanced Prompt Optimization (AdvPO)

プロンプト自動最適化 & マルチモデル移行ツール

2026-05-14

📋 概要

Amazon Bedrock に Advanced Prompt Optimization (AdvPO) が新たに導入された。この機能は、Bedrock 上の任意のモデルに対してプロンプトを自動最適化し、最大 5 つのモデルで同時に元のプロンプトと最適化後のプロンプトを比較評価できるツールである。プロンプトテンプレート、変数値のサンプル入力、オプションの正解データ、評価メトリクスを入力として受け取り、フィードバックループで反復的にプロンプトを最適化する。マルチモーダル入力 (jpg、png、PDF) にも対応。

🔄 Before / After

❌ アップデート前の課題

  • プロンプト最適化に数日から数週間の手動作業が必要
  • モデル移行時のリグレッションテストが困難
  • 複数モデルでのパフォーマンス比較が手動で時間とコストがかかっていた
  • プロンプト変更の効果を定量的に評価する統一的手段がなかった

✅ アップデート後の改善

  • 自動フィードバックループによりプロンプト最適化工数を大幅削減
  • 最大 5 モデルの同時比較でモデル移行の意思決定を迅速化
  • 評価スコア、コスト見積もり、レイテンシの定量データを自動生成
  • API 経由でプログラマティックに最適化ジョブを管理可能

⚡ 主要機能

🔄 プロンプト自動最適化

フィードバックループによる反復的なプロンプト改善。評価メトリクスまたは自然言語の評価基準に基づいてプロンプトを自動調整し、元のテンプレートを維持しつつ最適化版を生成。

🤖 マルチモデル同時比較

最大 5 つのモデルで同時にプロンプトを評価。現行モデルをベースラインとし、最大 4 つの候補モデルと比較可能。同一モデルでの Before/After 評価にも対応。

🖼️ マルチモーダル入力対応

テキストに加えて jpg、png、PDF の入力に対応。画像や文書を含むプロンプトの最適化が可能。

📊 定量的評価出力

評価スコアによるパフォーマンス比較、コスト見積もりによる費用対効果の把握、レイテンシ測定による応答速度の比較を自動出力。

ステップ 1: S3 バケットに入力データを準備

Bash 入力データのアップロード 
# プロンプトテンプレートとサンプル入力を S3 にアップロード
aws s3 cp prompt-template.json s3://my-bucket/advpo-input/
aws s3 cp sample-inputs.json s3://my-bucket/advpo-input/

ステップ 2: 最適化ジョブを作成

Bash ジョブ作成コマンド 
aws bedrock create-advanced-prompt-optimization-job \
  --job-name "optimize-for-claude-4" \
  --input-config '{"s3Uri": "s3://my-bucket/advpo-input/"}' \
  --output-config '{"s3Uri": "s3://my-bucket/advpo-output/"}' \
  --model-configurations '[
    {"modelId": "us.anthropic.claude-sonnet-4-20250514-v1:0", "inferenceConfig": {"maxTokens": 4096, "temperature": 0.7}},
    {"modelId": "us.amazon.nova-premier-v1:0", "inferenceConfig": {"maxTokens": 4096, "temperature": 0.7}}
  ]'

ステップ 3: ジョブのステータスを確認

Bash ステータス確認 
aws bedrock get-advanced-prompt-optimization-job \
  --job-identifier "arn:aws:bedrock:us-east-1:123456789012:advanced-prompt-optimization-job/optimize-for-claude-4"

🎯 ユースケース

1. モデル世代間の移行

現在 Claude 3.5 Sonnet で運用しているチャットボットを Claude Sonnet 4 に移行したい。既存のプロンプトがそのまま動作するか確認し、必要に応じて最適化したい。

JSON 移行ジョブ設定 
{
  "jobName": "migrate-chatbot-to-claude-4",
  "modelConfigurations": [
    {"modelId": "anthropic.claude-3-5-sonnet-20241022-v2:0"},
    {"modelId": "us.anthropic.claude-sonnet-4-20250514-v1:0"}
  ]
}

現行モデルをベースラインとして新モデルとの比較が自動で行われ、最適化されたプロンプトにより移行後も品質を維持または向上できる。

2. コスト最適化のためのモデル選定

高品質な要約タスクに最適なモデルを選定したい。複数のモデルでコストとパフォーマンスのバランスを比較評価する。

JSON モデル選定ジョブ 
{
  "jobName": "find-best-summarization-model",
  "modelConfigurations": [
    {"modelId": "us.anthropic.claude-sonnet-4-20250514-v1:0"},
    {"modelId": "us.amazon.nova-premier-v1:0"},
    {"modelId": "us.anthropic.claude-haiku-4-5-20251001-v1:0"}
  ]
}

各モデルの評価スコア、コスト見積もり、レイテンシを一覧で比較し、要件に最適なモデルを客観的に選定できる。

3. マルチモーダルプロンプトの最適化

画像分析パイプラインで使用しているプロンプトのパフォーマンスを改善したい。商品画像の説明文生成精度を向上させる。

JSON 画像分析プロンプト最適化 
{
  "jobName": "optimize-image-analysis-prompt",
  "inputConfig": {
    "s3Uri": "s3://my-bucket/image-analysis-input/"
  },
  "modelConfigurations": [
    {"modelId": "us.anthropic.claude-sonnet-4-20250514-v1:0", "inferenceConfig": {"maxTokens": 1024}}
  ]
}

jpg/png 画像を含むプロンプトが自動的に最適化され、画像解析タスクの精度が向上する。正解データと評価メトリクスに基づく定量的な改善が確認できる。

⚖️ メリット & デメリット

✅ メリット

  • ビジネス面:
  • → モデル移行の迅速化: 数日〜数週間の手動作業を自動化
  • → コスト最適化の可視化: モデルごとの費用対効果を定量判断
  • → リスク低減: 評価スコアによるリグレッション検知
  • 技術面:
  • → フィードバックループ最適化で人手では到達しにくいレベルを実現
  • → API ファースト設計で CI/CD パイプラインへの統合が容易
  • → マルチモーダル対応 (画像、PDF)
  • → KMS 暗号化サポートで機密データも安全に処理

⚠️ デメリット・制約事項

  • 制限事項:
  • → 同時比較モデル数は最大 5 つまで
  • → S3 経由のバッチ処理形式 (リアルタイム最適化ではない)
  • → 対応マルチモーダル形式は jpg、png、PDF に限定
  • 考慮すべき点:
  • → 各モデルでの推論コストが発生
  • → 反復回数に応じて処理時間とコストが増加の可能性
  • → 評価メトリクスの設定品質が結果に大きく影響
