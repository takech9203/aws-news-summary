📋 概要

Amazon EC2 P5.48xl インスタンスが SageMaker Studio ノートブック上で新たに 7 リージョンで一般利用可能 (GA) になった。特に東京リージョン (ap-northeast-1) での利用が可能になったことで、日本のユーザーはデータの国内保持要件を満たしつつ、最新の NVIDIA H100 GPU を活用した大規模モデルのトレーニングや推論を低レイテンシで実行できるようになった。

❌ Before

  • 東京リージョンで P5.48xl が利用不可
  • リージョン間レイテンシを受け入れる必要あり
  • アジア太平洋での H100 GPU アクセスが限定的
  • データレジデンシー要件との両立が困難

✅ After

  • 東京含む 7 リージョンで P5.48xl 利用可能
  • 国内データ保持のまま H100 GPU を活用
  • 前世代比 4 倍高速な深層学習を実行可能
  • JupyterLab / CodeEditor から直接アクセス

import sagemaker
from sagemaker.huggingface import HuggingFace

# 東京リージョンで SageMaker セッションを作成

# P5.48xl でファインチューニングジョブを設定
huggingface_estimator = HuggingFace(
    entry_point='train.py',
    instance_type='ml.p5.48xlarge',
    instance_count=1,
    role=role,
    transformers_version='4.36',
    pytorch_version='2.1',
    py_version='py310',
    hyperparameters={
        'model_name': 'meta-llama/Llama-3-70b',
        'epochs': 3,
        'per_device_train_batch_size': 4,
        'gradient_accumulation_steps': 8,
    },
    sagemaker_session=session,
