📋 概要

Amazon RDS for SQL Server が、第 5 世代 AMD EPYC プロセッサを搭載した M8a (汎用) および R8a (メモリ最適化) インスタンスタイプをサポート。同等の x86 インスタンスと比較して最大 70% 高いスループットを実現し、Optimize CPU 機能により SQL Server ライセンスコストの最適化も可能。

Before / After

❌ Before
  • AMD ベースのインスタンスが旧世代に限定
  • パフォーマンス維持とコスト最適化の両立が困難
  • ネットワーク / EBS 帯域幅がボトルネック
✅ After
  • 最大 70% 高いスループットを実現
  • Optimize CPU でライセンスコスト削減
  • 最大 75 Gbps ネットワーク / 60 Gbps EBS
  • 第 6 世代 Nitro Cards で I/O オフロード

🔧 設定方法

前提条件

  • 既存の Amazon RDS for SQL Server インスタンスまたは新規作成の権限
  • M8a / R8a インスタンスが利用可能なリージョンであること
  • SQL Server のライセンスモデルの理解 (License Included / BYOL)

新規インスタンスの作成

Bash AWS CLI - 新規作成 
aws rds create-db-instance \
  --db-instance-identifier my-sqlserver-m8a \
  --db-instance-class db.m8a.4xlarge \
  --engine sqlserver-ee \
  --master-username admin \
  --master-user-password <password> \
  --allocated-storage 200

既存インスタンスのクラス変更

Bash AWS CLI - インスタンスクラス変更 
aws rds modify-db-instance \
  --db-instance-identifier my-existing-sqlserver \
  --db-instance-class db.r8a.8xlarge \
  --apply-immediately

Optimize CPU の設定

Bash AWS CLI - Optimize CPU 
aws rds modify-db-instance \
  --db-instance-identifier my-sqlserver-m8a \
  --processor-features "Name=coreCount,Value=8" \
  --apply-immediately

⚖️ メリット / デメリット

✅ メリット

  • ライセンスコスト最適化: Optimize CPU で必要な vCPU 数のみにライセンス課金
  • 価格性能比 +19%: 前世代 AMD ベースと比較
  • 最大 70% スループット向上: 同等 x86 インスタンス比
  • 一貫したパフォーマンス: 各 vCPU が物理コアに対応
  • 高帯域幅 I/O: 75 Gbps NW / 60 Gbps EBS
  • AES-256 常時メモリ暗号化: AMD SME によるセキュリティ強化

⚠️ デメリット / 制約

  • EC2 で M8a/R8a が利用可能なリージョンのみ
  • ベアメタル (metal) は RDS では利用不可
  • インスタンスクラス変更時にダウンタイム発生
  • 既存 Reserved Instances は新ファミリーに非適用
  • Optimize CPU でコア数削減時は CPU バウンドなワークロードに影響の可能性
  • AMD 固有の命令セット依存ワークロードは互換性確認が必要

🎯 ユースケース

🚀 OLTP データベースの高スループット化

大量のトランザクション処理を行う SQL Server データベースで、現行インスタンスのスループットが限界に達しているシナリオ。db.r6i.4xlarge から db.r8a.4xlarge に移行。

✅ 同等サイズで最大 70% のスループット向上により、ピーク時のトランザクション処理能力が大幅に改善

💰 SQL Server ライセンスコストの最適化

メモリ集約型ワークロードのため大きなインスタンスが必要だが、CPU はフル活用していないシナリオ。r8a.8xlarge (32 vCPU) でコア数を 16 に制限。

✅ 256 GiB のメモリを維持しつつ、ライセンス対象の vCPU 数を半減させ、コストを約 50% 削減

📊 データウェアハウスの大規模クエリ処理

レポーティングや分析用のデータウェアハウスで、大量のデータスキャンを伴うクエリのパフォーマンスが課題。r8a.24xlarge + io2 ストレージで構成。

✅ 768 GiB メモリと 40 Gbps EBS 帯域幅により、大規模テーブルスキャンのパフォーマンスが向上。45% 高いメモリ帯域幅が分析クエリの実行時間を短縮

💰 料金情報

RDS for SQL Server の M8a / R8a インスタンスはオンデマンド料金または Database Savings Plans で利用可能。料金はインスタンスサイズ、SQL Server エディション、ライセンスモデルにより異なる。
