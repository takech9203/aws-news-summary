Amazon RDS Custom for SQL Server

🛡️ 最新 CU / GDR アップデートのサポート開始

SQL Server 2019 CU32+GDR / SQL Server 2022 CU25 に対応し、CVE-2026-40370 への対処が可能に
📅 2026 年 6 月 25 日

📌 概要

Amazon RDS Custom for SQL Server が、Microsoft SQL Server の最新の 累積的更新プログラム (CU) および General Distribution Release (GDR) アップデートのサポートを開始しました。 今回のリリースで SQL Server 2019 CU32+GDR および SQL Server 2022 CU25 が利用可能になりました。

GDR は CVE-2026-40370 で説明されている脆弱性に対処します。CU は機能改善やバグ修正を累積的に含む更新であり、GDR はセキュリティなど重要な修正のみを提供します。本アップデートでは両者を組み合わせ、機能改善とセキュリティ修正の両方を適用できます。

管理者は RDS Management Console / AWS SDK / AWS CLI からインスタンスをアップグレードして適用できます。なお本アップデートは RDS Custom 向けであり、標準の Amazon RDS for SQL Server 向け GDR とは別リリースです。

⏮ アップデート前の課題
  • SQL Server 2019 CU32+GDR / 2022 CU25 相当の更新が RDS Custom で利用できなかった
  • CVE-2026-40370 の脆弱性に対処する手段が限定的だった
  • 最新 CU による機能改善・セキュリティ修正を反映したエンジンバージョンが未提供だった
⏭ アップデート後の改善
  • CU32+GDR / CU25 を含むエンジンバージョンへのアップグレードが可能に
  • CVE-2026-40370 で説明される脆弱性への対処が可能に
  • Console / SDK / CLI から容易にアップグレードを実施可能に

管理者がコンソール、SDK、または CLI からエンジンバージョンの変更を実行することで、CU および GDR が適用された RDS Custom エンジンバージョンに DB インスタンスをアップグレードします。GDR による CVE-2026-40370 の修正が両バージョンに適用されます。

⚡ 主要機能

🗄️ SQL Server 2019 CU32+GDR サポート
  • RDS バージョン: 15.00.4470.1.v1
  • Microsoft KB: KB5090407
  • 累積的更新プログラム 32 に GDR のセキュリティ修正を統合
🗄️ SQL Server 2022 CU25 サポート
  • RDS バージョン: 15.00.4255.1.v1
  • Microsoft KB: KB5081477
  • 累積的更新プログラム 25 による機能改善とバグ修正を提供
🛡️ CVE-2026-40370 への対処
  • GDR アップデートが CVE-2026-40370 で説明されている脆弱性に対処
  • GDR チャネルを通じた重要なセキュリティ修正の提供

API 変更履歴

本アップデートは、エンジンバージョンの変更により CU/GDR を適用するものであり、新規 API の追加は伴いません。既存の RDS API (ModifyDBInstance 等) を使用してアップグレードを実行します。

🚀 設定方法

前提条件

✓対象の SQL Server (2019 または 2022) を実行している RDS Custom インスタンスが存在すること
✓エンジンバージョン変更の権限 (rds:ModifyDBInstance など) を持つ IAM 権限があること
✓RDS Custom 固有のカスタマイズがアップグレードと互換性があることを事前確認していること

⬆️ エンジンバージョン
アップグレード
Bashステップ1: 現在のエンジンバージョンを確認
aws rds describe-db-instances \
  --db-instance-identifier my-rds-custom-instance \
  --query "DBInstances[].EngineVersion"
Bashステップ2: 利用可能なアップグレード先を確認
aws rds describe-db-engine-versions \
  --engine custom-sqlserver-ee \
  --engine-version 15.00.4470.1.v1 \
  --query "DBEngineVersions[].ValidUpgradeTarget[].EngineVersion"
--engine には対象エディション (例: custom-sqlserver-ee / custom-sqlserver-se / custom-sqlserver-web) を指定します。
Bashステップ3: エンジンバージョンをアップグレード
aws rds modify-db-instance \
  --db-instance-identifier my-rds-custom-instance \
  --engine-version 15.00.4470.1.v1 \
  --apply-immediately
--apply-immediately を指定すると即時適用、省略すると次回メンテナンスウィンドウで適用されます。アップグレード中は再起動が発生するため、本番では事前にスナップショット取得とメンテナンスウィンドウでの適用を検討してください。

⚖️ メリットと制約事項

✅ メリット

✓セキュリティリスクの低減: CVE-2026-40370 への対処でインシデントリスクを低減
✓コンプライアンス対応: 最新セキュリティ修正の適用で基準・要件への対応が容易に
✓運用負荷の軽減: マネージドサービスによりパッチ適用の負担を軽減
✓機能改善とセキュリティの両立: CU の改善と GDR の修正を同時に適用
✓管理者アクセス維持: OS / DB への管理者アクセスを保ちながら更新可能
✓複数の適用手段: Console / SDK / CLI から適用でき自動化が容易

⚠️ 制約事項・考慮点

!エンジンバージョン変更には再起動が伴い、一時的なダウンタイムが発生
!元のバージョンへ戻すのは容易でないため、事前のスナップショット取得を推奨
!RDS Custom 固有のカスタマイズの互換性を事前検証する必要がある
!本番適用前にテスト環境で動作・アプリ互換性テストを実施することが望ましい
!CU には機能変更が含まれるため、ワークロードへの影響を確認
!Multi-AZ 構成ではフェイルオーバーの挙動とタイミングを計画

💡 ユースケース

1. 本番データベースのセキュリティパッチ適用

シナリオ: SQL Server 2019 を RDS Custom で本番運用しており、CVE-2026-40370 への対処が必要なケース。

実装例: スナップショット取得 → メンテナンスウィンドウ設定 → エンジンバージョンを 15.00.4470.1.v1 に変更

計画的なメンテナンスウィンドウ内でセキュリティパッチを適用し、脆弱性のリスクを低減
2. 最新 CU による機能改善の取り込み

シナリオ: SQL Server 2022 を運用しており、CU25 の機能改善とバグ修正を取り込みたいケース。

Bashテスト先行検証 → 本番適用
# テスト環境で先行検証
aws rds modify-db-instance \
  --db-instance-identifier test-sql2022-instance \
  --engine-version 15.00.4255.1.v1 \
  --apply-immediately

# 検証後、本番環境にメンテナンスウィンドウで適用
aws rds modify-db-instance \
  --db-instance-identifier prod-sql2022-instance \
  --engine-version 15.00.4255.1.v1
機能改善を取り込みつつ、計画的なダウンタイムで影響を最小化
3. コンプライアンス要件への対応

シナリオ: セキュリティ監査で、DB エンジンが最新のセキュリティ修正を適用していることを示す必要があるケース。

実装例: describe-db-instances で全インスタンスのエンジンバージョンを取得し、CU/GDR 適用済みであることを確認

最新の CU/GDR 適用状況を可視化し、監査やコンプライアンス報告に活用

💰 料金・リージョン・関連サービス

💰 料金

CU/GDR アップデートの適用自体に追加料金は発生しません。Amazon RDS Custom for SQL Server の通常料金 (インスタンス、ストレージ、ライセンス等) が適用されます。

📝 まとめ

本アップデートにより、Amazon RDS Custom for SQL Server で SQL Server 2019 CU32+GDR (KB5090407) および SQL Server 2022 CU25 (KB5081477) が利用可能になり、CVE-2026-40370 への対処と最新の機能改善の取り込みが可能になりました。対象バージョンを運用しているお客様は、スナップショット取得やテスト環境での検証などの準備を行ったうえで、計画的にエンジンバージョンのアップグレードを実施することが推奨されます。
