📝 概要

AWS Interconnect - multicloud の無料 500 Mbps ティアが提供開始されました。有料プランと同じネットワークパス、ファシリティ、デバイスレジリエンシーを備えたフルマネージドインターコネクトを、AWS 側の料金なしで利用できます。

さらに各 Free Tier インターコネクトには Amazon CloudWatch Network Synthetic Monitor が追加料金なしで含まれ、クラウド間のネットワークヘルスとパフォーマンスを監視可能です。

🔄 Before / After

❌ Before

  • マルチクラウド接続の試用にもコミットメントとコストが必要
  • PoC 開始時に帯域幅プラン選択と料金見積もりが必要
  • クラウド間のネットワーク監視に別途 CloudWatch の設定・コストが発生

✅ After

  • AWS 側料金なしで 500 Mbps フルマネージド接続を利用開始可能
  • 月約 160 TB のデータ転送を無料枠内で実行可能
  • CloudWatch Network Synthetic Monitor が無料付属、追加設定不要
  • 有料プランと同じレジリエンシーで評価可能

⚡ 主要機能

🆓 無料 500 Mbps マルチクラウド接続

AWS 側の料金なしで 500 Mbps のフルマネージドインターコネクトを提供。有料プランと同じネットワークパス、ファシリティ、デバイスレジリエンシーを維持し、月あたり約 160 TB のデータ転送が可能です。

📊 CloudWatch Network Synthetic Monitor の無料付属

各 Free Tier インターコネクトに Amazon CloudWatch Network Synthetic Monitor が追加料金なしで含まれ、クラウド間のネットワークヘルスとパフォーマンスをプロアクティブに監視できます。

🔒 エンタープライズグレード機能の継承

ビルトイン冗長性 (4 接続モデルと ECMP ロードバランシング)、MACsec 暗号化による転送中データの保護、API / CLI / コンソールからの管理をサポートします。

🛠️ 設定方法

前提条件

→AWS アカウントが有効であること
→Direct Connect Gateway が作成済みであること
→接続先 CSP のアカウントおよび料金を事前に確認済みであること
→適切な IAM 権限が設定されていること

ステップ 1: Free Tier インターコネクトの作成

Bash 500 Mbps Free Tier インターコネクトの作成 
# 500 Mbps Free Tier インターコネクトを作成
aws interconnect create-connection \
  --description "Free Tier - MultiCloud Evaluation" \
  --bandwidth "500Mbps" \
  --attach-point '{"directConnectGateway": "dxgw-xxxxxxxx"}' \
  --environment-id "env-gcp-us-east1" \
  --remote-account '{"identifier": "project-id@example.com"}' \
  --tags '{"Purpose": "FreeTier", "Environment": "Evaluation"}'

ステップ 2: CSP 側での接続承認

Bash アクティベーションキーの確認 
# アクティベーションキーを確認
aws interconnect get-connection \
  --identifier "conn-xxxxxxxx"

生成されたアクティベーションキーを使用して、接続先 CSP のコンソールまたは API で接続を承認します。

ステップ 3: ネットワーク監視の確認

Bash CloudWatch Network Synthetic Monitor の状態確認 
# CloudWatch Network Synthetic Monitor の状態確認
aws cloudwatch describe-alarms \
  --alarm-name-prefix "Interconnect-FreeTier"

Free Tier に付属する CloudWatch Network Synthetic Monitor が自動的に設定されます。追加の設定なしでクラウド間のネットワーク監視が開始されます。

✅ メリット

ビジネス面

✓ ゼロコストでのマルチクラウド評価: AWS 側の料金なしで PoC の初期投資を削減
✓ 本番品質での検証: 有料プランと同じレジリエンシーで検証、本番移行時の差異を最小化
✓ 段階的な導入: 無料枠で開始し、需要増加に応じて帯域幅をアップグレード

技術面

✓ 十分な転送容量: 月あたり約 160 TB で多くのワークロードに対応
✓ 統合監視: CloudWatch Network Synthetic Monitor 無料付属でネットワークヘルスを可視化
✓ エンタープライズグレードのセキュリティ: MACsec 暗号化とプライベート接続による保護

⚠️ デメリット・制約事項

制限事項

! 顧客あたりリージョンごとに 1 本、GA 済み CSP ごとに 1 本の制限 (複数の Free Tier 接続は不可)
! ローカル (Tier 1) インターコネクトのみが対象。リージョナルやグローバル接続は無料枠の対象外
! CSP 側の料金は各 CSP が独自に設定するため、AWS 側が無料でも接続先で料金が発生する可能性あり

考慮すべき点

△ 接続先 CSP の料金ページを必ず確認してからインターコネクトを作成すること
△ パブリックプレビュー中の OCI への Free Tier 接続は、GA 後に条件変更の可能性あり
△ 500 Mbps を超える帯域幅が必要な場合は有料プランへのアップグレードが必要

💡 ユースケース

🧪 マルチクラウド PoC の低コスト実施

マルチクラウド戦略を検討中の企業が、AWS と Google Cloud 間のプライベート接続を初期投資なしで評価。月 160 TB の転送容量で実際のワークロードパターンを用いた現実的なテストが実施可能。投資判断の精度が向上します。

🔄 クラウド間データレプリケーション

AWS 上のデータベースから Google Cloud のデータウェアハウスへ定期的にデータを同期。月 50 TB 程度のレプリケーションなら Free Tier の 160 TB 内で十分対応可能。プライベート接続でセキュリティを確保しつつコストを節約できます。

🛠️ ハイブリッドアプリケーションの開発・テスト

本番環境では高帯域幅の有料プランを使用し、開発・テスト環境は Free Tier で運用。本番と同じアーキテクチャパターンで開発でき、環境差異による問題を事前に検知。開発環境のマルチクラウド接続コストをゼロに削減します。

🗺️ 利用可能リージョン

AWS Direct Connect コンソールから AWS Interconnect を利用可能なリージョンで Free Tier を利用できます。Free Tier はローカル (Tier 1) インターコネクトに限定されるため、利用可能な接続先は同一地域内の CSP ロケーションに限られます。
