📋 概要

Amazon Aurora DSQL のシングルリージョンクラスターが、アジアパシフィック (香港、ムンバイ、シンガポール)、ヨーロッパ (ストックホルム)、南米 (サンパウロ) の 5 つの新しい AWS リージョンで利用可能になりました。Aurora DSQL は、常時可用なアプリケーションを構築するための最速のサーバーレス分散 SQL データベースです。

❌ Before

  • 東南アジア、南アジア、北欧、南米のお客様は地理的に離れたリージョンに接続が必要でレイテンシーが高かった
  • 香港のお客様は東京やソウルに依存
  • 南米には Aurora DSQL 利用可能なリージョンが存在しなかった

✅ After

  • 5 つの新リージョンで低レイテンシーアクセスが可能に
  • 合計 19 リージョン、6 大陸カバーのグローバルプレゼンス確立
  • 南米初のリージョン追加でブラジル市場に対応

🛠️ 設定方法

前提条件: AWS アカウント、Aurora DSQL へのアクセス権限 (IAM ポリシー)、対象リージョンへのアクセス

Bash Step 1: シングルリージョンクラスターの作成 
# シンガポールリージョンでシングルリージョンクラスターを作成
aws dsql create-cluster \
  --region ap-southeast-1 \
  --deletion-protection-enabled
Bash Step 2: クラスターエンドポイントの確認 
# クラスターの詳細情報を取得
aws dsql get-cluster \
  --region ap-southeast-1 \
  --identifier <cluster-id>
Bash Step 3: PostgreSQL 互換クライアントで接続 
# 認証トークンの生成
aws dsql generate-db-connect-admin-auth-token \
  --region ap-southeast-1 \
  --endpoint <cluster-endpoint>

# psql で接続
psql "host=<cluster-endpoint> dbname=postgres user=admin sslmode=require"

ビジネス面

  • ✓グローバルカバレッジの大幅拡大: 19 リージョン、6 大陸カバーのグローバルプレゼンス確立
  • ✓南米市場への対応: 南米初のリージョン追加でブラジルおよび南米全域のお客様に対応
  • ✓アジア市場の強化: 香港、ムンバイ、シンガポールの金融ハブおよび成長市場をカバー
  • ✓データレジデンシー対応: 各地域のデータ保存規制要件に対応
  • ✓AWS Free Tier 対応: 毎月 100,000 DPU + 1 GB ストレージが無料

技術面

  • ✓低レイテンシー: 地理的に近いリージョンを選択して読み取り/書き込みレイテンシーを最小化
  • ✓PostgreSQL 互換: 既存の PostgreSQL ドライバー、ORM、フレームワークをそのまま使用可能
  • ✓サーバーレス: プロビジョニング、パッチ適用、スケーリングが完全自動化
  • ✓ゼロダウンタイムメンテナンス: バージョンアップグレードやパッチ適用時のダウンタイムなし
  • ✓VPC エンドポイント対応: Gateway VPC エンドポイント/AWS PrivateLink によるプライベート接続

⚠️ デメリット・制約事項

  • !新規 5 リージョンはシングルリージョンクラスターのみ対応 (マルチリージョンクラスターのリージョンセットには含まれていない可能性がある)
  • !マルチリージョンクラスターは同一リージョンセット内でのみ構成可能で、大陸をまたいだ構成は不可
  • !PostgreSQL 互換のみ (MySQL 非対応)
  • !楽観的同時実行制御 (OCC) のため、書き込み競合が多いワークロードではコンフリクトが発生する可能性
  • !DPU ベースの従量課金のため、ワークロードパターンによってはコスト予測が難しい場合がある
  • !新規リージョンでのサービスクォータや制限値は既存リージョンと異なる場合がある

💡 ユースケース

🏦 東南アジア向けフィンテックアプリケーション
シンガポールを拠点とするフィンテック企業が、東南アジア全域のユーザーに低レイテンシーの決済処理サービスを提供。強整合性と高可用性が必須要件。
→ シンガポールリージョンで 1 桁ミリ秒台の読み取りレイテンシーと ACID トランザクションによる強整合性を提供可能
📈 インド市場向け SaaS プラットフォーム
インド市場向けのマルチテナント SaaS プラットフォーム構築。ユーザー数の急成長に対応できるスケーラブルなデータベースが必要。
→ サーバーレスでユーザー数増加に自動スケール。インドのデータレジデンシー要件にも準拠
🛒 ブラジル向け E コマースプラットフォーム
ブラジルおよび南米全域で E コマースサービスを展開。現地の低レイテンシー要件とデータ保護法 (LGPD) への対応が必要。
→ 南米初の Aurora DSQL リージョンで低レイテンシーアクセスと LGPD 準拠のデータ保存が可能

💰 料金

Aurora DSQL は完全な従量課金制で、アイドル時はゼロにスケールダウンします。

項目 説明
DPUデータベースアクティビティ全体の課金単位。クエリ実行のコンピュート + I/O を含む
ストレージデータベースサイズ (GB-月)。3 AZ レプリケーション込みで 1 論理コピー分のみ課金

AWS Free Tier: 毎月 100,000 DPU + 1 GB ストレージが無料。開発・テスト環境は Free Tier でカバー可能。

DPU 内訳は CloudWatch で ComputeDPU、ReadDPU、WriteDPU、MultiRegionWriteDPU として確認可能。Database Savings Plans による割引も利用可能。
