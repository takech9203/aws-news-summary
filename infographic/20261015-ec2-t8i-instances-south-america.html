Amazon EC2

💻 T8i インスタンスが南米 (サンパウロ) リージョンで利用可能に

📅 リリース日: 2026 年 10 月 15 日 | 🌎 sa-east-1 | バースト可能汎用インスタンス

📝 概要

Amazon EC2 T8i インスタンスが南米 (サンパウロ) リージョンで利用可能になりました。T8i は AWS 専用にカスタマイズされた第 6 世代 Intel Xeon 6 プロセッサを搭載し、最新の第 6 世代 AWS Nitro カード上に構築されたバースト可能汎用インスタンスです。

T3 比で最大 30% 優れた価格性能を実現し、nano / micro / small / medium の 4 サイズで提供。T3 と同じ CPU クレジットシステムを採用しているため、既存の T3 ユーザーはインスタンスタイプの変更のみで移行でき、すぐに TCO を削減できます。

T3 から T8i への移行はインスタンスタイプの変更のみで可能であり、サンパウロリージョンにおいて価格性能・コンピューティング性能・帯域幅の向上をすぐに利用できます。

⚙️ 主要機能

🧠 カスタム第 6 世代 Intel Xeon 6 プロセッサ

AWS 専用にカスタマイズされたプロセッサを搭載。第 6 世代 AWS Nitro カード上に構築され、仮想化処理を専用ハードウェアにオフロード。T3 比で最大 70% 高いコンピューティング性能を実現。

📈 T3 比で大幅な性能向上

最大 30% 優れた価格性能、1.25 倍のネットワーク帯域幅 (最大 6.25 Gbps バースト)、2.4 倍の EBS 帯域幅 (最大 5 Gbps バースト) を提供。

🔄 T3 と互換性のある CPU クレジットシステム

Standard モードと Unlimited モードの両方をサポート。ベースライン未満の使用時にクレジットを蓄積し、バースト時に消費する仕組みは T3 と同一。既存の T3 ユーザーは運用モデルを変更せずに移行可能。

🆓 AWS 無料利用枠への対応

t8i.micro と t8i.small は AWS 無料利用枠の対象。AWS を初めて利用するユーザーやオンプレミスからの移行ユーザーに、コスト効率の高いエントリーポイントを提供。

🪙 CPU クレジットシステム

モード動作
Unlimited モード (デフォルト)クレジットを使い切った後も追加料金でバースト継続が可能。24 時間平均の使用率がベースライン以下であれば追加料金なし
Standard モード蓄積したクレジットを使い切るとベースライン性能に制限される

1 CPU クレジットは、1 vCPU が 100% 使用率で 1 分間稼働することに相当します。

🛠️ 設定方法

✅ 前提条件

✓AWS アカウントを保有していること
✓南米 (サンパウロ) リージョン (sa-east-1) を利用できること
✓EC2 インスタンスを起動する IAM 権限があること

ステップ 1: 利用可能なインスタンスタイプの確認

Bash T8i インスタンスタイプの一覧取得 
aws ec2 describe-instance-type-offerings \
  --region sa-east-1 \
  --filters "Name=instance-type,Values=t8i.*" \
  --query "InstanceTypeOfferings[].InstanceType"

ステップ 2: T8i インスタンスの起動

Bash t8i.micro を Unlimited モードで起動 
aws ec2 run-instances \
  --region sa-east-1 \
  --instance-type t8i.micro \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --count 1 \
  --credit-specification CpuCredits=unlimited

CpuCredits には standard または unlimited を指定できます。

ステップ 3: 既存の T3 インスタンスからの移行

Bash 停止 → タイプ変更 → 再起動 
# インスタンスを停止
aws ec2 stop-instances --region sa-east-1 --instance-ids i-xxxxxxxxxxxxxxxxx

# インスタンスタイプを T8i に変更
aws ec2 modify-instance-attribute \
  --region sa-east-1 \
  --instance-id i-xxxxxxxxxxxxxxxxx \
  --instance-type "{\"Value\": \"t8i.micro\"}"

# インスタンスを再起動
aws ec2 start-instances --region sa-east-1 --instance-ids i-xxxxxxxxxxxxxxxxx

CPU クレジットシステムが共通のため、運用方法の変更は不要です。

💡 メリット・制約事項

👍 ビジネス面のメリット

✓TCO の削減: T3 比で最大 30% 優れた価格性能により運用コストを削減
✓低コストのエントリーポイント: 無料利用枠対象の t8i.micro / t8i.small で低コストに開始可能
✓南米ユーザーへの低レイテンシ提供: サービス品質とコスト効率を両立

🔧 技術面のメリット

✓性能向上: 最大 70% 高い性能、1.25 倍のネットワーク帯域、2.4 倍の EBS 帯域
✓移行の容易さ: 同じ CPU クレジットシステムでタイプ変更のみで移行可能
✓Nitro System による効率化: 仮想化処理をオフロードし性能とセキュリティを向上

⚠️ 制限事項

✗サイズは 4 種類のみで全サイズ 2 vCPU 構成 (大きなサイズや持続的な高 CPU 使用には M8i-flex などを推奨)
✗購入オプションは現時点でオンデマンドとスポットのみ (Savings Plans は近日対応予定)
✗バースト可能インスタンスのため、持続的に高い CPU 使用率が必要なワークロードには不向き

🤔 考慮すべき点

⚠Unlimited モードでは、24 時間平均の CPU 使用率がベースラインを超えると vCPU 時間あたりの追加料金が発生
⚠Standard モードでは、クレジット枯渇時にベースライン性能へ制限されるため、ワークロード特性に応じたモード選択が必要
⚠Savings Plans 前提のコスト計画の場合は、対応開始を待つ必要がある

🎯 ユースケース

1️⃣ 低トラフィック Web サイトのコスト最適化

シナリオ: 南米のユーザー向けに低トラフィックのコーポレートサイトを T3 インスタンスで運用しており、コストを削減したい。

BashT3 から t8i.small へ変更
aws ec2 modify-instance-attribute \
  --region sa-east-1 \
  --instance-id i-xxxxxxxxxxxxxxxxx \
  --instance-type "{\"Value\": \"t8i.small\"}"

効果: インスタンスタイプの変更のみで最大 30% の価格性能向上を得られ、運用コストを削減できる。

2️⃣ CI/CD パイプラインのビルドエージェント

シナリオ: 断続的に実行される CI/CD パイプラインのビルドエージェントを、コスト効率よく運用したい。

Basht8i.medium を Unlimited モードで起動
aws ec2 run-instances \
  --region sa-east-1 \
  --instance-type t8i.medium \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --credit-specification CpuCredits=unlimited

効果: アイドル時間にクレジットを蓄積し、ビルド実行時にバーストすることで、小さいインスタンスサイズでも快適なビルド性能を確保できる。

3️⃣ AWS 無料利用枠での検証環境構築

シナリオ: AWS を初めて利用する開発チームが、サンパウロリージョンで小規模な検証環境を構築したい。

Bash無料利用枠対象の t8i.micro を起動
aws ec2 run-instances \
  --region sa-east-1 \
  --instance-type t8i.micro \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --count 1

効果: 無料利用枠対象の t8i.micro を使用して、最新世代インスタンスの性能を低コストで検証できる。

💰 料金

T8i インスタンスは、オンデマンドインスタンスおよびスポットインスタンスで購入できます。Savings Plans への対応は近日提供予定です。

✓t8i.micro と t8i.small は AWS 無料利用枠の対象
⚠Unlimited モードで 24 時間平均の CPU 使用率がベースラインを超えた場合、vCPU 時間あたりの少額の追加料金が発生

最新の料金は Amazon EC2 料金ページ を参照してください。

前世代のバースト可能インスタンス。T8i と同じ CPU クレジットシステムを採用しており、容易に移行できる。

同じ第 6 世代 Intel Xeon 6 プロセッサを採用した汎用インスタンス。より大きなサイズや持続的な CPU 使用が必要な場合の移行先。

🛡️ AWS Nitro System

仮想化機能を専用ハードウェアにオフロードし、性能とセキュリティを向上させる基盤技術。

t8i.micro と t8i.small が対象となり、低コストで AWS を開始できる。

📌 まとめ

Amazon EC2 T8i インスタンスが南米 (サンパウロ) リージョンに拡大し、T3 比で最大 30% 優れた価格性能を同リージョンで利用できるようになりました。CPU クレジットシステムが T3 と共通のため、既存の T3 ユーザーはインスタンスタイプの変更のみで移行でき、すぐに TCO を削減できます。サンパウロリージョンで T3 を運用中のユーザーは、T8i への移行によるコスト効果の検証を推奨します。
