Kiro Web

📝 リポジトリ不要のセッション開始とモード切替の柔軟化

2026 年 6 月 2 日
Kiro Changelog

🔍 概要

Kiro Web において、GitHub リポジトリを接続せずにセッションを開始できるようになり、 また Vibe セッション中の任意のタイミングで Autonomous モードへ切り替えが可能になった。 利用開始の摩擦が大幅に低減され、セッション中のワークフローの柔軟性が向上している。

Before
  • セッション開始に GitHub リポジトリ接続が必須
  • モード選択はセッション開始時のみ
  • タイムスタンプは絶対時刻のみ
→
After
  • リポジトリなしでセッション開始可能
  • 任意のタイミングで Autonomous モードに切替
  • 相対タイムスタンプ + ホバーで絶対時刻

✨ 主要機能

NEW GitHub リポジトリなしでセッション開始
→ リポジトリ接続が不要に。タスクを記述するだけで作業開始
→ リポジトリは後から必要に応じて接続可能
NEW Vibe セッション中の Autonomous モード切替
→ 最初のプロンプト送信後、任意のタイミングで切替可能
→ セッション再起動が不要に
IMPROVED 相対タイムスタンプ表示
→ 「5 分前」「1 時間前」の表示。ホバーで絶対時刻確認
IMPROVED ネットワークモード可視性向上
→ 接続状態をより明確に表示
FIX サンドボックスと信頼性の修正
→ サンドボックス環境の安定性向上と全般的な信頼性修正

📋 技術仕様: モード比較

項目 Vibe Autonomous
操作スタイル 対話的・逐次指示 自律的・タスク委任
ユーザー介入 各ステップで確認 エージェントが自律実行
適用場面 探索的な開発、学習 明確なタスクの一括実行
切替タイミング NEW セッション中いつでも

📋 セッション開始要件の変更

項目 変更前 変更後
GitHub リポジトリ接続 必須 任意
モード選択タイミング 開始時のみ いつでも
セッション再起動 モード変更時必要 不要

🛠️ 設定方法

前提条件: Kiro Web へのアクセス権 (Pro、Pro+、または Power プラン) + Web ブラウザ

1 Kiro Web にアクセスし、リポジトリ接続なしで新規セッション開始
2 必要に応じてセッション内から GitHub リポジトリを接続
3 Vibe セッション中、任意のタイミングで Autonomous モードを選択

💡 メリット

ビジネス面
🚀 オンボーディング高速化: リポジトリ設定なしで即座に試用。評価・導入検討が迅速化
🔄 ワークフロー中断削減: モード切替のためのセッションやり直しが不要
📊 柔軟なタスク管理: タスクの性質に応じてリアルタイムにモード変更
技術面
⚡ 摩擦のない開始体験: リポジトリ準備前にプロトタイピングやアイデア検証を開始可能
🧠 コンテキスト保持: モード切替時にセッションコンテキストが維持される
⏱️ 時間追跡の改善: 相対タイムスタンプで長時間タスクのデバッグ・進捗確認が容易

⚠️ デメリット・制約事項

制限事項
  • Kiro Web のみが対象 (IDE 版や CLI 版は対象外)
  • リポジトリ未接続時はファイルシステムアクセスが制限される可能性
  • Autonomous モードへの切替は Vibe セッションからのみ可能
考慮すべき点
  • 後からリポジトリ接続時にコンテキスト再構築が必要になる場合あり
  • Autonomous から Vibe への再切替可否は要確認

💼 ユースケース

1. クイックプロトタイピング
リポジトリ作成前にアイデアを素早く検証。セットアップ時間をスキップし、有望なプロトタイプ完成後にリポジトリ接続。
2. 段階的なタスク委任
Vibe モードで対話的にアーキテクチャを議論 → 方針が固まったら Autonomous モードに切り替えて実装を一括委任。
3. チーム内での Kiro 紹介
リポジトリ設定なしでデモセッションを即開始。セットアップの手間なくツールの価値を素早く示す。
