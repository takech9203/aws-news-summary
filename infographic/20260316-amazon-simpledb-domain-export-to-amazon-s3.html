📋 概要

Amazon SimpleDB が、ドメインデータを Amazon S3 バケットに直接エクスポートする機能をサポート開始しました。エクスポートされたデータは標準 JSON 形式で出力され、バックグラウンドで実行されるためデータベースのパフォーマンスに影響を与えません。

新たに 3 つの API (StartDomainExport、GetExport、ListExports) が追加され、SimpleDBv2 サービスとして利用可能です。エクスポートツールの使用自体は無料です。

❌ Before

  • カスタムスクリプトで手動データ抽出が必要
  • 大量データ移行時に DB パフォーマンスへ影響
  • クロスリージョン/アカウント移行に複雑な設定
  • 標準的なエクスポート手段が未提供

✅ After

  • ネイティブ API で S3 に直接エクスポート可能
  • バックグラウンド実行で DB パフォーマンス影響なし
  • クロスリージョン/アカウントを標準サポート
  • AES256 / KMS 暗号化でセキュアなエクスポート
  • 標準 JSON 形式で他システムへの移行が容易

🚀 主要機能

📤 S3 直接エクスポート
ドメインデータを標準 JSON 形式で S3 バケットに直接エクスポート。バックグラウンド実行で DB パフォーマンスに影響なし。ステータスは PENDING / IN_PROGRESS / SUCCEEDED / FAILED で追跡可能。
🌍 クロスリージョン/アカウント
異なるリージョンの S3 バケットへのエクスポートをサポート。s3BucketOwner パラメータで別 AWS アカウントの S3 バケットへの出力も可能。
🔐 複数の暗号化オプション
AES256 (S3 マネージド暗号化) と AWS KMS キーによる暗号化をサポート。s3SseAlgorithm パラメータで暗号化方式を選択。
🔌 3 つの新しい API
StartDomainExport: エクスポート開始。GetExport: ステータス取得。ListExports: エクスポート一覧をページネーション付きで取得。

💻 設定方法

Step 1: エクスポートを開始

Bash StartDomainExport 
aws sdb start-domain-export \
    --domain-name my-domain \
    --s3-bucket my-export-bucket \
    --s3-key-prefix exports/my-domain/ \
    --s3-sse-algorithm AES256 \
    --client-token unique-token-001

Step 2: 進捗を確認

Bash GetExport 
aws sdb get-export \
    --export-arn arn:aws:sdb:us-east-1:123456789012:export/my-domain/export-id

Step 3: エクスポート一覧を確認

Bash ListExports 
aws sdb list-exports \
    --domain-name my-domain \
    --max-results 10

Step 4: KMS 暗号化 + クロスアカウントエクスポート

Bash KMS + Cross-Account 
aws sdb start-domain-export \
    --domain-name my-domain \
    --s3-bucket partner-account-bucket \
    --s3-key-prefix shared-data/my-domain/ \
    --s3-sse-algorithm KMS \
    --s3-sse-kms-key-id arn:aws:kms:us-east-1:987654321098:key/01234567-89ab-cdef-0123-456789abcdef \
    --s3-bucket-owner 987654321098 \
    --client-token unique-token-002

💡 メリット

💼 ビジネス面

  • データ移行の簡素化: カスタムスクリプト不要、ネイティブ API でデータ移行が可能
  • コンプライアンス対応: データアーカイブ/長期保存要件を標準機能で実現
  • コスト削減: ツール利用無料、データ転送料金のみ発生

🔧 技術面

  • パフォーマンス影響なし: バックグラウンド実行で DB に影響を与えない
  • セキュリティ: AES256 / KMS 暗号化オプション
  • 柔軟性: クロスリージョン/アカウントに対応
  • 冪等性: clientToken で重複実行を防止

⚠️ 制限事項・注意点

  • ドメインあたり 24 時間以内に 5 エクスポートまでのレート制限
  • アカウントあたり 24 時間以内に 25 エクスポートまでのレート制限
  • 出力形式は JSON のみ (CSV / Parquet 非対応)
  • バックグラウンド実行のためリアルタイム同期には不向き
  • クロスアカウント時は宛先 S3 バケットに適切なバケットポリシーが必要
  • KMS 暗号化利用時はエクスポート元から KMS キーへのアクセス権限が必要
  • クロスリージョン転送時のデータ転送料金に注意
  • exportDataCutoffTime によるデータカットオフタイムに注意

🎯 ユースケース

🗃️ データの長期アーカイブ
SimpleDB の過去のトランザクションデータを S3 にエクスポートし、S3 ライフサイクルポリシーで Glacier に移行。コンプライアンス要件に基づく長期保存をコスト効率よく実現。
🔄 他 DB サービスへの移行
SimpleDB データを S3 にエクスポート後、AWS Glue や Lambda を使用して DynamoDB / RDS にインポート。JSON 形式なので変換処理が容易。
🤝 クロスアカウントデータ共有
開発アカウントの SimpleDB データを本番アカウントの S3 バケットに直接エクスポート。中間ステップなしでデータ共有のワークフローを大幅に簡素化。

📝 まとめ

Amazon SimpleDB のドメインデータ S3 エクスポート機能は、データの移行、アーカイブ、共有を大幅に簡素化する重要なアップデートです。バックグラウンドで実行されるため、データベースのパフォーマンスに影響を与えることなく、クロスリージョン/アカウントサポートや複数の暗号化オプションにより、様々なユースケースに対応できます。SimpleDB のデータ移行やアーカイブを検討している場合は、この新機能の活用を推奨します。
