📅 リリース日: 2026 年 10 月 22 日
🏷️ セキュリティ & クリティカルアップデート

無料・マルチプラットフォーム対応・本番環境対応の OpenJDK ディストリビューションである Amazon Corretto の LTS バージョンに対する四半期セキュリティおよびクリティカルアップデートが公開されました。

📋 概要

今回のリリースは、2026 年 9 月に GA した Corretto 27 を含む 6 つのバージョンを対象とした定期アップデートです。 各バージョンの最新ビルドにはセキュリティ修正とクリティカルなバグ修正が含まれ、本番環境での安全かつ安定した Java アプリケーションの実行をサポートします。

❌ アップデート前の課題

  • 以前のビルドにはセキュリティ脆弱性が存在していた可能性がある
  • クリティカルなバグが未修正のまま残っている可能性があった
  • 定期アップデートを適用しない場合、既知の問題への露出が継続する

✅ アップデート後の改善

  • セキュリティおよびクリティカルな問題が修正され、より安全で安定した Java 実行環境を提供
  • Corretto 27 を含む 6 バージョンすべてで最新のセキュリティ修正を利用可能
  • ダウンロードに加えて、Linux では Apt / Yum / Apk リポジトリ経由での更新にも対応

🛠️ 設定方法

📌 前提条件

✓Java アプリケーションまたは開発環境
✓適切なプラットフォーム (Linux、Windows、macOS)
✓管理者権限 (インストールに必要)
1

Corretto のダウンロード

Corretto ホームページから適切なバージョンをダウンロードします。各プラットフォーム向けのインストーラーやアーカイブを入手できます。

2

Linux でのリポジトリ設定 (オプション)

Apt / Yum / Apk リポジトリを設定すると、パッケージマネージャー経由でインストールと更新を受け取れます。

Bash Apt の例 (Debian/Ubuntu) 
# 署名キーの登録と Apt リポジトリの追加
wget -O- https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/corretto-keyring.gpg] https://apt.corretto.aws stable main" | sudo tee /etc/apt/sources.list.d/corretto.list
sudo apt-get update
sudo apt-get install -y java-21-amazon-corretto-jdk
3

既存環境のアップデート

リポジトリ設定済みの環境では、更新コマンドで最新ビルドを適用します。

Bash Yum の例 (Amazon Linux / RHEL 系) 
sudo yum update java-21-amazon-corretto
4

バージョンの確認

インストールまたは更新後、今回のアップデート (例: 21.0.13.0.10) が反映されていることを確認します。

Bash バージョン確認 
java -version

🎯 ユースケース

1️⃣ 本番環境での Java アプリケーション運用

シナリオ: EC2 インスタンスで LTS バージョンの Java アプリケーションを運用

実装例: EC2 に Corretto 21 をインストールしてアプリケーションを実行し、四半期アップデート (例: 21.0.13.0.10) を定期的に適用

✅ 効果: 無料で本番環境対応の Java ランタイムを使用し、セキュリティアップデートを継続的に受け取る

2️⃣ コンテナ化された Java アプリケーション

シナリオ: Amazon ECS / EKS 上で Java マイクロサービスを Docker コンテナとして実行

Dockerfile Corretto 21 ベースイメージの例 
FROM amazoncorretto:21
COPY target/myapp.jar /app.jar
ENTRYPOINT ["java", "-jar", "/app.jar"]
✅ 効果: 最新のセキュリティ修正を含む Corretto イメージでコンテナを再ビルドし、脆弱性への露出を低減できる

3️⃣ 複数バージョンが混在する環境の一括更新

シナリオ: Corretto 8 のレガシーアプリケーションと Corretto 27 の新規アプリケーションが混在する環境を運用

実装例: レガシー環境には 8u512、新規環境には 27.0.1.0.10 を適用し、Linux パッケージリポジトリを活用して更新を自動化

✅ 効果: 新旧すべての Java バージョンで同一タイミングのセキュリティ修正を適用し、環境全体のセキュリティレベルを統一できる
