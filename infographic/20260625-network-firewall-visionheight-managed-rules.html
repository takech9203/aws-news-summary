🔥 AWS Network Firewall

VisionHeight マネージド脅威インテリジェンスルール

Zero-Day Threat Protection / Noisy Scanners and Tor Protection
📅 リリース日
2026 年 6 月 25 日

📌 概要

AWS Network Firewall が、VisionHeight 提供の 2 つの新しいマネージドルールグループをサポートしました。AWS Marketplace 経由で利用でき、VisionHeight の Pulse テレメトリを基盤とした独自の脅威インテリジェンスを、運用負荷なしでお客様に提供します。

これにより Network Firewall のマネージドルール提供事業者が拡大し、お客様はゼロデイ脅威への先回り防御と、ログノイズの削減という 2 つの価値を得られます。

❌ アップデート前の課題

  • ⚠️公開ブロックリスト掲載後の対処となり、攻撃インフラへの対応が後手に
  • ⚠️Tor 出口ノードや大量スキャンのノイズがログを増大、SOC アラートと SIEM コストが増加
  • ⚠️独自の脅威インテリジェンスを取り込むには自前のフィード収集・管理が必要

✅ アップデート後の改善

  • ✔️Pulse テレメトリで公開ブロックリスト掲載前の悪意ある IP をプロアクティブにブロック
  • ✔️Tor 出口ノードや大量スキャンを最初のパケット時点で抑制し、ノイズと運用コストを削減
  • ✔️AWS Marketplace で購読するだけで独自の脅威インテリジェンスを取り込める

VisionHeight が Pulse テレメトリから生成した脅威インテリジェンスを AWS Marketplace 経由のマネージドルールとして提供し、お客様の VPC の Network Firewall がトラフィックを検査します。

⚡ 主要機能

⚡ Zero-Day Threat Protection

  • 公開ブロックリスト掲載前の悪意ある IP インフラストラクチャをプロアクティブにブロック
  • VisionHeight の Pulse テレメトリに基づく独自の脅威インテリジェンスを活用
  • 新たに出現する脅威に対し数週間先回りした防御を実現

🚫 Noisy Scanners and Tor Protection

  • アクティブな Tor 出口ノードとの通信をブロックし、侵入経路・出口経路としての利用を排除
  • 既知の大量スキャン送信元からのトラフィックをフィルタリング
  • 日次の更新サイクルで、イベント生成前の最初のパケット時点でノイズを抑制
  • SOC のアラート量を削減し、SIEM の取り込みコストを抑制

🛒 AWS Marketplace を通じた提供

  • 2 つのルールグループは AWS Marketplace を通じて購読可能
  • VisionHeight が既存事業者に加わるマネージドルール提供事業者として参入
VisionHeight (新規) Check Point Fortinet Infoblox Lumen Rapid7 ThreatSTOP Trend Micro

⚙️ 設定方法

前提条件

✓AWS Network Firewall を利用可能な VPC とサブネット構成が存在すること
✓AWS Marketplace でのサブスクリプション購入権限を持つこと
✓Network Firewall のファイアウォールポリシーを管理する IAM 権限を持つこと

手順

1

AWS Marketplace でルールグループを購読

VisionHeight が提供する「Zero-Day Threat Protection」または「Noisy Scanners and Tor Protection」を購読し、自身の AWS アカウントから利用可能にします。

2

ファイアウォールポリシーへの追加

Network Firewall コンソールから、対象のファイアウォールポリシーにマネージドルールグループを関連付け、トラフィック検査に適用します。

3

動作確認とログの確認

Network Firewall のログを確認し、想定どおりにブロック・フィルタリングされているか、ログノイズの削減効果を検証します。

💡 メリット

📈 ビジネス面

✓運用コストの削減: ノイズを最初のパケット時点で抑制し、SOC アラートと SIEM コストを削減
✓脅威への先回り対応: ブロックリスト掲載前の脅威をブロックしインシデントリスクを低減
✓導入の容易さ: Marketplace 購読のみで独自の脅威インテリジェンスを取り込める

🔧 技術面

✓プロアクティブな防御: 悪意ある IP インフラを事前にブロック
✓ログノイズの削減: Tor 出口ノード・大量スキャンをフィルタしログの可読性を向上
✓最新の脅威情報: 日次更新サイクルで最新の脅威インテリジェンスを反映

⚠️ デメリット・制約事項

制限事項

●マネージドルールグループは AWS Marketplace 経由の購読が前提
●利用可能リージョンは AWS リージョン別サービスページで確認する必要がある
●公式発表時点で、料金の詳細は明示されていない

考慮すべき点

●適用前に、正規のトラフィックが誤ってブロックされないか検証することが望ましい
●複数の提供事業者を併用する場合、ルールの重複や評価順序を考慮する必要がある

🎯 ユースケース

1. ゼロデイ脅威への先回り防御

シナリオ: 公開されたばかりの攻撃キャンペーンに対し、ブロックリスト掲載を待たずにワークロードを保護したい。

✅ 効果: Zero-Day Threat Protection により悪意ある IP インフラを事前ブロックし、攻撃が到達する前に防御。

2. SOC のアラート疲れの軽減

シナリオ: Tor 出口ノードや大量スキャンによるノイズトラフィックが大量のアラートを発生させ、SOC の運用負荷が高い。

✅ 効果: Noisy Scanners and Tor Protection でノイズを最初のパケット時点で抑制し、アラート量と SIEM コストを削減。

3. コンプライアンス要件への対応

シナリオ: Tor 経由の通信を侵入経路・出口経路として遮断する必要がある規制環境で運用している。

✅ 効果: アクティブな Tor 出口ノードとの通信をブロックし、Tor を経路とした通信を排除してコンプライアンス対応を支援。
