既存 MWAA 環境のインポート

分析・機械学習・ワークフロー管理を同一インターフェイスに統合
Amazon SageMaker Unified Studio
📅 リリース日: 2026 年 7 月 7 日

📌 概要

Amazon SageMaker Unified Studio が、既存の Amazon Managed Workflows for Apache Airflow (MWAA) 環境をプロジェクトに接続できるようになりました。すでに MWAA 環境を運用しているデータエンジニアやプラットフォームチームは、分析や機械学習に利用しているのと同じインターフェイスから Airflow ワークフローを管理できます。

構成の再作成や DAG の移行は不要。接続後は、SageMaker Unified Studio から直接ワークフローを同期 (sync)、トリガー (trigger)、モニタリング (monitor) できます。さらに Apache Airflow 3 以降の環境では、ドラッグアンドドロップエディターによるビジュアルオーサリングも利用できます。

❌ アップデート前の課題
  • Airflow ワークフロー管理と、分析・機械学習作業が別々のインターフェイスに分かれていた
  • 既存 MWAA 環境の活用に、構成の再作成や DAG 移行が必要になる懸念があった
  • 実行状況の確認に複数ツールを行き来する必要があった
➜
✅ アップデート後の改善
  • 既存 MWAA 環境を構成の再作成・DAG 移行なしで接続できる
  • 分析・機械学習・ワークフロー管理を同一インターフェイスで操作できる
  • Airflow 3 以降ではビジュアルオーサリングで新規ワークフローを作成できる

🔧 主要機能

1️⃣ 既存 MWAA 環境の接続
  • すでに運用中の MWAA 環境をプロジェクトに接続できる
  • 構成の再作成や DAG の移行が不要
  • Workflows ツールの接続セレクターから「Add connection」を選択して接続する
2️⃣ 統合されたワークフロー管理
  • 分析や機械学習と同じインターフェイスから Airflow ワークフローを管理できる
  • プロジェクトメンバーがワークフローを同期・トリガー・モニタリングできる
  • ツール間を移動することなく実行状況を確認できる
3️⃣ ビジュアルオーサリング Apache Airflow 3 以降
  • Apache Airflow 3 以降を実行している環境で利用できる
  • ドラッグアンドドロップエディターで新しいワークフローを作成できる
  • コードを直接記述せずに視覚的にワークフローを設計できる

✓一元的な監視: 同期・トリガー・モニタリングを統合的に実行

⚠️ デメリット・制約事項

制限事項

▲ビジュアルオーサリング機能は Apache Airflow 3 以降を実行している環境でのみ利用できる
▲接続には、ドメインとプロジェクトを参照する適切な Airflow 構成オプションの指定が必要
▲MWAA 環境へのアクセスには適切な IAM 権限が求められる

考慮すべき点

▲Airflow 2 以前の環境では既存ワークフローの管理は可能だが、ビジュアルオーサリングは利用できない。ビジュアル機能が必要なら Airflow 3 以降へのアップグレードを検討
▲接続後のワークフロー操作はプロジェクトメンバーに開放されるため、権限設計を確認しておくことが望ましい
