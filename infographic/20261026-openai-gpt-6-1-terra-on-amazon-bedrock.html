🤖 OpenAI GPT-6.1 Terra の一般提供開始

📅 リリース日: 2026 年 10 月 26 日 | 能力・速度・コスト効率のバランスに優れた GPT-6 ファミリーの最新 Terra モデルが GA

📌 概要

OpenAI の GPT-6.1 Terra モデルが Amazon Bedrock で一般提供 (GA) されました。GPT-6.1 Terra は GPT-6 ファミリーに属する Terra ラインの最新モデルで、日常的なワークロードに向けて能力、速度、コスト効率のバランスを重視して設計されています。詳細な視覚的推論、正確な computer use、事実性の向上、より自然な文章作成において、前世代の GPT-5.6 Terra から強化されています。

性能面では、OpenAI の Agents' Last Exam 評価において GPT-5.6 Terra を 15 ポイント上回るスコアを記録し、上位モデルである GPT-6 Astra と同等の性能を達成しながら、タスク完了速度は GPT-6 Astra および GPT-6.1 Sol と比較して 3 倍以上高速です。入出力トークン価格は GPT-6.1 Sol および GPT-5.6 Terra より 50% 以上低価格に設定されています。

⚡ 主要機能

👁️ GPT-5.6 Terra からの能力向上
詳細な視覚的推論により技術図面や画像の解釈精度が向上。正確な computer use により画面操作を伴うエージェントタスクの精度が向上。事実性の向上とより自然な文章作成を実現しています。
🚀 高い性能と高速なタスク完了
OpenAI の Agents' Last Exam 評価で GPT-5.6 Terra を 15 ポイント上回るスコアを記録し、GPT-6 Astra と同等の性能を達成。タスク完了速度は GPT-6 Astra および GPT-6.1 Sol の 3 倍以上です。
💰 低価格な料金設定
入出力トークン価格は GPT-6.1 Sol および GPT-5.6 Terra より 50% 以上低価格。能力、速度、コスト効率のバランスを重視した日常ワークロード向けの位置づけです。
📚 大規模コンテキストとマルチモーダル入力
最大 100 万入力トークンのコンテキストウィンドウを備え、テキストと画像の両方の入力に対応します。
🔀 柔軟な利用方法
Amazon Bedrock コンソールまたは API から直接利用できるほか、ChatGPT Work や Codex から Bedrock 上のモデルを利用する構成も可能。AWS のコントロールでワークロードの保護、アクセスのガバナンス、モデル呼び出しの監査を行えます。

🛠️ 設定方法

前提条件

✓AWS アカウントを保有していること
✓Amazon Bedrock で OpenAI モデルへのアクセスが有効化されていること
✓Bedrock API を呼び出す IAM 権限が設定されていること
1
モデルアクセスの有効化

Amazon Bedrock コンソールの [モデルアクセス] から、OpenAI GPT-6.1 Terra へのアクセスをリクエストして有効化します。

2
モデル情報の確認
BashOpenAI の基盤モデル一覧を取得
aws bedrock list-foundation-models \
  --by-provider openai \
  --region <リージョン>

利用するリージョンで OpenAI の基盤モデル一覧を取得し、GPT-6.1 Terra のモデル ID と対応機能を確認します。

3
モデルの呼び出し

Bedrock コンソールのプレイグラウンド、または API からモデルを呼び出します。モデル ID、対応 API、推論プロファイルの詳細は OpenAI モデルカード を参照してください。ChatGPT Work や Codex から Bedrock 上のモデルを利用する場合は、各クライアント側で Bedrock をバックエンドとして構成します。

⚠既存の GPT-5.6 Terra 利用ワークロードを移行する場合は、プロンプトや出力の互換性を事前に検証する必要がある

🎯 ユースケース

🤖 1. 業務システムを横断するエージェントの構築
シナリオ: 社内の複数の業務システムを操作し、情報収集から処理実行までを自動化するエージェントを構築する。
1. Bedrock API で GPT-6.1 Terra を呼び出すエージェントを実装
2. computer use 機能で画面操作を伴うタスクを自動化
3. CloudTrail / Bedrock のログでモデル呼び出しを監査
✅ 効果: GPT-6 Astra 同等の性能を 3 倍以上高速かつ低コストで利用でき、エージェントの応答性と運用コストが改善します

3. 抽出結果をもとに自然な文章で提案書ドラフトを生成

1. 対象リポジトリのコードを収集し、最大 100 万トークンのコンテキストに投入
2. GPT-6.1 Terra に調査観点を指示して分析を実行

✅ 効果: 大規模コンテキストにより分割処理の手間が減り、コードベース全体を踏まえた精度の高い分析が可能になります

🌍 利用可能リージョン
対応リージョンは発表に明記されていません。リージョン、エンドポイント、推論プロファイルの詳細は Amazon Bedrock ドキュメント で確認してください。
