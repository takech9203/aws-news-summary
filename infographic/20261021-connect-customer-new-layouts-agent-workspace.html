Amazon Connect Customer

🖥️ エージェントワークスペースに 2 つの新レイアウト登場

📅 リリース日: 2026 年 10 月 21 日 ｜ 機能: Modern / Classic レイアウトのチーム単位割り当て

📌 概要

Amazon Connect Customer のエージェントワークスペースに、画面スペースを最適化する 2 つの新レイアウト Modern と Classic が追加されました。 管理者は UI Management のワークスペース機能を使い、ユーザーまたはルーティングプロファイル単位でレイアウトを割り当てられます。 チームの業務内容や習熟度に応じた画面構成により、エージェントの業務効率と満足度の向上が期待できます。

😣 アップデート前の課題

  • レイアウトは 1 種類のみで、チームごとに配置を変更できない
  • 音声通話中もコンタクトコントロールが画面を占有し、アプリ表示領域が制限される
  • チャットやメールの読み書き領域が狭く、長文で視認性が低下
  • 他社デスクトップ (上部コントロール型) からの移行時、操作感の違いが習熟の障壁に

😀 アップデート後の改善

  • チーム (ユーザー / ルーティングプロファイル) ごとに Modern / Classic を割り当て可能
  • Modern では音声通話中のコントロールを上部バーに集約し、画面全体をアプリに活用
  • チャット、メール、タスクでより高く広い読み書き領域を確保
  • Classic でもチャネル別コントロール幅とサイズ変更可能なエージェントアシストを提供

⚡ 主要機能

1️⃣ Modern レイアウト — 画面スペースの最大化

  • ヘッダーバー、コンタクトリスト、コンタクトコントロールバー、チャネル別コントロール、アプリケーションタブ、エージェントアシストの 6 コンポーネントで構成
  • 音声通話中のコンタクトコントロール表示は、アフターコンタクトワーク中、トランスクリプト利用時、ビデオ通話有効時のみ
  • コンタクトリストはアクティブなコンタクトが 2 件以上ある場合のみ表示され、チャネル別アイコンに折りたたみ可能。チャットでは最新メッセージのプレビューも表示
  • コンタクトリスト、コンタクトコントロール、エージェントアシストは展開 / 折りたたみ / サイズ変更が可能
  • アクティブなコンタクトがない場合はウェルカムメッセージを表示し、コンタクトなしでのアプリ利用や新規コンタクト開始が可能

2️⃣ Classic レイアウト — 従来の操作感 + 改善

  • ヘッダーバー、コンタクトリスト、コンタクトコントロール、アプリケーションタブ、エージェントアシストの 5 コンポーネントで構成
  • 従来レイアウトとの違いは 4 点: ステータス切り替えがヘッダーバーに移動 / チャットとメールのコントロールがデフォルトで広く表示 / チャネル間の切り替えでも幅を維持 / エージェントアシストのサイズ変更が可能

3️⃣ チームごとのレイアウト割り当て

  • UI Management のワークスペース機能で、ユーザーまたはルーティングプロファイル単位で割り当て可能
  • 可視性は「全ユーザーに表示」「割り当てたユーザーのみに表示」「非表示 (準備・テスト用)」から選択
  • レイアウト未割り当てのエージェントは引き続き従来レイアウトを使用

4️⃣ 共通の設定メニュー

  • 両レイアウトとも、ヘッダーバーのドロップダウンから言語、ライト / ダークモード、サインアウトを操作可能
  • デバイス設定ダイアログからカメラ、スピーカー、マイク、着信音などを変更可能

👀 レイアウトのプレビュー

両レイアウトは AWS マネージドビューとして提供されます。割り当て前にプレビューするには、 UI Management > Views で Agent Workspace - Classic または Agent Workspace - Modern を UI ビルダーで開きます。

ステップ 1: ワークスペースを作成してレイアウトを設定する

  • UI Management > Workspaces で Add new workspace を選択し、ワークスペース名を入力して保存
  • Pages セクションで Add page > Use existing Connect page を選択し、Agent Workspace を指定
  • Page layout で Agent Workspace - Classic または Agent Workspace - Modern を選択し、View version は LATEST を選択して保存

ステップ 2: ワークスペースをエージェントに割り当てる

  • Assignments セクションで可視性を Visible to all users / Visible to assigned users / Visible to no users から選択
  • Users で対象エージェントを検索して選択、または Routing profiles でプロファイル内の全エージェントに一括割り当て (チーム単位の割り当てに最適)
  • 割り当てを解除するには、該当の割り当てを選択して Delete を選択

ステップ 3: レイアウトを事前にプレビューする (任意)

  • UI Management > Views で各レイアウトを UI ビルダーで開き、見た目を確認
  • 可視性を Visible to no users にしたままテストすることも可能

💡 メリットと制約事項

📈 ビジネス面のメリット

  • 生産性向上: 通話中の画面領域最大化と広い読み書き領域で対応効率が向上
  • 移行の容易化: 他社デスクトップに近い操作感で再教育コストを削減
  • 変更管理の柔軟性: 既存チームは Classic、新規 / 移行チームは Modern と段階的に展開可能

⚙️ 技術面のメリット

  • チーム単位の割り当て: ルーティングプロファイル単位で一括展開
  • 安全な展開: 3 段階の可視性設定でテストから段階的展開まで制御
  • AWS マネージドビュー: カスタム開発なしで利用可能

⚠️ 制限事項・考慮すべき点

  • 利用可能リージョンは 9 リージョンに限定 (東京リージョンは現時点で対象外)
  • レイアウト未割り当てのエージェントは従来レイアウトのまま変更されない
  • Modern の音声通話中コントロール表示は、アフターコンタクトワーク中、トランスクリプト利用時、ビデオ通話有効時のみ
  • ワークスペース管理にはセキュリティプロファイルへの権限追加が必要
  • Classic も従来と完全に同一ではない (ステータス切り替えの位置が変わる) ため、エージェントへの事前周知が必要
  • Modern ではコンタクトリストの表示条件 (2 件以上のみ) が変わるため、複数コンタクトを扱うチームでは運用への影響を確認
  • 操作習慣に影響するため、ピーク時間帯を避けた段階的な展開が望ましい

🎯 ユースケース

1. 他社コンタクトセンター製品からの移行

シナリオ: コントロールが画面上部に配置された他社のエージェントデスクトップから Amazon Connect Customer へ移行する。

実装: 移行対象チームのルーティングプロファイルを確認 → Modern レイアウトのワークスペースを作成 → 可視性を「Visible to assigned users」にして移行チームのプロファイルへ割り当て。

✅ 効果: 従来製品に近い操作感で再教育コストを削減し、移行後の生産性低下を最小化。

2. 音声中心のチームでのアプリケーション活用強化

シナリオ: 音声通話中心のサポートチームが、通話中に Customer Profiles、Cases、サードパーティ CRM を頻繁に参照している。

実装: 音声チーム用ワークスペースに Modern レイアウトを設定し、音声チームのルーティングプロファイルへ割り当て。通話中はコントロールバー以外の全領域でアプリとエージェントアシストを表示。

✅ 効果: 顧客情報やナレッジの参照がしやすくなり、平均処理時間 AHT の短縮に寄与。

3. 既存チームへの段階的な機能改善の提供

シナリオ: 既存のワークスペースに慣れたチャット / メール対応チームに、操作感を大きく変えずに利便性を向上させたい。

実装: Classic レイアウトのワークスペースを作成 → 可視性を「Visible to no users」にしてプレビューで検証 → 検証後に対象チームのルーティングプロファイルへ割り当てて展開。

✅ 効果: 従来の操作感を維持しつつ、チャネル別に最適化されたコントロール幅とサイズ変更可能なエージェントアシストで読み書きのしやすさが向上。

💰 料金

レイアウト機能自体に関する追加料金の記載はありません (公式発表時点)。 Amazon Connect Customer は従量課金制のサービスであり、音声、チャット、メール、タスクなどチャネルごとの使用量に基づいて課金されます。 詳細は 料金ページ を参照してください。

🧩 関連サービス・機能

  • Amazon Connect Customer Profiles: 顧客情報を表示する機能。両レイアウトのアプリケーションタブで利用可能
  • Amazon Connect Customer Cases: ケース管理機能。アプリケーションタブに統合され、レイアウトに応じた表示領域で利用可能
  • エージェントアシスト (Amazon Q in Connect): リアルタイムのレコメンデーションを提供。両レイアウトでサイズ変更可能に
  • ステップバイステップガイド: 定型業務を視覚的にガイドする機能。ワークスペース内で利用可能
  • サードパーティアプリケーション統合: CRM などの外部アプリをワークスペースに統合し、画面切り替えを削減

📝 まとめ

エージェントワークスペースに Modern と Classic の 2 レイアウトが追加され、 管理者がチームごとに最適な画面構成を割り当てられるようになりました。

👉 他社製品からの移行チームには Modern、既存ワークスペースに慣れたチームには Classic を割り当てるなど、状況に応じた展開が可能です。 まずは UI Management の Views でレイアウトをプレビューし、対象チームのルーティングプロファイルへ段階的に割り当てることを推奨します。
