🚀 概要

AWS Transform に、Power BI および Tableau のダッシュボードを Amazon QuickSight に変換する BI マイグレーションエージェントが追加。従来数か月かかっていた BI マイグレーション作業を 数日に短縮 できる。

AWS Advanced Consulting Partner である Wavicle Data Solutions が構築し、AWS Marketplace を通じて 4 つのエージェントとして提供される。すべての処理は顧客の AWS アカウント内で実行され、データが環境外に出ることはない。

⚡ 主要機能

🔍 Analyzer Agent

移行元 BI ダッシュボードを自動スキャンし、移行準備状況を評価。Power BI 用と Tableau 用の 2 種類を提供。チャットベースで対話的に分析結果を確認可能。

🔄 Converter Agent

評価済みダッシュボードを QuickSight アセットに変換。データセット、計算フィールド、ビジュアライゼーション、フィルターを再構築。

🤖 AWS Transform 統合

エージェント型 AI 機能と完全統合。専門エージェント、ツール、ナレッジベース、ワークフローを活用。処理は顧客アカウント内で実行。

✨ 移行後の活用

変換後に QuickSight 管理者がダッシュボード所有権を割り当て。Amazon Quick の AI ワークフロー (自然言語質問、自動リサーチ) を利用可能。

📋 設定方法

前提条件

  • ✓ AWS アカウントを保有していること
  • ✓ AWS Transform へのアクセスが有効であること
  • ✓ Amazon QuickSight がセットアップ済みであること
  • ✓ 移行元の Power BI または Tableau 環境へのアクセス

手順

  1. AWS Marketplace からサブスクライブ
    Power BI Migration Agent または Tableau Migration Agent をサブスクライブする
  2. Analyzer Agent で評価
    チャットベースのインターフェースで移行元ダッシュボードの移行準備状況を評価。複雑さ、コンポーネント、互換性を分析
  3. Converter Agent で変換
    評価結果に基づき、ダッシュボードを QuickSight アセットに変換。データセット、計算フィールド、ビジュアル、フィルターを自動再構築
  4. 検証と公開
    QuickSight 管理者が所有権を BI 作成者に割り当て、内容を検証後に公開
