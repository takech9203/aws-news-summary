Amazon SageMaker Unified Studio

🎨 IDC ベースドメインでライトモードをサポート

📅 リリース日: 2026 年 10 月 26 日 | IAM Identity Center ベースドメインでもダーク / ライトテーマを自由に選択可能に

📋 概要

Amazon SageMaker Unified Studio が IAM Identity Center (IDC) ベースのドメインでライトモードをサポートしました。 これにより、IAM ベースと IDC ベースの両方のドメインで、ユーザーが好みのビジュアルテーマ (ダークモードまたはライトモード) を選択できるようになりました。

ライトモードは明るい環境での可読性を向上させ、ダークモードと合わせてさまざまな照明条件下での アクセシビリティ向上と眼精疲労の軽減に貢献します。 選択した設定はブラウザやデバイスをまたいで永続化されるため、複数の環境からでも一貫した表示体験が得られます。

対象はデータ分析、機械学習、生成 AI の開発を統合環境で行うデータサイエンティストやデータエンジニアなど、SageMaker Unified Studio のすべてのユーザーです。

❌ アップデート前の課題
✗IDC ベースドメインではライトモードを選択できず、テーマの選択肢が制限されていた
✗IAM / IDC ドメイン間でテーマ選択機能に差異があり、一貫したユーザー体験を提供できなかった
✗明るいオフィスや日中の屋外では、可読性の面で最適な表示モードを選択できないケースがあった
✅ アップデート後の改善
✓IAM / IDC 両方のドメインでダーク / ライトテーマを自由に選択可能
✓デバイス設定オプションで OS のテーマ設定に自動追従が可能
✓テーマ設定がブラウザ・デバイスをまたいで永続化され、どの環境でも同じ表示設定が適用

⚡ 主要機能

1️⃣ ライトモードの IDC ベースドメイン対応
これまで IAM ベースドメインで利用できていたテーマ選択が、IDC ベースドメインでも利用可能に。明るい環境での可読性が向上し、照明条件に応じたアクセシビリティ改善と眼精疲労の軽減を実現。
2️⃣ 3 つの表示モードオプション
Light (常にライト)、Dark (常にダーク)、Device setting (OS のテーマ設定に自動追従、デフォルト) から選択可能。
3️⃣ 設定の永続化
選択した設定は自動的に保存され、セッションをまたいで適用。ブラウザやデバイスを変更しても同じテーマ設定が維持される。

💡 メリット

📈 ビジネス面

✓ユーザー体験の統一: 認証方式 (IAM/IDC) に関わらず一貫した表示カスタマイズ体験を提供
✓アクセシビリティの向上: 視覚特性や作業環境に合わせた表示モードを選択でき、インクルーシブな開発環境を実現
✓生産性の向上: 可読性向上と眼精疲労の軽減により、長時間の分析・開発作業の快適性が向上

⚙️ 技術面

✓OS 設定との連携: 時間帯による OS のテーマ自動切り替えなどに追従可能
✓設定の永続化: ブラウザやデバイスをまたいで設定が維持され、環境ごとの再設定が不要
✓追加設定不要: 管理者の追加設定やデプロイ作業なしで、ユーザーが即座に利用可能

⚠️ デメリット・制約事項

制限事項

•本アップデートは表示テーマに関する機能であり、機能面での変更はない
•テーマの選択はユーザー単位であり、管理者がドメイン全体のデフォルトテーマを強制する仕組みは案内されていない

考慮すべき点

→スクリーンショットを含む社内手順書を整備している場合、ユーザーごとにテーマが異なると画面の見た目が変わる点に留意が必要
→「Device setting」を選択した場合、OS 側のテーマ変更に連動して表示が切り替わる

🎯 ユースケース

☀️ ユースケース 1: 明るいオフィス環境での分析作業
日当たりの良いオフィスや外出先の明るい環境で、データアナリストが Query Editor を使用して SQL 分析を行うケース。
操作手順
プロファイルアイコン → Customize appearance → Light を選択
✅ 効果: 明るい環境でも画面の可読性が確保され、長時間の分析作業における視認性が向上。
🔄 ユースケース 2: OS のテーマ自動切り替えとの連携
OS の設定で日中はライトモード、夜間はダークモードに自動切り替えするよう設定しており、SageMaker Unified Studio もこれに追従させたいケース。
操作手順
プロファイルアイコン → Customize appearance → Device setting を選択
✅ 効果: 時間帯に応じて表示テーマが OS 設定と連動して自動的に切り替わり、常に目に優しい表示を維持。
🏢 ユースケース 3: IDC ベースドメインを利用する組織での表示統一
IAM Identity Center で認証を統合している企業で、これまでライトモードを利用できなかった IDC ベースドメインのユーザーが、他の社内ツールと同じライトテーマで作業したいケース。
操作手順
プロファイルアイコン → Customize appearance → Light を選択
設定はブラウザ・デバイスをまたいで永続化
✅ 効果: 社内の他ツールと見た目を揃えることができ、複数デバイスからのアクセスでも同じテーマが適用され、一貫した作業環境が得られる。

💰 料金・利用可能リージョン

💵 料金
本アップデートによる追加料金はありません。表示テーマの選択機能は SageMaker Unified Studio の標準機能として提供されます。SageMaker Unified Studio 自体の利用料金は、使用するコンピューティングリソースやストレージに応じた従量課金です。
🌍 利用可能リージョン
Amazon SageMaker Unified Studio が利用可能なすべての AWS リージョンで利用できます。

🔗 関連サービス・機能

→Amazon SageMaker Unified Studio: データ、分析、AI/ML のための統合開発環境。本アップデートの対象サービス
→AWS IAM Identity Center (IDC): 組織のワークフォースユーザーの認証を一元管理するサービス。IDC ベースドメインの認証基盤
→表示言語設定: 表示テーマに加えて 12 言語 (日本語を含む) の表示言語切り替えもサポート。同じプロファイルメニューから設定可能

📝 まとめ

SageMaker Unified Studio のライトモードが IDC ベースドメインでも利用可能になり、 認証方式に関わらずすべてのユーザーが好みの表示テーマを選択可能になりました。 設定はプロファイルメニューから数クリックで完了し、ブラウザ・デバイスをまたいで永続化されます。 IDC ベースドメインを利用している組織のユーザーは、作業環境や好みに合わせて「Customize appearance」から表示モードを設定することをおすすめします。
