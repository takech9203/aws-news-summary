🛠️ Amazon WorkSpaces Applications
マルチセッションフリートのドレインモード

メンテナンス時もユーザーの作業を止めない。段階的なインスタンス管理を実現する新機能
🆕 追加料金なし 全リージョン対応
📅 2026 年 4 月 2 日
Amazon WorkSpaces Applications

📝 概要

マルチセッションフリートの個々のインスタンスにドレインモードを設定できるようになりました。有効にすると新規セッションの受け入れを停止しつつ、既存セッションは中断なく継続できます。

マルチセッションフリートは 1 つのインスタンス上に複数のユーザーセッションをホストし、インフラ使用率を最大化する仕組みです。

🔄 Before / After

❌ Before

  • メンテナンス時にセッションを強制終了
  • パッチ適用時にユーザー作業が中断
  • 新規セッション制御の標準手段なし
➡️

✅ After

  • 既存セッション維持のまま新規停止
  • 段階的にインスタンスを空にできる
  • API で自動化ワークフロー構築可能

    A->>I: メンテナンス実施

管理者がドレインモードを有効にすると、新規セッション受け入れを停止し、既存セッション終了後にメンテナンスを安全に実施できます。

⭐ 主要機能

🆕
DrainSessionInstance API
セッション ID を指定してドレインモードを有効化。マルチセッションフリート専用。
🔍
ドレインモードステータス監視
DescribeSessions API に InstanceDrainStatus フィールドが追加
ACTIVE
DRAINING
NOT_APPLICABLE
📊
ComputeCapacityStatus 拡張
CreateFleet / UpdateFleet / DescribeFleets に 3 つの新フィールド追加
Draining DrainModeActiveUserSessions DrainModeUnusedUserSessions

🔧 API 変更の概要

API メソッド 変更種別 内容
DrainSessionInstance 新規追加 ドレインモード有効化
CreateFleet 拡張 ドレイン関連フィールド追加
UpdateFleet 拡張 ドレイン関連フィールド追加
DescribeFleets 拡張 ドレイン関連フィールド追加
DescribeSessions 拡張 InstanceDrainStatus 追加

⚙️ 設定方法

前提条件: マルチセッションフリート作成済み / RUNNING 状態 / AWS CLI v2

Bash Step 1: セッション確認 
aws appstream describe-sessions \
  --stack-name "my-stack" \
  --fleet-name "my-multi-session-fleet"
Bash Step 2: ドレインモード有効化 
aws appstream drain-session-instance \
  --session-id "session-id-on-target-instance"
Bash Step 3: ドレイン状態の監視 
aws appstream describe-fleets \
  --names "my-multi-session-fleet" \
  --query "Fleets[0].ComputeCapacityStatus.{
    Draining:Draining,
    ActiveSessions:DrainModeActiveUserSessions,
    UnusedSessions:DrainModeUnusedUserSessions
  }"

💡 ユースケース

🛡️ セキュリティパッチの適用

インスタンスを順次ドレインモードに設定し、ユーザー作業を中断せずにパッチを適用

📉 スケールダウンの最適化

業務時間外に使用率の低いインスタンスをドレインし、アクティブユーザーに影響なくコスト削減

🔄 アプリケーションイメージの更新

既存セッションを維持しながらインスタンスを入れ替え、ゼロダウンタイムでイメージ更新

⚖️ メリット / 制約事項

✅
ユーザー体験向上: メンテナンス時に作業が中断されず、生産性を維持
✅
API で自動化: DrainSessionInstance API でワークフロー自動化が容易
✅
きめ細かな制御: インスタンス単位でドレイン制御、フリート全体停止不要
✅
監視の強化: ドレイン中のインスタンスとセッション状態をリアルタイム把握
~ ~ ~ ~ ~
⚠️
マルチセッションのみ: シングルセッションフリートには適用不可
⚠️
強制終了なし: 既存セッションの強制終了機能は提供されない
⚠️
キャパシティ影響: ドレイン中インスタンスは新規受入停止のため、計画的な運用が必要
⚠️
長時間セッション: 長いセッションがあると待機時間が長くなる可能性

💰 料金 / リージョン
