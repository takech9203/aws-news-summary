📌 概要

Amazon S3 Vectors は、1,000 万件を超えるベクトルを含むインデックスに対するクエリの「データ処理 (data processed)」料金を最大 80% 引き下げました。大規模な AI / RAG / セマンティック検索ワークロードで類似検索を実行するお客様のコストが削減されます。

クエリ料金は「クエリリクエスト数」「データ処理量」「返却データ量」の 3 要素で構成され、今回引き下げられたのは 「データ処理量」 の単価です。1,000 万件超のインデックスの $/TB 単価 が引き下げられ、大規模に運用するほど効果が大きくなります。新料金はアプリケーション変更なしで全リージョン即時有効です。

⚙️ 主要機能

1. 大規模インデックスのデータ処理料金引き下げ

1,000 万件を超えるベクトルを含むインデックスに対するクエリのデータ処理料金が最大 80% 削減。データ処理量は、クエリ実行時にスキャンされるベクトルデータ量に応じて課金されます。

2. 自動適用

新料金はアプリケーションの変更なしに自動的に適用されます。既存のインデックスやクエリコードを変更する必要はありません。

3. 全リージョンで即時有効

S3 Vectors が利用可能なすべての AWS リージョンで本日付けで有効。段階的なロールアウトではなく、即座に新料金が適用されます。

🔧 技術仕様: データ処理料金の段階

クエリのデータ処理料金は、インデックスに含まれるベクトル数に応じた段階制です。今回のアップデートで 1,000 万件超の段階の単価が引き下げられました。(米国東部 / バージニア北部リージョン)

インデックスのベクトル数データ処理単価
最初の 100K 件0.004 USD/TB
100K - 1,000 万件0.002 USD/TB
1,000 万件超 ⬅ 引き下げ対象0.0004 USD/TB

1,000 万件超の段階の単価 (0.0004 USD/TB) は、直前の段階 (0.002 USD/TB) と比較して 80% 低い水準であり、大規模インデックスほどデータ処理コストが抑えられます。

ℹ️ 今回のアップデートは料金体系の変更であり、API の追加・変更は含まれません (API 変更履歴の記載なし)。

⚠️ デメリット・制約事項

制限事項

✗料金引き下げの対象は、1,000 万件を超えるインデックスに対するクエリのデータ処理料金に限定される
✗クエリリクエスト料金や返却データ料金は今回の対象外
✗具体的な料金は AWS S3 料金ページの値が正であり、リージョンによって異なる場合がある

考慮すべき点

⚖️AWS はパフォーマンス向上のため、引き続き複数のインデックスにベクトルを分散させることを推奨。単一の巨大なインデックスへの集約はコスト面で有利でもパフォーマンス面では推奨されない
⚖️1 つのインデックスを 1,000 万件超に拡大して料金段階の恩恵を得る設計と、パフォーマンスのための分散設計はトレードオフ。ワークロード特性に応じた判断が必要

💲 料金

クエリ料金は「クエリリクエスト数」「データ処理量」「返却データ量」の 3 要素で構成。今回引き下げられたのは「データ処理量」で、1,000 万件超のインデックスが対象です。(米国東部 / バージニア北部リージョンの目安)

クエリリクエスト2.50 USD/100 万クエリ
データ処理 (100K 件まで)0.004 USD/TB
データ処理 (100K - 1,000 万件)0.002 USD/TB

今回のアップデートは、1,000 万件を超える大規模ベクトルインデックスに対するクエリのデータ処理料金を最大 80% 削減するもので、大規模な AI / RAG / セマンティック検索ワークロードのコスト効率を大きく改善します。新料金はアプリケーション変更なしに全リージョンで自動適用されるため、すでに S3 Vectors を利用しているお客様は追加作業なしでコスト削減の恩恵を受けられます。
