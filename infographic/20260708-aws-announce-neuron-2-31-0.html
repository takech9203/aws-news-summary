AWS Neuron

⚡ AWS Neuron 2.31.0
NKI 0.5.0 と UltraServer Operator

2026-07-08
一般提供開始 (GA)

📌 概要

AWS Neuron 2.31.0 が一般提供を開始しました。AWS Neuron は、AWS Trainium および AWS Inferentia ベースの Amazon EC2 インスタンス (Trn1、Trn2、Trn3、Inf1、Inf2) 上で深層学習ワークロードを実行するための SDK です。コンパイラ、ランタイム、プロファイリングツール、NKI (Neuron Kernel Interface) などで構成され、大規模モデルの学習・推論を高性能かつ低コストで実現します。

今回のリリースでは NKI 0.5.0 が導入され、MX FP8 スケール dtype のサポート、テンソルインダイレクション、ゼロコストのレイアウト変換を可能にする NkiTensor view API が追加されました。さらに、Amazon EKS 上の Trainium UltraServer ワークロード向けに Neuron UltraServer Operator がパブリックベータで提供されます。

😓 アップデート前の課題
  • Amazon EKS 上で UltraServer ワークロードの init コンテナやノードラベルを手動設定
  • スクラッチパッドのページサイズを手動で設定する必要
  • MX FP8 スケール dtype やテンソルインダイレクションが NKI で未サポート
  • レイアウト変換にコストが発生し、命令数が増大
🎉 アップデート後の改善
  • UltraServer Operator が EKS 上の検出とワークロード割り当てを自動化
  • 連続共有スクラッチパッドで手動設定が不要に
  • MX FP8 とテンソルインダイレクションで命令数を削減
  • NkiTensor view API でゼロコストのレイアウト変換
  • Trn2/Trn3 で新コード生成バックエンドがデフォルト有効に

Neuron UltraServer Operator が Amazon EKS 上で Trainium UltraServer を自動検出し、ワークロードへのリソース割り当てを自動化する流れ

🚀 主要機能

📐 NKI 0.5.0
  • MX FP8 スケール dtype のサポートを追加
  • テンソルインダイレクション (gather/scatter) をサポートし命令数を削減
  • NkiTensor view API でゼロコストのレイアウト変換
  • nc_matmul の出力容量拡張と IDE 向け型スタブ
🔧 UltraServer Operator Beta
  • Amazon EKS 向け Trainium UltraServer 用 Kubernetes オペレーター
  • UltraServer 検出・ワークロード割り当て・リソースクレーム生成を自動化
  • 手動の init コンテナ設定やノードラベルマッチングが不要
🛠️ Neuron Compiler
  • 再設計コード生成バックエンドが Trn2/Trn3 でデフォルト有効
  • 命令スケジューリングとメモリプリフェッチを改善
  • アテンションカーネルを含む StableHLO 複合演算をサポート
⏱️ Neuron Runtime
  • 連続共有スクラッチパッドで手動ページサイズ設定が不要
  • テンソルリスト・合体コレクティブ API で通信を改善
  • ライブ電力モニタリング、Trn2/Trn3 マルチノードリング通信
📚 NKI ライブラリ
  • MoE 学習、deformable attention、DeepSeek MLA、ring attention をカバーする 14 個の実験的カーネル
  • PyTorch リファレンス実装を併せて提供
  • 統一精度セレクターと FP8 パック KV パスを追加
🔍 Neuron Explorer
  • System Trace Viewer にソースコードリンク機能を追加
  • デフォルトのグルーピングを更新しデバッグを改善
  • torch.compile と eager モードのプロファイリングをサポート

♻️ ライフサイクルの変更

⚠️pytorch-training-neuronx の Deep Learning Container (DLC) は公開されなくなりました
⚠️NxD Training が DLAMI から削除されました
⚠️暗黙的な非同期実行モードが削除されました
⚠️カーネル kv_parallel_segmented_prefill が attention_kv_parallel_segmented_cte にリネームされました

⚙️ 設定方法

ステップ 1: Neuron SDK 2.31.0 へのアップデート

Bash主要パッケージを最新版に更新
# Neuron リポジトリを設定し、主要パッケージを最新版に更新
python3 -m pip install --upgrade neuronx-cc torch-neuronx

ステップ 2: 対応 DLAMI または DLC の利用

BashDeep Learning Container を取得
# Neuron SDK 2.31.0 対応の Deep Learning Container を取得
# （リージョンとタグは AWS ドキュメントに従って指定）
docker pull <account-id>.dkr.ecr.<region>.amazonaws.com/pytorch-inference-neuronx:2.31.0

ステップ 3: UltraServer Operator の導入 (Amazon EKS)

Amazon EKS 上で Trainium UltraServer ワークロードを実行する場合、Neuron UltraServer Operator をデプロイすることで、UltraServer の検出とワークロード割り当てが自動化されます。詳細な導入手順は公式ドキュメントを参照してください。

💡 メリット

📈 ビジネス面

✓運用負荷の軽減: UltraServer Operator で大規模学習環境の構築・運用を自動化
✓コスト最適化: Trn2/Trn3 の新バックエンドで同一ワークロードを高性能に実行
✓最新モデル対応: MoE、DeepSeek MLA、ring attention などの新カーネル

🛠️ 技術面

✓開発効率向上: NkiTensor view API と IDE 向け型スタブでカーネル開発を効率化
✓設定の簡素化: 連続共有スクラッチパッドで手動設定が不要
✓デバッグ改善: System Trace Viewer のソースコードリンク

⚠️ デメリット・制約事項

•Neuron UltraServer Operator はパブリックベータであり、本番環境での利用には注意が必要
•NKI ライブラリの 14 個の新カーネルは実験的で、API が変更される可能性がある
•新コード生成バックエンドのデフォルト有効化は Trn2/Trn3 に限られる
•DLC の公開終了や NxD Training の DLAMI 削除など、移行が必要な場合がある
•暗黙的な非同期実行モードの削除、カーネルのリネームに伴うコード修正が必要

🎯 ユースケース

1. Amazon EKS での大規模モデル学習

シナリオ: Kubernetes 上で Trainium UltraServer を用いた大規模言語モデルの分散学習を行いたい。

効果: UltraServer Operator が検出とリソース割り当てを自動化し、init コンテナやノードラベル設定の手間を省いて学習ジョブのデプロイを迅速化。

2. MoE モデルの学習

シナリオ: Mixture of Experts (MoE) アーキテクチャのモデルを Trainium 上で効率的に学習したい。

効果: NKI ライブラリの新しい MoE 学習コレクティブカーネルと PyTorch リファレンス実装で、MoE 特有の通信パターンを最適化。

3. カスタムカーネルの開発

シナリオ: 特定の演算に最適化されたカスタムカーネルを NKI で開発したい。

効果: NkiTensor view API のゼロコストレイアウト変換とテンソルインダイレクションによる命令数削減で、高性能カーネルを効率的に開発。

💰 料金・利用可能リージョン

💵 料金

AWS Neuron SDK 自体は無償で提供されます。利用にあたっては、Trainium/Inferentia ベースの EC2 インスタンス (Trn1、Trn2、Trn3、Inf1、Inf2) の利用料金、および Amazon EKS を利用する場合はクラスター料金が発生します。

🌐 利用可能リージョン

AWS Neuron 2.31.0 は、EC2 Trn1、Trn2、Trn3、Inf1、Inf2 インスタンスが利用可能なすべての AWS リージョンで利用できます。

🔗 関連サービス・機能

AWS Trainium — 学習用 ML アクセラレーター AWS Inferentia — 推論用 ML アクセラレーター Amazon EKS — UltraServer 運用の自動化 PyTorch — 新カーネルのリファレンス実装

📝 まとめ

AWS Neuron 2.31.0 は、NKI 0.5.0 による開発体験の向上、UltraServer Operator による Amazon EKS 運用の自動化、コンパイラとランタイムのパフォーマンス改善を含む重要なアップデートです。Trainium や Inferentia を用いた大規模学習・推論ワークロードを運用しているユーザーは、対応 DLAMI または DLC への移行を検討し、ライフサイクル変更に伴う影響を確認することが推奨されます。
