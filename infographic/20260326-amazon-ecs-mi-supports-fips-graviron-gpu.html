FIPS 準拠ワークロードが Graviton および GPU インスタンスに対応
2026.03.26 AWS What's New

📋 概要

Amazon ECS Managed Instances が、AWS GovCloud (US) リージョンにおいて Graviton ベースおよび GPU アクセラレーテッドインスタンスでの FIPS 準拠モードでのワークロードデプロイをサポートしました。FIPS は、機密情報を保護する暗号モジュールのセキュリティ要件を規定する米国およびカナダの政府標準規格です。GovCloud では FIPS 準拠がデフォルトで自動的に有効化されます。

❌ Before

  • Graviton インスタンスでの FIPS 準拠ワークロード実行が制限
  • GPU インスタンスで FIPS 準拠モードの有効化が困難
  • コスト効率の高い Graviton を FIPS 準拠で活用できず

✅ After

  • Graviton で FIPS 準拠コンテナワークロードを GovCloud で実行可能
  • GPU を含む幅広いインスタンスタイプで FIPS 対応
  • GovCloud では FIPS がデフォルト自動有効化、追加設定不要

Bash Step 1: ECS クラスターの作成 
aws ecs create-cluster \
  --cluster-name my-fips-cluster \
  --region us-gov-west-1
Bash Step 2: キャパシティプロバイダー設定 
aws ecs put-cluster-capacity-providers \
  --cluster my-fips-cluster \
  --capacity-providers FARGATE FARGATE_SPOT \
  --default-capacity-provider-strategy \
    capacityProvider=FARGATE,weight=1 \
  --region us-gov-west-1
Bash Step 3: タスクのデプロイ 
aws ecs run-task \
  --cluster my-fips-cluster \
  --task-definition my-task-definition \
  --region us-gov-west-1

✓ GovCloud リージョンでは FIPS 準拠が自動的に適用されるため、タスク定義の変更は不要です。

💡 ユースケース

🤖 連邦政府機関の ML/AI ワークロード

連邦政府機関が機密データを使用した機械学習モデルの推論を FIPS 準拠環境で実行するシナリオ。GPU アクセラレーテッドインスタンス上で FIPS 準拠の ML 推論パイプラインを運用。

JSON ML 推論タスク定義例 
{
  "family": "ml-inference-fips",
  "containerDefinitions": [{
    "name": "ml-inference",
    "image": "my-govcloud-account.dkr.ecr.us-gov-west-1.amazonaws.com/ml-model:latest",
    "cpu": 4096,
    "memory": 8192,
    "resourceRequirements": [{ "type": "GPU", "value": "1" }]
  }]
}
→ 連邦政府のセキュリティ要件を満たしながら高パフォーマンスな推論処理を実現

🌐 コスト最適化された政府系 Web アプリケーション

政府系 Web アプリケーションを FIPS 準拠環境で運用しつつ、Graviton インスタンスでコストを最適化。ARM64 アーキテクチャで動作。

JSON Graviton Web アプリタスク定義例 
{
  "family": "gov-web-app",
  "runtimePlatform": {
    "cpuArchitecture": "ARM64",
    "operatingSystemFamily": "LINUX"
  },
  "containerDefinitions": [{
    "name": "web-app",
    "image": "my-govcloud-account.dkr.ecr.us-gov-west-1.amazonaws.com/web-app:latest",
    "cpu": 1024,
    "memory": 2048,
    "portMappings": [{ "containerPort": 8080, "protocol": "tcp" }]
  }]
}
→ Graviton で FIPS 準拠を維持しながら x86 比でコンピュートコストを削減

⚖ メリットと制約事項

✅ メリット

  • 政府コンプライアンス達成: FIPS 140 準拠が求められる連邦/州政府ワークロードに対応
  • コスト最適化: Graviton で最大 40% のコスト削減
  • 運用の簡素化: デフォルト自動有効化で設定管理負荷を軽減
  • 幅広い選択肢: ワークロードに最適なインスタンスを FIPS 準拠で選択可能
  • 透過的な統合: 既存タスク定義の変更なしに FIPS 準拠を適用

⚠ 制約事項

  • AWS GovCloud (US) リージョンのみで利用可能
  • ECS Managed Instances の管理に追加料金が発生
  • FIPS モードの暗号処理でわずかなパフォーマンスオーバーヘッドの可能性
  • GovCloud アカウント取得に特定要件を満たす必要あり
  • アプリケーションが FIPS 検証済み暗号ライブラリを使用していることの確認が必要

💰 料金

ECS Managed Instances のコンピュート管理に対する料金が通常の EC2 コストに追加されます。FIPS 準拠の有効化自体に追加料金はありません。

構成要素 料金体系
Amazon EC2 インスタンス 使用するインスタンスタイプに応じた通常料金
ECS Managed Instances 管理料金 プロビジョニングされたコンピュートに対する追加料金
FIPS 準拠 追加料金なし
