🎯 概要

AWS Marketplace が Agreements API を発表し、AWS Marketplace 製品の調達と契約管理をプログラマティックに実行できるようになった。見積もりの生成、オファーの受け入れ、課金とエンタイトルメントの追跡、購入注文の更新、契約管理を既存のツールやワークフロー内で完結できる。

Discovery API と組み合わせることで、製品の検索から購入までのエンドツーエンドの調達ジャーニーを API で実現可能。パートナーは API を使用してカスタムストアフロントを構築し、顧客に統合された調達体験を提供できる。

❌ Before

  • Web サイトまたは Management Console へのアクセスが必要
  • 調達ワークフローの自動化が困難
  • 既存の社内調達システムとの統合が限定的
  • 大規模組織での調達プロセスのスケーリングに課題

✅ After

  • API 経由で調達プロセス全体をプログラマティックに実行
  • 既存の調達システムに API を統合してカスタムワークフロー構築
  • Discovery API との連携で検索から購入まで完全自動化
  • パートナーがカスタムストアフロントを構築可能

⚡ 主要機能

📝 契約リクエストの作成と受け入れ
CreateAgreementRequest で見積もり生成、AcceptAgreementRequest で契約確定。新規/修正/置換の 3 つのインテントをサポート。
💰 課金とエンタイトルメント管理
ListAgreementCharges で課金情報を一覧取得、GetAgreementEntitlements でライセンス情報を確認。
🔄 契約ライフサイクル管理
契約のキャンセル、キャンセルリクエストの承認/拒否、支払いリクエストの管理を API で実行。
🧾 購入注文の管理
UpdatePurchaseOrders で購入注文参照情報を更新。課金ごとに購入注文を関連付け可能。

💻 実装例

CreateAgreementRequest のリクエスト例

Python 契約リクエストの作成と見積もり取得 
import boto3

client = boto3.client('marketplace-agreement', region_name='us-east-1')

response = client.create_agreement_request(
    clientToken='unique-token-string',
    intent='NEW',
    requestedTerms=[
        {
            'id': 'term-id-string',
            'configuration': {
                'configurableUpfrontPricingTermConfiguration': {
                    'selectorValue': 'selected-option',
                    'dimensions': [
                        {
                            'dimensionKey': 'users',
                            'dimensionValue': 100
                        },
                    ]
                },
                'renewalTermConfiguration': {
                    'enableAutoRenew': True
                }
            }
        },
    ],
    agreementProposalIdentifier='proposal-id',
    taxConfiguration={
        'taxEstimation': 'ENABLED'
    }
)

# レスポンスから見積もり情報を取得
charge_summary = response['chargeSummary']
print(f"合計金額: {charge_summary['newAgreementValue']} {charge_summary['currencyCode']}")
print(f"税込金額: {charge_summary['newAgreementValueAfterTax']} {charge_summary['currencyCode']}")

⚠️ 既存の手動調達プロセスからの移行にはワークフローの再設計が必要

💡 ユースケース

🏢 エンタープライズ調達の自動化

大規模企業で、複数の部門が AWS Marketplace から SaaS 製品を購入する際、社内承認フローと連携した自動調達システムを構築する。

効果: 調達リードタイムを数日から数分に短縮し、コンプライアンスを自動的に担保できる。

🛍️ パートナーカスタムストアフロントの構築

AWS パートナーが顧客向けに統合された調達ポータルを構築し、複数の AWS Marketplace 製品を一元管理する。

効果: 顧客に対してブランド化された統一的な調達体験を提供でき、パートナーの付加価値を高められる。

🔄 契約ライフサイクルの自動管理

契約の更新、キャンセル、支払い承認を自動化し、管理工数を削減する。

効果: 契約管理の工数を大幅に削減し、更新漏れや支払い遅延を防止できる。

💲 料金とリージョン

🆓 Agreements API 自体の利用に追加料金は発生しない。
AWS Marketplace での製品購入に対する通常の料金が適用される。
