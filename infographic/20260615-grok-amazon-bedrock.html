🤖 xAI 製 Grok 4.3 モデルの提供開始

📅 2026-06-15 リリース

📌 概要

AWS は、xAI が開発する Grok 4.3 を Amazon Bedrock で利用可能にしたと発表しました。 これにより xAI が Bedrock 上のモデルプロバイダーとして初参加。 推論中心に設計されたモデルで、推論負荷を 4 段階に調整でき、強力なツール利用と高いトークン効率を備えます。

Grok 4.3 は Bedrock の新しい推論エンジン Mantle で動作します。Mantle は価格性能を重視して設計され、 ツール呼び出し・構造化出力・レスポンスストリーミングをサポート。カスタマーサポート、Web 開発、判例調査、財務文書の Q&A、 会話型 AI、検索、チャット、マルチターンワークフローといったエンタープライズ用途に適しています。

⏪ アップデート前の課題
  • Bedrock のモデルプロバイダーに xAI が含まれず、Grok を Bedrock 上で利用できなかった
  • 推論負荷を段階調整できる Grok 系モデルをフルマネージド環境で使えなかった
  • xAI 製モデル利用には Bedrock 以外の経路を検討する必要があった
➡
⏩ アップデート後の改善
  • Bedrock 上で Grok 4.3 を利用できるようになった
  • 推論負荷を 4 段階で調整し、コストと品質のバランスを取れる
  • ツール呼び出し・構造化出力・ストリーミングを活用したエージェントを Bedrock 上で構築可能

💻 API 呼び出し例

Python Converse API で Grok 4.3 を呼び出す 
import boto3

# Amazon Bedrock Runtime クライアントを作成する
client = boto3.client("bedrock-runtime", region_name="us-east-1")

# Converse API を使用して Grok 4.3 を呼び出す
response = client.converse(
    modelId="xai.grok-4-3",  # 実際のモデル ID はモデル詳細ページで確認する
    messages=[
        {
            "role": "user",
            "content": [{"text": "Amazon Bedrock の特徴を 3 点で説明してください。"}],
        }
    ],
    inferenceConfig={"maxTokens": 1024, "temperature": 0.7},
)

print(response["output"]["message"]["content"][0]["text"])

🪜 手順

提供リージョンの確認
リージョン対応ドキュメントで提供リージョンを確認し、利用リージョンで Bedrock が有効化されていることを確認します。
モデルアクセスの有効化
Bedrock コンソールの「モデルアクセス」画面で Grok 4.3 へのアクセスを有効化します。これで API から呼び出せます。
推論負荷の選定とアプリへの組み込み
ワークロード特性に応じて推論負荷を選定し、InvokeModel / Converse API でモデルを組み込みます。エージェントではツール呼び出しと構造化出力を活用します。
