📊 Grafana v12.4 インプレースアップグレード

既存ワークスペースを再作成なしで v10.4 から v12.4 へアップグレード

2026 年 5 月 15 日

🎯 概要

Amazon Managed Grafana が、既存のワークスペースを Grafana v10.4 から v12.4 へインプレースアップグレード する機能をサポート。AWS コンソール、SDK、CLI を通じて、ワークスペースを再作成することなくバージョンアップが可能に。

2026 年 4 月に v12.4 での新規ワークスペース作成がサポートされたが、今回のアップデートにより既存環境のアップグレードパスが提供された。

❌ Before

  • v10.4 から v12.4 への公式アップグレードパスなし
  • 新規ワークスペース作成と手動移行が必要
  • 移行時のダウンタイムや設定漏れリスク
  • アラートルール・データソースの再設定

✅ After

  • インプレースで既存ワークスペースを v12.4 に更新
  • ダッシュボード、データソース、権限すべて保持
  • コンソール / SDK / CLI から実行可能
  • 新規作成・移行作業が不要で運用負荷軽減

🛠️ 設定方法

前提条件

✓ Grafana バージョン 10.4 で稼働中のワークスペース
✓ ワークスペース管理者権限を持つ IAM ロール/ユーザー
✓ ダッシュボードおよび設定のバックアップ (推奨)

Step 1: 現在のバージョンを確認

Bash バージョン確認 
aws grafana describe-workspace \
  --workspace-id <your-workspace-id> \
  --query 'workspace.grafanaVersion'

Step 2: インプレースアップグレードの実行

Bash アップグレード実行 
aws grafana update-workspace-configuration \
  --workspace-id <your-workspace-id> \
  --grafana-version "12.4"

アップグレード中はワークスペースのステータスが VERSION_UPDATING に変わります。

Step 3: アップグレード完了の確認

Bash 完了確認 
aws grafana describe-workspace \
  --workspace-id <your-workspace-id> \
  --query 'workspace.{Status:status,Version:grafanaVersion}'

ステータスが ACTIVE に戻り、バージョンが 12.4 になっていることを確認。

💡 ユースケース

🏢 マルチアカウント環境のモニタリング統合
複数の AWS アカウントでワークロードを運用し、各アカウントの CloudWatch メトリクスを一元監視したい組織向け。v12.4 にアップグレード後、CloudWatch データソースでクロスアカウント Metrics Insights を有効化し、統合ダッシュボードで全アカウントを可視化。
→ 複数アカウントのメトリクスを単一ダッシュボードで俯瞰。異常検出もクロスアカウントで機能。
👥 非エンジニアチームへのオブザーバビリティ拡大
プロダクトマネージャーやビジネスアナリストもシステム状態を確認したいが、PromQL や CloudWatch クエリの知識がないケース。Queryless Drilldown アプリを有効化し、ポイント&クリック探索を設定。
→ クエリ言語を知らないメンバーでも直感的にメトリクスやログを探索可能。セルフサービスのオブザーバビリティを実現。
🔍 CloudWatch Logs の高度な分析
大量のアプリケーションログから特定パターンを分析したいが、既存の Logs Insights クエリでは表現力不足。PPL/SQL の強力なクエリ言語で複雑なログ分析が可能に。
→ PPL/SQL で柔軟なログ分析を実現。ログ異常検出で問題を自動サーフェス。

📌 まとめ

Amazon Managed Grafana のインプレースアップグレードにより、既存の v10.4 ワークスペースを再作成なしで v12.4 に移行可能に。Scenes ダッシュボード、Queryless Drilldown、CloudWatch PPL/SQL 対応など多数の新機能を即座に活用できるため、現在 v10.4 を使用している組織はアップグレード計画を推奨。

推奨アクション: 事前にカスタムプラグインの互換性確認とダッシュボードのバックアップを実施した上でアップグレードを実行。
