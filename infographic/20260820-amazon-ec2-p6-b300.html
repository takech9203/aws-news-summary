🚀 Amazon EC2 P6-B300 インスタンス
Asia Pacific (Seoul) リージョンでの提供開始

📅 リリース日: 2026 年 8 月 20 日 | 🖥️ 機能: P6-B300 インスタンスの Asia Pacific (Seoul) リージョン拡大

📌 概要

Amazon EC2 P6-B300 インスタンスが Asia Pacific (Seoul) リージョンで利用可能になりました。 8 基の NVIDIA Blackwell Ultra GPU を搭載し、2.1 TB の高帯域幅 GPU メモリ、6.4 Tbps の EFA ネットワーキング、 300 Gbps の専用 ENA スループット、4 TB のシステムメモリを提供する最上位クラスの GPU インスタンスです。

数兆パラメータ規模の基盤モデル (FM) や大規模言語モデル (LLM) のトレーニングとデプロイに最適化されており、 アジア太平洋地域では初の提供リージョンとなります。米国 3 リージョンと合わせて 4 リージョン体制になりました。

❌ Before: アップデート前の課題
  • P6-B300 は米国 3 リージョンのみで提供され、アジア太平洋地域では利用不可
  • アジアの組織は米国リージョンへのデータ転送や高いネットワークレイテンシーを許容する必要があった
  • データレジデンシー要件を持つ韓国の組織は最新世代の Blackwell Ultra GPU を活用できなかった
✅ After: アップデート後の改善
  • Seoul リージョンで低レイテンシーの最高性能 GPU コンピューティングにアクセス可能
  • 韓国国内にデータを保持したまま数兆パラメータ規模の基盤モデルをトレーニング・デプロイ可能
  • 4 リージョン体制でワークロード分散配置や災害復旧の選択肢が拡大

P6-B300 インスタンスのアーキテクチャ構成と利用可能リージョンを示しています。8 基の NVIDIA Blackwell Ultra GPU、2.1 TB の GPU メモリ、 6.4 Tbps の EFA ネットワーキング、300 Gbps の ENA スループット、4 TB のシステムメモリを搭載し、 今回の Asia Pacific (Seoul) 追加により 4 リージョンで利用可能です。

⚡ 主要機能

🎮 NVIDIA Blackwell Ultra GPU

8 基の NVIDIA Blackwell Ultra GPU を搭載。FP4 (スパーシティなし) で P6-B200 比 1.5 倍の GPU TFLOPS を提供し、数兆パラメータ規模のモデルのトレーニングとデプロイに最適化。

💾 大容量 GPU メモリ

2.1 TB の高帯域幅 GPU メモリ (HBM) を搭載。P6-B200 比 1.5 倍のメモリサイズで、大規模モデルのメモリ内保持が可能となり、モデル並列化の必要性を低減。

🌐 高速ネットワーキング

6.4 Tbps の EFA ネットワーキングと 300 Gbps の専用 ENA スループット。P6-B200 比 2 倍のネットワーク帯域幅で分散トレーニングを加速。

🌏 アジア太平洋地域初の提供リージョン

Asia Pacific (Seoul) はアジア太平洋地域で初めて P6-B300 が提供されるリージョン。データレジデンシー要件への対応と低レイテンシーアクセスを両立。

🛠️ 設定方法

前提条件

✓Asia Pacific (Seoul) リージョンへのアクセス権限を持つ AWS アカウント
✓P6-B300 インスタンスのサービスクォータが承認済みであること
✓EFA を使用する場合は、EFA 対応の AMI とセキュリティグループの設定が必要
✓適切な VPC とサブネットの構成

手順

1
サービスクォータの確認と申請
BashP6 系クォータの確認
aws service-quotas list-service-quotas \
  --service-code ec2 \
  --region ap-northeast-2 \
  --query "Quotas[?contains(QuotaName, 'P6')]"

Seoul リージョンにおける P6 系インスタンスの vCPU クォータを確認します。不足している場合は、Service Quotas コンソールまたは CLI からクォータの引き上げをリクエストしてください。

2
EFA 対応セキュリティグループの作成
Bashセキュリティグループの作成と設定
aws ec2 create-security-group \
  --group-name p6-b300-efa-sg \
  --description "Security group for P6-B300 with EFA" \
  --vpc-id vpc-xxxxxxxx \
  --region ap-northeast-2

aws ec2 authorize-security-group-ingress \
  --group-id sg-xxxxxxxx \
  --protocol -1 \
  --source-group sg-xxxxxxxx \
  --region ap-northeast-2

EFA を使用するためにセキュリティグループを作成し、同じセキュリティグループ内のインスタンス間での全トラフィックを許可します。

3
インスタンスの起動
BashEFA インターフェース付きで起動
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-xxxxxxxx \
  --key-name my-key-pair \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxxxxxxx,Groups=sg-xxxxxxxx,InterfaceType=efa" \
  --region ap-northeast-2

EFA ネットワークインターフェースを指定してインスタンスを起動します。AMI は NVIDIA ドライバーと EFA ドライバーがプリインストールされた Deep Learning AMI の使用を推奨します。

⚖️ メリット・制約事項

👍 メリット

ビジネス面

  • 低レイテンシーアクセス: 韓国およびアジア地域の組織が最高性能の GPU コンピューティングに低レイテンシーでアクセス可能
  • データレジデンシー対応: 韓国国内にデータを保持したまま AI ワークロードを実行し、規制・コンプライアンス要件に対応
  • リージョン選択の柔軟性: 4 リージョンから、コスト、レイテンシー、コンプライアンスに応じて最適な選択が可能

技術面

  • 大規模モデル対応: 2.1 TB GPU メモリで数兆パラメータ規模のモデルをメモリ内に保持
  • 高速分散トレーニング: EFA 6.4 Tbps でノード間通信のボトルネックを解消
  • 高スループット推論: ENA 300 Gbps で大量の推論リクエストを低レイテンシーで処理
⚠️ 制約事項・考慮点

制限事項

  • インスタンスサイズは p6-b300.48xlarge のみ。より小さなサイズは未提供
  • アジア太平洋地域では Seoul のみ。東京など他のアジアリージョンでは未提供
  • サービスクォータの引き上げが必要になる場合があり、承認まで時間がかかる可能性

考慮すべき点

  • 最上位クラスのため利用コストが高額。長期利用では購入オプションの検討が必要
  • Blackwell Ultra GPU のドライバーとソフトウェアスタック (CUDA、cuDNN、NCCL) の互換性を事前確認
  • EFA を最大限活用するにはクラスタープレースメントグループの設定など適切なネットワーク構成が不可欠

💡 ユースケース

1️⃣ 韓国国内での大規模基盤モデルのトレーニング

シナリオ: 韓国の AI 企業が、韓国語に特化した数兆パラメータ規模の基盤モデルを国内リージョンでトレーニング。学習データを国外に転送せず、データレジデンシー要件を満たす。

Bashクラスタープレースメントグループと分散トレーニング
# クラスタープレースメントグループの作成
aws ec2 create-placement-group \
  --group-name p6-b300-training-cluster \
  --strategy cluster \
  --region ap-northeast-2

# P6-B300 クラスターでの分散トレーニング起動
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --count 8 \
  --image-id ami-deep-learning-base \
  --placement "GroupName=p6-b300-training-cluster" \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=sg-xxx,InterfaceType=efa" \
  --region ap-northeast-2

効果: 8 ノード x 8 GPU = 64 GPU で合計 16.8 TB の GPU メモリを活用。EFA 6.4 Tbps のノード間通信により、データ並列・モデル並列の双方で高いスケーリング効率を実現しつつ、データを韓国国内に保持。

2️⃣ アジア太平洋地域向け LLM 推論サービング

シナリオ: 大規模 LLM を本番環境にデプロイし、韓国および近隣アジア地域のエンドユーザーにリアルタイムの推論サービスを低レイテンシーで提供。

Bash推論用インスタンスの起動
aws ec2 run-instances \
  --instance-type p6-b300.48xlarge \
  --image-id ami-deep-learning-inference \
  --network-interfaces "DeviceIndex=0,SubnetId=subnet-xxx,Groups=sg-xxx,InterfaceType=efa" \
  --region ap-northeast-2 \
  --tag-specifications "ResourceType=instance,Tags=[{Key=Purpose,Value=LLM-Inference}]"

効果: 2.1 TB の GPU メモリにより超大規模モデルを単一インスタンスにロードして推論可能。300 Gbps の ENA スループットで大量リクエストを高スループット処理し、米国リージョン提供と比較してアジアのエンドユーザーへの応答レイテンシーを大幅に削減。

3️⃣ 日米韓にまたがるグローバル AI プラットフォーム

シナリオ: グローバル企業が US West (Oregon)、US East (N. Virginia)、Asia Pacific (Seoul) の各リージョンで P6-B300 を使用し、地理的な冗長性を持つ AI プラットフォームを構築。

効果: 複数リージョンにわたるワークロード分散により、リージョン障害時のフェイルオーバーやピーク時の負荷分散が可能。エンドユーザーの地理的位置に基づいたルーティングでグローバル全体のレイテンシーを最適化。

🔗 関連サービス・機能

🎯 まとめ

Amazon EC2 P6-B300 インスタンスが Asia Pacific (Seoul) リージョンで利用可能になり、 アジア太平洋地域で初めて提供されるリージョンとなりました。 8 基の NVIDIA Blackwell Ultra GPU、2.1 TB の GPU メモリ、6.4 Tbps の EFA ネットワーキングを搭載した P6-B300 は、 数兆パラメータ規模の基盤モデルのトレーニングやデプロイに最適です。

韓国国内でのデータ処理が求められる組織や、アジアのエンドユーザーに低レイテンシーで AI サービスを提供したい組織は、 Seoul リージョンでの P6-B300 利用を検討することを推奨します。
