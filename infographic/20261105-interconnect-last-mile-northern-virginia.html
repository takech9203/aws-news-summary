📝 概要

AWS は、フルマネージドなラストマイル接続サービスAWS Interconnect - last mile の新メトロとして Northern Virginia, USA の提供を発表しました。クロスコネクトの発注やルーターの設定なしに、マネージドでプライベートかつ高耐障害性の接続を AWS へ確立できます。

すべての接続は物理的に分離された 2 つのロケーションと 4 つの冗長リンクにまたがってデフォルトでプロビジョニングされ、Direct Connect ポートまで 99.99% の可用性 SLA が適用されます。AWS とパートナーのエッジデバイス間のトラフィックは、デフォルトで MACsec により暗号化されます。

Lumen のお客様は米国本土のどこからでも GA の接続を発注でき、中国リージョンを除くすべてのパブリック AWS リージョンおよび AWS Local Zones へ到達できます。

❌ Before: アップデート前の課題
  • Lumen 経由の GA 接続で利用できるメトロが New York のみで、接続経路の選択肢が限られていた
  • us-east-1 周辺に拠点やワークロードを持つお客様も、地理的に離れたメトロを経由する必要があった
  • メトロの選択肢が少なく、メトロ単位での経路分散や冗長構成の設計自由度が限られていた
✅ After: アップデート後の改善
  • 2 番目のメトロとして Northern Virginia が追加され、接続経路の選択肢が拡大
  • Lumen のお客様は米国本土のどこからでも GA 接続を発注し、中国を除く全パブリックリージョンと Local Zones へ到達可能に
  • 同一メトロで Megaport と Equinix のプレビュー接続も利用でき、パートナーの選択肢が拡大

米国本土のお客様拠点から Northern Virginia メトロのパートナー (Lumen は GA、Megaport と Equinix はプレビュー) を経由して AWS Interconnect - last mile に接続し、Direct Connect Gateway を介して中国を除くすべてのパブリック AWS リージョンおよび AWS Local Zones へ到達する構成です。すべての接続は 2 つの物理的に分離されたロケーションと 4 つの冗長リンクでプロビジョニングされます。

⚡ 主要機能

📍 Northern Virginia メトロの追加

New York に続く 2 番目のメトロとして利用可能に。データセンター、支社、コロケーション施設から AWS へのプライベート接続の経路として選択できます。メトロはパートナーのネットワークと AWS の相互接続地点であり、料金ティアの算出基準にもなります。

📡 Lumen 経由の GA 接続

米国本土のどこからでも Northern Virginia メトロ経由で GA の接続を発注できます。中国リージョンを除くすべてのパブリック AWS リージョンと AWS Local Zones へ到達可能。接続は AWS Management Console、AWS CLI、AWS Interconnect API から作成できます。

🧪 Megaport と Equinix 経由のプレビュー接続

2026 年 10 月の Megaport プレビュー、2026 年 11 月 4 日の Equinix プレビュー発表に続き、同一メトロで複数パートナーを選択できる体制が整いました。

🛡️ デフォルトでの高耐障害性とセキュリティ

物理的に分離された 2 ロケーションと 4 冗長リンクで標準プロビジョニング。Direct Connect ポートまで 99.99% の可用性 SLA が適用され、AWS とパートナーのエッジデバイス間はデフォルトで MACsec 暗号化されます。

項目詳細
ティア数Tier 1 (最安) 〜 Tier 5 (最高) の 5 段階

Northern Virginia メトロは us-east-1 に近接しているため、接続先リージョンが us-east-1 のみであれば低いティアで利用できる可能性があります。ただし、Cloud WAN 構成では最も遠い CNE がティアに反映される点に注意が必要です。

🛠️ 設定方法

前提条件

✓Direct Connect Gateway が作成済みであること
✓パートナー (Lumen、Megaport、Equinix のいずれか) のサブスクライバー ID またはプロジェクト ID を保有していること
✓接続元拠点がパートナーのネットワークフットプリントでカバーされていること (Lumen GA の場合は米国本土)

手順

  1. Interconnect の作成 AWS Management Console、AWS CLI、AWS Interconnect API のいずれかで、希望する AWS リージョン、帯域速度、Direct Connect Gateway、パートナー情報を指定し、メトロとして Northern Virginia を選択して Interconnect を作成します。AWS が接続に必要な構成を準備します。
  2. パートナー側でのプロビジョニング完了 接続を開始すると AWS がアクティベーションキーを生成します。このキーをパートナーのポータルに入力することで、パートナー側のプロビジョニングが完了し、拠点から AWS への接続が確立されます。
  3. 接続の確認 BGP ピアリング、VLAN 設定、ASN 割り当てなどのネットワーク構成は自動化されるため、プロビジョニング完了後に Direct Connect Gateway を介した接続先リージョンへの疎通を確認します。

💡 メリット

ビジネス面

✓接続経路の選択肢拡大: New York に加えて Northern Virginia メトロを選択でき、拠点の立地や接続先リージョンに応じた最適な経路を選べる
✓コスト最適化の可能性: 料金ティアはメトロと最も遠い接続先リージョンの距離で決まるため、us-east-1 中心のお客様は近接メトロの選択でコストを抑えられる可能性がある
✓広域からの発注: Lumen のお客様は米国本土のどこからでも GA の接続を発注でき、拠点の所在地にかかわらず利用しやすい

技術面

✓デフォルトの高耐障害性: 2 ロケーション・4 冗長リンクの構成が標準で提供され、追加の冗長設計が不要
✓Direct Connect ポートまでの SLA: 99.99% の可用性 SLA が適用され、エンドツーエンドに近い品質保証が得られる
✓デフォルトの MACsec 暗号化: AWS とパートナーのエッジデバイス間が追加設定なしで暗号化される

⚠️ デメリット・制約事項

制限事項

✗GA の接続は現時点で Lumen 経由に限られ、Megaport と Equinix はプレビュー段階である
✗Lumen の GA 接続は米国本土のお客様が対象であり、日本を含む米国外の拠点からは利用できない
✗中国リージョンは接続先の対象外である

考慮すべき点

⚠️料金ティアは Direct Connect Gateway に接続された最も遠い AWS リージョンで決まるため、遠方リージョンや Cloud WAN の CNE を追加するとティアが上がる可能性がある
⚠️プレビューパートナー (Megaport、Equinix) を利用する場合は、本番適用前に提供条件や SLA を確認する必要がある

🎯 ユースケース

1. us-east-1 を中心としたハイブリッド接続のコスト最適化

シナリオ: 米国東海岸にデータセンターを持つ企業が、us-east-1 のワークロードと接続するハイブリッド構成を運用したい。

効果: Northern Virginia メトロは us-east-1 に近接しているため、低い料金ティアでの接続が期待でき、GB あたりのデータ転送料金なしの時間課金でコストを予測しやすくなります。

2. メトロ分散による接続経路の冗長化

シナリオ: ミッションクリティカルなワークロードのため、単一メトロの障害にも耐えられる接続構成を設計したい。

効果: New York メトロと Northern Virginia メトロの両方で Interconnect を作成することで、各接続が持つ 2 ロケーション・4 リンクの冗長性に加え、メトロレベルでの地理的な経路分散を実現できます。

3. 複数パートナーの比較評価

シナリオ: ラストマイルパートナーの選定にあたり、同一メトロで複数パートナーのサービスを比較したい。

効果: Northern Virginia メトロでは Lumen (GA) に加えて Megaport と Equinix (いずれもプレビュー) が利用できるため、既存のパートナー契約や拠点カバレッジに応じた比較評価を単一メトロで実施できます。

💰 料金

Interconnect ごとに選択した帯域幅と自動割り当てされる料金ティア (Tier 1〜Tier 5) に基づく時間課金制で、GB あたりのデータ転送料金は発生しません。課金は Interconnect の作成時に開始し、削除時に終了します (1 時間単位で切り上げ)。料金ティアは、Interconnect メトロと Direct Connect Gateway に接続された最も遠い AWS リージョンとの地理的距離に基づいて決定されます。

🔗 関連サービス・機能

AWS Direct Connect

専用ネットワーク接続を提供するサービス。AWS Interconnect - last mile の SLA は Direct Connect ポートまで適用されます。

AWS Direct Connect Gateway

複数の VPC やリージョンへの接続を集約するゲートウェイ。接続作成時に指定し、接続された最も遠いリージョンが料金ティアの算出に使用されます。

AWS Cloud WAN

グローバルネットワークを構築するサービス。CNE の配置が料金ティアに影響します。

AWS Interconnect - multicloud

他クラウドプロバイダーとのプライベート接続を提供する姉妹機能です。

📌 まとめ

AWS Interconnect - last mile の Northern Virginia メトロ追加により、New York に続く 2 番目のメトロとして、Lumen 経由の GA 接続と Megaport および Equinix 経由のプレビュー接続が利用可能になりました。us-east-1 に近接したメトロの追加は、料金ティアの最適化やメトロレベルでの経路分散の観点で有用です。米国に拠点を持ち AWS へのプライベート接続を検討しているお客様は、拠点の立地と接続先リージョンに応じて New York と Northern Virginia のメトロを比較し、最適な構成を評価することを推奨します。
