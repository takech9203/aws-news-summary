📋 Overview

Amazon Bedrock AgentCore Runtime が Agent-User Interaction (AG-UI) Protocol Support to be added. AG-UI is an open event-based protocol that standardizes communication between AI Agents and user interfaces, enabling developers to build responsive, real-time agent experiences into user-facing applications.

AgentCore Runtime already supports MCP and A2A, and with this AG-UI support, it now covers all 3 major agent communication protocols.

🚀 Deployment Configuration

Set serverProtocol to AGUI in protocolConfiguration to create an AG-UI enabled runtime.

Python Create AgentCore Runtime with AG-UI 
import boto3

client = boto3.client('bedrock-agentcore-control')

# Create AgentCore Runtime with AG-UI protocol
response = client.create_agent_runtime(
    agentRuntimeName='my-agui-server',
    agentRuntimeArtifact={
        'containerConfiguration': {
            'containerUri': '123456789012.dkr.ecr.us-east-1.amazonaws.com/my-agui-server:latest'
        }
    },
    roleArn='arn:aws:iam::123456789012:role/AgentCoreRuntimeRole',
    protocolConfiguration={
        'serverProtocol': 'AGUI'
    },
    networkConfiguration={
        'networkMode': 'PUBLIC'
    }
)

Step 1: Implement AG-UI Server

Python AG-UI Server Implementation 
from agui import AGUIServer, Event

server = AGUIServer("my-agent-ui")

@server.on_message
async def handle_message(message: str, session):
    # Stream text chunks
    async for chunk in agent.generate_response(message):
        await session.emit(Event.text_chunk(chunk))

    # Visualize tool execution results
    tool_result = await agent.execute_tool("search", query=message)
    await session.emit(Event.tool_result(
        tool_name="search",
        result=tool_result
    ))

    # State sync
    await session.emit(Event.state_update(
        progress=100,
        status="completed"
    ))

Step 3: Connect from Frontend

JavaScript AG-UI Client Connection 
import { AGUIClient } from '@ag-ui/client';

const client = new AGUIClient({
  endpoint: 'https://<runtime-endpoint>/agui',
  transport: 'sse' // or 'websocket'
});

// Receive text streaming
client.on('text_chunk', (chunk) => {
  appendToChat(chunk.content);
});

// Receive tool execution results
client.on('tool_result', (result) => {
  renderToolAction(result.tool_name, result.result);
});

// Receive state updates
client.on('state_update', (state) => {
  updateProgressBar(state.progress);
});

// Send message
await client.send('Analyze the sales data');

⚠️ Limitations and Considerations

Limitations

📌 AG-UI is a relatively new protocol; client library and framework ecosystem may still be maturing
📌 Network environment and proxy constraints must be considered when choosing between SSE and WebSocket
📌 Client-side event handling and error handling implementation required due to real-time streaming nature

Considerations

💡 If already using MCP or A2A with AgentCore Runtime, AG-UI server must be created separately
💡 Choose WebSocket for bidirectional communication needs, SSE for unidirectional streaming

@server.on_message
async def analyze_data(query: str, session):
    await session.emit(Event.state_update(progress=10, status="Fetching data"))
    data = await fetch_data(query)

    await session.emit(Event.state_update(progress=50, status="Running analysis"))
    analysis = await run_analysis(data)

    # Send chart data
    await session.emit(Event.state_update(
        progress=90, chart_data=analysis.to_chart()
    ))

    async for chunk in summarize(analysis):
        await session.emit(Event.text_chunk(chunk))

    await session.emit(Event.state_update(progress=100, status="Complete"))
Effect: Display analysis progress via progress bar and reflect chart data to the dashboard in real-time.
🤝 Multi-Agent Collaborative Workflow
Multiple agents collaborate via A2A to process tasks, with progress and results displayed to users in real-time via AG-UI.
Python Multi-Agent Example 
@server.on_message
async def multi_agent_task(request: str, session):
    # Delegate to research agent via A2A
    await session.emit(Event.reasoning_step("Delegating research to research agent..."))
    research = await a2a_client.delegate("research-agent", request)
    await session.emit(Event.tool_result("research_agent", research))

    # Delegate to writing agent via A2A
    await session.emit(Event.reasoning_step("Delegating writing to writing agent..."))
    async for chunk in a2a_client.stream("writing-agent", research):
        await session.emit(Event.text_chunk(chunk))
Effect: Visualize the multi-agent collaboration process to users, transparently showing each agent's role and deliverables.
