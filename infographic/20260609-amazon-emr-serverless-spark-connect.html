Spark Connect でインタラクティブ開発

Amazon EMR Serverless Spark Connect EMR リリース 7.13
📅 2026 年 6 月 9 日

📌 概要

Amazon EMR Serverless が Spark Connect を利用したインタラクティブセッションに対応しました。SageMaker Unified Studio のマネージドノートブックに加えて、Jupyter や Visual Studio Code などの使い慣れた IDE / ノートブックから、Apache Spark アプリケーションを開発・実行できます。

Spark Connect のクライアントサーバーアーキテクチャにより、アプリケーションクライアントを Spark ドライバーから分離。Spark インフラを独立して実行しながら、使い慣れたツールをそのまま利用できます。セルやスクリプトをまたいで持続する Spark コンテキストにより、ローカルの Python 実行とリモートの Spark 処理を 1 つの環境で扱えます。

対象は Spark を用いたデータ分析や ETL 開発を行うデータエンジニア、データサイエンティスト、データアナリストです。本機能は EMR リリース 7.13 で利用可能です。

😟 アップデート前の課題
  • 使い慣れた Jupyter / VS Code などのローカル IDE から EMR Serverless の Spark コンテキストへ直接接続する手段が限られていた
  • 個々のセッション単位での詳細なコストや使用状況の可視化が難しかった
  • アクティブ / 完了したセッションを EMR コンソール上で一元的に監視・デバッグする仕組みがなかった
🎉 アップデート後の改善
  • SageMaker Unified Studio に加え、Jupyter / VS Code など好みの IDE から Spark アプリを開発・実行できる
  • 個々のセッション単位で詳細なコストと使用状況を可視化できる
  • Spark UI / Spark History Server / EMR コンソール・API・CLI・SDK でセッションを監視・デバッグ・管理できる

✨ 主要機能

🔌 Spark Connect によるインタラクティブセッション
  • クライアントサーバーアーキテクチャでアプリケーションクライアントを Spark ドライバーから分離
  • セルやスクリプトをまたいで持続する Spark コンテキストを提供
  • ローカルの Python 実行とリモートの Spark 処理を 1 つの環境で組み合わせて実行
📔 複数のノートブック環境および IDE のサポート
  • Amazon SageMaker Unified Studio のマネージドノートブック
  • Jupyter
  • Visual Studio Code をはじめとする好みの IDE / ノートブック環境
🔍 セッションのオブザーバビリティと管理
  • Spark UI によるリアルタイムのセッション監視
  • Spark History Server による履歴追跡
  • EMR コンソール / API / CLI / SDK によるセッション管理
  • アクティブ / 完了したセッションを EMR コンソールで監視・デバッグ
💰 セッション単位のコストと使用状況の可視化

⚙️ 設定方法

前提条件

  • EMR リリース 7.13 に対応した EMR Serverless アプリケーションを利用できること
  • EMR Serverless へのアクセスに必要な基本的な IAM 権限が設定されていること
  • 接続するクライアント (SageMaker Unified Studio、Jupyter、VS Code など) が準備されていること
  • インタラクティブワークロードを実行するための十分な vCPU サービスクォータが確保されていること

Bashステップ 1: EMR Serverless アプリケーションを作成
aws emr-serverless create-application \
  --release-label emr-7.13.0 \
  --type SPARK \
  --name interactive-spark-connect-app

EMR リリース 7.13 を指定して Spark タイプのアプリケーションを作成します。

Bashステップ 2: アプリケーションを事前起動
aws emr-serverless start-application \
  --application-id <your-application-id>

事前に起動しておくことで、セッション接続時にすぐ利用できます。事前初期化容量を構成すると起動待ち時間を短縮できます。

ステップ 3: クライアントから Spark Connect で接続

SageMaker Unified Studio のマネージドノートブック、または Jupyter / VS Code から Spark Connect 経由で EMR Serverless 上の Spark コンテキストに接続します。接続後はセルやスクリプトをまたいで持続する Spark コンテキスト上で、アドホックなデータ探索や段階的な PySpark ジョブ開発を行えます。

👍 メリット

💼 ビジネス面

  • 開発生産性の向上: 使い慣れた IDE から直接 Spark を扱え、開発からデバッグの反復サイクルを高速化
  • コスト管理の精緻化: セッション単位の可視化で、チーム / プロジェクトごとの費用配賦や最適化が容易
  • 運用負荷の低減: サーバーレスでクラスター管理なしにインタラクティブ分析環境を提供

🛠️ 技術面

  • クライアントとドライバーの分離: クライアント環境と Spark インフラを独立して扱える
  • 持続的な Spark コンテキスト: 状態を保持し、ローカル Python とリモート Spark を組み合わせて開発
  • 充実したオブザーバビリティ: Spark UI / History Server / EMR コンソールでリアルタイム監視と履歴追跡を両立

⚠️ デメリット・制約事項

制限事項

  • 本機能の利用には EMR リリース 7.13 が必要
  • SageMaker Unified Studio の体験はサポートされるリージョンに限定
  • インタラクティブワークロードの実行には十分な vCPU サービスクォータが必要

考慮すべき点

  • 持続的な Spark コンテキストを維持するため、アイドル時の自動停止設定やコスト管理を適切に行う必要がある
  • 最適な起動体験には、ドライバー / エグゼキューターの事前初期化容量の構成とアプリの事前起動を検討

🎯 ユースケース

1. アドホックなデータ探索

シナリオ: データアナリストが Amazon S3 上の大規模データセットを Jupyter ノートブックから対話的に探索したい。

実装例: Jupyter ノートブックから Spark Connect で EMR Serverless に接続し、データの読み込み・集計・可視化を反復的に実行する。

💡 効果: クラスター管理を意識せず、使い慣れた環境から大規模データを探索でき、分析の試行錯誤を高速化できる。
2. 段階的な PySpark ジョブ開発

シナリオ: データエンジニアが本番デプロイ前に PySpark の ETL ジョブを段階的に開発・検証したい。

実装例: Visual Studio Code から Spark Connect で接続し、処理ロジックをセル単位で実装・実行しながら段階的に組み立てる。

💡 効果: 持続的な Spark コンテキスト上でステップバイステップの検証ができ、本番ジョブの品質を高めながら開発期間を短縮できる。
3. 反復的なデバッグとチューニング

シナリオ: 既存の Spark 処理のパフォーマンス問題を切り分けてチューニングしたい。

実装例: SageMaker Unified Studio のマネージドノートブックから接続し、Spark UI でリアルタイムに実行状況を確認しながら処理を調整する。

💡 効果: Spark UI と Spark History Server による可視化を活用して、ボトルネックを特定し効率的にチューニングできる。

💵 料金

Spark Connect によるインタラクティブセッションの利用に対する追加料金はなし。EMR Serverless の標準的な従量課金体系に基づき、実行に使用した vCPU、メモリ、ストレージなどのリソースに応じて課金されます。

本アップデートにより、個々のセッション単位で詳細なコストと使用状況を可視化できるため、費用の把握と最適化が容易になります。最新かつ正確な料金は公式の料金ページを参照してください。

🌍 利用可能リージョン

Amazon EMR Serverless 上の Spark Connect は EMR リリース 7.13 で、Amazon EMR Serverless が利用可能なすべての AWS リージョンで提供されます。

ただし、SageMaker Unified Studio の体験はサポートされるリージョンに限定されます。

本アップデートにより、使い慣れた IDE やノートブックから Spark Connect を介して EMR Serverless のインタラクティブセッションを利用でき、アドホックなデータ探索から段階的な PySpark ジョブ開発まで一貫して行えます。
