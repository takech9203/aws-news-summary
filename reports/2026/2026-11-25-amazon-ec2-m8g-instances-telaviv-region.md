# Amazon EC2 - M8g インスタンスがイスラエル (テルアビブ) リージョンで利用可能に

**リリース日**: 2026 年 11 月 25 日
**サービス**: Amazon EC2
**機能**: AWS Graviton4 ベースの汎用インスタンス M8g のリージョン拡大

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/aws-news-summary/20261125-amazon-ec2-m8g-instances-telaviv-region.html)

## 概要

AWS Graviton4 プロセッサを搭載した汎用インスタンス Amazon EC2 M8g が、イスラエル (テルアビブ) リージョンで利用可能になりました。M8g インスタンスは、アプリケーションサーバー、マイクロサービス、ゲームサーバー、中規模のデータストア、キャッシュフリートなどの汎用ワークロード向けに設計されています。

Graviton4 プロセッサは、Graviton3 ベースのインスタンスと比較して最大 30% 高いパフォーマンスを提供します。前世代の M7g インスタンスと比較すると、データベースで最大 40%、Web アプリケーションで最大 30%、大規模な Java アプリケーションで最大 45% 高速に動作します。また、M7g と比較して最大 3 倍の vCPU とメモリを持つ大型サイズが提供されます。

**アップデート前の課題**

- イスラエル (テルアビブ) リージョンでは Graviton4 ベースの M8g インスタンスを利用できず、最新世代の価格性能比の恩恵を受けられなかった
- 同リージョンで大規模な汎用ワークロードを Graviton で実行する場合、前世代インスタンスのサイズ上限が制約となる可能性があった
- データレジデンシー要件によりイスラエル国内でワークロードを実行する必要がある場合、他リージョンの M8g を選択できなかった

**アップデート後の改善**

- イスラエル (テルアビブ) リージョンで Graviton4 ベースの M8g インスタンスを起動できるようになった
- 最大 192 vCPU / 768 GiB メモリの大型サイズ (48xlarge、metal-48xl) まで選択肢が広がった
- Savings Plans、オンデマンド、スポットインスタンス、Dedicated Instances、Dedicated Hosts の各購入オプションで利用できるようになった

## サービスアップデートの詳細

### 主要機能

1. **AWS Graviton4 プロセッサ**
   - AWS が設計した最新世代の Arm ベースプロセッサ
   - Graviton3 ベースのインスタンスと比較して最大 30% 高いコンピューティングパフォーマンス
   - M7g 比でデータベースは最大 40%、Web アプリケーションは最大 30%、大規模 Java アプリケーションは最大 45% 高速

2. **より大きなインスタンスサイズ**
   - M7g と比較して最大 3 倍の vCPU とメモリを提供
   - 最大サイズは 192 vCPU / 768 GiB メモリ (m8g.48xlarge、m8g.metal-48xl)
   - ベアメタルサイズ (metal-24xl、metal-48xl) も提供

3. **AWS Nitro System**
   - CPU の仮想化、ストレージ、ネットワーキングの機能を専用のハードウェアとソフトウェアにオフロード
   - ワークロードのパフォーマンスとセキュリティを向上
   - 常時オンのメモリ暗号化、vCPU ごとの専用キャッシュ、ポインタ認証などのセキュリティ機能

## 設定方法

### 前提条件

1. イスラエル (テルアビブ) リージョン (il-central-1) が AWS アカウントで有効化されていること
2. ワークロードが Arm (aarch64) アーキテクチャに対応していること
3. Arm 対応の AMI (Amazon Linux 2023、Ubuntu など) を準備していること

### 手順

#### ステップ 1: リージョンで利用可能な M8g サイズを確認

```bash
aws ec2 describe-instance-type-offerings \
  --region il-central-1 \
  --filters "Name=instance-type,Values=m8g.*" \
  --query "InstanceTypeOfferings[].InstanceType" \
  --output table
```

イスラエル (テルアビブ) リージョンで提供されている M8g インスタンスサイズの一覧を取得します。

#### ステップ 2: M8g インスタンスを起動

```bash
aws ec2 run-instances \
  --region il-central-1 \
  --instance-type m8g.xlarge \
  --image-id <Arm 対応 AMI の ID> \
  --key-name <キーペア名> \
  --subnet-id <サブネット ID>
```

指定したサブネットに m8g.xlarge インスタンスを起動します。AMI は必ず Arm64 アーキテクチャ用のものを指定します。

#### ステップ 3: 既存ワークロードの移行検証

x86 ベースのインスタンスから移行する場合は、アプリケーションやコンテナイメージを Arm64 向けにビルドし、性能テストを実施した上で段階的に切り替えます。移行のガイダンスとして AWS Graviton の Level up ページや AWS Graviton Technical Guide を参照してください。

## メリット

### ビジネス面

- **価格性能比の向上**: Graviton3 世代比で最大 30% の性能向上により、同等ワークロードのコスト効率が改善される
- **データレジデンシー対応**: イスラエル国内にデータを保持する要件があるワークロードでも最新世代インスタンスを利用できる
- **柔軟な購入オプション**: Savings Plans やスポットインスタンスを組み合わせてコストを最適化できる

### 技術面

- **ワークロード別の性能向上**: M7g 比でデータベース最大 40%、Web アプリケーション最大 30%、大規模 Java アプリケーション最大 45% の高速化
- **スケールアップ余地の拡大**: 最大 192 vCPU / 768 GiB メモリまで単一インスタンスでスケール可能
- **Nitro System によるセキュリティ**: 常時オンのメモリ暗号化など、ハードウェアレベルのセキュリティ機能を利用できる

## デメリット・制約事項

### 制限事項

- Arm (aarch64) アーキテクチャのため、x86 専用のバイナリやソフトウェアはそのままでは動作しない
- M8g は EBS のみのストレージ構成であり、ローカル NVMe SSD が必要な場合は M8gd などの別バリアントを検討する必要がある

### 考慮すべき点

- 商用ソフトウェアを利用している場合は、ベンダーの Arm 対応状況とライセンス条件を事前に確認する
- コンテナ環境ではマルチアーキテクチャイメージ (amd64 / arm64) のビルドパイプライン整備が必要になる場合がある

## ユースケース

### ユースケース 1: Web アプリケーション / マイクロサービスの基盤

**シナリオ**: イスラエル国内のユーザー向けに低レイテンシーで Web サービスを提供し、コスト効率も改善したい。

**実装例**:
```
Amazon EKS / ECS のノードグループに m8g.xlarge〜m8g.4xlarge を採用し、
arm64 対応のコンテナイメージをデプロイする
```

**効果**: M7g 比で Web アプリケーションが最大 30% 高速化され、少ないノード数で同等のスループットを達成できる。

### ユースケース 2: 中規模データストア・キャッシュフリート

**シナリオ**: セルフマネージドの PostgreSQL や Redis などをテルアビブリージョンで運用しており、性能向上とコスト削減を両立したい。

**実装例**:
```
データベースノードを m7g.8xlarge から m8g.8xlarge へ移行し、
負荷テストでスループットとレイテンシーを比較検証する
```

**効果**: データベースワークロードで最大 40% の高速化が見込まれ、インスタンス台数の削減余地が生まれる。

### ユースケース 3: 大規模 Java アプリケーション

**シナリオ**: Java ベースの業務アプリケーションやゲームサーバーを運用しており、ピーク時の処理能力を強化したい。

**実装例**:
```
Arm64 対応の JDK (Amazon Corretto など) を使用し、
m8g.12xlarge 以上のサイズで JVM ワークロードを実行する
```

**効果**: 大規模 Java アプリケーションで最大 45% の高速化が見込まれ、ピーク時の応答性能が改善する。

## 料金

M8g インスタンスは、イスラエル (テルアビブ) リージョンにおいて Savings Plans、オンデマンド、スポットインスタンス、Dedicated Instances、Dedicated Hosts で購入できます。リージョンおよびサイズごとの具体的な料金は、Amazon EC2 の料金ページを参照してください。

## 利用可能リージョン

今回の発表により、イスラエル (テルアビブ) リージョン (il-central-1) で M8g インスタンスが利用可能になりました。その他の提供リージョンは AWS 公式サイトの M8g インスタンスページで確認できます。

## 関連サービス・機能

- **AWS Graviton**: AWS が設計する Arm ベースプロセッサファミリー。M8g は第 4 世代の Graviton4 を搭載
- **AWS Nitro System**: 仮想化機能を専用ハードウェアにオフロードする基盤技術。M8g のパフォーマンスとセキュリティを支える
- **Amazon EBS**: M8g は EBS のみのストレージ構成であり、暗号化された EBS ボリュームをサポート
- **EC2 M8gd / M8gn インスタンス**: ローカル NVMe SSD 搭載 (M8gd) や高ネットワーク帯域 (M8gn) が必要な場合の選択肢
