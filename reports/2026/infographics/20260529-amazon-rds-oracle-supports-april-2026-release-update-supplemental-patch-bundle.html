📋 概要

Amazon RDS for Oracle が Oracle 2026 年 4 月 Release Update (RU) および Supplemental Patch Bundle (SPB) をサポート。RU にはセキュリティ更新、SPB には Oracle Spatial / Data Pump / GoldenGate 向けの追加パッチが含まれる。

名称変更のお知らせ

SPB は以前「Oracle Spatial Patch Bundle」と呼ばれていたが、2026 年 4 月リリースから「Supplemental Patch Bundle」に名称変更された。

Before - アップデート前
  • セキュリティパッチ適用に手動作業が必要
  • 以前の RU では最新脆弱性に未対応
  • 推奨パッチ未適用による安定性リスク
After - アップデート後
  • RDS コンソール / CLI で簡単にパッチ適用
  • SPB で推奨パッチを一括適用可能
  • 自動アップグレードで運用負荷軽減

⚡ 主要機能

🛡️ Release Update (RU)
  • - Oracle データベース製品向けセキュリティ更新
  • - Oracle 19c / 21c の両方で利用可能
  • - AWS は最新 RU へのアップグレードを推奨
📦 Supplemental Patch Bundle (SPB)
  • - Oracle Spatial / Data Pump / GoldenGate 向け追加パッチ
  • - Oracle 19c でのみ利用可能
  • - エンジンバージョン: 19.0.0.0.ru-2026-04.spb-1.r1
🔄 段階的ロールアウトポリシー
  • - AWS Organizations で自動アップグレードを段階適用
  • - 非本番環境で検証後に本番環境へ適用
  • - リスクを最小化するワークフローを実現

適用方法の選択

🖥️ RDS コンソール
💻 AWS CLI / SDK
🔄 自動アップグレード
Bash Release Update の適用 
aws rds modify-db-instance \
  --db-instance-identifier my-oracle-instance \
  --engine-version 19.0.0.0.ru-2026-04.r1 \
  --apply-immediately
Bash SPB の適用 (RU を含む) 
aws rds modify-db-instance \
  --db-instance-identifier my-oracle-instance \
  --engine-version 19.0.0.0.ru-2026-04.spb-1.r1 \
  --apply-immediately
Bash 自動マイナーバージョンアップグレード有効化 
aws rds modify-db-instance \
  --db-instance-identifier my-oracle-instance \
  --auto-minor-version-upgrade \
  --apply-immediately

⚠️ 制約事項・注意点

制限事項
  • ✗ SPB は Oracle 19c のみ (21c は非対応)
  • ✗ パッチ適用時にインスタンス再起動が必要
  • ✗ SPB の適用には RU が前提条件
推奨事項
  • → パッチ適用前にスナップショットを取得
  • → 段階的ロールアウトには AWS Organizations の設定が必要
  • → Multi-AZ 構成でダウンタイムを最小化
