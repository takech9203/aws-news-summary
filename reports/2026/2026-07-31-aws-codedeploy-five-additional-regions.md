# AWS CodeDeploy - 5 つの追加リージョンで利用可能に

**リリース日**: 2026 年 7 月 31 日
**サービス**: AWS CodeDeploy
**機能**: リージョン拡大 (アジアパシフィック 4 リージョンおよびメキシコ)

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/aws-news-summary/20260731-aws-codedeploy-five-additional-regions.html)

## 概要

AWS CodeDeploy が新たに 5 つの AWS リージョンで利用可能になりました。対象リージョンは、アジアパシフィック (ニュージーランド)、アジアパシフィック (タイ)、アジアパシフィック (台北)、アジアパシフィック (マレーシア)、メキシコ (中部) です。

AWS CodeDeploy は、Amazon EC2 インスタンス、オンプレミスサーバー、AWS Lambda 関数、Amazon ECS サービスへのアプリケーションデプロイを自動化するフルマネージド型のデプロイサービスです。手作業によるデプロイで発生しがちなエラーを排除し、単一インスタンスから数千インスタンスまでシームレスにスケールするため、EC2 フリート、サーバーレスの Lambda 関数、コンテナ化された ECS ワークロードにまたがる複雑なデプロイパイプラインを管理するチームに適しています。

今回の拡大により、AWS CodeDeploy は 34 の商用リージョンに加え、AWS GovCloud (US) および AWS 中国リージョンで利用可能になりました。

**アップデート前の課題**

- 上記 5 リージョンでは CodeDeploy を直接利用できず、デプロイ自動化のために他リージョンのリソースや代替手段を検討する必要があった
- リージョン外のサービスを利用する場合、レイテンシーやデータレジデンシー (データ所在地) の要件への対応が課題となっていた

**アップデート後の改善**

- 5 つの新リージョン内で CodeDeploy をローカルに利用でき、低レイテンシーでのデプロイ操作が可能になった
- デプロイ関連のデータをリージョン内に保持できるため、データレジデンシー要件への対応が容易になった
- 新リージョンでも他リージョンと同様に、EC2、オンプレミスサーバー、Lambda、ECS への自動デプロイとダウンタイム回避 (Blue/Green デプロイなど) を活用できるようになった

## サービスアップデートの詳細

### 追加されたリージョン

| リージョン名 | リージョンコード |
|--------------|------------------|
| アジアパシフィック (ニュージーランド) | ap-southeast-6 |
| アジアパシフィック (タイ) | ap-southeast-7 |
| アジアパシフィック (台北) | ap-east-2 |
| アジアパシフィック (マレーシア) | ap-southeast-5 |
| メキシコ (中部) | mx-central-1 |

### CodeDeploy の主要機能 (再掲)

1. **多様なデプロイターゲット**
   - Amazon EC2 インスタンス、オンプレミスサーバー、AWS Lambda 関数、Amazon ECS サービスへのデプロイを自動化

2. **ダウンタイムの回避**
   - In-place デプロイや Blue/Green デプロイにより、アプリケーション更新時のダウンタイムを回避しながら新機能を迅速にリリース可能

3. **スケーラビリティ**
   - 単一インスタンスから数千インスタンスまでシームレスにスケールし、手作業によるデプロイ操作のエラーを排除

## メリット

### ビジネス面

- **データレジデンシー対応**: デプロイ関連データをリージョン内に保持でき、各国の規制やコンプライアンス要件に対応しやすくなる
- **新リージョンでの CI/CD 整備**: 新興リージョンでワークロードを展開する際に、リリースプロセスの自動化を最初から組み込める

### 技術面

- **低レイテンシー**: リージョン内で CodeDeploy にアクセスできるため、デプロイ操作のレイテンシーが低減される
- **アーキテクチャの一貫性**: 既存リージョンと同じデプロイパイプライン構成を新リージョンにも展開でき、マルチリージョン運用の統一性が向上する

## 料金

AWS CodeDeploy は、AWS サービス (EC2、Lambda、ECS) へのデプロイは追加料金なしで利用できます。オンプレミスインスタンスへのデプロイは、更新 1 回あたり 0.02 USD が課金されます。詳細は[料金ページ](https://aws.amazon.com/codedeploy/pricing/)を参照してください。

## 利用可能リージョン

今回追加された 5 リージョン (アジアパシフィック (ニュージーランド)、アジアパシフィック (タイ)、アジアパシフィック (台北)、アジアパシフィック (マレーシア)、メキシコ (中部)) を含め、34 の AWS 商用リージョン、AWS GovCloud (US)、AWS 中国リージョンで利用可能です。

## 関連サービス・機能

- **AWS CodePipeline**: CodeDeploy と組み合わせて CI/CD パイプライン全体を構築できる継続的デリバリーサービス
- **Amazon EC2 / Amazon ECS / AWS Lambda**: CodeDeploy のデプロイターゲットとなるコンピューティングサービス
- **Amazon EC2 Auto Scaling**: Auto Scaling グループと統合し、スケールアウト時のインスタンスにも自動でアプリケーションをデプロイ可能

## まとめ

AWS CodeDeploy がアジアパシフィックの 4 リージョンとメキシコ (中部) に拡大し、これらの地域のユーザーは低レイテンシーかつデータレジデンシー要件に対応した形でデプロイ自動化を利用できるようになりました。対象リージョンでワークロードを運用している場合は、手動デプロイからの移行や既存 CI/CD パイプラインの新リージョン展開を検討することを推奨します。
