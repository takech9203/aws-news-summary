# Amazon FSx for Lustre - Intelligent-Tiering ストレージクラスのリージョン拡大

**サービス**: Amazon FSx for Lustre

## 概要

AWS は、Amazon FSx for Lustre の Intelligent-Tiering ストレージクラスを新たに 13 の AWS リージョンで利用可能にしました。これにより、より多くのリージョンのユーザーが、フルマネージドな完全エラスティック (弾力的) の Lustre ファイルストレージを利用できるようになります。

Intelligent-Tiering ストレージクラスは、クラウドにおける最も低コストで唯一の完全エラスティックな Lustre ファイルストレージとして位置付けられています。ホットデータとコールドデータが混在し、常に SSD レベルの速度を必要としないワークロードを対象としています。アクセスパターンに基づいて、データを Frequent Access (高頻度アクセス)、Infrequent Access (低頻度アクセス)、Archive (アーカイブ) の 3 つのティアに自動的に移動させることで、コストとパフォーマンスを両立します。

このアップデートにより、アフリカ、ヨーロッパ、アジアパシフィック、南米の各地域でこのストレージクラスが利用可能になり、データレジデンシー要件やレイテンシー要件を持つユーザーが、より身近なリージョンで HPC や AI/ML ワークロードを実行できるようになります。

**アップデート前の課題**

- 一部の AWS リージョンでは Intelligent-Tiering ストレージクラスが利用できず、対象リージョンのユーザーは従来の SSD ベースのストレージクラスを選択する必要があった
- データレジデンシー要件がある場合、特定のリージョンで完全エラスティックな Lustre ストレージを利用できなかった
- アクセス頻度の低いデータも SSD ストレージに保持する必要があり、コスト最適化が難しいケースがあった

**アップデート後の改善**

- 13 の追加リージョンで Intelligent-Tiering ストレージクラスが利用可能になり、より多くの地域でコスト最適化されたストレージを選択できるようになった
- 事前のキャパシティプロビジョニングが不要で、保存したデータ量に対してのみ課金されるエラスティックなモデルを幅広いリージョンで利用できるようになった
- アクセスパターンに応じた自動ティアリングにより、対象リージョンでもコールドデータのコストを大幅に削減できるようになった

## サービスアップデートの詳細

### 主要機能

1. **自動ティアリング**
   - データへのアクセスパターンに基づいて、Frequent Access、Infrequent Access、Archive の 3 つのティア間でデータを自動的に移動
   - アクセス頻度の高いデータは高速なティアに、アクセス頻度の低いデータは低コストなティアに配置
   - ユーザーによる手動でのデータ移動操作は不要

2. **オプションの SSD 読み取りキャッシュ**
   - アクティブなデータを SSD 読み取りキャッシュに保持することで高速なアクセスを実現
   - HPC や AI/ML ワークロードに対して高いパフォーマンスを提供しつつ、めったにアクセスされないデータは低コストで保管

3. **完全エラスティックなストレージ**
   - 事前にキャパシティをプロビジョニングする必要がなく、保存したデータ量に対してのみ課金
   - ストレージ容量の管理オーバーヘッドを削減

## 技術仕様

### Intelligent-Tiering の特性

| 項目 | 詳細 |
|------|------|
| ストレージティア | Frequent Access、Infrequent Access、Archive の 3 ティア |
| ティア移動 | アクセスパターンに基づき自動 |
| 読み取りキャッシュ | オプションの SSD 読み取りキャッシュを利用可能 |
| キャパシティ | 完全エラスティック (事前プロビジョニング不要) |
| 課金モデル | 保存したデータ量に対する従量課金 |
| 価格性能比 | オンプレミスの HDD ファイルストレージと比較して最大 34% 向上 |
| コスト削減 | めったにアクセスされないデータで、他のフルマネージドクラウドファイルストレージと比較して最大 96% のコスト削減 |

## メリット

### ビジネス面

- **コスト最適化**: アクセス頻度の低いデータを低コストのティアに自動配置することで、ストレージコストを大幅に削減
- **地理的な選択肢の拡大**: 13 の追加リージョンでの提供により、データレジデンシー要件やレイテンシー要件を満たしやすくなる
- **初期投資の削減**: 事前のキャパシティプロビジョニングが不要なため、予測が難しいワークロードでも無駄なコストを抑えられる

### 技術面

- **運用負荷の軽減**: ティア間のデータ移動が自動化されており、手動でのデータ管理が不要
- **パフォーマンスの確保**: オプションの SSD 読み取りキャッシュにより、HPC や AI/ML ワークロードに必要な高速アクセスを維持
- **スケーラビリティ**: 完全エラスティックなストレージにより、データ量の増減に応じて自動的にスケール

## デメリット・制約事項

### 制限事項

- 今回のアップデートは Intelligent-Tiering ストレージクラスのリージョン拡大であり、対象は記載された 13 リージョンに限られる
- 常に SSD レベルの一貫した低レイテンシーが求められるワークロードでは、SSD ベースのストレージクラスの方が適している場合がある

### 考慮すべき点

- アクセスパターンによってデータが配置されるティアが変わるため、コストやパフォーマンスはワークロードの特性に依存する
- 最新の対応リージョンは FSx for Lustre のリージョンテーブルで確認することが推奨される

## ユースケース

### ユースケース1: HPC ワークロードのデータ管理

**シナリオ**: 高性能計算 (HPC) のジョブで生成される大量の中間データと結果データを扱う。アクティブに処理しているデータは高速アクセスが必要だが、過去のジョブ結果はアクセス頻度が低い。

**効果**: アクティブなデータは SSD 読み取りキャッシュにより高速にアクセスでき、過去のデータは Archive ティアに自動移動してコストを削減できる。

### ユースケース2: AI/ML トレーニングデータセットの保管

**シナリオ**: 機械学習のトレーニングに使用する大規模なデータセットを保管する。一部のデータセットは頻繁に再利用されるが、多くは一度トレーニングに使用した後はアクセス頻度が低くなる。

**効果**: 頻繁に利用するデータセットは高速なティアで提供され、利用頻度の低いデータセットは低コストのティアに移動することで、全体のストレージコストを最適化できる。

### ユースケース3: 地理的要件を持つワークロードの展開

**シナリオ**: データレジデンシー要件により、特定の地域 (例: ヨーロッパやアジアパシフィック) でデータを保管する必要がある組織が、コスト効率の高い Lustre ストレージを必要としている。

**効果**: 今回追加されたリージョンで Intelligent-Tiering を利用することで、要件を満たしつつコスト最適化されたファイルストレージを利用できる。

## 料金

Intelligent-Tiering ストレージクラスは、事前のキャパシティプロビジョニングが不要で、保存したデータ量に対してのみ課金されます。オンプレミスの HDD ファイルストレージと比較して最大 34% の価格性能比の向上を実現し、めったにアクセスされないデータについては、他のフルマネージドなクラウドファイルストレージと比較して最大 96% のコスト削減が可能とされています。

正確な料金は、リージョンやアクセスパターンによって異なるため、Amazon FSx の料金ページで確認してください。
