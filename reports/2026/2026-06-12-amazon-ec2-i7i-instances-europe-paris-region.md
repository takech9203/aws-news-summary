# Amazon EC2 - I7i インスタンスが欧州 (パリ) リージョンで利用可能に

## 概要

AWS は、高性能なストレージ最適化インスタンスである Amazon EC2 I7i インスタンスを、AWS 欧州 (パリ) リージョンで利用可能にしたことを発表しました。I7i インスタンスは、第 5 世代 Intel Xeon プロセッサ (Emerald Rapids) を搭載し、全コアターボ周波数 3.2 GHz で動作します。前世代の I4i インスタンスと比較して、最大 23% 高いコンピューティング性能と 10% 以上優れた価格性能を提供します。

ストレージ面では、第 3 世代 AWS Nitro SSD を採用しており、最大 45TB の NVMe ストレージを利用できます。I4i インスタンスと比較して、最大 50% 優れたリアルタイムストレージ性能、最大 50% 低いストレージ I/O レイテンシー、最大 60% 低いストレージ I/O レイテンシーのばらつきを実現しています。

I7i インスタンスは、非常に高いランダム IOPS 性能とリアルタイムのレイテンシーを必要とする、I/O 集約型かつレイテンシーに敏感なワークロードに最適です。小規模から中規模のデータセットへのアクセスを伴うリレーショナルデータベースや NoSQL データベース、リアルタイム分析などのワークロードを対象としています。今回のパリリージョンでの提供開始により、欧州でデータレジデンシー要件を持つお客様も、これらの高性能インスタンスを利用できるようになりました。

**アップデート前の課題**

- 欧州 (パリ) リージョンでは、最新世代のストレージ最適化 I7i インスタンスを利用できず、前世代の I4i インスタンスなどを使用する必要がありました。
- パリリージョンでデータレジデンシー要件を持つお客様は、I7i の高いストレージ性能を活用できませんでした。
- I/O 集約型ワークロードにおいて、前世代インスタンスのストレージ I/O レイテンシーやそのばらつきがボトルネックとなる場合がありました。

**アップデート後の改善**

- 欧州 (パリ) リージョンで I7i インスタンスを利用できるようになり、最新世代のストレージ性能を活用できます。
- 前世代の I4i と比較して、最大 23% 高いコンピューティング性能と 10% 以上優れた価格性能を享受できます。
- Torn Write Prevention 機能により、最大 16KB のブロックサイズに対応し、データベースの性能ボトルネックを解消できます。

## サービスアップデートの詳細

### 主要機能

1. **第 5 世代 Intel Xeon プロセッサ**
   - Intel Xeon Scalable プロセッサ (Emerald Rapids) を搭載し、全コアターボ周波数 3.2 GHz で動作します。
   - 前世代 I4i インスタンスと比較して、最大 23% 高いコンピューティング性能を提供します。
   - DDR5 メモリおよび Intel Total Memory Encryption (TME) に対応しています。

2. **第 3 世代 AWS Nitro SSD ストレージ**
   - 最大 45TB の NVMe ストレージを提供します。
   - 常時有効な AES-256 暗号化に対応しています。
   - I4i と比較して、最大 50% 優れたリアルタイムストレージ性能、最大 50% 低い I/O レイテンシー、最大 60% 低いレイテンシーのばらつきを実現します。

3. **Torn Write Prevention (TWP)**
   - 最大 16KB のブロックサイズの書き込みアトミシティをサポートします。
   - データベースのダブルライトバッファを不要にし、性能ボトルネックを解消します。

4. **高いネットワークおよび EBS 帯域幅**
   - 最大 100Gbps のネットワーク帯域幅を提供します。
   - 最大 60Gbps の Amazon Elastic Block Store (EBS) 帯域幅を提供します。

## 設定方法

### 前提条件

1. AWS 欧州 (パリ) リージョン (eu-west-3) を利用できる AWS アカウント。
2. I7i インスタンスを起動するための EC2 関連の IAM 権限。
3. 適切な VPC、サブネット、セキュリティグループの構成。

### 手順

#### ステップ1: 利用可能なインスタンスタイプの確認

```bash
aws ec2 describe-instance-type-offerings \
  --location-type availability-zone \
  --filters "Name=instance-type,Values=i7i.*" \
  --region eu-west-3
```

このコマンドは、欧州 (パリ) リージョンで利用可能な I7i インスタンスタイプの一覧をアベイラビリティーゾーン単位で確認します。

#### ステップ2: I7i インスタンスの起動

```bash
aws ec2 run-instances \
  --image-id ami-xxxxxxxxxxxxxxxxx \
  --instance-type i7i.4xlarge \
  --key-name my-key-pair \
  --region eu-west-3
```

このコマンドは、欧州 (パリ) リージョンで i7i.4xlarge インスタンスを起動します。実際の利用時には、適切な AMI ID、キーペア、サブネット、セキュリティグループを指定してください。

#### ステップ3: ローカル NVMe ストレージの準備

起動後、インスタンスストアボリュームはマウントされていない状態のため、ファイルシステムの作成とマウントを行います。データベースや分析エンジンのデータ配置先として、低レイテンシーのローカル NVMe ストレージを活用できます。

## メリット

### ビジネス面

- **価格性能の向上**: 前世代 I4i と比較して 10% 以上優れた価格性能により、同等のワークロードをより低コストで実行できます。
- **データレジデンシー対応**: 欧州 (パリ) リージョンでの提供により、欧州内でのデータ保管要件を満たしつつ高性能インスタンスを利用できます。
- **SLA の達成**: 高スループットと低レイテンシーの組み合わせにより、厳格なサービスレベル契約を持つアプリケーションに適しています。

### 技術面

- **高いストレージ性能**: 最大 45TB の NVMe ストレージと最大 50% 低い I/O レイテンシーにより、I/O 集約型ワークロードを高速化できます。
- **データベース性能の改善**: Torn Write Prevention によりダブルライトバッファが不要になり、最大 30% のデータベース性能向上が見込めます。
- **柔軟なサイズ選択**: 仮想サイズに加えてベアメタルサイズも提供され、ライセンス要件やハードウェアレベルのアクセスにも対応できます。

## デメリット・制約事項

### 制限事項

- インスタンスストア (ローカル NVMe) は揮発性ストレージのため、インスタンスの停止や終了時にデータが失われます。永続化が必要なデータは EBS や S3 などに保存する必要があります。
- DSA、IAA、QAT アクセラレーターはベアメタルインスタンスでのみ利用可能です。
- EFA は 48xlarge および metal-48xl サイズでのみサポートされます。

### 考慮すべき点

- ローカルストレージを前提とするため、ワークロードのデータ永続化戦略を検討する必要があります。
- I7i は I/O 集約型ワークロード向けに最適化されており、CPU やメモリ中心のワークロードには他のインスタンスファミリーの方が適している場合があります。

## ユースケース

### ユースケース1: 高性能リレーショナルデータベース

**シナリオ**: 欧州内でデータを保管する必要がある MySQL や PostgreSQL、SQL Server などのデータベースを、低レイテンシーかつ高 IOPS で運用したいケース。

**効果**: ローカル NVMe ストレージと Torn Write Prevention により、書き込み性能のボトルネックを解消し、トランザクション処理を高速化できます。

### ユースケース2: NoSQL データベースとリアルタイム分析

**シナリオ**: Cassandra、MongoDB、Redis、ScyllaDB などの NoSQL データベースや、Spark、Kafka、Splunk などのリアルタイム分析基盤を運用するケース。

**効果**: 高いランダム IOPS とリアルタイムのレイテンシーにより、大量のデータストリームを安定して処理できます。

### ユースケース3: 検索エンジンとインデックス処理

**シナリオ**: Elasticsearch や OpenSearch などの検索エンジン、インデックス処理、AI/LLM トレーニングの前処理を実行するケース。

**効果**: 大規模なデータセットへの高速アクセスにより、インデックス構築やクエリ応答時間を短縮できます。

## 関連サービス・機能

- **Amazon EBS**: I7i インスタンスは最大 60Gbps の EBS 帯域幅を提供し、永続データの保存先として利用できます。
- **AWS Nitro System**: 第 3 世代 AWS Nitro SSD によって高いストレージ性能とセキュリティを実現しています。
- **Elastic Fabric Adapter (EFA)**: 48xlarge および metal-48xl サイズで、高性能なネットワーク通信に対応します。
