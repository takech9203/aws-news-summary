# Amazon Connect Customer - エージェントワークスペースの 2 つの新レイアウト

**リリース日**: 2026 年 10 月 21 日
**サービス**: Amazon Connect Customer
**機能**: エージェントワークスペースの新レイアウト (Modern / Classic)

📊 [このアップデートのインフォグラフィックを見る](https://takech9203.github.io/aws-news-summary/20261021-connect-customer-new-layouts-agent-workspace.html)

## 概要

Amazon Connect Customer のエージェントワークスペースに、画面スペースを最適化する 2 つの新しいレイアウト「Modern」と「Classic」が追加されました。レイアウトはワークスペース上のコンポーネントとアプリケーションの配置を制御するもので、管理者はチームごとに最適なレイアウトを選択して割り当てることができます。これにより、エージェントの業務効率と満足度の向上が期待できます。

Modern レイアウトは、コンタクトコントロールをワークスペース上部のコントロールバーに配置することで、音声通話中にアプリケーションとエージェントアシストの表示領域を最大化します。チャット、メール、タスクの対応時には、従来よりも広い読み書き領域を提供します。他社のエージェントデスクトップ (コントロールが上部に配置されたタイプ) から移行するチームに推奨されます。

Classic レイアウトは、従来のエージェントワークスペースの外観と操作感を維持しながら、チャネルごとに拡大縮小するコンタクトコントロールや、サイズ変更可能なエージェントアシストアプリケーションなどの改善を加えたものです。既存のワークスペースに慣れているチームに適しています。

**アップデート前の課題**

- エージェントワークスペースのレイアウトは 1 種類のみで、チームの業務内容や習熟度に応じて配置を変更できなかった
- 音声通話中もコンタクトコントロールが画面の一定領域を占有し、アプリケーションやエージェントアシストの表示領域が制限されていた
- チャットやメールの対応時に読み書き領域が狭く、長文のやり取りで視認性が低下していた
- 他社のエージェントデスクトップ (コントロールが上部配置) から移行するチームにとって、操作感の違いが習熟の障壁になっていた

**アップデート後の改善**

- 管理者が UI Management のワークスペース機能を使い、チーム (ユーザーまたはルーティングプロファイル) ごとに Modern / Classic レイアウトを割り当てられるようになった
- Modern レイアウトでは音声通話中のコントロールが上部のコントロールバーに集約され、画面全体をアプリケーションとエージェントアシストに活用できるようになった
- チャット、メール、タスクでは、より高く広い読み書き領域が確保され、対応効率が向上した
- Classic レイアウトでもチャネルごとに幅が変化するコンタクトコントロールと、サイズ変更可能なエージェントアシストが利用可能になった

## サービスアップデートの詳細

### 主要機能

1. **Modern レイアウト**
   - ヘッダーバー、コンタクトリスト、コンタクトコントロールバー、チャネル別コンタクトコントロール、アプリケーションタブ、エージェントアシストの 6 コンポーネントで構成
   - 音声通話中は、ミュート、保留、転送、通話終了などの操作がすべて上部のコンタクトコントロールバーに集約され、その下の全領域をアプリケーションとエージェントアシストに使用可能
   - 音声通話でコンタクトコントロールが表示されるのは、アフターコンタクトワーク中、トランスクリプト利用時、ビデオ通話有効時のみ
   - チャット、メール、タスクでは、コンタクトコントロールがアプリケーションの左側に表示され、Classic レイアウトより高く広い読み書き領域を提供
   - コンタクトリストはアクティブなコンタクトが 2 件以上ある場合のみ表示され、チャネル別アイコンのリストに折りたたみ可能。チャットでは最新メッセージのプレビューも表示
   - コンタクトリスト、コンタクトコントロール、エージェントアシストは展開、折りたたみ、サイズ変更が可能
   - アクティブなコンタクトがない場合はウェルカムメッセージが表示され、コンタクトなしでのアプリケーション利用や、画面右上のボタンからの新規コンタクト開始が可能

2. **Classic レイアウト**
   - ヘッダーバー、コンタクトリスト、コンタクトコントロール、アプリケーションタブ、エージェントアシストの 5 コンポーネントで構成
   - 従来のレイアウトと同様の外観と操作感を維持
   - 従来レイアウトとの違いは 4 点。ステータス切り替えなどがヘッダーバーに移動、チャットとメールのコンタクトコントロールがデフォルトで広く表示、チャネル間でコンタクトを切り替えてもコントロールの幅を維持、エージェントアシストのサイズ変更が可能
   - 既存のエージェントワークスペースに慣れているチームに推奨

3. **チームごとのレイアウト割り当て**
   - 管理者が UI Management のワークスペース機能でレイアウトを選択し、ユーザーまたはルーティングプロファイル単位で割り当て可能
   - 可視性は「全ユーザーに表示」「割り当てたユーザーのみに表示」「非表示 (準備・テスト用)」から選択可能
   - レイアウトを割り当てられていないエージェントは、引き続き従来のレイアウトを使用

4. **共通の設定メニュー**
   - 両レイアウトとも、ヘッダーバーのドロップダウンメニューから言語、ライト / ダークモード、サインアウトを操作可能
   - デバイス設定ダイアログからカメラ、スピーカー、マイク、着信音などを変更可能

## 技術仕様

### レイアウトの比較

| 項目 | Modern レイアウト | Classic レイアウト |
|------|-------------------|--------------------|
| コンタクトコントロールの位置 | 上部のコントロールバー + チャネル別コントロール | 画面左側 (従来と同様) |
| 音声通話中の画面利用 | コントロールバー以外の全領域をアプリケーションに利用可能 | コンタクトコントロールが左側に常時表示 |
| チャット / メール / タスク | より高く広い読み書き領域 | デフォルトで従来より広いコントロール幅 |
| コンタクトリスト | 2 件以上のコンタクト時のみ表示、アイコンに折りたたみ可能 | 常時表示 (従来と同様) |
| エージェントアシスト | サイズ変更可能 | サイズ変更可能 |
| 推奨対象 | 他社エージェントデスクトップからの移行チーム | 既存ワークスペースに慣れたチーム |

### レイアウトのプレビュー

両レイアウトは AWS マネージドビューとして提供されます。割り当て前にプレビューするには、**UI Management** > **Views** で **Agent Workspace - Classic** または **Agent Workspace - Modern** を UI ビルダーで開きます。

### 必要な権限

ワークスペースの作成と割り当てには、セキュリティプロファイルに以下の権限が必要です。

| 権限 | 内容 |
|------|------|
| ワークスペースの表示 / 編集 / 作成 / 削除 | ワークスペースのライフサイクル管理 |
| ワークスペースの割り当て / 可視性の編集 | ユーザーやルーティングプロファイルへの割り当て |

## 設定方法

### 前提条件

1. Amazon Connect Customer インスタンスが利用可能リージョンに存在すること
2. セキュリティプロファイルにワークスペースの表示、編集、作成、削除、割り当て、可視性編集の権限があること
3. 割り当て対象のユーザーまたはルーティングプロファイルが作成済みであること

### 手順

#### ステップ 1: ワークスペースを作成してレイアウトを設定する

1. Connect Customer の管理ワークスペースを開く
2. **UI Management** > **Workspaces** に移動する
3. **Add new workspace** を選択し、ワークスペース名を入力する (説明とタイトルは任意)
4. **Save** を選択すると、ワークスペースが作成され詳細ページが開く
5. **Pages** セクションで **Add page** を選択し、**Use existing Connect page** を選択する
6. **Page** で **Agent Workspace** を選択する
7. **Page layout** で **Agent Workspace - Classic** または **Agent Workspace - Modern** を選択する
8. **View version** で **LATEST** を選択し、**Save** を選択する

管理ワークスペース上でワークスペースを作成し、使用するレイアウトをページに紐付けます。

#### ステップ 2: ワークスペースをエージェントに割り当てる

1. ワークスペース詳細ページの **Assignments** セクションに移動する
2. 可視性ドロップダウンから **Visible to all users**、**Visible to assigned users**、**Visible to no users** のいずれかを選択する
3. **Visible to assigned users** を選択した場合は **Add assignments** を選択する
4. **Users** で対象エージェントを検索して選択する
5. **Routing profiles** でルーティングプロファイルを選択する (プロファイル内の全エージェントに一括割り当てが可能で、チーム単位の割り当てに最適)
6. **Save** を選択する

割り当てが完了すると、対象エージェントに新しいレイアウトが表示されます。割り当てを解除するには、該当の割り当てを選択して **Delete** を選択します。

#### ステップ 3: レイアウトを事前にプレビューする (任意)

1. **UI Management** > **Views** に移動する
2. **Agent Workspace - Classic** または **Agent Workspace - Modern** を UI ビルダーで開く

本番のエージェントに割り当てる前に、レイアウトの見た目を確認できます。可視性を **Visible to no users** にしたままテストすることも可能です。

## メリット

### ビジネス面

- **エージェントの生産性向上**: 音声通話中の画面領域最大化や、チャット / メールの広い読み書き領域により、対応効率が向上する
- **移行の容易化**: コントロール上部配置の他社エージェントデスクトップから移行するチームは、Modern レイアウトにより操作感の変化を抑えてスムーズに移行できる
- **変更管理の柔軟性**: 既存チームには Classic、新規 / 移行チームには Modern というように、チームの状況に応じた段階的な展開が可能

### 技術面

- **チーム単位の割り当て**: ルーティングプロファイル単位の割り当てにより、チーム全体へのレイアウト展開を一括で実行できる
- **安全な展開**: 可視性設定 (全ユーザー / 割り当てユーザーのみ / 非表示) により、テストから段階的展開までを制御できる
- **AWS マネージドビュー**: レイアウトは AWS が管理するビューとして提供されるため、独自のカスタム開発なしで利用できる

## デメリット・制約事項

### 制限事項

- 利用可能リージョンは 9 リージョンに限定される (東京リージョンは現時点で対象外)
- レイアウトを割り当てていないエージェントは従来のレイアウトのまま変更されない
- Modern レイアウトでは、音声通話中のコンタクトコントロールはアフターコンタクトワーク中、トランスクリプト利用時、ビデオ通話有効時のみ表示される
- ワークスペースの管理にはセキュリティプロファイルへの権限追加が必要

### 考慮すべき点

- Classic レイアウトも従来レイアウトと完全に同一ではなく、ステータス切り替えの位置などが変わるため、エージェントへの事前周知が必要
- Modern レイアウトではコンタクトリストの表示条件 (2 件以上のコンタクト時のみ) が変わるため、複数コンタクトを扱うチームでは運用への影響を確認すべき
- レイアウト変更はエージェントの操作習慣に影響するため、ピーク時間帯を避けた段階的な展開が望ましい

## ユースケース

### ユースケース 1: 他社コンタクトセンター製品からの移行

**シナリオ**: コントロールが画面上部に配置された他社のエージェントデスクトップを利用してきたコンタクトセンターが、Amazon Connect Customer へ移行する。

**実装例**:
```
1. 移行対象チームのルーティングプロファイルを確認
2. Modern レイアウトを設定したワークスペースを作成
3. 可視性を「Visible to assigned users」に設定し、移行チームの
   ルーティングプロファイルを割り当て
```

**効果**: 従来製品に近い操作感を提供することで、エージェントの再教育コストを削減し、移行後の生産性低下を最小化できる。

### ユースケース 2: 音声中心のチームでのアプリケーション活用強化

**シナリオ**: 音声通話が中心のサポートチームで、通話中に Customer Profiles、Cases、サードパーティ CRM アプリケーションを頻繁に参照している。

**実装例**:
```
1. 音声チーム用のワークスペースを作成し Modern レイアウトを設定
2. 音声チームのルーティングプロファイルに割り当て
3. 通話中はコントロールバー以外の全領域でアプリケーションと
   エージェントアシストを表示
```

**効果**: 通話中の画面スペースが最大化され、顧客情報やナレッジの参照がしやすくなり、平均処理時間 (AHT) の短縮に寄与する。

### ユースケース 3: 既存チームへの段階的な機能改善の提供

**シナリオ**: 既存のエージェントワークスペースに慣れたチャット / メール対応チームに対し、操作感を大きく変えずに利便性を向上させたい。

**実装例**:
```
1. Classic レイアウトを設定したワークスペースを作成
2. 可視性を「Visible to no users」にしてプレビューで検証
3. 検証後、対象チームのルーティングプロファイルに割り当てて展開
```

**効果**: 従来の操作感を維持しながら、チャネルごとに最適化されたコントロール幅やサイズ変更可能なエージェントアシストにより、読み書きのしやすさが向上する。

以下の 9 リージョンで利用可能です。

- アジアパシフィック (ソウル)

## 関連サービス・機能

- **Amazon Connect Customer Profiles**: エージェントワークスペースに顧客情報を表示する機能。両レイアウトのアプリケーションタブで利用可能
- **Amazon Connect Customer Cases**: ケース管理機能。アプリケーションタブに統合され、レイアウトに応じた表示領域で利用可能
- **エージェントアシスト (Amazon Q in Connect)**: リアルタイムのレコメンデーションを提供。両レイアウトでサイズ変更可能になった
- **ステップバイステップガイド**: コンタクトセンターの定型業務を視覚的にガイドする機能。ワークスペース内で利用可能
- **サードパーティアプリケーション統合**: CRM などの外部アプリケーションをワークスペースに統合し、画面切り替えを削減

## まとめ

Amazon Connect Customer のエージェントワークスペースに Modern と Classic の 2 つのレイアウトが追加され、管理者がチームごとに最適な画面構成を割り当てられるようになりました。他社製品からの移行チームには Modern、既存ワークスペースに慣れたチームには Classic を割り当てるなど、チームの状況に応じた展開が可能です。まずは UI Management の Views でレイアウトをプレビューし、対象チームのルーティングプロファイルへ段階的に割り当てることを推奨します。
