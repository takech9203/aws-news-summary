# AWS News Summary v0.3.0

*Released: 2026-03-03*

---

## English

### 🚀 What's New

This is a major feature release introducing a **subagent architecture** for parallel report generation, along with many improvements ported from the google-cloud-news-summary project.

### ✨ Features

- **Subagent Parallel Processing**: Report creation is now delegated to `report-generator` subagents via the Task tool, enabling parallel execution (batch size: 10)
- **Infographic Batch Processing**: Infographic generation now uses batch processing (batch size: 5) with delays to avoid SDK race conditions
- **`--days` Parameter**: New CLI option to specify how many days back to look for updates (default: 3)
- **Module-level Tool Constants**: `COMMON_TOOLS` and `MCP_TOOLS` extracted as reusable constants
- **Simplified Agent Prompts**: Agents now delegate to `SKILL.md` for workflow guidance, keeping `run.py` lean
- **SDK Race Condition Workaround**: Handles the known Issue #584 race condition in the Claude Agent SDK
- **CLI Exit Code Handling**: `result_received` flag ensures successful runs are not incorrectly treated as failures
- **Japanese Comments**: All comments and docstrings translated to Japanese
- **Updated Architecture Diagrams**: README diagrams updated to reflect the new batch processing architecture

### 📝 Changes

#### Added
- ✨ Subagent support for parallel report generation via Task tool
- ✨ `--days` CLI parameter for configurable lookback period
- ✨ Batch processing for infographic generation with inter-batch delays
- 🛠️ `COMMON_TOOLS` and `MCP_TOOLS` module-level constants
- 🛡️ SDK race condition workaround (Issue #584)
- 🛡️ `result_received` flag for CLI exit code error handling

#### Changed
- 🔄 Orchestrator prompt redesigned for subagent delegation
- 🔄 Agent prompts simplified to use Skill tool for workflow
- 📝 All comments and docstrings translated to Japanese
- 📊 README architecture diagrams updated for batch processing

### ⚠️ Breaking Changes

None. The subagent architecture is backward-compatible — the same `run.py` interface is preserved.

## 日本語

### 🚀 新機能

**サブエージェントアーキテクチャ**を導入した主要機能リリースです。並列レポート生成が可能になり、google-cloud-news-summary プロジェクトからの多くの改善が取り込まれました。

### ✨ 機能

- **サブエージェント並列処理**: Task ツール経由で `report-generator` サブエージェントにレポート作成を委譲し、並列実行を実現 (バッチサイズ: 10)
- **インフォグラフィックバッチ処理**: SDK レースコンディション対策として遅延を入れたバッチ処理を実装 (バッチサイズ: 5)
- **`--days` パラメータ**: 遡って取得する日数を指定する CLI オプションを追加 (デフォルト: 3)
- **モジュールレベルのツール定数**: `COMMON_TOOLS` と `MCP_TOOLS` を再利用可能な定数として抽出
- **シンプルなエージェントプロンプト**: エージェントが `SKILL.md` に委譲することで `run.py` をシンプルに保つ
- **SDK レースコンディション対策**: Claude Agent SDK の既知の Issue #584 への対処を実装
- **CLI 終了コードハンドリング**: `result_received` フラグで成功した実行が誤ってエラーとして扱われないよう対処
- **日本語コメント**: すべてのコメントとドキュメント文字列を日本語に翻訳
- **アーキテクチャ図の更新**: バッチ処理アーキテクチャを反映した README 図に更新
