# AWS News Summary v0.5.0

*Released: 2026-06-09*

---

## English

### 🚀 What's New

This release updates the models to Claude Opus 4.8 and Claude Sonnet 4.6 for improved performance.

### ✨ Features

- **Model Upgrade**: Primary model updated to Claude Opus 4.8 — optimized for coding, agents, and deeper reasoning in enterprise workflows
- **Fallback Upgrade**: Fallback model updated to Claude Sonnet 4.6

### 📊 Model Configuration

| Role | Model | Model ID |
|------|-------|----------|
| Primary | Claude Opus 4.8 | `global.anthropic.claude-opus-4-8` |
| Fallback | Claude Sonnet 4.6 | `global.anthropic.claude-sonnet-4-6` |

### 📝 Changes

#### Changed
- 🔄 Updated primary model: `claude-opus-4-6-v1` → `claude-opus-4-8`
- 🔄 Updated fallback model: `claude-sonnet-4-5-20250929-v1:0` → `claude-sonnet-4-6`

### 🔗 Resources

- [Claude Opus 4.8 Documentation](https://docs.aws.amazon.com/bedrock/latest/userguide/model-card-anthropic-claude-opus-4-8.html)

### ⚠️ Breaking Changes

None. This is a backward-compatible model update.
