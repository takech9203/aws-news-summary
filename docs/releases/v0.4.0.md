# AWS News Summary v0.4.0

*Released: 2026-03-05*

---

## English

### 🚀 What's New

This release focuses on stability and performance improvements, addressing Bedrock API rate limits and CI/CD reliability.

### ✨ Features

- **Reduced Subagent Batch Size**: Lowered the report-generator batch size to reduce Bedrock API rate limit errors
- **CI Timeout Extended**: Increased the AWS news summary CI job timeout to 120 minutes for large batches
- **Secrets Management Fix**: `AWS_ROLE_ARN` now correctly uses `secrets` instead of `vars` in CI
- **CLAUDE.md Cleanup**: Removed AWS-specific references to make the project more portable

### 📝 Changes

#### Fixed
- 🐛 Reduced subagent batch size to avoid Bedrock API rate limit errors
- 🐛 Fixed `AWS_ROLE_ARN` to use `secrets` instead of `vars` in CI configuration

#### Changed
- ⏱️ Increased CI job timeout to 120 minutes
- 📝 Removed AWS-specific references from `CLAUDE.md`

### ⚠️ Breaking Changes

None.
