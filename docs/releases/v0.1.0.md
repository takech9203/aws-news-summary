*Released: 2026-02-14*

## English

### 🚀 Initial Release

The first release of AWS News Summary — a Claude Agent SDK skill that automatically fetches AWS What's New and AWS API Changes feeds, and generates detailed Japanese reports.

### ✨ Features

- **RSS Feed Ingestion**: Fetch AWS What's New and AWS API Changes via curl + Python parsers
- **Japanese Report Generation**: Generate detailed Markdown reports in Japanese using Claude on Amazon Bedrock
- **Infographic Generation**: Convert reports into HTML infographics in graphic-recording style
- **CI/CD Integration**: Automated daily execution via GitHub Actions and GitLab CI
- **MCP Support**: AWS documentation enrichment via `aws-knowledge-mcp-server`
- **Duplicate Detection**: Automatically skip already-reported items

## 日本語

### 🚀 初回リリース

AWS News Summary の初回リリースです。Claude Agent SDK スキルとして、AWS What's New と AWS API Changes のフィードを自動取得し、日本語で詳細なレポートを生成します。

### ✨ 機能

- **RSS フィード取得**: curl + Python パーサーで AWS What's New と AWS API Changes を取得
- **日本語レポート生成**: Amazon Bedrock 上の Claude を使用して日本語の詳細 Markdown レポートを生成
- **インフォグラフィック生成**: グラフィックレコーディング風の HTML インフォグラフィックに変換
- **CI/CD 連携**: GitHub Actions と GitLab CI による毎日自動実行
- **MCP サポート**: `aws-knowledge-mcp-server` 経由で AWS ドキュメントを補完
- **重複検出**: レポート済みのアイテムを自動スキップ
