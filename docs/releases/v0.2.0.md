# AWS News Summary v0.2.0

*Released: 2026-02-15*

---

## English

### 🚀 What's New

This release improves the CI/CD infrastructure setup, with better IAM automation and CI error handling.

### ✨ Features

- **OIDC Provider Reuse**: IAM deployment script now supports reusing an existing OIDC provider instead of always creating a new one
- **Flexible Repository Config**: Repository/project name is now optional in `deploy-iam.sh`
- **Improved CI Error Handling**: Better AWS authentication error messages and artifact setup in CI pipelines
- **Architecture Diagram Required**: AWS news reports now require a Mermaid architecture diagram section
- **Self-referencing Link Removal**: Infographic footers no longer include links back to themselves
- **Skill Directory Renamed**: Skill directory standardized to `aws-news-summary` (was `awsnews-summary`)
- **CloudFormation Tag Standardization**: Consistent tag format across all CloudFormation templates
- **Improved CI/CD Documentation**: Detailed resource tables added to setup guides

### 📝 Changes

#### Added
- ✨ Support for reusing existing OIDC providers in IAM setup
- 📋 Architecture diagram requirement in report template
- 📚 Detailed resource tables in CI/CD setup documentation (`docs/SETUP.md`)

#### Changed
- 🔄 Renamed skill directory: `awsnews-summary` → `aws-news-summary`
- 🏷️ Standardized CloudFormation tag format
- 🔧 Improved AWS authentication error handling in CI
- 📝 Made repository/project name optional in `deploy-iam.sh`

#### Fixed
- 🐛 Removed self-referencing links from infographic footers

### ⚠️ Breaking Changes

- Skill directory renamed from `.claude/skills/awsnews-summary/` to `.claude/skills/aws-news-summary/`. Update any local references if needed.

## 日本語

### 🚀 新機能

CI/CD インフラのセットアップを改善し、IAM 自動化と CI エラーハンドリングを強化しました。

### ✨ 機能

- **OIDC プロバイダー再利用**: IAM デプロイスクリプトが既存の OIDC プロバイダーを再利用できるよう対応
- **柔軟なリポジトリ設定**: `deploy-iam.sh` でリポジトリ/プロジェクト名がオプションに
- **CI エラーハンドリング改善**: CI パイプラインでの AWS 認証エラーメッセージとアーティファクト設定を改善
- **アーキテクチャ図の必須化**: AWS ニュースレポートに Mermaid アーキテクチャ図セクションが必須に
- **自己参照リンクの削除**: インフォグラフィックフッターの自己参照リンクを削除
- **スキルディレクトリのリネーム**: `awsnews-summary` → `aws-news-summary` に標準化
- **CloudFormation タグの標準化**: 全 CloudFormation テンプレートのタグ形式を統一
- **CI/CD ドキュメント改善**: セットアップガイドに詳細なリソーステーブルを追加

### 📝 変更内容

#### 追加
- ✨ IAM セットアップで既存 OIDC プロバイダーの再利用をサポート
- 📋 レポートテンプレートにアーキテクチャ図の必須セクションを追加
- 📚 CI/CD セットアップドキュメント (`docs/SETUP.md`) に詳細なリソーステーブルを追加

#### 変更
- 🔄 スキルディレクトリのリネーム: `awsnews-summary` → `aws-news-summary`
- 🏷️ CloudFormation タグ形式を標準化
- 🔧 CI での AWS 認証エラーハンドリングを改善
- 📝 `deploy-iam.sh` でリポジトリ/プロジェクト名をオプション化

#### 修正
- 🐛 インフォグラフィックフッターの自己参照リンクを削除

### ⚠️ 破壊的変更

- スキルディレクトリが `.claude/skills/awsnews-summary/` から `.claude/skills/aws-news-summary/` にリネームされました。ローカルの参照がある場合は更新が必要です。
