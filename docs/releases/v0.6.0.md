# AWS News Summary v0.6.0

*Released: 2026-07-26*

---

## English

### 🚀 What's New

This release updates the models to the latest 5th generation Claude models for improved performance and capabilities.

#### Model Updates

**Primary Model: Claude Fable 5**
- Anthropic's next-generation model for complex knowledge work and coding
- Capable of sustained autonomous operation across multi-day tasks
- Plans across stages, delegates to sub-agents, and self-verifies its work
- Model ID: `global.anthropic.claude-fable-5`

**Fallback Model: Claude Opus 5**
- Anthropic's most advanced Opus model
- Provides top-tier intelligence at Opus-tier pricing
- Offers deeper reasoning for long documents and higher accuracy for complex analysis
- Model ID: `global.anthropic.claude-opus-5`

### 📊 Model Configuration

| Role | Model | Model ID |
|------|-------|----------|
| Primary | Claude Fable 5 | `global.anthropic.claude-fable-5` |
| Fallback | Claude Opus 5 | `global.anthropic.claude-opus-5` |

### 🔧 Technical Details

- Uses Bedrock global inference endpoints for optimal performance
- Verified compatibility with Claude Agent SDK
- Confirmed model IDs against AWS official documentation
- Test script included for model verification

### 📝 Changes

#### Added
- ✨ Model update: Claude Fable 5 as primary model
- ✨ Model update: Claude Opus 5 as fallback model
- 🧪 Test script for model ID verification (`test_model_ids.py`)

#### Changed
- 🔄 Updated `run.py` model configuration
- 📝 Updated model comments

### 🔗 Resources

None. This is a backward-compatible model update.

### 📦 Installation

No changes to the installation process. Continue using the existing setup.
